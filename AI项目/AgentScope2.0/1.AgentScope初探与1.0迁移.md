# AgentScope初探与1.0迁移

> 先区分 Core、Harness 与模型扩展，再开始写 Agent。版本固定为 **v2.0.4**；返回 [[AI项目/AgentScope2.0/README]]。

## 框架定位与模块

推理与行动 Reasoning and Acting（ReAct）仍是主循环；2.0 把会话状态、权限和长期运行配套能力拆得更明确。

| 模块 | 负责什么 | 使用入口 |
|:---|:---|:---|
| `agentscope-core` | Agent、消息、事件、工具、权限、状态接口 | `ReActAgent` |
| `agentscope-harness` | 工作区、记忆、压缩、计划、子 Agent 等装配 | `HarnessAgent`，包装 Core |
| `agentscope-extensions-model-*` | 模型提供商与 formatter | 独立依赖，按实际提供商选 |
| `agentscope-service` | 服务化与托管运行相关组件 | 本系列先学 SDK，不把服务部署当成创建 Agent 的前提 |

本地 pom 声明 Java 17、revision=2.0.4；这不是对所有 2.x 或未来版本的保证。

## 最小依赖

将以下依赖放入已有 Maven 项目的 `<dependencies>`，编译版本设为 Java 17。示例固定 2.0.4，避免学习时依赖漂移。

```xml
<dependency>
    <groupId>io.agentscope</groupId>
    <artifactId>agentscope-core</artifactId>
    <version>2.0.4</version>
</dependency>
<dependency>
    <groupId>io.agentscope</groupId>
    <artifactId>agentscope-extensions-model-dashscope</artifactId>
    <version>2.0.4</version>
</dependency>
```

## 最小代码

运行环境需提供 `DASHSCOPE_API_KEY`；下面只演示 Core，不装配文件工具或工作区。

```java
import io.agentscope.core.ReActAgent;
import io.agentscope.core.agent.RuntimeContext;
import io.agentscope.core.message.Msg;
import io.agentscope.core.message.UserMessage;
import java.util.List;

public class HelloAgent {
    public static void main(String[] args) {
        ReActAgent agent = ReActAgent.builder()
                .name("learning-assistant")
                .sysPrompt("你是一个帮助理解 Java Agent 的助手。")
                .model("dashscope:qwen-plus")
                .build();
        RuntimeContext ctx = RuntimeContext.builder()
                .userId("alice").sessionId("lesson-1").build();
        Msg result = agent.call(List.of(new UserMessage("用一句话解释 ReAct。")), ctx).block();
        System.out.println(result.getTextContent());
    }
}
```

字符串模型 ID 由注册机制解析，对应扩展必须在 classpath；仅加 core 不能推导成已安装所有模型。

## 迁移先做四件事

1. 按提供商替换模型类 import，例如 DashScope 位于 `io.agentscope.extensions.model.dashscope`。
2. 新代码通过 RuntimeContext 传用户与会话，通过 AgentStateStore 保存状态。
3. 优先使用 Middleware 与 AgentEvent；旧 Hook 存在兼容路径，不能简单认定已经删除。
4. 重审长期记忆、RAG、Skill 与压缩 API；能编译的 deprecated 接口不代表新版推荐用法。

先看第 3、7、9、13 篇建立状态和执行边界，再接 Harness。完整映射见 README。
