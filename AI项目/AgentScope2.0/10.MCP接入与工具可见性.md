# MCP接入与工具可见性

> 协议连接、注册与过滤分别核对，模型看到工具不代表调用已授权。版本固定为 **v2.0.4**；返回 [[AI项目/AgentScope2.0/README]]。

## MCP 的位置

模型上下文协议 Model Context Protocol（MCP）把远端能力转换成 Toolkit 可处理的工具。推理循环仍负责选工具、权限评估与结果回填；MCP 连接成功不等于业务权限正确。

本标签 McpClientBuilder 提供 stdio、SSE 与 Streamable HTTP 接入路径。实际传输能力以服务端和 SDK 版本协商为准，不能从类注释推断所有 HTTP 工具都无状态。

## 接入片段

```java
import io.agentscope.core.tool.Toolkit;
import io.agentscope.core.tool.mcp.McpClientBuilder;
import io.agentscope.core.tool.mcp.McpClientWrapper;

McpClientWrapper client = McpClientBuilder.create("learning-mcp")
        .streamableHttpTransport(System.getenv("LEARNING_MCP_URL"))
        .buildAsync().block();
Toolkit toolkit = new Toolkit();
toolkit.registerMcpClient(client).block();
// 把 toolkit 传入 ReActAgent builder；应用退出时按实际客户端所有权释放连接。
```

环境变量需提供服务端 URL；此片段未连接真实 MCP 服务。需要官方 MCP SDK 依赖，版本与本标签 documentation 示例 pom 保持一致，不从旧教程随意抄版本。

## 三层检查

| 层次 | 检查内容 | 常见误判 |
|:---|:---|:---|
| 连接 | 进程/URL、鉴权、初始化与请求超时 | 能连通就认为所有工具可用 |
| 注册与可见性 | 工具名、组、允许/拒绝列表、请求视图 | 不展示就认为不能被任何入口调用 |
| 执行与授权 | 权限规则、业务身份、实际资源权限 | 模型会选择就代表已经获授权 |

请求级外部工具与 MCP 注册是不同机制；前者只带 schema，可在名字冲突时覆盖后端视图。需对照第 9 篇核对实际解析顺序。

## 调用上下文与元数据

MCP Builder 有元数据传播配置；传播内容与服务端使用方式应逐项检查。RuntimeContext 的任意对象不会因此自动全部变成远端可信身份。

## 验收建议

建议验证初始化失败、超时、列表为空、同名覆盖、服务端拒绝、会话身份传播与连接关闭。⚠️ raw 缺失，待补充：本目录真实 MCP 联调和权限隔离记录。
