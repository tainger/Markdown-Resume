# 实战：三层记忆与会话恢复

> 给出可复查的配置与验收步骤，区分源码支持和实际跑通。版本固定为 **v2.0.4**；返回 [[AI项目/AgentScope2.0/README]]。

## 实战目标

延续 1.0 的三层思路：当前推理上下文 → 可恢复会话 → 长期事实。2.0 中分别落到 AgentState.context、AgentStateStore 与工作区记忆文件/工具；原始日志作为历史证据补充。

依赖第 1 篇模型扩展，将 core 依赖替换为同版本 `agentscope-harness`（它会引入 core）。

## 配置片段

```java
import io.agentscope.core.agent.RuntimeContext;
import io.agentscope.core.message.UserMessage;
import io.agentscope.harness.agent.HarnessAgent;
import io.agentscope.harness.agent.memory.compaction.CompactionConfig;
import java.nio.file.Path;

// 放入应用方法中；运行前设置 DASHSCOPE_API_KEY。
HarnessAgent agent = HarnessAgent.builder()
        .name("memory-lab")
        .sysPrompt("依据已知信息回答；没有证据时说明不确定。")
        .model("dashscope:qwen-plus")
        .workspace(Path.of(".agentscope/memory-lab"))
        .compaction(CompactionConfig.builder()
                .triggerMessages(12)
                .keepMessages(4)
                .keepTokens(0)
                .build())
        .build();
try {
    agent.call(new UserMessage("我叫小林，正在准备 Java 技术分享。"),
            RuntimeContext.builder().userId("alice").sessionId("lab-1").build()).block();
    agent.call(new UserMessage("我正在准备什么？"),
            RuntimeContext.builder().userId("alice").sessionId("lab-1").build()).block();
} finally {
    agent.close();
}
```

示例缩小消息阈值只是便于观察，不是生产推荐值；工具回合也会增加消息数。
