# 框架架构与ReAct执行原理

> 答题骨架：机制 → 调用链 → 场景 → 边界。源码为 **v2.0.4**；返回 [[AI项目/AgentScope2.0/interview/README]]。

## Q01｜2.0 的 Core、Harness、Service 如何分工？

**口述答案**：Core 提供 ReAct、工具、事件、权限与状态接口；Harness 包装 Core，把工作区、记忆、压缩、计划与子 Agent 等长期运行能力装配起来；Service 是服务化相关模块。学习裸循环可从 ReActAgent 开始，需要工作区配套再使用 HarnessAgent。

**追问**：引入 Harness 会替换 ReAct 算法吗？主要是在原循环关键位置装配工程能力，并非另造一套完全不同的推理循环。

**边界**：模块定位不能代替具体部署架构，也不代表所有能力都由同一份 AgentState 保存。

**依据**：[[AI项目/AgentScope2.0/1.AgentScope初探与1.0迁移]]、[[AI项目/AgentScope2.0/14.Plan模式、子Agent与Harness部署]]；[HarnessAgent.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-harness/src/main/java/io/agentscope/harness/agent/HarnessAgent.java:169>)、[pom.xml](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/pom.xml:57>)。

## Q03｜一次 call 何时开始？主链是什么？

**口述答案**：返回 Mono 是组装惰性调用，订阅后进入会话队列。获得执行位置后加载 slot 状态，建立 CallExecution，再走生命周期、推理与工具处理，终止时按对应路径保存和清理。

**追问**：只执行 prepareCall 会开始模型请求吗？不会，AgentRun.stream 被订阅才执行。

**边界**：错误、中断、立即取消与正常返回的保存/清理路径不同。

**依据**：[[AI项目/AgentScope2.0/8.ReActAgent执行原理与会话并发]]、[[AI项目/AgentScope2.0/13.Human-in-the-Loop与AgentRun执行控制]]；[AgentBase.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/agent/AgentBase.java:264>)、[AgentRun.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/agent/AgentRun.java:66>)。

## Q04｜reasoning 与 acting 如何连接？

**口述答案**：reasoning 组合上下文与工具视图，消费模型流并累积响应；出现工具调用后进入 acting。acting 做权限判断和执行或挂起，结果写回后继续推理；无后续动作或出现终止条件时返回。

**追问**：模型调用工具等于真实执行吗？模型只提出结构化调用，运行时才决定是否有权限、在哪里执行及怎样回填。

**边界**：一轮结束只表示控制流完成，业务结果还需验证。

**依据**：[[AI项目/AgentScope2.0/8.ReActAgent执行原理与会话并发]]、[[AI项目/AgentScope2.0/9.工具集成、权限治理与请求隔离]]；[ReActAgent.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/ReActAgent.java:1821>)、[PermissionEngine.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/permission/PermissionEngine.java:139>)。

## Q05｜为什么说引擎无状态，却仍看到缓存字段？

**口述答案**：无状态主要指配置引擎与每个会话的 AgentState 解耦。CallExecution 持有本次调用的数据，RuntimeContext 显式传递；实例仍维护缓存、队列和连接等运行资源。

**追问**：中间件如何访问状态？使用 ctx.getAgentState 或 resolveAgentState，避免共享字段记录当前用户。

**边界**：无状态这个设计说法不等于每个字段 immutable，也不自动证明所有业务工具线程安全。

**依据**：[[AI项目/AgentScope2.0/3.多轮会话、RuntimeContext与状态持久化]]、[[AI项目/AgentScope2.0/8.ReActAgent执行原理与会话并发]]；[ReActAgent.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/ReActAgent.java:740>)、[ReActAgent.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/ReActAgent.java:286>)。

## Q06｜pending 工具恢复为什么先检查 ASKING？

**口述答案**：有 pending 时先识别等待人工确认的工具，必须提交 ConfirmResult 才能继续；之后才做可选的孤立调用补洞、空输入续跑或外部结果校验。这样自动恢复不会越过审批。

**追问**：默认开启补洞吗？本标签 enablePendingToolRecovery=false，需要显式配置。

**边界**：合成错误结果用于恢复协议一致性，不代表工具真实执行成功。

**依据**：[[AI项目/AgentScope2.0/8.ReActAgent执行原理与会话并发]]、[[AI项目/AgentScope2.0/13.Human-in-the-Loop与AgentRun执行控制]]；[ReActAgent.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/ReActAgent.java:1821>)、[ReActAgent.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/ReActAgent.java:4815>)。

## Q07｜为什么 Msg 使用内容块？

**口述答案**：文本、思考、工具调用与工具结果有不同语义。ToolUseBlock 带工具名、参数与 ID，ToolResult 用 ID 对应调用；只保存 getTextContent 会丢掉恢复与协议所需结构。

**追问**：流式文本能代替最终结果对象吗？不能，片段、控制事件和完整结果承担不同职责。

**边界**：不要从 REASONING 等标签推断全部内容都是可展示的内部思考。

**依据**：[[AI项目/AgentScope2.0/2.流式输出、结构化输出与执行控制]]、[[AI项目/AgentScope2.0/8.ReActAgent执行原理与会话并发]]；[UserMessage.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/message/UserMessage.java:37>)、[AgentEventType.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/event/AgentEventType.java:40>)。

## Q08｜returnDirect 是否任意工具设置后就马上返回？

**口述答案**：本标签只有整批工具均声明 returnDirect 且结果全部成功等条件满足，才跳过下一轮模型把工具结果作为最终答案。混合批次、分次恢复等情况会回到模型。

**追问**：工具内容只有图片时，纯文本界面一定能显示吗？消息能携带非文本内容，但文字事件投影不能保证展示图片，消费端需处理内容类型。

**边界**：直接返回只控制结果交付，不改变工具权限，也不证明输出可直接公开。

**依据**：[[AI项目/AgentScope2.0/8.ReActAgent执行原理与会话并发]]、[[AI项目/AgentScope2.0/9.工具集成、权限治理与请求隔离]]；[Tool.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/tool/Tool.java:171>)。
