# Skill计划与子Agent协作

> 答题骨架：机制 → 调用链 → 场景 → 边界。源码为 **v2.0.4**；返回 [[AI项目/AgentScope2.0/interview/README]]。

## Q49｜Skill 与 Tool 有什么不同？

**口述答案**：Skill 是说明用途和流程的能力包，可附文档与脚本；Tool 提供实际执行协议与结果。读取 SKILL.md 不等于脚本已经运行，也不等于获得执行权限。

**追问**：Skill 能否调用未注册工具？指令不能凭空创建工具能力，实际执行仍受工具与权限约束。

**边界**：来源于技能文件的内容也需按其信任范围处理。

**依据**：[[AI项目/AgentScope2.0/12.Skill装配、作用域与自学习]]；[DynamicSkillMiddleware.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/skill/DynamicSkillMiddleware.java:62>)、[Tool.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/tool/Tool.java:60>)。

## Q50｜同名 Skill 的四层优先级是什么？

**口述答案**：从低到高为项目全局目录、市场/仓库、工作区共享、用户目录；动态装配根据本次 ctx 获取作用域，高层覆盖同名低层。

**追问**：用户覆盖系统技能是否等于业务权限提升？不等，只改变读取的说明，工具执行仍须授权。

**边界**：禁用动态更新后还要重新确认刷新时机和运行资源。

**依据**：[[AI项目/AgentScope2.0/12.Skill装配、作用域与自学习]]；[skill.md](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/docs/v2/zh/docs/harness/skill.md:182>)、[DynamicSkillMiddleware.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/skill/DynamicSkillMiddleware.java:125>)。

## Q51｜技能自学习为什么需要审核与上下文？

**口述答案**：草稿、正式技能、审计与维护有不同生命周期，晋升要通过配置的闸门。程序化 promoteSkill 在本标签要求 name、reviewerId 与 RuntimeContext，明确用户命名空间。

**追问**：文档两参数示例可以直接用吗？本标签方法应显式带 ctx，残留示例需按实现修正。

**边界**：本目录未实跑技能晋升与回滚，不能声称形成可靠自学习闭环。

**依据**：[[AI项目/AgentScope2.0/12.Skill装配、作用域与自学习]]；[HarnessAgent.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-harness/src/main/java/io/agentscope/harness/agent/HarnessAgent.java:312>)。

## Q52｜Plan Mode 和普通计划提示词有什么差别？

**口述答案**：Plan Mode 有状态与工具拦截，plan_enter 进入，plan_write 写正文，plan_exit 通过 ASK 请求退出；普通提示词只是给模型建议，没有相同的工具约束。

**追问**：开启能力就等于每个任务自动进入计划并被批准吗？不是，要核对实际状态转换与调用。

**边界**：计划正文不是已经完成的可执行工作流。

**依据**：[[AI项目/AgentScope2.0/14.Plan模式、子Agent与Harness部署]]；[PlanModeTools.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-harness/src/main/java/io/agentscope/harness/agent/tool/PlanModeTools.java:46>)、[AgentState.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/state/AgentState.java:236>)。

## Q53｜Plan Mode、todo 与计划文件为什么分开？

**口述答案**：PlanModeContextState 表达阶段和计划路径，todo 是独立任务清单，计划正文在工作区文件。摘要只处理对话，不会代替它们管理状态。

**追问**：只复制 plans/PLAN.md 能完整恢复任务吗？不能，还缺状态、任务记录和外部执行结果。

**边界**：恢复完整性需要按每个存储面分别验收。

**依据**：[[AI项目/AgentScope2.0/14.Plan模式、子Agent与Harness部署]]；[AgentState.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/state/AgentState.java:231>)、[AgentState.java](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/agentscope-core/src/main/java/io/agentscope/core/state/AgentState.java:236>)。

## Q54｜同步子 Agent 超时就一定终止吗？

**口述答案**：Harness 普通同步等待超时可能晋升后台，返回 task_id 而任务继续；RuntimeContext 强制同步时超时语义不同，会走超时/中断而不晋升。

**追问**：主 Agent 怎样取后台完成结果？后续推理前可注入完成提醒，也有任务查询/等待工具。

**边界**：不应把服务端超时响应当成外部或后台任务已经停止的证明。

**依据**：[[AI项目/AgentScope2.0/14.Plan模式、子Agent与Harness部署]]；[subagent.md](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/docs/v2/zh/docs/harness/subagent.md:116>)。

## Q55｜ISOLATED 与 SHARED 能保证什么？

**口述答案**：它们指定子 Agent 的工作区关系，子会话和资源作用域仍要结合实现与 userId/sessionId 理解。独立上下文有助于控制主上下文大小，共享工作区方便交付文件。

**追问**：共享文件能随意并行写吗？不能，应按任务依赖、文件冲突和业务资源决定并发。

**边界**：工作区隔离不是任意代码执行的安全沙箱证明。

**依据**：[[AI项目/AgentScope2.0/14.Plan模式、子Agent与Harness部署]]；[subagent.md](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/docs/v2/zh/docs/harness/subagent.md:109>)。

## Q56｜什么时候用确定性 Pipeline，什么时候用子 Agent？

**口述答案**：步骤固定、依赖明确时由代码控制顺序；需要独立上下文、自主处理或不同能力时再委派子 Agent。互不依赖的任务可并行，有依赖的先等上游并验证结果。

**追问**：模型拆分得很多就代表吞吐更好吗？不一定，通信、模型调用、共享资源和汇总都增加开销。

**边界**：这是设计建议，本目录没有吞吐或成本对比实验。

**依据**：[[AI项目/AgentScope2.0/14.Plan模式、子Agent与Harness部署]]；[subagent.md](</Users/rocky/study/profile/Markdown-Resume/AI项目/AgentScope2.0/repo/agentscope-java/docs/v2/zh/docs/harness/subagent.md:141>)。
