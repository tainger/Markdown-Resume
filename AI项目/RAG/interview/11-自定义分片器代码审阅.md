# 十一、自定义分片器代码审阅

[返回题库目录](./README.md) · 更新：2026-10-20

> 将正文 Markdown、Word 和重叠分片器作为代码阅读素材。以下验证用例是拟定的验收方法，尚未在可编译工程中执行；不将发现风险等同于已复现的运行故障。

## Q1: Markdown 标题跳级、重复标题、代码块内的 # 如何处理？

**难度**: ⭐⭐⭐ 高级

**参考答案**:

**先说结论**：按文档结构解析标题，父子身份不能仅依赖标题文字。

1. 先识别代码围栏等语法上下文，代码内的 `# 配置示例` 不应成为正文标题；围栏类型和闭合方式也要纳入解析。
2. 对正文标题维护层级栈，同级或更高层级新标题出现时弹出旧分支；保留完整章节路径。
3. 跳级标题应有明确策略，例如连接到最近有效祖先，并记录缺失级别；不能凭空生成标题内容。
4. 重复标题可使用文档版本、结构位置和独立片段 ID 区分，不能只用“注意事项”作为全局键。

正文代码通过向前寻找较低级标题关联父块；面试时要说明其假设、复杂度和边界，并比较与解析树或栈实现的取舍。保留标题文本还是只放 metadata，也应验证对检索和来源定位的影响。

**验证**：覆盖无标题、H1→H3、同名标题、多个同级章节、嵌套代码和未闭合围栏；逐节点核对父链、路径与正文内容。

**追问**：父子关系正确就说明能取回完整父内容吗？不是，还需保存父节点内容并维护可查询映射。

## Q2: Word 没有规范标题样式，如何识别章节并控制误判？

**难度**: ⭐⭐⭐ 高级

**参考答案**:

**先说结论**：优先使用结构信息，再用可解释规则兜底；不能因为某行加粗或字号大就认定是标题。

原笔记分别处理 Word 格式，并从标题样式和文本模式识别级别。可将样式、编号、段落位置和格式等作为候选线索；出现冲突时明确规则优先级，低置信度可回退到段落切分。

正文中的编号列表、目录、表格内短句也可能像标题。需要避免目录与正文重复入库，也不能把未识别标题的正文直接丢弃。识别结果保存规则来源和位置，便于人工查看错误。

文件解析与章节检测是两个阶段：格式不支持、解析失败不能伪装成“文档没有章节”。规则针对具体语料校准，不宣称覆盖所有 Word 文档。

**验证**：使用规范样式、纯编号、加粗正文、目录、表格、无标题及 .doc/.docx 样本，人工标注章节边界并统计误分和漏分。

**追问**：用字号最大的段落当一级标题可以吗？只能是启发式线索，需考虑封面、页眉和版式差异。

## Q3: 父块再次按长度切分，如何维护 chunkId、parentChunkId 和章节路径？

**难度**: ⭐⭐⭐ 高级

**参考答案**:

**先说结论**：先定义“标题父节点”与“检索子块”两类身份，再做二次切分；新子块不能丢掉原章节归属。

- 父节点保存完整章节内容及可查询 ID，子块使用独立 ID，并明确指向该父节点。
- 子块保存文档版本、章节路径、分段序号和来源位置；原父节点还有上级时，区分两层关系，不能复用一个字段却含义不清。
- 在重切后重新生成或校验映射；子块 ID 添加序号，不自动保证父记录存在或父子语义正确。
- 若同一段文字被多个祖先内容覆盖，回填时按约定层级取证并去重，控制上下文长度。

正文 Word 示例复制原 metadata，再添加分段 ID 和序号；应检查其父链指向的原块是否仍被保存，而不是仅确认出现了 `parentChunkId` 字段。

**验证**：对超长章节二次切分后逐个回查父块，检查同级章节不串联、版本一致、原文位置可定位；更新后清除失效子块。

**追问**：直接继承原 parentChunkId 就够吗？取决于原字段代表什么，必须检查它是否指向预期的完整回填单元。

## Q4: 如何测试分片器不丢文本、元数据完整且能正常终止？

**难度**: ⭐⭐⭐ 高级

**参考答案**:

**先说结论**：测试可观察的不变量和反例，而不是只检查“能返回几块”。

| 不变量 | 检查方式 |
|:---|:---|
| 内容覆盖 | 记录来源位置，扣除约定的重复后检查原文是否完整；空白清洗需有明确规则 |
| 预算符合 | 使用目标 tokenizer 校验片段，结构完整与长度冲突时有明确处理策略 |
| 元数据保留 | 每块保留文档、版本、来源与授权字段，新增 ID 不能覆盖其他信息 |
| 循环前进 | 超长段落、极端 overlap 和空输入不会卡住或无限输出 |
| 结构与身份 | 父链有效、不同块 ID 不冲突、代码/图片等边界按规则处理 |

正文重叠分片器 `apply` 中使用 `new Document(chunk)`，这段构造没有显式携带原文档 metadata；应把“带页码与权限字段的输入切分后还能否回查”作为具体审阅题。

**验证**：覆盖空文档、超长无分隔文本、换行边界、中文与 emoji、非法 overlap 及带元数据输入；核对结果而非只做快照。

**追问**：把切片直接拼起来等于原文就够吗？使用 overlap 时会重复，应按来源位置和约定清洗规则验证覆盖。
