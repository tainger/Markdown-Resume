## 使用建议

- **准备方向**：先刷基础篇和优化篇，范式演进和评测体系是中高级面试的高频考点
- **答案说明**：每题参考答案均引用本库对应文档的知识点，便于回溯源码
- **面试策略**：遇到 "对比/选型" 类问题，优先从"原理差异 → 适用场景 → 工程代价"三层展开
