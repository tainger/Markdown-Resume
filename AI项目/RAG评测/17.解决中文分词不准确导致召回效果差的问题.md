# ✅解决中文分词不准确导致召回效果差的问题

## 本文脑图

```markmap
- 中文分词不准致召回差
  - 问题
    - ES装了IK分词器却未启用
    - 中文逐字分词，相关内容召不回
  - 创建组件模板
    - ik_analyzer_component
    - custom_ik_max_word索引细粒度
    - custom_ik_smart查询粗粒度
  - 创建索引模板
    - global_search_template匹配所有索引
    - priority 99，composed_of组件模板
    - text：analyzer=ik_max_word，search_analyzer=ik_smart
    - dynamic模板：字符串映射keyword
  - 重建索引验证
    - DELETE know-engine-vector后重建
    - text字段带analyzer/search_analyzer
    - 查询可见中文分词生效
```


我们虽然在ES中安装了IK分词器，但是并没有用上，所以导致中文分词是每个中文字单独作为一个分词了，就导致召回结果不好，明明相关的内容却召不回。


所以我们需要让IK分词器生效。


### 创建组件模板


```
PUT http://127.0.0.1:9200/_component_template/ik_analyzer_component﻿{  "template": {    "settings": {      "analysis": {        "analyzer": {          "custom_ik_max_word": {            "type": "ik_max_word"          },          "custom_ik_smart": {            "type": "ik_smart"          }        }      }    }  }}﻿
```


### 创建索引模板


```
PUT http://127.0.0.1:9200/_index_template/global_search_template﻿{  "index_patterns": ["*"],   "priority": 99,  "composed_of": ["ik_analyzer_component"],  "template": {    "mappings": {      "dynamic_templates": [        {          "strings_as_keyword": {            "match_mapping_type": "string",            "mapping": {              "type": "keyword"            }          }        }      ],      "properties": {        "text": {          "type": "text",          "analyzer": "custom_ik_max_word",          "search_analyzer": "custom_ik_smart"        }      }    }  }}﻿
```


### 重建索引


```
DELETE http://127.0.0.1:9200/know-engine-vector
```


使用命令，或者代码重新创建一个新的索引。然后查看索引，可以看到text字段已经有analyzer和search\_analyzer。


```
"text": { "type": "text", "fields": {   "keyword": {   "type": "keyword",   "ignore_above": 256   } }, "analyzer": "ik_max_word", "search_analyzer": "ik_smart" }
```


在针对问题做查询，就能看到中文的分词了
