# 开篇词：DodoAgent 智能体应用实战全览

> 本系列 23 篇笔记完整拆解「仿豆包」智能体应用的 Java 落地全流程：
> 技术栈 **Spring Boot 3.5.6 + Spring AI 1.1.0 + 通义千问**（qwen-plus / qwen3-vl / nanobanana）+ MySQL + MinIO + PgVector + Reactor。
> 四大业务线：**智能对话**（ReactAgent + MCP 联网）、**文件问答**（RAG + 多模态）、**PPT 生成**（状态机 + python-pptx，全系列最重头）、**DeepResearch**（Plan-Execute 模式）。
> 一条工程化暗线贯穿始终：流式启停 → 多实例任务管理 → Skills 机制 → 上下文压缩。

### 二、文件问答与 PPT 生成（06-11）

```markmap
- 文件问答与 PPT 生成
  - 文件问答助手（06）
    - RAG 链路：上传 → 向量化 → 检索增强

    - LLM 产出大纲 → 结构化 JSON
```

### 四、进阶：Skills 机制与上下文工程（16-23）

```markmap
- Skills 机制与上下文工程
  - Skills 实现原理（16）
    - Skill = 指令包 + 资源 + 脚本
    - 按需注入：description 常驻，正文懒加载
  - 操作系统能力（17）
    - 文件系统 / 终端 / 代码执行类比 OS
    - Agent = 内核，Skills = 应用程序
  - spring-ai-agent-utils（18）
    - Skills 能力沉淀为可复用组件库
  - Think 模型解析（19）
    - 思考链与正文分离：think 标签解析
    - 流式场景下的分段状态机
  - 分阶段流式（20）
    - 阶段事件：规划 / 检索 / 生成各阶段推送
    - 前端进度条联动
  - 重写 PPTX Skill（21）
    - PPT 生成封装为 Skill 复用
  - 上下文压缩（22-23）
    - micro_compact：单轮内工具结果裁剪
    - auto_compact：接近窗口上限自动摘要折叠
    - 保留系统提示 + 近期完整轮次 + 压缩历史
```
