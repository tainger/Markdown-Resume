# ✅为什么不用Java解析PDF文档

  

一般的知识库内容，通常由word、markdown、pdf以及在线文档这几种形式。其中比较难处理的就是pdf。

  

我们可以先试一下，用spring ai和langchain4j的话，处理一下pdf，看看什么效果。

  

先准备一份图文并茂的PDF:

r7-product-manual-20250

123.pdf(46.1 MB)

  

（以上文档在https://thoughts.aliyun.com/workspaces/6963289eb0fc2e001bb052eb/docs/6a847264c71a890001a0a88e 中已提供）

### LangChain4J

  

那我们试试langchain4j。他支持下面几种文档处理器，我们使用pdfbox的试一下。

  

![](https://tcs-devops.aliyuncs.com/storage/113s32801bcf4f0656a4d68ec378476a1d49?Signature=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJBcHBJRCI6IjVlNzQ4MmQ2MjE1MjJiZDVjN2Y5YjMzNSIsIl9hcHBJZCI6IjVlNzQ4MmQ2MjE1MjJiZDVjN2Y5YjMzNSIsIl9vcmdhbml6YXRpb25JZCI6IiIsImV4cCI6MTc4OTg3NTA4MiwiaWF0IjoxNzg5MjcwMjgyLCJyZXNvdXJjZSI6Ii9zdG9yYWdlLzExM3MzMjgwMWJjZjRmMDY1NmE0ZDY4ZWMzNzg0NzZhMWQ0OSJ9.zj4CxCAqtR1E7DSFTNFNTDCDp2FIFN96rhNgD-x39KQ)

和Spring AI差不多，文档的结构读取的是正确的了，该有的问题还是有。

  

也就是说，用JAVA中的工具，解析出来的文档都存在各种问题，而且除了这些问题外，还有些情况也无法处理，比如如果PDF是个扫描件怎么办？PDF中有表格怎么办？PDF中如果存在LaTex公式怎么办，都无能为力了。

  

所以，我们需要换一种能一次性解决搜游问题的方案。
