# 04. 核心原理速览

> 应用开发者**够用即可**的原理。不展开数学推导（见原论文），只讲「这个机制为什么让 DeepSeek 又便宜又快又强」，面试能说清就行。

---

## 一、MoE：稀疏激活 = 便宜快的根因

```
DeepSeek-V3 总参数 671B，分 256 个路由专家 + 1 个共享专家
每次推理只激活 top-8 路由专家 + 1 共享 ≈ 37B 激活参数
```

| 对比 | Dense（如 Llama-70B）| MoE（V3）|
|:---|:---|:---|
| 总参数 | 70B | 671B（大）|
| 激活参数 | 70B（全用）| 37B（只用一小撮）|
| 单次推理 FLOPs | 高（70B）| 低（37B）|
| 显存占用 | 全装 70B | 要装 671B 权重（推理显存压力大）|

> 💡 **一句话**：MoE 把「大模型容量」和「低推理成本」解耦——参数多学得多、激活少算得快。代价是**显存要装下全部 671B**（自部署门槛高）。
>
> DeepSeekMoE 创新：**细粒度专家**（把一个粗专家拆成多个小专家）+ **共享专家**（所有 token 都走的公共知识），路由更灵活、知识更专精。

---

## 二、MLA：KV 缓存压缩 = 长上下文 + 低显存

```
传统 MHA/GQA：每层每头都存 K、V → 长上下文 KV 缓存爆炸
MLA（V2 引入）：把 K、V 联合低秩压缩成一个 latent 向量
              推理时只缓存 latent，需要时再解压成 K/V
```

| 维度 | MHA / GQA | MLA |
|:---|:---|:---|
| KV 缓存大小 | 大 | **小一个数量级** |
| 长上下文支持 | 显存吃紧 | 64K~128K 友好 |
| 推理速度 | KV 大 → 慢 | KV 小 → 快 |

> 💡 **一句话**：MLA = 把 KV 缓存低秩压缩，**长上下文又便宜又快**。这是 V3 能开 128K 上下文且不贵的核心。
>
> 面试加分：MLA 与 GQA 思路相反——GQA 是「多个头共享 K/V」省内存，MLA 是「低秩潜变量解压」，压缩率更高但实现更复杂。

---

## 三、MTP：多 token 预测 = 训练效率 + 推理投机

```
传统：一次预测 1 个 token
MTP：训练时同时预测下 1~N 个 token（多头预测）
推理时可用于「投机解码」——一次猜多个，验证后批量出 token
```

| 作用 | 说明 |
|:---|:---|
| 训练 | 信号更密集，训练效率高 |
| 推理 | 可做 speculative decoding，吞吐提升 |

> V3 默认部署时 MTP 多用于训练；推理侧投机解码需框架支持（SGLang/vLLM 部分实现）。

## 四、R1 的 RL：纯强化学习涌现推理（⭐⭐⭐ 面试皇冠）

### 4.1 R1-Zero：纯 RL 的「顿悟」

```
基座：V3 base 模型
方法：GRPO（Group Relative Policy Optimization）直接 RL，无 SFT 冷启动
奖励：正确性奖励（答案对不对）+ 格式奖励（用 <think> 标签）
结果：模型自己学会「思考 → 验证 → 反思 → 再答」，推理能力涌现！
问题：语言混杂、可读性差、思考链乱
```

### 4.2 R1：冷启动 + RL + 蒸馏

```
① 少量高质量 CoT 冷启动 SFT（解决 R1-Zero 的可读性）
② GRPO RL（推理对齐）
③ 拒绝采样 + SFT（数据扩充，含写作/翻译/编码等非推理任务）
④ 全场景 RL（RLHF，提升有用性、安全性）
⑤ 蒸馏：把 R1 输出做 SFT 给小模型 → 1.5B~70B 六档
```

### 4.3 GRPO 核心思想

```
PPO：要训一个 value 模型估基线，显存/工程重
GRPO：组内采样 G 个回答 → 用「组内均值/最大」当基线（无需 value 模型）
     → 显存省、工程简单，适合大模型推理任务
```

> 💡 **面试金句**：「R1 的突破是证明了——**不给 CoT 数据，只靠正确性奖励 RL，模型能自己长出推理能力**（R1-Zero）。工业落地用冷启动 + 多阶段 RL 修可读性，再蒸馏给小模型摊薄成本。」

## 五、FP8 训练 + DualPipe：工程加速

| 技术 | 作用 |
|:---|:---|
| **FP8 混合精度** | V3 训练用 FP8，显存/算力省一半，精度损失可控 |
| **DualPipe** | 双向流水线并行，计算与通信重叠，跨节点几乎无空等 |
| **aux-loss-free 均衡** | V3 不用辅助损失做专家均衡，靠动态偏置调整，省算力不损精度 |

> 这三条是 V3 「2048 张 H800 训 14.8T token、成本约 557 万美元」的工程底座——**别人花几亿，它花几百万**的根因。面试提一句「训练成本是 GPT-4 级别的 1/10」很加分。

## 六、原理速查表

| 缩写 | 全称 | 一句话 |
|:---|:---|:---|
| MoE | Mixture of Experts | 稀疏激活，671B 参数只激活 37B |
| MLA | Multi-head Latent Attention | KV 低秩压缩，长上下文又便宜又快 |
| MTP | Multi-Token Prediction | 多 token 预测，训练密 + 推理投机 |
| GRPO | Group Relative Policy Optimization | 组内相对基线，无需 value 模型的 PPO 变体 |
| DualPipe | 双向流水线 | 计算通信重叠，跨节点高效 |
| FP8 | 8-bit 浮点 | 训练省一半显存/算力 |

---

## 七、一句话总结

V3 的工程突破是**MoE（671B/37B 激活）+ MLA（KV 压缩）+ MTP + FP8/DualPipe**，让它**容量大、推理省、训练便宜**；R1 的科学突破是**纯 GRPO RL 涌现推理（R1-Zero）**，证明不靠 CoT 数据也能长出思考能力，再用冷启动 + 蒸馏摊薄落地。
