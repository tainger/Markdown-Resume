# RAG 评测系列脑图

> RAG 系统上线前怎么"体检"？本系列 28 篇给出完整答案：**指标体系 → RAGAS 框架 → 数据集工程 → know-engine 真实系统 bad case 逐个击破**。用 **markmap** 渲染为 XMind 风格可交互脑图（缩放/拖拽/折叠、暗色自适应），按四条主线拆成 4 棵子树避免单图过大。

## 一、评测理论与指标体系（01-04）

```markmap
- RAG 评测理论
  - 为什么评测（01）
    - 幻觉：模型自由发挥
    - 检索失败：答非所问
    - 回归防护：改一处坏一片
    - 上线依据：拍感觉→看数据
  - RAG Triad（02）
    - 上下文相关性
      - 检索内容是否切题
    - 忠实度 Faithfulness
      - 回答是否基于检索内容
    - 答案相关性
      - 回答是否回应了问题
  - 核心指标分层（03）
    - 检索层
      - Context Precision 排序质量
      - Context Recall 覆盖质量
    - 生成层
      - Faithfulness 忠实度
      - Answer Relevancy 切题度
      - Answer Correctness 正确性
    - 端到端 + 工程化
      - 延迟/成本/拒答率
  - LLM-as-Judge（04）
    - 用 LLM 给 LLM 打分
    - 评估维度 prompt + 评分细则
    - 位置偏差/自我偏好 治理
```

## 二、框架与 RAGAS 原理（05-07）

```markmap
- 框架与 RAGAS
  - 四大框架对比（05）
    - RAGAS 首选
      - 指标全 + LangChain 集成
    - TruLens
      - Triad 可视化追踪
    - DeepEval
      - pytest 单测集成
    - Phoenix
      - Tracing 观测为主
  - RAGAS 实现原理（06）
    - Context Precision
      - 命中排序加权 precision@k
    - Context Recall
      - 声明反向映射检索上下文
    - Answer Relevancy
      - 反向生成 N 个问题 求相似度
    - Faithfulness
      - 声明拆解 → NLI 逐条判定
    - Answer Correctness
      - 事实 F1 + 语义相似度加权
  - 结果不稳定治理（07）
    - 根因：Judge 模型采样随机
    - 关闭思维链 控温度
    - 多次采样投票
    - 固定 seed 复现
```

## 三、数据集工程与评测执行（08-14）

```markmap
- 数据集与执行
  - 数据集准备四法（08）

    - 历史数据加工
    - 人工构建 金标准
    - 线上真实问答
  - 好评测集标准（09）
    - 题型丰富 单跳/多跳/对比

    - 高质量 Ground Truth
    - 支持多维度指标
  - 文档生成数据集（10）

    - 提取器 标题/摘要/实体
    - 画像 personas × 场景 scenarios
    - 生成样本 问题+答案+上下文
  - 生成 RAG 回答（11）
    - 逐题跑 RAG 链路
    - 记录 检索上下文+答案
  - know-engine 评测集（12）
    - 评测集构成与规模
    - 生成模型选择
    - 流程跑通优先
  - 脚本与运行（13）
    - eval.py 编排全流程

  - 异步加速（14）

```

## 四、know-engine 实战：bad case 逐个击破（15-27）

```markmap
- 实战优化
  - 总纲（15）
    - 评测发现问题 → 定位 → 修复 → 回归
    - bad case 手术台 453 行全景
  - 解析层（16）
    - mineru 多级标题丢失
    - 切分错位 → 召回差
  - 召回层（17-21）
    - 中文分词不准（17）
      - IK 词库补充业务词
    - 查询改写偏差（18）
      - 职责下沉 语义纯净
    - RRF 乱序与重复（19）
      - Content 未覆写 equals
      - 按 chunkId 折叠去重
    - 引用补全乱序（20）
      - HashMap 无序
      - toMap 显式 LinkedHashMap
    - minScore 过滤（21）
      - 相关性阈值 0.6 滤噪
  - 生成层（22/24/25）
    - 优化系统提示词（22）
    - 换模型救忠诚度（24）
    - 分层拒答（25）
      - 拒答规则优先级
  - 评测基准修正（23/26）
    - ground truth 缺陷（23）
    - 自定义评测指标（26）
      - 诉求推进/可操作性维度
  - 总结（27）
    - 评测驱动迭代闭环
```
