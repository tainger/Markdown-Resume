## 数据库初始化

### MySQL

创建数据库

```
CREATE DATABASE dodo DEFAULT CHARACTER SET utf8mb4;
```

导入初始化数据：

```
classpath下：﻿/sql/ai_db.sql
```

执行：

```
mysql -uroot -p dodo < sql/ai_db.sql
```

### PPT 模板路径

数据库会初始化一条 PPT模板数据：表：ai\_ppt\_template，需要修改字段：

`file_path`

改为你本地 PPT 模板路径，例如：

```
/opt/ppt-template/ai.pptx
```

.pptx(13.8 MB)

|  |  |
| --- | --- |
| 接口 | 功能 |
| /agent/chat/stream | 联网搜索问答 |
| /agent/file/stream | 文件问答 |
| /agent/pptx/stream | PPT生成 |
| /agent/deep/stream | 深度研究 |

## 流式响应格式

文本：

```
{  "type": "text",  "content": "回答内容"}
```

思考过程：

```
{  "type": "thinking",  "content": "正在分析问题..."}
```

参考来源：

```
{  "type": "reference",  "content": [],  "count": 3}
```

推荐问题：

```
{  "type": "recommend",  "content": [],  "count": 3}
```
