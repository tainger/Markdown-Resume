## P7 必背清单（速查）

- **运行时数据区**：线程私有（PC/虚拟机栈/本地方法栈）vs 共享（堆/元空间）；PC 是唯一不 OOM 的区域
- **元空间取代永久代**（JDK 8）：位于本地内存，`OOM: Metaspace` 多为类加载器泄漏
- **对象未必在堆上**：逃逸分析 → 栈上分配 / 标量替换 / 锁消除
- **判活用可达性分析 + GC Roots**（引用计数解决不了循环引用）
- **四种引用**：强（不回收）/软（内存不足）/弱（下次 GC）/虚（跟踪回收）
- **分代**：新生代复制（8:1:1）、老年代标记-整理/清除；Minor/Major/Full/Mixed GC 区别
- **跨代引用**：记忆集 + 卡表 + 写屏障
- **收集器演进**：CMS（标记清除，碎片 + Concurrent Mode Failure）→ G1（Region + 可预测停顿）→ ZGC（染色指针 + 读屏障，亚毫秒且与堆无关）
- **类加载五阶段**：准备给零值、初始化 `<clinit>` 才赋真值
- **双亲委派**：保证核心类唯一安全；SPI 靠线程上下文类加载器打破、Tomcat 靠应用私有加载器隔离
- **happens-before** 是并发正确性金标准；**volatile** = 可见性 + 禁止重排（不保证原子性），DCL 必须加
- **排查三板斧**：CPU 高（top -Hp + jstack）、OOM（heap dump + MAT）、频繁 GC（jstat + GC 日志）
