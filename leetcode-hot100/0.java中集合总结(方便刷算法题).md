## 一、按「刷题需求」选容器（最常用的一张表）

| 我想要… | 首选容器 | 关键 API | 复杂度 |
|:---|:---|:---|:---|
| 可变长数组、随机下标访问 | `ArrayList` | `add / get(i) / set(i,v) / size` | 尾插均摊 \(O(1)\)，`get` \(O(1)\) |
| 栈（后进先出） | `ArrayDeque` | `push / pop / peek` | \(O(1)\) |
| 队列（先进先出）/ BFS | `ArrayDeque` | `offer / poll / peek` | \(O(1)\) |
| 双端队列 / 单调队列 | `ArrayDeque` | `offerFirst/Last`、`pollFirst/Last`、`peekFirst/Last` | \(O(1)\) |
| 键值映射、频次统计 | `HashMap` | `put / get / getOrDefault / merge` | 均摊 \(O(1)\) |
| 去重、判重、存在性 | `HashSet` | `add / contains / remove` | 均摊 \(O(1)\) |
| 按 key 有序的映射 | `TreeMap` | `firstKey / ceilingKey / floorKey / headMap` | \(O(\log n)\) |
| 有序集合 / 找前驱后继 | `TreeSet` | `ceiling / floor / higher / lower` | \(O(\log n)\) |
| 堆 / 取最值 / Top-K | `PriorityQueue` | `offer / poll / peek` | 入/出 \(O(\log n)\)，peek \(O(1)\) |
| 保持插入/访问顺序的 Map | `LinkedHashMap` | 同 `HashMap` + 有序遍历 | 均摊 \(O(1)\) |

> 一句话：**栈、队列、双端队列在刷题里统一用 `ArrayDeque`**（比 `Stack`/`LinkedList` 更快更规范）；映射用 `HashMap`，去重用 `HashSet`，要「有序」才上 `TreeMap`/`TreeSet`，要「最值」就上 `PriorityQueue`。

## 二、List：ArrayList vs LinkedList

| 维度 | `ArrayList`（底层数组） | `LinkedList`（双向链表） |
|:---|:---|:---|
| 随机访问 `get(i)` | \(O(1)\) ✅ | \(O(n)\) ❌ |
| 尾部增删 | 均摊 \(O(1)\) | \(O(1)\) |
| 中间插入/删除 | \(O(n)\)（挪元素） | 找到位置 \(O(n)\)，改指针 \(O(1)\) |
| 刷题定位 | **默认就用它** | 几乎不用（要双端就用 `ArrayDeque`） |

```java
List<Integer> list = new ArrayList<>();
list.add(3);                 // 尾插
list.get(0);                 // 随机访问
list.set(0, 5);              // 覆盖
Collections.sort(list);      // 升序
list.sort((a, b) -> b - a);  // 降序（注意大数用 Integer.compare 防溢出）
Collections.reverse(list);
int[] arr = list.stream().mapToInt(Integer::intValue).toArray(); // List<Integer> → int[]
```

> **坑**：`list.remove(2)` 是删**下标 2**，`list.remove(Integer.valueOf(2))` 才是删**值 2**。

## 三、栈 / 队列 / 双端队列：一律 `ArrayDeque`

`ArrayDeque` 一个类通吃三种角色，官方也推荐它替代 `Stack` 和 `LinkedList`。

```java
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1); stack.push(2);   // 压栈 = addFirst
stack.peek();                   // 看栈顶 → 2
stack.pop();                    // 弹栈 → 2

Deque<Integer> queue = new ArrayDeque<>();
queue.offer(1); queue.offer(2); // 入队 = addLast
queue.peek();                   // 看队头 → 1
queue.poll();                   // 出队 → 1

// 单调队列（滑动窗口最大值）：两端都操作
Deque<Integer> mono = new ArrayDeque<>();
mono.pollFirst();  mono.peekFirst();   // 队头
mono.pollLast();   mono.offerLast(3);  // 队尾
```

| 别用 | 用这个 | 原因 |
|:---|:---|:---|
| `Stack` | `ArrayDeque`（当栈） | `Stack` 继承 `Vector`，全同步、慢、遍历顺序反直觉 |
| `LinkedList`（当队列/栈） | `ArrayDeque` | `ArrayDeque` 数组实现，缓存友好、更快 |

> **坑**：`ArrayDeque` **不允许存 `null`**（`poll` 用 `null` 表示空）。BFS 里要存空标记时改用别的哨兵值。

## 四、Map：HashMap / TreeMap / LinkedHashMap

### HashMap —— 刷题最高频

```java
Map<Integer, Integer> cnt = new HashMap<>();
cnt.getOrDefault(x, 0);              // 取不到给默认值
cnt.put(x, cnt.getOrDefault(x, 0) + 1);
cnt.merge(x, 1, Integer::sum);       // 频次统计推荐写法：无则置1，有则+1
cnt.computeIfAbsent(k, key -> new ArrayList<>()).add(v); // 值是集合时初始化
for (Map.Entry<Integer,Integer> e : cnt.entrySet()) { e.getKey(); e.getValue(); }
```

### TreeMap —— 需要「有序 / 范围查询 / 前驱后继」时

```java
TreeMap<Integer, Integer> tm = new TreeMap<>();
tm.firstKey(); tm.lastKey();       // 最小/最大 key
tm.ceilingKey(x);                  // ≥ x 的最小 key（找不到返回 null）
tm.floorKey(x);                    // ≤ x 的最大 key
tm.higherKey(x); tm.lowerKey(x);   // 严格 > / < x
tm.headMap(x); tm.tailMap(x);      // 子视图，用于区间统计
```
适合：日程安排、区间合并、找最接近的数、按 key 排序输出。

### LinkedHashMap —— 需要「保持顺序」时

- **插入序**：遍历顺序 = 插入顺序（默认）。
- **访问序**：`new LinkedHashMap<>(cap, 0.75f, true)`，最近访问的移到末尾 → **LRU 缓存的核心**（配合重写 `removeEldestEntry`）。

## 五、Set：HashSet / TreeSet

```java
Set<Integer> seen = new HashSet<>();
seen.add(x); seen.contains(x); seen.remove(x);   // 去重/判重，均摊 O(1)

TreeSet<Integer> ts = new TreeSet<>();
ts.ceiling(x);  // ≥ x 最小；ts.floor(x) ≤ x 最大；ts.first()/last()
```

| 场景 | 选择 |
|:---|:---|
| 只判「存在/去重」 | `HashSet`（\(O(1)\)） |
| 要「有序 / 找最接近的值 / 前驱后继」 | `TreeSet`（\(O(\log n)\)） |

> 典型：[128. 最长连续序列](128.%20最长连续序列.md) 用 `HashSet` 判 `num-1` 是否存在，从序列起点扩展做到 \(O(n)\)。

## 六、PriorityQueue（堆）：取最值 / Top-K / Dijkstra

**默认小顶堆**（堆顶最小）。

```java
PriorityQueue<Integer> minHeap = new PriorityQueue<>();               // 小顶堆
PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a,b)->b-a);     // 大顶堆
PriorityQueue<Integer> maxHeap2 = new PriorityQueue<>(Comparator.reverseOrder());

// 按外部频次表排序（Top-K 高频）
PriorityQueue<Integer> pq = new PriorityQueue<>((a,b) -> cnt.get(a) - cnt.get(b));

pq.offer(x); pq.peek(); pq.poll();   // 入堆/看堆顶/出堆
```

**Top-K 口诀**（来自 [347. 前 K 个高频元素](347.%20前%20K%20个高频元素.md)）：

> **求前 K 大 → 小顶堆；求前 K 小 → 大顶堆。堆顶永远放「最容易被淘汰的那个」**，大小超过 K 就 `poll` 掉堆顶。这样是 \(O(n \log k)\)，优于全排序 \(O(n \log n)\)。

> **坑**：比较器写 `(a,b)->a-b` 在 `a,b` 接近 `Integer.MAX/MIN` 时会**溢出**，稳妥用 `Integer.compare(a,b)` 或 `Long.compare`。

## 七、比较器（Comparator）：排序/堆的灵魂

```java
// 升序（自然序）
list.sort(Comparator.naturalOrder());
// 降序
list.sort(Comparator.reverseOrder());
// 按对象字段
people.sort(Comparator.comparingInt(p -> p.height));
// 多关键字：身高降序，k 升序（406. 根据身高重建队列）
people.sort((a,b) -> a[0]!=b[0] ? b[0]-a[0] : a[1]-b[1]);
// 链式写法
people.sort(Comparator.comparingInt((int[] p)->-p[0]).thenComparingInt(p->p[1]));
// 二维数组按首列排序
Arrays.sort(intervals, (a,b) -> Integer.compare(a[0], b[0]));  // 防溢出
```

> **区间调度贪心**（如华为OD #33）按**右端点**升序；**区间合并**按左端点升序——排序键选错直接全错。

## 八、数组与集合的互转（刷题高频踩坑区）

```java
// int[] → List<Integer>（不能直接 Arrays.asList(intArr)！那会得到 List<int[]> 大小为1）
List<Integer> a = Arrays.stream(arr).boxed().collect(Collectors.toList());
// Integer[] → List：Arrays.asList(boxedArr) 可以
// List<Integer> → int[]
int[] b = list.stream().mapToInt(Integer::intValue).toArray();
// char <-> int：'a' + i、c - 'a'（26 字母映射常用）
int[] freq = new int[26]; freq[c - 'a']++;
// 排序
Arrays.sort(arr);                          // 基本类型只能升序
Arrays.sort(boxed, Collections.reverseOrder()); // 降序需装箱
```

> **经典坑**：`Arrays.asList(new int[]{1,2,3})` 得到的是 `List<int[]>`（长度 1），不是 `List<Integer>`。要么用 `stream().boxed()`，要么一开始就用 `Integer[]`。

## 十、刷题防坑清单（速记）

1. **栈/队列/双端队列**：统一 `ArrayDeque`，别用 `Stack`/`LinkedList`；且它**不能存 `null`**。
2. **比较器减法防溢出**：`(a,b)->a-b` 换成 `Integer.compare(a,b)`。
3. **`list.remove`**：`remove(int)` 删下标，`remove(Integer)` 删值。
4. **`int[]` 转 `List`**：用 `Arrays.stream(arr).boxed()`，别用 `Arrays.asList(intArr)`。
5. **频次统计**：`map.merge(k, 1, Integer::sum)` 最简洁。
6. **值是集合的 Map**：`computeIfAbsent(k, x->new ArrayList<>()).add(v)` 免判空。
7. **求前 K 大用小顶堆，前 K 小用大顶堆**；超过 K 就 `poll` 堆顶。
8. **遍历时增删**：直接改集合会 `ConcurrentModificationException`，用 `Iterator.remove()` 或先收集后删。
9. **`HashMap` 容量**：已知规模可 `new HashMap<>(expectedSize * 4 / 3 + 1)` 减少扩容（面试加分，非必需）。
10. **累加/前缀和/乘积**：先想 `long` 防溢出，尤其带负数或大数据量时。
