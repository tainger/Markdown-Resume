## 题目描述

给你一个字符串 `s` 和一个字符规律 `p`，请你来实现一个支持 `'.'` 和 `'*'` 的正则表达式匹配。

- `'.'` 匹配任意单个字符
- `'*'` 匹配零个或多个前面的那一个元素

所谓匹配，是要涵盖 **整个** 字符串 `s` 的，而不是部分字符串。

---

## 示例

**示例 1**

```
输入：s = "aa", p = "a"
输出：false
解释："a" 无法匹配 "aa" 整个字符串。
```

**示例 2**

```
输入：s = "aa", p = "a*"
输出：true
解释：'*' 表示可匹配零个或多个前面的那一个元素, 这里前面的元素就是 'a'。因此，字符串 "aa" 可被视为 'a' 重复了一次。
```

**示例 3**

```
输入：s = "ab", p = ".*"
输出：true
解释：".*" 表示可匹配零个或多个（'*'）任意字符（'.'）。
```

---

## 提示

- `1 <= s.length <= 20`
- `1 <= p.length <= 20`
- `s` 只包含从 `a-z` 的小写字母
- `p` 只包含从 `a-z` 的小写字母，以及字符 `.` 和 `*`
- 保证每次出现字符 `*` 时，前面都匹配到有效的字符

## 思路

### 核心：逐字符匹配，`*` 是难点

从左到右匹配 `s` 和 `p`。关键看 `p` 当前位的**下一位是不是 `*`**，分两大类：

**情况 A：`p` 的下一个字符不是 `*`**（普通字符或 `.`）

当前 `s[i]` 必须与 `p[j]` 匹配（相等，或 `p[j]=='.'`），然后 `i`、`j` 各前进一位。

**情况 B：`p` 的下一个字符是 `*`**（即 `p[j+1]=='*'`，`x*` 组合）

`x*` 可以匹配「**0 个**」或「**多个**」`x`，两条分支只要有一条成立即可：

- **`*` 匹配 0 次**：直接跳过 `x*`，`j += 2`，`i` 不动（`p` 里这个 `x*` 当不存在）
- **`*` 匹配 ≥1 次**：需 `s[i]` 与 `p[j]` 匹配，然后 `i += 1`、`j` 不动（`x*` 留着继续吃下一个字符）

```
s = "aab", p = "c*a*b"
c* 匹配 0 个 c → 跳过, p 到 a*
a* 匹配 2 个 a → 吃掉 aa
b  匹配 b     → true
```

### 递归/DP 状态定义

设 `f(i, j)` = `s[i:]` 与 `p[j:]` 是否匹配（后缀匹配）。或 DP 里 `dp[i][j]` = `s` 前 `i` 个字符与 `p` 前 `j` 个字符是否匹配。转移就是上面 A/B 两类。

```
firstMatch = i < s.len && (s[i]==p[j] || p[j]=='.')   // 当前位是否匹配

若 p[j+1]=='*':
    f(i,j) = f(i, j+2)                    // * 匹配 0 次
             || (firstMatch && f(i+1, j)) // * 匹配 ≥1 次
否则:
    f(i,j) = firstMatch && f(i+1, j+1)    // 普通逐位匹配
```

### 解法一：递归回溯（最直观，理解入口）

直接把上面的 `f(i, j)` 写成递归，枚举 `*` 的「0 次 / 多次」两条路。

- 时间复杂度：最坏指数级（`*` 反复分叉），但因 `s,p ≤ 20` 能过
- 空间复杂度：\(O(m+n)\) 递归栈

> 瓶颈：同一个 `(i, j)` 会被不同的 `*` 展开路径**反复求解**——重叠子问题，加缓存即记忆化。

### 解法二：记忆化搜索（自顶向下 + 缓存）

给 `f(i, j)` 加 `memo[i][j]` 缓存，每个状态只算一次。把指数级降到 \(O(mn)\)。

- 时间复杂度：\(O(mn)\)，状态数 `m×n`，每个 O(1) 转移
- 空间复杂度：\(O(mn)\) 缓存 + 递归栈

### 解法三：二维 DP（自底向上，推荐）

`dp[i][j]` = `s` 前 `i` 个与 `p` 前 `j` 个是否匹配（**前缀**定义，注意下标偏移）。**从后往前的后缀递归翻成从前往后的前缀递推**：

1. `dp[0][0] = true`（两空串匹配）
2. **初始化空 `s` 行**：`dp[0][j]`——形如 `a*b*c*` 的模式能匹配空串，需预处理
3. 转移（`p[j-1]` 是 `p` 第 `j` 个字符）：
   - 若 `p[j-1] == '*'`：`dp[i][j] = dp[i][j-2]`（* 配 0 个）`|| (match(i,j-1) && dp[i-1][j])`（* 配多个）
   - 否则：`dp[i][j] = match(i,j) && dp[i-1][j-1]`
4. `match(i,j)` = `s[i-1]==p[j-1] || p[j-1]=='.'`
5. 答案 `dp[m][n]`

- 时间复杂度：\(O(mn)\)
- 空间复杂度：\(O(mn)\)

## 代码

### 解法一：递归回溯（先跑通）

```java
class Solution {
    public boolean isMatch(String s, String p) {
        return dfs(s, p, 0, 0);
    }

    // s[i:] 与 p[j:] 是否匹配
    private boolean dfs(String s, String p, int i, int j) {
        if (j == p.length()) return i == s.length();     // p 用完，s 也用完才匹配

        // 当前位是否匹配（注意 i 可能越界）
        boolean firstMatch = i < s.length()
                && (s.charAt(i) == p.charAt(j) || p.charAt(j) == '.');

        // p 下一位是 '*'：x* 组合
        if (j + 1 < p.length() && p.charAt(j + 1) == '*') {
            return dfs(s, p, i, j + 2)                    // * 匹配 0 次，跳过 x*
                || (firstMatch && dfs(s, p, i + 1, j));   // * 匹配 ≥1 次，吃掉 s[i]
        } else {
            return firstMatch && dfs(s, p, i + 1, j + 1); // 普通逐位匹配
        }
    }
}
```

### 解法二：记忆化搜索（自顶向下 + 缓存）

```java
class Solution {
    private Boolean[][] memo;

    public boolean isMatch(String s, String p) {
        memo = new Boolean[s.length() + 1][p.length() + 1];
        return dfs(s, p, 0, 0);
    }

    private boolean dfs(String s, String p, int i, int j) {
        if (j == p.length()) return i == s.length();
        if (memo[i][j] != null) return memo[i][j];

        boolean firstMatch = i < s.length()
                && (s.charAt(i) == p.charAt(j) || p.charAt(j) == '.');

        boolean res;
        if (j + 1 < p.length() && p.charAt(j + 1) == '*') {
            res = dfs(s, p, i, j + 2)
               || (firstMatch && dfs(s, p, i + 1, j));
        } else {
            res = firstMatch && dfs(s, p, i + 1, j + 1);
        }
        return memo[i][j] = res;
    }
}
```

### 解法三：二维 DP（推荐）

```java
class Solution {
    public boolean isMatch(String s, String p) {
        int m = s.length(), n = p.length();
        boolean[][] dp = new boolean[m + 1][n + 1];
        dp[0][0] = true;                               // 两空串匹配

        // 初始化：s 为空时，p 形如 a*b*c* 才可能匹配空串
        for (int j = 1; j <= n; j++) {
            if (p.charAt(j - 1) == '*') {
                dp[0][j] = dp[0][j - 2];               // x* 配 0 个 x
            }
        }

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (p.charAt(j - 1) == '*') {
                    // x* 配 0 个：看 dp[i][j-2]
                    dp[i][j] = dp[i][j - 2];
                    // x* 配 ≥1 个：当前位匹配且去掉 s 末字符仍匹配
                    if (match(s, p, i, j - 1)) {
                        dp[i][j] = dp[i][j] || dp[i - 1][j];
                    }
                } else {
                    dp[i][j] = match(s, p, i, j) && dp[i - 1][j - 1];
                }
            }
        }
        return dp[m][n];
    }

    // s 第 i 个字符与 p 第 j 个字符是否匹配（1-based）
    private boolean match(String s, String p, int i, int j) {
        return s.charAt(i - 1) == p.charAt(j - 1) || p.charAt(j - 1) == '.';
    }
}
```

## 个人总结

### 1. `*` 的两条分支是全题核心：匹配 0 次 or 多次

`x*` 不是独立元素，必须和前面的字符**捆绑**看。遇到 `p[j+1]=='*'` 时，永远是两条路取「或」：

- **配 0 次**：把 `x*` 整个跳过（`j+=2`），仿佛 `p` 里没这段；
- **配 ≥1 次**：当前 `s[i]` 与 `x` 匹配后，`i` 前进但 `x*` **留在原地**继续吃后面的字符。

想不清就记：「`*` 要么现在不用，要么再吃一个」。

### 2. `firstMatch` 一定要先判 `i` 不越界

`s[i]` 可能越界（`s` 已耗尽但 `p` 还有 `x*`）。必须写成 `i < s.length() && (...)`，否则 `charAt` 抛异常。这是本题最常见的运行时错误。

### 3. 从回溯到记忆化到 DP 的完整演进

| 解法 | 复杂度 | 关键 |
|:---|:---:|:---|
| 递归回溯 | 指数级（本题 n≤20 能过） | 枚举 `*` 的 0/多次两分支 |
| 记忆化搜索 | \(O(mn)\) | `memo[i][j]` 缓存后缀匹配结果 |
| 二维 DP | \(O(mn)\) | 前缀递推，需初始化空串行 |

和你整理的 [322 零钱兑换](322.%20零钱兑换.md)、[309 含冷冻期](309.%20买卖股票的最佳时机含冷冻期.md) 是同一套 DP 三部曲：暴力递归 → 加缓存 → 翻自底向上。**困难 DP 题从递归入手最稳，DP 数组的转移和递归完全对应**。

### 4. DP 的初始化：空 `s` 行别漏

`dp[0][j]` 表示「`s` 为空时 `p` 前 `j` 位能否匹配」。像 `a*`、`a*b*` 这种全是 `x*` 的模式能匹配空串，靠 `dp[0][j] = dp[0][j-2]` 递推出来。**漏了这行初始化，`s="", p="a*"` 之类用例就错**。

### 5. 递归用后缀 `f(i,j)`、DP 用前缀 `dp[i][j]`——下标方向别搞混

- 递归解法我用「`s[i:]` 与 `p[j:]`」后缀定义，从前往后消耗；
- DP 解法用「前 `i` 个、前 `j` 个」前缀定义，`dp[i][j]` 对应字符 `s[i-1]`、`p[j-1]`（1-based 偏移）。

两种定义都能做，但代码里下标含义必须自洽，混用是 DP 翻车重灾区。
