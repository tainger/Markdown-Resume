# 101. 对称二叉树

> **难度**：🟢 简单 | **标签**：树、深度优先搜索、广度优先搜索、二叉树 | **企业**：—

## 题目描述

给你一个二叉树的根节点 `root` ，检查它是否**轴对称**（即以根节点为中心，左右子树互为镜像）。

## 示例

**示例 1**

```
输入：root = [1,2,2,3,4,4,3]
输出：true

对称结构：
        1
      /   \
     2     2
    / \   / \
   3   4 4   3
```

**示例 2**

```
输入：root = [1,2,2,null,3,null,3]
输出：false

非对称结构：
        1
      /   \
     2     2
      \     \
       3     3
```

## 思路

### 核心思想

对称二叉树的本质：

```
一棵树对称 ⟺ 它的左右子树互为镜像
互为镜像 ⟺ 同时满足三个条件：
  ① 两棵子树的根节点值相等
  ② 左子树的左孩子 == 右子树的右孩子（外侧相等）
  ③ 左子树的右孩子 == 右子树的左孩子（内侧相等）
```

> 🔑 **关键洞察**：不是比较左右子节点各自是否相同，而是**交叉比较**——左.左 vs 右.右，左.右 vs 右.左。

```
        root          ← 不用比较 root 自己
       /    \
   left     right     ← 比较这两棵子树是否互为镜像
   /  \     /  \
  L1  R1   L2  R2

镜像条件：
  L1.val == R2.val  （外侧）
  R1.val == L2.val  （内侧）
```

### 解法一：递归（DFS）

定义一个辅助函数 `isMirror(t1, t2)` 判断两棵树是否互为镜像：

1. 终止条件：都为空 → true；一个为空 → false；值不等 → false
2. 递归判断：`isMirror(t1.left, t2.right) && isMirror(t1.right, t2.left)`

- 时间复杂度：\(O(n)\)，每个节点访问一次
- 空间复杂度：\(O(h)\)，递归栈深度 = 树高，最坏 \(O(n)\)

### 解法二：迭代（BFS + 队列）

用队列成对存储待比较的节点，每次弹出两个比较：

1. 初始入队：`(root.left, root.right)`
2. 每次弹出一对 `(u, v)`：
   - 都为空 → continue
   - 一个空或值不等 → return false
   - 按交叉顺序入队：`(u.left, v.right)` 和 `(u.right, v.left)`
3. 队列空 → return true

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(n)\)

### 解法一：递归

```java
public boolean isSymmetric(TreeNode root) {
    if (root == null) return true;
    return isMirror(root.left, root.right);
}

private boolean isMirror(TreeNode t1, TreeNode t2) {
    if (t1 == null && t2 == null) return true;   // 都空 → 对称
    if (t1 == null || t2 == null) return false;  // 一空一非空 → 不对称
    if (t1.val != t2.val) return false;          // 值不等 → 不对称
    // 交叉递归：外侧 vs 外侧，内侧 vs 内侧
    return isMirror(t1.left, t2.right) && isMirror(t1.right, t2.left);
}
```

### 解法二：迭代 + 队列

```java
public boolean isSymmetric(TreeNode root) {
    if (root == null) return true;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root.left);
    queue.offer(root.right);

    while (!queue.isEmpty()) {
        TreeNode u = queue.poll();
        TreeNode v = queue.poll();

        if (u == null && v == null) continue;     // 都空，跳过
        if (u == null || v == null) return false;  // 一空一非空
        if (u.val != v.val) return false;          // 值不等

        // 按交叉顺序入队
        queue.offer(u.left);   // 左.左
        queue.offer(v.right);  // 右.右（外侧一对）
        queue.offer(u.right);  // 左.右
        queue.offer(v.left);   // 右.左（内侧一对）
    }
    return true;
}
```
