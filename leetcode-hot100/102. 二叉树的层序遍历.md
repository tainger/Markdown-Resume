## 题目描述

给你二叉树的根节点 `root` ，返回其节点值的 **层序遍历** 。（即逐层地，从左到右访问所有节点）。

## 示例

**示例 1**

```
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[9,20],[15,7]]

树结构：
        3
       / \
      9  20
        /  \
       15   7
```

**示例 2**

```
输入：root = [1]
输出：[[1]]
```

**示例 3**

```
输入：root = []
输出：[]
```

## 思路

### 核心思想

BFS 用**队列**保证"先进先出"——先入队的上一层节点先出队。关键是**逐层处理**：进入循环时先记下当前队列长度 `size`（= 本层节点数），内层循环恰好弹出 `size` 个，处理完后队列里剩下的就全是下一层节点。

```
队列状态演化：
初始:      [3]           → 弹 1 个 → 第 1 层 [3]
处理 3 后: [9, 20]       → 弹 2 个 → 第 2 层 [9, 20]
处理 9/20 后: [15, 7]    → 弹 2 个 → 第 3 层 [15, 7]
队列为空 → 结束
```

### 解法一：BFS 队列逐层（基础）

1. 根节点入队；队列不空时循环
2. 每轮循环先固定 `size = queue.size()`，内层弹 `size` 个节点收集本层结果，同时把非空孩子入队
3. 每轮收集到的列表就是一层

- 时间复杂度：\\(O(n)\\)，每个节点进出队各一次
- 空间复杂度：\\(O(n)\\)，队列最坏存一层（满二叉树最后一层约 n/2 个节点）

### 解法二：DFS 递归按 depth 分层（推荐掌握）

1. 递归携带 `depth` 参数；`depth == res.size()` 说明**首次到达该层**，先建该层容器
2. 把当前节点值塞进 `res.get(depth)`，先递归左孩子再递归右孩子，访问顺序天然从左到右

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(h)\\) 递归栈（不计结果数组）

## 代码

### 解法一：BFS 队列逐层

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();          // ① 必须先固定本层节点数
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {  // ② 内层恰好弹 size 个
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left  != null) queue.offer(node.left);   // ③ 孩子是下一层
            if (node.right != null) queue.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

### 解法二：DFS 递归按 depth 分层（推荐）

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    dfs(root, 0, res);
    return res;
}

private void dfs(TreeNode node, int depth, List<List<Integer>> res) {
    if (node == null) return;
    // 首次到达该层：res.size() 恰好等于当前 depth
    if (depth == res.size()) res.add(new ArrayList<>());
    res.get(depth).add(node.val);
    // 先左后右，保证每层内部从左到右
    dfs(node.left,  depth + 1, res);
    dfs(node.right, depth + 1, res);
}
```

## 个人总结

### 1. 坑：size 在循环内动态变化

`for (int i = 0; i < queue.size(); i++)` 是经典错误——处理本层节点时它的孩子**不断入队**，`queue.size()` 随之变大，循环会"越层"把下一层也弹掉。必须在进入内层循环**之前**用局部变量把本层 size 固定下来。

### 2. DFS 分层的精髓：depth == res.size()

`res.size()` 永远等于"已建好的层数"。当前 `depth` 等于它，说明这一层还没被任何节点触达过，我是第一个来的——先 `add(new ArrayList<>())` 建层。这个判定与访问顺序无关（先右后左会得到右视图，见 199），但层容器只建一次。

### 3. BFS 与 DFS 版本对比

| | BFS 队列 | DFS 递归 |
|:---|:---|:---|
| 直觉 | 天然的"逐层" | 依赖 depth 参数人工分层 |
| 额外空间 | O(n)（最宽一层） | O(h)（递归栈） |
| 面试推荐 | 层序类问题首选 | 树深不大时更简洁 |

### 4. 层序模板的可复用点

几乎所有"按层统计"的题都套这个壳：103 锯齿形（奇数层 `Collections.reverse`）、107 自底向上（结果头插或最后反转）、199 右视图（取 `i == size - 1`）、515 每层最大值（层内取 max）。**记模板，不记题**。
