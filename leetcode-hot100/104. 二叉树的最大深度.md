# 104. 二叉树的最大深度

> **难度**：🟢 简单 | **标签**：树、深度优先搜索、广度优先搜索、二叉树 | **企业**：—

## 题目描述

给定一个二叉树 `root` ，返回其**最大深度**。

二叉树的**最大深度**是指从根节点到最远叶子节点的最长路径上的节点数。

## 示例

**示例 1**

```
输入：root = [3,9,20,null,null,15,7]
输出：3

树结构：
        3
       / \
      9  20
        /  \
       15   7
```

**示例 2**

```
输入：root = [1,null,2]
输出：2
```

---

## 提示

- 树中节点数目在范围 `[0, 10^4]` 内
- `-100 <= Node.val <= 100`

---

## 进阶

无特别进阶要求，但可以比较 **DFS（递归）** 与 **BFS（层序遍历）** 两种写法。

---

## 思路

### 核心思想

```
一棵树的最大深度 = 1（根节点本身）
                  + max(左子树的最大深度, 右子树的最大深度)
```

递归到叶子节点的下一层（null）时，返回 0。逐层往上，每层 +1，最终回到根节点就是答案。

```
        3          ← max(左=1, 右=2) + 1 = 3
       / \
      9  20        ← 左: 0+1=1  右: max(1,1)+1=2
        /  \
       15   7      ← 各为 0+1=1
      / \  / \
    null...null    ← 统统返回 0
```

### 解法一：递归（DFS）— 最简洁

1. 终止条件：`root == null` → 返回 0
2. 递归：`1 + Math.max(maxDepth(root.left), maxDepth(root.right))`

- 时间复杂度：\\(O(n)\\)，每个节点访问一次
- 空间复杂度：\\(O(h)\\)，递归栈深度，最坏 \\(O(n)\\)

### 解法二：迭代（BFS 层序遍历）

1. 用队列做层序遍历，每遍历完一层，depth + 1
2. 队列空时，depth 即为最大深度

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(n)\\)

## 代码

### 我的伪代码

```java
class Solution {
    public int maxDepth(TreeNode root) {
        // ❌ 空树 → 0，正确
        if(root == null) {
            return 0;
        }
        int depth = 1;
        
        // ⚠️ 冗余逻辑：这里手动 +1，search 里又 +1，
        //    两处各管一段，容易出边界 bug
        if(root.left != null || root.right != null) {
            depth++;
        }

        // ⚠️ search(null, depth) 返回的是 parent 的 depth，
        //    当兄弟子树更深时，这个值会干扰 Math.max
        return Math.max(search(root.left, depth), search(root.right,depth));
    }

    public int search(TreeNode root, int depth) {
        // ❌ 走到 null 不应该返回 depth，
        //    否则 null 被视为一个"有效深度"，影响 max 比较
        if(root == null) {
            return depth;
        }

        // ✅ 叶子节点正确处理：返回当前深度
        if(root.left == null && root.right == null) {
            return depth;
        }
        depth ++;

        return Math.max(search(root.left, depth), search(root.right,depth));
    }
}
```

### 解法一：递归（推荐）

```java
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}
```

### 解法二：迭代 BFS

```java
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    int depth = 0;

    while (!queue.isEmpty()) {
        int size = queue.size();   // 当前层的节点数
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (node.left  != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        depth++;  // 每处理完一层，深度 +1
    }
    return depth;
}
```

## 个人总结

| # | 踩坑点 | 说明 |
|:---:|:---|:---|
| 1 | **冗余 depth 管理** | `maxDepth` 里手动 `depth++`，`search` 里又 `depth++`，两处各自兜一段逻辑。根本原因是把"深度"当成一个需要传递和维护的状态变量，而不是用递归返回值自底向上计算 |
| 2 | **`search(null, depth)` 返回 depth** | 当节点为 null 时返回 parent 的 depth，在非叶子节点的空子树分支会导致 `Math.max` 取到错误值。正确做法：null 返回 0，逐层 +1 |
| 3 | **思维误区：自顶向下传参数** | 习惯性想把 depth 作为参数往下传，但二叉树深度问题用"自底向上"的递归更自然——叶子返回 0，每层往上 +1，一行代码搞定 |

> 💡 核心教训：**树的深度/高度问题，优先想自底向上（返回值累加），而不是自顶向下（参数传递）。**
