## 题目描述

给定两个整数数组 `preorder` 和 `inorder` ，其中 `preorder` 是二叉树的**先序遍历**， `inorder` 是同一棵树的**中序遍历**，请构造二叉树并返回其根节点。

## 示例

**示例 1**

```
输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出: [3,9,20,null,null,15,7]

树结构：
        3
       / \
      9  20
        /  \
       15   7
```

**示例 2**

```
输入: preorder = [-1], inorder = [-1]
输出: [-1]
```

- `preorder` **保证** 为二叉树的前序遍历序列
- `inorder` **保证** 为二叉树的中序遍历序列

## 思路

### 核心思想

两种遍历各提供一个信息，合起来能确定一棵树：

```
前序：[ 3 | 9 | 20, 15, 7 ]     ← 第一个 3 一定是根
        根   左    右
中序：[ 9 | 3 | 15, 20, 7 ]     ← 找到 3，左边全是左子树，右边全是右子树
       左   根      右
              ↑ leftSize = 1
```

**前序定根，中序分左右**：`leftSize = 中序中根左边的元素个数`，它同时决定前序里左子树区间的长度。对左右子树区间递归即可。

### 解法一：递归分治（每次线性扫中序定位根）（基础）

1. 取前序区间第一个元素作根
2. 在中序区间里**线性扫描**找到根的位置 `mid`
3. 按 `leftSize = mid - il` 切出两个子问题递归

- 时间复杂度：\\(O(n^2)\\)，每层递归线性扫描
- 空间复杂度：\\(O(h)\\)（不计建树本身）

### 解法二：哈希表存中序下标 + 递归分治（推荐）

1. 预处理：`HashMap<值, 中序下标>`，定位根 O(1)（题目保证值不重复）
2. 用**全局指针 `preIdx`** 顺序消费前序数组，配合中序区间 `[l, r]` 递归
3. 注意递归必须**先建左子树再建右子树**，与前序消费顺序一致

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(h)\\) + 哈希表 \\(O(n)\\)

## 代码

### 解法一：递归分治（线性定位）

```java
public TreeNode buildTree(int[] preorder, int[] inorder) {
    return build(preorder, 0, preorder.length - 1,
                 inorder,  0, inorder.length - 1);
}

// 前序区间 [pl, pr] 与中序区间 [il, ir] 描述同一棵子树
private TreeNode build(int[] pre, int pl, int pr, int[] in, int il, int ir) {
    if (pl > pr) return null;
    TreeNode root = new TreeNode(pre[pl]);   // 前序第一个 = 根
    int mid = il;
    while (in[mid] != pre[pl]) mid++;        // 中序里线性找根，O(区间长度)
    int leftSize = mid - il;                 // 左子树节点数 = 中序根左侧长度
    root.left  = build(pre, pl + 1, pl + leftSize,     in, il,     mid - 1);
    root.right = build(pre, pl + leftSize + 1, pr,     in, mid + 1, ir);
    return root;
}
```

### 解法二：哈希表 + 全局 preIdx（推荐）

```java
private Map<Integer, Integer> inIndex;   // 值 → 中序下标，O(1) 定位根
private int preIdx;                      // 当前要建的根在前序中的位置

public TreeNode buildTree(int[] preorder, int[] inorder) {
    inIndex = new HashMap<>();
    for (int i = 0; i < inorder.length; i++) {
        inIndex.put(inorder[i], i);      // 值不重复是建映射的前提
    }
    preIdx = 0;
    return build(preorder, 0, inorder.length - 1);
}

// 只需要中序区间 [l, r]，根由全局 preIdx 提供
private TreeNode build(int[] preorder, int l, int r) {
    if (l > r) return null;
    int rootVal = preorder[preIdx++];    // 消费前序当前位置
    TreeNode root = new TreeNode(rootVal);
    int mid = inIndex.get(rootVal);      // O(1) 定位根在中序中的位置
    // 顺序不能反！preIdx 从左往右消费，必须先建左子树
    root.left  = build(preorder, l, mid - 1);
    root.right = build(preorder, mid + 1, r);
    return root;
}
```

## 个人总结

### 1. 三个关键定位

| 信息 | 作用 |
|:---|:---|
| 前序第一个元素 | 就是根 |
| 中序中根的位置 `mid` | 左边 = 左子树，右边 = 右子树 |
| `leftSize = mid - il` | 同时决定前序里左子树区间的长度 |

想清楚 `leftSize`，前序区间切分 `pl+1 ~ pl+leftSize`（左）、`pl+leftSize+1 ~ pr`（右）就不用死记。

### 2. 哈希表把 O(n²) 降到 O(n)

解法一每层递归线性扫描中序，退化成 O(n²)；值不重复时哈希表 O(1) 定位，整棵树 O(n)。这是"空间换时间"在树构造题的标准应用。

### 3. 坑：全局 preIdx 的消费顺序必须与递归顺序一致

`preIdx++` 是顺序消费前序数组，递归体里**必须先递归左子树、再递归右子树**——因为前序里左子树的元素紧跟在根后面。如果先建右子树，preIdx 会拿右子树的值去建左子树，整棵树全错。不易错但略啰嗦的替代方案：前序、中序区间都传参（解法一写法）。

### 4. 变体：LeetCode 106 中序 + 后序

后序**最后一个**是根，从后往前消费 `postIdx--`；由于后序从后往前的顺序是「根 → 右子树 → 左子树」，递归必须**先建右子树再建左子树**，其余与本题完全对称。记住这个镜像关系，两道题就是同一道。
