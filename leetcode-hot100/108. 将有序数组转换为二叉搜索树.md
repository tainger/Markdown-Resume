## 题目描述

给你一个整数数组 `nums` ，其中元素已经按 **升序** 排列，请你将其转换为一棵 **平衡** 二叉搜索树。

## 示例

**示例 1**

```
输入：nums = [-10,-3,0,5,9]
输出：[0,-3,9,-10,null,5]
解释：[0,-10,9,-3,null,5] 也将被视为正确答案：

     0                0
    / \              / \
  -3   9    或     -10   9
  /   /               \   \
-10  5                -3   5
```

**示例 2**

```
输入：nums = [1,3]
输出：[3,1]
解释：[1,null,3] 和 [3,1] 都是高度平衡二叉搜索树。
```

---

## 提示

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 按 **严格递增** 顺序排列

## 思路

### 核心思想

**平衡的来源：中点做根。** 有序数组取中点，左右两半元素个数最多差 1；把中点作为根，左半递归建左子树、右半递归建右子树——每棵子树的左右节点数都近似相等，高度自然平衡（|左右子树高度差| ≤ 1）。

```
[-10, -3, 0, 5, 9]
           ↑ 中点 0 做根
   左半 [-10,-3]    右半 [5,9]
        -3 做根          5 或 9 做根（都合法）
```

有序性保证了"左半全 < 根 < 右半"，BST 性质天然满足，不需要任何额外检查。

### 解法一：递归二分，中点做根（基础）

1. 区间 `[l, r]`，`l > r` 返回 null
2. `mid = l + (r - l) / 2`，`nums[mid]` 建根
3. 左半 `[l, mid-1]`、右半 `[mid+1, r]` 递归

- 时间复杂度：\\(O(n)\\)，每个元素恰好建一个节点
- 空间复杂度：\\(O(\\log n)\\)，递归栈深度 = 平衡树高度

### 解法二：迭代（三队列模拟层序建树）（进阶理解）

递归改迭代的标准手法：用三个队列同步推进——待填充节点队列、对应区间左边界队列、右边界队列，出队时填中点值、非空子区间继续入队。

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(n)\\)

## 代码

### 解法一：递归二分，中点做根（推荐）

```java
public TreeNode sortedArrayToBST(int[] nums) {
    return build(nums, 0, nums.length - 1);
}

// 用 nums[l..r] 建平衡 BST，返回根
private TreeNode build(int[] nums, int l, int r) {
    if (l > r) return null;              // 空区间 → 空子树
    int mid = l + (r - l) / 2;           // 防溢出写法，取中点做根
    TreeNode root = new TreeNode(nums[mid]);
    root.left  = build(nums, l, mid - 1);    // 左半严格小于根
    root.right = build(nums, mid + 1, r);    // 右半严格大于根
    return root;
}
```

### 解法二：迭代（三队列模拟）

```java
public TreeNode sortedArrayToBST(int[] nums) {
    if (nums.length == 0) return null;
    // 三个队列一一对应：待填节点、区间左边界、区间右边界
    Queue<TreeNode> nodes = new LinkedList<>();
    Queue<Integer> lefts  = new LinkedList<>();
    Queue<Integer> rights = new LinkedList<>();
    TreeNode root = new TreeNode(0);     // 先占位，值稍后填
    nodes.offer(root);
    lefts.offer(0);
    rights.offer(nums.length - 1);

    while (!nodes.isEmpty()) {
        TreeNode node = nodes.poll();
        int l = lefts.poll(), r = rights.poll();
        int mid = l + (r - l) / 2;
        node.val = nums[mid];            // 中点元素即根
        if (l <= mid - 1) {              // 左区间非空 → 建左孩子
            node.left = new TreeNode(0);
            nodes.offer(node.left);
            lefts.offer(l);
            rights.offer(mid - 1);
        }
        if (mid + 1 <= r) {              // 右区间非空 → 建右孩子
            node.right = new TreeNode(0);
            nodes.offer(node.right);
            lefts.offer(mid + 1);
            rights.offer(r);
        }
    }
    return root;
}
```

## 个人总结

### 1. 为什么中点做根必然平衡（面试要能说出来）

中点把数组分成两半，两半**元素个数**最多差 1；递归下去每棵子树的左右两侧元素个数同样最多差 1。元素个数差 ≤ 1 ⇒ 高度差 ≤ 1，这正是"高度平衡"的定义。本质上是把"平衡 BST"这个全局约束拆成了"每次都选中点"这个局部贪心。

### 2. 两个区间细节

- `mid = l + (r - l) / 2` 防止 `(l + r)` 整型溢出（本题 n ≤ 10^4 不会溢出，但这是必须养成的习惯，34/153 等二分题同款）
- 递归用 `[l, mid-1]` 和 `[mid+1, r]`，**必须跳过 mid 本身**，否则区间不收缩导致死递归栈溢出

### 3. 答案不唯一，判题器接受所有平衡 BST

取中点偏左（`(l+r)/2`）、偏右（`(l+r+1)/2`）都是合法答案——示例 1 的解释里明确说了两种输出都对。面试时主动说一句"答案不唯一，我取中点保证平衡"是加分点。

### 4. 与 105 构造题的关系

105 是"无序遍历对 → 唯一确定的树"，靠哈希定位；本题是"有序数组 → 任取平衡结构"，靠中点贪心。共同骨架都是**分治：定根 → 切区间 → 递归**。
