## 题目描述

给定一个长度为 `n` 的整数数组 `height` 。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])` 。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的**水**。

返回容器可以储存的**最大水量**。

**说明**：你不能倾斜容器。

## 示例

**示例 1**

```
输入：[1,8,6,2,5,4,8,3,7]
输出：49
解释：图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 49。
```

**示例 2**

```
输入：height = [1,1]
输出：1
```

## 提示

- `n == height.length`
- `2 <= n <= 10^5`
- `0 <= height[i] <= 10^4`

## 思路

### 核心思想

面积 = 短板高度 × 宽度。先让两指针指向最宽的两端，之后面积只会受短板限制——**每次移动较短的指针**，只有换掉短板，面积才有机会变大。

### 解法一：暴力枚举（基础）

1. 双重循环枚举所有 `(i, j)` 数对；
2. 计算 `min(height[i], height[j]) * (j - i)`，取最大值。

- 时间复杂度：\(O(n^2)\)（`n` 达 \(10^5\) 会超时），空间复杂度：\(O(1)\)

### 解法二：双指针（推荐）

1. `left` 指向最左端、`right` 指向最右端，此时宽度最大；
2. 每轮先算当前面积更新答案，然后**移动较矮的那一端**；
3. 两指针相遇时结束。

正确性（反证法）：设 `height[left] <= height[right]`。若保留 `left` 不动、移动 `right` 向内，新面积 = `min(height[left], height[j]) * 新宽度`——宽度变小、高度仍不超过 `height[left]`，**必然不大于当前面积**。也就是说，所有包含旧 `left` 的组合里，与当前 `right` 的组合已经是最优，可以安全丢弃 `left`；反之同理。每次丢弃一个指针，`n-1` 轮内结束且不漏最优解。

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(1)\)

## 代码

### 解法一：暴力枚举（会超时，仅理解用）

```java
public int maxArea(int[] height) {
    int n = height.length, ans = 0;
    for (int i = 0; i < n; i++) {              // 枚举左板
        for (int j = i + 1; j < n; j++) {      // 枚举右板
            // 盛水量 = 短板高度 × 两板间距
            int area = Math.min(height[i], height[j]) * (j - i);
            ans = Math.max(ans, area);
        }
    }
    return ans;
}
```

### 解法二：双指针（推荐）

```java
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1, ans = 0;
    while (left < right) {
        // 盛水量由较短的板决定
        int area = Math.min(height[left], height[right]) * (right - left);
        ans = Math.max(ans, area);
        // 移动较短的一端：只有短板变高，面积才可能增大
        if (height[left] < height[right]) {
            left++;
        } else {
            right--;
        }
    }
    return ans;
}
```

## 个人总结

### 1. 为什么移动短板——本题唯一的「证明点」

| 移动谁 | 宽度 | 高度上限 | 结论 |
|:---|:---|:---|:---|
| 短板 | 变小 | 可能变高 | 面积可能变大 ✅ |
| 长板 | 变小 | 仍 ≤ 原短板 | 面积必然变小或不变 ❌ |

面积由 `min(h[l], h[r])` 决定，动长板根本不改变高度上限，还白白丢宽度。**一句话：短板决定水位，动短板才有救。**

### 2. 两板等高时移哪个都行

`height[left] == height[right]` 时走 `else` 移右指针即可，正确性不受影响（此时包含任一端的最大面积已经统计过）。有的写法等高时两个指针同时内移，也只是常数优化，不是必须。

### 3. 最大水量用 int 就够，但要有意识

`n <= 10^5`、`height[i] <= 10^4`，最大面积约 \(10^4 \times 10^5 = 10^9\)，仍小于 `Integer.MAX_VALUE ≈ 2.1 × 10^9`，不会溢出。但「短板 × 宽度」这类乘积题型要养成先估算量级的习惯，约束再大一点就得换 `long`。

### 4. 与 42. 接雨水区分（高频易混）

| 题目 | 求什么 | 核心量 | 解法骨架 |
