## 题目描述

给你二叉树的根结点 `root` ，请你将它展开为一个单链表：

- **展开后的单链表**应该同样使用 `TreeNode` ，其中 `right` 子指针指向链表中下一个结点，而左子指针始终为 `null` 。
- 展开后的单链表应该与二叉树 **先序遍历** 顺序相同。

## 示例

**示例 1**

```
输入：root = [1,2,5,3,4,null,6]
输出：[1,null,2,null,3,null,4,null,5,null,6]

展开前:           展开后:
      1             1
     / \             \

   / \   \             \

                         \

                             \
                              6
```

**示例 2**

```
输入：root = []
输出：[]
```

**示例 3**

```
输入：root = [0]
输出：[0]
```

## 思路

### 核心思想

目标形态 = **前序遍历序列串成的右链**（所有 `left` 为 null）。三条路都能到达：

1. 朴素：前序遍历把节点存进列表，再按顺序重连——空间 O(n)
2. 原地：观察到一个关键事实——**左子树的最右节点，恰好是前序意义下右子树的前驱**（前序中根 → 左子树 → 右子树，左子树最后一个访问的节点紧邻右子树第一个节点）。于是把右子树挂到前驱的 `right` 上，再把左子树整体搬到右边
3. 递归：先分别拉平左右子树（各自已成右链），再把"左链接在 root.right、原右链接到左链尾部"

```
      1                    1
     / \                    \
    2   5      →             2
   / \   \      (左链搬过去)   \
  3   4   6                    3
                                \
                                 4    ← 原右子树 5,6 接在左链(2,3,4)尾部之后
                                  \
                                   5
                                    \
                                     6
```

### 解法一：前序遍历存列表再重连（基础）

1. 前序遍历，节点按序存入 `List<TreeNode>`
2. 从第 2 个节点开始，`prev.left = null; prev.right = cur;` 逐个重连

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(n)\\)（列表）

### 解法二：原地寻找前驱（推荐，满足进阶 O(1) 空间）

1. `cur` 从根出发沿 `right` 前进
2. 若 `cur.left` 非空：找到左子树最右节点 `pre`；`pre.right = cur.right`（右子树接过去）；`cur.right = cur.left; cur.left = null`（左链搬上来）
3. `cur = cur.right` 继续处理下一个节点

- 时间复杂度：\\(O(n)\\)（每个节点的前驱查找合计 O(n)，均摊），空间复杂度：\\(O(1)\\)

### 解法三：递归（后序拉平）

1. 先递归拉平左子树、右子树（各自已是右链）
2. 保存原右子树，把左链接到 `root.right`，沿新右链走到尾，接回原右子树

- 时间复杂度：最坏 \\(O(n^2)\\)（每次找左链尾），空间复杂度：\\(O(h)\\)

## 代码

### 解法一：前序遍历存列表再重连

```java
public void flatten(TreeNode root) {
    List<TreeNode> list = new ArrayList<>();
    preorder(root, list);
    // 按前序顺序逐个重连成右链
    for (int i = 1; i < list.size(); i++) {
        TreeNode prev = list.get(i - 1), cur = list.get(i);
        prev.left  = null;           // 左指针必须清空
        prev.right = cur;
    }
}

private void preorder(TreeNode node, List<TreeNode> list) {
    if (node == null) return;
    list.add(node);                  // 根
    preorder(node.left, list);       // 左
    preorder(node.right, list);      // 右
}
```

### 解法二：原地寻找前驱（推荐，O(1) 空间）

```java
public void flatten(TreeNode root) {
    TreeNode cur = root;
    while (cur != null) {
        if (cur.left != null) {
            // ① 找左子树中最右节点 = 前序意义下右子树的前驱
            TreeNode pre = cur.left;
            while (pre.right != null) pre = pre.right;
            // ② 右子树挂到前驱的 right 上（别弄丢）
            pre.right = cur.right;
            // ③ 左子树整体搬到右边，左指针置空
            cur.right = cur.left;
            cur.left = null;
        }
        cur = cur.right;             // 继续处理下一个节点
    }
}
```

### 解法三：递归（后序拉平）

```java
public void flatten(TreeNode root) {
    if (root == null) return;
    // 先各自拉平左右子树（此时它们都已是右链）
    flatten(root.left);
    flatten(root.right);
    // 左链搬到右边，原右链接到左链尾部
    TreeNode oldRight = root.right;
    root.right = root.left;
    root.left = null;                // 必须清空，否则残留左指针
    TreeNode tail = root;
    while (tail.right != null) tail = tail.right;   // 找左链的尾
    tail.right = oldRight;
}
```

## 个人总结

### 1. 原地法的核心洞察：左子树最右节点 = 右子树的前驱

前序顺序是"根 → 左子树 → 右子树"，所以**左子树最后访问的节点**和**右子树第一个访问的节点**在中序……注意是前序里相邻。把右子树接到左子树最右节点的 `right` 上，再把左子树搬到右边，局部就完成了拼接。这个"找前驱"的手法与 Morris 遍历同源，值得记住。

### 2. 坑：展开后必须保证 left 全为 null

解法三里 `root.left = null` 这行极易漏——只搬运不清理，原左指针还挂在 root 上，结果树就"分叉"了。判断标准：遍历展开结果时沿 `right` 走，任何一个节点 `left != null` 都算错。

### 3. 递归法的顺序陷阱

必须**先递归拉平左右子树，再做搬运**——搬运操作假设"左右子树已经是右链"。如果先搬运再递归，原右子树指针已改，递归处理的就是错误的子树。典型后序思维：相信子问题已完成，只处理当前层的拼接。

### 4. 三种解法横向对比

列表重连 O(n)/O(n) 最直观，先存后连；原地前驱 O(n)/**O(1)** 是进阶要求的最优解；递归拉平 O(n)~O(n²)/O(h) 思路自然，找链尾可优化到 O(n)（辅助方法额外返回尾节点）。面试建议：先写解法一保底，主动提出解法二拿下进阶。
