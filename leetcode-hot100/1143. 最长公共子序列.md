## 题目描述

给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长 **公共子序列** 的长度。如果不存在 **公共子序列** ，返回 `0` 。

一个字符串的 **子序列** 是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

- 例如，`"ace"` 是 `"abcde"` 的子序列，但 `"aec"` 不是 `"abcde"` 的子序列。

两个字符串的 **公共子序列** 是这两个字符串所共同拥有的子序列。

## 示例

**示例 1**

```
输入：text1 = "abcde", text2 = "ace" 
输出：3  
解释：最长公共子序列是 "ace" ，它的长度为 3 。
```

**示例 2**

```
输入：text1 = "abc", text2 = "abc"
输出：3
解释：最长公共子序列是 "abc" ，它的长度为 3 。
```

**示例 3**

```
输入：text1 = "abc", text2 = "def"
输出：0
解释：两个字符串没有公共子序列，返回 0 。
```

## 思路

### 核心思想

双序列 DP 的标准模型：定义 `dp[i][j]` = `text1` 前 `i` 个字符与 `text2` 前 `j` 个字符的 LCS（Longest Common Subsequence）长度，只比较**末尾字符**：

```
text1[i-1] == text2[j-1]：dp[i][j] = dp[i-1][j-1] + 1        末尾配对，取左上
text1[i-1] != text2[j-1]：dp[i][j] = max(dp[i-1][j], dp[i][j-1])   丢掉一个末尾
```

```
text1="abcde", text2="ace" 的 dp 表
      ""  a  c  e
  ""   0  0  0  0
  a    0  1  1  1
  b    0  1  1  1
  c    0  1  2  2
  d    0  1  2  2
  e    0  1  2  3   → dp[5][3] = 3 ✅
```

下标从 1 开始（`dp[0][j] = dp[i][0] = 0`，空串与任何串的 LCS 为 0），天然处理了边界。

### 解法一：记忆化搜索（自顶向下）

`dfs(i, j)` = `text1[0..i]` 与 `text2[0..j]` 的 LCS 长度，按末尾字符是否相等递归，加 `memo` 缓存。

- 时间复杂度：\(O(mn)\)，空间复杂度：\(O(mn)\) 缓存 + \(O(m+n)\) 递归栈

### 解法二：二维 DP（推荐）

自底向上填表，边界全为 0。

- 时间复杂度：\(O(mn)\)，空间复杂度：\(O(mn)\)

### 解法三：滚动数组一维优化

`dp[i][j]` 只依赖上一行（左上、上）和本行左侧。一维数组里：更新前 `dp[j]` = 「上方」，`dp[j-1]` = 「左方」，还需 `prev` 变量暂存「左上」（更新 `dp[j]` 前先记下旧值）。

- 时间复杂度：\(O(mn)\)，空间复杂度：\(O(n)\)

## 代码

### 解法一：记忆化搜索（自顶向下）

```java
class Solution {
    private int[][] memo;

    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length(), n = text2.length();
        memo = new int[m][n];
        for (int[] row : memo) Arrays.fill(row, -1);   // -1 = 未计算
        return dfs(text1, text2, m - 1, n - 1);
    }

    // text1[0..i] 与 text2[0..j] 的最长公共子序列长度
    private int dfs(String t1, String t2, int i, int j) {
        if (i < 0 || j < 0) return 0;                  // 任一串走完，LCS = 0
        if (memo[i][j] != -1) return memo[i][j];
        if (t1.charAt(i) == t2.charAt(j)) {
            memo[i][j] = dfs(t1, t2, i - 1, j - 1) + 1;    // 末尾配对 → 进左上
        } else {
            memo[i][j] = Math.max(dfs(t1, t2, i - 1, j),    // 丢掉 t1 末尾
                                  dfs(t1, t2, i, j - 1));   // 丢掉 t2 末尾
        }
        return memo[i][j];
    }
}
```

### 解法二：二维 DP（推荐）

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length(), n = text2.length();
        // dp[i][j]：text1 前 i 个字符与 text2 前 j 个字符的 LCS 长度
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;              // 末尾配对 → 左上 + 1
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);  // 继承较优的一侧
                }
            }
        }
        return dp[m][n];
    }
}
```

### 解法三：滚动数组一维优化（空间 O(n)）

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length(), n = text2.length();
        int[] dp = new int[n + 1];
        for (int i = 1; i <= m; i++) {
            int prev = 0;                    // prev = dp[i-1][j-1]，即「左上」
            for (int j = 1; j <= n; j++) {
                int temp = dp[j];            // 暂存旧值（下一轮循环它就是「左上」）
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[j] = prev + 1;        // dp[j] 是上方，prev 是左上
                } else {
                    dp[j] = Math.max(dp[j], dp[j - 1]);   // 上方 vs 左方
                }
                prev = temp;
            }
        }
        return dp[n];
    }
}
```

## 个人总结

### 1. 双序列 DP 的统一套路：状态 = 两个前缀，决策看末尾

凡是「两个字符串/数组」的最值题，优先定义 `dp[i][j]` = 「s1 前 i 个 & s2 前 j 个」的答案，然后**只看末尾字符**分「配对 / 不配对」讨论。本题配对 → `dp[i-1][j-1] + 1`，不配对 → `max(上, 左)`。同模板的还有 72 编辑距离、583 两个字符串的删除操作、712 两个字符串的最小 ASCII 删除和——状态定义一模一样，只是转移里的运算不同（max ↔ min）。

### 2. 两个高频错误点

- **不相等时不能写 `max(左上+1, 上, 左)`**：末尾字符不相等，`dp[i-1][j-1] + 1` 无法成立（相等的前提没了），只能从「丢掉一个末尾」两个方向继承。
- **相等时直接取左上 + 1**：不需要再和上/左比较（可证明不配对不会更优），这是 LCS 转移最容易被追问证明的地方。

### 3. 滚动数组比 64. 最小路径和多一个「左上」

[64. 最小路径和](64.%20最小路径和.md) 的转移只依赖「上、左」两个来源，一维滚动直接写；本题不配对时依赖「上、左」，**配对时依赖「左上」**——必须用 `prev` 变量在覆盖 `dp[j]` 前暂存旧值。记忆口诀：**dp[j] 是上、dp[j-1] 是左、prev 是左上，进循环先存 temp**。

### 4. LCS 是字符串 DP 的母题，衍生题一串
