## 题目描述

给定一个非负整数 `numRows`，**生成「杨辉三角」的前 `numRows` 行**。

在「杨辉三角」中，数上的每个数是它左上方和右上方的数之和。

```
        1
       1 1
      1 2 1
     1 3 3 1
    1 4 6 4 1
```

## 示例

**示例 1**

```
输入：numRows = 5
输出：[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

**示例 2**

```
输入：numRows = 1
输出：[[1]]
```

---

## 提示

- `1 <= numRows <= 30`

## 思路

### 核心思想

杨辉三角本身就是一张 **DP 递推表**：第 `i` 行（下标从 0 计）共 `i+1` 个数，首尾恒为 1，中间每个数 = 上一行左上 + 右上：

```
row[j] = prev[j-1] + prev[j]     (0 < j < i)
```

逐行构造即可，没有任何弯。

### 解法一：逐行构造（推荐）

1. 外层循环行号 `i` 从 0 到 `numRows-1`，建长度 `i+1` 的列表 `row`
2. `row[0] = row[i] = 1`；中间 `j` 从 1 到 `i-1`，`row[j] = 上一行[j-1] + 上一行[j]`
3. 把 `row` 加入结果

- 时间复杂度：\(O(numRows^2)\)——全表元素总数就是 \(1+2+\dots+numRows\)
- 空间复杂度：\(O(1)\)（不计返回值；返回值本身占 \(O(numRows^2)\)）

### 解法二：递归（自顶向下）

`generate(numRows) = generate(numRows - 1)` 的全部行 + 用其末行递推出的新一行。结构上等价于逐行构造，只是用递归表达「第 i 行依赖第 i-1 行」。

- 时间复杂度：\(O(numRows^2)\)，空间复杂度：\(O(numRows)\) 递归栈（不计返回值）

## 代码

### 解法一：逐行构造（推荐）

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> res = new ArrayList<>();
        for (int i = 0; i < numRows; i++) {
            List<Integer> row = new ArrayList<>();
            row.add(1);                              // 行首恒为 1
            List<Integer> prev = res.isEmpty() ? null : res.get(i - 1);
            for (int j = 1; j < i; j++) {            // 中间：左上 + 右上
                row.add(prev.get(j - 1) + prev.get(j));
            }
            if (i > 0) row.add(1);                   // 行尾恒为 1（第 0 行只有行首）
            res.add(row);
        }
        return res;
    }
}
```

### 解法二：递归（自顶向下）

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> res = new ArrayList<>();
        if (numRows == 0) return res;                // 递归终止（约束下 numRows >= 1，防 0 保护）
        if (numRows == 1) {
            res.add(new ArrayList<>(List.of(1)));    // 第 1 行
            return res;
        }
        res = generate(numRows - 1);                 // 先生成前 numRows-1 行
        List<Integer> prev = res.get(res.size() - 1);
        List<Integer> row = new ArrayList<>();
        row.add(1);
        for (int j = 1; j < prev.size(); j++) {      // 用上一行递推中间元素
            row.add(prev.get(j - 1) + prev.get(j));
        }
        row.add(1);
        res.add(row);
        return res;
    }
}
```

## 个人总结

### 1. 「杨辉三角 = DP 教科书」：认识递推的最小模型

| DP 要素 | 在本题中的样子 |
|:---|:---|
| 状态 | 第 `i` 行第 `j` 个数 |
| 转移 | `row[j] = prev[j-1] + prev[j]` |
| 边界 | 行首、行尾 = 1 |
| 依赖方向 | 只依赖上一行 → 可滚动优化 |

本题的 dp 表是**三角形**的，比矩形网格更直观地展示「状态只依赖有限的前驱」。入门讲 DP 递推、或面试让候选人快速写个递推，都爱用它。

### 2. 下标是唯一的坑：第 i 行有 i+1 个元素

首尾都要放 1，中间循环 `j` 的范围是 `[1, i-1]`（访问 `prev[j-1]` 和 `prev[j]` 时最大下标 `i-2`，不越界）。用 `List` 时 `prev.get(j-1) + prev.get(j)` 是 `Integer` 自动拆箱相加，没问题；但注意第 0 行没有行尾，代码里要 `if (i > 0)` 判断。

### 3. numRows <= 30 是在给 int 留余量

`numRows = 30` 时最大元素 `C(30,15) ≈ 1.55×10^8`，远小于 `int` 上限约 `2.1×10^9`，本题不会溢出；若 `numRows` 到 35，`C(34,17) ≈ 2.3×10^9` 就会超 `int`。看到约束先估算极端值是否会溢出，是刷题的基本功（本题若改 `long` 则能开到约 66 行）。

### 4. 与 119. 杨辉三角 II 的关联

| 题目 | 要求 | 空间优化 |
|:---|:---|:---|
| 118. 杨辉三角 | 输出所有行 | 不计返回值 O(1) |
| 119. 杨辉三角 II | 只输出第 `rowIndex` 行 | 一维数组 **从右往左** 原地更新 `dp[j] += dp[j-1]`，空间 O(rowIndex) |

119 若从左往右更新，`dp[j-1]` 会被提前覆盖，破坏「左上 + 右上」的来源——这就是背包一维优化里「求组合数从大到小遍历」的同款技巧。
