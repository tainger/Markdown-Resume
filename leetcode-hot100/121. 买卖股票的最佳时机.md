# 121. 买卖股票的最佳时机

## 题目描述

给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

## 示例

**示例 1**

```
输入：[7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
     注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。
```

**示例 2**

```
输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 没有交易完成, 所以最大利润为 0 。
```

---

## 提示

- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`

---

## 思路

### 核心思想

在第 `i` 天卖出能赚到的最大利润 = `prices[i]` − **前 `i` 天的最低价**。所以不必枚举所有买卖对，只要一次遍历：边维护「历史最低价 `minPrice`」，边用 `prices[i] - minPrice` 刷新最大利润。这是「**枚举右、维护左**」套路的最简应用。

```
prices = [7, 1, 5, 3, 6, 4]
minPrice:  7  1  1  1  1  1
利润:      0  0  4  2  5  3   → ans = 5 ✅
```

### 解法一：暴力枚举（基础，会超时）

枚举所有「买入日 `i` < 卖出日 `j`」组合，取 `prices[j] - prices[i]` 最大值。

- 时间复杂度：\(O(n^2)\)，`n = 10^5` 时约 \(10^{10}\)，**必然 TLE**
- 空间复杂度：\(O(1)\)

### 解法二：一次遍历维护历史最低价（推荐）

1. `minPrice` 初始化为 `Integer.MAX_VALUE`，`ans = 0`
2. 每天先更新 `minPrice = min(minPrice, price)`，再尝试 `ans = max(ans, price - minPrice)`

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(1)\)

### 解法三：状态机 DP（打通股票系列）

`hold` = 截至今天**持股**的最大利润，`sold` = **不持股**的最大利润（只能交易一次）：

```
sold = max(sold, hold + prices[i])     今天卖出（用昨天的持股状态）
hold = max(hold, -prices[i])           昨天就持股 or 今天才买（买之前利润为 0）
```

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(1)\)

## 代码

### 解法一：暴力枚举（会 TLE，仅理解）

```java
class Solution {
    public int maxProfit(int[] prices) {
        int ans = 0;
        for (int i = 0; i < prices.length; i++) {         // 枚举买入日
            for (int j = i + 1; j < prices.length; j++) { // 枚举卖出日
                ans = Math.max(ans, prices[j] - prices[i]);
            }
        }
        return ans;   // 全程价格下跌时保持 0（不交易）
    }
}
```

### 解法二：一次遍历维护历史最低价（推荐）

```java
class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE;   // 迄今为止的最低买入价
        int ans = 0;                        // 迄今为止的最大利润（不交易则为 0）
        for (int price : prices) {
            if (price < minPrice) {
                minPrice = price;           // 先记录历史最低价
            } else {
                ans = Math.max(ans, price - minPrice);  // 再尝试在今天卖出
            }
        }
        return ans;
    }
}
```

### 解法三：状态机 DP（股票系列通用框架）

```java
class Solution {
    public int maxProfit(int[] prices) {
        int hold = -prices[0];      // 持股状态的最大利润（第 0 天买入）
        int sold = 0;               // 不持股状态的最大利润（尚未交易）
        for (int i = 1; i < prices.length; i++) {
            sold = Math.max(sold, hold + prices[i]);   // 今天卖出（用昨天的 hold）
            hold = Math.max(hold, -prices[i]);         // 今天买入（覆盖持股成本）
        }
        return sold;    // 最后一天不持股一定不劣于持股
    }
}
```

## 个人总结

### 1. 「枚举右、维护左」：O(n²) 降 O(n) 的通用套路

暴力慢在「对每个卖出日都重新找最低买入日」。观察发现：**最低买入日是前缀信息**，扫到哪维护到哪即可。同款套路见 53. 最大子数组和（维护前缀和最小值）。识别信号：枚举的二元组中有一个量「只取决于左侧历史」。

### 2. 与 122. 买卖股票的最佳时机 II 的对比（系列题入口）

| 题目 | 交易次数 | hold 转移 | sold 转移 |
|:---|:---|:---|:---|
| 121（本题） | 只能 1 次 | `max(hold, -price)` | `max(sold, hold + price)` |
| 122 | 任意多次 | `max(hold, sold - price)` | `max(sold, hold + price)` |

唯一差别在 hold：121 买入前利润必须是 0（用 `-price`），122 买入可以继承之前的利润（用 `sold - price`）。同系列还有 123（至多 2 次）、188（至多 k 次）、[309. 含冷冻期](309.%20买卖股票的最佳时机含冷冻期.md)、714（含手续费），全是这套「hold/sold 状态机」加状态维度。

### 3. 边界：全程下跌要返回 0

`ans` 初始化为 0 而不是负无穷——「不能获取任何利润，返回 0」等价于允许**不交易**。若把 `ans` 初始化成负数或最后没做 `max(0, ...)`，示例 2 就会输出负值。另一处细节：`sold = max(sold, hold + prices[i])` 要用**昨天**的 hold，所以先更新 `sold` 再更新 `hold`（或存临时变量），否则变成「今天买今天卖」，虽在本题不影响结果，但在 122/309 里会出错。

### 4. 解法二与解法三视角不同，结论一致

解法二把交易拆成「最低点买入 + 之后最高点卖出」两个独立决策；解法三把每一天拆成持股/不持股两个状态。面试建议：先给解法二（简单直接），被追问「如果允许多次交易/有冷冻期呢」时切换到状态机 DP 展示扩展性——这正是股票系列一串题的存在意义。
