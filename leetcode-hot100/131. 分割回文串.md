## 题目描述

给你一个字符串 `s`，请你将 `s` 分割成一些子串，使每个子串都是 **回文串** 。返回 `s` 所有可能的分割方案。

---

## 示例

**示例 1**

```
输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]
```

**示例 2**

```
输入：s = "a"
输出：[["a"]]
```

---

## 提示

- `1 <= s.length <= 16`
- `s` 仅由小写英文字母组成

## 思路

### 核心思想

「分割」= **在每个字符间隙决定切还是不切**，与子集/组合回溯同构：以 `start` 为当前切割起点，枚举第一段的终点 `end`；若 `s[start..end]` 是回文就切下来递归 `end + 1`，切到 `start == n` 收集一组方案。

### 解法一：回溯 + 双指针判回文（基础）

1. DFS(`start`)：`start == n` → `path` 就是一种方案，拷贝收集；
2. 枚举 `end = start .. n-1`：双指针判断 `s[start..end]` 是否回文；
3. 是回文 → 加入 `path`、递归 `DFS(end + 1)`、返回后弹出（回溯）。

- 时间复杂度：\(O(n \cdot 2^n)\)——最坏（如全相同字符）方案数 \(2^{n-1}\)，每个方案拷贝 \(O(n)\)；判回文 \(O(n)\) 且被大量重复计算；空间复杂度：\(O(n)\) 递归栈

### 解法二：回溯 + DP 预处理回文表（推荐）

1. 先 DP 预处理 `isPal[i][j]` 表示 `s[i..j]` 是否回文：`s[i] == s[j] && (j - i < 2 || isPal[i+1][j-1])`，**i 从大到小、j 从小到大**填表，\(O(n^2)\) 一次算完；
2. 回溯框架与解法一完全一致，只是判回文变成 O(1) 查表。

- 时间复杂度：\(O(n^2)\) 预处理 + \(O(n \cdot 2^n)\) 回溯；空间复杂度：\(O(n^2)\) 回文表 + 递归栈

## 代码

### 解法一：回溯 + 双指针判回文

```java
class Solution {
    private List<List<String>> ans = new ArrayList<>();
    private List<String> path = new ArrayList<>();
    private String s;

    public List<List<String>> partition(String s) {
        this.s = s;
        dfs(0);
        return ans;
    }

    private void dfs(int start) {
        if (start == s.length()) {             // 切到末尾，收集方案
            ans.add(new ArrayList<>(path));
            return;
        }
        for (int end = start; end < s.length(); end++) {   // 枚举第一段的终点
            if (isPalindrome(start, end)) {    // s[start..end] 是回文才切
                path.add(s.substring(start, end + 1));
                dfs(end + 1);                  // 从下一段继续切
                path.remove(path.size() - 1);  // 回溯撤销
            }
        }
    }

    private boolean isPalindrome(int l, int r) {
        while (l < r) {
            if (s.charAt(l++) != s.charAt(r--)) return false;
        }
        return true;
    }
}
```

### 解法二：回溯 + DP 回文表（推荐）

```java
class Solution {
    private List<List<String>> ans = new ArrayList<>();
    private List<String> path = new ArrayList<>();
    private String s;
    private boolean[][] isPal;                 // isPal[i][j]: s[i..j] 是否回文

    public List<List<String>> partition(String s) {
        this.s = s;
        int n = s.length();
        isPal = new boolean[n][n];
        for (int i = n - 1; i >= 0; i--) {     // i 从大到小，保证 isPal[i+1][j-1] 已算好
            for (int j = i; j < n; j++) {
                isPal[i][j] = s.charAt(i) == s.charAt(j)
                        && (j - i < 2 || isPal[i + 1][j - 1]);  // 长度 ≤ 2，或两头相等且内部回文
            }
        }
        dfs(0);
        return ans;
    }

    private void dfs(int start) {
        if (start == s.length()) {
            ans.add(new ArrayList<>(path));
            return;
        }
        for (int end = start; end < s.length(); end++) {
            if (isPal[start][end]) {           // O(1) 查表
                path.add(s.substring(start, end + 1));
                dfs(end + 1);
                path.remove(path.size() - 1);
            }
        }
    }
}
```

## 个人总结

### 1. 「切割」问题的回溯树 = 枚举第一段的终点

分割、子集、组合是同一棵回溯树的三个变体，区别只在「候选是什么」：

| 问题 | 候选 | 一次选择的含义 |
|:---|:---|:---|
| 78. 子集 | 每个元素 | 选 / 不选 |
| 39. 组合总和 | 剩余数字（可重复） | 放进组合 |
| 131. 分割回文串 | `end = start .. n-1` | 把 `s[start..end]` 切成一段 |

记住「**切割类的树枝 = 所有可能的第一段**」，框架立刻清晰；`start` 控制进度，天然无重复方案。

### 2. 回文判定是子问题，值得预计算成 DP 表

双指针判回文在最坏输入（如 `"aaaa..."`）下被重复调用海量次。`isPal[i][j]` 的递推 `s[i]==s[j] && isPal[i+1][j-1]` 把回文判定变成区间 DP——**「判定结果可复用 → 先建表再回溯」** 是回溯题的通用提速手段。填表方向：`i` 逆序、`j` 正序，保证更短的内部区间 `isPal[i+1][j-1]` 先算好；`j - i < 2` 兜住长度 1、2 的基本情况。

### 3. `substring` 右端开区间 + 快照拷贝

`substring(start, end + 1)`——**右端不含**，漏 `+1` 会切掉最后一个字符（`"aab"` 会输出错误残段）。收集方案同样要 `new ArrayList<>(path)` 拷贝快照，`path` 是共享可变列表，和 46 全排列一个道理，否则最终结果全是空引用。
