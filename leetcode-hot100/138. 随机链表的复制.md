## 题目描述

给你一个长度为 `n` 的链表，每个节点包含一个额外增加的随机指针 `random` ，该指针可以指向链表中的任何节点或空节点。

构造这个链表的 **深拷贝**。深拷贝应该正好由 `n` 个 **全新** 节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 `next` 指针和 `random` 指针也都应指向复制链表中的节点，并能保持原链表中的指针映射关系。复制链表中的指针都不应指向原链表中的节点。

例如，如果原链表中有 `X` 和 `Y` 两个节点，其中 `X.random --> Y` 。那么在复制链表中对应的两个节点 `x` 和 `y` ，同样有 `x.random --> y` 。

返回复制链表的头节点。

用一个由 `n` 个节点组成的链表来表示输入/输出中的链表。每个节点用一个 `[val, random_index]` 表示：

- `val`：一个表示 `Node.val` 的整数。
- `random_index`：随机指针指向的节点索引（范围从 `0` 到 `n-1`）；如果不指向任何节点，则为 `null` 。

你的代码 **只** 接受原链表的头节点 `head` 作为传入参数。

## 示例

**示例 1**

```
输入：head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
输出：[[7,null],[13,0],[11,4],[10,2],[1,0]]
```

**示例 2**

```
输入：head = [[1,1],[2,1]]
输出：[[1,1],[2,1]]
```

**示例 3**

```
输入：head = [[3,null],[3,0],[3,null]]
输出：[[3,null],[3,0],[3,null]]
```

## 思路

### 核心思想

难点在于 `random` 可能指向「还没创建」的节点，一遍成型不可行。要么用 **原节点 → 新节点** 的哈希映射（先建全所有副本，再统一补指针），要么用 **原地拼接** 让副本节点直接挂在原节点旁边，random 目标随手可取。

### 解法一：哈希表 + 两次遍历（推荐）

1. 第一次遍历：为每个原节点创建新节点（只建不连），存入 `Map<Node, Node>`（原 → 新）
2. 第二次遍历：按映射补齐每个新节点的 `next` 和 `random`，原指针为空则置 `null`
3. 返回 `map.get(head)`

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(n)\)（哈希表）

### 解法二：原地拼接 + 拆分（O(1) 空间）

1. 第一次遍历：把每个新节点插到对应原节点后面，拼成交错链 `A → A' → B → B' → ...`
2. 第二次遍历：设置副本的 random：`cur.next.random = cur.random.next`（`cur.random` 非空时）——副本的 random 目标恰好挂在原 random 目标的后面
3. 第三次遍历：把交错链拆成两条独立链表，恢复原链的同时摘出新链

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(1)\)（不算返回的新链表）

## 代码

### 解法一：哈希表 + 两次遍历（推荐）

```java
/*
// Definition for a Node.
class Node {
    int val;
    Node next;
    Node random;

    public Node(int val) {
        this.val = val;
        this.next = null;
        this.random = null;
    }
}
*/
class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) return null;

        // 原节点 → 新节点 的映射
        Map<Node, Node> map = new HashMap<>();

        // 第一遍：只建节点，不连任何指针
        for (Node cur = head; cur != null; cur = cur.next) {
            map.put(cur, new Node(cur.val));
        }

        // 第二遍：所有副本都已存在，按映射补齐 next 和 random
        for (Node cur = head; cur != null; cur = cur.next) {
            map.get(cur).next = (cur.next == null) ? null : map.get(cur.next);
            map.get(cur).random = (cur.random == null) ? null : map.get(cur.random);
        }
        return map.get(head);
    }
}
```

### 解法二：原地拼接 + 拆分（O(1) 空间）

```java
class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) return null;

        // 1) 拼接：新节点插到原节点后面，形成 A → A' → B → B' → ...
        for (Node cur = head; cur != null; cur = cur.next.next) {
            Node copy = new Node(cur.val);
            copy.next = cur.next;
            cur.next = copy;
        }

        // 2) 补 random：原节点的 random 的下一个，恰好就是它的副本
        for (Node cur = head; cur != null; cur = cur.next.next) {
            if (cur.random != null) {
                cur.next.random = cur.random.next;
            }
        }

        // 3) 拆分：交错链拆回两条独立链表
        Node dummy = new Node(-1);
        Node tail = dummy;
        for (Node cur = head; cur != null; cur = cur.next) {
            tail.next = cur.next;     // 收集副本节点
            tail = tail.next;
            cur.next = cur.next.next; // 同时恢复原链
        }
        return dummy.next;
    }
}
```

## 个人总结

### 1. 难点：random 指向「还没建出来」的节点

如果只遍历一遍、边建边连，`cur.random` 指向的目标副本可能还不存在。所以要拆成两个阶段：**先把全部副本建出来（建立原 → 新的对应关系），再统一补指针**。「先建全、再连接」是深拷贝类问题的通用套路。

### 2. 哈希表的 key 必须是节点对象，不能是 val

示例 3 里三个节点的 val 都是 3：若用 `Map<Integer, Node>`，三个不同节点会映射到同一个副本，random 关系全错。`Map<Node, Node>` 靠对象引用天然区分。

### 3. 拼接法的巧劲：random 一步到位

交错链里「原节点 random 目标的 next」恰好就是「random 目标的副本」，所以 `cur.next.random = cur.random.next` 一行完成 random 复制。代价是三遍遍历 + 临时修改原链，**拆分时必须把原链恢复**（循环里 `cur.next = cur.next.next` 就是恢复动作）。

### 4. 拆分循环的推进方向是「原链视角」

拆分循环体里先改了 `cur.next`（指向下一个原节点），而循环推进恰是 `cur = cur.next`——两个动作一个负责摘副本、一个负责沿原链前进，正好互不干扰，不会踩进副本节点。
