## 题目描述

给你链表的头结点 `head` ，请将其按 **升序** 排列并返回 **排序后的链表** 。

## 示例

**示例 1**

```
输入：head = [4,2,1,3]
输出：[1,2,3,4]
```

**示例 2**

```
输入：head = [5,-1,3,4,0]
输出：[-1,0,3,4,5]
```

**示例 3**

```
输入：head = []
输出：[]
```

---

## 提示

- 链表中节点的数目在范围 `[0, 5 * 10^4]` 内
- `-10^5 <= Node.val <= 10^5`

---

## 进阶

你可以在 `O(n log n)` 时间复杂度和常数级空间复杂度下，对链表进行排序吗？

---

## 思路

### 核心思想

对链表做 **归并排序**：快慢指针找中点把链表切成两半，分别递归排序，再用 21 题「合并两个有序链表」拼起来。链表归并相比数组归并的优势：不需要辅助数组，合并就是改指针。

### 解法一：转数组排序（基础）

1. 遍历链表，把值拷进数组
2. `Collections.sort` 排序
3. 按排序结果回写每个节点的 `val`（节点个数不变，直接覆盖）

- 时间复杂度：\(O(n \log n)\)，空间复杂度：\(O(n)\)
- ⚠️ 能过 OJ，但完全没用链表结构，面试官真正想要的是归并，只能当开场引子

### 解法二：自顶向下归并（推荐）

1. 递归基准：链表为空或只有一个节点，天然有序
2. **快慢指针找中点**：`slow` 每步 1、`fast` 每步 2（注意 `fast` 从 `head.next` 出发），把链表从 `slow` 处断成两半
3. 左半 `sortList(head)`、右半 `sortList(mid)` 递归排序
4. `merge` 合并两段有序链表（复用 21. 合并两个有序链表的迭代写法）

- 时间复杂度：\(O(n \log n)\)，空间复杂度：\(O(\log n)\)（递归栈）

## 代码

### 解法一：转数组排序（基础）

```java
class Solution {
    public ListNode sortList(ListNode head) {
        // 1. 拷贝值到数组
        List<Integer> vals = new ArrayList<>();
        for (ListNode cur = head; cur != null; cur = cur.next) {
            vals.add(cur.val);
        }
        // 2. 排序
        Collections.sort(vals);
        // 3. 按顺序回写节点值（节点本身不动）
        int i = 0;
        for (ListNode cur = head; cur != null; cur = cur.next) {
            cur.val = vals.get(i++);
        }
        return head;
    }
}
```

### 解法二：自顶向下归并（推荐）

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode sortList(ListNode head) {
        // 基准：空或单节点天然有序
        if (head == null || head.next == null) {
            return head;
        }

        // 1. 快慢指针找中点：fast 从 head.next 出发，偶数长度从中点偏左断开
        ListNode slow = head, fast = head.next;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // 2. 从 slow 处断链，切成两半
        ListNode mid = slow.next;
        slow.next = null;

        // 3. 两半分别递归排序
        ListNode left = sortList(head);
        ListNode right = sortList(mid);

        // 4. 合并两个有序链表（21 题写法）
        return merge(left, right);
    }

    // 迭代合并两个有序链表（复用 21. 合并两个有序链表）
    private ListNode merge(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(-1);
        ListNode curr = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val <= l2.val) {
                curr.next = l1;
                l1 = l1.next;
            } else {
                curr.next = l2;
                l2 = l2.next;
            }
            curr = curr.next;
        }
        curr.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}
```

## 个人总结

### 1. `fast = head.next` 是防死循环的关键

快慢指针找中点若 `fast` 从 `head` 出发：

```
[1, 2]：slow 停在 2，mid = slow.next = null → 右半为空
       sortList([1,2]) 又被切成 [1,2] + [] → 无限递归爆栈
```

`fast` 从 `head.next` 出发后，长度 ≥ 2 的链表切出来的右半至少有 1 个节点，递归必然收敛。

### 2. 找到中点必须「断链」

`slow.next = null` 把链表真正切成两条。不断链的话，左右两半藕断丝连，底层递归会重复处理同一批节点，结果错乱——和 25 题「先数够再翻」一样，属于链表分治的断链防护。

### 3. 递归栈 O(log n) ≠ 进阶要求的 O(1)

自顶向下归并时间满足 O(n log n)，但递归栈占 O(log n) 空间。要严格 O(1) 空间需改用 **自底向上归并**：以步长 1、2、4、8… 逐轮翻倍分组，组内两两合并，直到步长超过链长；每轮用「先数总长度 + dummy」循环完成，全程无需递归。面试被追问进阶时答这个方向即可。

### 4. merge 直接复用 21 题

排序链表 = 「找中点（快慢指针）+ 递归分治 + 合并两个有序链表」，其中合并一步与 21. 合并两个有序链表的迭代写法一字不差。这题本质是 21 题的套壳：**链表大题的零件，往往就是前面的基础题**。
