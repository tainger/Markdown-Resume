## 题目描述

给你一个整数数组 `nums` ，请你找出数组中乘积最大的**非空连续子数组**（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 **32 位** 整数。

---

## 示例

**示例 1**

```
输入：nums = [2,3,-2,4]
输出：6
解释：子数组 [2,3] 有最大乘积 6。
```

**示例 2**

```
输入：nums = [-2,0,-1]
输出：0
解释：结果不能为 2, 因为 [-2,-1] 不是子数组。
```

---

## 提示

- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- `nums` 的任何前缀或后缀的乘积都 **保证** 是一个 32 位整数

## 思路

### 核心：和版 Kadane 只存一个最大值就够了，乘积版不行——负数×负数会翻正

[53. 最大子数组和](53.%20最大子数组和.md) 里「以 i 结尾的最大和」只需存 max：加一个负数只会变小，最小值没有利用价值。乘积版多了两个变数：

1. **负×负=正**：一个很小的负乘积（如 -48），乘上后面一个负数（如 -1）可能一跃成为全局最大——**最小值有翻盘价值，必须同时存**；
2. **0 归零**：乘 0 后前面全部作废，从 0 重新开始——好在转移公式天然处理（见解法二），无需显式清零。

两种解法一条链：

| 解法 | 视角 | 时间 | 空间 |
|:---|:---|:---:|:---:|
| 解法一：暴力 | 枚举所有子数组累乘 | \(O(n^2)\) | \(O(1)\) |
| 解法二：DP（max/min 双状态） | 以 i 结尾的最大乘积 + 最小乘积各存一份 | \(O(n)\) | \(O(1)\)（滚动变量） |

### 解法一：暴力枚举（TLE，理解入口）

按定义直译：所有子数组里挑乘积最大的。

1. 外层枚举起点 `i`，内层枚举终点 `j`；
2. 内层**累乘**维护 `prod[i..j]`（终点右移一步只乘一个元素）；
3. 全程取 max。

- 时间 \(O(n^2)\)：`n = 2*10^4` 时约 \(4*10^8\) 次乘法，**超时风险大**；空间 \(O(1)\)
- 价值：先写它验证正确性。瓶颈与和版 53 完全一样——**相邻子问题之间零信息复用**；乘积版多一个隐患：中间累乘可能溢出 int（答案 32 位有保证，但暴力中间值没有），严谨实现要用 long/double，进一步说明暴力不可行

### 解法二：DP（max/min 双状态，Kadane 乘积版）

沿用 53 的推导纪律：**暴力按结尾分组 → 找「去掉最后一步」的依赖 → 写转移**。以 j 结尾的子数组去掉 `nums[j]` 后必是「以 j−1 结尾」的子数组，所以：

1. 定义**两个**状态（这是与和版的唯一结构差异）：
   - `dpMax[i]` = 以 `nums[i]` 结尾的子数组中，**最大**乘积
   - `dpMin[i]` = 以 `nums[i]` 结尾的子数组中，**最小**乘积（专为负数翻盘准备）
2. 转移是**三选一**：新乘积要么接在最大上、要么接在最小上（负负翻正用）、要么自己另起：

```text
dpMax[i] = max(dpMax[i-1] * x, dpMin[i-1] * x, x)
dpMin[i] = min(dpMax[i-1] * x, dpMin[i-1] * x, x)      // x = nums[i]
```

   为什么 min 也是同样三选一：最大和最小的「候选来源」相同（三种接法），只是取的方向相反。
3. 答案 = 全程 `max(dpMax[0..n-1])`；
4. `dpMax[i]/dpMin[i]` 只依赖 i−1 → 各压成一个滚动变量，空间 \(O(1)\)。

- 时间 \(O(n)\)、空间 \(O(1)\)
- **0 的处理是免费的**：`x = 0` 时三选一必取到 `x` 分支 → `dpMax = dpMin = 0`，下一轮相当于从零重开，不需要任何特判

## 代码

### 解法一：暴力枚举（TLE，理解入口）

```java
class Solution {
    public int maxProduct(int[] nums) {
        int n = nums.length, ans = Integer.MIN_VALUE;
        for (int i = 0; i < n; i++) {          // 枚举起点 i
            long prod = 1;                     // long 防中间累乘溢出
            for (int j = i; j < n; j++) {      // 终点 j 右扩，prod = 乘积[i..j]
                prod *= nums[j];               // 累乘代替重新相乘：O(n³) → O(n²) 的关键
                ans = Math.max(ans, (int) Math.min(prod, Integer.MAX_VALUE));
            }
        }
        return ans;
    }
}
```

- `n = 2*10^4` 时约 \(4*10^8\) 次乘法，**LeetCode 超时风险高**——先写它验证正确性
- 题目只保证「前缀/后缀乘积」在 32 位内，任意中间子数组累乘可能溢出，所以暴力版严谨实现必须用 long

### 解法二：DP（max/min 双状态，推荐）

```java
class Solution {
    public int maxProduct(int[] nums) {
        int curMax = nums[0], curMin = nums[0], ans = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int x = nums[i];
            // 三选一候选：接最大 / 接最小(负负翻正) / 自己重开
            int c1 = curMax * x, c2 = curMin * x;
            curMax = Math.max(x, Math.max(c1, c2));
            curMin = Math.min(x, Math.min(c1, c2));
            ans = Math.max(ans, curMax);
        }
        return ans;
    }
}
```

- **必须用临时变量**：先算好 `c1/c2` 再更新 `curMax`——如果直接 `curMax = max(curMax*x, ...)` 先覆盖了 `curMax`，再算 `curMin` 时用的就是新值，状态污染（本题第一大坑）
- `ans` 只需要跟踪 `curMax`（最大乘积），`curMin` 是纯工具状态，最后不取它

## 个人总结

### 1. 题眼：乘积 + 连续子数组 → 53 的 Kadane 双状态化

状态设计完全继承 [53. 最大子数组和](53.%20最大子数组和.md) 的「以 i 结尾」，唯一结构差异：**最大值要配一个最小值**。记这个差异的口诀——「和看正负甩，积看正负翻」：加法里负数只能拖累（甩掉即可），乘法里负数可能翻盘（必须留底）。

### 2. 推导链：和版 53 的推导直接迁移，只多一步「为什么存 min」

把暴力枚举按结尾分组后，与 53 完全相同的依赖链浮现：以 j 结尾 ⇐ 以 j−1 结尾。但转移时多了一个候选来源：

```
dp[j] = max( dpMax[j-1]*x , dpMin[j-1]*x , x )     // 比和版多一个 dpMin 分支
```

为什么和版不需要这个分支：加法里 `sum[i..j-1]` 越大接上 `x` 后越大，最小值永无翻盘机会；乘法里 **dpMin 是负数时，乘负 x 后变最大**——`dpMin[j-1]` 是「未来翻盘的种子」。这不是背出来的，是从「负×负=正」反推出的必要状态。

### 3. 三选一转移统一处理所有情况（含 0、负数）

| x | curMax 走哪个分支 | curMin 走哪个分支 | 效果 |
|:---:|:---|:---|:---|
| x > 0 | 通常接 curMax | 通常接 curMin | 常规延续 |
| x < 0 | 接 curMin（负负翻正） | 接 curMax（正变最负） | **双状态同时发挥作用** |
| x = 0 | 取 x 分支 | 取 x 分支 | 双双归零，下轮自动重开，无需特判 |

一张表看懂：**不需要对 0 / 负数写任何 if，三选一 max/min 天然覆盖**——这就是状态设计正确的标志。

### 4. 更新顺序是第一大坑：先存候选再覆盖

```java
int c1 = curMax * x, c2 = curMin * x;   // ★ 先算好两个候选
curMax = ...;  curMin = ...;            // 再更新
```

若直接更新 `curMax` 后再用旧 `curMin` 的思路写 `curMin = min(curMax * x, ...)`，此时 `curMax` 已是新值——**交叉引用互相污染**。和版 53 单变量无所谓，双状态必须先缓存候选。

### 5. 答案取 curMax 的全程 max，不取 curMin

`curMax` 的含义是「必须以 i 结尾」的局部最优（同 53），所以答案 = `max(dpMax[0..n-1])`。`curMin` 是辅助状态，不存在于答案里。

### 6. 同源题族：「以 i 结尾」模板的迁移

| 题目 | 变化点 | 迁移要点 |
|:---|:---|:---|
| [53. 最大子数组和](53.%20最大子数组和.md) | 积→和 | 加法负数只拖累 → 单状态 max 即可 |

| 1567. 乘积为正数的最长子串长度 | 乘积→正负性 | 同款双状态：以 i 结尾乘积为正/负的**最长长度** |
