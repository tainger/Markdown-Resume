## 题目描述

设计一个支持 `push` ，`pop` ，`top` 操作，并能在常数时间内检索到最小元素的栈。

实现 `MinStack` 类:

- `MinStack()` 初始化堆栈对象。
- `void push(int val)` 将元素 `val` 推入堆栈。
- `void pop()` 删除堆栈顶部的元素。
- `int top()` 获取堆栈顶部的元素。
- `int getMin()` 获取堆栈中的最小元素。

---

## 示例

**示例 1**

```
输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

输出：
[null,null,null,null,-3,null,0,-2]

解释：
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   --> 返回 -3.
minStack.pop();
minStack.top();      --> 返回 0.
minStack.getMin();   --> 返回 -2.
```

---

## 提示

- `-2^31 <= val <= 2^31 - 1`
- `pop`、`top` 和 `getMin` 操作总是在 **非空栈** 上调用
- `push`, `pop`, `top`, and `getMin` 最多被调用 `3 * 10^4` 次

## 思路

### 核心思想

难点只在 `getMin` 要 **O(1)**。普通栈想拿最小值得遍历一遍（O(n)）。关键洞察：**栈的进出是「后进先出」，某一时刻的最小值只跟「当前及之前压入的元素」有关**。所以只要在每次 push 时，把「到目前为止的最小值」也记录下来，弹栈时同步弹掉，`getMin` 直接读记录即可。

### 解法一：辅助栈（推荐，最清晰）

用两个栈：

- **数据栈 `stack`**：正常存所有元素。
- **辅助栈 `minStack`**：栈顶始终是**数据栈当前所有元素的最小值**。

操作规则：

- `push(val)`：`val` 压数据栈；同时把 `min(val, 辅助栈栈顶)` 压辅助栈（辅助栈为空时直接压 val）。
- `pop()`：两个栈**同步**弹出。
- `top()`：返回数据栈栈顶。
- `getMin()`：返回辅助栈栈顶（O(1)）。

```
push(-2): stack=[-2]      minStack=[-2]
push(0):  stack=[-2,0]    minStack=[-2,-2]   （min(0,-2)=-2）
push(-3): stack=[-2,0,-3] minStack=[-2,-2,-3]（min(-3,-2)=-3）
getMin(): minStack 顶 = -3 ✅
pop():    stack=[-2,0]    minStack=[-2,-2]
getMin(): minStack 顶 = -2 ✅
```

- 时间复杂度：所有操作 \(O(1)\)；空间复杂度：\(O(n)\)（多一个等长辅助栈）。

### 解法二：单栈存「差值」（省空间进阶）

只用一个栈，栈里存 **`val - 当前最小值`（差值）**，另用变量 `min` 记录当前最小值。

- `push(val)`：若栈空，`min = val`，压 `0`；否则压 `val - min`；若 `val < min`，更新 `min = val`。
- `pop()`：取差值 `diff`，若 `diff < 0`（说明当前栈顶就是最小值），需先恢复 `min = min - diff`（还原上一个最小值），再弹出。
- `top()`：`diff >= 0` 时 `top = min + diff`；`diff < 0` 时 `top = min`（栈顶即最小值）。
- `getMin()`：返回 `min`。

- 时间复杂度：\(O(1)\)；空间复杂度：\(O(n)\) 但只存一个栈。**注意差值可能溢出 int**，用 `long` 存差值更稳。

## 代码

### 解法一：辅助栈（推荐）

```java
class MinStack {
    private Deque<Integer> stack;      // 数据栈
    private Deque<Integer> minStack;   // 辅助栈，栈顶=当前最小值

    public MinStack() {
        stack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }

    public void push(int val) {
        stack.push(val);
        // 压入 val 与当前最小值中的较小者
        if (minStack.isEmpty()) {
            minStack.push(val);
        } else {
            minStack.push(Math.min(val, minStack.peek()));
        }
    }

    public void pop() {
        stack.pop();
        minStack.pop();                // 同步弹出
    }

    public int top() {
        return stack.peek();
    }

    public int getMin() {
        return minStack.peek();        // O(1)
    }
}
```

### 解法二：单栈存差值（省空间）

```java
class MinStack {
    private Deque<Long> stack;         // 存 val - min 的差值，用 long 防溢出
    private long min;                  // 当前最小值

    public MinStack() {
        stack = new ArrayDeque<>();
    }

    public void push(int val) {
        if (stack.isEmpty()) {
            min = val;
            stack.push(0L);            // 第一个元素差值为 0
        } else {
            stack.push(val - min);     // 存差值
            if (val < min) min = val;  // 更新最小值
        }
    }

    public void pop() {
        long diff = stack.pop();
        if (diff < 0) {                // 栈顶原本是最小值，需还原上一个最小值
            min = min - diff;
        }
    }

    public int top() {
        long diff = stack.peek();
        return (int) (diff >= 0 ? min + diff : min);  // diff<0 时栈顶即最小值
    }

    public int getMin() {
        return (int) min;
    }
}
```

## 个人总结

### 1. 核心洞察：最小值随栈「同生共死」

栈是 LIFO，弹出栈顶后，最小值应回退到「压入该元素之前」的状态。所以最自然的做法是**每次 push 都把当时的最小值一起记住**，pop 时一起丢弃——这就是辅助栈的本质。想清这点，题目就从"设计题"变成"套模板"。

### 2. 辅助栈压的是「min(val, 栈顶)」不是 val

辅助栈每个位置存的是**「压到这一层为止的最小值」**，而非当前元素本身。所以压的是 `min(val, minStack.peek())`。这样即使后来压入更大的数，辅助栈栈顶依然保留着之前的最小值，getMin 永远正确。

### 3. 用 Deque 而不是 Stack

Java 的 `Stack` 是遗留类（继承 `Vector`，方法都加了 synchronized，性能差），官方推荐用 `ArrayDeque` 当栈：`push` / `pop` / `peek` 语义一致且更快。这是刷栈题的通用规范。

### 4. 单栈解法的两个坑

- **溢出**：`val - min` 在 val 和 min 一正一负且都接近 int 边界时会溢出，必须用 `long` 存差值。
- **恢复最小值的时机**：只有 `diff < 0`（说明弹出的正是当前最小值）时才需要 `min = min - diff` 还原。这一步最容易写错或漏写。

### 5. 两种解法取舍

| 解法 | 时间 | 空间 | 定位 |
|:---|:---:|:---:|:---|
| 辅助栈 | 全 \(O(1)\) | \(O(n)\)（两个栈） | 最清晰，面试首选 |
| 单栈差值 | 全 \(O(1)\) | \(O(n)\)（一个栈） | 省一半空间，但要处理溢出/还原 |

**面试建议**：直接讲辅助栈（清晰、不易错），若面试官追问优化空间，再补单栈差值法并主动点出「差值溢出」这个坑。
