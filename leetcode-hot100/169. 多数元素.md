# 169. 多数元素

> **难度**：🟢 简单 | **标签**：数组、哈希表、分治、计数、排序 | **企业**：—

## 题目描述

给定一个大小为 `n` 的数组 `nums` ，返回其中的**多数元素**。

多数元素是指在数组中出现次数**大于** \\(\\lfloor n/2 \\rfloor\\) 的元素。你可以假设数组是非空的，并且给定的数组总是存在多数元素。

## 示例

**示例 1**

```
输入：nums = [3,2,3]
输出：3
```

**示例 2**

```
输入：nums = [2,2,1,1,1,2,2]
输出：2
```

---

## 提示

- `n == nums.length`
- \\(1 \\le n \\le 5 \\times 10^4\\)
- \\(-10^9 \\le \\text{nums[i]} \\le 10^9\\)

---

## 进阶

尝试设计时间复杂度为 \\(O(n)\\)、空间复杂度为 \\(O(1)\\) 的算法解决此问题。

## 思路

### 核心思想

**多数元素**——出现次数 > n/2，意味着把所有数分成"多数派"和"少数派"，多数派的数量一定比少数派多。

四种解法，从易到难：

```
解法              时间       空间      面试价值
─────────────────────────────────────────────
HashMap 计数       O(n)      O(n)      ⭐ 保底
排序取中间         O(n log n) O(1)     ⭐ 巧
Boyer-Moore 投票   O(n)      O(1)     ⭐⭐⭐ 必会
分治               O(n log n) O(log n) ⭐ 了解
```

### 解法一：哈希表计数

遍历数组，`Map<值, 次数>` 统计，次数 > n/2 时返回。

### 解法二：排序取中间

排序后，下标 `n/2` 的位置一定是多数元素（因为多数元素至少占据一半以上位置）。

```
排序前: [2,2,1,1,1,2,2]
排序后: [1,1,1,2,2,2,2]
              ↑ n/2 = 3 → 2 ✓
```

### 解法三：Boyer-Moore 投票算法（最优）

```
核心逻辑：

维护 candidate（候选人）和 count（票数）

遍历每个数字 x：
  - count == 0 → candidate = x, count = 1 （换候选人）
  - x == candidate → count++            （支持票）
  - x != candidate → count--            （反对票，互相抵消）

最终 candidate 就是多数元素
```

**为什么正确？** 多数元素的数量 > n/2，意味着即使所有非多数元素联合起来"反对"，投票耗尽后，多数元素依然能胜出。

```
演示：nums = [2,2,1,1,1,2,2]

 i   x   candidate  count   说明
─────────────────────────────────
 0   2      2         1    初始化
 1   2      2         2    支持
 2   1      2         1    反对，count--
 3   1      2         0    反对，count=0 → 下次换人
 4   1      1         1    换候选人
 5   2      1         0    反对，count=0
 6   2      2         1    换候选人 → 最终 candidate=2 ✓
```

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(1)\\)

### 解法一：哈希表

```java
public int majorityElement(int[] nums) {
    Map<Integer, Integer> map = new HashMap<>();
    int half = nums.length / 2;
    for (int x : nums) {
        map.put(x, map.getOrDefault(x, 0) + 1);
        if (map.get(x) > half) return x;
    }
    return -1; // 不会到这里，题目保证存在多数元素
}
```

### 解法二：排序取中间

```java
public int majorityElement(int[] nums) {
    Arrays.sort(nums);
    return nums[nums.length / 2];
}
```

### 解法三：Boyer-Moore 投票（推荐，O(1) 空间）

```java
public int majorityElement(int[] nums) {
    int candidate = 0, count = 0;
    for (int x : nums) {
        if (count == 0) {
            candidate = x;      // 无人领先，换候选人
        }
        count += (x == candidate) ? 1 : -1;  // 支持票 +1，反对票 -1
    }
    return candidate;
}
```
