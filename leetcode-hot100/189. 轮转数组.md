## 题目描述

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是**非负数**。

## 示例

**示例 1**

```
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
解释:
向右轮转 1 步: [7,1,2,3,4,5,6]
向右轮转 2 步: [6,7,1,2,3,4,5]
向右轮转 3 步: [5,6,7,1,2,3,4]
```

**示例 2**

```
输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
解释:
向右轮转 1 步: [99,-1,-100,3]
向右轮转 2 步: [3,99,-1,-100]
```

---

## 提示

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

---

## 思路

### 核心思想

右旋 `k` 位后，**末尾 `k` 个元素整体搬到前面，其余元素顺序后移**。三种解法都围绕这个结构：换容器（额外数组）、三次翻转（原地最优雅）、环状替换（原地逐环搬运）。无论哪种，第一行都是 `k %= n`。

### 解法一：额外数组（基础）

1. 新开数组 `tmp`，原下标 `i` 的元素右旋后落在 `(i + k) % n`：`tmp[(i + k) % n] = nums[i]`；
2. 把 `tmp` 拷回 `nums`。

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(n)\)

### 解法二：三次翻转（推荐）

1. `k %= n`；
2. 翻转**整个**数组；
3. 翻转**前 `k` 个**；
4. 翻转**后 `n-k` 个**。

例：`[1,2,3,4,5,6,7], k=3` → 整体翻 `[7,6,5,4,3,2,1]` → 前 3 个翻回 `[5,6,7,4,3,2,1]` → 后 4 个翻回 `[5,6,7,1,2,3,4]` ✅

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(1)\)

### 解法三：环状替换

1. 元素 `i` 的目的地是 `(i + k) % n`，从某个起点出发沿环搬运；一个环的大小为 `n / gcd(n, k)`，要走 `gcd(n, k)` 个环才搬完 `n` 个元素；
2. 从 `start = 0, 1, ...` 依次出发，用临时变量把值沿环传下去，直到回到 `start`；用计数器控制总搬运数为 `n` 时结束。

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(1)\)

## 代码

### 解法一：额外数组

```java
public void rotate(int[] nums, int k) {
    int n = nums.length;
    int[] tmp = new int[n];
    // 原下标 i 的元素右旋后落在 (i + k) % n
    for (int i = 0; i < n; i++) {
        tmp[(i + k) % n] = nums[i];
    }
    System.arraycopy(tmp, 0, nums, 0, n);
}
```

### 解法二：三次翻转（推荐）

```java
public void rotate(int[] nums, int k) {
    int n = nums.length;
    k %= n;                       // k 可能大于 n，必须先取模
    reverse(nums, 0, n - 1);      // ① 整体翻转
    reverse(nums, 0, k - 1);      // ② 翻转前 k 个
    reverse(nums, k, n - 1);      // ③ 翻转后 n - k 个
}

private void reverse(int[] nums, int l, int r) {
    while (l < r) {
        int tmp = nums[l];
        nums[l] = nums[r];
        nums[r] = tmp;
        l++;
        r--;
    }
}
```

### 解法三：环状替换

```java
public void rotate(int[] nums, int k) {
    int n = nums.length;
    k %= n;
    int count = 0;                      // 已搬运的元素个数
    for (int start = 0; count < n; start++) {
        int cur = start;
        int val = nums[start];          // 手里拿着待放进环上下一个位置的值
        do {
            int next = (cur + k) % n;   // cur 的元素要去的位置
            int tmp = nums[next];       // 暂存被覆盖的值
            nums[next] = val;
            val = tmp;                  // 接着搬运刚被挤出来的值
            cur = next;
            count++;
        } while (cur != start);         // 回到起点，这个环搬完
    }
}
```

## 个人总结

### 1. `k %= n` 忘了必错

`0 <= k <= 10^5` 而 `n` 可以很小：`k = 100000, n = 1` 时不取模的话，三次翻转的 `reverse(nums, 0, k-1)` 直接越界。**见到「旋转 k 位」第一行就写 `k %= n`**（`n = 1` 时取模后 `k = 0`，天然安全，无需特判）。

### 2. 三次翻转的口诀与区间

核心观察：右旋后「前 k 个」和「后 n-k 个」两段内部相对顺序都不变，只是换了位置——**先整体翻转，再各段翻回来**。三个区间别写错：整体 `[0, n-1]`、前段 `[0, k-1]`、后段 `[k, n-1]`。面试建议现场用 `[1,2,3,4,5,6,7], k=3` 走一遍，比背结论有说服力。

### 3. 三种解法对比（进阶明确要求「至少三种」）

| 解法 | 时间 | 空间 | 备注 |
|:---|:---|:---|:---|
| 额外数组 | \(O(n)\) | \(O(n)\) | 最好想，先说它垫底 |
| 三次翻转 | \(O(n)\) | \(O(1)\) ✅ | 代码最短、最优雅，主推 |
| 环状替换 | \(O(n)\) | \(O(1)\) ✅ | 难写难讲，体现功底 |

### 4. 面试高频追问：环状替换为什么按 gcd 分环

从 0 出发每次跳 `k`，能访问的下标集合是 `{(t·k) % n}`，大小为 `n / gcd(n, k)`——**一个环只覆盖 `n/gcd` 个位置**，所以必须从 `0, 1, ..., gcd(n,k)-1` 各出发一次才能搬完。用 `count < n` 做总闸也能写对，但能讲出 gcd 才说明真懂。变体：**左旋**只需把三段翻转改成「先翻前 n-k、再翻后 k、最后整体」；本题是「旋转数组」最裸的模型，151（翻转字符串里的单词）同款翻转思想。
