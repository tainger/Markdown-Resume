## 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是**相邻的房屋装有相互连通的防盗系统**，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你 **不触动警报装置的情况下** ，一夜之内能够偷窃到的最高金额。

## 示例

**示例 1**

```
输入：[1,2,3,1]
输出：4
解释：偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。偷窃到的最高金额 = 1 + 3 = 4 。
```

**示例 2**

```
输入：[2,7,9,3,1]
输出：12
解释：偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。偷窃到的最高金额 = 2 + 9 + 1 = 12 。
```

- `0 <= nums[i] <= 400`

## 思路

### 核心思想

每间房只有「偷 / 不偷」两种选择，且选择只与**前一间**是否被偷有关：

- **偷第 i 间** → 第 i-1 间必须不偷 → 最优是 `dp[i-2] + nums[i]`
- **不偷第 i 间** → 沿用前 i-1 间的最优 `dp[i-1]`

定义 `dp[i]` = 考虑前 `i+1` 间房（下标 0..i）能偷到的最高金额：

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])        i >= 2
dp[0] = nums[0]，dp[1] = max(nums[0], nums[1])
```

```
nums = [2,7,9,3,1]
dp    = 2, 7, 11, 11, 12    → dp[4] = 12 ✅（2+9+1）
```

### 解法一：一维 DP（基础）

按转移方程直接填表。只依赖前两个状态，是滚动优化的天然候选。

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(n)\)

### 解法二：滚动变量（推荐）

用 `prev`（= dp[i-2]）、`cur`（= dp[i-1]）两个变量滚动前进，每轮算出 `next = max(cur, prev + num)` 再整体前移。初值 `prev = cur = 0` 等价于「前两间虚拟空房」，连 `n == 1` 的特判都省了。

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(1)\)

## 代码

### 解法一：一维 DP

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];         // 只有一间，直接偷
        int[] dp = new int[n];              // dp[i]：偷前 i+1 间房的最高金额
        dp[0] = nums[0];
        dp[1] = Math.max(nums[0], nums[1]);
        for (int i = 2; i < n; i++) {
            // 不偷第 i 间 → dp[i-1]；偷第 i 间 → dp[i-2] + nums[i]
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
        }
        return dp[n - 1];
    }
}
```

### 解法二：滚动变量（推荐）

```java
class Solution {
    public int rob(int[] nums) {
        int prev = 0, cur = 0;              // prev = dp[i-2]，cur = dp[i-1]
        for (int num : nums) {
            int next = Math.max(cur, prev + num);  // 不偷当前 vs 偷当前
            prev = cur;                     // 整体前移一格
            cur = next;
        }
        return cur;                         // 全部考虑完的最优值
    }
}
```

## 个人总结

### 1. 状态定义选「考虑前 i 间」，不要选「必须偷第 i 间」

「考虑前 `i+1` 间」的定义让答案直接是 `dp[n-1]`，无须枚举最后一间偷没偷；若定义「必须偷第 `i` 间」为 `f[i]`，转移会变成 `f[i] = max(f[i-2], f[i-3]) + nums[i]`，还要多比较一层才能出答案。两种都对，但前者转移更简洁——**定义状态时优先选「前缀最优」而不是「必须以 i 结尾」**（后者是子数组型题的常用定义，见 53）。

### 2. 滚动变量初值 `prev = cur = 0` 是隐式边界技巧

等价于在下标 0 前面虚拟了两间「金额为 0 的空房」，使 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` 对 `i = 0` 也成立（`max(0, 0 + nums[0]) = nums[0]`），从而消灭了 `n == 1`、`n == 2` 的特判分支。凡是「只依赖前 k 个状态」的 DP 都可以用 k 个虚拟初值 + k 个滚动变量压缩空间。

### 3. 打家劫舍系列：同一约束的三种变形

| 题目 | 变形 | 解法 |
|:---|:---|:---|
| 198（本题） | 直线，相邻不能同偷 | 线性 DP + 滚动变量 |
| 213. 打家劫舍 II | **环形**（首尾相邻） | 拆成「不偷首」`[1..n-1]` 与「不偷尾」`[0..n-2]` 两次线性 DP 取 max |
| [337. 打家劫舍 III](337.%20打家劫舍%20III.md) | **树形**（父子不能同偷） | 后序遍历，每个节点返回 (偷, 不偷) 两个状态 |

三个题共享「选了我就不能选相邻」这一约束，DP 状态数都极小（2 个），考的是建模方式从线性 → 环形 → 树形的迁移。

### 4. 「相邻互斥」类约束的通用转移模板

把约束翻译成转移：「选 i → 只能继承 i-2 的最优」。同族题：740. 删除并获得点数（把点数转成桶数组后即打家劫舍）、面试题 17.16 按摩师。识别信号：元素之间有「选 A 就不能选相邻 B」的互斥关系、且目标是求最大收益 → 直接套 `max(不选, 选 + 跳过前一个)`。
