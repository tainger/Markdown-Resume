## 题目描述

给定一个二叉树的 **根节点** `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

## 示例

**示例 1**

```
输入: root = [1,2,3,null,5,null,4]
输出: [1,3,4]

树结构：
        1            ←
       / \
      2   3          ←  看到的是 3
       \   \
        5   4        ←  看到的是 4
```

**示例 2**

```
输入: root = [1,null,3]
输出: [1,3]
```

**示例 3**

```
输入: root = []
输出: []
```

## 思路

### 核心思想

**右视图 = 每一层最靠右的那个节点组成的序列**（自顶向下）。注意：不是"从根一直沿 right 走下来的链"——如果某层右子树为空，该层最右节点可能在左子树里（如示例 1 的 5 下面如果再挂 6，6 也能被看到……更准确的反例见个人总结第 3 点）。所以必须老老实实"逐层、取最右"。

两条实现路径：BFS 天然逐层取 `i == size - 1`；DFS 用「根 → 右 → 左」的访问顺序，**每层第一个被访问到的就是最右节点**。

### 解法一：BFS 逐层取最后一个（基础）

1. 标准层序模板：固定本层 `size`，内层弹 `size` 个
2. 内层循环 `i == size - 1` 时，当前节点即本层最右，收入结果

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(n)\\)（队列最宽一层）

### 解法二：DFS「根右左」首次到达即最右（推荐）

1. 递归顺序：先访问 `node.right`，再访问 `node.left`
2. `depth == res.size()` 说明**首次到达该层**——因为是先右后左，首个到达的一定是本层最右节点

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(h)\\) 递归栈（不计结果）

## 代码

### 解法一：BFS 逐层取最后一个

```java
public List<Integer> rightSideView(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();               // 固定本层节点数
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (i == size - 1) {               // 本层最后一个 = 右侧看到的
                res.add(node.val);
            }
            if (node.left  != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
    }
    return res;
}
```

### 解法二：DFS「根右左」首次到达即最右（推荐）

```java
public List<Integer> rightSideView(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    dfs(root, 0, res);
    return res;
}

// 「根 → 右 → 左」遍历，每层第一个被访问到的就是最右节点
private void dfs(TreeNode node, int depth, List<Integer> res) {
    if (node == null) return;
    if (depth == res.size()) {                 // 首次到达该层
        res.add(node.val);
    }
    dfs(node.right, depth + 1, res);           // 先右，顺序不能反
    dfs(node.left,  depth + 1, res);
}
```

## 个人总结

### 1. 本质是"每层最后一个"，不是"右侧链"

最想当然的错误：从根沿 `right` 指针一路走到底。反例 `[1,2,3,4]`（4 是 2 的左孩子）：

```
      1
     / \          沿 right 走：1 → 3，漏掉 4
    2   3         正确右视图：[1, 3, 4]
   /
  4               ← 4 在左子树，但它是第 3 层最右节点
```

第 3 层没有任何右子树节点，最右的是左子树里的 4。凡是"每层最值"类问题，都得逐层找，不能走单链。

### 2. DFS 版两个关键点

- **先右后左**：顺序反了就变成"左视图"，一行之差结果完全镜像
- **depth == res.size() 判首次到达**：因为先右后左，首个触达某层的必然是该层最右节点；该层其余节点（从左边来的）`depth < res.size()` 直接跳过

### 3. BFS 版取 i == size - 1

和 102 的区别只在一行：内层循环最后一步多一个下标判断。层序模板的复利就在这种题上体现——骨架 90% 相同，改的是"层内收集什么"。

### 4. 关联变体

左视图（取每层第一个 / DFS 先左后右）、每层最大值（515）、每层平均值（637）：全部共用 102 的逐层骨架。遇到"每层 XXX"先想 BFS 固定 size，再想 DFS 首次到达，两个都写熟。
