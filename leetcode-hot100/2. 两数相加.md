# 2. 两数相加

> **难度**：🟡 中等 | **标签**：链表、数学、模拟 | **企业**：—

## 题目描述

给你两个 **非空** 的链表，表示两个非负的整数。它们每位数字都是按照 **逆序** 的方式存储的，并且每个节点只能存储 **一位** 数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

## 示例

**示例 1**

```
输入：l1 = [2,4,3], l2 = [5,6,4]
输出：[7,0,8]
解释：342 + 465 = 807
```

**示例 2**

```
输入：l1 = [0], l2 = [0]
输出：[0]
```

**示例 3**

```
输入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
输出：[8,9,9,9,0,0,0,1]
解释：9999999 + 9999 = 10009998
```

---

## 提示

- 每个链表中的节点数在范围 `[1, 100]` 内
- `0 <= Node.val <= 9`
- 题目数据保证列表表示的数字不含前导零（数字 0 本身除外）

---

## 思路

### 核心思想：竖式加法（逐位相加 + 进位）

链表是**逆序存储**，头节点正好是个位——天然就是「从低位往高位加」，和手算竖式完全一致：逐位相加，超过 9 就往前进位。

```
  2 → 4 → 3        (342)
+ 5 → 6 → 4        (465)
─────────
  7 → 0 → 8        (807)   ← 中间一位 4+6=10，记 0 进 1
```

### 解法一：迭代 + dummy 节点（推荐）

1. `dummy` 哑节点 + `cur` 指针串联结果链表
2. `carry` 记录进位，初始为 0
3. `while (l1 != null || l2 != null)` 循环——**其中一个为空时用 0 补位**
4. 每位 `sum = v1 + v2 + carry`，新节点值 `sum % 10`，进位 `sum / 10`
5. 循环结束后若 `carry == 1`，再补一个值为 1 的节点
6. 返回 `dummy.next`

- 时间复杂度：\(O(\max(m, n))\)，空间复杂度：\(O(1)\)（不含结果链表的空间）

### 解法二：递归

1. 递归定义：`add(l1, l2, carry)` = 当前位节点 + `add(l1.next, l2.next, 新carry)`
2. 基准情况：两链表都空时，若 `carry == 1` 返回单节点 `[1]`，否则返回 `null`
3. 代码简洁，但递归深度可达 100+（题目节点数上限 100，无栈溢出风险）

- 时间复杂度：\(O(\max(m, n))\)，空间复杂度：\(O(\max(m, n))\)（递归栈）

> ⚠️ 常见误区：**别把链表转成 int/long 再相加**——节点数最多 100，数值远超 64 位范围，必然溢出。

### 解法一：迭代 + 补位（修正版）

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode cur = dummy;
        int carry = 0;

        while (l1 != null || l2 != null) {
            int x = (l1 != null) ? l1.val : 0;   // 空链表用 0 补位
            int y = (l2 != null) ? l2.val : 0;
            int sum = x + y + carry;

            cur.next = new ListNode(sum % 10);   // 当前位
            carry = sum / 10;                    // 进位
            cur = cur.next;

            if (l1 != null) l1 = l1.next;        // 非空才移动，避免 NPE
            if (l2 != null) l2 = l2.next;
        }
        if (carry == 1) cur.next = new ListNode(1);   // 最高位进位
        return dummy.next;
    }
}
```

### 解法二：递归

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        return add(l1, l2, 0);
    }

    private ListNode add(ListNode l1, ListNode l2, int carry) {
        if (l1 == null && l2 == null) {
            return carry == 1 ? new ListNode(1) : null;   // 最后进位
        }
        int x = (l1 != null) ? l1.val : 0;
        int y = (l2 != null) ? l2.val : 0;
        int sum = x + y + carry;

        ListNode node = new ListNode(sum % 10);
        node.next = add((l1 != null) ? l1.next : null,
                        (l2 != null) ? l2.next : null,
                        sum / 10);
        return node;
    }
}
```

## 个人总结

### 1. 代码是对的——复盘点是「结构冗余」而非 bug

三个官方用例全过：主循环（同长部分）+ 余数循环（l1/l2 更长）+ 尾进位，分工逻辑完整，`marry > 0` 的最高位进位也没漏。

真正值得改的不是正确性，而是**同一份「加一位」的逻辑写了三遍**——主循环、l1 余数、l2 余数各一份。以后要加个边界判断（比如某位 >= 10 特殊处理），就得同时改三处，极易漏改。

### 2. 标准写法：`||` + 三元补 0，三循环合并成一个

```java
// ❌ 我的写法：&& 主循环 + 2 个余数循环，约 25 行
while (l1 != null && l2 != null) { ... }
while (l1 != null) { ... }
while (l2 != null) { ... }

// ✅ 0 补位写法：一个循环覆盖所有情况，约 12 行
while (l1 != null || l2 != null) {
    int x = (l1 != null) ? l1.val : 0;   // 空链表用 0 补位
    int y = (l2 != null) ? l2.val : 0;
    int sum = x + y + carry;
    resultCur.next = new ListNode(sum % 10);
    carry = sum / 10;
    resultCur = resultCur.next;
    if (l1 != null) l1 = l1.next;        // 非空才移动，避免 NPE
    if (l2 != null) l2 = l2.next;
}
if (carry == 1) resultCur.next = new ListNode(1);
```

「链表不同长」是这类题的通用场景，`||` + 补 0 是标准模式，三份逻辑合并成一份。

### 3. 细节：marry 笔误 + 空链表死代码

- `int marry = 0` —— 编译运行都没问题，但「进位」标准命名是 `carry`。OJ 不在乎，**面试手写代码时变量名会暴露英文功底**，建议统一。
- `if (l1 == null) return l2;` —— 题目约束「链表非空」，这两段是**死代码**，永远不会触发。留着无害，但要意识到它是防御性的，不是算法的一部分。

### 4. 最危险的思路：转成整数再相加

看到「两个数相加」第一反应可能是 `Integer.parseInt(链表转字符串)` —— 节点数 ≤ 100，数值远超 `long`（64 位）范围，**必然溢出**。竖式逐位加才是正解，这也正是题目把数字**逆序**存储的原因：头节点即个位，天然支持从低位往高位模拟进位。
