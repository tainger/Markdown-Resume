# 20. 有效的括号

> **难度**：🟢 简单 | **标签**：栈、字符串 | **企业**：—

## 题目描述

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合（即后进先出，最内层的括号必须先闭合，才能闭合外层）。
3. 每个右括号都有一个对应的相同类型的左括号。

> ⚠️ 原题描述对「正确顺序」定义模糊，真正的含义通过示例 4 `([])` ✓ 和示例 5 `([)]` ✗ 的对比才明确：**后进先出**。

---

## 示例

**示例 1**

```
输入：s = "()"
输出：true
```

**示例 2**

```
输入：s = "()[]{}"
输出：true
```

**示例 3**

```
输入：s = "(]"
输出：false
```

**示例 4**

```
输入：s = "([])"
输出：true
```

**示例 5**

```
输入：s = "([)]"
输出：false
```

---

## 提示

- `1 <= s.length <= 10^4`
- `s` 仅由括号 `'()[]{}'` 组成

---

## 思路

**栈** 是处理括号匹配的标准解法：

1. 遍历字符串，遇到左括号则**入栈**
2. 遇到右括号则**弹栈**，检查是否与栈顶的左括号匹配
3. 最终栈为空则有效，否则无效

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(n)\)

    public boolean isValid(String s) {
        Stack<Integer> stack = new Stack<>();   // ❌ 应为 Character

        for (int i = 0; i < s.length(); i++) {

                if (c == '}' && top != '{') return false;
                if (c == ']' && top != '[') return false;

### 解法一：常规弹栈比对（修正版）

```java
class Solution {
    public boolean isValid(String s) {
        Stack<Character> stack = new Stack<>();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(' || c == '{' || c == '[') {
                stack.push(c);
            } else {
                if (stack.isEmpty()) return false;  // 栈空来了右括号，直接无效
                char top = stack.pop();
                if (c == ')' && top != '(') return false;
                if (c == '}' && top != '{') return false;
                if (c == ']' && top != '[') return false;
            }
        }
        return stack.isEmpty();  // 栈必须为空才算有效
    }
}
```

### 解法二：压入对应右括号（更简洁）

```java
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') {
            stack.push(')');
        } else if (c == '{') {
            stack.push('}');
        } else if (c == '[') {
            stack.push(']');
        } else if (stack.isEmpty() || stack.pop() != c) {
            return false;
        }
    }
    return stack.isEmpty();
}
```

## 个人总结

### 1. 泛型类型要用包装类

`Stack<Character>` 不能用 `Stack<Integer>`，虽然 char 可以隐式转 int，但语义不对且容易埋坑。

### 2. pop 前必须先判空

```java
// ❌ 输入 ")" 或 "]" 时，栈为空，直接抛 EmptyStackException
char top = stack.pop();

// ✅ 先判空
if (stack.isEmpty()) return false;
char top = stack.pop();
```

### 3. 结尾必须检查栈是否清空

```java
// ❌ 输入 "(" → 遍历结束后栈里还剩 '('，却返回 true
return true;

// ✅
return stack.isEmpty();
```

### 4. Deque 替代 Stack

`Stack` 是遗留类（继承 Vector，同步开销大），推荐用 `Deque<Character> stack = new ArrayDeque<>()`。
