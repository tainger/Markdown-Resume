# 206. 反转链表

> **难度**：🟢 简单 | **标签**：递归、链表 | **企业**：—

## 题目描述

给你单链表的头节点 `head` ，请你反转链表，并返回反转后的链表。

## 示例

**示例 1**

```
输入：head = [1,2,3,4,5]
输出：[5,4,3,2,1]

反转前:  1 → 2 → 3 → 4 → 5 → null
反转后:  5 → 4 → 3 → 2 → 1 → null
```

**示例 2**

```
输入：head = [1,2]
输出：[2,1]
```

**示例 3**

```
输入：head = []
输出：[]
```

---

## 提示

- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

---

## 进阶

链表可以选用**迭代**或**递归**方式完成反转。你能否用两种方法解决这道题？

---

## 思路

### 核心思想

反转链表 = 把每个节点的 `next` 指针指向前一个节点。需要三个指针协作：

```
before:  ① → ② → ③ → null
 after:  null ← ① ← ② ← ③

关键操作（原地反转）：
  next = curr.next   // 先存下一个，防止断链
  curr.next = prev   // 反转指针方向
  prev = curr        // prev 前进
  curr = next        // curr 前进
```

### 解法一：迭代（必会）

```
初始化:  prev = null, curr = head

每次循环做三步：
  ① 暂存: next = curr.next   （不存就丢了）
  ② 反转: curr.next = prev   （核心）
  ③ 前进: prev = curr; curr = next

curr == null 时结束，prev 就是新头节点
```

**逐步演示**：

```
初始化               prev=null, curr=1

Step 1:  next=2    1→null   prev=1, curr=2
Step 2:  next=3    2→1      prev=2, curr=3
Step 3:  next=4    3→2      prev=3, curr=4
Step 4:  next=5    4→3      prev=4, curr=5
Step 5:  next=null 5→4      prev=5, curr=null → 结束

返回 prev = 5 → 4 → 3 → 2 → 1 → null ✓
```

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(1)\\)

### 解法二：递归

递归到最后一个节点作为新头，回溯时逐层反转：

```
head.next.next = head   // 让下一个节点指向自己
head.next = null        // 断开原来的 next
```

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(n)\\)（递归栈）

> ⚠️ 面试首选迭代写法，递归主要用于展示你理解递归回溯的执行顺序。

### 解法一：迭代（推荐）

```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;

    while (curr != null) {
        ListNode next = curr.next;  // ① 暂存下一个节点
        curr.next = prev;           // ② 反转指针
        prev = curr;                // ③ prev 前进
        curr = next;                // ④ curr 前进
    }
    return prev;  // 新头节点
}
```

### 解法二：递归

```java
public ListNode reverseList(ListNode head) {
    // 终止条件：空链表或只剩一个节点
    if (head == null || head.next == null) return head;

    ListNode newHead = reverseList(head.next);  // 递归反转后续链表
    head.next.next = head;  // 让下一个节点指向自己
    head.next = null;       // 断开当前节点的 next（防环）

    return newHead;  // newHead 始终是原链表的尾节点
}
```
