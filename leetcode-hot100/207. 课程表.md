## 题目描述

你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1` 。

在选修某些课程之前需要一些先修课程。先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [ai, bi]` ，表示如果要学习课程 `ai` 则 **必须** 先学习课程 `bi` 。

- 例如，先修课程对 `[0, 1]` 表示：想要学习课程 `0` ，你需要先完成课程 `1` 。

请你判断是否可能完成所有课程的学习？如果可以，返回 `true` ；否则，返回 `false` 。

---

## 示例

**示例 1**

```
输入：numCourses = 2, prerequisites = [[1,0]]
输出：true
解释：总共有 2 门课程。学习课程 1 之前，你需要完成课程 0 。这是可能的。
```

**示例 2**

```
输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false
解释：总共有 2 门课程。学习课程 1 之前，你需要先完成课程 0 ；并且学习课程 0 之前，你还应先完成课程 1 。这是不可能的。
```

## 思路

### 核心：把课程依赖建成有向图，问题 = 判断图中是否有环

把每门课看成**节点**，先修关系 `[a, b]`（学 a 前要先学 b）看成一条**有向边 `b → a`**（先修 b 指向后修 a）。

- 若图中**无环** → 存在合法学习顺序（拓扑序）→ 返回 `true`；
- 若图中**有环**（如 `0→1→0`）→ 互相依赖，永远学不完 → 返回 `false`。

**「能否完成所有课程」= 有向图是否为 DAG（无环）**，这是拓扑排序的经典应用。

### 解法一：BFS 拓扑排序（Kahn 算法，入度法，推荐）

不断「移除没有前置依赖的课」，能全部移除就无环：

1. 建**邻接表** + 统计每个节点的**入度**（有多少门先修课指向它）；
2. 所有**入度为 0**的课入队（没有前置依赖，可直接学）；
3. 每次出队一门课 `u`，把它「学完」，将它指向的邻居 `v` 入度 `-1`；若某邻居入度减到 0，说明它的先修全部学完，入队；
4. 统计出队的课程总数，若 `== numCourses` → 全部可修完（无环）；否则有环剩了一部分。

- 时间复杂度：\(O(V + E)\)，每个点/边各处理一次
- 空间复杂度：\(O(V + E)\) 邻接表 + 队列

> 直觉：环上的节点入度永远减不到 0（互相指），进不了队，最终出队数会 `< numCourses`。

### 解法二：DFS 判环（三色标记）

对每个节点 DFS，用三种状态标记检测「回边」：

- `0` 未访问；`1` 访问中（在当前 DFS 递归栈里）；`2` 已完成（子树全部安全）。
- DFS 到某节点时标 `1`，递归其邻居：若遇到状态为 `1` 的邻居 → **碰到正在访问的祖先，成环**，返回有环；遇到 `2` 的可跳过；递归完标 `2`。

- 时间复杂度：\(O(V + E)\)
- 空间复杂度：\(O(V + E)\) + 递归栈

## 代码

### 解法一：BFS 拓扑排序（入度法，推荐）

```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 建邻接表 + 入度数组
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
        int[] indegree = new int[numCourses];
        for (int[] p : prerequisites) {
            graph.get(p[1]).add(p[0]);      // 先修 p[1] → 后修 p[0]
            indegree[p[0]]++;               // p[0] 的入度 +1
        }

        // 入度为 0 的课先入队（无前置依赖）
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if (indegree[i] == 0) queue.offer(i);
        }

        int finished = 0;                   // 已学完的课程数
        while (!queue.isEmpty()) {
            int u = queue.poll();
            finished++;
            for (int v : graph.get(u)) {    // 学完 u，解锁它指向的课
                if (--indegree[v] == 0) queue.offer(v);
            }
        }
        return finished == numCourses;      // 全部学完 = 无环
    }
}
```

### 解法二：DFS 判环（三色标记）

```java
class Solution {
    private List<List<Integer>> graph;
    private int[] state;    // 0 未访问, 1 访问中, 2 已完成

    public boolean canFinish(int numCourses, int[][] prerequisites) {
        graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
        for (int[] p : prerequisites) graph.get(p[1]).add(p[0]);
        state = new int[numCourses];

        for (int i = 0; i < numCourses; i++) {
            if (state[i] == 0 && hasCycle(i)) return false;  // 有环 → 修不完
        }
        return true;
    }

    // 返回从 u 出发是否存在环
    private boolean hasCycle(int u) {
        state[u] = 1;                       // 标记为「访问中」
        for (int v : graph.get(u)) {
            if (state[v] == 1) return true;         // 遇到访问中的祖先 → 成环
            if (state[v] == 0 && hasCycle(v)) return true;
        }
        state[u] = 2;                       // 子树全部安全，标记完成
        return false;
    }
}
```

## 个人总结

### 1. 题眼：依赖关系 + 能否全部完成 → 拓扑排序判环

看到「A 依赖 B」「能否排出合法顺序 / 全部完成」这类描述，立刻建**有向图**，问题归结为**是否有环**（无环即可拓扑排序）。这是拓扑排序最经典的信号。[210. 课程表 II](210.%20课程表%20II.md) 只是把「能否」换成「输出一个合法顺序」。

### 2. 建边方向别搞反

`prerequisites[i] = [a, b]` 表示「学 a 前先学 b」，边应从**先修指向后修**：`b → a`。方向反了入度统计全错。记法：**箭头指向「后学的」，入度是「还欠多少先修课」**。

### 3. BFS 入度法：出队数是否等于总数

Kahn 算法的判环技巧——**统计能出队的节点数**。无环时所有节点都能因入度归零而出队，`finished == numCourses`；有环时环上节点入度永远 `>0`、进不了队，`finished < numCourses`。不需要额外显式找环。

### 4. DFS 三色标记：区分「访问中」和「已完成」

只用「访问过 / 没访问过」两态**无法判环**——遇到已访问的节点，它可能是当前递归栈上的祖先（成环），也可能是另一条已安全走完的分支（不成环）。必须用第三态 `2` 区分：**只有遇到状态 `1`（正在访问、在当前栈中）才是环**。这是有向图判环和无向图的关键区别。

### 5. 两种解法怎么选

| | BFS（入度法） | DFS（三色） |
|:---|:---|:---|
| 思路 | 逐步移除无依赖节点 | 沿依赖深入找回边 |
| 判环 | 出队数 `< n` | 遇到「访问中」节点 |
| 顺带产出 | 拓扑序（出队顺序） | 逆拓扑序（完成顺序反转） |
| 栈溢出风险 | 无（迭代） | 深图可能爆栈 |

面试推荐 **BFS 入度法**：直观、无递归爆栈风险、天然产出拓扑序。
