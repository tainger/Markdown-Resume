# 21. 合并两个有序链表

> **难度**：🟢 简单 | **标签**：链表、递归、双指针 | **企业**：—

## 题目描述

将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

## 示例

**示例 1**

```
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

**示例 2**

```
输入：l1 = [], l2 = []
输出：[]
```

**示例 3**

```
输入：l1 = [], l2 = [0]
输出：[0]
```

---

## 提示

- 两个链表的节点数目范围是 `[0, 50]`
- `-100 <= Node.val <= 100`
- `l1` 和 `l2` 均按 **非递减顺序** 排列

---

## 思路

### 核心思想：双指针归并

两个链表已经有序，类似归并排序的 merge 阶段：每次取两个链表头部中较小的节点，接到结果链表末尾。

```
l1: 1 → 2 → 4
l2: 1 → 3 → 4
        ↓ 每次比较头部，取较小者
res: 1 → 1 → 2 → 3 → 4 → 4
```

### 解法一：迭代（推荐）

1. 创建 **哑节点（dummy）**，简化头节点的特殊处理
2. `curr` 指针指向当前结果链表的尾部
3. 循环比较 `l1.val` 和 `l2.val`，`curr.next` 指向较小者，移动对应指针
4. 任一链表走完后，把剩余部分直接接上
5. 返回 `dummy.next`

- 时间复杂度：\(O(n + m)\)，空间复杂度：\(O(1)\)

### 解法二：递归

1. 递归定义：`merge(l1, l2)` = 较小节点 + `merge(剩余, l2)`
2. 基准情况：任一链表为空，直接返回另一条
3. 代码极简但递归深度 = 链表长度

- 时间复杂度：\(O(n + m)\)，空间复杂度：\(O(n + m)\)（递归栈）

> ⚠️ 虽然题目限制节点数 ≤ 50，递归没问题，但面试中推荐先说迭代，再提递归作为加分项。

## 代码

### 我的伪代码

> 👇 初次尝试的错误版本（保留用于复盘），具体问题见下方 [个人总结](#个人总结)。

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        // ❌ 空链表处理 OK，但后面缺第三个指针建结果链
        if (list1 == null) {
            return list2;
        }
        if (list2 == null) {
            return list1;
        }
        // ❌ 只有 list1/list2 两个输入指针，缺 curr + dummy
        while (list1 != null && list2 != null) {
            if (list1.val <= list2.val)   // ❌ 循环体空，比完不知道往哪接
        }
        // ❌ 缺 return
    }
}
```

### 解法一：迭代（dummy 节点）

```java
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(-1);
    ListNode curr = dummy;

    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {
            curr.next = l1;
            l1 = l1.next;
        } else {
            curr.next = l2;
            l2 = l2.next;
        }
        curr = curr.next;
    }
    // 剩余部分直接拼接
    curr.next = (l1 != null) ? l1 : l2;
    return dummy.next;
}
```

### 解法二：递归

```java
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    if (l1 == null) return l2;
    if (l2 == null) return l1;

    if (l1.val <= l2.val) {
        l1.next = mergeTwoLists(l1.next, l2);
        return l1;
    } else {
        l2.next = mergeTwoLists(l1, l2.next);
        return l2;
    }
}
```

## 个人总结

### 1. 双指针 ≠ 两个指针就够了

误以为 `list1` 和 `list2` 就是「双指针」，实际还需要 **第三个指针 `curr`** 来串联结果链表。

```
list1 → 1 → 2 → 4     ← 输入指针：从头部逐个取节点
list2 → 1 → 3 → 4     ← 输入指针：从头部逐个取节点
curr  → 结果链尾部     ← 输出指针：负责把取到的节点串起来
```

**双指针指的是输入侧的两个遍历指针，输出侧还需要 `dummy + curr`。**

### 2. while 循环里不能只比较不操作

```java
// ❌ 只会比大小，不知道结果往哪放
while (list1 != null && list2 != null) {
    if (list1.val <= list2.val)
}

// ✅ 比完要立刻接到 curr 后面，并移动对应指针
while (list1 != null && list2 != null) {
    if (list1.val <= list2.val) {
        curr.next = list1;
        list1 = list1.next;
    } else {
        curr.next = list2;
        list2 = list2.next;
    }
    curr = curr.next;
}
```

### 3. dummy 节点的作用

dummy 节点的本质是**占位**，避免处理「结果链表第一个节点从哪来」的边界情况。最后 `return dummy.next` 跳过它即可。
