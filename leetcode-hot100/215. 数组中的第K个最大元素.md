## 题目描述

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

---

## 示例

**示例 1**

```
输入：[3,2,1,5,6,4], k = 2
输出：5
```

**示例 2**

```
输入：[3,2,3,1,2,4,5,5,6], k = 4
输出：4
```

## 提示

- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 思路

### 核心思想

第 `k` 大 = 数组**升序排序后下标为 `n-k`** 的元素。三条路线：

- **排序**：最直观，`O(n log n)`，但没满足题目「O(n)」的要求。
- **小顶堆维护 K 个**：只保留最大的 K 个数，堆顶就是第 K 大，`O(n log k)`。
- **快速选择（Quick Select）**：借快排的 `partition`，每次只递归一侧，均摊 `O(n)`——满足题目要求，最优。

### 解法一：排序（先跑通）

排完序取倒数第 `k` 个，即 `nums[n-k]`。

- 时间复杂度：\(O(n\log n)\)，空间复杂度：\(O(\log n)\)（排序栈）。没满足 O(n) 要求，作起点。

### 解法二：小顶堆维护 K 个最大元素

维护一个大小为 `k` 的**小顶堆**：遍历数组，堆不满就入堆；满了就和堆顶比，比堆顶大才替换。遍历完，堆里是最大的 K 个，**堆顶即第 K 大**。

- 为什么用**小**顶堆求第 K **大**：堆顶是这 K 个里最小的，只要新元素比它大就能"挤掉"最小的，最终留下的就是 Top-K，堆顶恰是第 K 大。
- 时间复杂度：\(O(n\log k)\)，空间复杂度：\(O(k)\)。适合**数据流 / n 极大 k 较小**的场景。

### 解法三：快速选择（推荐，均摊 O(n)）

借用快排的 `partition`：选一个基准 `pivot`，一趟把数组分成「≤pivot」和「>pivot」两部分，`pivot` 落到它最终排序后的正确位置 `p`。

- 目标位置是 `target = n - k`（第 K 大在升序下的下标）。
- 若 `p == target`：`nums[p]` 就是答案；
- 若 `p < target`：答案在右半，只递归右边；
- 若 `p > target`：答案在左半，只递归左边。

**每次只递归一侧**（快排要递归两侧），均摊复杂度从 `O(n log n)` 降到 `O(n)`。

```
[3,2,1,5,6,4], k=2 → target = 6-2 = 4（升序下标4）
一次 partition 后 pivot 归位到某个 p：
  p==4 → 命中；p<4 → 找右半；p>4 → 找左半
最终 nums[4] = 5
```

- 时间复杂度：**均摊** \(O(n)\)，最坏 \(O(n^2)\)（用**随机化基准**避免有序数据退化）。空间 \(O(\log n)\)。

## 代码

### 解法一：排序（先跑通）

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        Arrays.sort(nums);                     // 升序
        return nums[nums.length - k];          // 倒数第 k 个 = 第 k 大
    }
}
```

### 解法二：小顶堆维护 K 个

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        PriorityQueue<Integer> heap = new PriorityQueue<>();  // 默认小顶堆
        for (int x : nums) {
            heap.offer(x);
            if (heap.size() > k) {
                heap.poll();                   // 堆超过 k 个，弹出最小的
            }
        }
        return heap.peek();                    // 堆顶即第 k 大
    }
}
```

### 解法三：快速选择（推荐，均摊 O(n)）

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        int n = nums.length;
        return quickSelect(nums, 0, n - 1, n - k);  // 目标：升序下标 n-k
    }

    private int quickSelect(int[] nums, int lo, int hi, int target) {
        int p = partition(nums, lo, hi);       // pivot 归位后的下标
        if (p == target) {
            return nums[p];
        } else if (p < target) {
            return quickSelect(nums, p + 1, hi, target);   // 只递归右半
        } else {
            return quickSelect(nums, lo, p - 1, target);   // 只递归左半
        }
    }

    // 随机化基准 + 一趟划分，返回 pivot 最终位置
    private int partition(int[] nums, int lo, int hi) {
        int rand = lo + (int) (Math.random() * (hi - lo + 1));
        swap(nums, rand, hi);                  // 随机基准换到末尾，防有序退化
        int pivot = nums[hi], i = lo;
        for (int j = lo; j < hi; j++) {
            if (nums[j] < pivot) {             // 小于基准的都挪到左边
                swap(nums, i++, j);
            }
        }
        swap(nums, i, hi);                     // 基准归位
        return i;
    }

    private void swap(int[] nums, int a, int b) {
        int t = nums[a]; nums[a] = nums[b]; nums[b] = t;
    }
}
```

## 个人总结

### 1. 「第 K 大」= 升序下标 n-k，别记反

第 K 大在**升序**数组里的下标是 `n - k`（第 1 大是 `n-1`，第 n 大是 `0`）。快速选择的 `target`、排序解法的取值都靠它，写反就全错。若按降序思考则是下标 `k-1`，两套别混。

### 2. 求第 K 大用「小」顶堆，而不是大顶堆

反直觉但关键：维护大小为 `k` 的**小顶堆**，堆顶是这 K 个中最小的。新元素只要 > 堆顶就替换，最终堆里留下最大的 K 个，堆顶正好是第 K 大。若用大顶堆存全部再弹 k 次是 `O(n + k log n)`，不如小顶堆省空间（`O(k)`），也更适合数据流。

### 3. 快速选择的精髓：只递归一侧

快排要递归**两侧**（`O(n log n)`）；快速选择每次 partition 后，根据 pivot 位置 `p` 和 `target` 的关系**只走一侧**，均摊 `T(n)=T(n/2)+O(n)=O(n)`。这是它比排序快的根本原因。

### 4. 必须随机化基准，否则退化 O(n²)

若固定取末尾/首元素为基准，遇到**已排序数组**会每次只划掉一个元素，退化成 `O(n²)`。加一句「随机选基准换到末尾」即可把最坏情况变成极小概率，是快速选择的标配。

### 5. 三种解法取舍

| 解法 | 时间 | 空间 | 适用场景 |
|:---|:---:|:---:|:---|
| 排序 | \(O(n\log n)\) | \(O(\log n)\) | 最简单，不满足 O(n) 要求 |
| 小顶堆 | \(O(n\log k)\) | \(O(k)\) | 数据流 / n 极大 k 小 |
| 快速选择 | \(O(n)\) 均摊 | \(O(\log n)\) | 一次性求第 K 大，最优 |

**面试建议**：先说排序（会做），再讲小顶堆（Top-K 通用），最后亮快速选择（满足 O(n)，并主动提随机化避免退化）——层层递进最出彩。
