# 22. 括号生成

> **难度**：🟡 中等 | **标签**：字符串、动态规划、回溯 | **企业**：—

## 题目描述

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的** 括号组合。

## 示例

**示例 1**

```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

**示例 2**

```
输入：n = 1
输出：["()"]
```

---

## 提示

- `1 <= n <= 8`

---

## 思路

### 核心思想：回溯 + 两条铁律

生成过程就是在 **2n 个空位** 上决定填 `(` 还是 `)`，但有两个硬性约束：

1. **左括号还剩 > 0 才能放 `(`**；
2. **右括号不能比左括号多**（剩余 `)` > 剩余 `(` 才能放 `)`）——否则出现 `)(` 这种无法闭合的非法串。

回溯时用「剩余数量」或「已放数量」记录状态，每次尝试后**撤销**，穷举所有合法路径。

```
n = 2 的决策树（剪掉非法分支后）：

        ""
      /    \
    (        ✗ 右括号不能比左括号多
   /  \
 (     )          ← 这里右 > 左 才允许放 )
 |     |
(())   ()  
        |
       ( )        → ()()
```

### 解法一：回溯（推荐）

1. 参数：剩余左括号 `left`、剩余右括号 `right`，以及正在拼接的字符串/`StringBuilder`
2. 终止：`left == 0 && right == 0` → 加入结果
3. 分支 1：`left > 0` 时放 `(`
4. 分支 2：`right > left` 时放 `)`（剪枝铁律 ②）
5. 用 `StringBuilder` 时必须**撤销** `deleteCharAt`；用 `String` 拼接则天然不可变，无需撤销但每次递归都新建对象

- 时间复杂度：\(O(\frac{4^n}{\sqrt{n}})\)（卡特兰数级别的节点数），空间复杂度：\(O(n)\)（递归深度 + StringBuilder）

### 解法二：暴力生成 + 合法性校验

1. 生成全部 \(2^{2n}\) 种括号串（每个位置 `(` 或 `)`）
2. 逐个校验：扫描时左括号计数恒 ≥ 0，且最终为 0

- 时间复杂度：\(O(2^{2n} \cdot n)\)，空间复杂度：\(O(n)\)
- `n ≤ 8` 时 \(2^{16} = 65536\) 种，其实也能跑完——但回溯剪枝是面试正解

> 💡 扩展：还有「按序列长度递归」的 DP 解法：`"(" + A + ")" + B`，其中 A、B 分别是 k 和 n-1-k 对括号的合法组合（k 从 0 到 n-1）。答案数量是**卡特兰数** \(\frac{1}{n+1}\binom{2n}{n}\)。

## 代码

### 我的伪代码

> 👇 初次尝试的错误版本（保留用于复盘），具体问题见下方 [个人总结](#个人总结)。

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> res = new ArrayList<>();
        StringBuilder sb = new StringBuilder();
        dfs(res, sb, n, n);
        return res;
    }

    private void dfs(List<String> res, StringBuilder sb, int left, int right) {
        if (left == 0 && right == 0) {
            res.add(sb.toString());
            return;
        }
        if (left > 0) {
            sb.append('(');
            dfs(res, sb, left - 1, right);
            // ❌ ① 忘了撤销：StringBuilder 是可变的，不删掉刚加的 '('，
            //    回到本层后继续放 ')' 时，字符串已经被污染
        }
        if (right > 0) {
            // ❌ ② 缺剪枝：right 只剩 1 个而 left 也为 1 时放 ')'，
            //    会生成 ")(..." 这类无法闭合的非法串
            sb.append(')');
            dfs(res, sb, left, right - 1);
            // 同 ①，也没撤销
        }
    }
}
```

> 这个版本跑 `n = 1` 会输出 `[")(", ")("]`——非法串 + 重复，两个 bug 同时爆发。

### 解法一：回溯 + 剪枝（修正版）

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> res = new ArrayList<>();
        dfs(res, new StringBuilder(), n, n);
        return res;
    }

    private void dfs(List<String> res, StringBuilder sb, int left, int right) {
        if (left == 0 && right == 0) {
            res.add(sb.toString());
            return;
        }
        if (left > 0) {                          // 铁律①：还有左括号才放 '('
            sb.append('(');
            dfs(res, sb, left - 1, right);
            sb.deleteCharAt(sb.length() - 1);    // ✅ 撤销
        }
        if (right > left) {                      // 铁律②：剩余右括号 > 剩余左括号才能放 ')'
            sb.append(')');
            dfs(res, sb, left, right - 1);
            sb.deleteCharAt(sb.length() - 1);    // ✅ 撤销
        }
    }
}
```

### 解法二：暴力生成 + 校验

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> res = new ArrayList<>();
        generateAll(new char[2 * n], 0, res);
        return res;
    }

    private void generateAll(char[] cur, int pos, List<String> res) {
        if (pos == cur.length) {
            if (isValid(cur)) res.add(new String(cur));
            return;
        }
        cur[pos] = '(';
        generateAll(cur, pos + 1, res);
        cur[pos] = ')';
        generateAll(cur, pos + 1, res);
    }

    private boolean isValid(char[] cur) {
        int balance = 0;
        for (char c : cur) {
            if (c == '(') balance++;
            else balance--;
            if (balance < 0) return false;       // 任意前缀右括号不能多于左括号
        }
        return balance == 0;
    }
}
```

> 💡 记忆：**回溯三件套 = 选（尝试）→ 递（递归）→ 撤（撤销）**；括号题多一个「右不能超左」的剪枝。`String` 拼接版不用撤销，但 `StringBuilder` 版必须 `deleteCharAt`。

## 个人总结

### 1. StringBuilder 版忘撤销 → 字符串污染

`StringBuilder` 是**可变**的，递归返回后刚加的字符还在。两个分支共享同一个 sb，不删就会叠加出 `")("` 这种怪串。

```java
sb.append('(');
dfs(res, sb, left - 1, right);
sb.deleteCharAt(sb.length() - 1);   // ✅ 递归返回后立刻撤销
```

如果嫌麻烦，可以改用 `String cur` 递归（`cur + "("` 每次新建），代码更短但每层都要复制字符串，牺牲一点效率换可读性——**面试手写用 String 版更不容易错**。

### 2. 剪枝条件：剩余 `)` 必须多于剩余 `(`

`left`、`right` 是「剩余数量」。放 `)` 的前提是**还有没闭合的左括号**，即 `right > left`：

```
n=1 时：
"(" 之后 left=0, right=1 → 1 > 0 ✅ 放 ')' → "()" 合法
"" 根节点        left=1, right=1 → 1 > 1 ❌ 不放 ')' → 不会生成 ")(...)"
```

等价写法：`已放左 > 已放右` 时才能放 `)`。**两个计数器版本（剩余/已放）二选一，别混用。**

### 3. 输出数量是卡特兰数，可用于自检

`n=3` 答案是 5 个，`n=4` 是 14 个，`n=5` 是 42 个。写完代码拿 `n=3` 对个数（5 个），比逐串比对更快暴露「漏分支」或「重复」。

### 4. 和 46 全排列、77 组合的关联

括号生成本质是**带约束的排列**：2n 个位置里选 n 个放 `(`（`C(2n,n)`），但要求任意前缀 `(` ≥ `)`（卡特兰数）。回溯模板一模一样——选/递/撤三件套，区别只在剪枝条件不同。
