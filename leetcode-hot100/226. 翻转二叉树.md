# 226. 翻转二叉树

> **难度**：🟢 简单 | **标签**：树、深度优先搜索、广度优先搜索、二叉树 | **企业**：—

## 题目描述

给你一棵二叉树的根节点 `root` ，翻转这棵二叉树，并返回其根节点。

翻转二叉树 = 每个节点的左右子树互换位置。

## 示例

**示例 1**

```
输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]

翻转前:         翻转后:
     4              4
   /   \          /   \
  2     7   →    7     2
 / \   / \      / \   / \
1   3 6   9    9   6 3   1
```

**示例 2**

```
输入：root = [2,1,3]
输出：[2,3,1]
```

**示例 3**

```
输入：root = []
输出：[]
```

## 思路

### 核心思想

翻转二叉树 = 对每个节点，交换它的左右子树。从根节点开始递归（或层序遍历）即可。

```
对每一层做的事：
  ① 交换 root.left 和 root.right
  ② 递归翻转 root.left（原来的右子树）
  ③ 递归翻转 root.right（原来的左子树）

注意：②③的顺序不重要，因为各自独立。
```

### 解法一：递归（DFS）

从根节点开始，先交换左右孩子，再递归翻转左右子树：

1. 终止条件：`root == null` → 返回 null
2. 交换：`TreeNode tmp = root.left; root.left = root.right; root.right = tmp;`
3. 递归：`invertTree(root.left); invertTree(root.right);`
4. 返回 root

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(h)\\)

### 解法二：迭代（BFS 层序遍历）

用队列辅助，每弹出一个节点就交换它的左右孩子，然后将非空孩子入队：

1. 根节点入队
2. 队列不空 → 弹出节点 → 交换左右孩子 → 左右孩子（非空）入队

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(n)\\)

### 解法一：递归（推荐）

```java
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;

    // 交换左右孩子
    TreeNode tmp = root.left;
    root.left = root.right;
    root.right = tmp;

    // 递归翻转子树
    invertTree(root.left);
    invertTree(root.right);

    return root;
}
```

### 解法二：迭代（BFS 队列）

```java
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        TreeNode node = queue.poll();

        // 交换左右孩子
        TreeNode tmp = node.left;
        node.left = node.right;
        node.right = tmp;

        // 非空孩子入队
        if (node.left  != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
    return root;
}
```
