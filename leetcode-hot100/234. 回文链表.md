# 234. 回文链表

> **难度**：🟢 简单 | **标签**：栈、递归、链表、双指针 | **企业**：—

## 题目描述

给你一个单链表的头节点 `head` ，请你判断该链表是否为回文链表。如果是，返回 `true` ；否则，返回 `false` 。

> 回文：正着读和反着读一样。

## 示例

**示例 1**

```
输入：head = [1,2,2,1]
输出：true

链表: 1 → 2 → 2 → 1 → null
反转: 1 ← 2 ← 2 ← 1       ← 相同 ✓
```

**示例 2**

```
输入：head = [1,2]
输出：false
```

- 链表中节点数目在范围 `[1, 10^5]` 内
- `0 <= Node.val <= 9`

## 思路

### 核心思想

三种解法，面试逐级递进：

```
解法                  时间       空间      面试表现
────────────────────────────────────────────────
转数组 + 双指针        O(n)      O(n)      ⭐ 保底
递归（后序遍历）        O(n)      O(n)      ⭐ 展示递归功底
快慢指针 + 反转后半段   O(n)      O(1)      ⭐⭐⭐ 最优
```

### 解法一：转数组 + 双指针

把链表值复制到数组，然后头尾双指针比较：

```
[1, 2, 2, 1]
 ↑        ↑
 left   right   相等 → 同时内移 → 重复直到相遇
```

### 解法二：快慢指针 + 反转后半段（O(1) 空间）

这是面试最想看到的解法，组合了两道经典题：

```
Step 1: 快慢指针找中点
        1 → 2 → 2 → 1 → null
             ↑
           slow（前半段尾）

Step 2: 反转后半段
        前半段: 1 → 2 → null
        后半段: 1 → 2 → null（反转后）

Step 3: 同时遍历两段，逐节点比较
        p1: 1 → 2
        p2: 1 → 2    全部相等 → true

Step 4: [可选] 恢复链表（还原现场）
```

**分步详解**：

```
原始链表: 1 → 2 → 2 → 1 → null

① 快慢指针找中点：
   slow 每次 1 步，fast 每次 2 步
   fast 到 null 时，slow 在中间（偏右）

   1(慢/快) → 2 → 2 → 1 → null    step0
   1 → 2(慢) → 2(快) → 1 → null   step1
   1 → 2 → 2(慢) → 1 → null(快)   step2 → 结束
                           慢在第二个"2"

② 反转后半段（从 slow 开始）：
   反转前: 2 → 1 → null
   反转后: 1 → 2 → null

③ 比较：
   前半段 head: 1 → 2 → 2（下一个是 slow）
   后半段 rev:  1 → 2
   
   p1=1, p2=1 ✓ → p1=2, p2=2 ✓ → 结束，true
```

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(1)\\)

### 解法一：转数组 + 双指针

```java
public boolean isPalindrome(ListNode head) {
    List<Integer> vals = new ArrayList<>();
    ListNode p = head;
    while (p != null) {
        vals.add(p.val);
        p = p.next;
    }

    int l = 0, r = vals.size() - 1;
    while (l < r) {
        if (!vals.get(l).equals(vals.get(r))) return false;
        l++;
        r--;
    }
    return true;
}
```

### 解法二：快慢指针 + 反转后半段（最优，O(1) 空间）

```java
public boolean isPalindrome(ListNode head) {
    // ① 快慢指针找中点
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    // slow 现在在后半段的起点

    // ② 反转后半段
    ListNode prev = null;
    while (slow != null) {
        ListNode next = slow.next;
        slow.next = prev;
        prev = slow;
        slow = next;
    }
    // prev 是反转后的头

    // ③ 同时遍历比较
    ListNode p1 = head, p2 = prev;
    while (p2 != null) {       // 后半段可能短一个节点
        if (p1.val != p2.val) return false;
        p1 = p1.next;
        p2 = p2.next;
    }
    return true;
}
```
