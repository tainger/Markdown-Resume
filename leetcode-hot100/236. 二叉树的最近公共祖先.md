## 题目描述

给定一个二叉树, 找到该树中两个指定节点的**最近公共祖先**（Lowest Common Ancestor, LCA）。

百度百科中最近公共祖先的定义为："对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个结点 x，满足 x 是 p、q 的祖先且 x 的**深度尽可能大**（**一个节点也可以是它自己的祖先**）。"

## 示例

**示例 1**

```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
解释：节点 5 和节点 1 的最近公共祖先是节点 3 。

树结构：
          3
        /   \
       5     1
      / \   / \
     6   2 0   8
        / \
       7   4
```

**示例 2**

```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5
解释：节点 5 和节点 4 的最近公共祖先是节点 5 。因为根据定义最近公共祖先节点可以为节点 5 本身。
```

**示例 3**

```
输入：root = [1,2], p = 1, q = 2
输出：1
```

## 提示

- 树中节点数目在范围 `[2, 10^5]` 内
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` **互不相同**
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中

## 思路

### 核心思想

后序递归，定义**「在以 node 为根的子树里找 p 或 q」**：找到返回那个节点，找不到返回 null。

- 左右子树**都非空** → p、q 分居两侧 → 当前节点就是分岔点，即 LCA
- 只有**一侧非空** → 把非空结果原样上抛（p、q 必存在，上抛的要么是目标节点之一，要么是子树内已确定的 LCA）

```
找 (5, 4)：            3
                      / \
                     5   1          ← 左边返回 5，右边返回 null → 上抛 5
                    / \
                   …  2              ← 5 自己命中直接上抛（p 可以是自己的祖先）
                     /
                    4
```

### 解法一：递归后序（基础）

1. 终止：`root == null || root == p || root == q` 直接返回 root（命中即上抛）
2. 递归左右子树各拿一个结果
3. 都非空 → 返回当前节点；否则返回非空的那个

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(h)\\)（最坏 O(n)）

### 解法二：父指针哈希表 + 祖先集合（推荐理解）

1. DFS 建立每个节点的**父指针表**，直到 p、q 都记录到
2. 从 p 沿父链向上，把祖先链（含 p 自己）放进 `HashSet`
3. 从 q 沿父链向上走，**第一个命中集合的节点**就是 LCA

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(n)\\)（父表 + 集合）

## 代码

### 解法一：递归后序（推荐）

```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    // 命中 p/q 或走到空：p 可以是自己的祖先，命中直接上抛
    if (root == null || root == p || root == q) return root;

    TreeNode left  = lowestCommonAncestor(root.left,  p, q);   // 左子树找
    TreeNode right = lowestCommonAncestor(root.right, p, q);   // 右子树找

    // 两侧各命中一个 → 当前节点就是分岔点 = LCA
    if (left != null && right != null) return root;
    // 单侧命中 → 原样上抛（非空的那个就是答案或答案所在子树）
    return left != null ? left : right;
}
```

### 解法二：父指针哈希表 + 祖先集合

```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    Map<TreeNode, TreeNode> parent = new HashMap<>();   // 节点 → 父节点
    parent.put(root, null);
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);
    // DFS 建父指针表，直到 p、q 都收录
    while (!parent.containsKey(p) || !parent.containsKey(q)) {
        TreeNode node = stack.pop();
        if (node.left  != null) { parent.put(node.left,  node); stack.push(node.left);  }
        if (node.right != null) { parent.put(node.right, node); stack.push(node.right); }
    }
    // p 的祖先链（含 p 自己）入集合
    Set<TreeNode> ancestors = new HashSet<>();
    for (TreeNode i = p; i != null; i = parent.get(i)) ancestors.add(i);
    // q 沿父链上溯，第一个命中集合的就是最近公共祖先
    for (TreeNode i = q; i != null; i = parent.get(i))
        if (ancestors.contains(i)) return i;
    return null;    // 题目保证 p、q 存在，不会到达
}
```

## 个人总结

### 1. 递归函数的语义要先定义清楚

`lowestCommonAncestor(node, p, q)` 返回的不是严格意义的 LCA，而是「子树中找到的 p/q 或已确定的 LCA」。定义模糊是这题最大的门槛——先想清楚"我返回什么、上抛什么"，代码自然就三五行。

### 2. 为什么"单侧命中直接上抛"是对的

p、q 保证存在。单侧非空时，非空返回值要么是 p/q 本身（另一个必然在它的子树里，它就是 LCA），要么是更深处已确定的 LCA。所以不需要额外判断，上抛即可。若题目改成"p、q 可能不存在"，就必须额外记录命中次数，不能这样偷懒。

### 3. "一个节点可以是它自己的祖先"（示例 2）

终止条件 `root == p || root == q` 直接返回，天然覆盖了 p 是 q 祖先的情形：p 自己先被命中并上抛，q 在 p 的子树里根本不需要单独返回。这是题面定义的直接利用，不要额外写"判断 q 是否在 p 子树里"。

### 4. BST 变体：LeetCode 235 用值判断

普通二叉树必须遍历；BST 有序，可以走"导航"：`p、q 都 < root` → 往左；`都 > root` → 往右；**第一次分居两侧（或一个等于 root）** 的节点就是 LCA。单次 O(h)，无需遍历全树。两题代码看起来像，内核完全不同——236 靠"结构信息"，235 靠"值信息"。
