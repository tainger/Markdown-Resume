## 题目描述

给你一个整数数组 `nums`，返回 数组 `answer` ，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。

题目数据 **保证** 数组 `nums` 之中任意元素的全部前缀元素和后缀的乘积都在 **32 位** 整数范围内。

请 **不要使用除法，** 且在 `O(n)` 时间复杂度内完成此题。

---

## 示例

**示例 1**

```
输入：nums = [1,2,3,4]
输出：[24,12,8,6]
```

**示例 2**

```
输入：nums = [-1,1,0,-3,3]
输出：[0,0,9,0,0]
```

---

## 提示

- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`
- **保证** 数组 `nums` 之中任意元素的全部前缀元素和后缀的乘积都在 **32 位** 整数范围内

**进阶**：你可以在 `O(1)` 的额外空间复杂度内完成这个问题吗？（出于对空间复杂度分析的目的，输出数组 **不被视为** 额外空间。）

---

## 思路

### 核心思想

`answer[i]` = **`i` 左边所有数的乘积** × **`i` 右边所有数的乘积**。把「除自身以外的乘积」拆成**前缀积**和**后缀积**两部分相乘，就绕开了除法，也避开了「有 0 时无法用除法」的坑。

### 解法一：除法（能想到，但违反约束）

先求全体乘积 `total`，则 `answer[i] = total / nums[i]`。**但题目禁止除法**，且存在 `0` 时除法会出错（要特判 0 的个数），所以只作为对照。

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(1)\)，但**违反「不能用除法」**。

### 解法二：前缀积数组 + 后缀积数组

- `prefix[i]` = `nums[0..i-1]` 的乘积（`i` 左边所有数之积），`prefix[0] = 1`；
- `suffix[i]` = `nums[i+1..n-1]` 的乘积（`i` 右边所有数之积），`suffix[n-1] = 1`；
- `answer[i] = prefix[i] * suffix[i]`。

```
nums   = [ 1,  2,  3,  4]
prefix = [ 1,  1,  2,  6]   （左边乘积：1, 1, 1×2, 1×2×3）
suffix = [24, 12,  4,  1]   （右边乘积：2×3×4, 3×4, 4, 1）
answer = [24, 12,  8,  6]   （prefix × suffix）
```

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(n)\)（两个辅助数组）。

### 解法三：滚动变量优化到 O(1) 额外空间（推荐）

进阶要求：输出数组不算额外空间。做法是**分两趟直接在 `answer` 上累乘**：

1. **第一趟从左到右**：`answer[i]` 先存「`i` 左边的前缀积」。
2. **第二趟从右到左**：用一个变量 `R` 累计「右边的后缀积」，令 `answer[i] *= R`，再更新 `R *= nums[i]`。

这样只用一个额外变量 `R`，把两个辅助数组省掉了。

```
nums = [1,2,3,4]
第一趟(前缀积): answer = [1, 1, 2, 6]
第二趟(右往左乘后缀 R):
  i=3: answer[3]*=R(1)=6;  R=1*4=4
  i=2: answer[2]*=R(4)=8;  R=4*3=12
  i=1: answer[1]*=R(12)=12; R=12*2=24
  i=0: answer[0]*=R(24)=24; R=24*1=24
answer = [24,12,8,6]
```

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(1)\)（不计输出数组）✅ 最优。

## 代码

### 解法一：除法（对照，违反约束）

```java
// ❌ 题目禁止除法；且遇到 0 需特判 0 的个数，不推荐
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int total = 1;
        for (int x : nums) total *= x;         // 若含 0，此处 total 为 0，下面会除 0 出错
        int[] answer = new int[nums.length];
        for (int i = 0; i < nums.length; i++) {
            answer[i] = total / nums[i];
        }
        return answer;
    }
}
```

### 解法二：前缀积数组 + 后缀积数组

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] prefix = new int[n];             // prefix[i] = i 左边所有数之积
        int[] suffix = new int[n];             // suffix[i] = i 右边所有数之积
        int[] answer = new int[n];

        prefix[0] = 1;
        for (int i = 1; i < n; i++) {
            prefix[i] = prefix[i - 1] * nums[i - 1];
        }
        suffix[n - 1] = 1;
        for (int i = n - 2; i >= 0; i--) {
            suffix[i] = suffix[i + 1] * nums[i + 1];
        }
        for (int i = 0; i < n; i++) {
            answer[i] = prefix[i] * suffix[i];
        }
        return answer;
    }
}
```

### 解法三：滚动变量优化 O(1) 额外空间（推荐）

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];

        // 第一趟：answer[i] 先存 i 左边的前缀积
        answer[0] = 1;
        for (int i = 1; i < n; i++) {
            answer[i] = answer[i - 1] * nums[i - 1];
        }

        // 第二趟：R 累计右边后缀积，从右往左乘进 answer
        int R = 1;
        for (int i = n - 1; i >= 0; i--) {
            answer[i] *= R;                    // 左前缀积 × 右后缀积
            R *= nums[i];                      // 更新后缀积
        }
        return answer;
    }
}
```

## 个人总结

### 1. 约束是灵魂：不能用除法

看到「除自身以外的乘积」第一反应是「全体积 ÷ 自己」，但题目**明令禁止除法**。这条约束把简单解法堵死，逼出「**前缀积 × 后缀积**」的拆分思路。同时除法还有个致命坑：**数组含 0 时不能直接除**（要单独统计 0 的个数、分类讨论），前缀积思路则天然处理 0（0 会自然乘进对应的前/后缀）。

### 2. 核心拆分：answer[i] = 左边积 × 右边积

把「除自身以外」翻译成「左边一段乘积 × 右边一段乘积」，是**前缀和思想在乘法上的迁移**：前缀和解决区间求和，前缀积解决区间求积。掌握这个「拆成前缀 + 后缀」的套路，很多数组题都能套。

### 3. O(1) 空间的技巧：借输出数组 + 一个滚动变量

进阶不算输出数组，于是：**第一趟把前缀积直接写进 `answer`，第二趟用单变量 `R` 从右往左把后缀积乘进去**。省掉两个辅助数组，是「用输出数组当中间缓存 + 滚动变量」的经典优化手法。

### 4. 边界：prefix[0] 和 suffix[n-1] 初始化为 1

- `answer[0] = 1`（0 左边没有元素，空积为 1）；
- `R` 初始为 1（n-1 右边没有元素，空积为 1）。
- **乘法的「空积」是 1**，类比加法前缀和的「空和」是 0，别写成 0，否则全乘成 0。

### 5. 三种解法取舍

| 解法 | 时间 | 空间 | 用除法 | 定位 |
|:---|:---:|:---:|:---:|:---|
| 全体积除法 | \(O(n)\) | \(O(1)\) | ❌ 违规 | 对照，含 0 要特判 |
| 前后缀数组 | \(O(n)\) | \(O(n)\) | 否 | 满足约束，直观 |
| 滚动变量 | \(O(n)\) | \(O(1)\) ✅ | 否 | 满足进阶，最优 |

**面试建议**：先点出除法的两个问题（违规 + 0），再讲前后缀数组，最后亮滚动变量 O(1) 空间——层层递进最出彩。
