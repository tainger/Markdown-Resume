## 题目描述

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行 **节点交换**）。

## 示例

**示例 1**

```
输入：head = [1,2,3,4]
输出：[2,1,4,3]
```

**示例 2**

```
输入：head = []
输出：[]
```

**示例 3**

```
输入：head = [1]
输出：[1]
```

---

## 提示

- 链表中节点的数目在范围 `[0, 100]` 内
- `0 <= Node.val <= 100`

## 思路

### 核心思想

每两个节点为一组做「断链 + 重连」，关键是记下每组的前驱 `prev`，交换完成后让它指向新的组头。

### 解法一：迭代（dummy + 三步重连，推荐）

1. 建哑节点 `dummy`，`prev` 从 `dummy` 出发，表示「已处理部分的尾部」
2. 循环条件：`prev.next` 与 `prev.next.next` 都存在，说明后面还剩完整的一对
3. 记 `first = prev.next`、`second = prev.next.next`，按「先保后、再反指、最后接前」的顺序重连三条指针
4. `prev` 移到 `first`（交换后这一对的尾部），继续处理下一对
5. 返回 `dummy.next`

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(1)\)

### 解法二：递归

1. 递归定义：`swapPairs(head)` 交换以 `head` 开头的一对节点，返回交换后的新头
2. 基准情况：`head` 为空或只剩一个节点，无法成对，直接返回 `head`
3. 记 `first = head`、`second = head.next`：先把 `second.next` 之后的部分递归交换并接到 `first` 后面，再让 `second.next = first`，返回 `second`

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(n)\)（递归栈）

## 代码

### 解法一：迭代（dummy + 三步重连，推荐）

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode swapPairs(ListNode head) {
        ListNode dummy = new ListNode(-1, head);
        ListNode prev = dummy;

        // 后面还剩完整的一对，才交换
        while (prev.next != null && prev.next.next != null) {
            ListNode first = prev.next;       // 本对第一个节点
            ListNode second = prev.next.next; // 本对第二个节点

            // 三步重连：第 1 步读 second.next 必须发生在第 2 步改它之前
            first.next = second.next;  // 1) 先保住 second 后面的链
            second.next = first;       // 2) second 反指 first
            prev.next = second;        // 3) 前驱指向新的组头 second

            prev = first;              // prev 落到本对尾部（first），处理下一对
        }
        return dummy.next;
    }
}
```

### 解法二：递归

```java
class Solution {
    public ListNode swapPairs(ListNode head) {
        // 基准情况：空或单节点，无法成对
        if (head == null || head.next == null) {
            return head;
        }
        ListNode first = head;
        ListNode second = head.next;

        // 先递归交换后面的部分，接到 first 后面
        first.next = swapPairs(second.next);
        // 再让 second 反指 first，完成本层交换
        second.next = first;
        // second 是交换后的新头
        return second;
    }
}
```

## 个人总结

### 1. 重连三步的顺序有讲究：先读后写

`first.next = second.next` 是「读 second.next」，`second.next = first` 是「写 second.next」——**读必须发生在写之前**，否则 `second` 后面的整条链（3 → 4）直接丢失。`prev.next = second` 放最后只是习惯，它不与谁争抢。

```
交换前:  prev → 1 → 2 → 3 → 4
                first second

1) first.next = second.next  →  1 ─────→ 3 → 4   （2 暂时悬空）
2) second.next = first       →  1 ⇄ 2            （本对成环）
3) prev.next = second        →  prev → 2 → 1 → 3 → 4
```

### 2. prev 的落脚点是 first，不是 second

交换后这一对的**尾部是 first**。`prev = first` 才能正确衔接下一对；若误写成 `prev = second`，下一轮会把刚处理完的一对再翻一次，`[1,2,3,4]` 会错成 `[2,3,1,4]`。

### 3. 循环条件 = 「还剩完整的一对」

`prev.next != null && prev.next.next != null` 两个判断缺一不可：只判第一个时，剩单个节点（示例 3）会在取 `prev.next.next` 时抛空指针。

### 4. 递归版语义更直白，但面试先写迭代

递归把「交换一对」直接写成了函数定义，五行搞定；代价是 O(n) 递归栈。建议面试先给迭代版（O(1) 空间），递归作为对照展示。
