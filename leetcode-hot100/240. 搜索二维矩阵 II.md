## 题目描述

编写一个高效的算法来搜索 `m x n` 矩阵 `matrix` 中的一个目标值 `target` 。该矩阵具有以下特性：

- 每行的元素从左到右升序排列。
- 每列的元素从上到下升序排列。

---

## 示例

**示例 1**

```
输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 5
输出：true
```

**示例 2**

```
输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 20
输出：false
```

---

## 提示

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= n, m <= 300`
- `-10^9 <= matrix[i][j] <= 10^9`
- 每行的所有元素从左到右升序排列
- 每列的所有元素从上到下升序排列
- `-10^9 <= target <= 10^9`

## 思路

### 核心思想

矩阵**每行升序、每列升序**，但整体并不是「一条完全有序的序列」（不能把它拉直成一维数组做二分）。关键是**站在右上角（或左下角）**看：那个位置同时是「所在行最大、所在列最小」的分界点，比较后能**每次排除一整行或一整列**，从而走出一条单调路径。

### 解法一：暴力遍历（先跑通）

直接双重循环扫每个元素，等于 `target` 就返回。没用到任何有序性质。

- 时间复杂度：\(O(mn)\)，空间复杂度：\(O(1)\)

### 解法二：逐行二分查找

每行都是升序，对每一行做一次二分查找。

- 时间复杂度：\(O(m\log n)\)，空间复杂度：\(O(1)\)
- 比暴力好，但没用到「列也有序」，不是最优。

### 解法三：Z 字形查找（右上角出发，推荐）

从**右上角** `(0, n-1)` 出发，记当前元素为 `cur`：

- 该位置是**所在行的最大值**、同时是**所在列的最小值**——所以它是一个天然的「分水岭」。
- 若 `cur == target`：找到，返回 `true`；
- 若 `cur > target`：`target` 不可能在当前这一列（这一列它是最小值，往下只会更大）→ **排除整列**，列左移 `col--`；
- 若 `cur < target`：`target` 不可能在当前这一行（这一行它是最大值，往左只会更小）→ **排除整行**，行下移 `row++`。

每一步都排除一行或一列，走出一条从右上到左下的单调路径，最多走 `m + n` 步。

```
matrix, target = 5，从右上角 15 出发：
[ 1  4  7 11 15]   15>5 → 列左移
[ 2  5  8 12 19]   → 11>5 → 列左移 → 7>5 → 列左移 → 4<5 → 行下移
[ 3  6  9 16 22]        到 (1,1)=5 命中 ✅
[10 13 14 17 24]
[18 21 23 26 30]
```

- 时间复杂度：\(O(m+n)\)，空间复杂度：\(O(1)\)（最优）

> 也可从**左下角** `(m-1, 0)` 出发，逻辑对称：它是「所在列最大、所在行最小」，`cur > target` 上移、`cur < target` 右移。**注意左上角和右下角不能作为起点**——它们是全局最小/最大，两个方向单调性一致，无法排除。

## 代码

### 解法一：暴力遍历（先跑通）

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        for (int[] row : matrix) {
            for (int x : row) {
                if (x == target) return true;
            }
        }
        return false;
    }
}
```

### 解法二：逐行二分查找

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        for (int[] row : matrix) {
            int lo = 0, hi = row.length - 1;
            while (lo <= hi) {
                int mid = lo + (hi - lo) / 2;
                if (row[mid] == target) {
                    return true;
                } else if (row[mid] < target) {
                    lo = mid + 1;
                } else {
                    hi = mid - 1;
                }
            }
        }
        return false;
    }
}
```

### 解法三：Z 字形查找（推荐，O(m+n) O(1)）

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int m = matrix.length, n = matrix[0].length;
        int row = 0, col = n - 1;               // 从右上角出发
        while (row < m && col >= 0) {           // 未越界
            int cur = matrix[row][col];
            if (cur == target) {
                return true;
            } else if (cur > target) {
                col--;                          // 当前列最小值都比 target 大 → 排除整列
            } else {
                row++;                          // 当前行最大值都比 target 小 → 排除整行
            }
        }
        return false;
    }
}
```

## 个人总结

### 1. 别被「二维有序」骗了：整体不是全序

行有序、列有序，**不代表能拉直成一维数组做二分**。反例：`[[1,4],[2,5]]` 拉直是 `1,4,2,5`，并不单调。所以「把矩阵当有序数组二分」是错的，必须逐行二分或用 Z 字形。

### 2. Z 字形的精髓：选一个「单调性相反」的角

- **右上角**：行方向（左）递减、列方向（下）递增——两个方向单调性相反，比较一次就能砍掉一整行或一整列。
- **左上角/右下角**：两个可走方向单调性相同（都变大或都变小），无法排除，**不能作起点**。
- 记忆：**起点要选「所在行最大且所在列最小」的右上角，或「所在列最大且所在行最小」的左下角。**

### 3. 三种解法的取舍

| 解法 | 时间 | 空间 | 用到的性质 | 定位 |
|:---|:---:|:---:|:---|:---|
| 暴力遍历 | \(O(mn)\) | \(O(1)\) | 无 | 先跑通 |
| 逐行二分 | \(O(m\log n)\) | \(O(1)\) | 只用「行有序」 | 中间态 |
| Z 字形查找 | \(O(m+n)\) ✅ | \(O(1)\) ✅ | 行、列都用上 | 最优 |

**面试建议**：先说暴力（表明会做），再说逐行二分（用上一半性质），最后亮 Z 字形（同时利用行列有序，O(m+n)）——层层递进。

### 4. 边界与易错点

- 循环条件是 `row < m && col >= 0`，两个方向都要判越界。
- 移动方向别写反：`cur > target` 是**列左移**（排除列），`cur < target` 是**行下移**（排除行）。
- `matrix[0].length` 取列数前，本题保证至少 1×1，无需额外空判；若不保证需先判 `matrix == null || matrix.length == 0`。
