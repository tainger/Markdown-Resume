## 题目描述

给你链表的头节点 `head` ，每 **k 个节点一组**进行翻转，请你返回修改后的链表。

`k` 是一个正整数，它的值 **小于或等于** 链表的长度。如果节点总数 **不是** `k` 的整数倍，那么请将最后剩余的节点 **保持原有顺序**。

你 **不能** 只是单纯的改变节点内部的值，而是需要实际进行节点交换。

## 示例

**示例 1**

```
输入：head = [1,2,3,4,5], k = 2
输出：[2,1,4,3,5]
```

**示例 2**

```
输入：head = [1,2,3,4,5], k = 3
输出：[3,2,1,4,5]
```

## 思路

### 核心思想

按 K 个一组切块：**每组先数够 K 个再翻转**，数不够就整体保持原序。翻转本身不难（复用普通链表翻转），难点在**重连**：上一组尾 → 本组新头、本组新尾 → 下一组头，以及 prevGroupEnd 的正确推进。

### 解法一：迭代（分组翻转，推荐）

1. 建 `dummy`，`prevGroupEnd` 指向 `dummy`（上一组翻转后的尾）
2. 探针从 `prevGroupEnd` 走 K 步定位本组尾部 `groupEnd`；走不到说明剩余不足 K 个，直接结束
3. 记下本组原头 `groupStart`（= `prevGroupEnd.next`）和下一组头 `nextGroupStart`（= `groupEnd.next`）
4. 断开 `groupEnd.next`，翻转 `[groupStart, groupEnd]`：新头 = 原 groupEnd，新尾 = 原 groupStart
5. 重连两个外部断点：`prevGroupEnd.next = 新头`，`新尾.next = nextGroupStart`
6. `prevGroupEnd` 推进到新尾（原 groupStart），回到第 2 步

- 时间复杂度：\(O(n)\)（每个节点只被常数次访问），空间复杂度：\(O(1)\)

### 解法二：递归

1. 递归定义：`reverseKGroup(head, k)` 翻转从 `head` 开始的链表并返回新头
2. 先探针检查：从 `head` 起不足 K 个，保持原序直接返回 `head`（必须在翻转前做）
3. 翻转前 K 个节点；翻转结束后 `curr` 正好指向下一组头、`head` 是本组新尾
4. `head.next = reverseKGroup(curr, k)` 接上后续，返回本组新头 `prev`

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(n/k)\)（递归栈）

## 代码

### 解法一：迭代（分组翻转，推荐）

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        ListNode dummy = new ListNode(-1, head);
        ListNode prevGroupEnd = dummy; // 上一组翻转后的尾

        while (true) {
            // 1) 探针先走 K 步：数够才翻，不足 K 个直接结束（保持原序）
            ListNode groupEnd = prevGroupEnd;
            for (int i = 0; i < k && groupEnd != null; i++) {
                groupEnd = groupEnd.next;
            }
            if (groupEnd == null) {
                break;
            }

            ListNode groupStart = prevGroupEnd.next;  // 本组原头（翻转后变新尾）
            ListNode nextGroupStart = groupEnd.next;  // 先保住下一组头，防断链

            // 2) 断开本组并翻转
            groupEnd.next = null;
            ListNode newHead = reverse(groupStart); // 新头 = 原 groupEnd

            // 3) 重连两个外部断点
            prevGroupEnd.next = newHead;      // 上组尾 → 本组新头
            groupStart.next = nextGroupStart; // 本组新尾 → 下组头

            // 4) prevGroupEnd 推进到本组新尾（原 groupStart）
            prevGroupEnd = groupStart;
        }
        return dummy.next;
    }

    // 翻转已断开的链表段，返回新头
    private ListNode reverse(ListNode head) {
        ListNode prev = null, curr = head;
        while (curr != null) {
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }
        return prev;
    }
}
```

### 解法二：递归

```java
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        // 1) 先检查：从 head 起不足 K 个，保持原序（必须放在翻转之前）
        ListNode probe = head;
        for (int i = 0; i < k; i++) {
            if (probe == null) return head;
            probe = probe.next;
        }

        // 2) 翻转前 K 个节点
        ListNode prev = null, curr = head;
        for (int i = 0; i < k; i++) {
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }

        // 此时 prev = 本组新头，head = 本组新尾，curr = 下一组头
        head.next = reverseKGroup(curr, k);
        return prev;
    }
}
```

## 个人总结

### 1. 「先数够再翻」是本题唯一的坑位

逐组处理的通病：翻到一半才发现剩余不足 K 个，但链已经翻乱、无法恢复。正确做法是**每组处理前先用探针走 K 步**：

- 走得到 → 本组完整，放心断链翻转
- 走不到 → `break`，剩余节点保持原序

### 2. 一组牵动三个断点

```
翻转前:  prevGroupEnd → a → b → c → nextGroupStart
翻转后:  prevGroupEnd → c → b → a → nextGroupStart
                        新头        新尾(原头)
```

组内 K-1 条指针由 `reverse` 搞定，**两个外部断点必须手动重连**：`prevGroupEnd.next = 新头`、`新尾.next = nextGroupStart`。其中 `nextGroupStart` 必须在 `groupEnd.next = null` 之前先存下来（断链防护）。

### 3. prevGroupEnd 的下一站是 groupStart

翻转后本组新尾 = 原 groupStart，所以推进写 `prevGroupEnd = groupStart`。误写成 `newHead` 会让下一组从本组已翻转的头部开始数，全盘错乱。

### 4. 递归版：检查必须在翻转之前

递归的基准情况就是「不足 K 个原样返回」。若先翻 K 个再检查，尾组会被翻坏一半且无法恢复——**探针循环必须放在翻转循环前面**。递归版还需注意不足 K 个时连翻转都不能开始，这一点与迭代版的探针语义完全一致。
