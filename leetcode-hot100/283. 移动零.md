# 283. 移动零

> **难度**：🟢 简单 | **标签**：数组、双指针 | **企业**：—

## 题目描述

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持**非零元素的相对顺序**。

请注意，必须**原地**操作，不能拷贝额外的数组。尽量减少操作次数。

## 示例

**示例 1**

```
输入：nums = [0,1,0,3,12]
输出：[1,3,12,0,0]

过程:  [0,1,0,3,12]
  →    [1,0,0,3,12]   非零 1 前移
  →    [1,3,0,0,12]   非零 3 前移
  →    [1,3,12,0,0]   非零 12 前移 ✓
```

**示例 2**

```
输入：nums = [0]
输出：[0]
```

## 思路

### 核心思想

双指针，`slow` 指向"下一个非零元素应该放的位置"：

```
slow: 下一个非零元素的写入位
fast: 遍历整个数组

fast 遇到非零 → 放到 slow 位置 → slow++
fast 遇到零   → 跳过

最后 slow 之后的位置全部填 0
```

**逐步演示**：

```
初始: [0, 1, 0, 3, 12]    slow=0, fast=0

fast=0: nums[0]=0 → 跳过
        slow=0

fast=1: nums[1]=1 → nums[0]=1, slow=1
        [1, 1, 0, 3, 12] ← 注意有"脏"值

fast=2: nums[2]=0 → 跳过
        slow=1

fast=3: nums[3]=3 → nums[1]=3, slow=2
        [1, 3, 0, 3, 12]

fast=4: nums[4]=12 → nums[2]=12, slow=3
        [1, 3, 12, 3, 12]

遍历结束。slow=3 之后全部填 0：
        [1, 3, 12, 0, 0] ✓
```

### 优化：覆盖 → 直接 swap

上面方案最后需要补零。更干净的做法是 fast 和 slow 直接交换：

```
fast 遇非零 → swap(nums[slow], nums[fast]) → slow++
```

这样零自然被换到后面，不需要最后补零。

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(1)\\)

### 解法一：双指针覆盖 + 末尾补零

```java
public void moveZeroes(int[] nums) {
    int slow = 0;
    // 非零元素前移
    for (int x : nums) {
        if (x != 0) {
            nums[slow++] = x;
        }
    }
    // 剩余位置填零
    while (slow < nums.length) {
        nums[slow++] = 0;
    }
}
```

### 解法二：双指针 swap（推荐）

```java
public void moveZeroes(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            // 交换 slow 和 fast
            int tmp = nums[slow];
            nums[slow] = nums[fast];
            nums[fast] = tmp;
            slow++;
        }
    }
}
```

> 💡 如果 slow == fast（当前位置就是对的），swap 就是自己换自己，无副作用。
