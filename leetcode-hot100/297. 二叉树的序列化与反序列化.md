## 题目描述

序列化是将一个数据结构或者对象转换为连续的比特位的操作，进而可以将转换后的数据存储在一个文件或者内存中，同时也可以通过网络传输到另一个计算机环境，采取相反方式重构得到原数据。

请设计一个算法来实现二叉树的序列化与反序列化。这里不限定你的序列 / 反序列化算法执行逻辑，你只需要保证一个二叉树可以被序列化为一个字符串并且将这个字符串反序列化为原始的树结构。

**提示**：输入输出格式与 LeetCode 目前使用的方式一致，你并非必须采取这种方式，你也可以采用其他的方法解决这个问题。

## 思路

### 核心：序列化必须保留「结构信息」，null 要显式占位

普通的前序遍历序列（不记 null）**无法唯一还原**一棵树——比如 `[1,2]` 可能是「2 是 1 的左孩子」也可能是「右孩子」。所以序列化时必须**把空节点也记下来**（用 `#` 或 `null` 占位），这样才能一一对应地重建。

```
     1
    / \
   2   3
      / \
     4   5

前序序列化（含 null 占位）：
1,2,#,#,3,4,#,#,5,#,#
（# 表示空节点；每个真实节点后面必跟它的左右子树序列）
```

### 解法一：前序 DFS 序列化 + 递归反序列化（推荐）

**序列化**：前序遍历（根→左→右），遇到 null 输出占位符 `#`，节点值之间用分隔符（如 `,`）连接。

**反序列化**：把字符串按分隔符拆成队列，**按前序的顺序消费**——每次取一个 token：
- 若是 `#`，返回 null；
- 否则建节点，**递归**构建它的左子树、右子树（顺序和序列化时一致）。

因为序列化和反序列化都严格按「根→左→右」，token 顺序天然对齐，一次消费即可重建。

- 时间复杂度：\(O(n)\)，每个节点序列化/反序列化各一次
- 空间复杂度：\(O(n)\) 字符串 + \(O(h)\) 递归栈

### 解法二：BFS 层序（队列）

序列化用层序遍历，null 也入队并输出占位；反序列化用队列，按层序逐个给节点接左右孩子。与 LeetCode 官方 `[1,2,3,null,null,4,5]` 的展示格式一致，适合需要「人类可读的层序格式」时。

- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(n)\)

## 代码

### 解法一：前序 DFS（推荐）

```java
public class Codec {
    private static final String NULL = "#";
    private static final String SEP = ",";

    // 序列化：前序遍历，null 用 # 占位
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        dfsSerialize(root, sb);
        return sb.toString();
    }

    private void dfsSerialize(TreeNode node, StringBuilder sb) {
        if (node == null) {
            sb.append(NULL).append(SEP);       // 空节点占位
            return;
        }
        sb.append(node.val).append(SEP);       // 根
        dfsSerialize(node.left, sb);           // 左
        dfsSerialize(node.right, sb);          // 右
    }

    // 反序列化：按前序顺序消费队列
    public TreeNode deserialize(String data) {
        Queue<String> queue = new LinkedList<>(Arrays.asList(data.split(SEP)));
        return dfsDeserialize(queue);
    }

    private TreeNode dfsDeserialize(Queue<String> queue) {
        String val = queue.poll();
        if (NULL.equals(val)) return null;     // 遇占位符 → 空节点
        TreeNode node = new TreeNode(Integer.parseInt(val));
        node.left = dfsDeserialize(queue);     // 顺序与序列化一致：先左
        node.right = dfsDeserialize(queue);    // 再右
        return node;
    }
}
```

### 解法二：BFS 层序

```java
public class Codec {
    public String serialize(TreeNode root) {
        if (root == null) return "";
        StringBuilder sb = new StringBuilder();
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            if (node == null) {
                sb.append("#,");
            } else {
                sb.append(node.val).append(",");
                queue.offer(node.left);        // null 也入队，保留结构
                queue.offer(node.right);
            }
        }
        return sb.toString();
    }

    public TreeNode deserialize(String data) {
        if (data == null || data.isEmpty()) return null;
        String[] vals = data.split(",");
        TreeNode root = new TreeNode(Integer.parseInt(vals[0]));
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int i = 1;
        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            if (!vals[i].equals("#")) {        // 左孩子
                node.left = new TreeNode(Integer.parseInt(vals[i]));
                queue.offer(node.left);
            }
            i++;
            if (!vals[i].equals("#")) {        // 右孩子
                node.right = new TreeNode(Integer.parseInt(vals[i]));
                queue.offer(node.right);
            }
            i++;
        }
        return root;
    }
}
```

## 个人总结

### 1. 序列化的灵魂：null 必须显式占位

不记 null 的遍历序列无法唯一确定树形（同一前序序列可对应多棵树）。**用 `#` 之类占位符把空节点也写进去**，让「每个节点后面紧跟它左右子树的完整序列」，才能无歧义还原。这是本题第一原则。

### 2. 序列化与反序列化必须「同序」

前序序列化，就前序反序列化；层序序列化，就层序反序列化。**反序列化是序列化的逆放**——按写入顺序逐个消费 token，节点的左右子树递归/入队顺序要和序列化时严格一致，否则错位。

### 3. 前序为什么适合递归重建

前序序列的第一个 token 一定是当前子树的根，紧接着是**整棵左子树**的序列、再是**整棵右子树**的序列。递归 `dfsDeserialize` 每次 `poll` 一个 token 建根，再递归建左、建右，队列的消费顺序天然匹配——代码极简洁。

### 4. 用队列（而非下标）消费更省心

反序列化把字符串 `split` 后放进 `Queue`，靠 `poll()` 自动推进读取位置，避免手动维护下标 `i` 的传递（递归里传下标要用数组包装才能共享）。BFS 版用下标是因为它是迭代、下标在同一作用域好维护。

### 5. 空树与格式细节

- 空树 `root == null`：DFS 版会序列化成 `"#,"`，反序列化第一个就是 `#` 返回 null，天然正确；BFS 版需特判返回 `""`。
- 分隔符不能省——多位数（如 `12`、`-5`）和负号必须靠分隔符切分，否则 `1` `2` 会粘连。
