# 3. 无重复字符的最长子串

> **难度**：🟡 中等 | **标签**：哈希表、字符串、滑动窗口 | **企业**：—

## 题目描述

给定一个字符串 `s`，请你找出其中不含有重复字符的 **最长子串** 的长度。

## 示例

**示例 1**

```
输入：s = "abcabcbb"
输出：3
解释：因为无重复字符的最长子串是 "abc"，所以其长度为 3。
```

**示例 2**

```
输入：s = "bbbbb"
输出：1
解释：因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

**示例 3**

```
输入：s = "pwwkew"
输出：3
解释：因为无重复字符的最长子串是 "wke"，所以其长度为 3。
```

> 请注意，你的答案必须是 **子串** 的长度，`"pwke"` 是一个子序列，不是子串。

---

## 提示

- `0 <= s.length <= 5 * 10^4`
- `s` 由英文字母、数字、符号和空格组成

---

## 思路

### 核心思想：滑动窗口 + 去重

两个指针维护一个窗口，**窗口内保证无重复字符**：右指针每次扩展一位，若引入重复字符，就收缩左指针直到窗口重新合法。用 `HashSet` 判断重复。

```
s = "abcabcbb"

a b c a b c b b
↑   ↑
left right      窗口 [left, right] 内无重复 → 记录长度 3

a b c a b c b b
  ↑   ↑
  left right    右指针遇到重复 'a' → 收缩 left 直到窗口内没有 'a'
                窗口重新合法后继续扩展
```

### 解法一：滑动窗口 + HashSet（推荐，最易理解）

1. `left`、`right` 双指针 + `Set` 记录窗口内的字符
2. `right` 每步把 `s.charAt(right)` 加入窗口
3. 若 `Set` 已包含该字符：**循环**移除 `Set` 中的 `s.charAt(left)` 并 `left++`，直到重复字符被移出窗口
4. 窗口合法后更新 `ans = max(ans, right - left + 1)`

- 时间复杂度：\(O(n)\)（`left` 和 `right` 各最多移动 n 次）
- 空间复杂度：\(O(\min(n, |\Sigma|))\)（`|\Sigma|` 为字符集大小）

### 解法二：滑动窗口 + HashMap（跳变优化）

1. `Map<Character, Integer>`：字符 → 最近一次出现的位置
2. 遇到重复字符时，`left` **直接跳到**重复位置 + 1：`left = Math.max(left, map.get(c) + 1)`
3. 更新 `map.put(c, right)`，再算窗口长度

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(|\Sigma|)\)
- 相比解法一：不需要逐格收缩，`left` 一步到位

> ⚠️ **为什么 `Math.max` 不能省**：`map.get(c)` 可能是「上次出现但在当前窗口左边」的位置，直接赋值会让 `left` **回退**，把已经排除的重复字符重新圈进窗口，答案偏大（见 [个人总结](#个人总结) 第 3 点）。

## 代码

### 我的伪代码

> 👇 第二版（已修 ①③，② 仍在）：三个官方示例全过，但 `"abba"` / `"tmmzuxt"` 仍错，具体见下方 [个人总结](#个人总结)。

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {

        // 💡 用 int 即可，无需包装类型 Integer
        Integer maxLength = 0;

        Map<Character,Integer>  indexMap = new HashMap<>();

        int slow = 0;
        for(int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            Integer index = indexMap.get(c);
            if(index != null) {
                // ❌ ② 仍在：slow = index + 1 缺 Math.max，
                //    重复位置若已在窗口左侧（早被丢弃），slow 会回退
                slow = index+1;
            }
            indexMap.put(c, i);                             // ✅ ① 已修：无条件更新最新位置
            maxLength = Math.max(maxLength, i - slow + 1);  // ✅ ③ 已修：闭区间 +1
        }

        return maxLength;
        
    }
}
```

### 解法一：滑动窗口 + HashSet（推荐）

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> set = new HashSet<>();
        int left = 0, ans = 0;

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            while (set.contains(c)) {        // 循环收缩：可能连续移出多个字符
                set.remove(s.charAt(left));
                left++;
            }
            set.add(c);                      // 加入新字符
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

### 解法二：滑动窗口 + HashMap（跳变优化）

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> map = new HashMap<>();
        int left = 0, ans = 0;

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            if (map.containsKey(c)) {
                // ✅ Math.max 防止 left 回退（重复位置已在窗口外时保持原 left）
                left = Math.max(left, map.get(c) + 1);
            }
            map.put(c, right);
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

> 💡 字符集已知（ASCII 128）时，还可以用 `int[128]` 数组代替 HashMap，`last[c]` 存最近位置，速度更快。

## 个人总结

### 1. ✅ 已修复：闭区间长度 `i - slow + 1`

第一版写 `i - slow`，所有长度低估 1（`"bbbbb"` → 0、`"abc"` → 2）。第二版已改对。

### 2. ✅ 已修复：`put` 无条件更新

第一版 `put` 只写在 `if` 分支，map 存的是**最早位置**，`"abcabcbb"` 被算成 5。第二版把 `indexMap.put(c, i)` 提到 `if` 外面，每次循环都刷新为最新位置——「先查重复、再无条件更新」的顺序正确了。

### 3. ❌ 唯一剩余：`slow = index + 1` 缺 `Math.max` → 回退

官方三示例全过，但反例 `"abba"`（应为 2）仍错：

```
i=0 'a': slow=0 → len=1
i=1 'b': slow=0 → len=2
i=2 'b': index=1 → slow=2 → len=1
i=3 'a': index=0 → slow=1 ← 回退！(slow 从 2 变 1)
         len = 3 - 1 + 1 = 3 ❌（窗口 [1,3] = "bba" 含重复）
```

再补一个更隐蔽的反例 `"tmmzuxt"`（应为 5，答案 "mzuxt"）：

```
i=6 't'：index=0，而 slow 已经在 2 → slow = 1 ← 回退 → len = 6 - 1 + 1 = 6 ❌
```

修复：`slow = Math.max(slow, index + 1)`——**重复位置在窗口外时保持 slow 不动**。

### 4. 最终修复版（第二版 + 一行 Math.max）

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> map = new HashMap<>();
        int slow = 0, maxLength = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (map.containsKey(c)) {
                slow = Math.max(slow, map.get(c) + 1);   // ✅ 唯一还差的一行
            }
            map.put(c, i);                                // ✅ 无条件更新
            maxLength = Math.max(maxLength, i - slow + 1);// ✅ 闭区间 +1
        }
        return maxLength;
    }
}
```

> 💡 复盘：第一版 3 处错 → 第二版自修 2 处 → 只剩「回退」这个藏得最深的。它的特点是**官方示例全过也发现不了**，必须靠 `"abba"`、`"tmmzuxt"` 这类**字符隔空重复**的用例。窗口题提交前，务必用「重复字符之间隔着一段距离」的用例自测。
