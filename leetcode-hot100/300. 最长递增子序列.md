## 题目描述

给你一个整数数组 `nums`，找到其中**最长严格递增子序列**的长度。

**子序列**是数组中通过删除一些（也可以不删除）元素得到的新序列，**不改变剩余元素的相对顺序**（区别于「子数组」必须连续）。

## 示例

**示例 1**

```
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,101]（或 [2,3,7,18]），长度为 4。
```

**示例 2**

```
输入：nums = [0,1,0,3,2]
输出：4
解释：最长递增子序列是 [0,1,2,3]（注意不是 [0,1,0,3]，因为严格递增不能相等）。
```

**示例 3**

```
输入：nums = [7,7,7,7,7,7,7]
输出：1
```

## 思路


### 解法一(从后往前推)：

#### 暴力


```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int ans = 0;
        // 枚举每个位置作为子序列的结尾
        for (int i = 0; i < n; i++) {
            ans = Math.max(ans, dfs(nums, i));
        }
        return ans;
    }
    
    // 返回以 nums[i] 结尾的最长递增子序列长度
    private int dfs(int[] nums, int i) {
        int best = 1; // 只取自己
        
        // 往前找所有比 nums[i] 小的元素
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                // nums[i] 可以接在 nums[j] 后面
                best = Math.max(best, dfs(nums, j) + 1);
            }
        }
        return best;
    }
}

```

class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];
        Arrays.fill(dp, 1);
        
        int ans = 1;
        
        // 从后往前计算（因为 dp[i] 依赖 dp[j]，其中 j > i）
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i + 1; j < n; j++) {
                if (nums[i] < nums[j]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            ans = Math.max(ans, dp[i]);
        }
        
        return ans;
    }
}

### 解法二(从前往后推)

####  暴力

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        // 从索引0开始，前驱为负无穷（任何数都可以接在后面）
        return dfs(nums, 0, Integer.MIN_VALUE);
    }
    
    // 从 start 开始，寻找比 prev 大的元素构建递增子序列
    private int dfs(int[] nums, int start, int prev) {
        if (start == nums.length) {
            return 0; // 没有元素可选了
        }
        
        // 情况1：跳过当前元素 nums[start]
        int skip = dfs(nums, start + 1, prev);
        
        // 情况2：选当前元素 nums[start]（前提是比 prev 大）
        int take = 0;
        if (nums[start] > prev) {
            take = 1 + dfs(nums, start + 1, nums[start]);
        }
        
        return Math.max(skip, take);
    }
}


```

#### 记忆化搜索版本

```java
class Solution {
    private int[][] memo; // memo[start][prevIndex]
    
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        // prevIndex 范围：-1 表示负无穷，0 到 n-1 表示具体元素
        memo = new int[n + 1][n + 1];
        for (int[] row : memo) {
            Arrays.fill(row, -1);
        }
        return dfs(nums, 0, -1); // -1 表示前驱不存在
    }
    
    // start: 当前要决策的位置
    // prevIndex: 上一个选中的元素的索引，-1 表示没有前驱
    private int dfs(int[] nums, int start, int prevIndex) {
        if (start == nums.length) {
            return 0;
        }
        
        // 用 prevIndex + 1 作为索引（因为 prevIndex 可以是 -1）
        if (memo[start][prevIndex + 1] != -1) {
            return memo[start][prevIndex + 1];
        }
        
        // 跳过当前元素
        int skip = dfs(nums, start + 1, prevIndex);
        
        // 选当前元素（需要比前驱大）
        int take = 0;
        if (prevIndex == -1 || nums[start] > nums[prevIndex]) {
            take = 1 + dfs(nums, start + 1, start);
        }
        
        int result = Math.max(skip, take);
        memo[start][prevIndex + 1] = result;
        return result;
    }
}

```

### 解法三（贪心）：

```java

class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int[] tails = new int[n]; // tails[k] 表示长度为 k+1 的LIS的末尾最小值
        int size = 0; // 当前有效长度
        
        for (int num : nums) {
            // 二分查找第一个 >= num 的位置
            int left = 0, right = size;
            while (left < right) {
                int mid = left + (right - left) / 2;
                if (tails[mid] < num) {
                    left = mid + 1;
                } else {
                    right = mid;
                }
            }
            
            // left 是要替换或追加的位置
            tails[left] = num;
            if (left == size) {
                size++; // 追加到末尾，长度增加
            }
            // 否则只是替换，长度不变
        }
        
        return size;
    }
}
```

#### 核心洞察：长度相同时，尾值越小越有潜力

DP 的瓶颈：每个 i 要扫前面所有 j。换一个完全不同的视角——

> 维护一个数组 `tails`，`tails[k]` = **长度为 k+1 的递增子序列的最小可能尾值**。

**为什么「最小尾值」有用**：长度都是 1 的两个子序列 `[10]` 和 `[9]`，选哪个更有潜力接到后面？选尾值小的 `[9]`——后面来一个 11，能接上 `[9,11]` 但接不上 `[10,11]`（10 < 11 没问题，等等，能接上……换个例子：来一个 9.5 能接 `[9]` 不能接 `[10]`）。**尾值越小，未来能接上的数越多**。

**操作规则**：遍历 `nums`，对每个 `x`：

1. 如果 `x` > `tails` 末尾 → **追加**到 `tails` 末尾（LIS 又长了一格）；
2. 否则 → 在 `tails` 里二分找到**第一个 ≥ x 的位置**，**替换**它（把那个长度的尾值变得更小，给后面更多机会）。

```
nums = [10, 9, 2, 5, 3, 7, 101, 18]

x=10：tails=[10]                     （长度1的尾值=10）
x=9 ：9 < 10，替换 → tails=[9]        （长度1的尾值从10降到9，更优）
x=2 ：2 < 9，替换 → tails=[2]         （长度1的尾值再降到2）
x=5 ：5 > 2，追加 → tails=[2,5]       （长度2的尾值=5）
x=3 ：3 < 5，替换 → tails=[2,3]       （长度2的尾值从5降到3，更优）
x=7 ：7 > 3，追加 → tails=[2,3,7]     （长度3的尾值=7）
x=101：101 > 7，追加 → tails=[2,3,7,101]（长度4的尾值=101）
x=18 ：18 < 101，替换 → tails=[2,3,7,18]（长度4的尾值从101降到18）

最终 len(tails) = 4 → LIS 长度 = 4 ✓
```

**关键点**：`tails` 数组本身**不一定是**真正的 LIS（例子里 `[2,3,7,18]` 恰好是，但有时不是），但它的**长度**一定等于 LIS 长度。这是因为 `tails` 始终保持严格递增（替换不会破坏有序性），且每次追加都对应一次「找到更长的递增序列」。

- 时间 \(O(n \log n)\)：每个元素一次二分，二分 \(O(\log n)\)
- 空间 \(O(n)\)

> **严格递增的保证**：二分找的是「第一个 ≥ x 的位置」（`lower_bound`），不是「第一个 > x 的位置」。这保证相等元素会替换到同一位置，不会错误地追加——比如 `[2,2]`，第二个 2 替换第一个 2，`tails` 仍是 `[2]`，长度 1，正确。如果要的是**非递减**（允许相等），改成找「第一个 > x 的位置」（`upper_bound`）即可。

## 代码

### 解法一：动态规划（\(O(n^2)\)）

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];
        int ans = 1;
        
        for (int i = 0; i < n; i++) {
            dp[i] = 1;                              // 至少自己一个字符
            for (int j = 0; j < i; j++) {            // 扫前面所有更小的位置
                if (nums[j] < nums[i]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            ans = Math.max(ans, dp[i]);              // 全局取 max
        }
        return ans;
    }
}
```

- 外层枚举 i，内层扫 `[0, i)` 找所有 `nums[j] < nums[i]` 的位置取最大 `dp[j] + 1`
- `n = 2500` 时 \(n^2 = 6.25 \times 10^6\)，LeetCode 可过

### 解法二：贪心 + 二分（\(O(n\log n)\)，进阶）

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        // tails[k] = 长度为 k+1 的递增子序列的最小可能尾值
        int[] tails = new int[nums.length];
        int len = 0;                                 // tails 的有效长度
        
        for (int x : nums) {
            // 二分：找第一个 >= x 的位置（lower_bound，保证严格递增）
            int lo = 0, hi = len;                    // 搜索范围 [0, len)
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if (tails[mid] < x) lo = mid + 1;
                else hi = mid;
            }
            // lo == hi == 「第一个 >= x 的位置」或 == len（x 比所有都大）
            if (lo == len) {
                tails[len++] = x;                   // 追加：x 比所有尾值都大，LIS 又长一格
            } else {
                tails[lo] = x;                      // 替换：把该长度的尾值降到 x
            }
        }
        return len;
    }
}
```

- `tails` 始终严格递增：替换用的是 `lower_bound`（第一个 ≥ x），不会把相等的数追加到末尾
- **`lo == len` 的含义**：二分范围是 `[0, len)`，如果 `x` 比所有尾值都大，`lo` 会走到 `len`（越界），此时走追加分支
- 返回 `len` 而非 `tails`——`tails` 不是真正的 LIS，但长度正确

### 6. 同源题族：「LIS 模板」的迁移

| 题目 | 变化点 | 迁移要点 |
|:---|:---|:---|
| 354. 俄罗斯套娃信封问题 | 一维 → 二维 | 先按宽度升序、高度降序排，再对高度做一维 LIS |
| 673. 最长递增子序列的个数 | 问个数 | DP 同时记 `length[i]` 和 `count[i]` 两个状态 |
| 1671. 得到山形数组的最少删除次数 | 双向 LIS | 从左和从右各做一次 LIS，拼山形 |
| 1964. 俄式套娃（二维 LIS） | 同 354 | 同上，排序后一维化 |

> 记忆：**LIS = DP \(O(n^2)\)：以 i 结尾，扫前面更小的 j 取 max + 1；进阶贪心 + 二分 \(O(n\log n)\)：维护 tails 最小尾值数组，追加或替换，长度即答案；严格递增用 lower_bound，非递减用 upper_bound。**
