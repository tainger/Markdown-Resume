## 题目描述

给你一个由若干括号和字母组成的字符串 `s` ，删除最小数量的无效括号，使得输入的字符串有效。

返回所有可能的结果。答案可以按 **任意顺序** 返回。

---

## 示例

**示例 1**

```
输入：s = "()())()"
输出：["(())()","()()()"]
```

**示例 2**

```
输入：s = "(a)())()"
输出：["(a())()","(a)()()"]
```

**示例 3**

```
输入：s = ")("
输出：[""]
```

## 提示

- `1 <= s.length <= 25`
- `s` 由小写英文字母以及括号 `'('` 和 `')'` 组成
- 输入的字符串中至多含 `20` 个括号

## 思路

关键词是「删除**最小数量**」+「返回**所有**结果」——要的是所有**删得最少**的合法方案。这两点决定了两种典型思路：BFS 按层保证「最少」，回溯先算「删几个」再精确枚举。

### 如何判断括号串有效

一趟扫描，`(` 计数 +1、`)` 计数 -1，过程中计数**不能为负**（`)` 不能比 `(` 先出现太多），结束时计数**恰好为 0**。字母忽略。

### 解法一：BFS 逐层删一个（最直观，天然保证「最少」）

把「当前字符串」当作图的节点，一次删除**一个**括号得到下一层。逐层扩展：

1. 从 `s` 出发，检查这一层里**是否有合法串**；
2. 若有，这一层的所有合法串就是答案（因为 BFS 是按「删除个数」逐层推进，**第一次出现合法串的层删得最少**），直接返回，不再往下删；
3. 若无，把这一层每个串各删一个括号生成下一层（**用 Set 去重**），继续。

- 时间复杂度：最坏 \(O(2^n \times n)\)，每层组合爆炸
- 空间复杂度：\(O(2^n)\) 存每层状态
- 优点：**逻辑最直观**，天然保证最少；缺点：不去重会指数级重复

> BFS 的「层」= 删除的括号个数，第一层找到合法解就停，保证了「最小数量」。

### 解法二：回溯（先算要删的数量，再精确删除，推荐）

BFS 会生成大量无效状态。更高效的做法是**先算出到底要删几个左括号、几个右括号**，再回溯精确枚举：

1. **预计算**：扫一遍求出必须删除的左括号数 `lremove`、右括号数 `rremove`：
   - 遇 `(`，`lremove++`；
   - 遇 `)`，若 `lremove>0` 则 `lremove--`（和前面的 `(` 抵消），否则 `rremove++`（这个 `)` 多余必删）。
   - 最终 `lremove`、`rremove` 就是最少删除数。
2. **回溯**：对每个括号选择「删」或「不删」，但只在**还有配额**时删；同时**跳过连续相同括号的重复删除**去重（同一段连续 `(` 里删第 1 个和删第 2 个结果一样）；
3. 当 `lremove==0 && rremove==0` 时，检查剩余串是否有效，有效则收集。

- 时间复杂度：\(O(2^n)\)，但配额剪枝后实际远小于此
- 空间复杂度：\(O(n)\) 递归栈

## 代码

### 解法一：BFS 逐层删一个（推荐入门）

```java
class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> ans = new ArrayList<>();
        Set<String> level = new HashSet<>();
        level.add(s);

        while (!level.isEmpty()) {
            // 检查当前层是否有合法串
            for (String str : level) {
                if (isValid(str)) ans.add(str);
            }
            if (!ans.isEmpty()) return ans;    // 本层有解 → 删得最少，直接返回

            // 生成下一层：每个串各删一个括号
            Set<String> next = new HashSet<>();
            for (String str : level) {
                for (int i = 0; i < str.length(); i++) {
                    char c = str.charAt(i);
                    if (c != '(' && c != ')') continue;         // 只删括号
                    next.add(str.substring(0, i) + str.substring(i + 1));  // Set 去重
                }
            }
            level = next;
        }
        return ans;
    }

    private boolean isValid(String str) {
        int cnt = 0;
        for (char c : str.toCharArray()) {
            if (c == '(') cnt++;
            else if (c == ')') {
                cnt--;
                if (cnt < 0) return false;     // ) 多了
            }
        }
        return cnt == 0;
    }
}
```

### 解法二：回溯 + 预计算删除数（高效，推荐）

```java
class Solution {
    private List<String> ans = new ArrayList<>();

    public List<String> removeInvalidParentheses(String s) {
        // 1) 预计算必须删除的左、右括号数
        int lremove = 0, rremove = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                lremove++;
            } else if (c == ')') {
                if (lremove > 0) lremove--;    // 与前面的 ( 抵消
                else rremove++;                // 多余的 )
            }
        }
        // 2) 回溯
        backtrack(s, 0, lremove, rremove, new StringBuilder());
        return ans;
    }

    private void backtrack(String s, int i, int lremove, int rremove, StringBuilder path) {
        if (i == s.length()) {
            if (lremove == 0 && rremove == 0 && isValid(path.toString())) {
                ans.add(path.toString());
            }
            return;
        }
        char c = s.charAt(i);

        // 分支一：删除当前括号（需有配额；去重见下）
        if ((c == '(' && lremove > 0) || (c == ')' && rremove > 0)) {
            // 去重：一段连续相同括号只在「第一个」位置执行删除，避免删第1个/第2个产生相同结果
            if (i == 0 || s.charAt(i - 1) != c) {
                backtrack(s, i + 1,
                          c == '(' ? lremove - 1 : lremove,
                          c == ')' ? rremove - 1 : rremove,
                          path);
            }
        }

        // 分支二：保留当前字符（字母一定走这条；括号在无配额或去重时也走这条）
        path.append(c);
        backtrack(s, i + 1, lremove, rremove, path);
        path.deleteCharAt(path.length() - 1);   // 回溯撤销
    }

    private boolean isValid(String str) {
        int cnt = 0;
        for (char c : str.toCharArray()) {
            if (c == '(') cnt++;
            else if (c == ')' && --cnt < 0) return false;
        }
        return cnt == 0;
    }
}
```

> 去重核心是 `if (i == 0 || s.charAt(i - 1) != c)`——**对连续相同的括号，只允许在「第一个」位置执行删除分支**，避免「删第 1 个」和「删第 2 个」产生同样结果。

## 个人总结

### 1. 题眼：删「最少」+ 返回「所有」→ BFS 保最少 / 回溯先算数

- **BFS**：层数 = 删除个数，第一次某层出现合法串就返回，天然保证「最少」，最直观；
- **回溯**：先扫一遍算出该删几个左、几个右括号，再带配额精确枚举，避免生成海量无效中间态，更高效。

两种都要会：BFS 讲思路清晰，回溯讲效率漂亮。

### 2. 判断括号有效：计数不能为负 + 结尾归零

`(` +1、`)` -1，**过程中一旦为负立即失败**（右括号超前），结束必须等于 0。这个 `isValid` 是所有括号题的基础工具（[20](20.有效的括号.md)、[32](32.%20最长有效括号.md) 都用它）。

### 3. 预计算删除数：一次扫描定「删几个」

- 左括号先累加到 `lremove`（视作待匹配）；
- 右括号优先和 `lremove` 抵消，抵消不掉的是「多余右括号」计入 `rremove`；
- 扫完剩下的 `lremove`（没配对的左括号）和 `rremove` 之和，就是**最少删除总数**。这一步把「删最少」从搜索目标变成了已知配额，是回溯高效的前提。

### 4. 去重是本题最大难点

同一段连续相同括号（如 `((((`）里，删哪一个结果都一样。**规则：连续相同括号只在第一个位置执行「删除」分支**（`i>0 && s[i-1]==c` 时不再单独删）。漏掉去重会产生大量重复答案。BFS 版则靠 `HashSet` 天然去重，更省心。

### 5. 回溯的「删/留」二选一 + 配额剪枝

每个括号有「删」和「留」两条分支，但「删」只在还有对应配额（`lremove>0` 或 `rremove>0`）时才走。到达串尾时 `lremove==rremove==0` 且 `isValid` 才是合法的最少删除方案。**配额把指数搜索大幅剪枝**。
