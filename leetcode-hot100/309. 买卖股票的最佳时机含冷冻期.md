## 题目描述

给定一个整数数组 `prices`，其中第 `prices[i]` 表示第 `i` 天的股票价格 。​

设计一个算法计算出最大利润。在满足以下约束条件下，你可以尽可能地完成更多的交易（多次买卖一支股票）：

- 卖出股票后，你无法在第二天买入股票（即冷冻期为 1 天）。

**注意**：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

---

## 示例

**示例 1**

```
输入：prices = [1,2,3,0,2]
输出：3
解释：对应的交易状态为: [买入, 卖出, 冷冻期, 买入, 卖出]，利润 = (2-1) + (2-0) = 3
```

**示例 2**

```
输入：prices = [1]
输出：0
```

## 思路

### 核心：每天处于三种状态之一

普通买卖股票只有「持股 / 不持股」两态，本题因为**卖出后要冷冻 1 天**，把「不持股」细分成两种，共**三个状态**：

- **状态 0 持股中**：手上有股票（今天可能刚买，也可能之前买的）
- **状态 1 不持股且不在冷冻期**：手上没股票，且今天**可以买**（昨天不是刚卖出）
- **状态 2 冷冻期**：今天**刚卖出**，明天不能买

状态转移（今天由昨天哪个状态转来）：

```
持股[i]   = max( 持股[i-1],           不持股可买[i-1] - prices[i] )   保持持股 / 今天买入
可买[i]   = max( 可买[i-1],           冷冻[i-1] )                    保持空仓 / 冷冻期结束
冷冻[i]   = 持股[i-1] + prices[i]                                    今天卖出
```

- 初始：第 0 天 `持股 = -prices[0]`（买了）、`可买 = 0`、`冷冻 = 0`
- 答案：最后一天 `max(可买, 冷冻)`（不持股利润一定 ≥ 持股，故不必看持股）

```
prices = [1,2,3,0,2]
天  持股         可买        冷冻
0   -1           0          0
1   max(-1,-1)=-1 max(0,0)=0  -1+2=1
2   max(-1,0-3)=-1 max(0,1)=1  -1+3=2
3   max(-1,1-0)=1  max(1,2)=2  -1+0=-1
4   max(1,2-2)=1   max(2,-1)=2 1+2=3   → max(可买2,冷冻3)=3 ✅
```

### 关键陷阱

1. **冷冻期只锁「买入」，不锁「卖出」**：卖出当天进入「冷冻」，只是**下一天不能买**，当天卖出本身是允许的。
2. **「可买」由「冷冻」转来**：只有昨天是冷冻状态，今天才解冻能买；直接 `可买[i-1]` 保持空仓也行，取 max。
3. **答案取不持股的两态最大**：结尾还持股说明没卖出，利润必不优，只看 `max(可买, 冷冻)`。

### 解法一：回溯（暴力枚举，理解入口）

按「第 `i` 天，当前是否持股、是否处于冷冻」递归枚举每天「买 / 卖 / 不操作」，返回能获得的最大利润。

- 时间复杂度：最坏 \(O(2^n)\)（每天分叉），指数级
- 空间复杂度：\(O(n)\) 递归栈
- `n ≤ 5000` 时**必然 TLE**，仅用于理清「状态 + 每天可选操作」

> 瓶颈：`(第 i 天, 持股状态)` 的组合会被不同操作序列**反复递归到**——重叠子问题，加缓存即记忆化。

### 解法二：记忆化搜索（自顶向下 + 缓存）

状态由 `(天数 i, 持股标志 hold)` 唯一决定，用 `memo[i][hold]` 缓存。为处理冷冻，递归时「卖出」后直接跳到 `i+2`（隔过冷冻天）：

- `dfs(i, 持股)`：可「卖出」→ `prices[i] + dfs(i+2, 不持股)`（跳过冷冻），或「不操作」→ `dfs(i+1, 持股)`
- `dfs(i, 不持股)`：可「买入」→ `-prices[i] + dfs(i+1, 持股)`，或「不操作」→ `dfs(i+1, 不持股)`

- 时间复杂度：\(O(n)\)，状态数 `O(n)`，每个 O(1) 转移
- 空间复杂度：\(O(n)\)

### 解法三：状态机 DP（自底向上，推荐）

用上面三状态转移递推，`dp[i][0/1/2]`。因为每天只依赖前一天，可**滚动成三个变量** \(O(1)\) 空间。

- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(1)\)（滚动变量）

## 代码

### 解法一：回溯（会 TLE，理解入口）

```java
class Solution {
    private int[] prices;

    public int maxProfit(int[] prices) {
        this.prices = prices;
        return dfs(0, false);                  // 从第 0 天、不持股开始
    }

    // i：第几天；hold：当前是否持股。返回从这天起能获得的最大利润
    private int dfs(int i, boolean hold) {
        if (i >= prices.length) return 0;      // 越界，无利润
        int doNothing = dfs(i + 1, hold);      // 今天不操作
        if (hold) {
            int sell = prices[i] + dfs(i + 2, false);  // 卖出 → 跳过冷冻天 i+1
            return Math.max(doNothing, sell);
        } else {
            int buy = -prices[i] + dfs(i + 1, true);   // 买入
            return Math.max(doNothing, buy);
        }
    }
}
```

### 解法二：记忆化搜索（自顶向下 + 缓存）

```java
class Solution {
    private int[] prices;
    private Integer[][] memo;                  // memo[i][hold]

    public int maxProfit(int[] prices) {
        this.prices = prices;
        memo = new Integer[prices.length + 2][2];
        return dfs(0, 0);                       // 0 = 不持股
    }

    private int dfs(int i, int hold) {
        if (i >= prices.length) return 0;
        if (memo[i][hold] != null) return memo[i][hold];

        int doNothing = dfs(i + 1, hold);
        int res;
        if (hold == 1) {
            int sell = prices[i] + dfs(i + 2, 0);      // 卖出后跳过冷冻天
            res = Math.max(doNothing, sell);
        } else {
            int buy = -prices[i] + dfs(i + 1, 1);      // 买入
            res = Math.max(doNothing, buy);
        }
        return memo[i][hold] = res;
    }
}
```

### 解法三：状态机 DP（推荐，可滚动到 O(1) 空间）

```java
class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        // 三状态：0 持股，1 不持股可买，2 冷冻期（今天刚卖出）
        int hold = -prices[0];                 // 第 0 天买入
        int canBuy = 0;                        // 第 0 天空仓
        int cooldown = 0;                      // 第 0 天不可能刚卖出

        for (int i = 1; i < n; i++) {
            int newHold = Math.max(hold, canBuy - prices[i]);   // 保持持股 / 今天买入
            int newCanBuy = Math.max(canBuy, cooldown);         // 保持空仓 / 冷冻结束
            int newCooldown = hold + prices[i];                 // 今天卖出
            hold = newHold;
            canBuy = newCanBuy;
            cooldown = newCooldown;
        }
        return Math.max(canBuy, cooldown);     // 结尾不持股利润最优
    }
}
```

## 个人总结

### 1. 「卖出后有冷冻期」→ 把不持股拆成两态，做状态机 DP

普通股票买卖是「持股 / 不持股」两态；本题冷冻期约束逼着把「不持股」拆成「**可买**」和「**刚卖出（冷冻）**」两个状态。**看到「操作后有约束/延迟（冷冻、手续费、次数上限）」，就想在状态维度里加一维，画状态转移图**。这是股票系列题的通用套路。

### 2. 从回溯到记忆化到 DP 的完整演进

| 解法 | 复杂度 | 关键 |
|:---|:---:|:---|
| 回溯 | \(O(2^n)\) | 每天枚举买/卖/不操作，TLE |
| 记忆化搜索 | \(O(n)\) | `memo[i][hold]` 缓存，卖出跳 `i+2` 处理冷冻 |
| 状态机 DP | \(O(n)\)，空间 \(O(1)\) | 三状态滚动递推，最优 |

依旧是 DP 三部曲：暴力递归找状态与转移 → 加缓存去重叠 → 翻成自底向上、再滚动压空间。这套路和 [322 零钱兑换](322.%20零钱兑换.md) 一模一样。

### 3. 冷冻期在两种解法里的不同表达

- **记忆化/回溯**：卖出后 `dfs(i+2, ...)`，用「**跳一天**」体现冷冻；
- **状态机 DP**：新增「冷冻」状态，且「可买」只能由「冷冻」或「上一天可买」转来——用**状态转移**体现冷冻。

两者等价，理解其一即可，DP 版更利于压到 \(O(1)\) 空间。

### 4. 三条转移方程别写混

- `持股 = max(昨持股, 昨可买 - price)`：要么一直拿着，要么今天花钱买；
- `可买 = max(昨可买, 昨冷冻)`：要么继续空仓，要么昨天冷冻今天解冻；
- `冷冻 = 昨持股 + price`：今天把手里的卖了。

关键点：**买入只能发生在「可买」状态**（保证不是刚卖完的次日），这正是冷冻期的约束落点。

### 5. 初始化与答案

- 第 0 天：`持股 = -prices[0]`、`可买 = 0`、`冷冻 = 0`；
- 答案取最后一天 `max(可买, 冷冻)`——结尾若还持股，等于没兑现利润，一定不优。
