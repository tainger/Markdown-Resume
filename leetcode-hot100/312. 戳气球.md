## 题目描述

有 `n` 个气球，编号为 `0` 到 `n - 1`，每个气球上都标有一个数字，这些数字存在数组 `nums` 中。

现在要求你戳破所有的气球。戳破第 `i` 个气球，你可以获得 `nums[i - 1] * nums[i] * nums[i + 1]` 枚硬币。这里的 `i - 1` 和 `i + 1` 代表和 `i` 相邻的两个气球的序号。如果 `i - 1` 或 `i + 1` 超出了数组的边界，那么就当它是一个数字为 `1` 的气球。

求所能获得硬币的最大数量。

## 示例

**示例 1**

```
输入：nums = [3,1,5,8]
输出：167
解释：

coins =  3*1*5    +   3*5*8   +  1*3*8  + 1*8*1 = 167
```

## 思路

### 为什么「正向枚举先戳哪个」行不通

如果按「先戳哪个」来想，戳破一个气球后，它左右的气球**变成相邻**，后续每个气球的相邻关系都在动态变化——状态无法固定，子问题互相纠缠，没法拆分。

### 反向思维：枚举区间内「最后」戳破的气球

换个角度：假设开区间 `(i, j)` 内**最后**一个被戳破的气球是 `k`（`i < k < j`）。既然 `k` 是最后戳的，戳它时 `(i,k)` 和 `(k,j)` 里的气球都已戳完，`k` 的左右邻居就是**边界 `i` 和 `j`**（固定不变！）。得分：

```
nums[i] * nums[k] * nums[j]
```

这一步把「变动的相邻关系」钉死成「固定的区间边界」，子问题就能独立拆分了。

### 预处理：两端补 1

在 `nums` 两端各加一个值为 `1` 的虚拟气球，得到 `val`，长度 `n+2`。这样原始的「越界当作 1」自然融入边界，且所有真实气球都落在开区间 `(0, n+1)` 内部。

### 状态定义与转移

`dp[i][j]` = 戳破**开区间 `(i, j)`** 内所有气球能获得的最大硬币（不含 `i`、`j` 本身）。

枚举区间内最后戳破的 `k`：

```
dp[i][j] = max over k in (i, j) of {
    dp[i][k]                    // 先戳完左半开区间 (i,k)
  + dp[k][j]                    // 再戳完右半开区间 (k,j)
  + val[i] * val[k] * val[j]    // 最后戳 k，此时左右邻居是固定边界 i、j
}
```

- 边界：区间长度 `< 2`（即 `j <= i+1`，中间无气球）时 `dp[i][j] = 0`
- 答案：`dp[0][n+1]`
- 遍历顺序：区间 DP 要**从小区间到大区间**（`i` 从大到小、`j` 从小到大），保证 `dp[i][k]`、`dp[k][j]` 已算好

- 时间复杂度：\(O(n^3)\)，\(O(n^2)\) 个区间 × 每个枚举 \(O(n)\) 个 `k`
- 空间复杂度：\(O(n^2)\)

## 代码

### 解法一：记忆化搜索（自顶向下，最好想）

```java
class Solution {
    private int[] val;
    private int[][] memo;

    public int maxCoins(int[] nums) {
        int n = nums.length;
        val = new int[n + 2];
        val[0] = val[n + 1] = 1;                 // 两端虚拟气球，值为 1
        for (int i = 1; i <= n; i++) val[i] = nums[i - 1];
        memo = new int[n + 2][n + 2];
        for (int[] row : memo) Arrays.fill(row, -1);
        return dfs(0, n + 1);
    }

    // 戳破开区间 (i, j) 内所有气球的最大硬币
    private int dfs(int i, int j) {
        if (j - i < 2) return 0;                 // 区间内无气球
        if (memo[i][j] != -1) return memo[i][j];
        int best = 0;
        for (int k = i + 1; k < j; k++) {        // 枚举最后戳破的气球 k
            int coins = val[i] * val[k] * val[j] // 最后戳 k，邻居是边界 i、j
                      + dfs(i, k) + dfs(k, j);   // 左右两半子区间
            best = Math.max(best, coins);
        }
        memo[i][j] = best;
        return best;
    }
}
```

### 解法二：区间 DP（自底向上，从小区间到大区间）

```java
class Solution {
    public int maxCoins(int[] nums) {
        int n = nums.length;
        int[] val = new int[n + 2];
        val[0] = val[n + 1] = 1;
        for (int i = 1; i <= n; i++) val[i] = nums[i - 1];

        int[][] dp = new int[n + 2][n + 2];
        // i 从大到小、j 从小到大：保证内层小区间先算好
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i + 2; j <= n + 1; j++) {     // j >= i+2 才有中间气球
                for (int k = i + 1; k < j; k++) {      // 最后戳破 k
                    int coins = val[i] * val[k] * val[j]
                              + dp[i][k] + dp[k][j];
                    dp[i][j] = Math.max(dp[i][j], coins);
                }
            }
        }
        return dp[0][n + 1];
    }
}
```

## 个人总结

### 1. 题眼：相邻关系动态变化 → 反向枚举「最后」操作的元素

正向想「先戳哪个」会让剩余气球的相邻关系不断变化，子问题无法独立。**反向枚举「区间内最后戳破的 `k`」**：既然 `k` 最后戳，它左右两半早已戳空，邻居恰好是**固定的区间边界** `i`、`j`——把动态相邻钉成静态边界，这是本题（也是一类区间 DP）的灵魂。**「操作会改变相邻结构」的最优化题，常考虑倒着定义最后一步。**

### 2. 两端补 1 消除边界特判

在 `nums` 两端补虚拟气球 `1`，把「越界当 1」自然融进数组，所有真实气球都在开区间 `(0, n+1)` 内。省掉一堆 `i-1<0`、`i+1>=n` 的判断，代码干净很多。

### 3. `dp[i][j]` 是「开区间」，不含端点

`dp[i][j]` 表示戳破 `(i, j)` **内部**气球（不含 `i`、`j`）的最大硬币，端点只作边界乘数、不被戳破。这样 `dp[i][k] + dp[k][j]` 拼接时不重不漏——`k` 由当前层的 `val[i]*val[k]*val[j]` 负责，两个子区间各自开区间、互不重叠。

### 4. 区间 DP 的遍历顺序：小区间先于大区间

转移依赖更短的子区间 `dp[i][k]`、`dp[k][j]`，所以必须先算短区间。写法上要么**`i` 从大到小 + `j` 从小到大**（本题），要么**按区间长度 `len` 从小到大**外层枚举。顺序错了会读到未初始化的 0。

### 5. 记忆化 vs 递推

两者复杂度同为 \(O(n^3)\)。记忆化按「开区间」自然递归，最贴合思路、最好写；递推需想清遍历顺序但常数更小。**先用记忆化理清转移，再翻译成递推**——和你整理的 [动态规划.md](../算法思想/动态规划.md) 里「记忆化搜索 → 递推」的路径一致。
