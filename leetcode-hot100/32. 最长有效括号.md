## 题目描述

给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

---

## 示例

**示例 1**

```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

**示例 2**

```
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

**示例 3**

```
输入：s = ""
输出：0
```

---

## 提示

- `0 <= s.length <= 3 * 10^4`
- `s[i]` 为 `'('` 或 `')'`

---

## 思路

注意题目要的是**连续子串**（不是子序列），所以不能只数配对数量，还要保证这些配对**首尾相连**。这是本题比「判断括号是否有效」（[20 题](20.有效的括号.md)）难的地方。

### 解法一：暴力枚举所有子串（理解入口）

枚举每个偶数长度的子串，用一个计数器/栈判断它是否合法，记录最长的合法长度。

- 时间复杂度：\(O(n^2)\) 枚举子串 × \(O(n)\) 校验 = \(O(n^3)\)，优化校验后 \(O(n^2)\)
- 空间复杂度：\(O(n)\)（校验用栈）
- `n ≤ 3×10^4` 时 \(O(n^2)\) 约 `9×10^8`，**大概率 TLE**，仅用于理解题意

> 瓶颈：合法性判断在相邻子串间高度重复。下面三种 \(O(n)\) 解各用不同手段消除重复。

### 解法二：栈存「下标」（最好想的 O(n)，推荐）

和 [20 题](20.有效的括号.md) 一样用栈，但**栈里存下标而非字符**，用来算「当前合法段的长度」。技巧：**栈底垫一个 `-1` 作为「上一个未匹配位置」的哨兵**。

- 遍历，遇 `(` → 下标入栈；
- 遇 `)` → 先弹栈顶：
  - 若弹完栈**空**了，说明这个 `)` 没人匹配，它成为新的「未匹配边界」，把**当前下标入栈**当哨兵；
  - 若弹完栈**非空**，当前合法长度 = `i - 栈顶`（栈顶是这段合法串左边第一个未匹配位置）

```
s = ")()())"     栈初始 [-1]
i=0 ')' 弹出-1→空, 压入0        栈[0]
i=1 '(' 压入1                  栈[0,1]
i=2 ')' 弹出1→栈[0], len=2-0=2  栈[0]
i=3 '(' 压入3                  栈[0,3]
i=4 ')' 弹出3→栈[0], len=4-0=4  栈[0]  ← 最长4
i=5 ')' 弹出0→空, 压入5         栈[5]
→ 答案 4
```

- 时间复杂度：\(O(n)\)，每个字符进出栈一次
- 空间复杂度：\(O(n)\) 栈

### 解法三：动态规划

`dp[i]` = **以 `s[i]` 结尾**的最长有效括号长度（`s[i]='('` 时必为 0，因为不可能以 `(` 结尾）。只在 `s[i]=')'` 时转移，看它跟谁配对：

- **`s[i-1]=='('`**（形如 `...()`）：`dp[i] = dp[i-2] + 2`
- **`s[i-1]==')'`**（形如 `...))`）：设 `dp[i-1]` 那段合法串左边一位 `j = i - dp[i-1] - 1`，若 `s[j]=='('`（能和 `s[i]` 配对），则 `dp[i] = dp[i-1] + 2 + dp[j-1]`（还要接上 `j` 前面的合法段）

```
s = "()(())"
dp:  0 2 0 0 2 6
i=1: () → dp[1]=dp[-1]+2=2
i=4: () → dp[4]=dp[2]+2=2
i=5: )) 型, j=5-2-1=2, s[2]='(' → dp[5]=dp[4]+2+dp[1]=2+2+2=6
→ 答案 6
```

- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(n)\)

### 解法四：双向计数（O(1) 空间，最巧）

用两个计数器 `left`、`right` 统计左右括号数，正反各扫一遍：

- **从左到右**：遇 `(` 则 `left++`，遇 `)` 则 `right++`；当 `left==right` 时更新答案 `2*right`；当 `right>left`（右括号多了，不可能再补救）时把两者清零。
- **从右到左**：对称处理，改为当 `left>right` 时清零——解决「从左扫时 `left` 始终 > `right`（如 `(()`）永远触发不了相等」的漏网情况。

- 时间复杂度：\(O(n)\)，两趟
- 空间复杂度：\(O(1)\) ✅（唯一不用栈/数组的解法）

## 代码

### 解法一：暴力枚举所有子串（会 TLE，理解入口）

```java
class Solution {
    public int longestValidParentheses(String s) {
        int n = s.length(), max = 0;
        for (int i = 0; i < n; i++) {              // 枚举左端点
            for (int j = i + 1; j < n; j += 2) {   // 右端点，合法子串长度必为偶数
                if (isValid(s, i, j)) {
                    max = Math.max(max, j - i + 1);
                }
            }
        }
        return max;
    }

    // 用计数器判断 s[lo..hi] 是否为合法括号串
    private boolean isValid(String s, int lo, int hi) {
        int balance = 0;                           // 左括号未匹配数
        for (int k = lo; k <= hi; k++) {
            if (s.charAt(k) == '(') balance++;
            else balance--;
            if (balance < 0) return false;         // ) 多了，提前失败
        }
        return balance == 0;                       // 恰好全部配对
    }
}
```

### 解法二：栈存下标（推荐，最好想）

```java
class Solution {
    public int longestValidParentheses(String s) {
        int max = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1);                            // 哨兵：上一个未匹配位置

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);                     // 左括号下标入栈
            } else {
                stack.pop();                       // 尝试匹配一个左括号
                if (stack.isEmpty()) {
                    stack.push(i);                 // 没得配 → 当前 ) 成为新边界
                } else {
                    max = Math.max(max, i - stack.peek());  // 合法长度 = i - 栈顶
                }
            }
        }
        return max;
    }
}
```

### 解法三：动态规划

```java
class Solution {
    public int longestValidParentheses(String s) {
        int n = s.length(), max = 0;
        int[] dp = new int[n];                     // dp[i]：以 s[i] 结尾的最长有效长度
        for (int i = 1; i < n; i++) {
            if (s.charAt(i) == ')') {              // 只有 ) 结尾才可能有效
                if (s.charAt(i - 1) == '(') {      // 形如 ...()
                    dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
                } else {                           // 形如 ...))
                    int j = i - dp[i - 1] - 1;     // 与 s[i] 可能配对的位置
                    if (j >= 0 && s.charAt(j) == '(') {
                        dp[i] = dp[i - 1] + 2 + (j >= 1 ? dp[j - 1] : 0);
                    }
                }
                max = Math.max(max, dp[i]);
            }
        }
        return max;
    }
}
```

### 解法四：双向计数（O(1) 空间）

```java
class Solution {
    public int longestValidParentheses(String s) {
        int max = 0, left = 0, right = 0;
        // 从左到右
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') left++; else right++;
            if (left == right) max = Math.max(max, 2 * right);
            else if (right > left) left = right = 0;   // 右多了，清零重来
        }
        // 从右到左（解决 left 永远 > right 的情况，如 "(()"）
        left = right = 0;
        for (int i = s.length() - 1; i >= 0; i--) {
            if (s.charAt(i) == '(') left++; else right++;
            if (left == right) max = Math.max(max, 2 * left);
            else if (left > right) left = right = 0;    // 左多了，清零重来
        }
        return max;
    }
}
```

## 个人总结

### 1. 关键区别：要的是「连续子串」不是「配对数量」

[20 题](20.有效的括号.md) 只判断整串是否合法，本题要在**可能非法的串里找最长的连续合法段**。所以不能只数配对数，必须记住合法段的**边界/长度**——这正是「栈存下标」和「dp 记以 i 结尾的长度」两种解法的出发点。

### 2. 栈存「下标」而非「字符」是本题精髓

普通括号题栈存字符即可；这里存下标才能算长度 `i - 栈顶`。**栈底哨兵 `-1`** 是灵魂：它代表「当前合法段左边第一个未匹配位置」，弹空后压入当前下标来更新这个边界。想不清就套上面的走位表。

### 3. 四种解法各消除了什么重复

| 解法 | 复杂度 | 空间 | 核心手段 |
|:---|:---:|:---:|:---|
| 暴力 | \(O(n^2)\) | \(O(n)\) | 无优化，TLE |
| 栈存下标 | \(O(n)\) | \(O(n)\) | 下标算长度 + `-1` 哨兵 |
| 动态规划 | \(O(n)\) | \(O(n)\) | `dp[i]` 记以 i 结尾长度 |
| 双向计数 | \(O(n)\) | \(O(1)\) | 正反两趟计数，最省空间 |

**面试首推栈解法**（最直观），追问优化空间再上双向计数。

### 4. DP 的两种转移别漏「接上前面的合法段」

`s[i-1]==')'`（`...))`）这一支最容易错：配对成功后不仅 `+2`，还要 **`+ dp[j-1]`** 把配对位置左边已有的合法段接上，否则 `()(())` 这类嵌套+并列会算短。这是 DP 解法的核心难点。

### 5. 双向计数为什么要扫两遍

只从左扫，遇到 `(()` 这种 `left` 始终 `> right`、永远触发不了 `left==right`，会漏掉答案；从右往左再扫一遍、对称地在 `left>right` 时清零，就能补上。**一个方向处理不了「某种括号一直占多数」的情形，双向覆盖**。
