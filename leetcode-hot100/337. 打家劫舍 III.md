## 题目描述

小偷又发现了一个新的可行窃的地区。这个地区只有一个入口，我们称之为 `root` 。

除了 `root` 之外，每栋房子有且只有一个「父」房子与之相连。一番侦察之后，聪明的小偷意识到「这个地方的所有房屋的排列类似于一棵二叉树」。 如果 **两个直接相连的房子在同一天晚上被打劫** ，房屋将自动报警。

给定二叉树的 `root` 。返回 **在不触动警报的情况下** ，小偷能够盗取的最高金额 。

输入：root = [3,2,3,null,3,null,1]

解释：小偷一晚能够盗取的最高金额 3 + 3 + 1 = 7（偷根 3、左子树的 3、右子树的 1）

## 思路

### 从「打家劫舍 I」到树上版本

- [198. 打家劫舍 I](198.%20打家劫舍.md)：房子排成**一排**，不能偷相邻两家；
- 337：房子排成**一棵二叉树**，不能偷「父子直接相连」的两家。

线性版本每家有「偷 / 不偷」两态，树版本一样——只是「相邻」从「数组下标 ±1」变成了「父子边」。核心约束：**偷了某节点，就不能偷它的直接孩子**。

### 核心思想：每个节点返回「偷它」和「不偷它」两个最大收益

对任意节点 `node`，从它这棵子树能拿到的最大金额，取决于「偷不偷 `node`」：

- **偷 `node`**：则左右孩子都**不能偷**。收益 = `node.val + 左孩子不偷 + 右孩子不偷`
- **不偷 `node`**：左右孩子**偷不偷都行，各取最大**。收益 = `max(左偷,左不偷) + max(右偷,右不偷)`

所以让 DFS 对每个节点返回一个长度 2 的数组 `[不偷node的最大值, 偷node的最大值]`，**后序遍历**（先拿到左右孩子的两个值，再算当前节点）：

```
rob(node)  = node.val + notRob(left) + notRob(right)        // 偷当前
notRob(node) = max(rob(left),notRob(left)) + max(rob(right),notRob(right)) // 不偷当前

答案 = max(rob(root), notRob(root))
```

```
     3            节点3(根): 偷=3+ (左2不偷) + (右3不偷)
    / \                    不偷=max(左2偷,不偷)+max(右3偷,不偷)
   2   3
    \   \        叶子3: [不偷=0, 偷=3]   叶子1: [不偷=0, 偷=1]
     3   1       节点2: 偷=2+0=2, 不偷=max(0,3)=3 → [3,2]
                 节点3(右): 偷=3+0=3, 不偷=max(0,1)=1 → [1,3]
     根3: 偷=3+3(左不偷)+1(右不偷)=7, 不偷=max(3,2)+max(1,3)=3+3=6 → max=7 ✅
```

### 关键陷阱

1. **必须后序**：当前节点依赖左右孩子的结果，只能「先算孩子，再算自己」。
2. **返回两个值而非一个**：只返回「以该节点为根的最大收益」会丢信息——父节点需要知道「孩子不偷时的值」才能决定自己偷不偷。这是树形 DP 的典型套路：**状态要带上「当前节点选/不选」两种维度**。
3. **答案是 `max(偷根, 不偷根)`**，不是只看偷根。

### 解法一：朴素递归（会超时，理解入口）

直接按定义递归：`rob(node)` = 「偷 node」和「不偷 node」的较大值。但「偷 node」要递归到孙子、「不偷 node」要递归到孩子，**同一个节点被重复计算多次**，指数级爆炸。

- 时间复杂度：最坏 \(O(2^n)\)（大量重复子问题），会 TLE
- 空间复杂度：\(O(h)\) 递归栈

> 瓶颈：`rob(node)` 会重复求 `rob(孙子)`——爷爷偷时算一次孙子、父亲不偷时又算一次。重叠子问题正是 DP / 记忆化的信号。

### 解法二：记忆化递归（用哈希表缓存）

用两个 `Map<TreeNode, Integer>` 分别缓存「偷该节点」「不偷该节点」的结果，重复访问直接取缓存。把指数级降到 \(O(n)\)。

- 时间复杂度：\(O(n)\)，每个节点只算一次
- 空间复杂度：\(O(n)\) 缓存 + \(O(h)\) 栈

### 解法三：树形 DP，返回两值数组（最优，推荐）

不用哈希表，让 DFS 直接返回 `int[]{不偷, 偷}`，一次后序遍历自底向上算完。这是记忆化的等价优化——把「缓存」换成「递归返回值」，更省更快。

- 时间复杂度：\(O(n)\)，每个节点访问一次
- 空间复杂度：\(O(h)\) 递归栈（`h` 为树高）

## 代码

### 解法二：记忆化递归（先跑通）

```java
class Solution {
    Map<TreeNode, Integer> rob = new HashMap<>();      // 偷该节点的最大收益
    Map<TreeNode, Integer> notRob = new HashMap<>();   // 不偷该节点的最大收益

    public int rob(TreeNode root) {
        dfs(root);
        return Math.max(getRob(root), getNotRob(root));
    }

    private void dfs(TreeNode node) {
        if (node == null) return;
        dfs(node.left);
        dfs(node.right);
        // 偷当前：孩子都不能偷
        rob.put(node, node.val + getNotRob(node.left) + getNotRob(node.right));
        // 不偷当前：孩子各取偷/不偷的较大值
        notRob.put(node, Math.max(getRob(node.left), getNotRob(node.left))
                       + Math.max(getRob(node.right), getNotRob(node.right)));
    }

    private int getRob(TreeNode node)    { return node == null ? 0 : rob.get(node); }
    private int getNotRob(TreeNode node) { return node == null ? 0 : notRob.get(node); }
}
```

### 解法三：树形 DP，返回两值数组（推荐，最优）

```java
class Solution {
    public int rob(TreeNode root) {
        int[] res = dfs(root);
        return Math.max(res[0], res[1]);               // max(不偷根, 偷根)
    }

    // 返回 {不偷 node 的最大收益, 偷 node 的最大收益}
    private int[] dfs(TreeNode node) {
        if (node == null) return new int[]{0, 0};
        int[] left = dfs(node.left);                   // 后序：先算左右孩子
        int[] right = dfs(node.right);

        int rob = node.val + left[0] + right[0];       // 偷当前 → 孩子都不偷
        int notRob = Math.max(left[0], left[1])        // 不偷当前 → 孩子各取较大
                   + Math.max(right[0], right[1]);
        return new int[]{notRob, rob};
    }
}
```

## 个人总结

### 1. 树形 DP 的标志：每个节点带「选 / 不选」两个状态

从 [打家劫舍 I](198.%20打家劫舍.md) 的线性 DP `dp[i][0/1]` 迁移过来——线性是「按下标推进」，树上是「按后序递归」，但**每个节点仍是「选它 / 不选它」两态**这一点不变。看到「树 + 相邻不能同时选（父子约束）」，就想「DFS 返回 `[不选, 选]` 两个值」。

### 2. 为什么必须返回两个值，不能只返回一个

如果 `dfs(node)` 只返回「以 node 为根的最大收益」，父节点就无法知道「node 不偷时的值」——而父节点偷时恰恰需要这个值。**把「当前节点选/不选」拆成两个返回值，是树形 DP 携带足够信息给父节点的关键**。这类「返回多状态」的套路在树上问题里非常常见（如求直径、最大路径和）。

### 3. 后序遍历是树形 DP 的天然顺序

当前节点依赖左右孩子的计算结果，所以必须**先递归孩子、再算自己**——这就是后序（左→右→根）。凡是「子树信息汇总到父节点」的树 DP，几乎都用后序。

### 4. 从朴素递归到树形 DP 的演进

| 解法 | 复杂度 | 关键 |
|:---|:---:|:---|
| 朴素递归 | \(O(2^n)\) | 重复计算孙子层，TLE |
| 记忆化递归 | \(O(n)\) | 两个 Map 缓存偷/不偷 |
| 树形 DP 返回两值 | \(O(n)\) | 用返回值代替缓存，最省 |

三者本质都是「消除重叠子问题」。记忆化是「自顶向下 + 缓存」，树形 DP 是「自底向上 + 返回值」，后者不需要哈希表、常数更小，是本题最优写法。

### 5. 偷当前 → 孩子必不偷；不偷当前 → 孩子自由

这两条转移是全题核心，别写混：

- `rob = node.val + left[不偷] + right[不偷]`（偷了自己，孩子只能不偷）
- `notRob = max(left[偷],left[不偷]) + max(right[偷],right[不偷])`（不偷自己，孩子怎样都行，各取最大）
