# 338. 比特位计数

> **难度**：🟢 简单 | **标签**：位运算、动态规划 | **企业**：—

## 题目描述

给你一个整数 `n` ，对于 `0 <= i <= n` 中的每个 `i` ，计算其二进制表示中 **1 的个数**，返回一个长度为 `n + 1` 的数组 `ans` 作为答案。

## 示例

**示例 1**

```
输入：n = 2
输出：[0,1,1]

解释：
  0 的二进制: 0     → 1 个 1
  1 的二进制: 1     → 1 个 1
  2 的二进制: 10    → 1 个 1
```

**示例 2**

```
输入：n = 5
输出：[0,1,1,2,1,2]

解释：
  0     1     2     3     4     5
  0     1    10    11   100   101
  0     1     1     2     1     2  ← 1 的个数
```

---

## 提示

- \\(0 \\le n \\le 10^5\\)

## 进阶

- 很容易就能实现时间复杂度为 \\(O(n \\log n)\\) 的解决方案
- 你可以在线性时间复杂度 \\(O(n)\\) 内用一趟扫描解决此问题吗？
- 你能不借助任何内置函数（如 C++ 中的 `__builtin_popcount`）来解决此问题吗？

## 思路

### 核心思想

三种解法，从暴力到 DP：

```
解法                       时间          核心
────────────────────────────────────────────────
逐个数 bitCount            O(n log n)    循环调 Integer.bitCount
DP: 最低位去掉              O(n)         ans[i] = ans[i >> 1] + (i & 1)
DP: 消最低位 1              O(n)         ans[i] = ans[i & (i - 1)] + 1
```

### 解法一：逐个数 1（保底）

对每个 i 调 `Integer.bitCount(i)`，时间复杂度 \\(O(n \\log n)\\)。

### 解法二：DP — 右移 + 最低位

```
ans[i] = ans[i >> 1] + (i & 1)

i >> 1  → 去掉最低位（就是 i/2），已经算过了
i & 1   → 最低位是 0 还是 1

例：i=5 (101)
  i>>1 = 2 (10) → ans[2] = 1
  i&1  = 1
  ans[5] = 1 + 1 = 2 ✓
```

### 解法三：DP — 消最低位 1

```
ans[i] = ans[i & (i - 1)] + 1

i & (i-1) 消掉最低位的 1 → 相当于去掉了一个 1
所以 i 的 1 个数 = (去掉最末 1 后的数) 的 1 个数 + 1

例：i=5 (101)
  i & (i-1) = 101 & 100 = 100 = 4 → ans[4] = 1
  ans[5] = 1 + 1 = 2 ✓
```

### 解法一：逐个 `Integer.bitCount()`

```java
public int[] countBits(int n) {
    int[] ans = new int[n + 1];
    for (int i = 0; i <= n; i++) {
        ans[i] = Integer.bitCount(i);
    }
    return ans;
}
```

### 解法二：DP — `ans[i] = ans[i >> 1] + (i & 1)`（推荐）

```java
public int[] countBits(int n) {
    int[] ans = new int[n + 1];
    for (int i = 1; i <= n; i++) {
        // i >> 1 = i / 2，去掉最低位
        // i & 1  = 最低位是 1 就 +1
        ans[i] = ans[i >> 1] + (i & 1);
    }
    return ans;
}
```

### 解法三：DP — `ans[i] = ans[i & (i - 1)] + 1`

```java
public int[] countBits(int n) {
    int[] ans = new int[n + 1];
    for (int i = 1; i <= n; i++) {
        // i & (i-1) 消掉最低位的 1
        ans[i] = ans[i & (i - 1)] + 1;
    }
    return ans;
}
```
