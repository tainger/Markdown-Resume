## 题目描述

给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题。

---

## 示例

**示例 1**

```
输入：nums = [5,7,7,8,8,10], target = 8
输出：[3,4]
```

**示例 2**

```
输入：nums = [5,7,7,8,8,10], target = 6
输出：[-1,-1]
```

**示例 3**

```
输入：nums = [], target = 0
输出：[-1,-1]
```

---

## 提示

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `nums` 是一个非递减数组
- `-10^9 <= target <= 10^9`

---

## 思路

### 核心：`O(log n)` 要求 → 必须二分；重复元素 → 二分找「边界」

普通二分找到 `target` 就返回，但这里 `target` 可能重复出现，要的是**第一个位置**和**最后一个位置**。所以做**两次二分**：

- **左边界**：第一个 `>= target` 的位置；
- **右边界**：最后一个 `<= target` 的位置（等价于「第一个 `> target` 的位置」再 `-1`）。

找到后再校验该位置的值是否真的等于 `target`（否则说明数组里根本没有它，返回 `-1`）。

### 统一模板：找「第一个 >= target 的下标」（lower_bound）

把问题归约成一个通用函数 `lowerBound(nums, t)` = **第一个 `>= t` 的下标**（不存在则返回 `nums.length`）：

- **左边界** = `lowerBound(nums, target)`；
- **右边界** = `lowerBound(nums, target + 1) - 1`（第一个 `> target` 的下标减一）。

这样只写一个二分逻辑、调用两次，最不容易错。

```
nums = [5,7,7,8,8,10], target = 8

lowerBound(nums, 8)  = 3   （第一个 >=8 的下标 → 左边界）
lowerBound(nums, 9)  = 5   （第一个 >=9 的下标）
右边界 = 5 - 1 = 4

结果：[3, 4]
```

### 校验存在性

`left = lowerBound(target)`；若 `left == nums.length || nums[left] != target` → 数组无此元素，返回 `[-1,-1]`。否则右边界必然存在。

- 时间复杂度：\(O(\log n)\)，两次二分
- 空间复杂度：\(O(1)\)

## 代码

### 解法：统一 lowerBound 模板，调用两次（推荐）

```java
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int left = lowerBound(nums, target);        // 第一个 >= target
        // 数组里根本没有 target
        if (left == nums.length || nums[left] != target) {
            return new int[]{-1, -1};
        }
        int right = lowerBound(nums, target + 1) - 1;  // 第一个 > target 的前一位
        return new int[]{left, right};
    }

    // 返回第一个 >= t 的下标；都比 t 小则返回 nums.length
    private int lowerBound(int[] nums, int t) {
        int lo = 0, hi = nums.length;               // 左闭右开 [lo, hi)
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (nums[mid] >= t) {
                hi = mid;                           // mid 可能是答案，收缩右界（不 -1）
            } else {
                lo = mid + 1;                       // mid 太小，排除
            }
        }
        return lo;
    }
}
```

### 解法二：分别写「找左界」「找右界」两个闭区间二分

```java
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int left = findBound(nums, target, true);
        if (left == -1) return new int[]{-1, -1};
        int right = findBound(nums, target, false);
        return new int[]{left, right};
    }

    // leftmost=true 找第一个等于 target 的位置，否则找最后一个
    private int findBound(int[] nums, int target, boolean leftmost) {
        int lo = 0, hi = nums.length - 1, res = -1;   // 闭区间 [lo, hi]
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (nums[mid] == target) {
                res = mid;                            // 记录候选
                if (leftmost) hi = mid - 1;           // 继续往左找更靠前的
                else lo = mid + 1;                    // 继续往右找更靠后的
            } else if (nums[mid] < target) {
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        return res;
    }
}
```

## 个人总结

### 1. 题眼：有序 + `O(log n)` + 重复元素 → 二分找边界

「排序数组」「要求 `O(log n)`」几乎等于明示二分；而「第一个和最后一个位置」说明元素**重复**，普通二分不够，要找**左右边界**。这是二分的一个大类：不是找某个值，而是找**满足条件的边界位置**。

### 2. 首选「统一 lowerBound」模板，减少出错

分别写「找左界」和「找右界」两套二分，边界收缩方向容易记混。更稳的是只实现一个 `lowerBound`（第一个 `>= t`）：
- 左边界 = `lowerBound(target)`；
- 右边界 = `lowerBound(target + 1) - 1`。

一套逻辑调两次，`target+1` 的小技巧把「找右界」也转成「找左界」。

### 3. 左闭右开 `[lo, hi)` 二分的收缩规则

- 初始 `hi = nums.length`（开区间，允许答案越到末尾之后表示「不存在」）；
- `nums[mid] >= t` 时 `hi = mid`（**不减 1**，因为 mid 本身可能是答案，右开区间自然排除它右边）；
- 否则 `lo = mid + 1`。
- 循环条件 `lo < hi`，退出时 `lo == hi` 即答案。

记牢「右开区间收缩不减 1」是这套模板不越界、不死循环的关键。

### 4. 一定要校验 `nums[left] == target`

`lowerBound` 返回的是「第一个 `>=target`」的位置，**不保证等于** target（可能整个数组都比它小，或该位置是个更大的数）。必须判 `left == n || nums[left] != target` 才能断定不存在，返回 `[-1,-1]`。漏了这步会把「不存在」误判成存在。

### 5. 空数组与边界

`nums` 长度可能为 0。`lowerBound` 里 `hi = 0`，循环不进入直接返回 `0`，随后 `left == nums.length(0)` 触发不存在分支，返回 `[-1,-1]`，天然正确——统一模板的又一好处。
