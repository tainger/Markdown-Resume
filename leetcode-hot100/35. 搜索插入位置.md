## 题目描述

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

请必须使用时间复杂度为 `O(log n)` 的算法。

---

## 示例

**示例 1**

```
输入: nums = [1,3,5,6], target = 5
输出: 2
```

**示例 2**

```
输入: nums = [1,3,5,6], target = 2
输出: 1
```

**示例 3**

```
输入: nums = [1,3,5,6], target = 7
输出: 4
```

---

## 提示

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 为 **无重复元素** 的 **升序** 排列数组
- `-10^4 <= target <= 10^4`

---

## 思路

### 核心思想

「找到 target 或它的插入位置」= 求**第一个大于等于 target 的元素下标**（lower_bound）。一个定义统一三种情况：target 存在 → 其下标；不存在 → 第一个比它大的下标；都比它小 → `n`。

### 解法一：线性扫描（基础）

从左到右找第一个 `>= target` 的元素返回其下标；全部小于 target 则返回 `n`。不满足题目对复杂度的要求，仅作对照。

- 时间复杂度：\(O(n)\)；空间复杂度：\(O(1)\)

### 解法二：二分查找 lower_bound（推荐）

1. 闭区间 `[left, right] = [0, n-1]`，`while (left <= right)`，答案变量 `ans` 初始为 `n`；
2. `nums[mid] == target` → 直接返回 `mid`；
3. `nums[mid] < target` → 插入位置必在右侧，`left = mid + 1`；
4. `nums[mid] > target` → `mid` 可能是插入位置，记 `ans = mid` 后收缩 `right = mid - 1` 继续找更小的候选；
5. 循环结束仍未命中 → 返回 `ans`（target 比所有元素大时保持初始 `n`）。

- 时间复杂度：\(O(\log n)\)；空间复杂度：\(O(1)\)

## 代码

### 解法一：线性扫描

```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] >= target) return i;   // 第一个 >= target 的位置
        }
        return nums.length;                    // 全部小于 target，插到末尾
    }
}
```

### 解法二：二分 lower_bound（推荐）

```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        int ans = nums.length;                 // 默认插到末尾（target 比所有元素大）
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) return mid;   // 命中直接返回
            if (nums[mid] < target) {
                left = mid + 1;                // 插入位置在 mid 右侧
            } else {
                ans = mid;                     // mid 可能是插入位置，先记下
                right = mid - 1;               // 继续向左找更小的候选
            }
        }
        return ans;
    }
}
```

## 个人总结

### 1. 题眼：插入位置 = lower_bound（第一个 >= target 的下标）

把题意翻译成「找第一个 `>= target` 的下标」，三种情况被一个定义覆盖。C++ 的 `lower_bound` 就是这个语义；Java 里对应 `Arrays.binarySearch` 找不到时的 `-(插入点) - 1`。记住这个转化，二分系列题一半是它的变装。

### 2. 返回值可以是 n：插入位置在「数组外」

target 大于所有元素时插入位置是 `nums.length`，**下标越界是合法答案**（示例 3 的输出 4 = 数组长度）。所以 `ans` 的初始值必须是 `n`，写成 `-1` 或 `0` 都会错——这是本题最常见的初始化 bug。

### 3. 闭区间二分模板三要素

| 要素 | 取值 |
|:---|:---|
| 区间定义 | 闭区间 `[left, right]` |
| 循环条件 | `left <= right`（区间为空才停） |
| 收缩方式 | `left = mid + 1` / `right = mid - 1`（mid 已查过，两侧都跳过 mid） |

配套记忆：**闭区间配 `<=` 和 `mid ± 1`；左闭右开配 `<` 和 `right = mid`**——两套模板别混用，混了不是死循环就是漏区间。
