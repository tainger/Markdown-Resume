## 题目描述

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为：`k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k` ，例如不会出现像 `3a` 或 `2[4]` 的输入。

---

## 示例

**示例 1**

```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

**示例 2**

```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

**示例 3**

```
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

**示例 4**

```
输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"
```

## 提示

- `1 <= s.length <= 30`
- `s` 由小写英文字母、数字和方括号 `[]` 组成
- `s` 保证是一个 **有效** 的输入
- `s` 中所有整数的取值范围为 `[1, 300]`

## 思路

### 核心难点：括号可以嵌套

`3[a2[c]]` 里内层的 `2[c]` 要先算出来（`cc`），再和 `a` 拼成 `acc`，最后整体重复 3 次。**「先处理最内层，再往外层拼」——这种「后进先出」的结构天然适合用栈**。

### 核心思想：双栈保存「外层未完成的现场」

遇到 `[` 说明进入一个新的重复块，需要把**外层已经拼好的字符串**和**当前这个块的重复次数**先「存起来」，等内层块处理完再取出来拼接。用两个栈：

- `numStack`：保存每一层的重复次数 `k`
- `strStack`：保存进入 `[` 之前、外层已经拼好的字符串

逐字符扫描，分四种情况：

| 当前字符 | 操作 |
|:---|:---|
| **数字** | 累积成完整的 `k`（可能多位，如 `12[...]`） |
| **`[`** | 把当前 `k` 压入 `numStack`，把当前已拼字符串 `cur` 压入 `strStack`，然后 `cur` 清空、`k` 归零，开始收集括号内内容 |
| **字母** | 追加到当前字符串 `cur` |
| **`]`** | 弹出 `numStack` 得 `k`、弹出 `strStack` 得外层前缀 `prev`，令 `cur = prev + cur × k`（把当前块重复 k 次接到外层后面） |

扫描结束，`cur` 即为答案。

```
s = "3[a2[c]]"

'3'  : k=3
'['  : numStack=[3], strStack=[""],  cur="", k=0
'a'  : cur="a"
'2'  : k=2
'['  : numStack=[3,2], strStack=["","a"],  cur="", k=0
'c'  : cur="c"
']'  : k=2,prev="a" → cur = "a" + "c"*2 = "acc"     栈弹回上一层
']'  : k=3,prev=""  → cur = "" + "acc"*3 = "accaccacc"  ✅
```

### 关键陷阱

1. **数字可能多位**：`12[a]` 的 `k` 是 12，不是 1 和 2，要连续读完所有数字字符再乘。
2. **`]` 时的拼接顺序**：是 `prev + cur*k`（外层前缀在前），不是 `cur*k + prev`。
3. **进 `[` 时立刻清空 `cur`**：当前块要从空串开始收集，别把外层内容混进来。

### 解法一：暴力反复展开最内层（最直观，先跑通）

不用栈，直接模拟人手展开：**每轮找到一个「最内层」的 `k[...]`（即某个 `]`，往左找到与它配对的、中间不含其它 `[` 的 `[`），把这段 `k[content]` 就地替换成 `content` 重复 `k` 次；如此反复，直到字符串里再没有 `]`。**

「最内层」= 从左往右扫，遇到的**第一个 `]`**，它对应的 `[` 一定是它左边**最近的那个 `[`**（因为中间若还有 `[`，那个 `[` 对应的 `]` 会更早出现，与「第一个 `]`」矛盾）。所以每轮：

1. 找到最左的 `]`，记为 `right`
2. 从 `right` 往左找最近的 `[`，记为 `left`
3. `[left+1, right-1]` 是括号内内容 `content`；`left` 再往左连续读数字得到 `k`
4. 把 `[数字k ... left ... right]` 整段替换成 `content` 重复 `k` 次
5. 回到第 1 步，直到没有 `]`

```
"3[a2[c]]"
第一个 ] 在下标6 → 往左最近 [ 在下标4 → content="c", k=2 → 替换 "2[c]"→"cc"
"3[acc]"
第一个 ] 在下标5 → 往左最近 [ 在下标1 → content="acc", k=3 → 替换 "3[acc]"→"accaccacc"
"accaccacc"   无 ] → 结束 ✅
```

- 时间复杂度：最坏 \(O(L^2)\)（`L` 为输出长度），每轮都重建整个字符串、且要重新从头找 `]`
- 空间复杂度：\(O(L)\)
- `s.length ≤ 30`、`k ≤ 300` 时能过；它的价值是把题意跑通、作为栈解法的对照

> 瓶颈：每展开一层都**从头扫一遍找 `]` 并重建整串**，重复扫描了大量已处理的部分——栈解法一次遍历就能把所有层处理完，正是对这里的优化。

### 解法二：双栈迭代（推荐）

如上，一次遍历，用两个栈保存外层现场。

- 时间复杂度：\(O(n \times \text{maxK})\)（构造结果时按倍数展开），一般记 \(O(n)\)（n 为**输出**长度）
- 空间复杂度：\(O(n)\)，栈深度与结果长度

### 解法三：递归下降（把 `[]` 当成子问题）

遇到 `[` 就递归解码括号内的子串，返回时把子串重复 `k` 次。用一个全局下标 `i` 在递归间共享扫描进度：

1. 从 `i` 开始扫，遇数字累积 `k`
2. 遇 `[`：`i` 跳过 `[`，递归解出括号内内容，重复 `k` 次接上
3. 遇 `]`：当前层结束，返回已拼字符串（并让外层 `i` 前进）
4. 遇字母：追加

- 时间复杂度：\(O(n)\)（输出长度），空间复杂度：\(O(n)\)（递归栈）
- 与解法一等价，栈换成了系统调用栈

## 代码

### 解法一：暴力反复展开最内层（先跑通）

```java
class Solution {
    public String decodeString(String s) {
        // 只要还有 ]，就展开一个最内层的 k[...]
        while (s.indexOf(']') >= 0) {
            int right = s.indexOf(']');                 // 最左的 ]（对应最内层）
            int left = s.lastIndexOf('[', right);       // 从 right 往左最近的 [
            String content = s.substring(left + 1, right);   // 括号内内容

            // 从 left 往左连续读数字，得到重复次数 k 和数字起点
            int numStart = left;
            while (numStart > 0 && Character.isDigit(s.charAt(numStart - 1))) numStart--;
            int k = Integer.parseInt(s.substring(numStart, left));

            // 拼接：k[content] 整段替换成 content 重复 k 次
            StringBuilder expanded = new StringBuilder();
            for (int i = 0; i < k; i++) expanded.append(content);
            s = s.substring(0, numStart) + expanded + s.substring(right + 1);
        }
        return s;
    }
}
```

### 解法二：双栈迭代（推荐）

```java
class Solution {
    public String decodeString(String s) {
        Deque<Integer> numStack = new ArrayDeque<>();   // 每层重复次数
        Deque<String> strStack = new ArrayDeque<>();    // 每层进入 [ 前的前缀
        StringBuilder cur = new StringBuilder();        // 当前层已拼字符串
        int k = 0;                                      // 当前正在累积的数字

        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                k = k * 10 + (c - '0');                 // 多位数字累积
            } else if (c == '[') {
                numStack.push(k);                       // 保存现场：次数
                strStack.push(cur.toString());          // 保存现场：外层前缀
                k = 0;                                   // 归零，开始新块
                cur = new StringBuilder();
            } else if (c == ']') {
                int repeat = numStack.pop();            // 本块重复次数
                String prev = strStack.pop();           // 外层前缀
                StringBuilder tmp = new StringBuilder(prev);
                for (int i = 0; i < repeat; i++) tmp.append(cur);  // prev + cur*repeat
                cur = tmp;
            } else {
                cur.append(c);                          // 普通字母
            }
        }
        return cur.toString();
    }
}
```

### 解法三：递归下降

```java
class Solution {
    private int i = 0;                                  // 全局扫描下标（递归间共享）

    public String decodeString(String s) {
        return dfs(s);
    }

    private String dfs(String s) {
        StringBuilder res = new StringBuilder();
        int k = 0;
        while (i < s.length()) {
            char c = s.charAt(i);
            if (Character.isDigit(c)) {
                k = k * 10 + (c - '0');
                i++;
            } else if (c == '[') {
                i++;                                    // 跳过 '['
                String inner = dfs(s);                  // 递归解出括号内内容
                for (int t = 0; t < k; t++) res.append(inner);
                k = 0;
            } else if (c == ']') {
                i++;                                    // 跳过 ']'，当前层结束
                return res.toString();
            } else {
                res.append(c);
                i++;
            }
        }
        return res.toString();
    }
}
```

## 个人总结

### 1. 从暴力展开到栈：消除重复扫描

暴力解法「反复找最内层 `k[...]` 就地替换」思路最直白，但每展开一层都要**从头扫一遍找 `]` 并重建整个字符串**，最坏 \(O(L^2)\)。它的洞察很有用——**「第一个出现的 `]`，配对的一定是它左边最近的 `[`」**，这正是「最内层」的判定，也是理解嵌套结构的入口。

优化点：暴力反复回到串首重扫，而括号的处理其实可以「一遍扫描、边扫边用栈保存外层现场」完成——遇 `[` 压栈、遇 `]` 弹栈还原一层，一次遍历处理掉所有层。这就是解法二的双栈迭代，把重复扫描降为线性。**「反复从头扫 + 每次只处理最内层」几乎都能改写成「一次遍历 + 栈」**。

### 2. 「嵌套 + 后进先出」是栈的强信号

括号嵌套的结构——`3[a2[c]]` 要先算内层再拼外层——本质是「最后进入的块最先完成」，这正是栈的语义。**看到「括号嵌套 / 需要先处理最内层再回到外层」，先想栈（或等价的递归）**。这与 [20. 有效的括号](20.有效的括号.md) 的括号匹配是同一族思想。

### 3. 双栈的分工：一个存次数，一个存现场

- `numStack` 存重复次数 `k`——遇 `]` 时才知道要重复几次；
- `strStack` 存**进入 `[` 前外层已拼好的字符串**——它是「暂存的外层现场」，等内层算完再取回来接上。

理解 `strStack` 存的是「外层前缀」而非当前块，是这题不绕晕的关键。

### 4. `]` 时的拼接顺序：`prev + cur*k`，别写反

弹栈后是 `cur = prev + cur.repeat(k)`：**外层前缀在前，当前块重复在后**。写成 `cur*k + prev` 会把顺序颠倒，`2[abc]3[cd]ef` 这类含并列块的用例立刻错。

### 5. 数字要按多位累积

`k = k * 10 + (c - '0')` 是标准的多位数字读法。若每遇一个数字字符就当独立的 `k`，`12[a]` 会被当成 `1` 和 `2` 处理，结果全错。提示里 `k` 最大 300（三位），必须支持多位。

### 6. 进 `[` 必须重置 `cur` 和 `k`

压栈保存现场后，`cur` 要 `new StringBuilder()`、`k` 要归零，让新块从干净状态开始收集。漏了会把外层已拼内容重复计入。

### 7. 迭代 vs 递归

| 解法 | 栈 | 特点 |
|:---|:---|:---|
| 双栈迭代 | 两个显式栈 | 现场保存清晰，面试易讲 |
| 递归下降 | 系统调用栈 | 代码短，但要用**共享下标 `i`** 让递归间接续进度 |

两者本质一样——递归就是把「保存/恢复外层现场」交给系统调用栈。递归版关键是 `i` 必须是**成员变量或引用共享**，否则各层扫描进度对不上。
