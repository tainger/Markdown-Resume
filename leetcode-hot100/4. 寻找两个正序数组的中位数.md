## 题目描述

给定两个大小分别为 `m` 和 `n` 的**正序**（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数**。

算法的时间复杂度应该为 \(O(\log (m+n))\)。

## 示例

**示例 1**

```
输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1,2,2] ，中位数 2
```

**示例 2**

```
输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
解释：合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5
```

## 提示

- `0 <= m, n <= 1000`
- `1 <= m + n <= 2000`
- `-10^6 <= nums1[i], nums2[i] <= 10^6`

## 思路

### 核心：找「分割线」，而不是把数组合并出来

中位数的本质：把合并后的有序数组**切成长度相等（或差 1）的两半**，中位数就是「左半的最大值」（奇数）或「左半最大与右半最小的平均」（偶数）。

**不需要真的合并**——只要在两个数组上各切一刀，保证：

1. 左半部分元素总数 = \(\lfloor (m+n+1)/2 \rfloor\)（奇数时左边多 1 个，公式自动处理）；
2. **左半的最大值 ≤ 右半的最小值**（半序合法）。

```
        左半部分（(m+n+1)/2 个）          右半部分
   ┌──────────────────────────┬──────────────────────────┐
nums1:  1   3   5 │ 7                      i = 3（左边放 1,3,5）
nums2:  2   4 │ 6   8   9                  j = 2（左边放 2,4）

左半 = {1,2,3,4,5}    右半 = {6,7,8,9}
合法条件：max(左)=5 ≤ min(右)=6 ✓
总长 9（奇数）→ 中位数 = max(左) = 5
```

固定「左边元素总数」后，**i 定了 j 就定了**（\(j = \text{leftLen} - i\)）。i 的取值是否合适具有**单调性**（i 越大，nums1 左半最大越大、nums2 左半最大越小）→ **二分 i**，复杂度 \(O(\log \min(m,n))\)。

### 解法一：双指针走中位（保底，面试先说这个）

1. 两数组各一个读指针 `i/j`，按「谁小移谁」走 `total/2 + 1` 步
2. 只滚动记录 `prev`、`cur` 两个值（不需要真合并数组）
3. 奇数总数 → 中位数是 `cur`；偶数 → `(prev + cur) / 2.0`

- 时间复杂度：\(O(m+n)\)，空间复杂度：\(O(1)\)
- 不满足进阶要求，但思路简单、边界好写，**面试可先讲它保底再优化**

### 解法二：二分分割线（最优，推荐）

1. **保证 `nums1` 是较短数组**（否则交换）：在短数组上二分，才能保证 `j = leftLen - i` 永不越界
2. 在 `[0, m]` 上二分 `i`（nums1 左半贡献 `i` 个，nums2 左半贡献 `leftLen - i` 个）
3. 取四个边界值（越界用 ±∞ 哨兵）：`l1 = nums1[i-1]`、`r1 = nums1[i]`、`l2 = nums2[j-1]`、`r2 = nums2[j]`
4. 合法判定：`l1 <= r2 && l2 <= r1`
   - `l1 > r2` → nums1 拿多了 → `hi = i - 1`（i 左移）
   - `l2 > r1` → nums1 拿少了 → `lo = i + 1`（i 右移）
5. 命中后：奇数总数返回 `max(l1, l2)`；偶数返回 `(max(l1,l2) + min(r1,r2)) / 2.0`

- 时间复杂度：\(O(\log \min(m,n))\)，空间复杂度：\(O(1)\)

## 代码

### 解法一：双指针走中位（不真正合并）

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        int total = m + n;
        int i = 0, j = 0;
        int prev = 0, cur = 0;               // 只滚动保留「前一个」和「当前」值

        for (int k = 0; k <= total / 2; k++) {   // 走到中位下标即可，不必走完
            prev = cur;
            if (i < m && (j >= n || nums1[i] <= nums2[j])) {
                cur = nums1[i++];            // 谁小移谁；一方空了走另一方
            } else {
                cur = nums2[j++];
            }
        }
        // 奇数：中位数 = 第 total/2 个（0 基），即 cur
        // 偶数：中位数 = 第 total/2-1 与 total/2 个的平均，即 (prev+cur)/2
        return (total % 2 == 1) ? cur : (prev + cur) / 2.0;
    }
}
```

### 解法二：二分分割线（最优）

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        // ★ 保证 nums1 是较短数组：在短数组上二分，j 才不会越界
        if (nums1.length > nums2.length) {
            int[] tmp = nums1; nums1 = nums2; nums2 = tmp;
        }
        int m = nums1.length, n = nums2.length;
        int leftLen = (m + n + 1) / 2;       // 左半应放 (m+n+1)/2 个：奇偶通吃
        int lo = 0, hi = m;                  // 在 [0, m] 上二分 nums1 的分割位置

        while (lo <= hi) {
            int i = (lo + hi) / 2;           // nums1 左半贡献 i 个
            int j = leftLen - i;             // nums2 左半贡献 j 个（被 leftLen 锁定）

            // 四个边界值，越界用 ±∞ 哨兵，免去 4 种特判
            int l1 = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1];  // nums1 左半最大
            int r1 = (i == m) ? Integer.MAX_VALUE : nums1[i];      // nums1 右半最小
            int l2 = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1];  // nums2 左半最大
            int r2 = (j == n) ? Integer.MAX_VALUE : nums2[j];      // nums2 右半最小

            if (l1 <= r2 && l2 <= r1) {      // 找到合法分割线
                if ((m + n) % 2 == 1) {
                    return Math.max(l1, l2); // 奇数：中位数在左半（左边多 1 个）
                }
                return (Math.max(l1, l2) + Math.min(r1, r2)) / 2.0;  // 偶数：两侧平均
            } else if (l1 > r2) {
                hi = i - 1;                  // nums1 拿多了 → 分割线左移
            } else {
                lo = i + 1;                  // nums1 拿少了 → 分割线右移
            }
        }
        return 0.0;                          // 题目保证两数组非空，不会到达
    }
}
```

## 个人总结

### 1. 题眼：「两个有序 + 要求 \(O(\log(m+n))\)」→ 排除合并，二分分割线

看到「有序数组」先想二分，但二分的对象不是「某个下标的值」，而是**分割线的位置**。「中位数 = 左右均分」这个定义把问题转化成：**在 i 确定后 j 唯一确定，且 i 的合法性单调** → 标准二分场景。

### 2. 为什么必须在较短数组上二分

`j = leftLen - i`。若在长数组上二分（如 m=10, n=1, leftLen=5），当 i=0 时 j=5 超出 n=1，`nums2[j-1]` 越界。在**短数组**上二分时 \(i \in [0, m]\)，可以推出 \(j \in [\text{leftLen}-m,\ \text{leftLen}] \subseteq [0, n]\)，永远合法。这是本解法**唯一一处必须记死的实现细节**。

### 3. ±∞ 哨兵消灭 4 种边界特判

`i == 0`（nums1 左半空）、`i == m`（右半空）、`j == 0`、`j == n` 四种边界如果逐一 if 判断，代码翻倍且易漏。用哨兵后：

| 边界 | 哨兵取值 | 哨兵的作用 |
|:---|:---|:---|
| 左半为空（i==0 / j==0） | `Integer.MIN_VALUE` | 不影响「左半最大」的比较（任何数都 ≥ −∞） |
| 右半为空（i==m / j==n） | `Integer.MAX_VALUE` | 不影响「右半最小」的比较 |

### 4. `(m+n+1)/2` 一个公式统一奇偶

- 总长奇数：左边多 1 个，中位数落在左半 → `max(l1, l2)`
- 总长偶数：左右等分 → `(max(l1,l2) + min(r1,r2)) / 2.0`

返回值必须是 `double`，除数写 `2.0`（写成 `2` 会整数除法丢小数）。

### 5. 四种解法复杂度对比

| 解法 | 时间 | 空间 | 面试定位 |
|:---|:---|:---|:---|
| 合并成新数组再取中位 | \(O(m+n)\) | \(O(m+n)\) | 只配口提一句 |
| 双指针走中位（解法一） | \(O(m+n)\) | \(O(1)\) | 保底，先讲它稳住节奏 |
| 二分第 K 小 | \(O(\log(m+n))\) | \(O(1)\) | 思路自然的过渡，但实现较繁 |
| **二分分割线（解法二）** | \(O(\log \min(m,n))\) | \(O(1)\) | 标准答案，必须掌握 |
