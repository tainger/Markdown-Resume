## 题目描述

给你一个未排序的整数数组 `nums` ，请你找出其中没有出现的最小的正整数。

请你实现时间复杂度为 `O(n)` 并且只使用常数级别额外空间的解决方案。

## 示例

**示例 1**

```
输入：nums = [1,2,0]
输出：3
解释：范围 [1,2] 中的数字都在数组中。
```

**示例 2**

```
输入：nums = [3,4,-1,1]
输出：2
解释：1 在数组中，但 2 没有。
```

**示例 3**

```
输入：nums = [7,8,9,11,12]
输出：1
解释：最小的正数 1 没有出现。
```

---

## 提示

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`

---

## 思路

### 核心思想

长度为 `n` 的数组最多装下 `1..n` 这 `n` 个正数，所以**答案必在 `[1, n+1]` 内**。于是可以「原地哈希」：把值 `v`（`1 <= v <= n`）交换到下标 `v-1` 上，交换完成后**第一个 `nums[i] != i+1` 的位置就是答案**。

### 解法一：哈希集合（基础，不满足空间要求）

1. 全部元素放进 `HashSet`；
2. 从 `1` 到 `n` 依次查集合，第一个不在的就是答案；`1..n` 全在则返回 `n+1`。

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(n)\)

### 解法二：原地哈希——置换归位（推荐）

1. 遍历数组：当 `nums[i]` 在 `[1, n]` 内，且**目标位置 `nums[nums[i]-1]` 还不是 `nums[i]`** 时，把 `nums[i]` 交换到下标 `nums[i]-1`（用 `while`，换进来的新数留在 `i` 继续归位）；
2. 再扫一遍，第一个 `nums[i] != i+1` 的位置返回 `i+1`；
3. 全部归位说明 `1..n` 都在，返回 `n+1`。

每次交换都让至少一个数「永久归位」，总交换次数不超过 `n`，均摊仍是线性。

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(1)\)

## 代码

### 解法一：哈希集合（不满足 O(1) 空间）

```java
public int firstMissingPositive(int[] nums) {
    int n = nums.length;
    Set<Integer> set = new HashSet<>();
    for (int num : nums) {
        set.add(num);
    }
    // 答案一定在 [1, n + 1] 内
    for (int i = 1; i <= n; i++) {
        if (!set.contains(i)) {
            return i;
        }
    }
    return n + 1;
}
```

### 解法二：原地哈希（推荐）

```java
public int firstMissingPositive(int[] nums) {
    int n = nums.length;
    // 第一遍：把值 v（1 <= v <= n）交换到下标 v - 1 上
    for (int i = 0; i < n; i++) {
        // 三个条件缺一不可：范围合法 + 目标位还不是正确值（防死循环）
        while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
            int tmp = nums[nums[i] - 1];   // ① 先暂存目标位的值
            nums[nums[i] - 1] = nums[i];   // ② 归位（此时 nums[i] 还没被改）
            nums[i] = tmp;                 // ③ 换进来的数留在 i，继续 while
        }
    }
    // 第二遍：第一个没归位的位置就是缺失的最小正数
    for (int i = 0; i < n; i++) {
        if (nums[i] != i + 1) {
            return i + 1;
        }
    }
    return n + 1;   // 1..n 全部在数组中
}
```

## 个人总结

### 1. 先想通「答案范围是 [1, n+1]」，困难题秒变模板

数组长度 `n`，最好的情况是 `1..n` 全出现，那时答案是 `n+1`；否则答案是 `[1, n]` 中缺席的数。**范围一锁定，「找缺失」就转化成「哪个数没在它该在的位置」**，为原地哈希铺路。面试先讲这一步，思路立刻清晰。

### 2. 置换的两个易错点

| 易错点 | 错误写法 | 后果 |
|:---|:---|:---|
| 死循环 | 缺 `nums[nums[i]-1] != nums[i]` 判断，或把 `while` 写成只执行一次的 `if` | `[1,1]` 这类重复值永远互相交换 |
| 越界 | 用 `nums[i]-1` 当下标前不先判 `1 <= nums[i] <= n` | `nums[i]` 为负数、0 或大数时数组越界 |

`while` 条件三件事：**范围合法 → 防重复交换 → 才交换**。

### 3. 交换顺序：先存目标位，再赋值

「用值当下标」的写法里，`nums[i]` 一旦被提前改掉，第二步的 `nums[i]-1` 就不是原来的下标了。口诀：**先把要去的下标算好、目标值暂存，再动 `nums[i]`**。

### 4. 复杂度为什么是 O(n) 而不是 O(n²)

外层看着是双重循环，但「一次交换至少让一个数永久归位」，总交换次数 `<= n`，均摊线性。与 128（最长连续序列）同属「假双重循环、真 O(n)」，面试要能用**均摊分析**反驳「这不是 O(n²) 吗」的追问。

### 5. 变体：正负号标记法

另一类 \(O(1)\) 解法：先把非正数统一改成 `n+1`；再遍历，出现值 `v` 就把 `nums[v-1]` 取负当标记；最后第一个为正的下标即答案。两种都要会——「置换归位」更通用，LeetCode 442（找重复数）、448（找消失的数字）都是同款套路。
