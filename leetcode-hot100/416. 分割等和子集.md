## 题目描述

给你一个 **只包含正整数** 的 **非空** 数组 `nums`。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

---

## 示例

**示例 1**

```
输入：nums = [1,5,11,5]
输出：true
解释：数组可以分割成 [1, 5, 5] 和 [11]。
```

**示例 2**

```
输入：nums = [1,2,3,5]
输出：false
解释：数组不能分割成两个元素和相等的子集。
```

---

## 提示

- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`

---

## 思路

### 核心思想：转化为「能否选出子集和 = sum/2」的 0-1 背包

分成两个和相等的子集 → 每个子集的和都等于 `sum / 2`。所以问题等价于：

> **能否从 `nums` 中选出一个子集，使其和恰好等于 `target = sum / 2`？**

这正是 **0-1 背包的「能否装满容量」** 判定问题（每个数选/不选，各用一次）。它与 [494. 目标和](494.%20目标和.md) 是同一族——494 求**方案数**，本题求**能否**（布尔）。

### 关键前提检查

1. **`sum` 为奇数** → 不可能平分成两个整数和相等的子集，直接返回 `false`。
2. `target = sum / 2`，容量确定后套背包模板。

### 解法一：回溯（暴力，易理解）

对每个数枚举「选入子集 / 不选」，看能否凑出 `target`：

1. 从下标 0 开始，累计已选和 `cur`
2. `cur == target` → 找到，返回 `true`
3. `cur > target` 或越界 → 该分支失败，回溯
4. 对当前数：选（`cur + nums[i]`）或不选，任一分支成功即成功

- 时间复杂度：\(O(2^n)\)，每个数两种选择
- 空间复杂度：\(O(n)\)，递归深度
- `n ≤ 200` 时 \(2^{200}\) 会 **TLE**，仅作理解入口；剪枝（排序 + `cur > target` 提前砍）能缓解但不改本质

### 解法二：0-1 背包 DP（推荐）

- **状态**：`dp[j]` = 是否能从已考虑的数中选出若干个，凑出和恰为 `j`
- **转移**：`dp[j] = dp[j] || dp[j - num]`（不选 num：保持 `dp[j]`；选 num：看 `dp[j-num]` 能否凑出）
- **初始化**：`dp[0] = true`（凑和为 0：什么都不选，恒成立）
- **遍历顺序**：外层遍历物品 `num`，内层容量 **倒序** `j` 从 `target` 到 `num`（0-1 背包一维数组必须倒序，防止一个数被用多次）
- **提前返回**：一旦 `dp[target]` 为 `true` 可直接返回
- 时间复杂度：\(O(n \times target)\)
- 空间复杂度：\(O(target)\)，一维滚动数组

### 图解（`nums=[1,5,11,5]`）

```
sum = 22, target = 11        （目标：选子集和恰为 11）

dp 初始:  下标 0..11
         [T,F,F,F,F,F,F,F,F,F,F,F]     dp[0]=true

处理 1 :  [T,T,F,F,F,F,F,F,F,F,F,F]     能凑 0,1
处理 5 :  [T,T,F,F,F,T,T,F,F,F,F,F]     能凑 0,1,5,6
处理 11:  [T,...,                 T]    dp[11]=true → 直接返回 true ✅
```

## 代码

### 解法一：回溯（暴力，会 TLE）

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int x : nums) sum += x;
        if (sum % 2 != 0) return false;          // 奇数无法平分
        return backtrack(nums, 0, 0, sum / 2);
    }

    // 从下标 index 起，已选和为 cur，能否凑出 target
    private boolean backtrack(int[] nums, int index, int cur, int target) {
        if (cur == target) return true;          // 凑齐
        if (cur > target || index == nums.length) return false;
        // 选当前数 或 不选，任一成功即成功
        return backtrack(nums, index + 1, cur + nums[index], target)
            || backtrack(nums, index + 1, cur, target);
    }
}
```

### 解法二：0-1 背包 DP（推荐）

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int x : nums) sum += x;
        if (sum % 2 != 0) return false;          // 奇数直接不可能
        int target = sum / 2;

        boolean[] dp = new boolean[target + 1];
        dp[0] = true;                            // 凑和为 0：什么都不选，恒成立
        for (int num : nums) {                   // 外层遍历物品
            for (int j = target; j >= num; j--) {    // 内层容量倒序（0-1 背包关键）
                dp[j] = dp[j] || dp[j - num];    // 不选 || 选
            }
            if (dp[target]) return true;         // 提前返回优化
        }
        return dp[target];
    }
}
```

## 个人总结

### 1. 核心转化：分两半 → 选子集和 = sum/2 → 0-1 背包

「分割成两个和相等的子集」的信息量等价于「能否选一个子集和为 `sum/2`」——另一半自动补齐。**看到「把数组分成和相等的两组 / 选子集凑出某和」，先想 0-1 背包**。这与 [494. 目标和](494.%20目标和.md) 的转化思路一脉相承：

| 题目 | 转化 | 求什么 |
|:---|:---|:---|
| 416. 分割等和子集 | 子集和 = `sum/2` | **能否**（布尔 `\|\|`） |
| 494. 目标和 | 子集和 = `(sum+target)/2` | **方案数**（累加 `+=`） |

### 2. `sum` 为奇数直接 false

和为奇数不可能拆成两个相等的整数，第一步就砍掉。漏了会让 `target = sum/2` 因 `int` 除法取整而算错，得到假阳性。

### 3. 0-1 背包一维数组为什么必须倒序

`dp[j] = dp[j] || dp[j - num]` 中，`dp[j - num]` 必须是**上一轮（不含当前 num）**的值：

- **倒序**（`j` 从大到小）：算 `dp[j]` 时 `dp[j-num]` 还没被本轮更新，是旧值 → 每个 num 只用一次 ✅
- **正序**（`j` 从小到大）：`dp[j-num]` 已被本轮更新 → num 被重复使用 → 变成完全背包（可无限选同一个数）❌

这与 494 是同一个坑，本质是 0-1 背包与完全背包在一维数组上的唯一区别，详见 [动态规划.md](../算法思想/动态规划.md) 背包模型。

### 4. `dp[0] = true` 的含义

`dp[0]` 表示「能否凑出和为 0」。空集（什么都不选）的和就是 0，恒成立，所以为 `true`。这是布尔递推的起点，若设 `false` 则全盘皆 `false`。

### 5. 布尔背包 vs 计数背包

本题 `dp` 是 `boolean`，转移用 `||`（能凑出就行）；494 的 `dp` 是 `int`，转移用 `+=`（累加方案数）。**「能否」用布尔 `||`，「多少种」用整数 `+=`**——这是背包判定题和计数题的唯一差别。

### 6. 回溯 vs 背包 DP

| 解法 | 时间 | 空间 | 特点 |
|:---|:---:|:---:|:---|
| 回溯 | \(O(2^n)\) | \(O(n)\) | 直观，但 n≤200 会 TLE，理解题意用 |
| 背包 DP | \(O(n \times target)\) | \(O(target)\) | 最优解，把指数级降为多项式 |

回溯是「暴力枚举每个数选/不选」，背包 DP 是「发现子问题重叠后用递推」。这题和 [494. 目标和](494.%20目标和.md) 一起，是入门 0-1 背包最好的一对姊妹题。

### 7. 背包类题的识别套路

| 题目 | 类型 | 转移 |
|:---|:---|:---|
| 416. 分割等和子集 | 0-1 背包能否装满 | `dp[j] \|\|= dp[j-num]` |
| 494. 目标和 | 0-1 背包方案数 | `dp[j] += dp[j-num]` |
| 518. 零钱兑换 II | 完全背包方案数（内层正序） | `dp[j] += dp[j-coin]` |
| 322. 零钱兑换 | 完全背包最小个数 | `dp[j] = min(dp[j], dp[j-coin]+1)` |

> 记忆：**「元素选/不选 + 能否凑出/方案数」→ 0-1 背包（内层倒序）；元素可重复用 → 完全背包（内层正序）。**
