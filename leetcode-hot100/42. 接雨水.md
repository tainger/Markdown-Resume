## 题目描述

给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

---

## 示例

**示例 1**

```
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。
```

**示例 2**

```
输入：height = [4,2,0,3,2,5]
输出：9
```

## 提示

- `n == height.length`
- `1 <= n <= 2 * 10^4`
- `0 <= height[i] <= 10^5`

## 思路

### 核心洞察：每一列能接的水，由「左右两侧最高柱的较小者」决定

对位置 `i`，它头顶能积多少水，取决于它**左边最高柱** `leftMax` 和**右边最高柱** `rightMax` 中的**较小者**（木桶短板效应），再减去自身高度：

```
water[i] = max(0, min(leftMax[i], rightMax[i]) - height[i])
```

总雨水 = 每列水量之和。所有解法都围绕「怎么高效求每列的 `min(leftMax, rightMax)`」。

```
height = [0,1,0,2,1,0,1,3,2,1,2,1]
位置2: 左边最高=1, 右边最高=3, min=1, 减自身0 → 接 1
位置5: 左边最高=2, 右边最高=3, min=2, 减自身0 → 接 2
...累加 = 6
```

### 解法一：暴力，逐列向两边扫（理解入口）

对每个 `i`，向左扫一遍求 `leftMax`、向右扫一遍求 `rightMax`，再算水量。

- 时间复杂度：\(O(n^2)\)，每列都要向两侧各扫一遍
- 空间复杂度：\(O(1)\)
- `n ≤ 2×10^4` 时约 `4×10^8`，**可能 TLE**，仅用于确立「左右较小者 - 自身」的核心公式

> 瓶颈：每列都重新扫左右最高值，`leftMax`/`rightMax` 被**反复计算**。用数组预存即得 DP 解法。

### 解法二：前后缀最大值 DP（空间换时间）

预处理两个数组：`leftMax[i]` = `[0..i]` 的最高，`rightMax[i]` = `[i..n-1]` 的最高。然后一遍累加。

1. 正向扫求 `leftMax`：`leftMax[i] = max(leftMax[i-1], height[i])`
2. 反向扫求 `rightMax`：`rightMax[i] = max(rightMax[i+1], height[i])`
3. 累加 `min(leftMax[i], rightMax[i]) - height[i]`

- 时间复杂度：\(O(n)\)，三趟线性扫
- 空间复杂度：\(O(n)\) 两个数组

### 解法三：双指针（O(1) 空间，最优）

DP 解法的两个数组可以省掉。用 `left`、`right` 双指针从两端向中间夹逼，维护 `leftMax`、`rightMax`：

- **谁那边的最大值小，就先结算谁**。若 `leftMax < rightMax`，则位置 `left` 的水量只由 `leftMax` 决定（右边一定有更高的挡着，`min` 必是 `leftMax`），结算后 `left++`；否则结算 `right` 并 `right--`。

```
left→        ←right
leftMax=当前左边最高, rightMax=当前右边最高
if leftMax < rightMax:  水[left] = leftMax - height[left]; left++
else:                   水[right] = rightMax - height[right]; right--
```

- 时间复杂度：\(O(n)\)，双指针一趟
- 空间复杂度：\(O(1)\) ✅

### 解法四：单调栈（按「行」横向累加）

前三种是**按列竖着算**，单调栈是**按行横着算**。维护一个下标**递减**的栈（栈底到栈顶高度递减）：

- 遍历，当前柱 `height[i]` 比栈顶高时，说明形成了一个「凹槽」：弹出栈顶 `bottom`（槽底），此时新栈顶是左墙、`i` 是右墙；
- 该层水量 = `(min(左墙, 右墙) - bottom高) × (右墙下标 - 左墙下标 - 1)`（宽 × 高）。

- 时间复杂度：\(O(n)\)，每个下标进出栈一次
- 空间复杂度：\(O(n)\) 栈

## 代码

### 解法一：暴力逐列扫（会 TLE，理解入口）

```java
class Solution {
    public int trap(int[] height) {
        int n = height.length, ans = 0;
        for (int i = 0; i < n; i++) {
            int leftMax = 0, rightMax = 0;
            for (int j = i; j >= 0; j--) leftMax = Math.max(leftMax, height[j]);   // 左边最高
            for (int j = i; j < n; j++) rightMax = Math.max(rightMax, height[j]);  // 右边最高
            ans += Math.min(leftMax, rightMax) - height[i];   // 短板 - 自身
        }
        return ans;
    }
}
```

### 解法二：前后缀最大值 DP

```java
class Solution {
    public int trap(int[] height) {
        int n = height.length;
        if (n == 0) return 0;
        int[] leftMax = new int[n], rightMax = new int[n];

        leftMax[0] = height[0];
        for (int i = 1; i < n; i++) leftMax[i] = Math.max(leftMax[i - 1], height[i]);

        rightMax[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; i--) rightMax[i] = Math.max(rightMax[i + 1], height[i]);

        int ans = 0;
        for (int i = 0; i < n; i++) {
            ans += Math.min(leftMax[i], rightMax[i]) - height[i];
        }
        return ans;
    }
}
```

### 解法三：双指针（推荐，O(1) 空间）

```java
class Solution {
    public int trap(int[] height) {
        int left = 0, right = height.length - 1;
        int leftMax = 0, rightMax = 0, ans = 0;
        while (left < right) {
            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);
            if (leftMax < rightMax) {              // 左边短板确定 → 结算 left
                ans += leftMax - height[left];
                left++;
            } else {                               // 右边短板确定 → 结算 right
                ans += rightMax - height[right];
                right--;
            }
        }
        return ans;
    }
}
```

### 解法四：单调栈（按行横向累加）

```java
class Solution {
    public int trap(int[] height) {
        Deque<Integer> stack = new ArrayDeque<>();   // 存下标，对应高度递减
        int ans = 0;
        for (int i = 0; i < height.length; i++) {
            // 当前柱比栈顶高 → 形成凹槽，结算积水
            while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
                int bottom = stack.pop();            // 槽底
                if (stack.isEmpty()) break;          // 没有左墙，接不住水
                int left = stack.peek();             // 左墙下标
                int width = i - left - 1;            // 槽宽
                int h = Math.min(height[left], height[i]) - height[bottom];  // 槽高
                ans += width * h;
            }
            stack.push(i);
        }
        return ans;
    }
}
```

## 个人总结

### 1. 核心公式：`min(左最高, 右最高) - 自身高度`

想通「每列水量 = 左右两侧最高柱的**较小者**减自身」，全题就通了——这是木桶短板效应。四种解法只是**求这个 `min` 的效率不同**。做题先推出这个公式，再谈优化。

### 2. 四种解法的演进与取舍

| 解法 | 时间 | 空间 | 视角 | 关键 |
|:---|:---:|:---:|:---|:---|
| 暴力逐列 | \(O(n^2)\) | \(O(1)\) | 按列 | 反复扫左右最高，TLE |
| 前后缀 DP | \(O(n)\) | \(O(n)\) | 按列 | 预存 `leftMax/rightMax` |
| 双指针 | \(O(n)\) | \(O(1)\) | 按列 | 省掉两数组，最优 |
| 单调栈 | \(O(n)\) | \(O(n)\) | 按行 | 凹槽结算，横向累加 |

**面试首推双指针**（时间空间双最优），单调栈作为「按行」的另一视角展示广度。

### 3. 双指针为什么「谁小先结算谁」是对的

若 `leftMax < rightMax`，位置 `left` 的水量取 `min(leftMax, rightMax) = leftMax`——**因为右边已经存在一个 ≥ `rightMax > leftMax` 的柱子挡着**，无论中间还有什么，`left` 的右侧最高一定 `≥ leftMax`，所以 `min` 必然是 `leftMax`，可以放心结算。这是双指针能省掉 `rightMax` 数组的关键推理。

### 4. 单调栈是「横向按行」，和前三种正交

前三种解法竖着算「每一列头顶多少水」；单调栈横着算「每一层（行）能铺多宽的水」。**遇到「找左右第一个更高/更低」的结构就想单调栈**——这里维护高度递减栈，一旦来了更高的柱子就结算它和栈内形成的凹槽。和你整理的 [单调栈.md](../算法思想/单调栈.md)、[84 柱状图最大矩形](84.%20柱状图中最大的矩形.md) 同源。

### 5. 单调栈易错点：弹出后要判空 + 宽度算法

- 弹出槽底 `bottom` 后，若栈空说明**左边没有墙**，接不住水，`break`；
- 宽度是 `i - left - 1`（两墙之间的距离，不含墙本身），别写成 `i - left`。
