# 448. 找到所有数组中消失的数字

> **难度**：🟢 简单 | **标签**：数组、哈希表 | **企业**：—

## 题目描述

给你一个含 `n` 个整数的数组 `nums` ，其中 `nums[i]` 在区间 `[1, n]` 内。请你找出所有在 `[1, n]` 范围内但没有出现在 `nums` 中的数字，并以数组的形式返回结果。

## 示例

**示例 1**

```
输入：nums = [4,3,2,7,8,2,3,1]
输出：[5,6]

解释：n=8，数字 1~8 中，5 和 6 没有出现
```

**示例 2**

```
输入：nums = [1,1]
输出：[2]

解释：n=2，数字 1~2 中，2 没有出现
```

---

## 提示

- `n == nums.length`
- \\(1 \\le n \\le 10^5\\)
- \\(1 \\le \\text{nums[i]} \\le n\\)

## 思路

### 核心思想

**题目给了两个关键条件，恰好能实现原地标记：**

```
① 数字范围 [1, n]，恰好等于数组下标范围 [0, n-1]
② 每个数字可以映射到一个唯一的下标：num → idx = num - 1
```

**原地标记法**：把原数组当哈希表用。遍历每个数，把它「对应下标」的元素标记为负数。最后遍历一遍，哪个位置的值还是正数，就说明它对应的数字 `idx + 1` 没出现过。

```
演示：nums = [4,3,2,7,8,2,3,1], n=8

Step 1: 遍历每个数，标记对应位置为负

  索引:  0  1  2  3  4  5  6  7
  初始: [4, 3, 2, 7, 8, 2, 3, 1]

  num=4 → idx=3 → nums[3]=7 → 标记: nums[3]=-7
         [4, 3, 2,-7, 8, 2, 3, 1]

  num=3 → idx=2 → nums[2]=2 → 标记: nums[2]=-2
         [4, 3,-2,-7, 8, 2, 3, 1]

  num=-2 → 取绝对值=2 → idx=1 → nums[1]=3 → 标记: nums[1]=-3
         [4,-3,-2,-7, 8, 2, 3, 1]

  ... 重复直到遍历完

  最终: [-4,-3,-2,-7, 8, 2,-3,-1]
              ↑  ↑
             正数 正数 → idx=4→5, idx=5→6 没出现过

Step 2: 收集正数位置 → [4+1, 5+1] = [5, 6] ✓
```

> ⚠️ 关键技巧：读取值时用 `Math.abs(nums[i])`，因为前面可能已经被标记为负数。

### 解法：原地标记

1. 遍历 nums，对每个值 `Math.abs(nums[i])` 计算 `idx = val - 1`，将 `nums[idx]` 变为负数
2. 再次遍历 nums，若 `nums[i] > 0`，则 `i + 1` 未出现过，加入结果

- 时间复杂度：\\(O(n)\\)，空间复杂度：\\(O(1)\\)（结果列表不算）

### 解法：原地标记

```java
public List<Integer> findDisappearedNumbers(int[] nums) {
    // ① 原地标记：把出现过的数字对应的下标位置标记为负数
    for (int i = 0; i < nums.length; i++) {
        int idx = Math.abs(nums[i]) - 1;  // 数字 → 下标
        if (nums[idx] > 0) {
            nums[idx] = -nums[idx];        // 只标记一次，避免重复标记负负得正
        }
    }

    // ② 收集仍为正数的位置，idx+1 即为缺失数字
    List<Integer> result = new ArrayList<>();
    for (int i = 0; i < nums.length; i++) {
        if (nums[i] > 0) {
            result.add(i + 1);
        }
    }
    return result;
}
```
