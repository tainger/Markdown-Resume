## 题目描述

给定一个长度为 `n` 的 **0 索引**整数数组 `nums`。初始位置为 `nums[0]`。

每个元素 `nums[i]` 表示从索引 `i` 向前跳转的**最大长度**。换句话说，如果你在 `nums[i]` 位置，你可以跳转到任意 `nums[i + j]` 位置（`0 <= j <= nums[i]` ）。

返回到达 `nums[n - 1]` 的**最小跳跃次数**。生成的测试用例可以到达 `nums[n - 1]`。

## 示例

**示例 1**

```
输入: nums = [2,3,1,1,4]
输出: 2
解释: 跳到最后一个位置的最小跳跃数是 2。
     从下标为 0 跳到下标为 1 的位置，跳 1 步，然后跳 3 步到达数组的最后一个位置。
```

**示例 2**

```
输入: nums = [2,3,0,1,4]
输出: 2
```

## 提示

- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 1000`
- **题目保证可以到达** `nums[n-1]`

## 思路

### 核心思想

把跳跃过程看成 **逐层扩展（隐式 BFS）**：第 `k` 跳能覆盖的位置是一段连续区间，维护当前层边界 `end` 与下一层能到达的最远位置 `farthest`，走到 `i == end` 说明本层走完、必须再跳一次。

### 解法一：动态规划（基础）

1. 定义 `dp[i]` = 跳到下标 `i` 的最少次数，`dp[0] = 0`；
2. 对每个可达的 `i`，向右更新它能跳到的所有位置 `j`（`i+1 .. i+nums[i]`）：`dp[j] = min(dp[j], dp[i] + 1)`。

- 时间复杂度：\(O(n^2)\)（`n = 10^4` 尚可通过，但非最优），空间复杂度：\(O(n)\)

### 解法二：贪心（推荐）

1. 维护三个变量：当前层右边界 `end`、目前能到达的最远位置 `farthest`、步数 `steps`；
2. `i` 从 `0` 遍历到 `n-2`（**注意不含 `n-1`**）：
   - `farthest = max(farthest, i + nums[i])`；
   - 当 `i == end`：本层结束，`end = farthest`，`steps++`。

正确性：第 `k` 跳能覆盖的区间是确定的，区间内任何「接力点」能扩展出的下一层最远边界都相同（都是该区间内所有 `i + nums[i]` 的最大值），所以「本层不必挑点，走满边界再跳」不会错过更少的跳跃次数。

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(1)\)

## 代码

### 解法一：动态规划

```java
public int jump(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];                     // dp[i]：跳到 i 的最少次数
    Arrays.fill(dp, Integer.MAX_VALUE);
    dp[0] = 0;
    for (int i = 0; i < n; i++) {
        if (dp[i] == Integer.MAX_VALUE) continue;  // 位置 i 不可达
        for (int j = i + 1; j <= Math.min(n - 1, i + nums[i]); j++) {
            dp[j] = Math.min(dp[j], dp[i] + 1);
        }
    }
    return dp[n - 1];
}
```

### 解法二：贪心（推荐）

```java
public int jump(int[] nums) {
    int n = nums.length;
    int end = 0;        // 当前层（本跳）能覆盖的右边界
    int farthest = 0;   // 遍历至今能到的最远位置（下一层的边界）
    int steps = 0;
    // 只遍历到 n - 2：站在 n - 1 时不必再跳，避免多计一次
    for (int i = 0; i < n - 1; i++) {
        farthest = Math.max(farthest, i + nums[i]);
        if (i == end) {     // 走到当前层边界，必须再跳一次
            end = farthest; // 进入下一层
            steps++;
        }
    }
    return steps;
}
```

## 个人总结

### 1. 循环为什么只到 n-2（最经典的 off-by-one）

若遍历到 `n-1`，当 `i == end` 时会 `steps++`——但此时人已经站在终点，这一跳是白跳的。与其事后判断「是否已到终点」，不如**直接少看最后一格**。用 `[2,3,1,1,4]` 手动跑一遍边界即可验证：答案 2，多看一格会算成 3。

### 2. 贪心正确性 = 隐式 BFS 分层

`end` 是当前层的末尾，`farthest` 是下一层的末尾，`steps` 就是层数——这正是 BFS 的分层计数，只是省掉了队列。区间内任何接力点扩展出的下一层边界相同，所以「走满边界再跳」就是最优，无需回溯。

### 3. `farthest` 要在每次迭代都更新

`farthest = Math.max(...)` 必须放在 `if (i == end)` **之外**每轮执行；若只在跨边界时更新，会漏掉本层区间内的跳点。另外题目保证可达，`i == end` 时 `farthest > end` 恒成立，不会卡死；若去掉「保证可达」前提，这套写法需额外处理无解。

### 4. 「跳跃游戏」三兄弟对比

| 题目 | 问什么 | 套路 |
|:---|:---|:---|
| 55. 跳跃游戏 | 能否到达 | 单变量贪心：维护 `maxReach`，`i > maxReach` 则失败 |
| 45. 跳跃游戏 II | 最少跳几次 | 分层贪心：`end` / `farthest` 双边界计数 |
| 1306. 跳跃游戏 III | 能否到达值为 0 的位置（可跳 ±k） | 显式 BFS / DFS |

面试常从 55 追问到 45，务必能讲清「分层」概念以及为什么不需要队列。
