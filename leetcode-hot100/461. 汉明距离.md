# 461. 汉明距离

> **难度**：🟢 简单 | **标签**：位运算 | **企业**：—

## 题目描述

两个整数之间的**汉明距离**指的是这两个数字对应二进制位不同的位置的数目。

给你两个整数 `x` 和 `y`，计算并返回它们之间的汉明距离。

## 示例

**示例 1**

```
输入：x = 1, y = 4
输出：2

解释：
  1 的二进制: 0 0 0 1
  4 的二进制: 0 1 0 0
              ↑   ↑    ← 这两个位置不同，距离=2
```

**示例 2**

```
输入：x = 3, y = 1
输出：1

解释：
  3 的二进制: 0 0 1 1
  1 的二进制: 0 0 0 1
                    ↑  ← 这个位置不同，距离=1
```

---

## 提示

- \\(0 \\le x, y \\le 2^{31} - 1\\)

---

## 进阶

无特别进阶要求。这道题的核心是位运算基本功：**XOR + 统计 1 的个数**。

---

## 思路

### 核心思想

```
汉明距离 = x ⊕ y 的结果中 1 的个数

因为 XOR (⊕) 的特点是「相同得 0，不同得 1」，
恰好匹配汉明距离的定义——统计不同位的数量。
```

```
        十进制   二进制
x = 1     →     0 0 0 1
y = 4     →     0 1 0 0
     ⊕    ─────────────────
x ⊕ y = 5       0 1 0 1    ← 有 2 个 1 → 距离=2 ✓
```

### 统计二进制中 1 的个数

**方法一：`Integer.bitCount()`**（最简单）

```java
return Integer.bitCount(x ^ y);
```

**方法二：`n & (n - 1)` 消最低位 1**（经典位运算技巧）

```
每次操作: n = n & (n - 1)  可以消掉最低位的 1

演示：n = 5 (0101)
  n & (n-1) = 0101 & 0100 = 0100  (count=1, 消掉末位 1)
  n & (n-1) = 0100 & 0011 = 0000  (count=2, 消掉次高位 1)
  n == 0 → 结束，count=2 ✓
```

**方法三：逐位检查**

```java
while (n != 0) {
    count += n & 1;  // 判断最低位是否为 1
    n >>>= 1;         // 无符号右移
}
```


### 解法二：`n & (n - 1)` 手动统计

```java
public int hammingDistance(int x, int y) {
    int xor = x ^ y;
    int count = 0;
    while (xor != 0) {
        xor = xor & (xor - 1);  // 消掉最低位的 1
        count++;
    }
    return count;
}
```

### 解法三：逐位移位

```java
public int hammingDistance(int x, int y) {
    int xor = x ^ y;
    int count = 0;
    while (xor != 0) {
        count += xor & 1;
        xor >>>= 1;
    }
    return count;
}
```
