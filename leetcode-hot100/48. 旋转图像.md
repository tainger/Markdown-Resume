## 题目描述

给定一个 `n × n` 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在**原地**旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要**使用另一个矩阵来旋转图像。

---

## 示例

**示例 1**

```
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]
```

**示例 2**

```
输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

---

## 提示

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

---

## 思路

### 核心思想

顺时针旋转 90°，本质是找到「原位置 `(i,j)`」旋转后落到「新位置」的映射。观察规律：**原来的第 `i` 行，会变成新矩阵的倒数第 `i` 列**。用公式表达：

```
旋转后 matrix_new[j][n-1-i] = matrix_old[i][j]
```

直接开一个新矩阵按公式填写最简单（解法一），但题目要求**原地**。原地的巧法是把「旋转」拆成两个可原地完成的操作：**先沿主对角线转置，再把每一行左右翻转**——两步的复合恰好等于顺时针旋转 90°。

### 解法一：辅助矩阵（先跑通，不满足原地）

新建一个 `n×n` 矩阵，按映射公式 `new[j][n-1-i] = old[i][j]` 填入，再拷回原矩阵。

- 时间复杂度：\(O(n^2)\)，空间复杂度：\(O(n^2)\)。直观但用了额外矩阵，不满足进阶。

### 解法二：转置 + 每行翻转（推荐，原地）

**第一步：主对角线转置**（`(i,j)` 与 `(j,i)` 互换），把行列对调：

```
1 2 3        1 4 7
4 5 6   →    2 5 8
7 8 9        3 6 9
```

**第二步：每一行左右翻转**：

```
1 4 7        7 4 1
2 5 8   →    8 5 2
3 6 9        9 6 3   ← 即顺时针旋转 90° 的结果 ✅
```

为什么成立？转置把 `(i,j)→(j,i)`，行翻转再把 `(j,i)→(j,n-1-i)`，复合起来正是 `(i,j)→(j,n-1-i)`，与旋转公式一致。

- 时间复杂度：\(O(n^2)\)，空间复杂度：\(O(1)\)（原地，满足进阶）。

> 💡 逆时针旋转 90° 则是「转置 + 每列翻转」或「每行翻转 + 转置」。

## 代码

### 解法一：辅助矩阵（不满足原地）

```java
class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;
        int[][] tmp = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                tmp[j][n - 1 - i] = matrix[i][j];      // 旋转映射公式
            }
        }
        for (int i = 0; i < n; i++) {
            matrix[i] = tmp[i];                          // 拷回（或逐元素复制）
        }
    }
}
```

### 解法二：转置 + 每行翻转（推荐，原地）

```java
class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;
        // 第一步：主对角线转置，只遍历上三角（j 从 i+1 开始），避免换两次换回去
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int t = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = t;
            }
        }
        // 第二步：每一行左右翻转
        for (int i = 0; i < n; i++) {
            int l = 0, r = n - 1;
            while (l < r) {
                int t = matrix[i][l];
                matrix[i][l] = matrix[i][r];
                matrix[i][r] = t;
                l++; r--;
            }
        }
    }
}
```

## 个人总结

### 1. 先推出旋转映射公式

不管哪种解法，先在草稿纸上推出 `new[j][n-1-i] = old[i][j]`（可拿 3×3 具体带一组下标验证）。有了公式，辅助矩阵解法就是照着填；原地解法也是围绕它设计。**下标推错是本题唯一的难点。**

### 2. 原地精髓：转置 + 每行翻转

顺时针 90° = **主对角线转置 → 每行左右翻转**。这是必须记住的组合拳。理解「两步复合等于旋转」比死背更牢：转置 `(i,j)→(j,i)`，行翻转 `(j,i)→(j,n-1-i)`。

### 3. 转置只遍历上三角

转置的内层循环 `j` 要从 `i+1` 开始，只处理主对角线**上方**的元素。若 `j` 从 0 开始遍历整个矩阵，每对元素会被交换两次，等于没换。这是转置最常见的 bug。

### 4. 别混淆顺/逆时针

- **顺时针 90°**：转置 + 每行翻转（或：每列翻转 + 转置）。
- **逆时针 90°**：转置 + 每列翻转（或：每行翻转 + 转置）。
- **180°**：每行翻转 + 每列翻转（或直接 `(i,j)↔(n-1-i,n-1-j)`）。

记不住时，拿 `[[1,2],[3,4]]` 手推一遍最快。

### 5. 进阶还有「四点一组循环交换」法

更硬核的原地做法是把旋转看成**四个位置一组的环形交换**：`(i,j)→(j,n-1-i)→(n-1-i,n-1-j)→(n-1-j,i)→(i,j)`，一次循环搞定四个点，只遍历左上角 1/4。它空间也是 O(1) 但下标极易写错，面试用「转置+翻转」更稳、更好讲。

### 6. 两种解法取舍

| 解法 | 时间 | 空间 | 定位 |
|:---|:---:|:---:|:---|
| 辅助矩阵 | \(O(n^2)\) | \(O(n^2)\) | 直观，不满足原地 |
| 转置 + 翻转 | \(O(n^2)\) | \(O(1)\) ✅ | 满足进阶，最优 |

**面试建议**：先用辅助矩阵说清旋转映射公式（证明会做），再点出题目要原地，给出「转置 + 每行翻转」并解释两步复合为何等于旋转——层层递进最出彩。
