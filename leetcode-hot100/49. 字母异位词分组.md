## 题目描述

给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

**字母异位词** 是由重新排列源单词的所有字母得到的一个新单词。

## 示例

**示例 1**

```
输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

**示例 2**

```
输入: strs = [""]
输出: [[""]]
```

**示例 3**

```
输入: strs = ["a"]
输出: [["a"]]
```

---

## 提示

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

---

## 思路

### 核心思想

互为异位词的字符串必然共享同一个「规范形（canonical form）」——把它当哈希表的 key 分桶即可。两种规范形：**排序后的字符串**（简单）或 **26 个字母的计数串**（免排序）。

### 解法一：排序作 key（基础）

1. 对每个字符串内部排序，得到规范形 key；
2. `map.computeIfAbsent(key, ...)` 把原串挂到对应分组。

- 时间复杂度：\(O(n \cdot k\log k)\)（n 个串、串长 k），空间复杂度：\(O(n \cdot k)\)

### 解法二：26 位计数串作 key（推荐）

1. 对每个字符串统计 26 个字母的出现次数；
2. 把计数拼成定长串（如 `a1#b0#c0#...`）当 key，挂到分组。

计数是 \(O(k)\)、拼 key 是 \(O(26)\)，省掉了排序的 \(\log k\) 因子。

- 时间复杂度：\(O(n \cdot k)\)，空间复杂度：\(O(n \cdot k)\)

## 代码

### 解法一：排序作 key

```java
public List<List<String>> groupAnagrams(String[] strs) {
    // key：排序后的字符串；互为异位词的串排序后一定相同
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        char[] arr = s.toCharArray();
        Arrays.sort(arr);
        String key = new String(arr);
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
```

### 解法二：26 位计数串作 key（推荐）

```java
public List<List<String>> groupAnagrams(String[] strs) {
    // key：26 个字母的出现次数拼成的串，免去排序的 log 因子
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) {
            cnt[c - 'a']++;
        }
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 26; i++) {
            sb.append((char) ('a' + i)).append(cnt[i]).append('#');
        }
        String key = sb.toString();   // 如 "a1#b0#c0#..."，26 段定长、无歧义
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
```

## 个人总结

### 1. 拼 key 最怕歧义，分隔符不能省

直接拼计数数字串有歧义：`"a12b2"` 是 a×12 还是 a×1、b×2？**每个计数带上字母和分隔符**（`a1#b0#...`），26 段定长，天然无歧义。这是本题最隐蔽的高频 bug。

### 2. 两种规范形怎么选

| 规范形 | 单串成本 | 实现 | 适用 |
|:---|:---|:---|:---|
| 排序串 | \(O(k\log k)\) | 两行搞定 | 面试先写它，快且不易错 |
| 计数串 | \(O(k + 26)\) | 多几行 | 串很长（k 大）时更优 |

若字符集是 Unicode（无 26 上限），计数版要改成 `Map<Character, Integer>` 计数再排序 key——这也是常见追问。

### 3. `computeIfAbsent` 一行完成分组

`map.computeIfAbsent(key, k -> new ArrayList<>()).add(s)` 等价于「查 → 没有 new → add」三步，比 `getOrDefault` + `put` 少一次哈希查找，还不会写漏 `put`。最后 `new ArrayList<>(map.values())` 收组。
