## 题目描述

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或斜线上的棋子。

**n 皇后问题** 研究的是如何将 `n` 个皇后放置在 `n × n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n` ，返回所有不同的 **n 皇后问题** 的解决方案。

每一种解法包含一个不同的 **n 皇后问题** 的棋子放置方案，这些方案中 `'Q'` 和 `'.'` 分别代表了皇后和空位。

## 思路

### 核心思想

**逐行放置**：每行恰好放一个皇后，行冲突自动消除，只剩列和两个斜线方向要防——用三个集合记录已被占用的**列**、**主对角线（`r - c`）**、**副对角线（`r + c`）**，回溯时对每行逐列尝试，冲突即剪枝。

### 解法一：回溯 + 三个集合剪枝（推荐）

1. 从第 `0` 行开始 DFS，每行枚举列 `c = 0 .. n-1`；
2. 若 `c`、`r - c + n - 1`、`r + c` 任一已被占用 → 剪枝跳过；
3. 否则放置：标记三个集合、记录 `col[row] = c`，递归下一行，返回后**撤销三个标记**；
4. `row == n` → 找到完整方案，按 `col[]` 还原棋盘字符串加入结果。

**对角线编号技巧**：同一主对角线上 `r - c` 为定值（范围 `-(n-1) .. n-1`，加 `n - 1` 平移成数组下标）；同一副对角线上 `r + c` 为定值（范围 `0 .. 2n-2`）。

- 时间复杂度：\(O(n!)\)（剪枝后远小于暴力 \(O(n^n)\)）；空间复杂度：\(O(n)\) 递归栈 + 集合（不计结果）

### 解法二：位运算优化（加分项）

用三个整数的二进制位代替三个集合：`cols`、`ld`、`rd` 分别是列 / 左斜线 / 右斜线的「被攻击位置」掩码。当前行可放位置 = `((1 << n) - 1) & ~(cols | ld | rd)`；递归时 `cols | pos` 原样传，`(ld | pos) << 1`、`(rd | pos) >> 1`——**斜线攻击随下一行整体平移一格**。`pos & (-pos)` 取最低可用位逐个枚举。

- 时间复杂度：\(O(n!)\)，常数显著更小；空间复杂度：\(O(n)\)

## 代码

### 解法一：回溯 + 三个集合（推荐）

```java
class Solution {
    private int n;
    private int[] col;                                  // col[r] = 第 r 行皇后所在列
    private boolean[] usedCol, usedDiag1, usedDiag2;    // 列 / 主对角线 / 副对角线
    private List<List<String>> ans = new ArrayList<>();

    public List<List<String>> solveNQueens(int n) {
        this.n = n;
        col = new int[n];
        usedCol = new boolean[n];
        usedDiag1 = new boolean[2 * n - 1];   // 主对角线：r - c + n - 1 ∈ [0, 2n-2]
        usedDiag2 = new boolean[2 * n - 1];   // 副对角线：r + c ∈ [0, 2n-2]
        dfs(0);
        return ans;
    }

    private void dfs(int row) {
        if (row == n) {                        // n 行放满，还原棋盘
            List<String> board = new ArrayList<>();
            for (int r = 0; r < n; r++) {
                char[] ch = new char[n];
                Arrays.fill(ch, '.');
                ch[col[r]] = 'Q';
                board.add(new String(ch));
            }
            ans.add(board);
            return;
        }
        for (int c = 0; c < n; c++) {          // 当前行尝试每一列
            int d1 = row - c + n - 1, d2 = row + c;
            if (usedCol[c] || usedDiag1[d1] || usedDiag2[d2]) continue;  // 冲突剪枝
            usedCol[c] = usedDiag1[d1] = usedDiag2[d2] = true;   // 做选择
            col[row] = c;
            dfs(row + 1);
            usedCol[c] = usedDiag1[d1] = usedDiag2[d2] = false;  // 撤销选择
        }
    }
}
```

### 解法二：位运算优化

```java
class Solution {
    private int n;
    private int[] col;                          // col[r] = 第 r 行皇后所在列
    private List<List<String>> ans = new ArrayList<>();

    public List<List<String>> solveNQueens(int n) {
        this.n = n;
        col = new int[n];
        dfs(0, 0, 0, 0);
        return ans;
    }

    // cols: 已占列的掩码; ld: 左斜线攻击掩码; rd: 右斜线攻击掩码
    private void dfs(int row, int cols, int ld, int rd) {
        if (row == n) {                         // 还原棋盘
            List<String> board = new ArrayList<>();
            for (int r = 0; r < n; r++) {
                char[] ch = new char[n];
                Arrays.fill(ch, '.');
                ch[col[r]] = 'Q';
                board.add(new String(ch));
            }
            ans.add(board);
            return;
        }
        int available = ((1 << n) - 1) & ~(cols | ld | rd);  // 当前行可放位置
        while (available != 0) {
            int pos = available & (-available);  // 取最低位的 1（一个候选位置）
            available &= available - 1;          // 从候选中移除，继续枚举
            col[row] = Integer.numberOfTrailingZeros(pos);   // 位 → 列下标
            dfs(row + 1,
                cols | pos,        // 列占用直接累积
                (ld | pos) << 1,   // 左斜线攻击随下一行整体左移一格
                (rd | pos) >> 1);  // 右斜线攻击随下一行整体右移一格
        }
    }
}
```

## 个人总结

### 1. 逐行放置 = 消掉一个维度

皇后攻击行、列、斜线三个方向。**按行枚举**后「同行不冲突」自动满足，只需再防列和两条斜线——把二维问题压成一维。棋盘类回溯（数独、37 解数独）都吃这个套路：**固定行列顺序枚举 + 冲突判断做成 O(1) 查表**，回溯树才不会爆炸。

### 2. 对角线的数学表示：`r - c` 与 `r + c`

| 方向 | 同线特征 | 取值范围 | 数组化 |
|:---|:---|:---|:---|
| 主对角线（↘） | `r - c` 为定值 | `-(n-1) .. n-1` | `r - c + n - 1` 平移到 `[0, 2n-2]` |
| 副对角线（↙） | `r + c` 为定值 | `0 .. 2n-2` | 直接当下标用 |

在 4×4 棋盘上亲手把 `r-c`、`r+c` 各标一遍就能永久记住，比背结论靠谱。

### 3. `n = 2`、`n = 3` 无解是正常输出

n=2、n=3 时任何摆放都会互相攻击，返回**空列表**才是对的，别把空输出当 bug 排查半天。另外本题是「输出所有方案」；[52. N 皇后 II](52.%20N%20皇后%20II.md) 只问方案数——回溯骨架完全一致，去掉棋盘还原、改为计数即可，常作为追问。

### 4. 位运算版：斜线用「随行平移的掩码」

位运算解法把三个布尔数组压成三个整数，精髓在**斜线掩码的平移**：在第 `row` 行的 `pos` 位置放皇后，它对 `row+1` 行的攻击位置就是 `pos << 1`（左斜线）和 `pos >> 1`（右斜线），所以递归参数写 `(ld | pos) << 1`、`(rd | pos) >> 1`；列掩码不平移。`pos & (-pos)` 取最低位、`available & (available - 1)` 消掉已枚举位，是位枚举的固定招式。面试先写集合版（容易讲对），位运算作为加分项提一句。

> 记忆：**「N 皇后」→ 逐行回溯 + 三个布尔数组（列、`r-c+n-1`、`r+c`）O(1) 判冲突，递归返回必须撤销标记；位运算版用「平移的掩码」表达斜线攻击。**
