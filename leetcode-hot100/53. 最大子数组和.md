## 题目描述

给你一个整数数组 `nums` ，请你找出一个具有**最大和的连续子数组**（子数组最少包含一个元素），返回其最大和。

**子数组**是数组中的一个**连续**部分。

---

## 示例

**示例 1**

```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6。
```

**示例 2**

```
输入：nums = [1]
输出：1
```

**示例 3**

```
输入：nums = [5,4,-1,7,8]
输出：23
```

## 提示

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

**进阶**：如果你已经实现复杂度为 \(O(n)\) 的解法，尝试使用更为精妙的**分治法**求解。

## 思路

### 核心：以 i 结尾的最大子数组和，只由「前一个位置的状态」决定

暴力枚举所有子数组是 \(O(n^2)\)。关键观察：**以 `i` 结尾的最大子数组和**，要么是把 `nums[i]` 接到前面那段上，要么自己另起一段——前面那段是「正资产就接、负资产就甩」。这一步决策只依赖前一个位置的状态 → 一维 DP / 贪心，\(O(n)\)。

五种解法一条链：

| 解法 | 视角 | 时间 | 空间 |
|:---|:---|:---:|:---:|
| 解法一：暴力 | 枚举所有子数组逐个求和 | \(O(n^2)\) | \(O(1)\) |
| 解法二：贪心 | 前缀和是正资产就继续背，变负就清零重开 | \(O(n)\) | \(O(1)\) |
| 解法三：前缀和 | `sum[i..j] = P[j+1] - P[i]`，维护历史最小前缀 | \(O(n)\) | \(O(1)\) |
| 解法四：DP（Kadane） | `dp[i]` = 以 i 结尾的最大子数组和 | \(O(n)\) | \(O(1)\)（滚动变量） |
| 解法五：分治 | 区间答案 = max(左答案, 右答案, 跨中线答案) | \(O(n\log n)\) | \(O(\log n)\) 栈 |

### 解法一：暴力枚举（TLE，理解入口）

按定义直译：所有子数组里挑和最大的。

1. 外层枚举起点 `i`，内层枚举终点 `j`；
2. 内层**累加**维护 `sum[i..j]`（终点右移一步只加一个元素，避免三重循环的 \(O(n^3)\)）；
3. 全程取 max。

- 时间 \(O(n^2)\)：`n = 10^5` 时约 \(10^{10}\) 次操作，**必然 TLE**；空间 \(O(1)\)
- 价值：定义最直白，先写它把「正确答案」做实。瓶颈：每个终点都要从头累加，**相邻子问题之间零信息复用**——而「以 i 结尾」分组后状态可递推，正是后面 \(O(n)\) 解法的突破口

### 解法二：贪心（最直观）

遍历中维护当前累积和 `curSum`：

1. `curSum += nums[i]`，随时用 `curSum` 更新全局答案 `ans`；
2. 若 `curSum < 0`：**负的累积和只会拖累后文**，直接清零（丢弃前缀，从下一个元素重开）；
3. `ans` 记录全程出现过的最大值。

- 时间 \(O(n)\)、空间 \(O(1)\)
- 正确性：一段前缀一旦为负，接在它后面只会让后面的子数和变小，扔掉一定不亏

### 解法三：前缀和 + 维护最小前缀（换了视角的 \(O(n)\)）

子数组和 = 两个前缀和之差：`sum[i..j] = P[j+1] - P[i]`。要最大化 `P[j+1] - P[i]`，只需在遍历到 `j` 时，用「**之前出现过的最小前缀** `minPre`」去减：

1. 边遍历边累积前缀和 `P`；
2. `ans = max(ans, P - minPre)`；
3. 再用当前 `P` 更新 `minPre`（**先算差再更新最小值**，保证子数组非空）。

- 时间 \(O(n)\)、空间 \(O(1)\)
- 这套「维护历史最值前缀」直接迁移到环形版 918. 环形子数组的最大和，是它比 Kadane 更通用的原因

### 解法四：动态规划（Kadane 算法，面试标准答案）

1. 定义 `dp[i]` = **以 `nums[i]` 结尾**的最大子数组和（注意结尾必须含 i，不是全局）
2. 转移：`dp[i] = max(dp[i-1] + nums[i], nums[i])` —— 前一段是正资产就接上，否则从 i 另起炉灶
3. 答案 = `max(dp[0..n-1])`（全局最大）
4. `dp[i]` 只依赖 `dp[i-1]` → 滚动变量压缩成一维，空间 \(O(1)\)

- 时间 \(O(n)\)、空间 \(O(1)\)
- 易错点：初始化 `ans` 和 `cur` 都要用 `nums[0]`，不能初始化为 0（全负数组会错）

### 解法五：分治（进阶，面试加分）

把数组从中间劈成两半，最大子数组只有三种落位：**全在左 / 全在右 / 跨中线**。跨中线的情况 = 左半「以中线结尾的最大后缀」+ 右半「从中线开始的最大前缀」。递归四元组 `(区间和, 最大前缀, 最大后缀, 区间最大子数组和)` 自底向上合并。

- 时间 \(O(n\log n)\)、空间 \(O(\log n)\) 递归栈
- 价值：这是**线段树维护区间最大子段和**的雏形（单点修改 + 区间查询最大子段和，见 [洛谷 P4513 / 线段树进阶](../算法思想/README.md)），面试说出这层延伸即可，手写非必需

## 代码

### 解法一：暴力枚举（TLE，理解入口）

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int n = nums.length, ans = Integer.MIN_VALUE;
        for (int i = 0; i < n; i++) {          // 枚举起点 i
            int curSum = 0;
            for (int j = i; j < n; j++) {      // 终点 j 右扩，curSum = sum[i..j]
                curSum += nums[j];             // 累加代替重新求和：O(n³) → O(n²) 的关键
                ans = Math.max(ans, curSum);
            }
        }
        return ans;
    }
}
```

- `n = 10^5` 时约 \(10^{10}\) 次操作，**LeetCode 必超时**——先写它验证正确性，再往下优化
- 若再嵌一层「内层求和」就是最原始的 \(O(n^3)\)：`sum[i..j]` 每次从头加一遍，丢掉了「终点右移一步只多一个元素」的增量信息

### 解法二：贪心

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int ans = Integer.MIN_VALUE;
        int curSum = 0;
        for (int x : nums) {
            curSum += x;
            ans = Math.max(ans, curSum);   // 先记录，再判丢弃——保证至少包含当前元素
            if (curSum < 0) curSum = 0;    // 负前缀是负资产，清零重开
        }
        return ans;
    }
}
```

- 「先记录再清零」的顺序不能反：全负数组 `[-3,-1,-2]` 若先清零后记录，会把合法的 `-1` 丢成 0

### 解法三：前缀和 + 最小前缀

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int ans = Integer.MIN_VALUE;
        int prefix = 0, minPre = 0;        // minPre 初始 0 = 空前缀（对应子数组从头开始）
        for (int x : nums) {
            prefix += x;
            ans = Math.max(ans, prefix - minPre);  // 以当前为右端点的最大子数组
            minPre = Math.min(minPre, prefix);     // 再更新最小前缀（顺序不可反）
        }
        return ans;
    }
}
```

- 「先减后更新」保证子数组非空；反了就变成允许空前缀，全负数组会错回 0

### 解法四：DP（Kadane，推荐）

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int cur = nums[0], ans = nums[0];  // 都用 nums[0] 初始化，防全负数组
        for (int i = 1; i < nums.length; i++) {
            // 以 i 结尾的最大和 = max(接上前一段, 从 i 重开)
            cur = Math.max(cur + nums[i], nums[i]);
            ans = Math.max(ans, cur);
        }
        return ans;
    }
}
```

- `cur` 的含义是「**必须以 i 结尾**」——这就是为什么答案要在遍历中对所有 `cur` 取 max，而不是直接返回 `cur`

### 解法五：分治（进阶）

```java
class Solution {
    // {区间和, 最大前缀和, 最大后缀和, 最大子数组和}
    private int[] divide(int[] nums, int l, int r) {
        if (l == r) return new int[]{nums[l], nums[l], nums[l], nums[l]};
        int mid = l + (r - l) / 2;
        int[] left = divide(nums, l, mid);
        int[] right = divide(nums, mid + 1, r);
        int[] merged = new int[4];
        merged[0] = left[0] + right[0];                       // 总和 = 左和 + 右和
        merged[1] = Math.max(left[1], left[0] + right[1]);    // 前缀 = 左前缀 或 左全部+右前缀
        merged[2] = Math.max(right[2], right[0] + left[2]);   // 后缀对称
        merged[3] = Math.max(Math.max(left[3], right[3]),     // 跨中线 = 左最大后缀+右最大前缀
                             left[2] + right[1]);
        return merged;
    }

    public int maxSubArray(int[] nums) {
        return divide(nums, 0, nums.length - 1)[3];
    }
}
```

## 个人总结

### 1. 题眼：连续子数组 + 最大和 → Kadane 一维 DP，\(O(n)\) 是底线

`n ≤ 10^5` 排除 \(O(n^2)\) 暴力。「以 i 结尾」的状态设计是本题灵魂：**子数组问题几乎都能用「以 i 结尾」+ 一维递推解决**（乘积版 152 同款）。

### 2. 推导链：暴力分组 → 暴露重复子结构 → 转移方程自己浮出来

把暴力枚举的所有子数组**按结尾位置重新分组**：

```
以 j 结尾：[0..j], [1..j], ..., [j..j]    ← 每组 j+1 个子数组，组与组之间大量重叠
```

**重复子结构在哪**：以 j 结尾的任何一个子数组，去掉末尾 `nums[j]` 后，都必然是「一个以 j−1 结尾的子数组」——同一批「以 k 结尾的前段」会被所有更大的 j 反复拼接。暴力里每个 `sum[i..j]` 都独立累加，正是把这些重叠部分反复算了一遍。

**从重复结构推方程**：「以 j 结尾的最大和」只有两种来源——接在一个以 j−1 结尾的子数组后面，或 `nums[j]` 单独成段：

```
dp[j] = max( max_{i}(sum[i..j-1]) + nums[j] ,  nums[j] )
              ↑ j-1 个候选里挑最大 = 就是 dp[j-1] 的定义！
      = max(dp[j-1] + nums[j], nums[j])
```

关键收敛一步：接「最大前段」一定不劣于接「非最大前段」（`nums[j]` 加在谁身上都一样），所以 \(O(j)\) 个候选坍缩成 1 个状态——**这一步就是 O(n²) → O(n) 的全部秘密**。

> 通用套路：**暴力 → 按某个维度重新分组 → 找「去掉最后一步」的依赖 → 写出二选一/多选一转移**。这与 [5. 最长回文子串](5.%20最长回文子串.md) 的「区间递推」是同一套推导纪律。

### 3. 状态定义的坑：「以 i 结尾」vs「前 i 个里选」

`dp[i]` 必须定义为**包含 `nums[i]`** 的最大子数组和——这样转移才有 `max(dp[i-1]+nums[i], nums[i])` 的清晰二选一。若定义成「前 i 个元素中的最大子数组和」，转移无从下手。**结尾必须连着**，全局答案另取 max。

### 4. 贪心 / 前缀和 / Kadane 三者同源

三版代码几乎是同一个循环的三种写法：贪心的 `curSum<0 清零` = Kadane 的 `max(cur+x, x)` 取 `x` 分支 = 前缀和的 `P - minPre`。**面试先写 Kadane（状态定义清晰），用前缀和视角讲原理（负前缀必甩），最顺**。

### 5. 全负数组是最大坑

`[-3,-1,-2]` 答案是 `-1` 不是 0（子数组不能为空）。三个守门点：初始化用 `nums[0]`/`MIN_VALUE`、贪心「先记录再清零」、前缀和「先减再更新最小值」。**测试用例必带全负数组**。

### 6. 分治的真正价值在延伸

单次求解分治 \(O(n\log n)\) 并不比 Kadane 快，它的价值是**四元组可挂到线段树上**：单点修改 + 区间查询最大子段和 \(O(\log n)\)，这是 Kadane 做不到的。面试口径：「静态数组用 Kadane，动态修改用线段树维护四元组」。

### 7. 同源题族：「以 i 结尾」模板的迁移

| 题目 | 变化点 | 迁移要点 |
|:---|:---|:---|
| 152. 乘积最大子数组 | 和→积 | 负×负变正 → 同时维护 max/min 双状态 |
| 918. 环形子数组的最大和 | 首尾可接 | 答案 = max(普通 Kadane, 总和−最小子数组和)，全负需特判 |
| 121. 买卖股票的最佳时机 | 差分后同构 | 价格转差分（前缀和视角），即求最大子数组和 |

> 记忆：**最大子数组和 = Kadane：`cur = max(cur+x, x)`，答案取全程 max；初始化和清零顺序防全负；进阶分治四元组挂线段树。**
