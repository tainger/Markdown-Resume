## 题目描述

给出二叉 **搜索** 树（BST）的根节点，该树的节点值各不相同，请你将其转换为累加树（Greater Sum Tree），使每个节点 `node` 的新值等于原树中大于或等于 `node.val` 的值之和。

提醒一下，二叉搜索树满足下列约束条件：

- 节点的左子树仅包含键 **小于** 节点键的节点。
- 节点的右子树仅包含键 **大于** 节点键的节点。
- 左右子树也必须是二叉搜索树。

## 思路

### 核心思想

**BST 的中序遍历（左→根→右）是升序**。要让每个节点加上「所有 ≥ 它的值之和」，就需要**从大到小**依次访问，累加一个 `sum`，赋给当前节点。

**从大到小 = 反序中序遍历（右→根→左）**：

```
普通中序（左→根→右）：升序 1 2 3 4 5 6 7 ...
反序中序（右→根→左）：降序 ... 7 6 5 4 3 2 1
```

沿降序方向遍历，维护一个累加值 `sum`，每到一个节点就 `sum += node.val`，再把 `sum` 写回 `node.val`。

### 图解（`[1,0,2]`）

```
        1
       / \
      0   2

反序中序遍历顺序：2 → 1 → 0

访问 2：sum = 0+2 = 2，节点2 = 2
访问 1：sum = 2+1 = 3，节点1 = 3
访问 0：sum = 3+0 = 3，节点0 = 3

结果：
        3
       / \
      3   2
```

### 解法一：反序中序遍历 - 递归（推荐）

1. 先递归**右子树**（更大的值）
2. 处理**当前节点**：`sum += node.val`，`node.val = sum`
3. 再递归**左子树**（更小的值）
- 时间复杂度：\(O(n)\)，每个节点访问一次
- 空间复杂度：\(O(n)\)，递归栈最坏为树高，退化链表时 \(O(n)\)

### 解法二：反序中序遍历 - 迭代（栈）

用栈显式模拟反序中序：先一路压入右链，弹出时累加，再转向左子树。
- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(n)\)（栈）

## 代码

### 我的伪代码

> 👇 初次尝试的错误版本（保留用于复盘），具体问题见下方 [个人总结](#个人总结)。

```java
// ✅ 遍历方向正确：先右 → 根 → 左（反序中序），思路对了
// ❌ 唯一的 bug：sum 用值传递，子调用里 sum 的累加传不回来，导致累加断裂
class Solution {
    public TreeNode convertBST(TreeNode root) {
        sumConvertBST(root, 0);
        return root;
    }

    private void sumConvertBST(TreeNode root, int sum) {  // ❌ sum 值传递，每层栈帧各一份
        if (root == null) {
            return;
        }
        if (null != root.right) {
            sumConvertBST(root.right, sum);               // ❌ 右子树里累加的 sum 出不来
        }
        sum += root.val;                                  //    这里的 sum 还是「进入本层时的值」
        root.val = sum;                                   //    → 写回的值不含右子树的累加
        if (null != root.left) {
            sumConvertBST(root.left, sum);
        }
    }
}
```

### 解法一：反序中序遍历 - 递归（修正版）

```java
class Solution {
    private int sum = 0;                  // 成员变量，跨递归共享累加值

    public TreeNode convertBST(TreeNode root) {
        dfs(root);
        return root;
    }

    private void dfs(TreeNode node) {
        if (node == null) return;
        dfs(node.right);                  // 1. 先遍历右子树（更大的值）
        sum += node.val;                  // 2. 累加：加上所有已访问的更大值
        node.val = sum;                   //    写回当前节点
        dfs(node.left);                   // 3. 再遍历左子树（更小的值）
    }
}
```

### 解法二：反序中序遍历 - 迭代（栈）

```java
public TreeNode convertBST(TreeNode root) {
    int sum = 0;
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {             // 一路压入右链（先访问最大值）
            stack.push(cur);
            cur = cur.right;
        }
        cur = stack.pop();
        sum += cur.val;                   // 累加并写回
        cur.val = sum;
        cur = cur.left;                   // 转向左子树
    }
    return root;
}
```

## 个人总结

### 1. 抓住「BST 中序有序」这一根本性质

BST 最重要的性质：**中序遍历（左→根→右）结果严格升序**。几乎所有 BST 题都能从这条性质切入：

| 需求 | 遍历方向 | 得到的顺序 |
|:---|:---|:---|
| 从小到大处理 | 中序：左→根→右 | 升序 |
| **从大到小处理** | **反序中序：右→根→左** | **降序** |

本题要「加上所有更大的值」，自然要从大到小走，于是用反序中序。

### 2. 为什么必须从大到小

每个节点的新值 = 原树中所有 ≥ 它的值之和。如果从大到小遍历，用 `sum` 累加已访问过的值（都比当前节点大），到当前节点时 `sum` 恰好就是「所有更大值之和」，加上自己即为答案。

- **顺序不能反**：若从小到大（普通中序：左→根→右），累加的是「更小的值」，得到的是「小于等于它的和」，与题意相反。（我的伪代码这一步是对的：先右→根→左，方向正确）

### 3. `sum` 为什么要用成员变量（我的伪代码的真实 bug）

我的伪代码方向完全正确（先右→根→左），唯一的问题是 **`sum` 用方法参数值传递**。Java 的 `int` 是值传递，子调用里对 `sum` 的累加，出了那层递归就丢了。

**用 `[1,0,2]` 走一遍看 bug 怎么发生**：

```
        1
       / \
      0   2      正确结果应为：节点2=2，节点1=3，节点0=3

进入 sumConvertBST(节点1, sum=0)
  → 递归右子树 sumConvertBST(节点2, sum=0)
        节点2 无右子树
        sum += 2 → sum=2，节点2.val=2 ✅
        （但这个 sum=2 是节点2 栈帧里的局部副本）
  ← 回到节点1，这里的 sum 仍然是 0 ❌（右子树的 2 没传回来）
  → sum += 1 → sum=1，节点1.val=1 ❌（本应是 3）
  → 递归左子树 sumConvertBST(节点0, sum=1)
        sum += 0 → sum=1，节点0.val=1 ❌（本应是 3）

错误结果：节点2=2，节点1=1，节点0=1
```

问题根源：**每层递归拿到的是 `sum` 的副本**，右子树累加出的值传不回父节点，累加链断裂。

**三种正确写法**：

| 写法 | 说明 |
|:---|:---|
| 成员变量 `private int sum` | 最直观，本笔记修正版采用 |
| 数组/包装 `int[] sum` | 用引用传递绕过值传递限制 |
| 让 dfs **返回**累加和 | `sum = dfs(node.right, sum)` 把结果接回来，再传给左子树 |

> 如果坚持用参数传递，最小改动是把 `sumConvertBST` 改成**返回 int**：右子树返回的 sum 接住后再累加当前节点，最后传给左子树——这样就不依赖成员变量也能跑通。

### 4. 递归 vs 迭代

| 解法 | 时间 | 空间 | 特点 |
|:---|:---:|:---:|:---|
| 递归 | \(O(n)\) | \(O(h)\) 递归栈 | 代码简洁，反序中序一目了然 |
| 迭代（栈） | \(O(n)\) | \(O(h)\) 显式栈 | 避免深递归爆栈，但代码较长 |

`h` 为树高，平衡时 \(O(\log n)\)，退化成链时 \(O(n)\)。

### 5. 与其他 BST 遍历题的联系

一旦掌握「中序=升序、反序中序=降序」，一批 BST 题都能统一处理：

| 题目 | 用到的性质 |

| 94. 二叉树的中序遍历 | 中序模板 |
| 230. BST 中第 K 小的元素 | 中序遍历到第 k 个 |
| 538 / 1038. 累加树 | **反序中序** + 累加 |
