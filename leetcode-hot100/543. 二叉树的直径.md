# 543. 二叉树的直径

> **难度**：🟢 简单 | **标签**：树、深度优先搜索、二叉树 | **企业**：—

## 题目描述

给你一棵二叉树的根节点 `root`，返回该树的**直径**。

二叉树的**直径**是指树中任意两个节点之间最长路径的**长度**。这条路径可能经过也可能不经过根节点 `root`。

两节点之间路径的**长度**由它们之间边的数量表示。

## 示例

**示例 1**

```
输入：root = [1,2,3,4,5]
输出：3

树结构:       路径分析:
     1        从节点 4 到节点 3:
    / \         4 → 2 → 1 → 3
   2   3        共 3 条边 ✓
  / \
 4   5
```

> 注意：最长路径是 `[4, 2, 1, 3]`，长度为 3。不是 `[4, 2, 1, 3] + [5, 2]`。

**示例 2**

```
输入：root = [1,2]
输出：1

树: 1 → 2，只有一条边
```

---

## 提示

- 树中节点数目在范围 `[1, 10^4]` 内
- `-100 <= Node.val <= 100`

## 进阶

无特别进阶要求。核心是理解「直径不一定过根节点」，需要在递归过程中用一个全局变量记录最大值。

---

## 思路

### 核心思想

```
对于任意节点 root，经过该节点的最长路径 =
  左子树深度（从 root.left 到最远叶子）+
  右子树深度（从 root.right 到最远叶子）

全局最大直径 = 所有节点的 max(左深度 + 右深度)
```

**关键洞察**：求深度和求直径可以在**同一次递归**中完成——递归返回深度，同时更新全局最大直径。

```
以示例 1 为例：

     1       节点 1: 左深=2, 右深=1, 直径=3  ← 更新 max=3
    / \      节点 2: 左深=1, 右深=1, 直径=2
   2   3     节点 3: 左深=0, 右深=0, 直径=0
  / \        节点 4: 左深=0, 右深=0, 直径=0
 4   5       节点 5: 左深=0, 右深=0, 直径=0

最终 max = 3 ✓
```

### 解法：递归（后序遍历）

1. 终止条件：`root == null` → 返回 0（null 的深度为 0）
2. 递归获取左右子树深度：`int L = depth(root.left)`, `int R = depth(root.right)`
3. **更新全局最大直径**：`max = Math.max(max, L + R)`
4. 返回当前节点的深度：`1 + Math.max(L, R)`

```
一次递归同时做两件事：
  ┌─ 返回值：当前节点的深度（用于父节点计算直径）
  └─ 副作用：更新全局最大直径
```

- 时间复杂度：\\(O(n)\\)，每个节点访问一次
- 空间复杂度：\\(O(h)\\)，递归栈深度

> ⚠️ 常见错误：直接 `return depth(root.left) + depth(root.right)`，这只算了**过根节点**的直径。必须用全局变量遍历所有节点。

### 解法：递归 + 全局变量

```java
class Solution {
    int maxDiameter = 0;

    public int diameterOfBinaryTree(TreeNode root) {
        depth(root);
        return maxDiameter;
    }

    // 返回当前节点的最大深度，同时更新全局 maxDiameter
    private int depth(TreeNode root) {
        if (root == null) return 0;

        int L = depth(root.left);   // 左子树深度
        int R = depth(root.right);  // 右子树深度

        // 经过当前节点的直径 = 左深 + 右深
        maxDiameter = Math.max(maxDiameter, L + R);

        // 当前节点的深度 = 1 + max(左深, 右深)
        return 1 + Math.max(L, R);
    }
}
```

### 解法二：纯树形 DP（`dfs` 返回多状态，不用全局变量）

上面那版其实已经是**树形递归**了：后序遍历、返回深度、顺带更新答案。这里给一个更「纯粹」的[树形 DP](../算法思想/1.动态规划.md) 写法——**不依赖成员变量**，让 `dfs` 一次返回**两个状态**：

- `res[0]` = 以该节点为端点、**向下**的最大深度（供父节点算深度用）
- `res[1]` = 以该节点为根的**子树内**的最大直径（把答案也随递归带上来）

父节点只需用左右子树的返回值合并出自己的两个值，根节点的 `res[1]` 就是答案。

```java
class Solution {
    public int diameterOfBinaryTree(TreeNode root) {
        return dfs(root)[1];        // 根子树内的最大直径即为答案
    }

    // 返回 [向下最大深度, 子树内最大直径]
    private int[] dfs(TreeNode root) {
        if (root == null) return new int[]{0, 0};   // 空节点：深度 0、直径 0

        int[] l = dfs(root.left);
        int[] r = dfs(root.right);                    // 后序：先拿左右子树的解

        int depth = 1 + Math.max(l[0], r[0]);         // 当前节点向下的最大深度
        int through = l[0] + r[0];                    // 经过当前节点的直径 = 左深 + 右深
        int diameter = Math.max(through,              // 三者取最大：过当前 / 落在左子树 / 落在右子树
                        Math.max(l[1], r[1]));

        return new int[]{depth, diameter};
    }
}
```

**两版对比**：

| | 解法一（全局变量） | 解法二（返回多状态） |
|:---|:---|:---|
| 答案存放 | 成员变量 `maxDiameter`（副作用更新） | 随 `dfs` 返回值 `res[1]` 层层带上来 |
| `dfs` 返回 | 单值（深度） | 数组 `[深度, 直径]` |
| 是否可重入 | 否（多次调用要重置成员变量） | 是（纯函数，无外部状态） |
| 本质 | 都是**后序遍历的树形 DP**，复杂度完全相同 | 同左 |

> 这正是 [1.动态规划.md 的「树形 DP」](../算法思想/1.动态规划.md) 里说的套路：**父子约束（这里是「路径经过某节点时只能各向下走一条链」）时，让 `dfs` 返回多个状态值**。同一模板可套 [337 打家劫舍 III](337.%20打家劫舍%20III.md)（返回 `[不偷, 偷]`）、[124 二叉树中的最大路径和](124.%20二叉树中的最大路径和.md)（返回向下最大链和 + 更新全局最大路径和）。

- 时间复杂度：\\(O(n)\\)　空间复杂度：\\(O(h)\\)（递归栈），与解法一一致。
