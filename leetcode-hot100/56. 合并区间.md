## 题目描述

以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [starti, endi]` 。请你合并所有重叠的区间，并返回 一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间 。

---

## 示例

**示例 1**

```
输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6]。
```

**示例 2**

```
输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释：区间 [1,4] 和 [4,5] 可被视为重叠区间。
```

---

## 提示

- `1 <= intervals.length <= 10^4`
- `intervals[i].length == 2`
- `0 <= starti <= endi <= 10^4`

---

## 思路

### 核心：先按左端点排序，让可能重叠的区间挨在一起

如果区间是乱序的，判断谁和谁重叠要两两比较，\(O(n^2)\)。**先按左端点升序排序**后，重叠的区间一定相邻，只需一次遍历，用「当前合并区间的右端点」和「下一个区间的左端点」比较即可。

```
排序后：[1,3] [2,6] [8,10] [15,18]

[1,3]           → 结果区放入 [1,3]
[2,6]  2 <= 3   → 与 [1,3] 重叠，合并右端点 max(3,6)=6 → [1,6]
[8,10] 8 >  6   → 不重叠，另起一段 [8,10]
[15,18]15 > 10  → 不重叠，另起一段 [15,18]

结果：[1,6] [8,10] [15,18]
```

### 判断重叠的条件

排序后，设结果里最后一个区间是 `last = [ls, le]`，当前区间 `cur = [cs, ce]`：

- **`cs <= le`**：重叠（或相邻可合并，如 `[1,4]` 与 `[4,5]`），合并 → `le = max(le, ce)`；
- **`cs > le`**：不重叠，`cur` 作为新区间加入结果。

注意合并时右端点取 `max(le, ce)`，不能直接用 `ce`——因为可能出现 `[1,9]` 与 `[2,5]` 这种**当前区间被上一个完全包住**的情况，此时右端点仍是 9。

### 步骤

1. 按左端点排序 `Arrays.sort(intervals, (a,b) -> a[0]-b[0])`；
2. 遍历每个区间：若结果为空、或当前左端点 `>` 结果末区间右端点 → 直接加入；否则更新末区间右端点为 `max`；
3. 返回结果。

- 时间复杂度：\(O(n \log n)\)，瓶颈在排序，遍历是 \(O(n)\)
- 空间复杂度：\(O(n)\)（结果数组）或 \(O(\log n)\)（排序栈，不计输出）

## 代码

### 排序 + 一次遍历合并（推荐）

```java
class Solution {
    public int[][] merge(int[][] intervals) {
        // 1) 按左端点升序排序，让重叠区间相邻
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        List<int[]> merged = new ArrayList<>();
        for (int[] cur : intervals) {
            int n = merged.size();
            // 结果为空，或当前左端点 > 上一个右端点 → 不重叠，另起一段
            if (n == 0 || cur[0] > merged.get(n - 1)[1]) {
                merged.add(new int[]{cur[0], cur[1]});
            } else {
                // 重叠：合并，右端点取较大者（防止当前区间被上一个包住）
                merged.get(n - 1)[1] = Math.max(merged.get(n - 1)[1], cur[1]);
            }
        }
        return merged.toArray(new int[merged.size()][]);
    }
}
```

## 个人总结

### 1. 区间题第一步：按端点排序

绝大多数区间问题（合并、覆盖、交集、插入）的第一步都是**排序**——按左端点或右端点排，把无序的两两比较变成有序的一次扫描。本题按**左端点**排，让重叠区间相邻。这和你整理的 [贪心算法.md](../算法思想/贪心算法.md) 里「区间问题先排序」的套路一致。

### 2. 重叠判断用 `cur[0] <= last[1]`（含相邻）

排序后只需比较当前左端点和上一个右端点。**`<=` 而非 `<`**：题目把 `[1,4]` 与 `[4,5]` 视为可合并（端点相接算重叠）。若某题要求「相接不算重叠」，才改成 `<`——看题意定。

### 3. 合并右端点必须取 `max`，别直接赋值

合并时 `last[1] = max(last[1], cur[1])`。反例 `[[1,9],[2,5]]`：排序后 `[2,5]` 的右端点 5 比 `[1,9]` 的 9 小，若直接赋值会把结果错缩成 `[1,5]`。**当前区间可能被上一个完全包含**，右端点要取大的。

### 4. 为什么排左端点就够，不用管右端点乱序

按左端点排序后，遍历到 `cur` 时，所有左端点 `≤ cur[0]` 的区间都已处理并合并进 `merged` 末尾。只要 `cur[0] <= merged 末尾右端点` 就必然与之重叠——**左端点有序保证了「不重叠就永远不会再重叠」**，可以放心另起新段。
