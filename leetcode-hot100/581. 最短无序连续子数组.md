## 题目描述

给你一个整数数组 `nums` ，你需要找出一个 **连续子数组** ，如果对这个子数组进行升序排序，那么整个数组都会变为升序排序。

请你找出符合题意的 **最短** 子数组，并输出它的长度。

---

## 示例

**示例 1**

```
输入：nums = [2,6,4,8,10,9,15]
输出：5
解释：你只需要对 [6,4,8,10,9] 进行升序排序，那么整个表都会变为升序排序。
```

**示例 2**

```
输入：nums = [1,2,3,4]
输出：0
解释：数组已经是升序，无需排序。
```

**示例 3**

```
输入：nums = [1]
输出：0
解释：单元素数组必然有序。
```

---

## 提示

- `1 <= nums.length <= 10^4`
- `-10^5 <= nums[i] <= 10^5`
- **进阶**：你可以设计一个时间复杂度为 \(O(n)\) 的解决方案吗？

## 思路

### 核心思想

把数组看成三段：**左段有序** | **中段无序** | **右段有序**。要求的就是**中段的长度**。关键是找出中段的左右边界。

### 解法一：排序对比（最直观）

1. 拷贝一份数组并排序
2. 从左找第一个与排序后不同的位置 → 左边界
3. 从右找第一个与排序后不同的位置 → 右边界
4. 两边界之间即为答案
- 时间复杂度：\(O(n\log n)\)（排序主导）
- 空间复杂度：\(O(n)\)（拷贝数组）

### 解法二：双指针多次遍历（易理解）

先把两个方向拆成**两趟独立扫描**，思路最清晰，是理解「一次遍历」版本的铺垫：

1. **第一趟（从左往右）找右边界**：维护前缀最大值 `max`，凡 `nums[i] < max` 就把 `right` 更新到 `i`
2. **第二趟（从右往左）找左边界**：维护后缀最小值 `min`，凡 `nums[j] > min` 就把 `left` 更新到 `j`
3. 两趟互不依赖，先后跑完即可
- 时间复杂度：\(O(n)\)（两趟线性，常数 2）
- 空间复杂度：\(O(1)\)

### 解法三：双指针一次遍历（推荐）

**核心洞察**：

- **右边界**：从左往右扫，维护「已扫过的最大值 `max`」。若 `nums[i] < max`，说明 `i` 处的值比左边某个数还小、位置不对，右边界要扩到 `i`
- **左边界**：从右往左扫，维护「已扫过的最小值 `min`」。若 `nums[i] > min`，说明 `i` 处的值比右边某个数还大、位置不对，左边界要扩到 `i`

在**同一个循环**里用对称下标 `i` 和 `n-1-i` 同时完成两个方向的扫描（把解法二的两趟合并成一趟）。
- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(1)\)

### 图解（`[2,6,4,8,10,9,15]`）

```
从左找右边界（维护 max）：
  i=1 6>2  max=6
  i=2 4<6  → right=2       (4 应该在 6 左边)
  i=5 9<10 → right=5       (9 应该在 10 左边)
  → right = 5

从右找左边界（维护 min）：
  i=5 9     min=9
  i=4 10>9  → left=4
  i=3 8>9? 否 min=8
  i=2 4>8? 否 min=4
  i=1 6>4  → left=1        (6 应该在 4 右边)
  → left = 1

长度 = right - left + 1 = 5 - 1 + 1 = 5 ✅
```

## 代码

### 我的伪代码

> 👇 初次尝试的错误版本（保留用于复盘），具体问题见下方 [个人总结](#个人总结)。

```java
// ❌ 错误1：已有序时（right 从未更新）忘了返回 0，会返回 right-left+1 = 负数或脏值
// ❌ 错误2：用 <= / >= 非严格比较，[1,1,1] 会被误判为无序
public int findUnsortedSubarray(int[] nums) {
    int n = nums.length;
    int left = 0, right = 0;
    int max = Integer.MIN_VALUE, min = Integer.MAX_VALUE;
    for (int i = 0; i < n; i++) {
        if (nums[i] <= max) right = i;        // ❌ <= 会把相等也算无序
        else max = nums[i];
        int j = n - 1 - i;
        if (nums[j] >= min) left = j;         // ❌ >= 同上
        else min = nums[j];
    }
    return right - left + 1;                   // ❌ 已有序时未返回 0
}
```

### 解法一：排序对比

```java
public int findUnsortedSubarray(int[] nums) {
    int n = nums.length;
    int[] sorted = nums.clone();
    Arrays.sort(sorted);
    int left = 0, right = n - 1;
    while (left < n && nums[left] == sorted[left]) {
        left++;                                // 跳过左侧已就位的部分
    }
    if (left == n) return 0;                    // 完全有序
    while (right > left && nums[right] == sorted[right]) {
        right--;                               // 跳过右侧已就位的部分
    }
    return right - left + 1;
}
```

### 解法二：双指针多次遍历（两趟）

```java
public int findUnsortedSubarray(int[] nums) {
    int n = nums.length;
    int left = -1, right = -1;                 // -1 表示尚未发现无序

    // 第一趟：从左往右，维护前缀最大值，找右边界
    int max = Integer.MIN_VALUE;
    for (int i = 0; i < n; i++) {
        if (nums[i] < max) {
            right = i;                         // 比左边最大值还小，位置不对
        } else {
            max = nums[i];
        }
    }

    // 第二趟：从右往左，维护后缀最小值，找左边界
    int min = Integer.MAX_VALUE;
    for (int j = n - 1; j >= 0; j--) {
        if (nums[j] > min) {
            left = j;                          // 比右边最小值还大，位置不对
        } else {
            min = nums[j];
        }
    }

    return right == -1 ? 0 : right - left + 1;
}
```

### 解法三：双指针一次遍历（推荐）

```java
public int findUnsortedSubarray(int[] nums) {
    int n = nums.length;
    int left = -1, right = -1;                 // -1 表示尚未发现无序
    int max = Integer.MIN_VALUE, min = Integer.MAX_VALUE;
    for (int i = 0; i < n; i++) {
        // 从左往右：比左侧最大值还小 → 位置不对，扩右边界
        if (nums[i] < max) {
            right = i;
        } else {
            max = nums[i];
        }
        // 从右往左：比右侧最小值还大 → 位置不对，扩左边界
        int j = n - 1 - i;
        if (nums[j] > min) {
            left = j;
        } else {
            min = nums[j];
        }
    }
    return right == -1 ? 0 : right - left + 1;  // 全程没更新说明已有序
}
```

## 个人总结

### 1. 三段式模型是解题的关键

数组天然分成 **左段有序 | 中段无序 | 右段有序** 三部分，题目要的就是中段长度。想清楚这个模型，剩下就是「如何定位中段左右边界」。

- **左段**：从头开始一直递增、且每个数都 ≤ 右边所有数的部分
- **右段**：从尾开始一直递增、且每个数都 ≥ 左边所有数的部分
- **中段**：夹在中间需要重排的部分

### 2. 为什么「前缀最大」能定右边界

从左往右扫时，`max` 是 `[0..i]` 的最大值。如果 `nums[i] < max`，说明在 `i` 左边存在一个比 `nums[i]` 大的数——那么 `nums[i]` 必须被移动，它的位置属于无序区，右边界至少要到 `i`。

**对称地**，从右往左维护 `min`，若 `nums[j] > min` 说明 `j` 右边有更小的数，`j` 属于无序区，左边界至少要到 `j`。

> 一句话：**「右边界 = 最后一个破坏前缀最大单调性的位置；左边界 = 最后一个破坏后缀最小单调性的位置」**。

### 3. 严格比较 vs 非严格比较

必须用 `<` 和 `>`（严格），不能用 `<=` / `>=`：

| 输入 | 严格 `<` | 非严格 `<=` |
|:---|:---|:---|
| `[1,1,1]` | right 不更新 → 返回 0 ✅ | 相等也算无序 → 返回 3 ❌ |

相等元素本身不破坏有序性，所以相等时不能扩边界。

### 4. 已有序时必须返回 0

`left`/`right` 初始化为 `-1`，若整个数组有序，两者始终为 `-1`，此时应返回 0 而不是 `right - left + 1`（会算出 `-1 - (-1) + 1 = 1` 的脏值）。用 `right == -1 ? 0 : ...` 判断最稳妥。

### 5. 从「多次遍历」到「一次遍历」的演进

**解法二（多次遍历）** 把两个方向拆成两趟：第一趟从左扫找右边界，第二趟从右扫找左边界，思路最直白。

**解法三（一次遍历）** 发现两趟互不干扰——从左扫用 `i` + `max`，从右扫用 `n-1-i` + `min`，操作的是不同变量，于是塞进同一个 `for` 里，把两趟合并成一趟：

```java
for (int i = 0; i < n; i++) {
    if (nums[i] < max) right = i; else max = nums[i];      // 正向：找右边界
    int j = n - 1 - i;
    if (nums[j] > min) left = j; else min = nums[j];       // 反向：找左边界
}
```

两者复杂度都是 \(O(n)\)/\(O(1)\)，一次遍历只是常数从 2 降到 1。**建议先用多次遍历理清思路，再合并成一次遍历**。

### 6. 四种解法的取舍

| 解法 | 时间 | 空间 | 何时用 |
|:---|:---:|:---:|:---|
| 排序对比 | \(O(n\log n)\) | \(O(n)\) | 想快速 AC、思路直观 |
| 双指针（多次遍历） | \(O(n)\) | \(O(1)\) | 理解阶段，两趟拆开最清晰 |
| 双指针（一次遍历） | \(O(n)\) | \(O(1)\) | 满足进阶要求，面试首选 |
| 单调栈 | \(O(n)\) | \(O(n)\) | 也可用栈找左右边界，但不如双指针简洁，见 [单调栈.md](../算法思想/单调栈.md) |

> 面试建议：先说排序对比证明思路，再给双指针 \(O(n)\)/\(O(1)\) 拿满进阶分；讲双指针时可以先说多次遍历、再顺势合并成一次遍历，展示优化过程。
