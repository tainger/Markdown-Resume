# 617. 合并二叉树

> **难度**：🟢 简单 | **标签**：树、深度优先搜索、广度优先搜索、二叉树 | **企业**：—

## 题目描述

给你两棵二叉树：`root1` 和 `root2`。

想象一下，当你将其中一棵覆盖到另一棵之上时，两棵树上的一些节点将会重叠（而另一些不会）。你需要将这两棵树合并成一棵新二叉树。

合并规则为：如果两个节点重叠，那么将这两个节点的值相加作为合并后节点的新值；否则，**不为** null 的节点将直接作为新二叉树的节点。

返回合并后的二叉树。合并过程必须从两个树的根节点开始。

## 示例

**示例 1**

```
输入：root1 = [1,3,2,5], root2 = [2,1,3,null,4,null,7]
输出：[3,4,5,5,4,null,7]

树 1:    1             树 2:    2              合并:     3
        / \                   / \                     /   \
       3   2                 1   3                   4     5
      /                       \   \                 / \     \
     5                         4   7               5   4     7
```

**示例 2**

```
输入：root1 = [1], root2 = [1,2]
输出：[2,2]
```

## 思路

### 核心思想

```
对每个位置 (node1, node2)：

  node1 和 node2 都非空 → 值相加，递归合并左右子树
  node1 为空 → 直接用 node2
  node2 为空 → 直接用 node1
```

以示例 1 的根节点为例：

```
root1 = 1, root2 = 2
  → 合并后根 = 1 + 2 = 3

左子树：node1=3, node2=1 → merged=4
  左.左: node1=5, node2=null → 直接用 5
  左.右: node1=null, node2=4 → 直接用 4

右子树：node1=2, node2=3 → merged=5
  右.右: node1=null, node2=7 → 直接用 7
```

### 解法一：递归（DFS）

1. 终止条件：`t1 == null` → 返回 t2；`t2 == null` → 返回 t1
2. 合并当前节点：`t1.val += t2.val`
3. 递归合并左右孩子：`t1.left = merge(t1.left, t2.left)`；`t1.right = merge(t1.right, t2.right)`
4. 返回 t1（复用 t1 节点，节省空间）

- 时间复杂度：\\(O(\\min(m, n))\\)，空间复杂度：\\(O(\\min(m, n))\\)

### 解法二：迭代（BFS 三队列）

用三个队列分别存合并后的节点、t1 节点、t2 节点，每次同时处理一堆：

1. 初始三队列入队根节点
2. 弹出 → 值相加 → 根据左右孩子情况决定入队 or 直接接管

- 时间复杂度：\\(O(\\min(m, n))\\)，空间复杂度：\\(O(\\min(m, n))\\)

> ⚠️ 面试时递归写法更受青睐，简洁且不容易出错。

### 解法一：递归（推荐）

```java
public TreeNode mergeTrees(TreeNode t1, TreeNode t2) {
    if (t1 == null) return t2;   // t1 空 → 直接用 t2
    if (t2 == null) return t1;   // t2 空 → 直接用 t1

    t1.val += t2.val;                                          // 合并值
    t1.left  = mergeTrees(t1.left,  t2.left);                 // 合并左子树
    t1.right = mergeTrees(t1.right, t2.right);                // 合并右子树

    return t1;
}
```

### 解法二：不修改原树（新建节点）

```java
public TreeNode mergeTrees(TreeNode t1, TreeNode t2) {
    if (t1 == null && t2 == null) return null;

    int val = (t1 == null ? 0 : t1.val) + (t2 == null ? 0 : t2.val);
    TreeNode node = new TreeNode(val);

    node.left  = mergeTrees(t1 == null ? null : t1.left,
                            t2 == null ? null : t2.left);
    node.right = mergeTrees(t1 == null ? null : t1.right,
                            t2 == null ? null : t2.right);
    return node;
}
```
