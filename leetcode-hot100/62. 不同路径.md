## 题目描述

一个机器人位于一个 `m x n` 网格的左上角 （起始点在下图中标记为 “Start” ）。

机器人每次只能**向下**或者**向右**移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

问总共有多少条不同的路径？

## 示例

**示例 1**

```
输入：m = 3, n = 7
输出：28
```

**示例 2**

```
输入：m = 3, n = 2
输出：3
解释：从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
```

**示例 3**

```
输入：m = 3, n = 3
输出：6
```

## 思路

### 核心思想

只能**向下或向右**走，所以到达 `(i,j)` 的每条路径，最后一步必然来自**上方 `(i-1,j)`** 或**左方 `(i,j-1)`**，两个来源的路径集合互不重叠且覆盖所有情况，直接相加即可。定义 `dp[i][j]` = 从左上角走到 `(i,j)` 的路径数：

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

```
3x3 网格的 dp 表（路径数）      3x7 的 dp 末行 → 答案 28
1  1  1
1  2  3
1  3  6   → dp[2][2] = 6 ✅
```

> 与 [64. 最小路径和](64.%20最小路径和.md) 是**孪生题**：同一网格模型、同一来源分析，那里求最值用 `min(上, 左)`，这里计数用 `上 + 左`。

### 解法一：二维 DP（基础）

第一行、第一列只有一条直路，初始化为 1；其余格子按转移方程递推。

- 时间复杂度：\(O(mn)\)，空间复杂度：\(O(mn)\)

### 解法二：一维滚动数组（推荐）

第 `i` 行只依赖第 `i-1` 行，可用一维数组滚动：更新前 `dp[j]` 存的是「上方」，`dp[j-1]` 已在本行更新过是「左方」，`dp[j] += dp[j-1]` 即可。

- 时间复杂度：\(O(mn)\)，空间复杂度：\(O(n)\)

### 解法三：组合数学（加分项）

任何一条路径都由 `m-1` 个「下」和 `n-1` 个「右」共 `m+n-2` 步排列而成，路径数 = 在 `m+n-2` 个位置里选 `m-1` 个放「下」：

```
ans = C(m+n-2, m-1)
```

计算时用 `long` 边乘边除（每一步结果都是组合数 `C(N-k+i, i)`，保证整除），复杂度 \(O(\min(m,n))\)。

## 代码

### 解法一：二维 DP

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];
        for (int i = 0; i < m; i++) dp[i][0] = 1;   // 第一列：只能一路向下，1 条
        for (int j = 0; j < n; j++) dp[0][j] = 1;   // 第一行：只能一路向右，1 条
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];  // 来自上方 + 来自左方
            }
        }
        return dp[m - 1][n - 1];
    }
}
```

### 解法二：一维滚动数组（推荐）

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[] dp = new int[n];
        Arrays.fill(dp, 1);                    // 第 0 行：全 1
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                // 更新前 dp[j] = 上一行同列(上方)，dp[j-1] = 本行左一列(左方)
                dp[j] = dp[j] + dp[j - 1];
            }
        }
        return dp[n - 1];
    }
}
```

### 解法三：组合数学（加分项）

```java
class Solution {
    public int uniquePaths(int m, int n) {
        // ans = C(m+n-2, k)，k 取较小的边，减少乘法次数
        int N = m + n - 2, k = Math.min(m - 1, n - 1);
        long ans = 1;                          // 中间乘积可能超 int，用 long
        for (int i = 1; i <= k; i++) {
            ans = ans * (N - k + i) / i;       // 边乘边除，每步恰好整除
        }
        return (int) ans;
    }
}
```

## 个人总结

### 1. 与 64. 最小路径和：同网格、同来源、不同运算

| 题目 | 状态定义 | 转移 | 初始化 |
|:---|:---|:---|:---|
| 62. 不同路径 | 到 (i,j) 的**路径数** | `dp[i-1][j] + dp[i][j-1]` | 第一行/列 = **1**（各只有一条直路） |
| 64. 最小路径和 | 到 (i,j) 的**最小路径和** | `grid[i][j] + min(上, 左)` | 第一行/列 = 前缀累加 |

见 [64. 最小路径和](64.%20最小路径和.md)。网格题先问自己：移动方向受限吗？受限 → 到某格的来源就固定，转移直接写出来。63. 不同路径 II 加障碍物，只需让障碍格 `dp = 0`。

### 2. 一维滚动的方向感

更新 `dp[j]` 时它还没被本行写过 → 是「上方」；`dp[j-1]` 刚更新过 → 是「左方」。和 64 的滚动数组完全一致的技巧，第一行用 `Arrays.fill(dp, 1)` 一次到位，不用单独处理第一列（`j=0` 不会被内层循环更新，天然保持 1）。

### 3. 组合数公式是面试加分项

推导：路径长度固定 `m+n-2`，本质是「下/右」两种步的多重排列 `C(m+n-2, m-1)`。实现细节：用 `long` 防溢出；`ans * (N-k+i) / i` 每步都整除（前 i 步乘积 = C(N-k+i, i) 是整数），不能先累乘再除。若被问「m、n 很大怎么算」或要求 \(O(\min(m,n))\) 时间，这解法就是标准答案。

### 4. 计数型 DP 的初始化语义与求最值型不同

计数题第一行/列的值是「方案的天然存在数」（= 1），不是 0 也不是负无穷；如果错填 0 会导致全表为 0。读题时先判断是**计数**（加法转移）还是**最值**（min/max 转移），初始化跟着语义走。
