## 题目描述

给定一个包含非负整数的 `m x n` 网格 `grid` ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**说明**：每次只能向下或者向右移动一步。

---

## 示例

**示例 1**

```
输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7
解释：因为路径 1→3→1→1→1 的总和最小。
```

**示例 2**

```
输入：grid = [[1,2,3],[4,5,6]]
输出：12
```

---

## 提示

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 200`

---

## 思路

### 核心思想

只能**向下或向右**走，所以到达 `(i,j)` 的路径必然从**上方 `(i-1,j)`** 或**左方 `(i,j-1)`** 而来。要让到 `(i,j)` 的路径和最小，就取这两个来源里较小的那个，再加上当前格子的值。定义 `dp[i][j]` = 从左上角走到 `(i,j)` 的最小路径和，则：

```
dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
```

> 思路演进遵循「**暴力递归 → 记忆化 → DP**」：先按上面的关系写自顶向下递归（解法一），发现 `(i,j)` 被重复计算导致指数级 → 加缓存变记忆化（解法四）→ 改成自底向上填表就是二维 DP（解法二）→ 滚动数组把空间压到 O(n)（解法三）。

### 初始化（边界）

- `dp[0][0] = grid[0][0]`：起点。
- **第一行**只能一路向右：`dp[0][j] = dp[0][j-1] + grid[0][j]`。
- **第一列**只能一路向下：`dp[i][0] = dp[i-1][0] + grid[i][0]`。

第一行/列没有「上方」或「左方」两个来源，不能套用通用转移，必须单独初始化。

```
grid            dp（最小路径和）
1 3 1           1  4  5
1 5 1     →     2  7  6
4 2 1           6  8  7   → dp[2][2] = 7 ✅
```

- 时间复杂度：\(O(mn)\)，空间复杂度：\(O(mn)\)（可滚动数组优化到 \(O(n)\)）。

## 代码

### 解法一：暴力递归（先跑通，会超时）

不带缓存的自顶向下递归：`dfs(i, j)` = 从起点走到 `(i,j)` 的最小路径和。存在大量**重复子问题**（同一 `(i,j)` 被上、左两条路反复问到），会退化成指数级。

```java
class Solution {
    public int minPathSum(int[][] grid) {
        return dfs(grid, grid.length - 1, grid[0].length - 1);
    }
    // 从 (0,0) 走到 (i,j) 的最小路径和
    private int dfs(int[][] grid, int i, int j) {
        if (i == 0 && j == 0) return grid[0][0];            // 起点
        if (i < 0 || j < 0) return Integer.MAX_VALUE;       // 越界，非法路径
        int up = dfs(grid, i - 1, j);                       // 从上方来
        int left = dfs(grid, i, j - 1);                     // 从左方来
        return grid[i][j] + Math.min(up, left);
    }
}
```

- 时间复杂度：最坏 \(O(2^{m+n})\)（每格两叉展开），指数级，会超时；空间 \(O(m+n)\)（递归栈）。

### 解法二：二维动态规划（推荐）

```java
class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dp = new int[m][n];
        dp[0][0] = grid[0][0];
        for (int j = 1; j < n; j++) dp[0][j] = dp[0][j - 1] + grid[0][j];  // 第一行
        for (int i = 1; i < m; i++) dp[i][0] = dp[i - 1][0] + grid[i][0];  // 第一列
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = grid[i][j] + Math.min(dp[i - 1][j], dp[i][j - 1]);
            }
        }
        return dp[m - 1][n - 1];
    }
}
```

### 解法三：滚动数组优化（空间 O(n)）

```java
class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] dp = new int[n];
        dp[0] = grid[0][0];
        for (int j = 1; j < n; j++) dp[j] = dp[j - 1] + grid[0][j];        // 第一行
        for (int i = 1; i < m; i++) {
            dp[0] += grid[i][0];                                            // 第一列（累加）
            for (int j = 1; j < n; j++) {
                // dp[j]=上一行同列(上方)  dp[j-1]=本行左一列(左方)
                dp[j] = grid[i][j] + Math.min(dp[j], dp[j - 1]);
            }
        }
        return dp[n - 1];
    }
}
```

### 解法四：记忆化搜索（自顶向下）

在解法一暴力递归基础上，用 `memo[i][j]` 缓存到 `(i,j)` 的最小路径和，每格只算一次，复杂度降到 \(O(mn)\)。

```java
class Solution {
    int[][] memo;
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        memo = new int[m][n];
        for (int[] row : memo) Arrays.fill(row, -1);
        return dfs(grid, m - 1, n - 1);
    }
    private int dfs(int[][] grid, int i, int j) {
        if (i == 0 && j == 0) return grid[0][0];
        if (i < 0 || j < 0) return Integer.MAX_VALUE;
        if (memo[i][j] != -1) return memo[i][j];
        int res = grid[i][j] + Math.min(dfs(grid, i - 1, j), dfs(grid, i, j - 1));
        return memo[i][j] = res;
    }
}
```

## 个人总结

### 1. 状态定义：dp[i][j] = 到 (i,j) 的最小路径和

「只能向下/向右」的网格路径题，标准状态就是「到某格的最优值」。因为移动方向受限，到 `(i,j)` 只可能从上方或左方来，转移天然是 `grid[i][j] + min(上, 左)`。看到这种网格 + 单向移动，直接套这个模型。

### 2. 第一行、第一列必须单独初始化

第一行没有「上方」、第一列没有「左方」，只有一个来源，是**前缀累加**。若不单独初始化就套用 `min(上, 左)`，会读到未定义/错误的值。这是网格 DP 最常见的坑。

### 3. 暴力递归的重复子问题

`dfs(i, j)` 会被 `(i+1, j)`（下方）和 `(i, j+1)`（右方）两条路都问到，同一格反复计算，退化成指数级。加 `memo` 后每格只算一次 → `O(mn)`。这条「暴力 → 记忆化 → DP」的链路和 [72 编辑距离](72.%20编辑距离.md)、[139 单词拆分](139.%20单词拆分.md) 完全一致。

### 4. 滚动数组：dp[j] 复用为「上方」，dp[j-1] 天然是「左方」

一维优化时，遍历到 `dp[j]` 时它**还没更新**，存的是上一行同列的值（即「上方」`dp[i-1][j]`）；而 `dp[j-1]` 已在本行更新过，是「左方」`dp[i][j-1]`。所以 `dp[j] = grid[i][j] + min(dp[j], dp[j-1])` 恰好对应 min(上, 左)。第一列要记得先 `dp[0] += grid[i][0]` 累加。

### 5. 求最小值时非法路径返回极大值

暴力/记忆化里越界返回 `Integer.MAX_VALUE`，让它在 `min` 中被自然淘汰。注意此时 `grid[i][j] + MAX_VALUE` 可能**溢出**——本题因为起点必达、越界只出现在第一行/列的边界外且总能取到合法的另一侧，未真正相加溢出；更稳妥可用二维 DP 显式初始化边界避开这个隐患。

### 6. 四种解法取舍

| 解法 | 时间 | 空间 | 定位 |
|:---|:---:|:---:|:---|
| 暴力递归 | \(O(2^{m+n})\) | \(O(m+n)\) | 理解转移，会超时 |
| 记忆化搜索 | \(O(mn)\) | \(O(mn)\) | 自顶向下，好理解 |
| 二维 DP | \(O(mn)\) | \(O(mn)\) | 标准解，最清晰 |
| 滚动数组 | \(O(mn)\) | \(O(n)\) ✅ | 空间最优 |

**面试建议**：先说暴力递归点出重复子问题 → 记忆化 → 二维 DP（配一张 dp 表最直观）→ 滚动数组优化。链路完整最加分。
