## 题目描述

给你一个字符串 `s` ，请你统计并返回这个字符串中 **回文子串** 的数目。

**回文字符串** 是正着读和倒过来读一样的字符串。

**子字符串** 是字符串中的由连续字符组成的一个序列。

**示例 1**

```
输入：s = "abc"
输出：3
解释：三个回文子串: "a", "b", "c"

**示例 2**

```
输入：s = "aaa"
输出：6
解释：6个回文子串: "a", "a", "a", "aa", "aa", "aaa"

## 思路

### 核心思想

**中心扩展法**：回文以「中心」对称——如果 `s[l..r]` 是回文，且 `s[l-1] == s[r+1]`，那么 `s[l-1..r+1]` 也是回文。所以我们**从一个种子中心出发，不断向两侧扩展**，每扩展成功一次就得到一个新的回文。

#### 与暴力的关键差异

| 解法 | 枚举对象 | 个数 | 每次判回文 | 总复杂度 |
|:---|:---|:---:|:---:|:---:|
| 暴力 | 子串起点终点 | \(O(n^2)\) | 从头双指针判 \(O(n)\) | \(O(n^3)\) |
| 中心扩展 | 中心位置 | \(2n-1\) | 增量判：只比较两侧新增字符 \(O(1)\) | \(O(n^2)\) |

**关键洞察**：暴力每次都从头判回文，做了大量重复比较；中心扩展**只比较「新增的两端」**一次，前缀的回文性已经保证。

#### 图解：以 `s = "aaa"` 为例

**单字符中心**（产生奇数长度回文，共 n=3 个）：

```
中心 = 索引 0（字符 'a'）
  扩展 step 0: l=0, r=0, s[0]==s[0] ✅ → 命中 "a"      count=1
  扩展 step 1: l=-1 越界 → 停

中心 = 索引 1（字符 'a'）
  扩展 step 0: l=1, r=1, s[1]==s[1] ✅ → 命中 "a"      count=2
  扩展 step 1: l=0, r=2, s[0]=='a'==s[2]=='a' ✅ → 命中 "aaa"  count=3
  扩展 step 2: l=-1 越界 → 停

中心 = 索引 2（字符 'a'）
  扩展 step 0: l=2, r=2, s[2]==s[2] ✅ → 命中 "a"      count=4
  扩展 step 1: l=1, r=3 越界 → 停
```

**双字符中心**（产生偶数长度回文，共 n-1=2 个）：

```
中心 = 索引 (0,1)（字符 'a','a'）
  扩展 step 0: l=0, r=1, s[0]=='a'==s[1]=='a' ✅ → 命中 "aa"   count=5
  扩展 step 1: l=-1 越界 → 停

中心 = 索引 (1,2)（字符 'a','a'）
  扩展 step 0: l=1, r=2, s[1]=='a'==s[2]=='a' ✅ → 命中 "aa"   count=6
  扩展 step 1: l=0, r=3 越界 → 停
```

最终 `count = 6`，与示例 2 一致：3 个 `"a"` + 2 个 `"aa"` + 1 个 `"aaa"`。

> **关键观察**：每个中心扩展一次 = 找到一个新回文，所以「成功扩展的次数」=「回文总数」。

### 关键陷阱：中心数量是 `2n-1`，不是 `n`

| 中心类型 | 数量 | 对应回文长度 | 例子 |
|:---|:---|:---:|:---|
| 单字符中心 | n | 奇数 | `"aba"` 的 `b` |
| 双字符中心 | n-1 | 偶数 | `"abba"` 中间的两个 `b` |
| **合计** | **2n-1** | — | — |

> 漏掉双字符中心 = 丢掉所有偶数长度回文（`"aa"`, `"abba"`, ...），是本题最常见的错。

### 解法零：暴力枚举（对照用，会 TLE）

1. 枚举所有子串起点 `i` 和终点 `j`（共 \(\frac{n(n+1)}{2}\) 个子串）
2. 对每个子串用双指针判回文：`l` 从 `i`、`r` 从 `j` 向中间靠拢，全程 `s[l] == s[r]` 即回文
3. 命中回文则 `count++`
- 时间复杂度：\(O(n^3)\)（\(O(n^2)\) 个子串 × 每个判回文 \(O(n)\)）
- 空间复杂度：\(O(1)\)
- 本题 \(n \le 1000\)，\(n^3 = 10^9\)，**会 TLE**，仅作思路对照

### 解法一：中心扩展（推荐）

**两步**：
1. **枚举中心**：遍历 `i` 从 `0` 到 `n-1`，对每个 `i` 分别处理「单字符中心」和「双字符中心」
2. **向两侧扩展**：从中心出发，只要 `s[l] == s[r]` 就 `count++` 并继续 `l--; r++`，失败则停

**核心代码骨架**（把扩展抽成独立函数，避免 `l--/r++` 写在 while 条件里混乱）：

```java
// 扩展函数：从中心 (left, right) 出发，统计能扩展出的回文数
private int expand(String s, int left, int right) {
    int count = 0;
    while (left >= 0 && right < s.length()
            && s.charAt(left) == s.charAt(right)) {
        count++;                // 成功扩展一次 = 找到一个回文
        left--;                 // 向左移
        right++;                // 向右移
    }
    return count;
}

// 主函数：枚举所有中心，调用扩展函数累加
public int countSubstrings(String s) {
    int count = 0;
    for (int i = 0; i < s.length(); i++) {
        count += expand(s, i, i);       // 单字符中心（奇数长度回文）
        count += expand(s, i, i + 1);   // 双字符中心（偶数长度回文）
    }
    return count;
}
```

**为什么这样写对**：
- `expand(i, i)`：初始 `l == r`，单个字符必回文，至少 `count++` 一次
- `expand(i, i+1)`：初始 `l + 1 == r`，若 `s[i] == s[i+1]` 则命中偶数回文，否则立即返回 0
- **两种中心分开枚举**，思路比「合并成 `2n-1`」更直观，不易写错

- 时间复杂度：\(O(n^2)\)，每次 `expand` 最多扩展 \(O(n)\) 次，共 \(2n-1\) 次调用
- 空间复杂度：\(O(1)\)

### 解法二：区间 DP

1. `dp[i][j]` 表示 `s[i..j]` 是否为回文
2. 转移：`dp[i][j] = (s[i] == s[j]) && dp[i+1][j-1]`
3. 边界：`dp[i][i] = true`，长度 2 时 `dp[i][i+1] = (s[i] == s[i+1])`
4. 按**长度从小到大**枚举，统计 `true` 的个数
- 时间复杂度：\(O(n^2)\)
- 空间复杂度：\(O(n^2)\)

### 解法三：Manacher（进阶，了解即可）

- 在字符间插入 `#` 统一奇偶长度，用已算出的回文半径加速
- 时间复杂度：\(O(n)\)，空间复杂度：\(O(n)\)
- 代码复杂度高，面试极少要求，知道存在即可

### 解法零：暴力枚举（对照用，不推荐提交）

```java
public int countSubstrings(String s) {
    int n = s.length();
    int count = 0;
    for (int i = 0; i < n; i++) {
        for (int j = i; j < n; j++) {                  // 枚举所有子串 [i, j]
            if (isPalindrome(s, i, j)) {
                count++;
            }
        }
    }
    return count;
}

private boolean isPalindrome(String s, int l, int r) {
    while (l < r) {
        if (s.charAt(l++) != s.charAt(r--)) {          // 双指针向中间靠拢
            return false;
        }
    }
    return true;
}
```

### 解法一：中心扩展（修正版）

```java
public int countSubstrings(String s) {
    int count = 0;
    for (int i = 0; i < s.length(); i++) {
        count += expand(s, i, i);          // 单字符中心（奇数长度回文）
        count += expand(s, i, i + 1);      // 双字符中心（偶数长度回文）
    }
    return count;
}

// 扩展函数：从中心 (left, right) 向两侧扩展，返回能扩展出的回文数
private int expand(String s, int left, int right) {
    int count = 0;
    while (left >= 0 && right < s.length()
            && s.charAt(left) == s.charAt(right)) {
        count++;                          // 成功扩展一次 = 找到一个回文
        left--;
        right++;
    }
    return count;
}
```

### 解法二：区间 DP

```java
public int countSubstrings(String s) {
    int n = s.length();
    boolean[][] dp = new boolean[n][n];
    int count = 0;
    for (int len = 1; len <= n; len++) {                 // 按长度从小到大枚举
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            if (len == 1) {
                dp[i][j] = true;                        // 单字符必回文
            } else if (len == 2) {
                dp[i][j] = (s.charAt(i) == s.charAt(j));
            } else {
                dp[i][j] = (s.charAt(i) == s.charAt(j)) && dp[i + 1][j - 1];
            }
            if (dp[i][j]) count++;
        }
    }
    return count;
}
```

## 个人总结

### 1. 暴力 → 中心扩展：复杂度从 \(O(n^3)\) 到 \(O(n^2)\) 的关键

| 解法 | 枚举对象 | 个数 | 每次判回文 | 总复杂度 |
|:---|:---|:---:|:---:|:---:|
| 暴力 | 子串起点终点 | \(O(n^2)\) | \(O(n)\) | \(O(n^3)\) |
| 中心扩展 | 中心位置 | \(2n-1 = O(n)\) | 每次扩展 \(O(1)\)，总扩展 \(O(n)\) | \(O(n^2)\) |

关键洞察：**回文的对称性让我们不需要为每个子串重新判回文**——从中心向外扩展时，只要 `s[l] == s[r]` 就能继续，一次失败就停。中心扩展 = 把"枚举子串"和"判回文"合并成一次遍历。

> 暴力解法的 `isPalindrome(s, i, j)` 函数虽然清晰，但每个子串都从头判一次，做了大量重复工作（`s[i..j]` 是回文 ⟺ `s[i+1..j-1]` 是回文且 `s[i]==s[j]`）。区间 DP 和中心扩展都是从不同角度消除这种重复。

### 2. 中心数量为什么是 `2n-1`

| 中心类型 | 个数 | 例子 |
|:---|:---:|:---|
| 单字符（产生奇数长度回文） | n | `"aba"` 的 `b` |
| 双字符（产生偶数长度回文） | n-1 | `"abba"` 中间的两个 `b` |

记忆口诀：**「奇 + 偶 = 2n - 1」**。看到回文字符串题，先问自己「中心是奇还是偶」，两种都要枚举。

### 3. `l--` `r++` 放在 `while` 条件里 vs 循环体里

```java
// ❌ 反面：写在条件里
while (l >= 0 && r < n && s.charAt(l--) == s.charAt(r++)) {
    count++;            // 当 l/r 越界时，比较可能已经越界访问，且多算了一次
}

// ✅ 正面：写在循环体里
while (l >= 0 && r < n && s.charAt(l) == s.charAt(r)) {
    count++;
    l--;                // 移动放到计数之后
    r++;
}
```

原则：**边界检查与字符比较用原始的 `l`/`r`，移动放在判断通过之后**。短路求值保证 `l >= 0 && r < n` 在 `charAt` 之前。

### 4. 中心扩展 vs 区间 DP 的选择

| 维度 | 中心扩展 | 区间 DP |
|:---|:---|:---|
| 时间 | \(O(n^2)\) | \(O(n^2)\) |
| 空间 | \(O(1)\) | \(O(n^2)\) |
| 代码量 | 短 | 中 |
| 思维难度 | 直观（回文天然对称） | 略绕（按长度递推） |
| **扩展性** | 适合「计数」「求最长」 | 适合「需要查询任意子区间是否回文」（如 131/132 分割回文串） |

> 经验：**纯计数/最长用中心扩展**，**分割类用区间 DP**。

### 6. 为什么 Manacher 不是本题首选

Manacher \(O(n)\) 看似比 \(O(n^2)\) 快，但：

- \(n=1000\) 时 \(n^2 = 10^6\)，Java 1s 内绰绰有余，\(O(n^2)\) 完全够用
- Manacher 代码量是中心扩展的 3~5 倍，面试现场容易写错
- Manacher 的核心价值在于 \(n \ge 10^5\) 的场景，本题 1000 上限不构成瓶颈

> 面试答法：先用中心扩展 \(O(n^2)\) AC，被追问能否 \(O(n)\) 时再提 Manacher。

### 7. 不同位置的同值子串要分别计数

示例 2 `"aaa"` 输出 6 而非 3，因为：

| 子串 | 出现位置 |
|:---|:---|
| `"a"` | `[0,0]`, `[1,1]`, `[2,2]` 共 3 个 |
| `"aa"` | `[0,1]`, `[1,2]` 共 2 个 |
| `"aaa"` | `[0,2]` 共 1 个 |

题目问的是「子串的数目」按位置计数，而不是「不同回文串的集合」。这影响解法选择——**不能用 set 去重**，必须按位置枚举。
