## 题目描述

给你两个单词 `word1` 和 `word2`， 请返回将 `word1` 转换成 `word2` 所使用的最少操作数。

你可以对一个单词进行如下三种操作：

- 插入一个字符
- 删除一个字符
- 替换一个字符

---

## 示例

**示例 1**

```
输入：word1 = "horse", word2 = "ros"
输出：3
解释：
horse -> rorse (将 'h' 替换为 'r')
rorse -> rose (删除 'r')
rose -> ros (删除 'e')
```

**示例 2**

```
输入：word1 = "intention", word2 = "execution"
输出：5
解释：
intention -> inention (删除 't')
inention -> enention (将 'i' 替换为 'e')
enention -> exention (将 'n' 替换为 'x')
exention -> exection (将 'n' 替换为 'c')
exection -> execution (插入 'u')
```

## 提示

- `0 <= word1.length, word2.length <= 500`
- `word1` 和 `word2` 由小写英文字母组成

## 思路

### 核心思想

两个字符串的转换问题，是典型的**双序列 DP**。定义 `dp[i][j]` = 把 `word1` 的**前 `i` 个字符**变成 `word2` 的**前 `j` 个字符**所需的最少操作数。逐字符比较末尾：**末字符相同**则不用操作、直接继承 `dp[i-1][j-1]`；**不同**则在「增、删、改」三种操作里取代价最小的那个 `+1`。

> 思路演进遵循「**暴力递归 → 记忆化 → DP**」：先按上面的关系写自顶向下递归（解法一），发现 `(i,j)` 重复计算导致指数级 → 加缓存变记忆化（解法四）→ 改成自底向上填表就是二维 DP（解法二）→ 滚动数组把空间压到 O(n)（解法三）。

### 状态转移

比较 `word1[i-1]` 与 `word2[j-1]`（注意下标偏移，`dp` 的 `i/j` 是长度）：

- **相等**：`dp[i][j] = dp[i-1][j-1]`（末字符天然匹配，白拿）。
- **不等**：`dp[i][j] = 1 + min(` 三选一 `)`：

| 操作 | 转移来源 | 含义 |
|:---|:---|:---|
| 替换 | `dp[i-1][j-1]` | 把 word1[i-1] 改成 word2[j-1] |
| 删除 | `dp[i-1][j]` | 删掉 word1[i-1]，用前 i-1 个去匹配前 j 个 |
| 插入 | `dp[i][j-1]` | 在 word1 末尾补上 word2[j-1]，用前 i 个匹配前 j-1 个 |

### 初始化（边界）

- `dp[0][j] = j`：word1 为空，变成 word2 前 j 个需插入 j 次。
- `dp[i][0] = i`：word2 为空，把 word1 前 i 个全删需 i 次。

```
        ""  r  o  s
    ""   0  1  2  3
    h    1  1  2  3
    o    2  2  1  2
    r    3  2  2  2
    s    4  3  3  2
    e    5  4  4  3   → dp[5][3] = 3 ✅
```

- 时间复杂度：\(O(mn)\)，空间复杂度：\(O(mn)\)（可滚动数组优化到 \(O(n)\)）。

## 代码

### 解法一：暴力递归（先跑通，会超时）

不带缓存的自顶向下递归，直接翻译状态转移。`dfs(i, j)` = 把 `word1` 前 `i` 个变成 `word2` 前 `j` 个的最少操作数。因为存在大量**重复子问题**（同一对 `(i,j)` 被反复计算），会退化成指数级、在大用例上超时——它是记忆化 / DP 的雏形。

```java
class Solution {
    public int minDistance(String word1, String word2) {
        return dfs(word1, word2, word1.length(), word2.length());
    }
    // 把 word1 前 i 个变成 word2 前 j 个的最小操作数
    private int dfs(String w1, String w2, int i, int j) {
        if (i == 0) return j;                               // w1 空，插 j 个
        if (j == 0) return i;                               // w2 空，删 i 个
        if (w1.charAt(i - 1) == w2.charAt(j - 1)) {
            return dfs(w1, w2, i - 1, j - 1);               // 末字符相同，无操作
        }
        return 1 + Math.min(dfs(w1, w2, i - 1, j - 1),      // 替换
                   Math.min(dfs(w1, w2, i - 1, j),          // 删除
                            dfs(w1, w2, i, j - 1)));         // 插入
    }
}
```

- 时间复杂度：最坏 \(O(3^{m+n})\)（每层三叉展开），指数级，会超时；空间 \(O(m+n)\)（递归栈）。

### 解法二：二维动态规划（推荐）

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length(), n = word2.length();
        int[][] dp = new int[m + 1][n + 1];
        // 边界：一个串为空时，操作数 = 另一个串的长度
        for (int i = 0; i <= m; i++) dp[i][0] = i;
        for (int j = 0; j <= n; j++) dp[0][j] = j;

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];             // 末字符相同，直接继承
                } else {
                    dp[i][j] = 1 + Math.min(
                        dp[i - 1][j - 1],                    // 替换
                        Math.min(dp[i - 1][j], dp[i][j - 1]) // 删除 / 插入
                    );
                }
            }
        }
        return dp[m][n];
    }
}
```

### 解法三：滚动数组优化（空间 O(n)）

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length(), n = word2.length();
        int[] dp = new int[n + 1];
        for (int j = 0; j <= n; j++) dp[j] = j;             // 初始为 dp[0][j]

        for (int i = 1; i <= m; i++) {
            int prev = dp[0];                               // 保存左上角 dp[i-1][j-1]
            dp[0] = i;                                       // dp[i][0] = i
            for (int j = 1; j <= n; j++) {
                int temp = dp[j];                           // 覆盖前先存，作为下一轮的左上角
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[j] = prev;
                } else {
                    dp[j] = 1 + Math.min(prev, Math.min(dp[j], dp[j - 1]));
                    // prev=左上(替换)  dp[j]=上(删除)  dp[j-1]=左(插入)
                }
                prev = temp;
            }
        }
        return dp[n];
    }
}
```

### 解法四：记忆化搜索（自顶向下，好理解）

在解法一暴力递归的基础上，用 `memo[i][j]` 缓存「把 word1 前 i 个变 word2 前 j 个」的结果，避免重复子问题——每个 `(i,j)` 只算一次，复杂度从指数级降到 \(O(mn)\)。

```java
class Solution {
    Integer[][] memo;
    public int minDistance(String word1, String word2) {
        memo = new Integer[word1.length() + 1][word2.length() + 1];
        return dfs(word1, word2, word1.length(), word2.length());
    }
    // 把 word1 前 i 个变成 word2 前 j 个的最小操作数
    private int dfs(String w1, String w2, int i, int j) {
        if (i == 0) return j;                               // w1 空，插 j 个
        if (j == 0) return i;                               // w2 空，删 i 个
        if (memo[i][j] != null) return memo[i][j];
        int res;
        if (w1.charAt(i - 1) == w2.charAt(j - 1)) {
            res = dfs(w1, w2, i - 1, j - 1);
        } else {
            res = 1 + Math.min(dfs(w1, w2, i - 1, j - 1),
                     Math.min(dfs(w1, w2, i - 1, j), dfs(w1, w2, i, j - 1)));
        }
        return memo[i][j] = res;
    }
}
```

## 个人总结

### 1. 状态定义：dp[i][j] = 前 i 个变前 j 个的最小操作数

双序列问题的通用套路是**二维 DP，两维分别是两个串的"处理长度"**。`dp[i][j]` 的 `i/j` 是长度（1-indexed），对应字符是 `word1[i-1]`、`word2[j-1]`，下标错一位是最常见 bug。

### 2. 三个转移方向对应三种操作

这是本题精髓，务必背下含义：

- `dp[i-1][j-1]` → **替换**（对角线，改末字符）；
- `dp[i-1][j]` → **删除**（上方，删 word1 末字符）；
- `dp[i][j-1]` → **插入**（左方，在 word1 补一个字符）。

末字符相等时白拿对角线（无操作）；不等时三者取 min 再 +1。想清「删/插」哪个对应上、哪个对应左，靠的是"从谁转移过来只差一步操作"。

### 3. 边界初始化不能漏

`dp[0][j]=j`、`dp[i][0]=i` 表示"一个串为空，全靠插/删"。忘了初始化第 0 行/列，整张表就错。它们是递推的地基。

### 4. 为什么「不等」时是这三者取 min

要把 `word1[..i]` 变 `word2[..j]`，最后一步无非：改末字符（来自 `dp[i-1][j-1]`）、删 word1 末字符（来自 `dp[i-1][j]`）、或给 word1 插一个匹配 word2 末字符（来自 `dp[i][j-1]`）。三条路径都合法，取最省的。

### 5. 滚动数组的关键：用 prev 缓存左上角

优化到一维时，`dp[j]` 在更新前存的是"上一行同列"（即删除来源），但**替换需要"上一行左一列"**，会在处理 `dp[j-1]` 时被覆盖。所以要用 `prev`（`temp`）在覆盖前把左上角值存下来。这和 [221 最大正方形](221.%20最大正方形.md) 的滚动技巧完全一致。

### 6. 四种解法取舍

| 解法 | 时间 | 空间 | 定位 |
|:---|:---:|:---:|:---|
| 暴力递归 | \(O(3^{m+n})\) | \(O(m+n)\) | 理解转移，会超时 |
| 记忆化搜索 | \(O(mn)\) | \(O(mn)\) | 自顶向下，最好理解 |
| 二维 DP | \(O(mn)\) | \(O(mn)\) | 标准解，清晰易写 |
| 滚动数组 | \(O(mn)\) | \(O(n)\) ✅ | 空间最优 |

**面试建议**：先用暴力递归讲清「相等继承 / 不等三方向取 min」的转移，点出 `(i,j)` 重复子问题 → 记忆化 → 二维 DP（配一张 `horse→ros` 的表格最直观）→ 滚动数组优化。这条「暴力 → 记忆化 → DP」的链路完整讲出来最加分。
