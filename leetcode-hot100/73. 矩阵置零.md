## 题目描述

给定一个 `m x n` 的矩阵，如果一个元素为 **0** ，则将其所在行和列的所有元素都设为 **0** 。请使用 **原地** 算法。

## 示例

**示例 1**

```
输入：matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出：[[1,0,1],[0,0,0],[1,0,1]]
```

**示例 2**

```
输入：matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出：[[0,0,0,0],[0,4,5,0],[1,3,1,0]]
```

---

## 提示

- `m == matrix.length`
- `n == matrix[0].length`
- `1 <= m, n <= 200`
- `-2^31 <= matrix[i][j] <= 2^31 - 1`

---

## 进阶

一个直观的解决方案是使用 `O(mn)` 的额外空间，但这并不是一个好的解决方案。

一个简单的改进方案是使用 `O(m + n)` 的额外空间，但这仍然不是最好的解决方案。

你能想出一个仅使用常量空间的解决方案吗？

---

## 思路

### 核心思想

直接边扫边改会「污染」还没读到的元素。正确做法是**用矩阵自己的空间存标记**：第一遍扫描时用第一行、第一列记录「该行/该列是否需要置零」（首行首列本身是否含 0，提前用两个布尔变量备份），第二遍按标记置零。

### 解法一：两个标记数组（基础，O(m+n) 空间）

1. 第一遍扫描：遇到 0 就 `row[i] = col[j] = true`；
2. 第二遍扫描：`row[i] || col[j]` 为真就置 `matrix[i][j] = 0`。

- 时间复杂度：\(O(mn)\)，空间复杂度：\(O(m+n)\)

### 解法二：首行首列做标记（推荐，O(1) 空间）

1. 先用布尔变量 `firstRowZero / firstColZero` **备份第一行、第一列本身是否含 0**；
2. 扫描内部区域 `[1..m-1][1..n-1]`：遇到 0 就把 `matrix[i][0]`、`matrix[0][j]` 置 0（征用首行首列当标记位）；
3. 根据首行首列的标记，**先**把内部区域置零；
4. **最后**才根据两个布尔变量处理第一行、第一列。

- 时间复杂度：\(O(mn)\)，空间复杂度：\(O(1)\)

## 代码

### 解法一：两个标记数组（基础）

```java
public void setZeroes(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    boolean[] row = new boolean[m], col = new boolean[n];
    for (int i = 0; i < m; i++) {          // 第一遍：收集标记
        for (int j = 0; j < n; j++) {
            if (matrix[i][j] == 0) {
                row[i] = col[j] = true;
            }
        }
    }
    for (int i = 0; i < m; i++) {          // 第二遍：按标记置零
        for (int j = 0; j < n; j++) {
            if (row[i] || col[j]) {
                matrix[i][j] = 0;
            }
        }
    }
}
```

### 解法二：首行首列做标记（推荐）

```java
public void setZeroes(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    // ① 先备份第一行、第一列本身是否含 0（它们即将被征用作标记位）
    boolean firstRowZero = false, firstColZero = false;
    for (int j = 0; j < n; j++) {
        if (matrix[0][j] == 0) firstRowZero = true;
    }
    for (int i = 0; i < m; i++) {
        if (matrix[i][0] == 0) firstColZero = true;
    }
    // ② 扫描内部区域，用首行首列当标记
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;   // 第 i 行需要置零
                matrix[0][j] = 0;   // 第 j 列需要置零
            }
        }
    }
    // ③ 根据标记，先把内部区域置零
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                matrix[i][j] = 0;
            }
        }
    }
    // ④ 最后才处理第一行、第一列，避免过早覆盖标记信息
    if (firstRowZero) {
        Arrays.fill(matrix[0], 0);
    }
    if (firstColZero) {
        for (int i = 0; i < m; i++) matrix[i][0] = 0;
    }
}
```

## 个人总结

### 1. 步骤顺序错了就是全盘污染

O(1) 解法只有一种安全顺序：**备份首行首列 → 标记内部 → 置内部 → 置首行首列**。若提前置了首行/首列，步骤 ③ 读 `matrix[i][0]` / `matrix[0][j]` 时读到的全是「被污染的 0」，整个矩阵被误置零——示例 2（第一行本来就含 0）一跑就翻车。

### 2. 两个布尔变量是「被覆盖信息的备份」

首行首列被征用当标记位后，它们原本的 0 信息就丢了，`firstRowZero / firstColZero` 就是这份信息的备份。**凡「用数据区自己存元信息」的题（本题、41 原地哈希、448 取负标记），都要先备份将被覆盖的信息**——这是原地操作类题目的通用心法。

### 3. 为什么首行 + 首列刚好够用

行列标记共需 m+n 个布尔值：首行提供 n 个（列标记）、首列提供 m 个（行标记），`(0,0)` 共用一个，恰好覆盖，额外只花 2 个布尔变量。这就是空间从 \(O(m+n)\) 压到 \(O(1)\) 的全部来源。

### 4. 追问「能不能只扫一遍」怎么答

有一遍版（边扫边用首行首列 + 布尔变量标记），但代码更绕、更难讲对，而复杂度并没有更好。面试答「两遍已经是时间 \(O(mn)\)、空间 \(O(1)\) 的最优组合，一遍版牺牲清晰度换不来渐进收益」即可——**不要为炫技写易错版本**。
