## 题目描述

给你一个满足下述两条属性的 `m x n` 整数矩阵：

- 每行中的整数从左到右按**非严格递增**顺序排列。
- 每行的第一个整数大于前一行的最后一个整数。

给你一个整数 `target` ，如果 `target` 在矩阵中，返回 `true` ；否则，返回 `false` 。

---

## 示例

**示例 1**

```
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3
输出：true
```

**示例 2**

```
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13
输出：false
```

---

## 提示

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 100`
- `-10^4 <= matrix[i][j], target <= 10^4`

---

## 思路

### 核心思想

「行内递增 + 本行行首大于上一行行尾」意味着**按行优先展开成一维数组后整体升序**——对长度 `m*n` 的一维区间做一次标准二分，下标用 `matrix[mid / n][mid % n]` 映射回矩阵即可。

### 解法一：两次二分（先定位行，再在行内找，基础）

1. 第一趟在**第 0 列**上二分：找**最后一个行首 `<= target`** 的行（行首都大于 target 则直接 false）；
2. 第二趟在该行内标准二分找 `target`。

- 时间复杂度：\(O(\log m + \log n)\)；空间复杂度：\(O(1)\)

### 解法二：展开成一维，一次二分（推荐）

1. 把矩阵当作长度 `m * n` 的升序数组，对 `[0, m*n - 1]` 做闭区间二分；
2. 取值用映射 `value = matrix[mid / n][mid % n]`（`n` 为**列数**）；
3. 命中返回 `true`，循环结束返回 `false`。

- 时间复杂度：\(O(\log(mn))\)；空间复杂度：\(O(1)\)

## 代码

### 解法一：两次二分

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int m = matrix.length, n = matrix[0].length;
        // 第一趟：在第 0 列上找「最后一个 <= target 的行」
        int lo = 0, hi = m - 1, row = -1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (matrix[mid][0] <= target) {
                row = mid;                 // 记录候选行，继续往右试
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        if (row == -1) return false;       // 所有行首都 > target
        // 第二趟：在 row 行内标准二分
        lo = 0;
        hi = n - 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (matrix[row][mid] == target) return true;
            else if (matrix[row][mid] < target) lo = mid + 1;
            else hi = mid - 1;
        }
        return false;
    }
}
```

### 解法二：一维展开二分（推荐）

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int m = matrix.length, n = matrix[0].length;
        int left = 0, right = m * n - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            int value = matrix[mid / n][mid % n];   // 一维下标 → 二维坐标
            if (value == target) return true;
            else if (value < target) left = mid + 1;
            else right = mid - 1;
        }
        return false;
    }
}
```

## 个人总结

### 1. 两个条件 = 展开后整体升序；差一条就换解法

「行内递增 + 行首 > 上行行尾」拼起来是一维升序序列，才能 \(O(\log mn)\) 二分。对比 [240. 搜索二维矩阵 II](240.%20搜索二维矩阵%20II.md)：它只有「行、列各自递增」，展开后**不**升序，不能二分，只能右上角排除法。两题条件差一条、解法完全不同，面试常放一起追问：

| 题目 | 条件 | 方法 |
|:---|:---|:---|
| 74 | 行递增 + 行首 > 上行行尾 | 展开一维二分 \(O(\log mn)\) |
| 240 | 行、列各自递增 | 右上角起步排除 \(O(m+n)\) |

### 2. 坐标映射：除数和模数都是「列数 n」

`mid / n` 是行、`mid % n` 是列——行优先展开，模数必须是**列数**。顺手写 `mid / m` 是最典型的手滑，样例恰好是方阵时还测不出来。

### 3. 第一趟的语义：找「最后一个 <= target 的行」

不是找相等的行首，而是**右边界型二分**：`matrix[mid][0] <= target` 时先记 `row = mid` 再 `lo = mid + 1` 继续向右。找到的行才可能包含 target（target 落在 `[行首, 下行行首)` 区间内）；一行都没命中（所有行首 > target）直接 false。
