## 题目描述

给你一个字符串 `s` 、一个字符串 `t` 。返回 `s` 中涵盖 `t` 所有字符的最小子串。如果 `s` 中不存在涵盖 `t` 所有字符的子串，则返回空字符串 `""` 。

**注意**：

- 对于 `t` 中重复字符，我们寻找的子字符串中该字符数量必须不少于 `t` 中该字符数量。
- 如果 `s` 中存在这样的子串，我们保证它是唯一的答案。

---

## 示例

**示例 1**

```
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。
```

**示例 2**

```
输入：s = "a", t = "a"
输出："a"
解释：整个字符串 s 是最小覆盖子串。
```

**示例 3**

```
输入：s = "a", t = "aa"
输出：""
解释：t 中两个字符 'a' 均应包含在 s 的子串中，
因此没有符合条件的子字符串，返回空字符串。
```

## 提示

- `m == s.length`
- `n == t.length`
- `1 <= m, n <= 10^5`
- `s` 和 `t` 由英文字母组成

## 思路

### 核心：变长滑动窗口——右扩到覆盖，左缩到最短

和 [438 找异位词](438.%20找到字符串中所有字母异位词.md) 的**定长**窗口不同，本题窗口**大小可变**：

- **右指针扩窗**：不断把 `right` 右移，直到窗口**覆盖了 `t` 的所有字符**（含重复次数）；
- **左指针缩窗**：一旦覆盖，就尽量右移 `left` 压缩窗口，在「仍满足覆盖」的前提下找最短，记录答案；
- 一旦缩到不再覆盖，回到扩窗，重复。

```
s = "ADOBECODEBANC", t = "ABC"
right 扩到 "ADOBEC" 首次覆盖 ABC → 尝试缩左
缩到 "DOBEC"？丢了 A，不覆盖 → 停
继续扩... 最终找到最短 "BANC"（长度4）
```

### 如何判断「已覆盖」——用 need 计数 + valid 计数

- `need[c]`：`t` 中每个字符还**需要**的数量（可用 `int[128]` 或 `HashMap`）
- 窗口右扩纳入 `c`：若 `c` 是 `t` 需要的且当前窗口内 `c` 的数量**还没超过**需要量，`valid++`（`valid` = 已满足需求的字符总数）
- 当 `valid == t.length()` 时，窗口已覆盖 `t`（注意是按**字符出现次数**计，含重复）

用 `valid` 一个整数判断是否覆盖，避免每次比较整张计数表——这是把复杂度压到 \(O(n)\) 的关键。

### 解法一：暴力枚举所有子串（理解入口）

枚举所有子串 `s[i..j]`，检查它是否覆盖 `t`，取最短的。

- 时间复杂度：\(O(m^2 \times (m+n))\)（枚举 \(O(m^2)\) 子串，每个校验覆盖 \(O(m+n)\)）
- 空间复杂度：\(O(m+n)\)
- `m ≤ 10^5` 时**必然 TLE**，仅用于确立「找覆盖 t 的最短子串」题意

> 瓶颈：相邻子串的覆盖判断高度重叠，且大量子串根本不可能更短。用滑动窗口「扩到覆盖、缩到最短」一趟搞定。

### 解法二：变长滑动窗口 + 词频（推荐）

1. 用 `need` 统计 `t` 的词频，`window` 统计当前窗口词频，`valid` 记已满足数量的字符数
2. `right` 右移扩窗，更新 `window` 和 `valid`
3. 当 `valid == t.length()`（覆盖）时，进入内层循环右移 `left` 缩窗：更新最短答案，把 `left` 处字符移出窗口（对应减 `valid`），直到不再覆盖
4. 全程结束返回记录的最短子串

- 时间复杂度：\(O(m + n)\)，`left`、`right` 各最多走 `m` 步
- 空间复杂度：\(O(|\Sigma|)\)，字符集大小

## 代码

### 解法一：暴力枚举子串（会 TLE，理解入口）

```java
class Solution {
    public String minWindow(String s, String t) {
        int m = s.length();
        int[] need = new int[128];
        for (char c : t.toCharArray()) need[c]++;

        String ans = "";
        for (int i = 0; i < m; i++) {
            for (int j = i; j < m; j++) {
                if (covers(s, i, j, need, t.length())) {   // s[i..j] 是否覆盖 t
                    if (ans.isEmpty() || j - i + 1 < ans.length()) {
                        ans = s.substring(i, j + 1);
                    }
                    break;                    // 固定 i 时，第一个覆盖的 j 就是该 i 下最短
                }
            }
        }
        return ans;
    }

    private boolean covers(String s, int lo, int hi, int[] need, int total) {
        int[] cnt = new int[128];
        int valid = 0;
        for (int k = lo; k <= hi; k++) {
            char c = s.charAt(k);
            if (cnt[c] < need[c]) valid++;     // 还没满足该字符的需求
            cnt[c]++;
        }
        return valid == total;
    }
}
```

### 解法二：变长滑动窗口 + 词频（推荐）

```java
class Solution {
    public String minWindow(String s, String t) {
        int[] need = new int[128];             // t 的词频
        int[] window = new int[128];           // 当前窗口词频
        for (char c : t.toCharArray()) need[c]++;

        int left = 0, valid = 0;               // valid：已满足需求的字符个数（含重复）
        int start = 0, len = Integer.MAX_VALUE; // 记录最短窗口的起点与长度

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);          // 右扩，纳入 c
            window[c]++;
            if (window[c] <= need[c]) valid++; // 没超过需求 → 有效贡献一个

            // 窗口已覆盖 t → 尝试缩左求最短
            while (valid == t.length()) {
                if (right - left + 1 < len) {  // 更新最短答案
                    start = left;
                    len = right - left + 1;
                }
                char d = s.charAt(left);       // 移出最左字符
                left++;
                window[d]--;
                if (window[d] < need[d]) valid--;  // 少于需求 → 失去一个有效字符
            }
        }
        return len == Integer.MAX_VALUE ? "" : s.substring(start, start + len);
    }
}
```

## 个人总结

### 1. 定长窗口 vs 变长窗口：本题是变长的代表

和 [438 找异位词](438.%20找到字符串中所有字母异位词.md) 对照记忆：

| | 窗口大小 | 移动逻辑 | 目标 |
|:---|:---|:---|:---|
| 438 异位词 | **固定** = `\|p\|` | 右进一个、左出一个 | 找所有恰好匹配的起点 |
| 76 最小覆盖 | **可变** | 右扩到覆盖、左缩到最短 | 找最短的覆盖子串 |

**「异位词/排列」→ 定长；「覆盖/最短/最长」→ 变长**，这是滑动窗口两大分支，看题意就能判。

### 2. `valid` 计数是把 O(n²) 压到 O(n) 的关键

不要每次都比较整张 `need` 和 `window` 表（那是 \(O(|\Sigma|)\)）。用一个整数 `valid` 记「已满足需求的字符个数」，`valid == t.length()` 即覆盖。**扩窗时 `window[c] <= need[c]` 才 `valid++`，缩窗时 `window[d] < need[d]` 才 `valid--`**——只在跨越「需求满足线」时更新，O(1)。

### 3. 扩窗 `<=` 与缩窗 `<` 的不对称别写错

- 扩窗纳入 `c`：`if (window[c] <= need[c]) valid++`——加完还没超需求，说明这一个是「有效补充」；
- 缩窗移出 `d`：`if (window[d] < need[d]) valid--`——减完低于需求了，才损失一个有效字符。

一个用 `<=`（加之后判），一个用 `<`（减之后判），对称但边界不同，是本题最易错处。

### 4. 缩窗要用 `while` 不是 `if`

覆盖之后可能连续缩好几步仍然覆盖（窗口里有冗余字符），必须 `while (valid == t.length())` 一直缩到临界，才能得到该右端点下的最短。写成 `if` 只缩一步会漏最短解。

### 5. 记录答案用「起点 + 长度」，最后再截取

循环内只更新 `start` 和 `len` 两个整数，别每次都 `substring`（那会带来额外开销）。结束后用 `len == MAX_VALUE` 判断是否无解，否则 `s.substring(start, start+len)`。
