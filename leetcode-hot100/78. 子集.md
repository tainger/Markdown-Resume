## 题目描述

给你一个整数数组 `nums` ，数组中的元素 **互不相同** 。返回该数组所有可能的子集（幂集）。

解集 **不能** 包含重复的子集。你可以按 **任意顺序** 返回解集。

---

## 示例

**示例 1**

```
输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

**示例 2**

```
输入：nums = [0]
输出：[[],[0]]
```

---

## 提示

- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`
- `nums` 中的所有元素 **互不相同**

## 思路

### 核心思想

每个元素只有两种命运：**选**它进子集，或**不选**。`n` 个元素独立地做这个二选一决策，共 `2^n` 种组合——这就是全部子集。可以用回溯（DFS 遍历这棵"选/不选"决策树）、迭代（每来一个新数就把已有子集复制一份加上它）、或位运算（用 `n` 位二进制的每一位表示选或不选）三种方式枚举。

### 解法一：回溯（推荐，最通用）

从下标 `start` 开始做决策，避免选出重复组合。**关键：进入每个递归节点时，当前的 `path` 本身就是一个合法子集，先收集，再继续往后选。**

```
决策树（[1,2,3]）：每层决定"从 start 起选哪个数加入"
[]  → 收集 []
 ├─选1→[1] 收集 →├─选2→[1,2]→└─选3→[1,2,3]
 │                └─选3→[1,3]
 ├─选2→[2] → └─选3→[2,3]
 └─选3→[3]
```

- 时间复杂度：\(O(n\cdot2^n)\)（`2^n` 个子集，每个复制进结果需 O(n)），空间 \(O(n)\)（递归栈 + path）。

### 解法二：迭代逐个扩展

初始结果里只有空集 `[[]]`。每读入一个新元素 `num`，就把**当前所有子集各复制一份、在副本末尾加上 `num`**，追加回结果。

```
init:      [[]]
加 1: [[]] + [[1]]              = [[],[1]]
加 2: 上面 + [[2],[1,2]]        = [[],[1],[2],[1,2]]
加 3: 上面 + [[3],[1,3],[2,3],[1,2,3]]
```

每加一个数，子集数量翻倍（`2^n`）。

- 时间复杂度：\(O(n\cdot2^n)\)，空间 \(O(1)\)（不计结果）。

### 解法三：二进制枚举（位运算，最巧）

`n` 个元素的子集与 `0 ~ 2^n-1` 的整数一一对应：整数的**第 `i` 位为 1 表示选 `nums[i]`**，为 0 表示不选。

```
n=3, mask 从 000 到 111：
000 → []      001 → [1]      010 → [2]      011 → [1,2]
100 → [3]     101 → [1,3]    110 → [2,3]    111 → [1,2,3]
```

- 时间复杂度：\(O(n\cdot2^n)\)，空间 \(O(1)\)（不计结果）。适合 `n` 较小（本题 n≤10）。

## 代码

### 解法一：回溯（推荐）

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    List<Integer> path = new ArrayList<>();

    public List<List<Integer>> subsets(int[] nums) {
        backtrack(nums, 0);
        return res;
    }

    private void backtrack(int[] nums, int start) {
        res.add(new ArrayList<>(path));        // 每个节点的 path 都是一个合法子集，先收集
        for (int i = start; i < nums.length; i++) {
            path.add(nums[i]);                 // 选 nums[i]
            backtrack(nums, i + 1);            // 从 i+1 继续，避免重复组合
            path.remove(path.size() - 1);      // 回溯，撤销选择
        }
    }
}
```

### 解法二：迭代逐个扩展

```java
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        res.add(new ArrayList<>());            // 初始只有空集
        for (int num : nums) {
            int size = res.size();             // 固定当前数量，避免边加边遍历
            for (int i = 0; i < size; i++) {
                List<Integer> newSub = new ArrayList<>(res.get(i));
                newSub.add(num);               // 复制一份并加上 num
                res.add(newSub);
            }
        }
        return res;
    }
}
```

### 解法三：二进制枚举（位运算）

```java
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        int n = nums.length;
        List<List<Integer>> res = new ArrayList<>();
        for (int mask = 0; mask < (1 << n); mask++) {   // 0 ~ 2^n - 1
            List<Integer> sub = new ArrayList<>();
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) {           // 第 i 位为 1 → 选 nums[i]
                    sub.add(nums[i]);
                }
            }
            res.add(sub);
        }
        return res;
    }
}
```

## 个人总结

### 1. 本质：每个元素「选或不选」，共 2^n 个

子集问题的模型是**幂集**：`n` 个元素各自独立地"选/不选"，总数 `2^n`。想清这点，三种解法都是在"如何枚举这 2^n 种选择"上做文章。

### 2. 回溯：进入每个节点就收集，不用等到叶子

和「组合总和」「全排列」不同，子集问题**每个递归节点（包括中间节点）都是一个合法答案**，所以 `res.add(path)` 放在递归开头、无终止条件的收集。这是子集类回溯的标志性写法。

### 3. 回溯用 start 参数避免重复组合

`backtrack(nums, i+1)` 传 `i+1` 而不是 `0`，保证每个元素只在它之后的位置被考虑，避免选出 `[1,2]` 和 `[2,1]` 这种重复。这是「组合/子集」类问题防重的通用手段（排列问题才需要从头选）。

### 4. 收集时必须拷贝 path

`res.add(new ArrayList<>(path))` 一定要**新建副本**。`path` 是全局可变对象，若直接 `res.add(path)`，后续回溯修改 `path` 会连带改掉已加入结果的引用，最后全变成空列表。这是回溯最经典的坑。

### 5. 迭代法固定 size 再遍历

`int size = res.size()` 要在内层循环**前**取好。若边遍历边往 `res` 加元素，会导致无限循环或重复。这是"遍历时修改集合"的通用注意点。

### 6. 位运算法简洁但受 n 限制

二进制枚举把子集和整数一一对应，代码最短。但 `1 << n` 要求 `n` 不太大（int 下 n≤31），本题 n≤10 完全够用。是「小规模枚举全部子集」的利器。

### 7. 三种解法取舍

| 解法 | 时间 | 空间 | 定位 |
|:---|:---:|:---:|:---|
| 回溯 | \(O(n\cdot2^n)\) | \(O(n)\) | 最通用，易扩展到去重/组合 |
| 迭代扩展 | \(O(n\cdot2^n)\) | \(O(1)\) | 无递归，思路直观 |
| 二进制枚举 | \(O(n\cdot2^n)\) | \(O(1)\) | 最简洁，n 小时首选 |
