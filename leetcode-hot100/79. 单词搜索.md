## 题目描述

给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word` 。如果 `word` 存在于网格中，返回 `true` ；否则，返回 `false` 。

单词必须按照字母顺序，通过**相邻的单元格**内的字母构成，其中「相邻」单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母**不允许被重复使用**。

---

## 示例

**示例 1**

```
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"
输出：true
```

**示例 2**

```
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "SEE"
输出：true
```

**示例 3**

```
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCB"
输出：false
```

---

## 提示

- `m == board.length`
- `n = board[i].length`
- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` 和 `word` 仅由大小写英文字母组成

## 思路

### 核心思想

从每个等于 `word[0]` 的格子出发 DFS，向四方向逐字符匹配；**走过的格子当场标记「不可再用」，四方向都失败后恢复**——这就是「在网格上找一条不自交路径」的回溯模板。

### 解法一：DFS 回溯 + visited 标记（推荐）

1. 双重循环枚举起点：`board[i][j] == word[0]` 才进入 DFS；
2. DFS `(i, j, k)` 匹配 `word` 第 `k` 个字符：越界 / 已访问 / 字符不等 → `false`；
3. `k` 已是最后一个字符 → 匹配成功返回 `true`；
4. 标记 `visited[i][j] = true`，向上、下、左、右递归 `k + 1`，任一方向成功即一路返回 `true`；
5. 四方向全失败 → **恢复 `visited[i][j] = false`**（回溯，让其他路径能复用该格），返回 `false`。

- 时间复杂度：\(O(mn \cdot 3^L)\)，L 为 word 长度（起点 \(O(mn)\) 个，每个位置下一步最多 3 个新方向，来路不算）；空间复杂度：\(O(L)\) 递归栈 + \(O(mn)\) visited

### 解法二：原地修改恢复（免 visited 数组）

不申请 `visited`：走过时把 `board[i][j]` 暂存后改写成不可能匹配的占位符 `'#'`，递归返回前**恢复原字符**。正确性相同（`'#'` 不会与任何字母相等，天然挡住重访），空间省掉 \(O(mn)\)。

- 时间复杂度：\(O(mn \cdot 3^L)\)；空间复杂度：\(O(L)\) 递归栈

## 代码

### 解法一：DFS 回溯 + visited（推荐）

```java
class Solution {
    private char[][] board;
    private char[] word;
    private boolean[][] visited;
    private final int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};  // 上、下、左、右

    public boolean exist(char[][] board, String word) {
        this.board = board;
        this.word = word.toCharArray();
        this.visited = new boolean[board.length][board[0].length];
        for (int i = 0; i < board.length; i++) {
            for (int j = 0; j < board[0].length; j++) {
                if (dfs(i, j, 0)) return true;   // word[0] 可能出现在任意格子
            }
        }
        return false;
    }

    // 从 (i, j) 出发能否匹配 word[k..]
    private boolean dfs(int i, int j, int k) {
        if (i < 0 || i >= board.length || j < 0 || j >= board[0].length
                || visited[i][j] || board[i][j] != word[k]) {
            return false;                        // 越界 / 已用 / 字符不匹配
        }
        if (k == word.length - 1) return true;   // 最后一个字符也匹配上了
        visited[i][j] = true;                    // 标记占用
        for (int[] d : dirs) {                   // 四方向匹配下一个字符
            if (dfs(i + d[0], j + d[1], k + 1)) {
                return true;                     // 命中即短路返回（无需恢复，见总结 2）
            }
        }
        visited[i][j] = false;                   // 回溯：失败路径恢复占用
        return false;
    }
}
```

### 解法二：原地修改恢复

```java
class Solution {
    public boolean exist(char[][] board, String word) {
        char[] w = word.toCharArray();
        for (int i = 0; i < board.length; i++) {
            for (int j = 0; j < board[0].length; j++) {
                if (dfs(board, w, i, j, 0)) return true;
            }
        }
        return false;
    }

    private boolean dfs(char[][] board, char[] w, int i, int j, int k) {
        if (i < 0 || i >= board.length || j < 0 || j >= board[0].length
                || board[i][j] != w[k]) {
            return false;                        // 越界或字符不匹配（'#' 挡住重访）
        }
        if (k == w.length - 1) return true;
        char saved = board[i][j];
        board[i][j] = '#';                       // 原地标记为不可匹配字符
        boolean found = dfs(board, w, i + 1, j, k + 1)   // 下
                     || dfs(board, w, i - 1, j, k + 1)   // 上
                     || dfs(board, w, i, j + 1, k + 1)   // 右
                     || dfs(board, w, i, j - 1, k + 1);  // 左
        board[i][j] = saved;                     // 恢复现场
        return found;
    }
}
```

## 个人总结

### 1. 回溯两件套：标记 + 恢复，缺一不可

不标记 → 同一格被重复使用（示例 3 的 `ABCB` 会因 B 走回头路错误返回 true）；不恢复 → 失败路径污染状态，后面的起点再也看不到该格，漏解。**「进入 DFS 标记、四方向全失败后恢复」** 与 46 全排列的 `used[i] = false` 同源，是网格回溯的固定节奏。

### 2. 只求 boolean 时，成功路径可以不恢复

本题命中后一路 `return true` 终止全部搜索，路径上的标记不再被读取，所以成功分支**可以不恢复**（省几次写）。但若题目要输出具体路径（路径系列题）或命中后还要继续搜索，就必须完整恢复——两种场景的差别二刷时要留意。

### 3. 起点必须枚举，且可先做「存在性」剪枝

`word[0]` 可能出现在棋盘任何位置，外层双重循环不是可有可无的。回应进阶的最简单剪枝：先统计棋盘字符计数，`word` 中某字符出现次数超过棋盘总量 → 直接返回 false（如 `AAAB` 在只有两个 A 的棋盘上必无解）。

### 4. 更强剪枝与关联题

| 剪枝 / 题目 | 说明 |
|:---|:---|
| 反向匹配 | 若 `word` 末字符在棋盘中的出现次数比首字符少，倒着匹配 word，起点候选更少、分支更小 |
| 212. 单词搜索 II | 多个单词 → 先建 Trie 再回溯，避免逐词搜索，是本题的直接续作 |
| 200. 岛屿数量 | 网格 DFS 但求连通块：标记后**不恢复**（已访问格子永不重访），对照记忆 |
| 51. N 皇后 | 同为「标记 + 恢复」型回溯，只是冲突条件不同 |

> 记忆：**「网格找单词」→ 枚举起点 + DFS 四方向逐字符匹配：进入标记、失败恢复（求连通块则不恢复）、成功短路返回；多个单词先建 Trie（212）。**
