## 题目描述

给定 *n* 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

---

## 示例

**示例 1**

```
输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形为图中红色区域，面积为 10
```

**示例 2**

```
输入：heights = [2,4]
输出：4
```

## 提示

- `1 <= heights.length <= 10^5`
- `0 <= heights[i] <= 10^4`

## 思路

### 核心思想

最大矩形必然以**某根柱子的高度**作为高，且向左右延伸到「第一个更矮的柱子」为止。于是对每根柱子求出左右第一个更矮元素的位置，宽度即确定——单调递增栈能一趟扫完所有柱子的这两个信息。

### 解法一：暴力枚举（基础）

对每根柱子 `i` 分别向左、向右扩展，直到遇到比 `heights[i]` 更矮的柱子（或越界），得到以 `i` 为高的最大宽度，更新面积。

- 时间复杂度：\(O(n^2)\)，`n = 10^5` 会超时；空间复杂度：\(O(1)\)

### 解法二：单调递增栈 + 哨兵（推荐）

维护一个**栈内下标对应高度单调递增**的栈：

1. 末尾追加哨兵高度 `0`，保证扫描结束前栈里所有柱子都会被弹出（免收尾特判）；
2. 当前柱子 **不低于** 栈顶 → 下标入栈；
3. 当前柱子 **更矮** → 反复弹栈，**每次弹出都是一块矩形的确定**：高 = 弹出柱子的高度 `h`；宽 = 当前下标 `i` 与新栈顶之间（`i - stack.peek() - 1`）；栈已空则宽为 `i`（左侧没有更矮的，延伸到下标 0）；
4. 弹完再入栈，扫完哨兵即得答案。

- 时间复杂度：\(O(n)\)，每个下标至多入栈、出栈各一次；空间复杂度：\(O(n)\) 栈

## 代码

### 解法一：暴力枚举

```java
class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length, ans = 0;
        for (int i = 0; i < n; i++) {              // 枚举每根柱子作为矩形的高
            int left = i, right = i;
            while (left > 0 && heights[left - 1] >= heights[i]) left--;        // 向左扩
            while (right < n - 1 && heights[right + 1] >= heights[i]) right++; // 向右扩
            ans = Math.max(ans, heights[i] * (right - left + 1));
        }
        return ans;
    }
}
```

### 解法二：单调递增栈 + 哨兵（推荐）

```java
class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        int[] hs = new int[n + 1];
        System.arraycopy(heights, 0, hs, 0, n);
        hs[n] = 0;                                 // 哨兵：末尾追加 0，逼出栈内所有柱子

        Deque<Integer> stack = new ArrayDeque<>(); // 存下标，对应高度单调递增
        int ans = 0;
        for (int i = 0; i <= n; i++) {
            // 当前柱子比栈顶矮 → 栈顶柱子的左右边界都确定了，结算它
            while (!stack.isEmpty() && hs[stack.peek()] > hs[i]) {
                int h = hs[stack.pop()];           // 弹出柱子的高度
                int width = stack.isEmpty() ? i                  // 左边没有更矮的，宽到 0
                                            : i - stack.peek() - 1;  // 两根更矮柱之间
                ans = Math.max(ans, h * width);
            }
            stack.push(i);                         // 恢复递增性后再入栈
        }
        return ans;
    }
}
```

## 个人总结

### 1. 思维支点：枚举「每根柱子作为高」，而不是枚举矩形

矩形候选有 \(O(n^2)\) 个，但**任何最大矩形的高一定等于某根柱子的高度**（否则还能继续加高）。于是问题转化为：对每根柱子求「左右第一个更矮元素」→ 宽度确定。把 \(O(n^2)\) 个候选压缩成 \(O(n)\) 个「以 i 为高」的候选，是暴力升级到单调栈的桥梁。

### 2. 弹栈那一刻在算什么

栈里存下标、高度递增。当 `hs[i]` 比栈顶矮时：栈顶柱子的**右边界 = i**（第一个更矮），**左边界 = 新栈顶**（左边第一个更矮），宽 `i - stack.peek() - 1` 是两个「更矮柱」之间的开区间距离——中间所有柱子都 ≥ h。**弹出的不是一个柱子，而是一块完整矩形的确定**。想通这句，单调栈就从死记套路变成直觉。

### 3. 三个边界一网打尽：哨兵 + 栈空判断 + 高度 0

| 边界 | 处理 |
|:---|:---|
| 整体递增，末尾没人触发弹栈 | 末尾追加哨兵高度 `0`，在循环内统一结算 |
| 弹到栈空（左侧没有更矮的） | 宽度直接取 `i`（从下标 0 延伸到 i-1） |
| 高度为 0 的柱子 | 用严格 `>` 比较，0 柱正常入栈/结算，面积为 0 不影响答案 |

不加哨兵就得在循环结束后再写一段「清空栈结算」，容易漏；加了哨兵代码路径唯一。

### 4. 相等高度的语义，以及关联题

弹栈条件用 `hs[peek] > hs[i]`（严格大于）：相等时先压栈不结算，最后一段相等柱由**最右侧**那根以完整宽度结算出最大面积；中间的相等柱之后结算时宽度偏短但不漏最大值。若写成 `>=`（相等也弹）结果同样正确——**两种写法都对，关键是能说清边界语义，而不是背其中一种**。
