# 94. 二叉树的中序遍历

> **难度**：🟢 简单 | **标签**：树、栈、深度优先搜索 | **企业**：—

## 题目描述

给定一个二叉树的根节点 `root` ，返回它的 **中序** 遍历。

## 示例

**示例 1**

```
输入：root = [1,null,2,3]
输出：[1,3,2]
```

**示例 2**

```
输入：root = []
输出：[]
```

**示例 3**

```
输入：root = [1]
输出：[1]
```

---

## 提示

- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

---

## 进阶

递归算法很简单，你可以通过**迭代算法**完成吗？

---

## 思路

### 核心思想

中序遍历：**左 → 根 → 右**。递归天然符合这个顺序，迭代则需要用**栈**手动模拟。

```
    1
     \
      2
     /
    3

中序：1 → 3 → 2
```

### 解法一：递归（简单但面试不够）

1. 递归遍历左子树
2. 访问根节点
3. 递归遍历右子树

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(n)\)（递归栈）

### 解法二：迭代 + 栈（必会）

1. 从根开始，一路向左把沿途节点全部压栈
2. 弹栈一个节点，访问它
3. 转向该节点的右子树，重复步骤 1

核心循环：`一路向左压栈 → 弹栈访问 → 转向右子树`，直到栈空且当前节点为 null。

- 时间复杂度：\(O(n)\)，空间复杂度：\(O(n)\)

> ⚠️ 面试常问「不用递归写中序遍历」，迭代版本必须能手撕。

## 代码

### 我的伪代码

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        // ❌ 只写了递归版本，迭代版没写出来
        inorder(root, result);
        return result;
    }

    private void inorder(TreeNode node, List<Integer> result) {
        if (node == null) return;
        inorder(node.left, result);
        result.add(node.val);
        inorder(node.right, result);
    }
}
```

### 解法一：递归

```java
public List<Integer> inorderTraversal(TreeNode root) {

    return result;

private void inorder(TreeNode node, List<Integer> result) {

```

### 解法二：迭代 + 栈

```java
public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode curr = root;

    while (curr != null || !stack.isEmpty()) {
        // 一路向左，把沿途节点全部压栈
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }
        // 弹栈访问，然后转向右子树
        curr = stack.pop();
        result.add(curr.val);
        curr = curr.right;
    }
    return result;
}
```
