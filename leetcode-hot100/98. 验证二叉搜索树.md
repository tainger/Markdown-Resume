## 题目描述

给你一个二叉树的根节点 `root` ，判断其是否是一个有效的**二叉搜索树**（Binary Search Tree, BST）。

**有效** 二叉搜索树定义如下：

- 节点的左子树只包含 **小于** 当前节点的数。
- 节点的右子树只包含 **大于** 当前节点的数。
- 所有左子树和右子树自身必须也是二叉搜索树。

## 示例

**示例 1**

```
输入：root = [2,1,3]
输出：true
```

**示例 2**

```
输入：root = [5,1,4,null,null,3,6]
输出：false
解释：根节点的值是 5 ，但是右子节点的值是 4 。
```

```
        5
       / \
      1   4
         / \
        3   6    ← 3 < 5，却出现在 5 的右子树里，非法
```

**示例 3（隐藏反例）**

```
输入：root = [5,4,6,null,null,3,7]
输出：false
解释：6 的左孩子 3 < 5，父子比较查不出来，必须管整棵子树。
```

---

## 提示

- 树中节点数目范围在 `[1, 10^4]` 内
- `-2^31 <= Node.val <= 2^31 - 1`

## 进阶

无特别进阶要求。面试常追问：除了上下界递归，能否利用 BST 的**中序遍历严格递增**性质一行行比较？

## 思路

### 核心思想

BST 的约束是**跨层全局的**：一个节点合法 ⇔ 它的整棵左子树都小于它、整棵右子树都大于它。所以不能只比较 `父 > 左孩子 && 父 < 右孩子`，必须让每个节点携带一个合法值域 `(min, max)`，越往深层域越窄。

```
        5
       / \          5 的值域：(-∞, +∞)
      1   4         左子树值域收窄为 (-∞, 5)
         / \        右子树值域收窄为 (5, +∞)
        3   6       3 落在 (5, +∞) 之外 → 非法 ✘
```

另一条等价路径：**BST 的中序遍历是严格递增序列**，只需检查相邻两次访问的值是否递增。

### 解法一：递归传上下界 (min, max)（基础）

1. 根节点从开区间 `(Long.MIN_VALUE, Long.MAX_VALUE)` 出发
2. 进入左子树时，上界收窄为 `node.val`；进入右子树时，下界收窄为 `node.val`
3. 任一节点值 `<= min` 或 `>= max` → 立即返回 false

- 时间复杂度：\\(O(n)\\)，每个节点访问一次
- 空间复杂度：\\(O(h)\\)（h 是树高），递归栈开销

### 解法二：中序遍历维护前驱 prev（推荐）

1. 中序遍历（左 → 根 → 右），维护上一个访问到的值 `prev`
2. 在"根"的位置检查：`当前值必须 > prev`，否则非法
3. BST 合法 ⇔ 整条中序序列严格递增

- 时间复杂度：\\(O(n)\\)，最坏遍历全树（可提前终止）
- 空间复杂度：\\(O(h)\\)（递归）或 \\(O(h)\\)（迭代栈）

## 代码

### 解法一：递归传上下界

```java
public boolean isValidBST(TreeNode root) {
    // 节点值可达 Integer.MIN/MAX，边界必须用 long 防溢出/防误判
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

// 递归校验：node 的整棵子树值都必须落在开区间 (min, max) 内
private boolean validate(TreeNode node, long min, long max) {
    if (node == null) return true;
    // 越界即非法：BST 中不允许相等值
    if (node.val <= min || node.val >= max) return false;
    // 左子树值域收窄为 (min, node.val)，右子树收窄为 (node.val, max)
    return validate(node.left, min, node.val)
        && validate(node.right, node.val, max);
}
```

### 解法二：中序遍历维护前驱（推荐）

```java
public boolean isValidBST(TreeNode root) {
    Deque<TreeNode> stack = new ArrayDeque<>();
    long prev = Long.MIN_VALUE;   // 中序序列中上一个访问的值
    TreeNode cur = root;

    while (cur != null || !stack.isEmpty()) {
        // ① 一路向左，沿途节点入栈
        while (cur != null) {
            stack.push(cur);
            cur = cur.left;
        }
        // ② 弹栈 = 中序访问"根"的位置
        cur = stack.pop();
        if (cur.val <= prev) return false;   // 必须严格递增
        prev = cur.val;
        // ③ 转向右子树
        cur = cur.right;
    }
    return true;
}
```

## 个人总结

### 1. 坑：只比较父子节点值

| 写法 | 反例 | 结果 |
|:---|:---|:---|
| `node.left.val < node.val && node.right.val > node.val` | `[5,4,6,null,null,3,7]` | 误判 true ❌ |

BST 的定义是"整棵左子树 < 根 < 整棵右子树"，是**跨层**约束。上例中 3 在 5 的右子树里，隔了两层，父子比较完全发现不了。两种正解（上下界 / 中序递增）本质上都是在维护"所有祖先传下来的值域约束"。

### 2. 边界必须用 long，不能用 int

节点值可达 `-2^31` 和 `2^31 - 1`。若用 `int min = Integer.MIN_VALUE` 做初始下界，节点值恰为 `-2^31` 时 `node.val <= min` 成立，合法树被误判非法。用 `long` 的 `MIN/MAX_VALUE` 初始化即可（或用 `Integer` 包装类 + null 判断）。

### 3. 中序遍历性质是 BST 的万能钥匙

合法 BST ⇔ 中序序列严格递增。由此衍生：第 k 小（230）、中序后继、找两个错误交换节点（99）全都是这个套路的变体。维护一个 `prev` 只比较相邻两值，比"存数组再检查"省 O(n) 空间。

### 4. 递归解法二的成员变量版本

不想写迭代栈时，可用递归中序：成员变量 `prev` + 返回 `void`/`boolean` 的辅助方法，利用 `if (!dfs(left)) return false` 实现提前终止。注意成员变量在多测例间要重置（LeetCode 每次 new Solution 没问题，自己写测试时要小心）。
