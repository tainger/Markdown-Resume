# 994. 腐烂的橘子

## 题目描述

在给定的 `m x n` 网格 `grid` 中，每个单元格可以有以下三个值之一：

- 值 `0` 代表空单元格；
- 值 `1` 代表新鲜橘子；
- 值 `2` 代表腐烂的橘子。

每分钟，腐烂的橘子 **周围 4 个方向上相邻** 的新鲜橘子都会腐烂。

返回直到单元格中没有新鲜橘子为止所必须经过的最小分钟数。如果不可能，返回 `-1` 。

---

## 示例

**示例 1**

```
输入：grid = [[2,1,1],[1,1,0],[0,1,1]]
输出：4
```

**示例 2**

```
输入：grid = [[2,1,1],[0,1,1],[1,0,1]]
输出：-1
解释：左下角的橘子（第 2 行，第 0 列）永远不会腐烂，因为腐烂只会发生在 4 个正向上。
```

**示例 3**

```
输入：grid = [[0,2]]
输出：0
解释：因为 0 分钟时已经没有新鲜橘子了，所以答案就是 0 。
```

---

## 提示

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 10`
- `grid[i][j]` 仅为 `0`、`1` 或 `2`

---

## 思路

### 核心思想

所有腐烂橘子**第 0 分钟同时开始扩散**——这是**多源 BFS**：把全部源点一起放进初始队列，BFS 的层数就是分钟数，一层一层腐烂即是「同时扩散」下的最短时间。

### 解法一：多源 BFS + 新鲜橘子计数（推荐）

1. 扫描网格：所有值为 `2` 的格子入队（同一时间层），并统计新鲜橘子数 `fresh`；
2. 分层 BFS：每轮处理完当前队列里的**全部**节点（= 一分钟），把这一轮新污染的橘子（`grid` 改为 2）入队、`fresh--`；本层有真实扩散时分钟数 `+1`；
3. 结束后 `fresh == 0` → 返回分钟数；否则有新鲜橘子永远烂不到 → 返回 `-1`。

- 时间复杂度：\(O(mn)\)，每个格子至多入队一次；空间复杂度：\(O(mn)\) 队列

### 解法二：多源 BFS + 腐烂时刻表

用 `time[i][j]` 记录每个格子**被腐烂的时刻**（源点为 0，之后 = 来源节点时刻 + 1），答案 = 所有时刻的最大值。天然没有「最后一层空转多计一分钟」的问题，不需要 `spread` 标记；结束后仍需检查 `fresh` 是否清零。

- 时间复杂度：\(O(mn)\)；空间复杂度：\(O(mn)\) 队列 + 时刻表

## 代码

### 解法一：多源 BFS + 新鲜计数（推荐）

```java
class Solution {
    public int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        Queue<int[]> queue = new ArrayDeque<>();
        int fresh = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) queue.offer(new int[]{i, j});  // 所有源点同时入队
                else if (grid[i][j] == 1) fresh++;
            }
        }
        if (fresh == 0) return 0;              // 没有新鲜橘子（含全空网格），0 分钟

        int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        int minutes = 0;
        while (!queue.isEmpty()) {
            int size = queue.size();           // 当前这一分钟层的腐烂橘子
            boolean spread = false;            // 这一分钟是否真的污染了新橘子
            for (int s = 0; s < size; s++) {
                int[] cur = queue.poll();
                for (int[] d : dirs) {
                    int ni = cur[0] + d[0], nj = cur[1] + d[1];
                    if (ni >= 0 && ni < m && nj >= 0 && nj < n && grid[ni][nj] == 1) {
                        grid[ni][nj] = 2;      // 入队前就标记，防止重复入队
                        fresh--;
                        queue.offer(new int[]{ni, nj});
                        spread = true;
                    }
                }
            }
            if (spread) minutes++;             // 有真实扩散才计一分钟
        }
        return fresh == 0 ? minutes : -1;      // 还有新鲜橘子 → 永远烂不完
    }
}
```

### 解法二：多源 BFS + 腐烂时刻表

```java
class Solution {
    public int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] time = new int[m][n];          // time[i][j] = 被腐烂的时刻
        Queue<int[]> queue = new ArrayDeque<>();
        int fresh = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) queue.offer(new int[]{i, j});
                else if (grid[i][j] == 1) fresh++;
            }
        }
        int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            for (int[] d : dirs) {
                int ni = cur[0] + d[0], nj = cur[1] + d[1];
                if (ni >= 0 && ni < m && nj >= 0 && nj < n && grid[ni][nj] == 1) {
                    grid[ni][nj] = 2;          // 入队即标记
                    fresh--;
                    time[ni][nj] = time[cur[0]][cur[1]] + 1;   // 时刻 = 来源 + 1
                    queue.offer(new int[]{ni, nj});
                }
            }
        }
        if (fresh > 0) return -1;
        int ans = 0;
        for (int[] row : time) {
            for (int t : row) ans = Math.max(ans, t);
        }
        return ans;                            // 最大腐烂时刻即答案（无扩散时为 0）
    }
}
```

## 个人总结

### 1. 多源 BFS = 所有源点一起入队

「同时开始腐烂」等价于把所有腐烂橘子当**第 0 层**一起入队，之后逐层扩散，**层数 = 分钟数**。凡是「多个起点同时扩散、求最短时间」都这一套：火焰蔓延、僵尸传染、水波纹。单源 BFS 是它只有一个源点的特例。

### 2. 三个边界：无橘子 / 无新鲜 / 烂不完

| 场景 | 正确答案 | 常见错误 |
|:---|:---|:---|
| 网格全是 0（无橘子） | `0` | 漏特判 |
| 只有 2 没有 1 | `0` | 循环里多计了 1 分钟 |
| 新鲜橘子被空格隔开 | `-1` | 队空后直接返回 minutes |

**结束必查 `fresh == 0`**——队列空只说明「能烂的都烂了」，不代表「全烂了」（示例 2 的左下角永远孤立）。

### 3. minutes 的两种记法，选一种贯彻

- **分层法**（解法一）：`size = queue.size()` 固定一层，处理完整层后 `minutes++`，但必须用 `spread` 标记「本层是否真污染了新橘子」，否则最后空转的一层会多计 1；
- **时刻表法**（解法二）：每个格子记录腐烂时刻，答案取最大时刻，**天然没有多计 1 的问题**，也不用 spread。

两种都对；写分层法时最容易错的就是忘加 spread 导致 off-by-one。

### 4. 入队即标记 + 关联题

新鲜格子被污染时**立刻把 `grid` 改成 2 再入队**，不要等出队才标记——否则同一格会被多个腐烂邻居重复入队（fresh 被减成负数）。这是 BFS「访问即标记」纪律在网格上的体现，与 [200. 岛屿数量](200.%20岛屿数量.md) 同源。
