## 概念

### 前缀最大

### 堆（PriorityQueue）

Java 的 `PriorityQueue` 底层是二叉堆，**默认小顶堆**（堆顶最小，按元素自然顺序）。

**建堆：**

```java
// 小顶堆（默认，堆顶最小）
PriorityQueue<Integer> minHeap = new PriorityQueue<>();

// 大顶堆（堆顶最大）——传比较器
PriorityQueue<Integer> maxHeap  = new PriorityQueue<>(Comparator.reverseOrder());
PriorityQueue<Integer> maxHeap2 = new PriorityQueue<>((a, b) -> b - a);   // 大数值相减可能溢出，稳妥用 Integer.compare(b, a)

// 自定义对象：按字段排序（如按分数升序）
PriorityQueue<Student> stuHeap = new PriorityQueue<>((s1, s2) -> s1.score - s2.score);
```

**核心操作与复杂度：**

| 操作 | 复杂度 | 说明 |
|:---|:---:|:---|
| `offer(x)` / `add(x)` | \(O(\log n)\) | 插入并堆化（`offer` 失败返回 false，`add` 抛异常，刷题用 `offer`） |
| `poll()` | \(O(\log n)\) | 弹出并返回堆顶（极值） |
| `peek()` | \(O(1)\) | 只看堆顶不弹出 |
| `size()` / `isEmpty()` | \(O(1)\) | — |

**易错点：**

- **求第 K 大用「小」顶堆**（维护 K 个，堆顶即第 K 大）；求第 K 小用大顶堆——反直觉但关键，见 [215](215.%20数组中的第K个最大元素.md)。
- **不保证迭代顺序**：`for (int x : heap)` 输出**无序**，只有 `poll()` / `peek()` 才拿到极值；要有序只能反复 `poll()`（会清空堆）。
- **`(a,b)->b-a` 有溢出风险**：值域大时改用 `Integer.compare(b, a)` 或 `Long.compare`。

**典型应用：** Top-K（[215](215.%20数组中的第K个最大元素.md)、[347](347.%20前%20K%20个高频元素.md)）、贪心调度（[621 任务调度器](621.%20任务调度器.md) 用大顶堆每轮取剩余次数最多的任务）、合并 K 个有序链表、中位数（对顶堆）。
