## 规范要点

| 规则 | 说明 |
|:---|:---|
| **伪代码保留原始错误** | 不修正语法/逻辑，用 `// ❌` 标注每个 bug，方便二刷复盘 |
| **个人总结紧贴伪代码** | 每个总结对应伪代码的一个错误，形成「犯错 → 纠错」闭环 |
| **多解法并列** | 至少有迭代/暴力两种思路，标注推荐解法 |
| **难度用 emoji** | 🟢简单 🟡中等 🔴困难 |
| **复杂度用 LaTeX** | \(O(n)\) 格式 |
