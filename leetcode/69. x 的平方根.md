## 题目描述

给你一个非负整数 `x`，计算并返回 `x` 的 **算术平方根**。

由于返回类型是整数，结果只保留 **整数部分**，小数部分将被 **舍去**。

**注意：** 不允许使用任何内置指数函数和算符，例如 `pow(x, 0.5)` 或者 `x ** 0.5`。

---

## 提示

- `0 <= x <= 2^31 - 1`

## 思路

### 核心：在单调区间上找「满足 mid²≤x 的最大 mid」→ 二分找右边界

所求 `ans = ⌊√x⌋`，即满足 `k² ≤ x` 的最大整数 `k`。`k` 取值范围 `[0, x]`，且 `k²` 随 `k` 单调递增 → **二分查找**。

- 在 `[0, x]` 上二分，找**最后一个**满足 `mid * mid <= x` 的 `mid`；
- `mid * mid` 可能溢出 `int`（`x` 上界 `2^31-1`，`mid` 接近 `46340` 时 `mid²≈2.1×10^9` 刚好溢出），所以**用除法比较**：`mid <= x / mid`。

### 为什么用除法而非乘法

```
mid * mid <= x      // ❌ mid=46341 时 46341²=2147488281 > Integer.MAX_VALUE，溢出变负数，判断失效
mid <= x / mid      // ✅ 除法不溢出，等价变形（注意 mid=0 时要特判，避免除零）
```

- 时间复杂度：\(O(\log x)\)，二分区间长度为 x
- 空间复杂度：\(O(1)\)

## 代码

### 解法一：二分查找，找右边界（推荐）

```java
class Solution {
    public int mySqrt(int x) {
        // 特判：0 和 1 的平方根就是自身
        if (x <= 1) {
            return x;
        }
        int lo = 1, hi = x;            // 闭区间 [1, x]
        int ans = 0;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            // 用除法比较，防 mid*mid 溢出
            if (mid <= x / mid) {       // mid² <= x，mid 是合法候选
                ans = mid;              // 记录答案，继续往右找更大的
                lo = mid + 1;
            } else {                    // mid² > x，mid 太大
                hi = mid - 1;
            }
        }
        return ans;
    }
}
```

### 解法二：左闭右开模板，找「第一个 mid²>x 的位置」再减一

```java
class Solution {
    public int mySqrt(int x) {
        if (x <= 1) {
            return x;
        }
        int lo = 1, hi = x;            // 左闭右开 [lo, hi)，hi=x 表示「答案不超过 x」
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (mid <= x / mid) {       // mid² <= x，答案 >= mid，收缩左界
                lo = mid + 1;
            } else {                    // mid² > x，答案 < mid，收缩右界（不 -1，右开）
                hi = mid;
            }
        }
        // lo 是「第一个 mid²>x 的位置」，答案 = lo - 1
        return lo - 1;
    }
}
```

### 解法三：牛顿迭代法（进阶，面试加分）

```java
class Solution {
    public int mySqrt(int x) {
        if (x <= 1) {
            return x;
        }
        // 牛顿迭代：r 收敛到 √x，迭代式 r = (r + x/r) / 2
        long r = x;
        while (r * r > x) {             // 乘法用 long，不溢出
            r = (r + x / r) / 2;
        }
        return (int) r;
    }
}
```

## 个人总结

### 1. 题眼：单调区间 + 找满足条件的最大值 → 二分找右边界

求 `⌊√x⌋` = 找满足 `k² ≤ x` 的最大整数 `k`。`k` 在 `[0, x]` 上，`k²` 单调递增——这是**二分找右边界**的经典信号。和 [34. 查找元素的第一个和最后一个位置](../leetcode-hot100/34.%20在排序数组中查找元素的第一个和最后一个位置.md) 的「找最后一个 `<=target` 的位置」同构。

### 2. 防溢出：除法比较是保命线

`x` 上界 `2^31-1`，`mid` 在 `46340` 附近时 `mid²≈2.1×10^9` 已经**溢出 int**（`Integer.MAX_VALUE≈2.147×10^9`）。两种保命写法：
- **除法**：`mid <= x / mid`（注意 `mid=0` 特判防除零）；
- **升类型**：`(long) mid * mid <= x`。

面试被追问「会不会溢出」时，能主动指出 `46340` 这个临界点并给出除法方案是加分项。

### 3. 两种二分模板的对应关系

| 写法 | 找什么 | 返回 |
|:---|:---|:---|
| 闭区间 + `ans` 记录 | 最后一个 `mid²≤x` 的 mid | `ans` |
| 左闭右开 | 第一个 `mid²>x` 的位置 | `lo - 1` |

两种等价，选自己最不容易写错的那套。**闭区间 + `ans` 记录**更直观——「合法就记下来，继续往右找更大的」；**左闭右开**更通用——和 `lowerBound` 模板一脉相承。

### 4. 牛顿迭代法是面试加分项

二分是常规解法，能说出牛顿迭代法（`r = (r + x/r) / 2`，二次收敛，比二分快）是加分项。要点：
- 用 `long` 存 `r` 防 `r*r` 溢出；
- 终止条件 `r*r <= x`（此时 `r` 已收敛到 `⌊√x⌋`）。

### 5. 边界 case

- `x = 0` → `0`；`x = 1` → `1`：单独特判，避免除法除零或二分区间退化。
- `x = 2` → `1`（`√2≈1.414` 取整）：验证向下取整逻辑。
- `x = 2147395600` → `46340`（`46340²=2147395600`，`46341²=2147488281` 超过 `2^31-1`）：**溢出陷阱测试点**。
