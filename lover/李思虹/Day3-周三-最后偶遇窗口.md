## 一、三种开局，三种打法

### 场景 A：前两日已加微信 ✅

```
恭喜！主线已完成。

今天的你：
- 正常去食堂吃饭，不需要刻意找她
- 如果碰巧遇到 → 点头微笑 + 一句"嗨"就够了
- 如果还没发专业链接 → 今晚 20:00 必须发
- 保持自然、不紧迫的状态本身就是加分项

今日核心：不要因为"快离职了"而过度联系。
你已经拿到了通行证，现在要做的就是稳住。
```

### 场景 B：前两日见到但未开口 ⚠️

```
这是你最后的机会。没有退路。

行动方案：
12:00 到食堂 → 直接走到她面前（或斜对角）→
吃完饭后，在倒餐盘时自然开口。

今日话术（带上紧迫感，但语气依然要轻松）：

"嗨，你是前端组的李思虹对吧？
 其实前两天就想跟你打个招呼来着——
 我是 XX 部门的 XXX，这周五就离职了。
 之前看你们团队写的那个 [项目名]，
 动画那块的性能优化一直想请教一下。
 方便加个微信吗？以后万一卡住了还能问问你。"

注意："前两天就想打招呼" —— 这句话说明你不是一时冲动，
而是真的关注过，这会增加诚意分。
```

### 场景 C：连续三日未见 ❌

```
食堂偶遇路线正式关闭。

她可能：
- 带饭在工位吃
- 和团队出去吃
- 休假
- 就餐时间和你错开

今日行动：
1. 最后一次食堂尝试（12:00-12:20）
2. 若仍未见到 → 承认食堂路线失败
3. 回到工位，准备明天 D4 的通讯录方案

不要自责。你无法控制她出不出现。
你能控制的，是后备方案的执行力。
```

## 四、心理建设（重要）

```
三天了。

如果你还没开口，我要跟你说几句：

1. 你在怕的不是她拒绝你。
   你怕的是「自己不够好」被验证。
   但这不是事实。你是个认真的、欣赏她专业能力的同事。
   你的动机是真诚的，这就够了。

2. 她拒绝你不是世界末日。
   最坏的结果是她说不方便加微信。
   然后呢？你周五离职，这辈子大概率不会再见到她。
   拒绝的代价 = 零。不开口的代价 = 永远不知道。

3. 你已经在做大多数人不敢做的事。
   大部分人离职时默默走掉，连再见都不说。
   你至少认真准备了三天的计划。
   这份诚意本身就值得尊重。

今天，迈出那一步。
不是为了成功，是为了不留遗憾。
```
