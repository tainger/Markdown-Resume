## 二、通讯录方案详解

### Step 1：选择发送渠道

按优先级排序：

| 优先级 | 渠道 | 优点 | 缺点 |
|--------|------|------|------|
| 1 | 公司钉钉/飞书 | 已读状态可见，相对正式 | 离职后账号注销，需尽快加微信 |
| 2 | 企业微信 | 同上 | 同上 |
| 3 | 公司内部通讯录找手机号 → 短信 | 直达私人手机 | 短信略显唐突 |
| 4 | 公司邮箱 | 正式但不亲密 | 可能不看 |

> 推荐：**钉钉/飞书 + 短信双通道**。先发钉钉，2 小时后无回复补发短信。

### Step 2：发送时间

```
最佳窗口：上午 10:00 - 11:00

原因：
- 9:00 太早，她可能在赶早会/看消息
- 10:00 已进入工作状态，但还没到午休前的忙碌期
- 不要在 12:00-14:00（午休/吃饭）、17:00 后（准备下班）
```

### Step 3：消息内容

```text
思虹你好，我是 XX 部门的 XXX。

这周五就离职了，之前一直想请教一个前端
性能优化的问题，没找到合适的机会当面聊。

如果不打扰的话可以加个微信吗？
我的微信号是：[你的微信号]

祝工作顺利。
```

### 消息要点

| 要素 | 为什么 |
|------|--------|
| 报身份（XX 部门的 XXX） | 她需要知道你是谁 |
| 这周五离职 | 制造紧迫感 + 降低防备（你要走了） |
| 想请教前端问题 | 延续"技术认同"差异化定位 |
| 没找到合适机会当面聊 | 解释为什么用线上渠道 |
| 我的微信号是 xxx | 把主动权给她，不是"你能给我微信号吗" |
| 祝工作顺利 | 干净收尾，不拖泥带水 |
