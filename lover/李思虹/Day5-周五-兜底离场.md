## 一、三种结局，三种终章

### 结局 A：已加微信，已发专业链接 ✅（最优）

```
这是最好的结局。

今天你只需要做三件事：

1️⃣ 中午最后一次去食堂
   - 如果遇到她 → 点头微笑 + "嗨" + 继续走
   - 自然、轻松、没有任何压迫感
   - 你的离开应该是轻描淡写的，不是情感浓重的

2️⃣ 下班前发一条告别消息（微信）
   发送时间：16:30 - 17:00

   "今天最后一天啦。
    以后技术问题微信找你请教哈。
    祝一切顺利 🙌"

   - 语气轻松，不沉重
   - 用「以后微信聊」自然过渡到离职后的联系
   - 她回复就回，不回就到此为止

3️⃣ 正式离场
   - 清理工位，退群，走人
   - 不要在办公室搞任何"告别仪式"（与你无关的人不需要知道）
   - 离职后立即进入 Step 3 等待期

━━━━━━━━━━━━━━━━━━━━━━

后续节奏：
  离职后 D+7  → 技术话题自然跟进（"新公司前端框架不一样，在狂补"）
  离职后 D+14 → 约咖啡（"上次给你看的页面重构了一版，拜师礼"）
```

### 结局 B：通讯录已发，她回了但未加微信 ⚠️

```
今天你要做的：

1️⃣ 回复她的消息（如果她通过通讯录回复了）
   - 自然聊几句技术话题
   - 在对话中引导："回头微信方便聊一些，我微信号是 xxx"
   - 不要催，不要急

2️⃣ 如果她始终未加微信
   - 今天下午不要再发任何消息
   - 你已经表达了你的诚意，剩下的交给她
   - 离职后 D+7 用钉钉/飞书发送一次技术问题跟进
     （因为账号还在，最后用一次）
   - 若依然无回应 → 结束，体面退场
```

### 结局 C：至今无任何联系 🔴（兜底方案）

```
这是最后的方案。只有一次机会。必须精准执行。

━━━━━━━━━━━━━━━━━━━━━━
便签方案
━━━━━━━━━━━━━━━━━━━━━━

准备工作（下午 15:00-15:30）：
- 一张干净的手写便签纸（或打印出来裁好）
- 字迹工整，不要潦草

便签内容：

┌──────────────────────────────┐
│                              │
│   李思虹：                   │
│                              │
│   离职前一直想请教一个       │
│   前端问题没找到机会。       │
│                              │
│   如果不介意，可以加个       │
│   微信吗？                   │
│                              │
│   ——XXX（微信号：xxx）      │
│                              │
└──────────────────────────────┘

执行时间：16:00 - 16:30（她可能不在工位/开会/去茶水间）
执行方式：
- 走到她工位
- 如果她在 → 亲手递给她，说：
  "离职前一直想跟你请教个前端的问题，
   没找到机会。这个你收着，不着急。"
  然后离开，不逗留。
- 如果她不在 → 把便签放在键盘上（显眼但不招摇的位置）
- 放完就走，不要磨蹭

🚫 绝对规则：
- 只放一次。不放第二次。
- 不放任何礼物、零食、花。
- 不留任何"我会等你的"之类的文字。
- 只放便签，干净利落。
```

## 三、离场仪式（所有人通用）

> 这部分和你是否追到她无关。这是给你自己的。

```
在工位上的最后 10 分钟：

1. 打开手机备忘录，写下一句话：
   「2026 年 X 月 X 日，我在这里的最后一天。
    这五天，我做了以前不敢做的事。
    无论结果如何，我尊重了自己的心意。」

2. 环顾一下这个坐了 N 年的工位。
   记住这个场景。
   以后你会怀念的不是这个工位，
   而是那个勇敢迈出第一步的自己。

3. 起身，退群，关机。

   走出大门的那一刻，你就不是这里的员工了。
   你是一个有勇气表达自己心意的人。
   这个身份比任何 title 都值钱。
```

```text

比之前流畅多了。

哪天有空请你喝杯咖啡，算是上次的拜师礼 ☕
```

- 如果她没回 D+7 的消息，D+14 的约见面跳过
- 永远不要追加"你怎么不回我"之类的消息
- 你表达过了，决定了是她的选择
