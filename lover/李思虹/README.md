# 离职前搭讪计划 · 李思虹 Case

> 项目状态：⚠️ 紧急 — 仅剩 **5 个工作日**  
> 目标对象：李思虹（前端开发，5 年司龄）  
> 截止日期：最后一个工作日下班前  
> 文档用途：记录策略、每日执行清单与后续跟进

---

## ⏳ 5 天倒计时总览

```
Day 1 (周一)   → 观察 + 第一次偶遇尝试
Day 2 (周二)   → 若 D1 未成功，二次尝试 + 备选方案启动
Day 3 (周三)   → 最后偶遇窗口 / 启动公司通讯录备选
Day 4 (周四)   → 若已加微信，当晚发送专业链接；若未加，最后通讯录机会
Day 5 (周五)   → 离职日：告别消息（兜底方案）+ 正式离场
────────────────────────────────────────────
离职后 D+7    → 首次技术话题自然跟进
离职后 D+14   → 约见面（咖啡/拜师礼）
```

> 核心原则：**宁可 Day 5 兜底，不能 Day N 冒进。**

## 二、核心策略

**底层逻辑**：不打"外貌牌"，打"专业认同牌"。  
**差异化定位**：让她记住我的方式是——"那个人注意到了我的代码/项目，而不是我的脸。"

**五天内执行路线**：
1. 前 3 天 → 线下偶遇（食堂）加微信
2. 加微信当晚 → 发送"专业链接"强化定位
3. 若前 3 天未偶遇 → Day 4/5 启用通讯录备选方案
4. 离职后两周 → 自然启动约见

## 三、每日执行清单

### 🔵 Day 1（周一）— 侦察 + 第一次尝试

| 时间 | 动作 |
|------|------|

| 若见到她 | 执行下方「食堂话术」→ 若成功加微信，转入 Day 1 晚间步骤 |

**Day 1 晚间（若已加微信）**：
- 20:00 左右发送专业链接 + 简短消息（见 Step 2 话术）
- 此后不追问、不连续发消息

### 🟡 Day 2（周二）— 二次尝试

| 时间 | 动作 |

| 若连续两天未见 | 她可能带饭/外出/休假 → 启动备选方案思考 |

| 场景 | 动作 |

| 完全未联系 | 最后一搏：打印一张手写便签，内容：「李思虹：离职前一直想请教一个前端问题没找到机会，如果不介意可以加个微信吗？——XXX（微信号：xxx）」。下班前放到她工位上。**仅此一次，不重复。** |

## 四、话术库

### 食堂开场话术（提前练习到自然）

> "冒昧问一下，你是李思虹吧？我是 XX 部门的 XXX。之前看你们前端团队做的那个项目页面，动画流畅度做得特别好，我自己业余写点小东西，那个性能优化一直搞不太明白。下礼拜我就离职了，想着趁还在赶紧请教一下，方便加个微信吗？万一以后写代码卡住了还能找个大神问一句。"

**加完后立刻收尾**：
> "谢啦，不耽误你吃饭了。回头我把那个页面的链接发你，有空瞟一眼就行，不用特意回。"

### 通讯录备选话术（Day 4/5 使用）

> "思虹你好，我是 XX 部门的 XXX。这周五就离职了，之前一直想请教一个前端性能优化的问题没找到合适的机会。如果不打扰的话可以加个微信吗？我的微信号是 xxx。祝工作顺利。"

### 微信专业链接消息（加微信当晚发送）

> "哈喽，我是中午食堂遇到的 XXX。业余写的小项目：[链接]。离职前能认识一个前端大佬，算是这周意外收获了。你随便看看就好，不用特意回～祝工作顺利。"

### 离职后首次跟进（离职后 D+7 左右）

> "思虹，新公司这边前端框架跟之前完全不一样，最近在狂补。上次给你看那个页面我重构了一版，哪天有空请你喝杯咖啡，算是上次的拜师礼。"

## 五、红线与避坑清单

| 绝对不要做 | 原因 |
|------------|------|
| 直接坐她对面 | 像面试，压迫感强 |
| 说"你好漂亮/气质真好"之类的外貌评价 | 已被无数人说过，无效信号甚至负分 |
| 加微信后当天连续发消息 | 热情过度，暴露目的性 |
| 离职当天送花/礼物 | 太重，不知如何处理 |
| 假装懂技术（发假链接或吹牛） | 五年经验前端一眼识破，信用清零 |
| 便签方案去工位超过一次 | 变成骚扰 |
| 通讯录消息连续发两条 | 已被忽略就不要追加 |

## 七、最终目标

> 在她心中留下的印象不是"一个离职前搭讪我的男同事"，而是 **"一个离职前因为欣赏我的技术而加我微信的前同事"**。  
> 后续能否发展，取决于这个第一印象的纯度。
> 
> **5 天的意义不是"抓紧时间"，而是"每一步都做到位，不留遗憾"。**
