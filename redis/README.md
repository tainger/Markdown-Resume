## 高频「必背」清单

- **Redis 为什么快**：纯内存 + 单线程命令执行（无锁无上下文切换）+ IO 多路复用 + 高效数据结构
- **6.0 多线程**：只有网络 IO 多线程，命令执行仍单线程
- **ZSet 底层**：跳表（范围查询/排名 O(log n)）+ 哈希表（zscore O(1)）
- **RDB vs AOF**：RDB 全量快照小而快但丢数据多；AOF 写命令日志安全但大而慢；推荐**混合持久化**
- **AOF 是写后日志**：先执行命令再记日志（与 MySQL WAL 相反）
- **过期删除**：惰性删除 + 定期删除（随机抽样 + 25% 阈值）
- **内存淘汰 8 策略**：`volatile-*` / `allkeys-*` × `lru/lfu/random/ttl`（默认 noeviction，常用 allkeys-lru）
- **主从是最终一致**：命令异步传播；哨兵靠投票判「客观下线」再自动故障转移
- **Cluster 哈希槽**：16384 个槽，`slot = CRC16(key) % 16384`
- **缓存三兄弟**：穿透（布隆过滤器）、击穿（互斥锁）、雪崩（过期加随机 + 集群）
- **双写一致性**：先更新库再删缓存 + 过期兜底，追求最终一致
- **分布式锁**：`SET NX EX` + 唯一 value + Lua 解锁 + Redisson 看门狗续期
