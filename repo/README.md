# 开源仓库索引

> 收录 `repo/` 目录下已 clone 的开源仓库，方便以后重新 clone 或换机器同步。

## 仓库清单

| 仓库 | 说明 | 地址 |
|:---|:---|:---|
| JARVIS | DeepSeek Harness 风格的自主智能体后台：Spring Boot 4 + H2 + MyBatis + AgentScope，前端 React + Ant Design，支持 MCP 集成与简易 RAG 知识库 | https://github.com/tainger/JARVIS.git |
| deepseek-harness | DeepSeek 官方开源的 agent harness（`dsh`），一切皆插件，基于 Cordis 架构 | https://github.com/deepseek-ai/deepseek-harness.git |

## 一键 Clone

```bash
git clone https://github.com/tainger/JARVIS.git
git clone https://github.com/deepseek-ai/deepseek-harness.git
```

## 备注

- **CyberLoRA**：非独立 git 仓库，属于父仓库 [Markdown-Resume](https://github.com/tainger/Markdown-Resume.git) 的一部分（含 Colab 训练 notebook、预处理脚本与配置），无需单独 clone。
