# 开源仓库索引

> 收录 `repo/` 目录下已 clone 的开源仓库，方便以后重新 clone 或换机器同步。

## 仓库清单

| 仓库 | 说明 | 地址 |
|:---|:---|:---|
| JARVIS | DeepSeek Harness 风格的自主智能体后台：Spring Boot 4 + H2 + MyBatis + AgentScope，前端 React + Ant Design，支持 MCP 集成与简易 RAG 知识库 | https://github.com/tainger/JARVIS.git |
| OverSell-Defender | 秒杀系统后端：Spring Boot 3 + MyBatis-Plus + MySQL，纯 MySQL 方案防超卖，适合学习和二次开发 | https://github.com/tainger/OverSell-Defender.git |
| front-ui | 可视化设计提示词仓库系统：Markdown 存储风格模板 + 卡片网格展示 + 一键复制 Prompt，线上部署在 Vercel | https://github.com/tainger/front-ui.git |
| OpenBI-backend | BI（商业智能）后端服务，含 saturn 模块 | https://github.com/tainger/OpenBI-backend.git |
| OpenBI-front | BI（商业智能）前端项目，支持 dev/build 多环境 | https://github.com/tainger/OpenBI-front.git |
| connector | 万物皆可集成的连接器项目 | https://github.com/tainger/connector.git |
| agentscope-java | AgentScope 的 Java 实现：多智能体编排框架，支持 MCP 协议与工具调用 | https://github.com/agentscope-ai/agentscope-java.git |
| deepseek-harness | DeepSeek 官方开源的 agent harness（`dsh`），一切皆插件，基于 Cordis 架构 | https://github.com/deepseek-ai/deepseek-harness.git |

## 一键 Clone

```bash
git clone https://github.com/tainger/JARVIS.git
git clone https://github.com/tainger/OverSell-Defender.git
git clone https://github.com/tainger/front-ui.git
git clone https://github.com/tainger/OpenBI-backend.git
git clone https://github.com/tainger/OpenBI-front.git
git clone https://github.com/tainger/connector.git
git clone https://github.com/agentscope-ai/agentscope-java.git
git clone https://github.com/deepseek-ai/deepseek-harness.git
```

## 备注

- **CyberLoRA**：非独立 git 仓库，属于父仓库 [Markdown-Resume](https://github.com/tainger/Markdown-Resume.git) 的一部分（含 Colab 训练 notebook、预处理脚本与配置），无需单独 clone。
