# 二分查找 Binary Search

> 一句话：在单调性（或局部单调性）上每次排除一半搜索空间，O(log n)；难点全部在边界。

## 易错点

- `while (left < right)` 配 `right = mid`，`while (left <= right)` 配 `right = mid - 1`，两套模板不要混
- 求中点写 `left + (right - left) / 2` 防溢出
