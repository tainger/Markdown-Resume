# 二叉树遍历 Binary Tree Traversal

> 一句话：递归靠「位置决定语义」（前/中/后序），迭代靠显式栈，层序靠队列；序列化必须显式标记 null 才能唯一重建。

## 易错点

- BST 问题优先想「中序有序」这一性质，反序中序即降序
- 序列化不标 null 无法唯一重建；序列化与反序列化遍历序必须一致
