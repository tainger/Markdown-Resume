# gogo-agent 面试答题主线

> 答题骨架：业务目标 → 请求路径 → 两个深挖点 → 故障与边界 → 证据。题库入口：[[AI项目/gogo-agent/interview/README]]。

## 两分钟项目介绍

- 企业差旅助手：申请/审批管理、行程规划、信息查询与预订执行，报销仍待实现。以实际注册链路为准，不按类文件数量计算可用 Agent。来源：[[AI项目/gogo-agent/3.项目整体架构与核心功能]]、[[AI项目/gogo-agent/7.项目中有哪些智能体，各自职责是什么]]。
- 普通请求先用原问题走规则/向量快路径；未命中才改写并重新识别，最终由 Master 协调。来源：[[AI项目/gogo-agent/17.意图识别与问题改写的流水线编排]]、[[AI项目/gogo-agent/20.用户意图很明确时，直接路由给子智能体还是主智能体]]。
- 大语言模型 Large Language Model（LLM）负责语义理解和主观偏好，代码负责确定性计算、硬否决与业务写入。来源：[[AI项目/gogo-agent/43.为什么行程方案设计不用Skill要用工具]]、[[AI项目/gogo-agent/65.多维行程审核架构的方案设计]]。

## 不能混用的实现口径

- 普通高置信直跳已停用；continuation 续跑与挂起工具恢复另有路径。来源：[[AI项目/gogo-agent/20.用户意图很明确时，直接路由给子智能体还是主智能体]]、[[AI项目/gogo-agent/30.快速路由到上次执行的子智能体]]。
- 当前审核由工具编排，仲裁仍调用模型；代码强制客观 fail 不被覆盖。“0 分等于剔除”“代码硬限两轮”不能作为当前实现保证。原笔记口径差异与源码证据：[[AI项目/gogo-agent/interview/09.源码核对与待补证据]]；相关 raw：[[AI项目/gogo-agent/65.多维行程审核架构的方案设计]]、[[AI项目/gogo-agent/67.审核建议给出后如何优化给出新方案]]。
- 外部订单唯一键约束本地重复落库，不保证供应商下单幂等；酒店取消可能仅改变内部记录。来源：[[AI项目/gogo-agent/74.行程预订的下单结果持久化方案]]、[[AI项目/gogo-agent/76.取消预订工具的定义及开发]]；实现边界见 [[AI项目/gogo-agent/interview/03.工具设计与预订一致性]]。
- 安全、凭据加密和恢复一次消费不能从组件名称推断已完成。静态核对发现及定位统一见 [[AI项目/gogo-agent/interview/09.源码核对与待补证据]]，未修改原笔记或源码。
