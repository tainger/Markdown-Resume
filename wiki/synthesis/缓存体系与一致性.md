# 缓存体系与一致性

> 一句话：三兄弟（穿透/击穿/雪崩）是「怎么不挂」，一致性是「怎么不错」，先用兜底方案保命，再谈强一致。

## 答题骨架

```
穿透：  缓存空值 + 布隆过滤器
击穿：  热点互斥锁 / 逻辑过期
雪崩：  过期时间加随机 + 多级缓存 + 集群高可用
污染：  LFU / 访问频次淘汰
一致性：Cache Aside（先更库再删缓存）+ 延迟双删 + binlog 订阅兜底
```
