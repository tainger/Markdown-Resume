# 高并发库存扣减（秒杀主线）

> 一句话：前端漏斗挡流量 → Redis 预扣挡超卖 → MQ 异步挡峰值 → DB 最终一致兜底，每一层都有「为什么必须有它」。

## 答题骨架

```
流量漏斗：静态化/按钮置灰 → 网关限流 → MQ 削峰
库存方案：Redis 预扣（Lua 保证检查+扣减原子）→ MQ 异步下单 → MySQL 扣减兜底
一致性：  本地消息表 / 事务消息（见 [[wiki/synthesis/分布式事务选型]]）
兜底：    对账 + 库存回补 + 防重幂等
```
