## 分簇速查

> 每簇只收最致命的 2~5 条；全量踩坑可随时从 raw 重新聚合（Case 16 可重跑）。

### 双指针与滑动窗口

- [[leetcode-hot100/3. 无重复字符的最长子串]]：`slow = index+1` 缺 `Math.max` 保护会回退（反例 `"abba"`）；map 要存最新位置不是最早位置
- [[leetcode-hot100/75. 颜色分类]]：换 2 后必须原地重判（不 `cur++`），循环条件是 `cur <= p2`
- [[leetcode-hot100/76. 最小覆盖子串]]：扩窗判 `<=`、缩窗判 `<` 不对称最易写反；缩窗必须 `while` 不能 `if`
- [[leetcode-hot100/240. 搜索二维矩阵 II]]：行列各自有序 ≠ 整体全序，不能拉直一维二分；Z 字起点选单调性相反的角
- [[leetcode-hot100/581. 最短无序连续子数组]]：必须严格比较（`[1,1,1]` 应返 0）；有序时 left/right=-1 要特判，直接算得脏值

### 哈希·计数·前缀和

- [[leetcode-hot100/560. 和为 K 的子数组]]：`map.put(0,1)` 空前缀哨兵漏初始化 → 漏掉从头开始的整段
- [[leetcode-hot100/128. 最长连续序列]]：只从 `num-1` 不在集合的起点扩展是灵魂；要能口头辩护「外层 O(n)+内层累计 O(n) ≠ O(n²)」
- [[leetcode-hot100/437. 路径总和 III]]：树有分叉，离开一条链必须把该链独有前缀和从哈希表撤销（数组版没有此步）

### 链表

- [[leetcode-hot100/19. 删除链表的倒数第 N 个结点]]：`return head` 在删头场景返回已摘除节点，必须 `return dummy.next`；只有删头用例能抓出此 bug
- [[leetcode-hot100/21.合并两个有序链表]]：双指针 ≠ 只需两个指针，输出侧还要第三个 `curr` 串联
- [[leetcode-hot100/142. 环形链表 II]]：`fast.next.next` 前双判空；哈希判重存节点引用不是值；Floyd 是两阶段（相遇≠入口）
- [[leetcode-hot100/23. 合并 K 个升序链表]]：逐一合并 O(Nk) 慢在长链被反复扫，堆/分治降到每节点 log k

### 二叉树与递归

- [[leetcode-hot100/124. 二叉树中的最大路径和]]：更新答案用「拐弯路径」、返回父用「单边贡献」；全局初值 `MIN_VALUE`（树可能全负）
- [[leetcode-hot100/297. 二叉树的序列化与反序列化]]：null 显式占位才能唯一还原；序列化/反序列化必须同序
- [[leetcode-hot100/337. 打家劫舍 III]]：树形 DP 返回 `[不选, 选]` 两态，单值信息不够
- [[leetcode-hot100/538. 把二叉搜索树转换为累加树]]：BST 反序中序（右→根→左）得降序

### 回溯

- [[leetcode-hot100/78. 子集]]：`res.add(path)` 不拷贝 → 结果被后续回溯污染全变空列表（最经典坑）
- [[leetcode-hot100/22. 括号生成]]：StringBuilder 分支共享，返回前必须 `deleteCharAt` 撤销
- [[leetcode-hot100/46. 全排列]]：组合用 start 只往后、排列用 used 从头扫，混用会抹掉顺序差异
- [[leetcode-hot100/39. 组合总和]]：可重复选传 `i` 不是 `i+1`；排序后剪枝用 `break` 不是 `continue`

### 动态规划

- [[leetcode-hot100/416. 分割等和子集]]：一维 0-1 背包必须**倒序**（正序=物品重复使用）；sum 奇数先剪枝
- [[leetcode-hot100/494. 目标和]]：两个无解剪枝漏了会 `new int[负数]` 崩溃
- [[leetcode-hot100/322. 零钱兑换]]：哨兵用 `amount+1` 不用 `MAX_VALUE`（+1 溢出）；求最值循环序随意、求方案数必须外物品内金额
- [[leetcode-hot100/72. 编辑距离]] / [[leetcode-hot100/139. 单词拆分]]：dp 是长度维 1-indexed，与 `s[i-1]` 错一位是最高频 bug；`dp[0]` 初始化是灵魂
- [[leetcode-hot100/64. 最小路径和]]：第一行/列没有「上/左」来源，必须单独前缀累加
- [[leetcode-hot100/5. 最长回文子串]]：`dp[i][j]` 依赖左下角 → i 必须倒序枚举
- [[leetcode-hot100/312. 戳气球]]：反向枚举「最后戳的 k」把动态邻居钉成静态边界；两端补虚拟气球消越界；小区间先算
- [[leetcode-hot100/221. 最大正方形]]：dp 定义「以 (i,j) 为右下角」；答案是边长平方；滚动数组 prev 覆盖前用 temp 存

### 栈与单调栈

- [[leetcode-hot100/20.有效的括号]]：pop 前判空（`")"` 直接崩）；结尾检查栈是否清空
- [[leetcode-hot100/32. 最长有效括号]]：栈存**下标**才能算长度；栈底哨兵 -1 是合法段左侧第一个未匹配位
- [[leetcode-hot100/85. 最大矩形]]：逐行高度遇 0 必须归零；末尾哨兵强制清算
- [[leetcode-hot100/394. 字符串解码]]：strStack 存「进入 [ 前的外层前缀」不是当前块

### 二分查找

- [[leetcode-hot100/34. 在排序数组中查找元素的第一个和最后一个位置]]：两套边界模板易混，统一 lowerBound + `lowerBound(t+1)-1` 最稳
- [[leetcode-hot100/4. 寻找两个正序数组的中位数]]：必须在**较短**数组上二分；±∞ 哨兵消灭 4 种空半区特判
- [[leetcode-hot100/287. 寻找重复数]]：数组无序可对「答案值域」二分；或 i→nums[i] 建链找环入口（Floyd 复用）

### 贪心·排序·区间

- [[leetcode-hot100/56. 合并区间]]：重叠判 `<=`（端点相接看题意）；合并右端点必须 `max(last[1], cur[1])`
- [[leetcode-hot100/31. 下一个排列]]：交换对象是右边第一个大于 nums[i] 的元素（反例 `[1,3,2]`）；整体降序也要反转
- [[leetcode-hot100/215. 数组中的第K个最大元素]]：第 K 大 = 升序下标 n-k；快速选择必须随机化基准
- [[leetcode-hot100/406. 根据身高重建队列]]：双维牵制先锁死一维：h 降序 + 同高 k 升序，错一个计数全乱

### 图论与并查集

- [[leetcode-hot100/207. 课程表]]：建边方向先修→后修，反了入度全错；DFS 判环要三色标记；Kahn 数出队数即可
- [[leetcode-hot100/200. 岛屿数量]]：计数后必须淹没整岛；BFS 入队时就标记（出队才标会重复入队）；大网格 DFS 爆栈换 BFS
- [[leetcode-hot100/399. 除法求值]]：双向建边不能漏（权 1/k）；`x/x` 且 x 出现过是 1.0 不是 -1.0

### 堆与 TopK

- [[leetcode-hot100/215. 数组中的第K个最大元素]] / [[leetcode-hot100/347. 前 K 个高频元素]]：求 K 大用**小顶堆**（堆顶是最该淘汰的）；值域有界上桶排序 O(n)

### 建模与转化思维

- [[leetcode-hot100/238. 除自身以外数组的乘积]]：禁除法约束 + 含 0 坑 → 前缀积；「空积」是 1 不是 0
- [[leetcode-hot100/253. 会议室 II]]：最少房间 = 时间轴最大重叠数；开始/结束拆开排序正确（只关心计数）
- [[leetcode-hot100/621. 任务调度器]]：谁最多谁排骨架；冷却是两次相同任务间隔，最后一段不需要

### 工程细节（Java）

- [[leetcode-hot100/155. 最小栈]]：Java `Stack` 是遗留类，规范用 `ArrayDeque`；diff 解法一正一负接近边界溢出
- [[leetcode-hot100/1. 两数之和]]：数组 `length` vs 字符串 `length()`
- [[leetcode-hot100/221. 最大正方形]]：矩阵是 char，比较 `'1'` 别当 int 1
