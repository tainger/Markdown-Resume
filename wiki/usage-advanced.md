# LLM Wiki 使用手册·进阶卷（Case 13-20）

> 核心日常 12 个 Case 见 [[wiki/usage]]；本卷是低频高价值的进阶玩法。
> 维护规范见根目录 `AGENTS.md`。

## Case 13｜考前 24h 速记包（Cheat Sheet）

**你说**：

> 明天上午面 XX 公司，把相关内容蒸馏成一页速记包

**Agent 做**：从 [[wiki/synthesis/P7面试复习主线]] + 目标公司相关实体页，抽每页的「一句话总结 + 追问链关键词」→ 对话输出单页速记版（可选存 `wiki/cheatsheets/<日期>.md`）。

原则：**只蒸馏不新增**，内容全部能指回 wiki 页。

## Case 14｜答案评分器（五段式打分）

**你说**：（贴一段你的口述回答，语音转文字即可）

> 帮我打分：Redis 缓存穿透就是查询不存在的数据……（口述稿）

**Agent 做**：按 [[面试/Java后端高频面经速查]] 的五段式模型（定义→原理→优缺点→选型→落坑）逐层判定：命中 ✓ / 缺失 ✗ / 啰嗦 ⚠，指出最该补的一层和预计超时点。

与 Case 3 配套：**Drill 练被问，评分器练回答**。

## Case 15｜闪卡抽背 + 遗忘曲线调度

**你说**：

> 按遗忘曲线排今天该复习的页 / 滑动窗口页出 5 张闪卡

**Agent 做**：

- 读各页 frontmatter `updated` + `⚠️ 真题实录` 标记 → 生成「超过 N 天未碰」的复习队列
- 把 concept/entity 页的追问链转成 Q/A 闪卡，对话里抽背，答错的页 status 降级提醒

保温利器：**每天 10 分钟，只背该背的**。

## Case 16｜踩坑本聚合（全库错题本）

**你说**：

> 把 hot100 所有「个人总结」里的踩坑聚合一下

**Agent 做**：扫 [[leetcode-hot100/README]] 索引指向的每篇 `## 个人总结` 段落 → 按概念聚类（滑动窗口/DP/边界处理…）→ 生成「我的高频踩坑 Top N」页 → 二刷前先读它。

价值：**数据源现成，纯聚合就能长出新知识页**，这是 raw 层沉淀的复利。

## Case 17｜对比页工厂（该比未比）

**你说**：

> 扫一下还有哪些概念该对比没对比

**Agent 做**：统计各 wiki 页的双链共现频率 → 输出候选对比页清单，例如：

- select/poll/epoll（[[io/NIO与多路复用]] 内部）
- RDB vs AOF vs 混合（[[redis/持久化]]）
- synchronized vs ReentrantLock（[[java/JUC并发包]]）
- Kafka vs RocketMQ（[[wiki/entities/RocketMQ]]，⚠️ raw 缺 Kafka 笔记，标注待补充）

你点头才建页进 `comparisons/`。lint 找病灶，**工厂找空白**。

## Case 18｜全站死链巡检

**你说**：

> 全站链接巡检

**Agent 做**：VitePress 配置了 `ignoreDeadLinks: true`，构建会掩盖死链 → 扫全库 raw 笔记的 markdown 内链（含锚点、URL 编码空格 `%20`）→ 输出死链清单。

**边界**：修复涉及 raw 层，报告先行，改动需你授权。

## Case 19｜选题日历（公众号反向挖掘）

**你说**：

> 找写过笔记但没写过文章的选题

**Agent 做**：对齐 raw 笔记覆盖 vs [[自媒体/微信公众号/探小虎/README]] 已发文 → 输出：

- **写过笔记没写过文章**：如 深分页优化、MyBatis 插件机制
- **系列化缺口**：如 Agent 设计哲学系列已发篇目与断档
- **热点嫁接**：wiki/comparisons 素材直接可成文

Output（Case 5）管单篇生产，**选题日历管管线**。

## Case 20｜健康度报告（Wiki Dashboard）

**你说**：

> wiki 健康度

**Agent 做**：输出指标仪表盘：

| 指标 | 看什么 |
|:---|:---|
| status 分布 | seed/growing/stable 比例，喂养是否停滞 |
| 双链密度 | 平均每页入链数，孤页清单 |
| 目录覆盖 | 20+ raw 目录中还有哪些没被 wiki 触达 |
| log 频率 | 近 30 天 ingest/lint 次数，体系是否在活着 |

给出下一步建议：哪里该喂养、哪里该拆页、哪里该归档。
