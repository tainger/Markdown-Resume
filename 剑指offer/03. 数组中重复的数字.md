# 03. 数组中重复的数字

## 题目描述

在一个长度为 n 的数组 `nums` 里，所有数字都在 `0 ~ n-1` 范围内。数组中某些数字是重复的，找出**任意一个重复的数字**。

```
输入：[2, 3, 1, 0, 2, 5, 3]
输出：2 或 3
```

## 核心思路

**原地交换（鸽巢原理）**：值 `x ∈ [0, n-1]` 时，理想情况下 `nums[x] = x`。遍历数组，若 `nums[i] != i`，就把 `nums[i]` 交换到下标 `nums[i]` 的位置；如果发现 `nums[nums[i]]` 已经等于 `nums[i]`，说明重复了。

```
i=0: [2,3,1,0,2,5,3]  nums[0]=2, 看 nums[2]=1 ≠ 2 → 交换 → [1,3,2,0,2,5,3]
i=0: nums[0]=1, 看 nums[1]=3 ≠ 1 → 交换 → [3,1,2,0,2,5,3]
i=0: nums[0]=3, 看 nums[3]=0 ≠ 3 → 交换 → [0,1,2,3,2,5,3]   ← nums[0]=0，归位
i=1: nums[1]=1 归位
i=2: nums[2]=2 归位
i=3: nums[3]=3 归位
i=4: nums[4]=2, 看 nums[2]=2 已等于 2 → 命中重复，返回 2
```

## Java 最优解

```java
public int findRepeatNumber(int[] nums) {
    for (int i = 0; i < nums.length; i++) {
        // while 而不是 if：交换后新来的元素可能还需要继续归位
        while (nums[i] != i) {
            int x = nums[i];
            if (nums[x] == x) return x;   // 目标位置已是 x，重复
            // 把 nums[i] 交换到下标 x
            nums[i] = nums[x];
            nums[x] = x;
        }
    }
    return -1;
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n) | 每个元素最多被交换 2 次就归位（一次进一次出），均摊 O(1) |
| 空间 | O(1) | 原地交换，无额外空间 |

## 易错点

1. **用 `while` 不是 `if`**：交换后下标 `i` 位置来了新元素，可能还不等于 `i`，要继续处理
2. **先判断再交换**：`if (nums[x] == x) return x;` 必须在交换之前，否则会覆盖
3. **不能用排序法做最优解**：排序 O(n log n)，原地交换 O(n)
4. **值域限制**：题目保证 `0 ≤ nums[i] ≤ n-1`，否则该算法不适用，需用 HashSet

## 关键点

- **鸽巢原理**：n 个位置放 n 个值，若有重复必有冲突
- 这题的最优解思路可推广到「287. 寻找重复数」——但那题值域是 `[1, n]` 且不能修改原数组，要用**二分 + 计数**或**快慢指针判环**
- 面试官常追问「不修改数组怎么做」：用二分+计数（O(n log n)）或 Floyd 判圈（O(n)）

## 变种：不修改数组找重复

```
二分法：在 [1, n] 二分，每次统计 ≤ mid 的个数，若 > mid 则重复在左半
Floyd：把 nums[i] 当成链表 next 指针，问题转化为找链表环入口（287 题）
```
