# 04. 二维数组中的查找

## 题目描述

在一个 `m × n` 的二维数组中，**每一行按从左到右递增、每一列按从上到下递增**。判断数组中是否存在某个整数。

```
[
  [1,  4,  7,  11, 15],
  [2,  5,  8,  12, 19],
  [3,  6,  9,  16, 22],
  [10,13, 14, 17,  24],
  [18,21, 23, 26,  30]
]
target = 5  → true
```

## 核心思路

**右上角（或左下角）作为起点**：从右上角出发：
- 当前值 > target → 这列下面更大，**列左移**
- 当前值 < target → 这行左边更小，**行下移**
- 相等 → 找到

```
起点在右上角 (0, n-1) = 15
15 > 5  → 列左移 → (0,3)=11
11 > 5  → 列左移 → (0,2)=7
7  > 5  → 列左移 → (0,1)=4
4  < 5  → 行下移 → (1,1)=5  ✓
```

**为什么对**：右上角的元素是「该行最大、该列最小」。一次比较就能排除一行或一列，决策二分。

## Java 最优解

```java
public boolean findNumberIn2DArray(int[][] matrix, int target) {
    if (matrix == null || matrix.length == 0 || matrix[0].length == 0) return false;
    int m = matrix.length, n = matrix[0].length;
    int r = 0, c = n - 1;                       // 右上角
    while (r < m && c >= 0) {
        if (matrix[r][c] == target) return true;
        if (matrix[r][c] >  target) c--;        // 列左移
        else                        r++;        // 行下移
    }
    return false;
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(m + n) | 每次比较排除一行或一列，最多走 m+n 步 |
| 空间 | O(1) | 两个指针 |

## 易错点

1. **起点选错**：从左上角或右下角出发不能二分排除；只有右上角或左下角是「行最大+列最小」（或反之）的临界点
2. **空数组边界**：`matrix == null`、`length == 0`、`matrix[0].length == 0` 三种都要判
3. **越界**：`r < m && c >= 0` 两个条件都要写，否则数组越界
4. **用二分**：每行二分是 O(m log n)，比 O(m+n) 慢，且代码更复杂；行+列二分意义不大

## 关键点

- **核心思想**：找一个临界点，一次比较能「砍掉一行或一列」
- **起点选择**：右上角 / 左下角 都行；左上角 / 右下角 不行
- 对比 LeetCode 240「Search a 2D Matrix II」：本题就是 240
- **变种：每行首个 > 上一行末尾**（LeetCode 74）：展开成一维二分，O(log(mn))

## 变种：每行首个 > 上一行末尾（LeetCode 74）

```
可以看成展开后的一维升序数组
下标 i 映射到 [i/n][i%n]
二分一次 O(log(mn))
```
