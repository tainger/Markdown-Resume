# 05. 替换空格

## 题目描述

把字符串中的每个空格替换成 `%20`。

```
输入："We Are Happy."
输出："We%20Are%20Happy."
```

## 核心思路

**Java 直接用 StringBuilder**（不可变 String 必须新建）。如果用 C/C++ 的字符数组原位改写，可用**双指针从后向前填充**避免数据迁移。

```
原数组：We Are Happy.        （长度 14）
空格数 2 → 新长度 = 14 + 2*2 = 18
从后往前：
  - 源指针 p1 从原末尾 14 开始
  - 目标指针 p2 从新末尾 18 开始
  - 非 ' ' 复制到 p2
  - ' ' 写 %20 到 p2
```

## Java 最优解

```java
public String replaceSpace(String s) {
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (c == ' ') sb.append("%20");
        else          sb.append(c);
    }
    return sb.toString();
}
```

**容量预分配版**（性能更好）：

```java
public String replaceSpace(String s) {
    // 先数空格数，预分配容量
    int spaceCount = 0;
    for (int i = 0; i < s.length(); i++) {
        if (s.charAt(i) == ' ') spaceCount++;
    }
    StringBuilder sb = new StringBuilder(s.length() + spaceCount * 2);
    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (c == ' ') sb.append("%20");
        else          sb.append(c);
    }
    return sb.toString();
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n) | 一趟遍历 |
| 空间 | O(n) | 新字符串 |

## 易错点

1. **Java String 不可变**：不能「原地」修改，必须用 StringBuilder 或 `s.replace(" ", "%20")`
2. **不用 `s.replaceAll(" ", "%20")`**：能用但正则有开销；同时正则元字符需要转义
3. **预分配 StringBuilder 容量**：避免扩容时复制，是 P7 加分项
4. **C/C++ 原地改写**：需要先数空格、扩展长度、双指针从后往前；Java 不适用

## 关键点

- **Java 简单，C/C++ 才是面试考点**：面试官若问 Java 版，写出 StringBuilder + 容量预分配即可
- **从后往前的思想**：避免从前往后插入时每次都要后移字符，时间从 O(n²) 降到 O(n)
- **类似题目家族**：合并两个有序数组「从后往前填充」（LeetCode 88），思路完全相同
