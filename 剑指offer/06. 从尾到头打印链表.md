# 06. 从尾到头打印链表

## 题目描述

输入一个链表的头节点，从尾到头反过来返回每个节点的值（用数组）。

```
输入：1 → 2 → 3 → null
输出：[3, 2, 1]
```

## 核心思路

**两种写法**：
- **栈（推荐，简洁）**：遍历压栈，弹栈入数组
- **递归**：先递归后处理，天然逆序；但栈深 O(n)，长链表会 StackOverflow

```
链表 1 → 2 → 3 → null
压栈：[1, 2, 3]
弹栈：3, 2, 1
```

递归本质上**用了函数调用栈**，与显式栈等价。

## Java 最优解

```java
// 解法 1：栈（首选）
public int[] reversePrint(ListNode head) {
    Deque<Integer> stack = new ArrayDeque<>();
    for (ListNode p = head; p != null; p = p.next) {
        stack.push(p.val);
    }
    int[] res = new int[stack.size()];
    for (int i = 0; i < res.length; i++) {
        res[i] = stack.pop();
    }
    return res;
}
```

```java
// 解法 2：递归（注意栈深）
private List<Integer> tmp = new ArrayList<>();
public int[] reversePrint(ListNode head) {
    dfs(head);
    int[] res = new int[tmp.size()];
    for (int i = 0; i < tmp.size(); i++) res[i] = tmp.get(i);
    return res;
}
private void dfs(ListNode node) {
    if (node == null) return;
    dfs(node.next);              // 先递归后处理
    tmp.add(node.val);
}
```

```java
// 解法 3：反转链表（破坏原结构，慎用）
public int[] reversePrint(ListNode head) {
    ListNode prev = null, cur = head;
    int count = 0;
    while (cur != null) {
        ListNode next = cur.next;
        cur.next = prev;
        prev = cur;
        cur = next;
        count++;
    }
    int[] res = new int[count];
    for (int i = 0; i < count; i++) {
        res[i] = prev.val;
        prev = prev.next;
    }
    return res;
}
```

## 复杂度

| 解法 | 时间 | 空间 | 说明 |
|:---|:---:|:---:|:---|
| 栈 | O(n) | O(n) | 显式栈 |
| 递归 | O(n) | O(n) | 函数调用栈 |
| 反转链表 | O(n) | O(1) | 破坏原链表 |

## 易错点

1. **递归栈溢出**：链表超长（如 10000+）时递归会爆，生产用栈更稳
2. **数组大小**：栈版第一次压栈时不知道链表长度，可以先用 `size()` 取（Java 的 Deque 支持）；或先 count 再开数组
3. **破坏原链表**：解法 3 反转了原链表，面试时如果题目没说「可以修改」要确认
4. **时间复杂度差比较**：三种都是 O(n)，主要差在空间和可读性

## 关键点

- **「从尾到头」本质就是逆序**：栈、递归、反转链表三选一
- **递归的本质 = 函数调用栈**：栈能做的递归都能做，递归能做的栈也能做
- **后续遍历的链表版本**：二叉树后序遍历「左 → 右 → 根」与「先 dfs(next) 再访问 node」本质相同
- 对比 LeetCode 206「反转链表」：本题用反转更轻量（仅取值），206 要求真的反转指针

## 变种：反转链表（剑指 Offer 24）

```
三指针：prev=null, cur=head, next=cur.next
循环：cur.next = prev; prev = cur; cur = next
最后 prev 是新头
```
