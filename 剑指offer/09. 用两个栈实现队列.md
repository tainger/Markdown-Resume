# 09. 用两个栈实现队列

## 题目描述

用两个栈实现一个队列。队列的声明如下：实现它的 `push_back`（在队列尾部插入整数）和 `pop_front`（在队列头部删除整数）函数。

## 核心思路

**双栈翻转**：`stack1` 负责入队（直接 push），`stack2` 负责出队。当 `stack2` 为空时，把 `stack1` 全部倒入 `stack2`，顺序即反转，实现 FIFO。

```
入队 1,2,3:  stack1 = [1,2,3]
                │
                ▼ 倒栈
出队时:      stack2 = [3,2,1]  → pop → 1,2,3 (FIFO)
```

## Java 最优解

```java
class CQueue {
    Deque<Integer> stack1;  // 入队栈
    Deque<Integer> stack2;  // 出队栈

    public CQueue() {
        stack1 = new ArrayDeque<>();
        stack2 = new ArrayDeque<>();
    }

    public void appendTail(int value) {
        stack1.push(value);
    }

    public int deleteHead() {
        // stack2 空了才倒栈
        if (stack2.isEmpty()) {
            while (!stack1.isEmpty()) {
                stack2.push(stack1.pop());
            }
        }
        // 倒完还是空 → 队列空
        if (stack2.isEmpty()) {
            return -1;  // 题目约定空队列返回 -1
        }
        return stack2.pop();
    }
}
```

## 复杂度

| 操作 | 时间（最坏） | 时间（均摊） | 空间 |
|:---|:---:|:---:|:---:|
| appendTail | O(1) | O(1) | O(n) |
| deleteHead | O(n) | O(1) | O(n) |

**均摊分析**：每个元素最多被倒栈一次，单次倒栈 O(n) 但 n 次操作均摊 O(1)。

## 易错点

1. **倒栈时机**：必须在 `stack2` **空了**才倒，不能每次 delete 都倒（否则顺序会乱）
2. **空队列判断**：倒栈后 `stack2` 仍空说明队列空，返回 -1
3. **不要用 Stack 类**：Java 的 `Stack` 是旧类，推荐用 `Deque`（ArrayDeque）
4. **倒栈必须倒完**：while 循环倒完 stack1，不能只倒一个

## 关键点

- 双栈实现队列的核心：**倒栈翻转顺序**
- 均摊 O(1) 是关键考点，要会证明
- 反过来：两个队列也能实现栈（剑指 Offer 09 变种）

## 变种：用两个栈实现队列的简化思路

```
入队：直接 push stack1
出队：stack2 空 → 把 stack1 全倒入 stack2 → pop stack2
      stack2 非空 → 直接 pop stack2
```
