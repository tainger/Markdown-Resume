# 18. 删除链表的节点

## 题目描述

给定单向链表的头指针和一个要删除的节点的值，删除该节点并返回新的头节点。

```
输入：head = [4,5,1,9], val = 5
输出：[4,1,9]
```

## 核心思路

**哨兵节点 + 双指针**：用一个 dummy 节点统一头节点处理（删除头节点和其他节点逻辑一致），用 `prev` 和 `cur` 两个指针。

```
dummy → 4 → 5 → 1 → 9 → null
       ↑   ↑
     prev cur
val = 5
cur.val == 5 → prev.next = cur.next → 跳过 5
```

## Java 最优解

```java
public ListNode deleteNode(ListNode head, int val) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode prev = dummy, cur = head;
    while (cur != null) {
        if (cur.val == val) {
            prev.next = cur.next;          // 删除 cur
            break;
        }
        prev = cur;
        cur = cur.next;
    }
    return dummy.next;
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n) | 一次遍历 |
| 空间 | O(1) | 几个指针 |

## 易错点

1. **不写 dummy 直接处理**：删除头节点时要改 head，与中间节点的删除逻辑分支化；写 dummy 统一处理
2. **被删节点不存在**：上面代码用 `break`，没找到就什么都不做；也可以遍历到尾自然退出
3. **删除后 `cur` 的清理**：Java 自动 GC，不用手动 `cur.next = null`；C/C++ 要 free
4. **题目保证值存在**：剑指 Offer 题目保证；鲁棒代码仍要处理不存在的情况

## 关键点

- **dummy 节点是链表题的万能技巧**：统一头节点和中间节点处理逻辑
- **`prev.next = cur.next` 是删除模板**：跳过 cur 即可
- 对比 LeetCode 237「Delete Node in a Linked List」：只给你要删的节点指针，没有 head；用「值后移 + 删下一个」的奇技淫巧
- **变种：删除倒数第 N 个节点**（LeetCode 19）：dummy + 快慢指针，fast 先走 n+1 步

## 变种：删除倒数第 N 个节点（LeetCode 19）

```
dummy → head
fast 从 dummy 开始，先走 n+1 步（注意是 n+1 不是 n）
然后 slow 和 fast 一起走，fast 到 null 时 slow 在被删节点的前驱
slow.next = slow.next.next
```
