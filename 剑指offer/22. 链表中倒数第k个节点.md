# 22. 链表中倒数第 k 个节点

## 题目描述

输入一个链表，输出该链表中倒数第 `k` 个节点。**从 1 开始计数**，即链表尾节点是倒数第 1 个节点。

```
输入：1 -> 2 -> 3 -> 4 -> 5, k = 2
输出：节点 4（返回节点，不是值）
```

## 核心思路

**双指针（快慢指针）**：让快指针 `fast` 先走 `k` 步，然后 `slow` 和 `fast` 一起走，`fast` 走到 `null` 时 `slow` 正好在倒数第 `k` 个。

```
        快指针先走 k=2 步
1 → 2 → 3 → 4 → 5 → null
        ↑
       fast

然后快慢一起走，fast 到 null 时 slow 在倒数 k=2 即节点 4
1 → 2 → 3 → 4 → 5 → null
            ↑           ↑
          slow        fast
```

## Java 最优解

```java
public ListNode getKthFromEnd(ListNode head, int k) {
    ListNode fast = head, slow = head;
    // fast 先走 k 步
    for (int i = 0; i < k; i++) {
        if (fast == null) return null;   // 链表长度 < k，提前返回
        fast = fast.next;
    }
    // 一起走
    while (fast != null) {
        fast = fast.next;
        slow = slow.next;
    }
    return slow;
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n) | 一次遍历 |
| 空间 | O(1) | 两个指针 |

## 易错点

1. **k 大于链表长度**：快指针先走阶段 `fast == null` 时必须提前返回，否则后面 `fast.next` NPE
2. **k = 0 或负数**：题目保证 k 合法时可不处理；鲁棒代码可加 `if (k <= 0) return null`
3. **倒数从 1 开始**：不是 0，别搞错；倒数第 1 就是尾节点
4. **先走 k 步再走 n-k 步**：等价于 slow 走了 n-k 步，正好是倒数第 k 个

## 关键点

- **倒数第 k = 正数第 n-k+1**
- **快慢指针是链表题的万能技巧**：找中点（快指针走 2 步）、判环（快慢相遇）、倒数第 k（先走 k 步）、删除倒数第 N（用 dummy 让 slow 落在被删前驱）
- 链表题写 `dummy` 节点可以统一头节点的处理：如 LeetCode 19 删除倒数第 N，dummy 让 `slow` 落在被删节点的前驱

## 变种：删除倒数第 N 个节点（LeetCode 19）

```
关键：dummy.next = head，fast 从 dummy 开始，先走 n+1 步，再一起走
slow 落在被删节点的前驱，slow.next = slow.next.next
```
