# 24. 反转链表

## 题目描述

输入一个链表的头节点，反转该链表并输出反转后链表的头节点。

```
输入:  1 → 2 → 3 → 4 → 5
输出: 5 → 4 → 3 → 2 → 1
```

## 核心思路

**迭代法（头插法）**：遍历链表，逐个改变 next 指针方向，需要三个指针：`prev`、`curr`、`next`。

## Java 最优解（迭代）

```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;  // 暂存后继
        curr.next = prev;           // 反转指针
        prev = curr;                // prev 前进
        curr = next;                // curr 前进
    }
    return prev;  // prev 是新的头节点
}
```

## Java 递归解法（进阶）

```java
public ListNode reverseList(ListNode head) {
    if (head == null || head.next == null) return head;  // base case
    ListNode newHead = reverseList(head.next);  // 递归反转后续
    head.next.next = head;  // 让后继指向自己
    head.next = null;      // 断开原指向，防止环
    return newHead;
}
```

## 复杂度

| 方法 | 时间 | 空间 |
|:---|:---:|:---:|
| 迭代 | O(n) | O(1) |
| 递归 | O(n) | O(n)（递归栈） |

## 易错点

1. **断链**：`curr.next = prev` 前必须先暂存 `next`，否则链表断裂
2. **尾节点处理**：迭代法最终 `curr = null`，返回 `prev` 而非 `curr`
3. **递归环**：递归法必须 `head.next = null`，否则形成环
4. **空链表**：迭代法天然处理（while 不进，返回 prev=null）；递归法需 base case

## 关键点

- 迭代法是面试首选：O(1) 空间，无栈溢出风险
- 三指针模板要背熟：`prev ← curr.next`，逐个翻转
- 递归法优雅但栈深度可能溢出（链表很长时）
