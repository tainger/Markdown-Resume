# 25. 合并两个排序的链表

## 题目描述

输入两个递增排序的链表，合并这两个链表并使新链表中的节点仍然是递增排序的。

```
输入: 1→2→4, 1→3→4
输出: 1→1→2→3→4→4
```

## 核心思路

**双指针归并** + **哨兵节点**：用一个虚拟头节点简化边界处理，逐个比较两链表头节点，较小者接入新链表。

## Java 最优解（迭代 + 哨兵）

```java
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);  // 哨兵节点
    ListNode curr = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {
            curr.next = l1;
            l1 = l1.next;
        } else {
            curr.next = l2;
            l2 = l2.next;
        }
        curr = curr.next;
    }
    curr.next = (l1 != null) ? l1 : l2;  // 接入剩余部分
    return dummy.next;
}
```

## Java 递归解法（进阶）

```java
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    if (l1 == null) return l2;
    if (l2 == null) return l1;
    if (l1.val <= l2.val) {
        l1.next = mergeTwoLists(l1.next, l2);
        return l1;
    } else {
        l2.next = mergeTwoLists(l1, l2.next);
        return l2;
    }
}
```

## 复杂度

| 方法 | 时间 | 空间 |
|:---|:---:|:---:|
| 迭代 + 哨兵 | O(m+n) | O(1) |
| 递归 | O(m+n) | O(m+n)（递归栈） |

## 易错点

1. **忘记哨兵**：不用 dummy 节点需单独处理首个节点，容易出错
2. **剩余部分**：循环结束后必须接入未遍历完的链表（l1 或 l2）
3. **原地修改 vs 新建**：上面代码是原地修改 l1/l2 的指针，若要求新建链表需额外处理
4. **相等值**：`<=` 保证稳定排序，小于则不稳定

## 关键点

- 哨兵节点（dummy）是链表题常用技巧，简化空链表/首节点处理
- 双指针归并是归并排序的核心，必须熟练
- 迭代法 O(1) 空间优于递归法
