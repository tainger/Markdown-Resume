# 26. 树的子结构

## 题目描述

输入两棵二叉树 A 和 B，判断 B 是否是 A 的子结构（**空树不是任何树的子结构**）。

```
     A                B
     1                1
    / \              /
   2   3            2
  / \
 4   5

B 是 A 的子结构（节点 1 + 节点 2）
```

## 核心思路

**双递归**：
1. **外层 `isSubStructure`**：A 的每个节点都可能是 B 的根，递归判断 `A 是否包含 B`
2. **内层 `contains`**：判断「从 A 的某节点开始能否匹配 B 的整棵树」

```
isSubStructure(A, B) = contains(A, B) || isSubStructure(A.left, B) || isSubStructure(A.right, B)

contains(A, B):
  B == null       → true     (B 全部匹配完)
  A == null       → false    (A 走完但 B 没完)
  A.val != B.val  → false
  否则            → 递归左右子树
```

## Java 最优解

```java
public boolean isSubStructure(TreeNode A, TreeNode B) {
    if (A == null || B == null) return false;       // 空树不是子结构
    return contains(A, B)
        || isSubStructure(A.left, B)
        || isSubStructure(A.right, B);
}

// 判断「从 A 开始能否完全包含 B」
private boolean contains(TreeNode A, TreeNode B) {
    if (B == null) return true;       // B 走完就算匹配
    if (A == null) return false;      // A 走完但 B 没走完
    if (A.val != B.val) return false;
    return contains(A.left,  B.left)
        && contains(A.right, B.right);
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(m × n) | 最坏 A 的每个节点都要尝试匹配 B |
| 空间 | O(max(m, n)) | 递归栈深度 |

## 易错点

1. **空树判定**：`A == null || B == null` 返回 false；题目明说「空树不是任何树的子结构」
2. **终止条件 `B == null → true`**：B 完全匹配完是成功的标志
3. **`A == null → false` 在 B 之后**：顺序很重要，必须先判 `B == null` 再判 `A == null`
4. **B 可以比 A 小**：`contains` 中 B 走完即匹配成功，不需要 A 也走完
5. **不是子树**：剑指 Offer 26 是「子结构」不是「子树」（子树要求从某节点开始往下完全相同；子结构允许 B 在 A 中提前结束）

## 关键点

- **子结构 vs 子树**：子结构 = A 中包含 B 这段就行（B 的每个节点都能在 A 对应位置找到）；子树 = A 某节点开始往后整段 == B（叶子也对齐）
- **双递归模板**：外层遍历 A 的每个节点作为「起点」，内层判断「起点开始能否匹配 B」
- 对比 LeetCode 572「Subtree of Another Tree」：是「子树」不是「子结构」，需要叶节点完全对齐；可以**序列化 + KMP** 把树问题转字符串匹配
- **序列化技巧**：把两棵树先序序列化（带 null 标记），然后判断 B 序列是否是 A 序列的子串，O(m + n)

## 变种：子树判定（LeetCode 572）

```
序列化 + KMP：
  先序序列化时 null 用 # 占位（保证结构唯一）
  B 序列是 A 序列子串 → B 是 A 子树
  O(m + n)
```
