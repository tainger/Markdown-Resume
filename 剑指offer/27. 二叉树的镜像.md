# 27. 二叉树的镜像

## 题目描述

完成一个函数，输入一棵二叉树，输出它的镜像（左右子树交换）。

```
输入：
     4
    / \
   2   7
  / \ / \
 1  3 6  9

输出：
     4
    / \
   7   2
  / \ / \
 9  6 3  1
```

## 核心思路

**递归交换左右子树**：每个节点都把左右子树交换即可。

```
mirror(node):
  if node == null: return
  swap(node.left, node.right)
  mirror(node.left)
  mirror(node.right)
```

## Java 最优解

```java
// 解法 1：递归（最简）
public TreeNode mirrorTree(TreeNode root) {
    if (root == null) return null;
    TreeNode tmp = root.left;
    root.left  = mirrorTree(root.right);
    root.right = mirrorTree(tmp);
    return root;
}
```

```java
// 解法 2：BFS 层序 + 每个节点交换
public TreeNode mirrorTree(TreeNode root) {
    if (root == null) return null;
    Queue<TreeNode> q = new ArrayDeque<>();
    q.offer(root);
    while (!q.isEmpty()) {
        TreeNode n = q.poll();
        // 交换左右子
        TreeNode tmp = n.left;
        n.left  = n.right;
        n.right = tmp;
        // 入队继续
        if (n.left  != null) q.offer(n.left);
        if (n.right != null) q.offer(n.right);
    }
    return root;
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(h) | 递归栈深度，h 是树高；BFS 为 O(w) 最大宽度 |

## 易错点

1. **交换顺序**：`root.left = mirrorTree(root.right); root.right = mirrorTree(tmp)`；要用 tmp 暂存，否则先赋值会丢
2. **返回 root**：递归函数要返回当前节点，否则上层拿不到
3. **空树**：`root == null` 直接返回 null，不写会 NPE
4. **递归 vs BFS**：递归代码最短，但极端链表形树会栈溢出；BFS 更稳但代码更长

## 关键点

- **递归三步**：①递终止条件（null 返回） ②处理当前层（交换左右） ③递归下一层（左右子）
- **本质**：对每个节点做一次「左右孩子交换」操作，遍历方式不限（前序 / 后序 / 层序都行）
- 对比 LeetCode 226「Invert Binary Tree」：完全等价
- **进阶**：判断镜像对称（剑指 Offer 28），是判断「这棵树是否关于根对称」

## 变种：对称二叉树（剑指 Offer 28）

```
判断 root 是否关于根对称
左右两子树互为镜像
check(left, right):
  left==null && right==null → true
  left==null || right==null → false
  left.val != right.val → false
  return check(left.left, right.right) && check(left.right, right.left)
```
