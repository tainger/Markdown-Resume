# 28. 对称的二叉树

## 题目描述

判断一棵二叉树是否**关于根对称**（左右子树互为镜像）。

```
     1
    / \
   2   2
  / \ / \
 3  4 4  3   → true
```

## 核心思路

**双指针递归**：定义 `check(left, right)` 判断两棵子树是否互为镜像。镜像 = 左左对右右、左右对右左。

```
check(left, right):
  都空          → true
  一空          → false
  值不等       → false
  否则           → check(left.left, right.right) && check(left.right, right.left)

主函数：
  root == null → true
  return check(root.left, root.right)
```

## Java 最优解

```java
public boolean isSymmetric(TreeNode root) {
    if (root == null) return true;
    return check(root.left, root.right);
}

private boolean check(TreeNode left, TreeNode right) {
    if (left == null && right == null) return true;
    if (left == null || right == null) return false;
    if (left.val != right.val) return false;
    return check(left.left,  right.right)
        && check(left.right, right.left);
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n) | 遍历每个节点一次 |
| 空间 | O(h) | 递归栈深度 |

## 易错点

1. **空树判定**：`root == null` 返回 true（空树是对称的）
2. **null 比较顺序**：必须先判「都空」再判「一空」，否则 NPE
3. **镜像交叉递归**：是 `check(left.left, right.right)`，不是 `check(left.left, right.left)`（后者会判断两棵同结构的树）
4. **值比较要严格**：`!=` 直接 false，不能 `==` 直接 true（要配合 null 判定）

## 关键点

- **对称 = 镜像**：左子树关于根的镜像等于右子树
- **递归交叉匹配**：左左对右右、左右对右左
- 对比 LeetCode 100「Same Tree」：是 `check(p.left, q.left) && check(p.right, q.right)` 同向递归
- 对比剑指 Offer 27「二叉树的镜像」：27 是「交换」操作，28 是「判断」对称

## 变种：迭代版（用队列）

```
队列每次取两个节点对比
- 都空 continue
- 一空或值不等 return false
- 入队 (left.left, right.right), (left.right, right.left)
本质上是把递归用队列展开
```
