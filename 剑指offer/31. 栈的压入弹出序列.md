# 31. 栈的压入、弹出序列

## 题目描述

输入两个整数序列 `pushed` 和 `popped`，判断 `popped` 是否是 `pushed` 的合法弹出序列。

```
pushed = [1,2,3,4,5], popped = [4,5,3,2,1]  → true
pushed = [1,2,3,4,5], popped = [4,3,5,1,2]  → false
```

## 核心思路

**模拟栈**：按 `pushed` 顺序压栈，每次压入后判断栈顶是否等于 `popped` 当前要弹的元素，是就弹、继续判断下一个 `popped`，不是就继续压。最后栈空即合法。

```
pushed = [1,2,3,4,5], popped = [4,5,3,2,1]
pushed idx=0 → 栈[1]
pushed idx=1 → 栈[1,2]
pushed idx=2 → 栈[1,2,3]
pushed idx=3 → 栈[1,2,3,4]，栈顶=4=popped[0]，弹 → 栈[1,2,3]，popped idx=1
栈顶=3 ≠ 5，继续压
pushed idx=4 → 栈[1,2,3,5]，栈顶=5=popped[1]，弹 → 栈[1,2,3]，popped idx=2
栈顶=3=popped[2]，弹 → 栈[1,2]，popped idx=3
栈顶=2=popped[3]，弹 → 栈[1]，popped idx=4
栈顶=1=popped[4]，弹 → 栈[]，popped idx=5
栈空，true
```

## Java 最优解

```java
public boolean validateStackSequences(int[] pushed, int[] popped) {
    Deque<Integer> stack = new ArrayDeque<>();
    int popIdx = 0;
    for (int x : pushed) {
        stack.push(x);
        // 栈顶 == popped 当前 → 弹，继续匹配
        while (!stack.isEmpty() && stack.peek() == popped[popIdx]) {
            stack.pop();
            popIdx++;
        }
    }
    return stack.isEmpty();
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n) | 每个元素入栈出栈各一次 |
| 空间 | O(n) | 辅助栈 |

## 易错点

1. **while 不是 if**：栈顶弹之后可能新栈顶还能继续匹配
2. **栈顶 == popped[popIdx] 的判等**：注意 `==` 对 Integer 可能踩坑（装箱范围 -128~127 之外），用 `equals` 更稳；int 没问题
3. **不用真的全栈**：栈最大深度可能 = n，但本题元素值就是下标，可用一个数组模拟，节省空间
4. **「最后栈空」是判定标准**：弹出过程中匹配失败不立即 return false，因为后续可能压入新值匹配；要靠最后栈是否空

## 关键点

- **模拟栈是万能模板**：所有「给定 push/pop 序列判断合法」类题目都用模拟栈
- **弹出时机的连续性**：栈顶一旦匹配，连续弹到不匹配为止
- 对比 LeetCode 946「Validate Stack Sequences」：完全等价
- **变种题目**：判断某个序列是否是另一个序列的栈输出 → 这就是题目本身
- **进阶**：给定 push 序列，求所有合法 pop 序列数 → 卡特兰数 C_n

## 变种：给定 push 序列，求所有合法 pop 序列数

```
n 个不同元素入栈，合法出栈序列数 = 卡特兰数 C_n
公式：C_n = (1/(n+1)) * C(2n, n)
递推：C_0=1, C_{n+1} = sum(C_i * C_{n-i}) for i in [0, n]
```
