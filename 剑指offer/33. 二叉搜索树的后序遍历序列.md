# 33. 二叉搜索树的后序遍历序列

## 题目描述

输入一个整数数组，判断它是否是某棵**二叉搜索树（BST）的后序遍历**序列。

```
[1,3,2,5,7,6,4] → true
对应 BST：
       4
      / \
     2   6
    / \ / \
   1  3 5  7
后序：1,3,2 | 5,7,6 | 4
```

## 核心思路

**单调栈 + 倒序遍历**：后序遍历反过来是「根 → 右 → 左」，对 BST 来说是降序访问（根 > 右 > 左是错的，但 BST 的「根 → 右 → 左」递归遍历访问到的值是单调递减的）。用栈模拟，遇到「值跳变增大」时切换根节点，判断「右子树阶段才允许这种跳变」。

更朴素的方式：**分治递归**：
- 最后一个数是根
- 从前往后找到第一个 > 根 的位置 → 分成左子树（< 根）和右子树（> 根）
- 右子树都必须 > 根
- 递归判断左右子树

```
[1,3,2,5,7,6,4]  根=4
左 [< 4]: [1,3,2]   右 [> 4]: [5,7,6]
  [1,3,2] 根=2 左 [1] 右 [3]
  [5,7,6] 根=6 左 [5] 右 [7]
全部分裂成功 → true
```

## Java 最优解

```java
// 解法 1：分治递归
public boolean verifyPostorder(int[] postorder) {
    return verify(postorder, 0, postorder.length - 1);
}

private boolean verify(int[] post, int lo, int hi) {
    if (lo >= hi) return true;          // 单节点或空
    int root = post[hi];
    // 找右子树起点（第一个 > root）
    int p = lo;
    while (post[p] < root) p++;
    // 右子树必须全部 > root
    for (int i = p; i < hi; i++) {
        if (post[i] < root) return false;
    }
    // 递归左右
    return verify(post, lo, p - 1) && verify(post, p, hi - 1);
}
```

```java
// 解法 2：单调栈 O(n)（高级）
public boolean verifyPostorder(int[] post) {
    Deque<Integer> stack = new ArrayDeque<>();
    int root = Integer.MAX_VALUE;
    // 倒序遍历：根 → 右 → 左
    for (int i = post.length - 1; i >= 0; i--) {
        if (post[i] > root) return false;   // 当前节点不能大于当前根
        while (!stack.isEmpty() && stack.peek() > post[i]) {
            root = stack.pop();             // 切换根
        }
        stack.push(post[i]);
    }
    return true;
}
```

## 复杂度

| 解法 | 时间（平均/最坏） | 空间 |
|:---|:---:|:---|
| 分治 | O(n log n) / O(n²) | O(n) |
| 单调栈 | O(n) | O(n) |

## 易错点

1. **找到右子树起点后，右子树必须全部 > root**：分治解法必须做这个检查
2. **单调栈解法的判断方向**：`if (post[i] > root) return false`，是 `> root`，不是 `< root`
3. **单调栈切换根的时机**：`while (stack.peek() > post[i])` 时弹出，最后弹的值是当前节点的根
4. **空数组/单元素**：分治解法 `lo >= hi` 返回 true；单调栈解法空数组默认 true

## 关键点

- **BST 后序性质**：最后一个是根，前段「左子树都 < 根、右子树都 > 根」
- **分治思路**：每次根据根把数组分左右，验证「左小右大」递归
- **单调栈思路**：把后序反过来变成「根右左」的递归遍历，BST 这条路径上「右子树阶段值递减、左子树阶段切根」
- 对比 LeetCode 255「Verify Preorder Sequence in BST」：前序判定，思路类似（单调栈）

## 变种：BST 的前序序列判定（LeetCode 255）

```
前序「根左右」，BST 前序是「根 → 小 → 大」
单调栈：正序遍历，遇到「切到大根」时切换
```
