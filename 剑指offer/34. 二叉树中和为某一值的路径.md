# 34. 二叉树中和为某一值的路径

## 题目描述

输入一棵二叉树和一个整数，打印二叉树中**节点值之和等于该值的所有路径**（从根节点到叶节点的路径）。

```
       5
      / \
     4   8
    /   / \
   11  13  4
  / \     / \
 7  2    5  1
target = 22
输出：[[5,4,11,2], [5,8,4,5]]
```

## 核心思路

**回溯 DFS**：维护一条「当前路径」和「剩余目标和」。访问节点时把它加入路径并减 target，递归左右子树，回溯时把它从路径移除。

```
dfs(node, target, path, res):
  if node == null: return
  path.add(node.val)
  target -= node.val
  // 叶子节点判定：左右都 null
  if node.left == null && node.right == null && target == 0:
    res.add(深拷贝 path)
  dfs(node.left,  target, path, res)
  dfs(node.right, target, path, res)
  path.removeLast()   // 回溯
```

## Java 最优解

```java
public List<List<Integer>> pathSum(TreeNode root, int target) {
    List<List<Integer>> res = new ArrayList<>();
    LinkedList<Integer> path = new LinkedList<>();
    dfs(root, target, path, res);
    return res;
}

private void dfs(TreeNode node, int target, LinkedList<Integer> path, List<List<Integer>> res) {
    if (node == null) return;
    path.addLast(node.val);
    target -= node.val;
    // 叶子 + target 归零
    if (node.left == null && node.right == null && target == 0) {
        res.add(new ArrayList<>(path));      // 深拷贝
    }
    dfs(node.left,  target, path, res);
    dfs(node.right, target, path, res);
    path.removeLast();   // 回溯
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n²) 最坏 | 每个叶节点路径都要深拷贝一份，叶数 O(n)、路径长 O(n) |
| 空间 | O(n) | 递归栈 + path |

## 易错点

1. **深拷贝 path 加入结果**：`new ArrayList<>(path)`，不能直接 `res.add(path)`（path 是引用，会被后续修改）
2. **回溯必须做**：`path.removeLast()`，否则下次递归带着上次的残留
3. **叶子判定**：必须 `left == null && right == null`，不是「node 有 null 子树」（半叶子节点不算）
4. **target 在递归参数传递**：直接减后传给下一层，回溯不需要恢复 target（参数本身是值传递，每次递归独立）
5. **target 为 0 但不是叶子**：不能加入结果，因为路径要求「到叶子」

## 关键点

- **回溯模板**：访问时加入路径 → 递归 → 回溯时移除。适用于所有「找所有路径/组合」类题目
- **深拷贝时机的关键**：加入结果的瞬间拷贝，不能引用原 path
- 对比 LeetCode 113「Path Sum II」：完全等价
- 对比 LeetCode 112「Path Sum」：只要判断是否存在，不需返回路径，dfs 返回 boolean 即可
- **进阶**：路径可以不限于「根到叶」，而是「父到子」（LeetCode 437）：双重递归 + 前缀和

## 变种：任意父到子路径和 = target（LeetCode 437）

```
双重递归：以每个节点为起点做 dfs 找路径
优化：前缀和 + 哈希 + 回溯
  - 路径和 = prefix[j] - prefix[i]
  - 维护 map: prefix 出现次数
  - 递归时找 map[prefix - target] 的次数
  - 回溯时 map[prefix]--
```
