# 39. 数组中出现次数超过一半的数字

## 题目描述

数组中有一个数字出现次数**超过数组长度的一半**（> n/2），找出这个数字（即众数）。

```
输入：[1, 2, 3, 2, 2, 2, 5, 4, 2]
输出：2
```

## 核心思路

**摩尔投票法（Boyer-Moore）**：众数占过半，把众数看成 +1、非众数看成 -1，总和必为正。维护 `candidate` 和 `count`：`count` 归零就换 `candidate`，最终 `candidate` 必是众数。

```
[1, 2, 3, 2, 2, 2, 5, 4, 2]
 1  0 -1  1  2  3  2  1  2   ← count 变化
c=1 c=2 c=3 c=2 c=2 c=2 c=5 c=4 c=2
                              最终候选 = 2
```

更直白的图：
```
candidate = 1, count = 1
candidate = 2, count = 1（先归零再换）
candidate = 3, count = 1
candidate = 2, count = 1
candidate = 2, count = 2
candidate = 2, count = 3
candidate = 2, count = 2
candidate = 2, count = 1
candidate = 2, count = 2   ← 最终答案
```

## Java 最优解

```java
public int majorityElement(int[] nums) {
    int candidate = nums[0], count = 1;
    for (int i = 1; i < nums.length; i++) {
        if (count == 0) candidate = nums[i];   // 票数归零，换候选
        count += (nums[i] == candidate) ? 1 : -1;
    }
    return candidate;
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n) | 一趟遍历 |
| 空间 | O(1) | 两个变量 |

## 易错点

1. **题目是否保证众数存在**：
   - 剑指 Offer 题目**保证**，可直接返回
   - 若不保证（如 LeetCode 169 在保证下，但 229 求所有众数不保证），需**二次遍历验证** candidate 是否真 > n/2
2. **count 归零的时机**：先判断 `count == 0` 换候选，再加 1 或减 1，顺序不能反
3. **初始值**：`candidate = nums[0], count = 1`，不要写成 `count = 0`（会少算第一个元素）
4. **不是真的众数定义**：「超过一半」严格 > n/2，不是 ≥ n/2；奇偶长度都有解

## 关键点

- **核心思想**：众数 +1、非众数 -1，总和必为正
- **摩尔投票的本质是「抵消」**：把一段「候选 + 其他」配对抵消，剩下的一定是众数
- 面试官常问能不能用这方法找「出现次数 > n/3 的元素」（LeetCode 229）：可以，**最多 2 个候选**，分别维护两个 count
- 对比「最小堆 / 排序 / 哈希」三种朴素解法：哈希 O(n)/O(n)，排序 O(n log n)/O(1)，摩尔投票最优

## 变种：求出现次数 > n/3 的所有元素（LeetCode 229）

```
两个 candidate + 两个 count，三次遍历：
1. 投票出至多两个候选
2. 验证两个候选的真实出现次数是否 > n/3
```
