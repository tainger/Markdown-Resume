# 40. 最小的 k 个数

## 题目描述

输入整数数组 `arr` 和整数 `k`，返回数组中最小的 `k` 个数（任意顺序）。

```
输入：arr = [3,2,1,4,5,6,7,8], k = 4
输出：[1,2,3,4]
```

## 核心思路

**两种解法都要会**：

| 解法 | 时间 | 空间 | 适用 |
|:---|:---:|:---:|:---|
| 快排切分（Quick Select） | O(n) 均摊 | O(log n) 递归栈 | 原地、要求小空间 |
| 大顶堆（Top-K 模板） | O(n log k) | O(k) | 流式数据、k << n、不能修改原数组 |

### 解法 1：快排切分（推荐）

利用快排的 partition：partition 一次会把 pivot 放到它的最终位置 `m`：
- `m == k-1`：pivot 及左边就是最小的 k 个
- `m > k-1`：在左半部分继续找
- `m < k-1`：在右半部分继续找

```
[3,2,1,4,5,6,7,8], k=4
partition 后假设 pivot=4 到位 index=3：
    [3,2,1,4,5,6,7,8]
            ↑ index=3 = k-1
    左边 [3,2,1] + 4 = 最小 4 个
```

### 解法 2：大顶堆（Top-K 通用模板）

维护大小为 `k` 的**大顶堆**：新元素比堆顶（堆中最大）小就替换。最终堆里就是最小的 k 个。

```
堆顶永远是「当前 k 个里最大的」
新来 x：x < 堆顶 → 弹堆顶、push x
        x ≥ 堆顶 → 跳过
```

## Java 最优解

```java
// 解法 1：快排切分
public int[] getLeastNumbers(int[] arr, int k) {
    if (k == 0) return new int[0];
    quickSelect(arr, 0, arr.length - 1, k - 1);   // 找第 k 小的下标 k-1
    return Arrays.copyOf(arr, k);   // 前 k 个就是答案
}
private void quickSelect(int[] a, int lo, int hi, int k) {
    int m = partition(a, lo, hi);
    if (m == k) return;              // pivot 已在 k 位置
    if (m > k) quickSelect(a, lo, m - 1, k);
    else      quickSelect(a, m + 1, hi, k);
}
// Lomuto partition
private int partition(int[] a, int lo, int hi) {
    int pivot = a[hi], i = lo;
    for (int j = lo; j < hi; j++) {
        if (a[j] <= pivot) swap(a, i++, j);
    }
    swap(a, i, hi);
    return i;
}
```

```java
// 解法 2：大顶堆（Top-K 模板，Java PriorityQueue 是小顶堆，要传反转 Comparator）
public int[] getLeastNumbers(int[] arr, int k) {
    if (k == 0) return new int[0];
    // 大顶堆： (a,b) -> b - a
    PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
    for (int x : arr) {
        maxHeap.offer(x);
        if (maxHeap.size() > k) maxHeap.poll();   // 超过 k 就弹最大的
    }
    int[] res = new int[k];
    for (int i = 0; i < k; i++) res[i] = maxHeap.poll();
    return res;
}
```

## 复杂度

| 解法 | 时间（平均/最坏） | 空间 |
|:---|:---:|:---|
| 快排切分 | O(n) / O(n²) | O(log n) |
| 大顶堆 | O(n log k) | O(k) |

> 快排切分最坏 O(n²) 可用随机 pivot 优化到期望 O(n)；数据量大、k 小、流式场景用堆。

## 易错点

1. **k = 0 边界**：直接返回空数组，否则 `Arrays.copyOf(arr, 0)` 是合法的但堆解法会进负数判断
2. **Java PriorityQueue 默认小顶堆**：Top-K 大要用小顶堆（默认），Top-K 小要用大顶堆（`b - a` 或 `Comparator.reverseOrder()`），方向别反
3. **快排切分的 pivot 选择**：用最后一个 `a[hi]` 最坏会退化（已排序数组），生产代码可随机化
4. **partition 用 `<=` 还是 `<`**：Lomuto 标准是 `<=`，否则重复元素会出 bug

## 关键点

- **Top-K 模板**：求最小的 k 个 → 大顶堆；求最大的 k 个 → 小顶堆。**堆顶是淘汰的标尺**
- **快排切分 vs 堆**：堆是 Top-K 通用模板（流式、海量数据、不能修改原数组），快排切分更快但不能流式
- **海量数据求 Top-K**：分治 + 多路归并——每台机器用堆求本地 Top-K，再归并所有机器的 k 个结果
- 对比 LeetCode 215「第 K 大」：本题是「最小 k 个」，215 是「第 k 大」（即第 n-k+1 小），算法框架相同

