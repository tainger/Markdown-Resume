# 41. 数据流中的中位数

## 题目描述

设计一个数据结构，支持两个操作：
- `addNum(num)`：从数据流中接受一个整数
- `findMedian()`：返回当前所有数据的中位数

```
add 1 → add 2 → add 3 → findMedian → 2
add 4 → findMedian → 2.5
```

## 核心思路

**双堆**：
- **大顶堆 `left`**：存较小的一半，堆顶是这半的最大（中位数左候选）
- **小顶堆 `right`**：存较大的一半，堆顶是这半的最小（中位数右候选）
- **平衡条件**：`left.size() == right.size()` 或 `left.size() == right.size() + 1`
- 中位数：奇数取 left 堆顶，偶数取两堆顶平均

```
        left            right
       大顶堆          小顶堆
      [3,2,1]        [6,7,8]    堆顶：left=3, right=6
      较小一半        较大一半
中位数 = (3+6)/2 = 4.5

新增 4：
  4 应该进 right（left 堆顶 3 < 4）
  但要保证 left.size >= right.size
  → 先把 4 入 left，再把 left 堆顶弹出给 right
  → left=[3,2,1] right=[4,6,7,8]
```

## Java 最优解

```java
class MedianFinder {
    private PriorityQueue<Integer> left  = new PriorityQueue<>(Comparator.reverseOrder());  // 大顶堆
    private PriorityQueue<Integer> right = new PriorityQueue<>();                            // 小顶堆

    public void addNum(int num) {
        // 先入左堆，再把左堆最大推到右堆（保证右堆最小 ≥ 左堆最大）
        left.offer(num);
        right.offer(left.poll());
        // 平衡：左堆允许比右堆多 1
        if (left.size() < right.size()) {
            left.offer(right.poll());
        }
    }

    public double findMedian() {
        if (left.size() > right.size())  return left.peek();
        return (left.peek() + right.peek()) / 2.0;
    }
}
```

## 复杂度

| 操作 | 时间 | 空间 |
|:---|:---:|:---|
| addNum | O(log n) | O(n) |
| findMedian | O(1) | — |

## 易错点

1. **平衡方向**：题目要求奇数时返回中位数，约定左堆多 1 个；即 `left.size() == right.size() + 1` 或 `left.size() == right.size()`。代码 `if (left.size() < right.size())` 就是补这个差
2. **堆类型不要反**：左是大顶堆（要取最大），右是小顶堆（要取最小）。Java `PriorityQueue` 默认小顶，左堆要 `Comparator.reverseOrder()`
3. **addNum 三步法的顺序**：① 入左 → ② 左堆顶推到右堆 → ③ 若左堆比右堆少则右堆顶推回左堆
4. **偶数返回 0.5 倍**：用 `/ 2.0` 不是 `/ 2`（整数除法截断）

## 关键点

- **核心思想**：把数据动态分成「较小一半 + 较大一半」两个堆，堆顶即中位数候选
- **三步法保持平衡**：每次 add 后保证两个堆大小差 ≤ 1，且左堆元素 ≤ 右堆元素
- 对比 LeetCode 295「Find Median from Data Stream」：完全等价
- **进阶**：海量数据求中位数 → 分桶（按数值范围分桶，单桶计数找中位数桶）
- 对比 Top-K 题（剑指 40）：Top-K 是用**一个堆**，中位数用**两个堆**

## 变种：滑动窗口中位数（LeetCode 480）
