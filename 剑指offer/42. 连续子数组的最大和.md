# 42. 连续子数组的最大和

## 题目描述

输入一个整型数组，数组中的一个或连续多个整数组成一个子数组。求所有子数组的和的最大值。

```
输入: [-2,1,-3,4,-1,2,1,-5,4]
输出: 6
解释: 连续子数组 [4,-1,2,1] 的和最大，为 6
```

## 核心思路

**Kadane 算法（动态规划）**：维护两个变量——`curr`（以当前位置结尾的最大子数组和）和 `max`（全局最大）。

状态转移：`curr = max(nums[i], curr + nums[i])`
- 要么从当前位置重新开始（nums[i] 更大）
- 要么延续前面的子数组（curr + nums[i] 更大）

## Java 最优解（Kadane 算法）

```java
public int maxSubArray(int[] nums) {
    int curr = nums[0];  // 以当前位置结尾的最大和
    int max = nums[0];   // 全局最大和
    for (int i = 1; i < nums.length; i++) {
        curr = Math.max(nums[i], curr + nums[i]);  // 状态转移
        max = Math.max(max, curr);                  // 更新全局最大
    }
    return max;
}
```

## 等价 DP 写法（便于理解）

```java
public int maxSubArray(int[] nums) {
    int[] dp = new int[nums.length];
    dp[0] = nums[0];
    int max = nums[0];
    for (int i = 1; i < nums.length; i++) {
        dp[i] = Math.max(nums[i], dp[i-1] + nums[i]);
        max = Math.max(max, dp[i]);
    }
    return max;
}
```

## 复杂度

| 方法 | 时间 | 空间 |
|:---|:---:|:---:|
| Kadane（优化） | O(n) | O(1) |
| 标准 DP | O(n) | O(n) |

## 易错点

1. **初始化**：`curr` 和 `max` 必须初始化为 `nums[0]`，不能初始化为 0（数组全为负数时出错）
2. **全负数数组**：如 `[-3,-1,-2]`，答案是 -1（单个最大元素），不是 0
3. **状态转移方向**：`curr = max(nums[i], curr + nums[i])` 表示「重新开始 vs 延续」
4. **不要漏更新 max**：每次 curr 变化后都要检查是否更新全局 max

## 关键点

- Kadane 算法是 O(n) O(1) 的最优解，必须背熟
- 状态转移本质：当前最大子数组要么从当前元素重新开始，要么延续前面
- 贪心视角：当 curr < 0 时，继续延续只会拖累后面，不如重新开始
- 面试常追问：如果要输出子数组本身怎么办？记录 start/end 下标即可

## 贪心视角理解

```
curr = 累计和，但如果累计和 < 0，说明前面的部分是负担，
从当前位置重新开始比带上前面的包袱更好。
```
