# 51. 数组中的逆序对

## 题目描述

在数组中的两个数字如果前面一个大于后面的数字，则这两个数字组成一个**逆序对**。统计总数。

```
输入：[7,5,6,4]
输出：5   （7,5）（7,6）（7,4）（5,4）（6,4）
```

## 核心思路

**归并排序 + 跨段统计**：归并时左半和右半各自已排好序，当 `left[i] > right[j]` 时，`left[i..mid]` 这一段都 > `right[j]`（左半有序），逆序对 += `mid - i + 1`。

```
合并 [5,7] 和 [4,6]
i=0 j=0:  5 > 4  → 逆序对 += 2 - 0 + 1 = 2  即 (5,4)(7,4)，取 right[0]=4
i=0 j=1:  5 < 6  → 取 left[0]=5
i=1 j=1:  7 > 6  → 逆序对 += 2 - 1 + 1 = 2  即 (7,6)，但 (6,4) 已在前一步算了
              累计：left[i..mid] 中所有 ≥ right[j] 的元素和 right[j] 形成逆序对
```

### 为什么对：在「合并前」每段内部已有序，逆序只可能跨段出现。`left[i] > right[j]` 时，`i` 之后的所有左半元素都大于 `right[j]`（左半递增）。

## Java 最优解

```java
private int count = 0;

public int reversePairs(int[] nums) {
    mergeSort(nums, 0, nums.length - 1);
    return count;
}

private void mergeSort(int[] a, int lo, int hi) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(a, lo, mid);
    mergeSort(a, mid + 1, hi);
    merge(a, lo, mid, hi);
}

private void merge(int[] a, int lo, int mid, int hi) {
    int[] tmp = new int[hi - lo + 1];
    int i = lo, j = mid + 1, k = 0;
    while (i <= mid && j <= hi) {
        if (a[i] > a[j]) {
            // a[i..mid] 全 > a[j]
            count += mid - i + 1;
            tmp[k++] = a[j++];
        } else {
            tmp[k++] = a[i++];
        }
    }
    while (i <= mid)   tmp[k++] = a[i++];
    while (j <= hi)    tmp[k++] = a[j++];
    System.arraycopy(tmp, 0, a, lo, tmp.length);
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n log n) | 归并排序复杂度 |
| 空间 | O(n) | 临时数组和递归栈 |

## 易错点

1. **逆序对计数公式**：`count += mid - i + 1`，不是 `1`。因为左半有序，`left[i] > right[j]` 时 `i..mid` 都大于 `right[j]`
2. **`>` 还是 `>=`**：用 `>`。`>=` 在归并排序会让相同元素产生「伪逆序对」（看题目是否要求严格大于）
3. **临时数组每次 merge 新建 vs 全局复用**：每次新建简洁但有点慢；优化可用一个全局 `tmp` 数组，避免反复分配
4. **暴力 O(n²) 会超时**：n ≤ 50000，必须 O(n log n)

## 关键点

- **归并排序的本质**：分治 → 局部有序 → 合并阶段跨段统计
- **跨段统计的模板**：归并时左右两半各自有序，跨段统计某种「逆序/逆序对」计数
- 对比 LeetCode 315「计算右侧小于当前元素的个数」：要求返回每个元素的右侧小于其的个数，可用归并（带索引）或树状数组（离散化 + 单点更新 + 前缀查询）
- **归并 vs 树状数组 vs 线段树**：归并最适合「逆序对」类问题；树状数组适合「动态点修改 + 前缀查询」；线段树适合区间查询和区间更新
