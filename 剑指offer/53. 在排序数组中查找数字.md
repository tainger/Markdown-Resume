# 53. 在排序数组中查找数字

## 题目描述

统计一个数字在**排序数组**中出现的次数。

```
输入：nums = [5,7,7,8,8,10], target = 8
输出：2
```

## 核心思路

**二分找边界**：`bisect_left` 找 target 第一次出现的位置，`bisect_right` 找 target 最后一次出现的下一个位置，两者相减即为个数。

```
[5,7,7,8,8,8,8,8,10], target=8
        ↑ bisect_left = 3
                ↑ bisect_right = 7
个数 = 7 - 3 = 4
```

### 模板二分（左闭右开，最容易记）

```java
// bisect_left: 找第一个 ≥ target 的位置
int lo = 0, hi = n;
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (nums[mid] < target) lo = mid + 1;
    else                    hi = mid;
}
// lo 即 bisect_left
```

```
mid 判断     nums[mid] < target  →  lo = mid + 1  (mid 一定不是答案)
            nums[mid] ≥ target  →  hi = mid      (mid 可能是答案)
```

## Java 最优解

```java
public int search(int[] nums, int target) {
    // bisect_left 找第一个 ≥ target
    int left = lowerBound(nums, target);
    // bisect_left 找第一个 ≥ target+1，即 target 最后一个的下一个
    int right = lowerBound(nums, target + 1);
    return right - left;
}

// 模板：找第一个 ≥ target 的下标，找不到返回 n
private int lowerBound(int[] nums, int target) {
    int lo = 0, hi = nums.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] < target) lo = mid + 1;
        else                   hi = mid;
    }
    return lo;
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(log n) | 两次二分 |
| 空间 | O(1) | 无额外空间 |

## 易错点

1. **不用 bisect 而用线性扫描**：O(n)，面试官会追问「能不能更快」→ 二分
2. **找 left 和 right 分别写两个函数**：没必要，right 就是 `lowerBound(target + 1)`，**统一用一个函数**
3. **二分边界条件**：`lo < hi`，循环外返回 `lo`；不要用 `lo <= hi` 配 `mid-1/mid+1`（容易写错）
4. **target 不存在时**：`left == right`，返回 0，天然正确
5. **`mid` 溢出**：写 `mid = lo + (hi - lo) / 2` 而不是 `(lo + hi) / 2`，后者可能整型溢出

## 关键点

- **统一二分模板（左闭右开）**：`while lo < hi` + `hi = mid` / `lo = mid + 1`，循环外返回 `lo`
- **bisect_left 是底层工具**：右边界 = `bisect_left(target+1)`，避免写两个函数
- **Python bisect**：`bisect_left(arr, x)` 和 `bisect_right(arr, x)` 是同一函数族，差一个等号
- 对比 LeetCode 34「Find First and Last Position」：要求返回位置，本题返回个数；算法相同
- 二分边界题目家族：bisect_left/right、35 搜索插入位置、69 sqrt 的整数部分、162 寻找峰值
