# 54. 二叉搜索树的第 k 大节点

## 题目描述

给定一棵二叉搜索树（BST），找出其中第 `k` 大的节点。

```
输入：root = [5,3,6,2,4,null,null,1], k = 3
输出：4
```

## 核心思路

**反向中序遍历（右 → 根 → 左）**：BST 中序遍历是升序（左 → 根 → 右），反过来就是降序。降序遍历到的第 k 个就是第 k 大。

```
        5
       / \
      3   6
     / \
    2   4
   /
  1

中序（升序）：1,2,3,4,5,6
反向中序（降序）：6,5,4,3,2,1
第 k=3 大 → 4
```

## Java 最优解

```java
private int count = 0;
private int result = 0;

public int kthLargest(TreeNode root, int k) {
    count = k;                       // 倒数计数器
    reverseInorder(root);
    return result;
}

private void reverseInorder(TreeNode node) {
    if (node == null || count == 0) return;   // 提前终止
    reverseInorder(node.right);              // 右
    if (count == 0) return;                  // 右子树已找到，提前终止
    if (--count == 0) {                      // 根
        result = node.val;
        return;
    }
    reverseInorder(node.left);               // 左
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(k) | 找到第 k 个就停（最坏 O(n)） |
| 空间 | O(h) | 递归栈深度，h 是树高 |

## 易错点

1. **方向反了**：第 k 大要「右 → 根 → 左」；第 k 小才是「左 → 根 → 右」
2. **提前终止**：`count == 0` 时直接 return，避免继续遍历浪费时间
3. **`--count == 0` 的时机**：必须在访问根节点时减，不要在右子树回来时就减（否则会减右子树内的元素）
4. **用全局变量 vs 返回值**：递归返回第 k 大不太方便，用成员变量更清晰；要注意多组测试用例之间要重置

## 关键点

- **BST 的中序性质**：左 → 根 → 右 是升序；右 → 根 → 左 是降序
- **「第 k 大」记忆口诀**：右根左、减到 0
- 对比 LeetCode 230「二叉搜索树第 k 小」：方向相反，其他完全一致
- **进阶问法**：「动态第 k 大」（流式插入 + 查询）→ 用平衡 BST / 大小为 k 的堆，或 LeetCode 703 KthLargest

## 变种：二叉搜索树第 k 小（LeetCode 230）

```
反向即可：左 → 根 → 右，count 从 0 数到 k
```
