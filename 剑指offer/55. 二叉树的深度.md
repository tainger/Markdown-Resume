# 55. 二叉树的深度

## 题目描述

输入一棵二叉树的根节点，求该树的深度。从根节点到叶节点依次经过的节点（含根、叶）形成树的一条路径，最长路径的长度为树的深度。

```
输入：    3
        / \
       9  20
          / \
         15  7
输出：3   （3 → 20 → 7）
```

## 核心思路

**两种写法**：DFS 递归（最简）和 BFS 层序（更直观）。

```
深度 = max(左子树深度, 右子树深度) + 1
空节点深度 = 0

        3
       / \
      9  20         左子树深度=1，右子树深度=2，max=2 +1 = 3
         / \
        15  7
```

## Java 最优解

```java
// 解法 1：DFS 递归（最简）
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}
```

```java
// 解法 2：BFS 层序（每层 +1，适合同时用层序做其他事）
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    Queue<TreeNode> q = new ArrayDeque<>();
    q.offer(root);
    int depth = 0;
    while (!q.isEmpty()) {
        depth++;
        int size = q.size();           // 关键：当前层节点数
        for (int i = 0; i < size; i++) {
            TreeNode n = q.poll();
            if (n.left  != null) q.offer(n.left);
            if (n.right != null) q.offer(n.right);
        }
    }
    return depth;
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n) | 访问每个节点一次 |
| 空间 | DFS: O(h)，BFS: O(w) | h 树高，w 最大宽度 |

## 易错点

1. **空树返回 0，不是 -1 或 1**
2. **BFS 的「分批」模板**：循环内必须先 `size = q.size()` 固定当前层节点数，否则边 poll 边 offer 会无限循环
3. **DFS 的返回公式**：`1 + max(left, right)`；空节点返回 0；不能写成 `1 + max(left, right) - 1` 之类奇怪形式
4. **递归栈深度**：极端情况（链表形树）h = n，递归可能栈溢出；BFS 没此问题

## 关键点

- **DFS 写法极简**：`null → 0`，`node → 1 + max(左, 右)`，是后续遍历的天然结构
- **BFS 分批模板**：循环开始 `size = q.size()` 固定当前层，循环内 for 跑 size 次，这是所有 BFS 层序题的万能模板
- 对比 LeetCode 111「最小深度」：DFS 公式改成 `1 + min(left, right)`，但要注意**叶子节点**判定（左右子树都空才算叶子）
- **进阶：判断平衡树**（剑指 Offer 55-II）：每个节点的「左右子树深度差 ≤ 1」；自顶向下 O(n²)，自底向上 O(n)
- 对比 LeetCode 104 与本题完全等价

## 变种：判断平衡二叉树（剑指 Offer 55-II）

```
自底向上 DFS：返回 -1 表示「不平衡」，否则返回子树高度
int dfs(node) {
    if (node == null) return 0;
    int l = dfs(node.left);
    if (l == -1) return -1;
    int r = dfs(node.right);
    if (r == -1) return -1;
    return Math.abs(l - r) > 1 ? -1 : 1 + Math.max(l, r);
}
```
