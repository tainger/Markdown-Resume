# 56. 数组中数字出现的次数

## 题目描述

一个整型数组里除了两个数字只出现一次，其他数字都**出现两次**，找出这两个只出现一次的数字。要求时间 O(n)，空间 O(1)。

```
输入：[4,1,4,6]
输出：[1,6] 或 [6,1]
```

## 核心思路

**异或 + 分组**：

1. **全体异或**：相同数异或为 0，最终结果是两个目标数的异或 `xor = a ^ b`
2. **找一位不同的位**：`xor != 0`，必有某位为 1（a 和 b 在该位不同）；取 `xor` 中任意为 1 的位（如最低位 `lowbit = xor & -xor`）
3. **按该位分组**：该位为 0 的数异或到一组、该位为 1 的异或到另一组；相同数必然同组抵消，a 和 b 必不同组
4. **两组分别异或**：得到 a 和 b

```
xor = a ^ b
lowbit = xor & -xor   // 取最低位 1

for x in nums:
  if (x & lowbit) == 0:
    a ^= x
  else:
    b ^= x

例：[4,1,4,6]
xor = 4^1^4^6 = 1^6 = 7  (二进制 0111)
lowbit = 7 & -7 = 1
分组：4(100)&1=0,1(001)&1=1,4(100)&1=0,6(110)&1=0
0 组：4^4^6 = 6
1 组：1
答案：a=6, b=1
```

## Java 最优解

```java
public int[] singleNumbers(int[] nums) {
    int xor = 0;
    for (int x : nums) xor ^= x;                 // 1. 全体异或

    int lowbit = xor & (-xor);                   // 2. 取最低位 1
    int a = 0, b = 0;
    for (int x : nums) {
        if ((x & lowbit) == 0) a ^= x;           // 3. 分组异或
        else                    b ^= x;
    }
    return new int[]{a, b};
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n) | 两次遍历 |
| 空间 | O(1) | 几个变量 |

## 易错点

1. **`xor & -xor` 是找最低位 1**：利用补码取反加 1 的特性。也可以用 `xor & ~(xor - 1)`，等价
2. **分组按位判定**：`(x & lowbit) == 0`，注意优先级要加括号
3. **a 和 b 必不同组**：因为 `lowbit` 是 a、b 异或结果的某位 1，意味着 a 和 b 在该位不同
4. **必须有两个目标**：如果只有一个出现一次的数，全体异或直接得到答案（LeetCode 136）
5. **相同数成对抵消**：题目说「其他数都出现两次」是关键前提；如果是三次则要换方法

## 关键点

- **异或性质**：a ^ a = 0，a ^ 0 = a，可交换可结合
- **分组思路的本质**：把「两个不同的数」问题转化为「两个独立的『只出现一次的数』问题」
- 对比 LeetCode 136「Single Number」：只有一个目标数，全体异或即可
- **进阶：其他数都出现三次，找一个只出现一次的数**（LeetCode 137）：按位统计，每位 % 3 的余数就是答案
- **进阶：两个数出现一次，其他数出现三次**：更复杂，按位 % 3 后再按异或分组

## 变种：只有一个出现一次，其他出现三次（LeetCode 137）

```
方法 1：按位统计
  32 位的每一位，所有数在该位 1 的个数 % 3，余数即答案该位
方法 2：状态机
  用 two 个 32 位变量记录「出现 1 次」「出现 2 次」的状态
  触发 3 次自动清零
```
