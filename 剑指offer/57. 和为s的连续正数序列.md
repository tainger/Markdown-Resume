# 57. 和为 s 的连续正数序列

## 题目描述

输入一个正数 `target`，输出所有和为 `target` 的**连续正整数序列**（至少两个数）。

```
输入：target = 9
输出：[[2,3,4],[4,5]]
```

## 核心思路

**滑动窗口（双指针）**：维护区间 `[lo, hi]` 和区间和 `sum`：
- `sum < target`：`hi++` 扩展右端
- `sum > target`：`lo++` 收缩左端
- `sum == target`：记录窗口，然后 `lo++` 继续找下一个

```
target = 9
lo=1 hi=1 sum=1   扩 hi
lo=1 hi=2 sum=3   扩 hi
lo=1 hi=3 sum=6   扩 hi
lo=1 hi=4 sum=10  缩 lo → lo=2 sum=9 ✅ [2,3,4]
lo=2 hi=4 sum=9   收 lo → lo=3 sum=7
lo=3 hi=4 sum=7   扩 hi
lo=3 hi=5 sum=12  缩 lo → lo=4 sum=9 ✅ [4,5]
lo=4 hi=5 sum=9   收 lo → lo=5 sum=5 < target 且 hi > target/2+1 → 终止
```

终止条件：`lo > target/2 + 1`，因为两个连续数最小和 `lo + (lo+1) = 2lo+1`，超过 `target` 后没解。

## Java 最优解

```java
public int[][] findContinuousSequence(int target) {
    List<int[]> res = new ArrayList<>();
    int lo = 1, hi = 2;
    int sum = lo + hi;
    while (lo < hi && hi <= target / 2 + 1) {
        if (sum == target) {
            int[] one = new int[hi - lo + 1];
            for (int i = 0; i < one.length; i++) one[i] = lo + i;
            res.add(one);
            sum -= lo; lo++;              // 记录后继续找下一个
        } else if (sum < target) {
            hi++; sum += hi;
        } else {
            sum -= lo; lo++;
        }
    }
    return res.toArray(new int[0][]);
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(target) | 滑动窗口右端单调递增，总操作数线性 |
| 空间 | O(1) 结果不计 | 滑动窗口只存两个指针 + 一个 sum |

## 易错点

1. **终止条件用 `hi <= target/2 + 1`**：因为 hi ≥ lo + 1，hi 超过 target/2+1 时 `lo + hi > target`，不会再有解
2. **sum == target 后还要继续**：必须 `lo++` 继续，否则死循环（9 的解有 [2,3,4] 和 [4,5] 两个）
3. **不能用两层 for 暴力**：O(target²)，滑动窗口 O(target)
4. **起点从 1 开始不是 0**：题目要求正整数序列
5. **窗口大小至少 2**：所以 `hi` 初始 = 2

## 关键点

- **滑动窗口的适用前提**：区间和**单调递增**（正整数序列才有此性质）。如果数组有负数，区间和不单调，不能用双指针，要用前缀和 + 哈希
- **左指针收缩时机**：sum > target 就缩；sum == target 时也要缩（找下一个解）
- 对比 LeetCode 209「长度最小的子数组 ≥ s」：负数 absent 时也能用滑窗，但语义相反
- 对比 LeetCode 560「和为 K 的子数组」：含负数，必须用前缀和 + 哈希

## 变种：和为 s 的两个数（剑指 Offer 57-I）

```
排序数组中找两个数和为 s
双指针：lo=0, hi=n-1
sum < s → lo++
sum > s → hi--
sum == s → 返回 [nums[lo], nums[hi]]
```
