# 58. 翻转字符串

## 题目描述

输入一个英文句子，翻转句子中**单词的顺序**，但单词内字符顺序不变。标点和普通字母一样处理。

```
输入："the sky is blue"
输出："blue is sky the"
```

## 核心思路

**双指针从后向前找单词**：跳过末尾空格 → 找到一个单词的起止 → 加入结果 → 跳空格继续。

```
"the sky is blue    "
                  ↑ 从后往前跳空格 → 单词结尾 'e'
       ↑ 单词开头 'b'
"blue" 加入结果
继续向前 → "is blue"
继续 → "sky is blue"
继续 → "the sky is blue"
```

## Java 最优解

```java
public String reverseWords(String s) {
    StringBuilder sb = new StringBuilder();
    int i = s.length() - 1;
    while (i >= 0) {
        // 跳空格
        while (i >= 0 && s.charAt(i) == ' ') i--;
        if (i < 0) break;
        // 找单词开头
        int end = i + 1;
        while (i >= 0 && s.charAt(i) != ' ') i--;
        int start = i + 1;
        // 加入结果
        if (sb.length() > 0) sb.append(' ');
        sb.append(s, start, end);
    }
    return sb.toString();
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n) | 一趟遍历 |
| 空间 | O(n) | 结果 StringBuilder |

## 易错点

1. **多个连续空格**：开头跳空格循环必须写好，否则会加入空串
2. **单词后第一个空格才加 ' '**：`if (sb.length() > 0) sb.append(' ')`，避免末尾多一个空格
3. **全空格输入**："   " 应返回 ""，不能返回 " "；上面 break 处理了
4. **`s.substring` vs `s.append(s, start, end)`**：前者会新建 String，后者直接处理 StringBuilder，性能略好
5. **`s.split("\\s+")` + 反转**：能用，但 `split` 内部用正则有开销；O(n) 双指针更快

## 关键点

- **从后往前的双指针**：把「找所有单词」拆成「跳空格 + 找单词头 + 加结果」三步循环
- **末尾空格的处理**：开头先跳末尾空格是关键，否则第一个单词后会有多余的 ' '
- 对比 LeetCode 151「Reverse Words in a String」：完全等价
- **变种：左旋字符串**（剑指 Offer 58-II）：把前 k 个字符移到末尾，三种思路见下

## 变种：左旋字符串（剑指 Offer 58-II）

```
"abcdefg", k=2 → "cdefgab"
方法 1：substring + 拼接
  s.substring(k) + s.substring(0, k)
方法 2：三次反转
  反转 [0, k-1]：ba + cdefg
  反转 [k, n-1]：ba + gfedc
  反转整体：cdefgab
方法 3：拼接自身再截取
  (s + s).substring(k, k + n)
```
