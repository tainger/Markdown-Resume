# 59. 滑动窗口的最大值

## 题目描述

给定一个数组 `nums` 和滑动窗口大小 `k`，窗口从左往右滑动，返回每个窗口内的最大值。

```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]

[1 3 -1] -3 5 3 6 7   → 3
 1 [3 -1 -3] 5 3 6 7  → 3
 1 3 [-1 -3 5] 3 6 7  → 5
 ...
```

## 核心思路

**单调队列（双端队列）**：维护一个**递减**的双端队列，队首永远是当前窗口最大。

```
窗口右扩 r：
1. nums[r] 进队前，从队尾弹出所有 < nums[r] 的元素（保持递减）
2. 队首若是已出窗口（下标 ≤ r - k）就弹出
3. 当 r ≥ k-1 时记录队首（即最大值）

示例 k=3，nums=[1,3,-1,-3,5,3,6,7]
r=0 nums[0]=1: 队=[0]    队值=[1]
r=1 nums[1]=3: 弹 <3 的 0，队=[1]    队值=[3]
r=2 nums[2]=-1: 队=[1,2]  队值=[3,-1]   r≥2 → 记 3
r=3 nums[3]=-3: 队=[1,2,3] 队值=[3,-1,-3] 记 3
r=4 nums[4]=5:  弹所有 <5 的，队=[4]   队值=[5]   队首 1 已出窗口（1 ≤ 4-3=1），弹 → [4]  记 5
r=5 nums[5]=3:  队=[4,5]   队值=[5,3]   记 5
r=6 nums[6]=6:  弹 <6 的，队=[6]        记 6
r=7 nums[7]=7:  弹 <7 的，队=[7]        记 7
```

## Java 最优解

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    if (n == 0) return new int[0];
    int[] res = new int[n - k + 1];
    Deque<Integer> deque = new ArrayDeque<>();   // 存下标，便于判断是否过期
    for (int r = 0; r < n; r++) {
        // 1. 入队前，从队尾弹所有 < nums[r] 的（保持递减）
        while (!deque.isEmpty() && nums[deque.peekLast()] < nums[r]) {
            deque.pollLast();
        }
        deque.offerLast(r);
        // 2. 队首若已出窗口（下标 ≤ r - k），弹出
        if (deque.peekFirst() == r - k) {
            deque.pollFirst();
        }
        // 3. 窗口形成后开始记录
        if (r >= k - 1) {
            res[r - k + 1] = nums[deque.peekFirst()];
        }
    }
    return res;
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n) | 每个元素进队出队各一次，均摊 O(1) |
| 空间 | O(k) | 双端队列最多 k 个元素 |

## 易错点

1. **队存下标不存值**：因为要判断「队首是否过期」（下标 ≤ r - k）
2. **出窗口的判定**：`peekFirst() == r - k` 用 `==`，因为每个 r 只可能让一个元素过期
3. **从队尾弹出的判定**：用 `< nums[r]` 还是 `<=`？严格 `<`，相同元素保留（后进的相同元素先过期，能保证窗口内始终有最大值）
4. **`r >= k - 1` 才记录**：前 k-1 个元素还没形成完整窗口
5. **空数组**：直接返回 `new int[0]`，否则 `n - k + 1` 是负数

## 关键点

- **单调队列的本质**：维护一个窗口内「按值递减、按下标递增」的候选序列，淘汰那些「前面有更大且后进」的元素
- **存下标 vs 存值**：所有单调队列题目都建议**存下标**，方便判断过期
- 对比 LeetCode 155「最小栈」：用辅助栈维护最小值，但不是窗口；本题是窗口最大值
- 对比 LeetCode 239「Sliding Window Maximum」：本题就是 239 本体
- **单调队列家族**：本题（窗口最大）、剑指 Offer 59-II「队列最大值」（动态 push/pop/max，原理相同）

## 变种：队列最大值（剑指 Offer 59-II）

```
实现 push_front/push_back/pop_front/max
两个 deque：一个普通队列，一个单调递减队列
push_back: 普通队列入队，单调队列入队前弹尾保持递减
pop_front: 若普通队首 == 单调队首，两队列同时出
max: 单调队首
```
