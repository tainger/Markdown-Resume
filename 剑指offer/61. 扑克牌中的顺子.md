# 61. 扑克牌中的顺子

## 题目描述

从扑克牌中随机抽 5 张牌，判断是不是顺子（连续的 5 张）。**2~10 为数字本身，A 为 1，J 为 11，Q 为 12，K 为 13，大小王可以看成任何数（用 0 表示）**。

```
输入：[1,2,3,4,5]  → true
输入：[0,0,1,2,5] → false（gap 是 5-1=4 但只有 2 张王）
输入：[1,2,3,4,0] → true（王补 5）
```

## 核心思路

**排序 + 数王 + 数 gap**：
1. 排序后统计 0（王）的个数 `jokers`
2. 遍历非零部分，计算相邻两张牌之间的 gap（`gap = next - cur - 1`）
3. 累加 gap，如果 gap 总和 ≤ jokers，则能补成顺子
4. 注意判重：相邻相等直接 false（一副牌没有重复牌）

```
[0,0,2,5,7]
jokers = 2
非零：2,5,7
  gap(2→5) = 5-2-1 = 2
  gap(5→7) = 7-5-1 = 1
总 gap = 3 > jokers=2 → false
```

## Java 最优解

```java
public boolean isStraight(int[] nums) {
    Arrays.sort(nums);
    int jokers = 0;
    for (int i = 0; i < nums.length - 1; i++) {
        if (nums[i] == 0) {
            jokers++;
        } else if (nums[i] == nums[i + 1]) {
            return false;       // 重复牌，不可能是顺子
        }
    }
    // gap 总和 ≤ jokers
    int gap = 0;
    int first = jokers;        // 排序后第一个非零下标
    for (int i = first; i < nums.length - 1; i++) {
        gap += nums[i + 1] - nums[i] - 1;
    }
    return gap <= jokers;
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n log n) | 排序主导 |
| 空间 | O(1) | 排序原地 |

## 易错点

1. **重复牌不是顺子**：相邻相等要直接 return false（一副牌中不可能有 2 张「3」）
2. **gap 公式**：`next - cur - 1`，不是 `next - cur`；因为相邻差 1 时 gap = 0，差 2 时 gap = 1
3. **王可以多张**：4 张王 + 一个 5 = `[5,0,0,0,0]` 也是顺子（补 1,2,3,4 或 6,7,8,9）
4. **不排序的解法**：用 set 判重 + 记录最大最小，差值 < 5 即可，但要单独处理全王的情况

## 关键点

- **核心思想**：排序后王的张数能否填补 gap 总和
- **王 = 万能牌**：可以填任意大小的 gap，但只能填一个位置
- **不排序的 O(n) 解法**：set 判重 + max - min ≤ 4 即可（前提是没重复且非王部分最大差 ≤ 4）
- 对比 LeetCode 846「Hand of Straights」：更通用，要求分组成多组连续的 k 张牌
- **类比题：顺子判定** vs 区间合并 vs 调度问题，都是排序后贪心

## 变种：分组成多组顺子（LeetCode 846）

```
把牌按数字分组，每组 k 张连续牌
方法：哈希计数 + 贪心
  排序后从最小数开始，每组 k 个连续数
  每次减去对应计数，不够则 false
```
