# 62. 圆圈中最后剩下的数字

## 题目描述

0, 1, …, n-1 这 n 个数字排成一个圆圈，从数字 0 开始，每次删除第 m 个数字，求最后剩下的数字。即**约瑟夫环问题**。

```
输入：n = 5, m = 3
输出：3   删除顺序：2 → 0 → 4 → 1 → 剩 3
```

## 核心思路

**递推公式（数学解）**：设 `f(n, m)` 为 n 个数剩下的最后编号，则有：

```
f(1, m) = 0
f(n, m) = (f(n-1, m) + m) % n
```

**推导**：长度 n 时第 1 个被删的是 `(m-1) % n`，删完后从 `k = m % n` 开始新一轮长度 n-1 的约瑟夫环，递归得到 `f(n-1, m)` 是「相对 k 的下标」，再映射回原坐标系：`f(n, m) = (f(n-1, m) + k) % n = (f(n-1, m) + m) % n`。

```
n=5 m=3
删第 1 个：(3-1)%5=2，即 2 被删
剩下 [3,4,0,1] 从 3 开始，重新编号 0,1,2,3
子问题 f(4, 3) 的答案映射到原坐标：+3（即新坐标 0 → 原坐标 3）

从底向上递推：
f(1)=0
f(2)=(0+3)%2=1
f(3)=(1+3)%3=1
f(4)=(1+3)%4=0
f(5)=(0+3)%5=3   ✓
```

## Java 最优解

```java
public int lastRemaining(int n, int m) {
    int ans = 0;                  // f(1, m) = 0
    for (int i = 2; i <= n; i++) {
        ans = (ans + m) % i;
    }
    return ans;
}
```

## 复杂度

| 指标 | 值 | 说明 |
|:---|:---:|:---|
| 时间 | O(n) | 一趟递推 |
| 空间 | O(1) | 一个变量 |

## 易错点

1. **公式方向**：从 i=2 推到 i=n，**从底向上**。不要写递归（栈深 O(n)，重复子问题无意义）
2. **取模对象**：`(ans + m) % i`，模的是**当前规模 i**，不是 n 或 m
3. **m 边界**：m > n 时取模后公式仍正确，无需处理；m=1 时答案是 n-1（删完前面所有）
4. **朴素链表模拟**：O(nm) 时间，n 大时（如 n=10^5）超时；公式法 O(n) 总能过
5. **公式记忆**：`f(n) = (f(n-1) + m) % n`，从规模 i=2 开始迭代

## 关键点

- **约瑟夫环的本质**：删除第 m 个后，剩下 n-1 个数的子问题；映射到原坐标的关键是「加 m 取模」
- **为什么从底向上**：`f(n)` 依赖 `f(n-1)`，朴素递归会有 O(n) 栈深度；改成迭代既省空间又避免递归开销
- 对比 LeetCode 1823「Find the Winner of Circular Game」：完全等价
- **变种**：约瑟夫环变种在 ACM 里多见：n=10^9 时 O(n) 不行，需用「批量跳过法」O(log n) 的扩展

## 变种：约瑟夫环变种

```
- 「报 m 出局，问最后剩下谁」→ 本题
- 「每次报 2 出局」→ 经典版，有公式 f(n) = 2*(n - 2^k)（k 是 ≤ n 的最大 2 的幂）
- 「删除后从下一个重新报，不是从头」→ 本题设定
```
