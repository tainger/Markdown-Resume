| **单调队列** | 59 | 双端队列存下标，队首最大 |

| **快排切分** | 40 | Quick Select 找第 k 小 |
| **堆** | 40、41 | Top-K 单堆、中位数双堆 |
| **二叉树递归** | 26、27、28、55 | 前序/后序/层序，镜像交叉 |
| **BST 性质** | 33、54 | 反向中序找第 k 大 |
| **回溯** | 34 | 路径模板：访问→递→回 |
| **异或/位运算** | 56 | 全体异或 + lowbit 分组 |
| **投票** | 39 | count + candidate 抵消 |
| **数学递推** | 62 | 约瑟夫环 `f = (f + m) % n` |

## 一句话总结

> 剑指 Offer 的本质是**用经典数据结构（数组/链表/树/栈队列/哈希/堆）解决高频面试题**，掌握每道题的最优解模板和复杂度，面试时能快速写出 bug-free 代码。
