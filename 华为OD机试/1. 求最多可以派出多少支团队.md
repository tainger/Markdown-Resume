# 1. 求最多可以派出多少支团队

> **难度**：🟢 简单 | **分值**：100 | **标签**：排序、双指针 | **考点**：贪心

## 题目描述

用数组代表每个人的能力值。一个比赛活动要求参赛团队的**最低能力值为 N**，每个团队可以由 **1 人或者 2 人**组成，且 1 个人只能参加 1 个团队。

计算最多可以派出多少支符合要求的团队。

**输入描述**：

```
第一行：能力值数组（空格分隔）
第二行：团队最低能力值 N
```

**输出描述**：最多可以派出的团队数量。

## 示例

```
输入：
3 1 5 7 9
8
输出：
2
```

**解释**：`9` 单独成队（9 ≥ 8）；`7 + 1 = 8` 成队；剩余 `3`、`5` 组队为 `3 + 5 = 8`，也可成队 → 共 **3 支**。

> 注：示例为流传版本，实际以考试输入为准；另一版本无「单人成队」规则，此时答案可能不同。

---

## 提示

- 1 人只能参加 1 个团队，不能重复使用。
- 单人成队条件：能力值 ≥ N。
- 优先考虑大能力值的人，避免浪费。

---

## 思路

### 核心思想

排序 + 双指针（贪心）：

```
排序后：
left = 0（最小），right = n-1（最大）

1. a[right] >= N  → 单独成队（最大的一定能带上别人，但单独用最划算）
   count++, right--
2. a[left] + a[right] >= N  → 两人成队
   count++, left++, right--
3. 否则 → a[left] 谁都配不了（和最大的组都不够），丢弃
   left++
```

**为什么贪心是对的**：最大的人若能单独成队就单独出（不浪费别人）；最小的若和最大的都组不了队，那和谁都组不了，直接丢弃。

**逐步演示**（`[1,3,5,7,9]`，N=8）：

```
排序: [1, 3, 5, 7, 9]    left=0, right=4, count=0

right=4: 9 >= 8 → 单独成队         count=1, right=3
right=3: 7 + 1 = 8 >= 8 → 成队     count=2, left=1, right=2
right=2: 5 + 3 = 8 >= 8 → 成队     count=3, left=2, right=1

left >= right → 结束，输出 3 ✓
```

- 时间复杂度：\(O(n \log n)\)（排序主导）
- 空间复杂度：\(O(1)\)

### 解法（Java）

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // 第一行：能力值数组
        String[] parts = sc.nextLine().trim().split(" ");
        int[] a = new int[parts.length];
        for (int i = 0; i < parts.length; i++) {
            a[i] = Integer.parseInt(parts[i]);
        }
        // 第二行：最低能力值 N
        int n = Integer.parseInt(sc.nextLine().trim());

        Arrays.sort(a);

        int left = 0, right = a.length - 1;
        int count = 0;

        while (left < right) {
            if (a[right] >= n) {
                // 最大者单独成队
                count++;
                right--;
            } else if (a[left] + a[right] >= n) {
                // 最小 + 最大 成队
                count++;
                left++;
                right--;
            } else {
                // 最小的配谁都组不了队，丢弃
                left++;
            }
        }
        // 最后若只剩 1 人，单独检查
        if (left == right && a[left] >= n) {
            count++;
        }

        System.out.println(count);
    }
}
```

> 💡 若题目版本**不允许单人成队**，去掉 `a[right] >= n` 分支即可，其余逻辑不变。
