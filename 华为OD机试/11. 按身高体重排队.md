# 11. 按身高体重排队

> **难度**：🟢 简单 | **分值**：100 | **标签**：排序 | **考点**：多关键字稳定排序

## 题目描述

某学校举行运动会，学生们按编号 1 ~ n 进行标识。现需要按照**身高由低到高**排列；对身高相同的人，按**体重由轻到重**排列；对于身高体重都相同的人，**维持原有的编号顺序**。

给定身高序列 `heights` 和体重序列 `weights`（两序列等长，下标 i 对应编号为 i+1 的学生），返回排列后的学生编号数组。

### 函数签名

```java
class Solution {
    public int[] queueOrder(int[] heights, int[] weights) {
        // ...
    }
}
```

---

## 示例

### 示例 1

```
输入：heights = [100, 100, 120, 130], weights = [40, 30, 60, 50]
输出：[2, 1, 3, 4]
```

**解释**：学生 1(100,40)、2(100,30)、3(120,60)、4(130,50)。按身高升序，1、2 身高相同 → 按体重升序：2(30) 在 1(40) 前 → 编号顺序 `2 1 3 4`。

---

## 提示

- `0 < heights.length <= 100`
- `heights.length == weights.length`
- 身高、体重均为正整数
- 关键规则：**三关键字排序**：身高 → 体重 → 编号。
- 「维持原有编号顺序」= 稳定排序，用编号作为最后一个比较键即可。
- 注意输入是**两个等长序列**（先身高后体重），不是"每行一个学生"。

---

## 思路

### 核心思想

把 (编号, 身高, 体重) 打包成对象/数组，按 Comparator 排序：

```
比较规则：
  1. 身高升序
  2. 身高相同 → 体重升序
  3. 身高体重都相同 → 编号升序（保证稳定）
```

**逐步演示**（示例）：

```
学生: 1(100,40)  2(100,30)  3(120,60)  4(130,50)

按 身高 → 体重 → 编号 排序:
  身高 100 的: 2(30) < 1(40)
  身高 120 的: 3
  身高 130 的: 4
→ 2 1 3 4 ✓
```

- 时间复杂度：\(O(n \log n)\)
- 空间复杂度：\(O(n)\)

### 解法（Java）

```java
import java.util.*;

class Solution {
    private static class Student {
        int id, height, weight;
        Student(int id, int height, int weight) {
            this.id = id;
            this.height = height;
            this.weight = weight;
        }
    }

    public int[] queueOrder(int[] heights, int[] weights) {
        int n = heights.length;
        List<Student> list = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            list.add(new Student(i + 1, heights[i], weights[i]));
        }

        // 三关键字排序：身高 → 体重 → 编号
        list.sort((a, b) -> {
            if (a.height != b.height) return a.height - b.height;
            if (a.weight != b.weight) return a.weight - b.weight;
            return a.id - b.id;
        });

        int[] res = new int[n];
        for (int i = 0; i < n; i++) {
            res[i] = list.get(i).id;
        }
        return res;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n \log n)\)，排序主导。
- **空间复杂度**：\(O(n)\)，学生列表与结果数组。

> 💡 三关键字排序的通用写法：Comparator 链式比较，前两键相同才落到第三键（编号），等价于稳定排序。
