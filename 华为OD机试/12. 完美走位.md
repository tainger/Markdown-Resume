# 12. 完美走位

> **难度**：🟡 中等 | **分值**：100（C/D卷；早期版本分值更高，随卷次变化） | **标签**：滑动窗口 | **考点**：窗口合法性判断

## 题目描述

在第一人称射击游戏中，玩家通过键盘的 **A、S、D、W** 四个按键控制游戏人物分别向左、向后、向右、向前移动，从而完成走位。

给定玩家的走位字符串 `s`（**长度为 4 的倍数**，仅包含 W/A/S/D），请通过**替换其中一段连续走位**的方式，使得原走位能够变成一个「完美走位」。

**完美走位**：替换后，四个方向的出现次数**相等**（各为 `len/4` 次）。待替换的连续走位可以是**相同长度的任何走位**。

求**最小的替换子串长度**。

### 函数签名

```java
class Solution {
    public int minReplaceLength(String s) {
        // ...
    }
}
```

---

## 示例

### 示例 1

```
输入：s = "WASDAASD"
输出：1
```

**解释**：`WASDAASD` 中 W:1、A:3、S:2、D:2，目标各 2 次。A 多 1 个、W 少 1 个，把 1 个 `A` 换成 `W` 即可平衡 → 最小替换长度 1。

### 示例 2

```
输入：s = "AAAA"
输出：3
```

**解释**：目标各 1 次，把 `AAA` 替换为 `WSD` 即可 → 长度 3。

---

## 提示

- `s.length` 是 4 的倍数，且 `1 <= s.length <= 10^5`
- `s` 仅包含字符 `W`、`A`、`S`、`D`
- 替换的是一段**连续子串**，长度可以为 0（原走位本来就完美时返回 0）
- 判断核心：**窗口外**的字符数不能超过 `len/4`（超出部分才需要靠替换补）

## 思路

### 第 1 步：读题，把要素翻译成可操作对象

| 题目要素 | 转化为 |
|:---|:---|
| 替换「一段连续走位」 | 选一个连续子串 `[left..right]` 作窗口 |
| 替换后各方向 == `len/4` | 设 `k = n/4`，目标是 4 方向计数都 == k |
| 替换串可任意构造（同长度） | 只关心「能不能构造」，不关心具体填什么 |
| 求最小替换长度 | 求最短合法窗口 |

### 第 2 步：定位「合法性只取决于窗口外」

替换**只改窗口内**字符 → **窗口外计数固定不变**。所以替换后能否完美，**只看窗口外**：

```
设 outside[c] = 字符 c 在窗口外的个数 = total[c] - win[c]
```

### 第 3 步：推导合法性条件（本题最关键的一步）

对每个方向 c：替换后 = `outside[c] + 窗口内补的数`，要 == k，需 `outside[c] ≤ k`（窗口内补 `k - outside[c]` ≥ 0）。

```
窗口合法 ⇔ 对所有方向 c：outside[c] ≤ k
```

**还需证明可构造**（缺失总数 == 窗口长度，才能填满）：

```
∑outside[c] = 窗口外字符总数 = n - 窗口长度
∑(k - outside[c]) = 4k - ∑outside[c] = n - (n - 窗口长度) = 窗口长度 ✓
```

→ 合法条件就是「窗外四方向都 ≤ k」，**与具体填什么无关**。这一步把「能否构造」从直觉变成证明。

### 第 4 步：暴力 → 滑动窗口

**暴力**：枚举所有 `[i..j]` 窗口，逐个检查合法性取最短 → \(O(n^2)\)。

**滑动窗口信号识别**：
- 求「满足条件的连续子串的最短长度」→ 滑动窗口候选
- 合法性随窗口扩大**单调变易**（窗口越大 → 窗外越少 → 越易 ≤ k）→ 同向双指针可推进

→ `right` 扩张累加 `win`；合法时不断收缩 `left` 取最小：

```
for right in [0, n):
    win[s[right]]++
    while 窗外各方向 ≤ k:           // 合法
        ans = min(ans, right-left+1)
        win[s[left]]--; left++     // 收缩，看能否更短
```

### 关键推理（一句话）

> 窗外某方向 > k → 无论怎么替换，该方向最终都 > k → 不可能完美；反之 ≤ k 时一定可构造。**所以「合法」= 窗外四方向都 ≤ k，与具体填什么无关。**

### 逐步演示（`WASDAASD`）

```
W:1 A:3 S:2 D:2, k=2

窗口 [0,0]="W": 窗外 A:3 > 2 → 不合法
...
窗口 [1,1]="A": 窗外 A:2 ≤ 2, W:1, S:2, D:2 → 全部 ≤ 2 → 合法！
→ 最小长度 1 ✓
```

- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(1)\)

### 解法一（滑动窗口，O(n)）

```java
import java.util.*;

class Solution {
    private int idx(char c) {
        switch (c) {
            case 'W': return 0;
            case 'A': return 1;
            case 'S': return 2;
            default:  return 3; // 'D'
        }
    }

    public int minReplaceLength(String s) {
        int n = s.length();
        int k = n / 4;

        int[] total = new int[4];
        for (char c : s.toCharArray()) total[idx(c)]++;

        // 本来就完美（四方向各 k 次）→ 无需替换
        boolean balanced = true;
        for (int t : total) {
            if (t != k) { balanced = false; break; }
        }
        if (balanced) {
            return 0;
        }

        int[] win = new int[4];        // 窗口内计数
        int left = 0;
        int ans = n;                    // 初始化为最大

        for (int right = 0; right < n; right++) {
            win[idx(s.charAt(right))]++;

            // 窗口合法：窗口外每个方向 ≤ k
            while (true) {
                boolean ok = true;
                for (int i = 0; i < 4; i++) {
                    if (total[i] - win[i] > k) { ok = false; break; }
                }
                if (!ok) break;
                // 合法 → 尝试收缩
                ans = Math.min(ans, right - left + 1);
                win[idx(s.charAt(left))]--;
                left++;
            }
        }
        return ans;
    }
}
```

### 复杂度分析（解法一）

- **时间复杂度**：\(O(n)\)，其中 \(n\) 为字符串长度。`right` 与 `left` 指针各至多遍历一次。
- **空间复杂度**：\(O(1)\)，仅使用固定大小为 4 的计数数组。

### 解法二（暴力枚举，O(n²)）

枚举所有连续子串 `[i..j]` 作为替换窗口，逐个判断合法性（窗口外各方向计数 ≤ k）。利用单调性：固定 `i` 时窗口越大、窗外越少，一旦合法更长的也合法但更长，故找到第一个合法 `j` 即可 `break`。

```java
class Solution {
    private int idx(char c) {
        switch (c) {
            case 'W': return 0;
            case 'A': return 1;
            case 'S': return 2;
            default:  return 3;
        }
    }

    public int minReplaceLength(String s) {
        int n = s.length();
        int k = n / 4;
        int[] total = new int[4];
        for (char c : s.toCharArray()) total[idx(c)]++;

        if (total[0] == k && total[1] == k && total[2] == k && total[3] == k) return 0;

        int ans = n;
        for (int i = 0; i < n; i++) {
            int[] win = new int[4];
            for (int j = i; j < n; j++) {
                win[idx(s.charAt(j))]++;
                boolean ok = true;
                for (int d = 0; d < 4; d++) {
                    if (total[d] - win[d] > k) { ok = false; break; }
                }
                if (ok) {
                    ans = Math.min(ans, j - i + 1);
                    break;  // 固定 i：首个合法即最短
                }
            }
        }
        return ans;
    }
}
```

### 复杂度分析（解法二）

- **时间复杂度**：\(O(n^2)\)，双重循环枚举窗口；\(n = 10^5\) 时约 \(10^{10}\) 次会 TLE，仅作思路对照。
- **空间复杂度**：\(O(1)\)，固定大小 4 的计数数组。

### 解法三（int[128] 直接索引，免映射）

把 `int[4] + idx()` 换成 `int[128]`，**直接用 char 当下标**——既甩掉 `idx()` 的 switch 映射，又免 `HashMap` 的装箱/哈希开销。字符集固定且是 ASCII 时这是最省写法。

```java
class Solution {
    public int minReplaceLength(String s) {
        int n = s.length();
        int k = n / 4;
        int[] total = new int[128];
        for (char c : s.toCharArray()) total[c]++;

        if (total['W']==k && total['A']==k && total['S']==k && total['D']==k) return 0;

        int ans = n, left = 0;
        int[] win = new int[128];
        char[] dir = {'W','A','S','D'};
        for (int right = 0; right < n; right++) {
            win[s.charAt(right)]++;
            while (true) {
                boolean ok = true;
                for (char c : dir) {
                    if (total[c] - win[c] > k) { ok = false; break; }
                }
                if (!ok) break;
                ans = Math.min(ans, right - left + 1);
                win[s.charAt(left)]--;
                left++;
            }
        }
        return ans;
    }
}
```

### 复杂度分析（解法三）

- **时间复杂度**：\(O(n)\)，同解法一。
- **空间复杂度**：\(O(1)\)，`int[128]` 固定 128 格（远小于输入规模，视为常数）。

### 解法四（need/excess 视角，与解法一等价）

与解法一同为 O(n) 滑动窗口，只是把合法条件从「窗外 ≤ k」换成「窗口覆盖所有溢出需求 `need[i] = max(0, count[i]-k)`」。两者数学等价：`win[i] ≥ need[i]` ⇔ `win[i] ≥ count[i]-k` ⇔ 窗外 ≤ k。框架更贴近 [76. 最小覆盖子串](../leetcode-hot100/76.%20最小覆盖子串.md) 的 need 模型，对很多人更直观。

```java
class Solution {
    public int minReplaceLength(String s) {
        int n = s.length();
        int target = n / 4;

        // 1. 统计每个字符的出现次数（0:W 1:A 2:S 3:D）
        int[] count = new int[4];
        for (char c : s.toCharArray()) count[getIndex(c)]++;

        // 2. 已是完美走位 → 0
        if (count[0] == target && count[1] == target
                && count[2] == target && count[3] == target) {
            return 0;
        }

        // 3. need[i] = 第 i 个方向溢出多少（必须被窗口吃掉）
        int[] need = new int[4];
        for (int i = 0; i < 4; i++) need[i] = Math.max(0, count[i] - target);

        // 4. 滑动窗口：找覆盖所有 need 的最短窗口
        int left = 0;
        int[] window = new int[4];
        int minLen = n;
        for (int right = 0; right < n; right++) {
            window[getIndex(s.charAt(right))]++;
            while (left <= right && isValid(window, need)) {
                minLen = Math.min(minLen, right - left + 1);
                window[getIndex(s.charAt(left))]--;
                left++;
            }
        }
        return minLen;
    }

    private int getIndex(char c) {
        switch (c) {
            case 'W': return 0;
            case 'A': return 1;
            case 'S': return 2;
            case 'D': return 3;
            default: return -1;  // 输入保证仅 WASD
        }
    }

    // 合法 ⇔ 窗口已覆盖每个方向的溢出需求
    private boolean isValid(int[] window, int[] need) {
        for (int i = 0; i < 4; i++) {
            if (window[i] < need[i]) return false;
        }
        return true;
    }
}
```

### 复杂度分析（解法四）

- **时间复杂度**：\(O(n)\)，同解法一。
- **空间复杂度**：\(O(1)\)，固定大小 4 的 `count`/`need` 数组。

> 💡 选型口诀：**字符集固定 → `int[4]/int[128]`；动态或非 ASCII → `HashMap`**。

> 💡 要点：先扩展 right，再在 while 里「检查合法性 + 收缩」，收缩后窗口依然合法就继续收缩，直到不合法为止。
>
> ⚠️ 若全部走位本来就平衡（如 `WASD`），窗口为空时也合法 → 返回 0。
