# 12. 完美走位

> **难度**：🟡 中等 | **分值**：100（C/D卷；早期版本分值更高，随卷次变化） | **标签**：滑动窗口 | **考点**：窗口合法性判断

## 题目描述

在第一人称射击游戏中，玩家通过键盘的 **A、S、D、W** 四个按键控制游戏人物分别向左、向后、向右、向前移动，从而完成走位。

给定玩家的走位字符串 `s`（**长度为 4 的倍数**，仅包含 W/A/S/D），请通过**替换其中一段连续走位**的方式，使得原走位能够变成一个「完美走位」。

**完美走位**：替换后，四个方向的出现次数**相等**（各为 `len/4` 次）。待替换的连续走位可以是**相同长度的任何走位**。

求**最小的替换子串长度**。

## 示例

### 示例 1

```
输入：s = "WASDAASD"
输出：1
```

**解释**：`WASDAASD` 中 W:2、A:3、S:2、D:1，目标各 2 次。把 1 个 `A` 换成 `D` 即可平衡 → 最小替换长度 1。

### 示例 2

```
输入：s = "AAAA"
输出：3
```

**解释**：目标各 1 次，把 `AAA` 替换为 `WSD` 即可 → 长度 3。

---

## 提示

- `s.length` 是 4 的倍数，且 `1 <= s.length <= 10^5`
- `s` 仅包含字符 `W`、`A`、`S`、`D`
- 替换的是一段**连续子串**，长度可以为 0（原走位本来就完美时返回 0）
- 判断核心：**窗口外**的字符数不能超过 `len/4`（超出部分才需要靠替换补）

---

## 思路

### 核心思想

**滑动窗口**：窗口 `[left..right]` 就是要替换的连续段，判断窗口是否「可替换成完美走位」。

```
设 k = len / 4，cnt[c] = 窗口外字符 c 的个数（total[c] - 窗口内个数）

窗口合法 ⇔ 所有方向的 cnt[c] ≤ k
（因为替换只能改窗口内的字符，窗口外数量不变；
  窗口外每个方向 ≤ k 时，缺失部分 = k - cnt[c]，正好由窗口内字符补足，
  且缺失总数 = 窗口长度，可构造出合法替换串）

枚举 right，窗口合法时不断收缩 left，取最小窗口长度
```

**关键推理**：窗口外某方向若 > k 次，无论如何替换，该方向最终都会 > k → 不可能完美。反之 ≤ k 时一定可构造。

**逐步演示**（`WASDAASD`）：

```
W:2 A:3 S:2 D:1, k=2

窗口 [0,0]="W": 窗口外 A:3 > 2 → 不合法
...
窗口 [1,1]="A": 窗口外 A:2 ≤ 2, W:2, S:2, D:1 → 全部 ≤ 2 → 合法！
→ 最小长度 1 ✓
```

- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(1)\)

### 解法（Java，滑动窗口）

```java
import java.util.*;

class Solution {
    private int idx(char c) {
        switch (c) {
            case 'W': return 0;
            case 'A': return 1;
            case 'S': return 2;
            default:  return 3; // 'D'
        }
    }

    public int minReplaceLength(String s) {
        int n = s.length();
        int k = n / 4;

        int[] total = new int[4];
        for (char c : s.toCharArray()) total[idx(c)]++;

        // 本来就完美（四方向各 k 次）→ 无需替换
        boolean balanced = true;
        for (int t : total) {
            if (t != k) { balanced = false; break; }
        }
        if (balanced) {
            return 0;
        }

        int[] win = new int[4];        // 窗口内计数
        int left = 0;
        int ans = n;                    // 初始化为最大

        for (int right = 0; right < n; right++) {
            win[idx(s.charAt(right))]++;

            // 窗口合法：窗口外每个方向 ≤ k
            while (true) {
                boolean ok = true;
                for (int i = 0; i < 4; i++) {
                    if (total[i] - win[i] > k) { ok = false; break; }
                }
                if (!ok) break;
                // 合法 → 尝试收缩
                ans = Math.min(ans, right - left + 1);
                win[idx(s.charAt(left))]--;
                left++;
            }
        }
        return ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，其中 \(n\) 为字符串长度。`right` 与 `left` 指针各至多遍历一次。
- **空间复杂度**：\(O(1)\)，仅使用固定大小为 4 的计数数组。

> 💡 要点：先扩展 right，再在 while 里「检查合法性 + 收缩」，收缩后窗口依然合法就继续收缩，直到不合法为止。
>
> ⚠️ 若全部走位本来就平衡（如 `WASD`），窗口为空时也合法 → 返回 0。
