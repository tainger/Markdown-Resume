# 14. 九宫格按键输入

> **难度**：🟡 中等 | **分值**：200 | **标签**：模拟、字符串 | **考点**：状态机模拟

## 题目描述

九宫格按键输入，判断输出。键盘有**英文和数字两个模式**，默认是**数字模式**。

九宫格键盘布局：

```
1（,. ）   2（abc）   3（def）
4（ghi）   5（jkl）   6（mno）
7（pqrs）  8（tuv）   9（wxyz）
0（空格）  #         /
```

**规则**：

1. **数字模式**：数字直接输出（如 `1234` → `1234`）；
2. **英文模式**：连续按同一个按键会依次出现这个按键上的字母（如 `222` → `c`，按 4 次 `2222` → `a`，循环）；若输入 `/` 则**循环中断**（用于分隔连续按键）；
3. **#** 用于切换模式（默认数字模式，按一次切到英文，再按切回）；
4. **/** 表示延迟：如英文模式下输入 `22/222` → 显示 `bc`。

给定输入字符串 `s`（仅含数字 `0~9` 和字符 `#`、`/`），返回屏幕显示的内容。

### 函数签名

```java
class Solution {
    public String nineKeyInput(String s) {
        // ...
    }
}
```

## 示例

### 示例 1（数字模式）

```
输入：s = "1234"
输出："1234"
```

### 示例 2（英文模式，切模式）

```
输入：s = "#1234"
输出：",adg"
```

**解释**：`#` 切到英文模式；`1` 按 1 次 → `,`；`2` → `a`；`3` → `d`；`4` → `g`。

### 示例 3（延迟中断）

```
输入：s = "#22/222"
输出："bc"
```

**解释**：`22` → 按 2 键 2 次 → `b`；`/` 中断；`222` → 按 2 键 3 次 → `c`。

---

## 提示

- `1 <= s.length <= 10^5`
- `s` 仅包含数字 `0~9` 和字符 `#`、`/`
- 英文模式下连续按键次数 N 取字母：`letters[(N-1) % letters.length]`（循环）。
- `/` 和 `#` 在任何模式下都不输出字符，只起控制作用。
- 模式切换后，之前的连续按键计数清零。

---

## 思路

### 核心思想

**状态机模拟**：维护 `mode`（0 数字 / 1 英文），从左到右扫描：

```
# → 切换 mode
/ → 跳过（中断效果天然由「连续段扫描」实现）
数字模式: 直接输出数字
英文模式: 扫描连续相同数字段（长度 cnt）→ 输出该键字母表第 (cnt-1) % len 个
```

**逐步演示**（`#22/2022#33#872233444/44`）：

```
# → 英文模式
22 → 键2 按2次 → 'b'
/  → 跳过
2022 → '2'按1次→'a'；'0'按1次→' '；'22'按2次→'b'  → "a b"
# → 切回数字模式
33 → 数字模式直接输出 → "33"
# → 切回英文模式
872233444 → 8→'t'，7→'p'，22→'b'，3→'d'，3→'d'，444→'i' → "tpbddi"
/  → 跳过
44 → 键4按2次 → 'h'   （ghi 中第 2 个）
输出: "ba b33tpbddih"
```

- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(1)\)（字母表固定）

### 解法（Java，状态机模拟）

```java
import java.util.*;

class Solution {
    // 九宫格字母表：键 -> 字母数组
    private static final String[] KEYS = {
        " ",    // 0
        ",.",   // 1
        "abc",  // 2
        "def",  // 3
        "ghi",  // 4
        "jkl",  // 5
        "mno",  // 6
        "pqrs", // 7
        "tuv",  // 8
        "wxyz"  // 9
    };

    public String nineKeyInput(String s) {
        int mode = 0; // 0 数字模式，1 英文模式
        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '#') {
                mode = 1 - mode;              // 切换模式
            } else if (c == '/') {
                continue;                     // 延迟：跳过
            } else if (mode == 0) {
                sb.append(c);                 // 数字模式直接输出
            } else {
                // 英文模式：统计连续相同数字次数
                int cnt = 1;
                while (i + 1 < s.length() && s.charAt(i + 1) == c) {
                    cnt++;
                    i++;
                }
                String letters = KEYS[c - '0'];
                sb.append(letters.charAt((cnt - 1) % letters.length()));
            }
        }
        return sb.toString();
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，其中 \(n\) 为输入字符串长度。每个字符至多访问一次（连续段扫描中跳跃前进）。
- **空间复杂度**：\(O(1)\)（不计输出字符串的 `StringBuilder`），字母表 `KEYS` 为固定常量。

> 💡 常见坑：
> 1. 英文模式下 `/` 只是中断信号，`#` 才是切模式——两者别搞混；
> 2. 连续段计数要**循环取模**（`2222` 按 4 次回到 `a`）；
> 3. `0` 键对应空格。
