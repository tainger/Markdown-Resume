# 15. 考古学家

> **难度**：🟡 中等 | **分值**：200 | **标签**：回溯、排列 | **考点**：全排列 + 去重（LeetCode 47 变体）

## 题目描述

有一个考古学家发现一个石碑，可惜已经断裂成碎片。碎片上写着一些字符（可能**有重复**）。

考古学家想知道这些字符能组成**多少种不同的排列**（全排列，去重），请按**字典序**输出所有不重复的排列。

**输入描述**：

```
第一行：n（字符个数）
第二行：n 个字符（空格分隔）
```

（部分版本直接输入一行字符串，逻辑相同）

**输出描述**：所有不重复的排列，每个一行（字典序）。

## 示例

```
输入：
3
a b c
输出：
abc
acb
bac
bca
cab
cba
```

**示例 2**（含重复字符）

```
输入：
3
a a b
输出：
aab
aba
baa
```

**解释**：3 个字符共 6 种排列，去重后只剩 3 种。

---

## 提示

- 核心考点：**去重的全排列**（LeetCode 47 原题）。
- 去重两要素：**排序**（让相同字符相邻）+ **树层去重**（同层跳过相同字符）。
- 输出要求字典序 → 初始排序 + 回溯天然有序。

---

## 思路

### 核心思想

排序 + 回溯 + `used[]` 剪枝：

```
1. 字符排序（相同字符相邻，为去重做准备）
2. 回溯生成排列：
   - 第 i 层选择第 i 个字符
   - 剪枝：if (i > 0 && chars[i] == chars[i-1] && !used[i-1]) continue
     （同层相同字符只取第一个，避免重复排列）
3. 路径长度 == n → 输出
```

**为什么 `!used[i-1]` 能去重**：相同字符 a1、a2 相邻。当处理 a2 时，若 a1 还没被使用（说明 a1 在本层已经被跳过/即将被选择），选 a2 会和选 a1 产生相同排列 → 跳过 a2。这样保证**同一层只选一次相同字符**。

**逐步演示**（`a a b`）：

```
排序: [a, a, b]
第一层: 选 a1（跳过 a2 因为 a2==a1 且 a1 未用）
  ├ 第二层: 选 a2 → 第三层选 b → "aab"
  └ 第二层: 选 b  → 第三层选 a2 → "aba"
第一层(回溯后): 尝试 a2 → a2==a1 且 a1 未用 → 剪枝跳过
第一层: 选 b → 第二层选 a1 → 第三层选 a2 → "baa"
输出: aab / aba / baa ✓
```

- 时间复杂度：\(O(n \cdot n!)\)（排列总数）
- 空间复杂度：\(O(n)\)

### 解法（Java，回溯 + 去重）

```java
import java.util.*;

public class Main {
    static char[] chars;
    static boolean[] used;
    static StringBuilder sb = new StringBuilder();

    static void dfs(int depth, int n) {
        if (depth == n) {
            System.out.println(sb);
            return;
        }
        for (int i = 0; i < n; i++) {
            // 剪枝1：已使用
            if (used[i]) continue;
            // 剪枝2：同层去重（相同字符只取第一个）
            if (i > 0 && chars[i] == chars[i - 1] && !used[i - 1]) continue;

            used[i] = true;
            sb.append(chars[i]);
            dfs(depth + 1, n);
            sb.deleteCharAt(sb.length() - 1);
            used[i] = false;
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = Integer.parseInt(sc.nextLine().trim());
        String[] parts = sc.nextLine().trim().split(" ");

        chars = new char[n];
        for (int i = 0; i < n; i++) chars[i] = parts[i].charAt(0);

        Arrays.sort(chars);   // 排序：相同字符相邻 + 保证字典序
        used = new boolean[n];
        dfs(0, n);
    }
}
```

> 💡 记忆口诀：**「去重排列 = 排序 + used + 同层剪枝」**——`chars[i] == chars[i-1] && !used[i-1]` 这行就是 LeetCode 47 的核心。
