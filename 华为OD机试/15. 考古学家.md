# 15. 考古学家

> **难度**：🟡 中等 | **分值**：200 | **标签**：回溯、排列 | **考点**：全排列 + 去重（LeetCode 47 变体）

## 题目描述

有一个考古学家发现一个石碑，可惜已经断裂成碎片。碎片上写着一些字符（可能**有重复**）。

考古学家想知道这些字符能组成**多少种不同的排列**（全排列，去重），请按**字典序**返回所有不重复的排列。

### 函数签名

```java
class Solution {
    public List<String> permuteUnique(char[] chars) {
        // ...
    }
}
```

---

## 示例

### 示例 1

```
输入：chars = ['a', 'b', 'c']
输出：["abc", "acb", "bac", "bca", "cab", "cba"]
```

### 示例 2（含重复字符）

```
输入：chars = ['a', 'a', 'b']
输出：["aab", "aba", "baa"]
```

**解释**：3 个字符共 6 种排列，去重后只剩 3 种。

---

## 提示

- `1 <= chars.length <= 8`
- `chars[i]` 为小写英文字母（可能有重复）
- 核心考点：**去重的全排列**（LeetCode 47 原题）。
- 去重两要素：**排序**（让相同字符相邻）+ **树层去重**（同层跳过相同字符）。
- 返回结果要求字典序 → 初始排序 + 回溯天然有序。

---

## 思路

### 核心思想

排序 + 回溯 + `used[]` 剪枝：

```
1. 字符排序（相同字符相邻，为去重做准备）
2. 回溯生成排列：
   - 第 i 层选择第 i 个字符
   - 剪枝：if (i > 0 && chars[i] == chars[i-1] && !used[i-1]) continue
     （同层相同字符只取第一个，避免重复排列）
3. 路径长度 == n → 收集结果
```

**为什么 `!used[i-1]` 能去重**：相同字符 a1、a2 相邻。当处理 a2 时，若 a1 还没被使用（说明 a1 在本层已经被跳过/即将被选择），选 a2 会和选 a1 产生相同排列 → 跳过 a2。这样保证**同一层只选一次相同字符**。

**逐步演示**（`a a b`）：

```
排序: [a, a, b]
第一层: 选 a1（跳过 a2 因为 a2==a1 且 a1 未用）
  ├ 第二层: 选 a2 → 第三层选 b → "aab"
  └ 第二层: 选 b  → 第三层选 a2 → "aba"
第一层(回溯后): 尝试 a2 → a2==a1 且 a1 未用 → 剪枝跳过
第一层: 选 b → 第二层选 a1 → 第三层选 a2 → "baa"
输出: aab / aba / baa ✓
```

- 时间复杂度：\(O(n \cdot n!)\)（排列总数）
- 空间复杂度：\(O(n)\)

### 解法（Java，回溯 + 去重）

```java
import java.util.*;

class Solution {
    public List<String> permuteUnique(char[] chars) {
        Arrays.sort(chars);                       // 排序：相同字符相邻 + 保证字典序
        int n = chars.length;
        boolean[] used = new boolean[n];
        StringBuilder path = new StringBuilder();
        List<String> result = new ArrayList<>();
        dfs(chars, used, path, result, 0, n);
        return result;
    }

    private void dfs(char[] chars, boolean[] used, StringBuilder path,
                     List<String> result, int depth, int n) {
        if (depth == n) {
            result.add(path.toString());
            return;
        }
        for (int i = 0; i < n; i++) {
            // 剪枝1：已使用
            if (used[i]) continue;
            // 剪枝2：同层去重（相同字符只取第一个）
            if (i > 0 && chars[i] == chars[i - 1] && !used[i - 1]) continue;

            used[i] = true;
            path.append(chars[i]);
            dfs(chars, used, path, result, depth + 1, n);
            path.deleteCharAt(path.length() - 1);
            used[i] = false;
        }
    }
}
```

### 解法二（成员变量风格）

```java
import java.util.*;

class Solution {
    private List<String> res = new ArrayList<>();  // 成员变量收集结果

    public List<String> permuteUnique(char[] chars) {
        res.clear();                                // 防止多次调用残留
        Arrays.sort(chars);
        boolean[] used = new boolean[chars.length];
        StringBuilder path = new StringBuilder();
        dfs(chars, used, path);
        return res;
    }

    private void dfs(char[] chars, boolean[] used, StringBuilder path) {
        if (path.length() == chars.length) {
            res.add(path.toString());
            return;
        }
        for (int i = 0; i < chars.length; i++) {
            // 剪枝1：已使用
            if (used[i]) continue;
            // 剪枝2：同层去重（相同字符只取第一个）
            if (i > 0 && chars[i] == chars[i - 1] && !used[i - 1]) continue;

            used[i] = true;
            path.append(chars[i]);
            dfs(chars, used, path);
            path.deleteCharAt(path.length() - 1);
            used[i] = false;
        }
    }
}
```

### 两种风格对比

| 对比维度 | 解法一（参数传递） | 解法二（成员变量） |
|---------|------------------|------------------|
| dfs 参数个数 | 6 个（chars, used, path, result, depth, n） | 3 个（chars, used, path） |
| 终止条件 | `depth == n` | `path.length() == chars.length` |
| 结果收集 | 写入传入的 `result` | 写入成员变量 `res` |
| 多次调用安全性 | 天然安全 | 需 `res.clear()` |
| 状态管理 | 自包含，无外部依赖 | 依赖成员变量，dfs 签名更简洁 |

> ⚠️ **成员变量风格的坑**：忘记 `res.clear()` 会导致同一实例多次调用时结果累加。LeetCode 判题每次 `new Solution()`，不会触发此问题；但本地测试或华为 OD 框架中复用实例时必须手动清空。

### 复杂度分析

- **时间复杂度**：\(O(n \cdot n!)\)，其中 \(n\) 为字符个数。最坏情况所有字符互不相同，共 \(n!\) 种排列，每种构造需 \(O(n)\)。
- **空间复杂度**：\(O(n)\)，递归栈深度与 `path`、`used` 数组均为 \(O(n)\)（不计返回结果占用的空间）。

> 💡 记忆口诀：**「去重排列 = 排序 + used + 同层剪枝」**——`chars[i] == chars[i-1] && !used[i-1]` 这行就是 LeetCode 47 的核心。
