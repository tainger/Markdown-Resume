# 16. 德州扑克

> **难度**：🟡 中等 | **分值**：200 | **标签**：模拟、哈希 | **考点**：牌型判断

## 题目描述

五张牌，每张牌由**牌面大小**和**花色**组成。牌面大小为 `2~10、J、Q、K、A`，花色为红桃、黑桃、梅花、方块四种之一。

给定长度为 5 的字符串数组 `cards`，每个元素格式为「牌面 + 花色」（如 `"A红桃"`、`"10红桃"`，花色为 2 个汉字）。判断这五张牌的**牌型**（按优先级从高到低）：

| 牌型 | 说明 | 编号 |
|:---|:---|:---|
| 同花顺 | 同一花色的顺子 | 1 |
| 四条 | 四张牌面大小相同 | 2 |
| 葫芦 | 三张相同 + 两张相同 | 3 |
| 同花 | 同一花色（不要求连续） | 4 |
| 顺子 | 五张连续（不要求同花色） | 5 |
| 三条 | 三张相同 + 两张不同 | 6 |
| 两对 | 两组对子 | 7 |
| 对子 | 只有一对 | 8 |
| 高牌 | 什么都不满足 | 9 |

返回牌型编号（1~9）。

## 提示

- `cards.length == 5`
- 牌面大小为 `2~10、J、Q、K、A`，花色为 `红桃`、`黑桃`、`梅花`、`方块` 之一
- 顺子判断：A 可以当 **1** 用（`A2345` 是最小顺子），也可以当 **14** 用（`10JQKA` 是最大顺子）。
- 判断顺序**必须从高到低**（先同花顺，最后高牌）。
- 建议把牌面映射为数值：2~10 → 2~10，J→11，Q→12，K→13，A→14。

---

## 思路

### 核心思想

解析 + 统计 + 按优先级判断：

```
1. 解析：牌面 → 数值（A=14），花色 → 字符串
2. 统计：所有牌是否同花？牌面是否连续（顺子）？
       牌面出现次数频次（用于 四条/葫芦/三条/两对/对子）
3. 从高到低依次判断：
   同花 && 顺子 → 1
   频次含 4     → 2
   频次 3+2     → 3
   同花         → 4
   顺子         → 5
   频次含 3     → 6
   频次两个 2   → 7
   频次一个 2   → 8
   否则         → 9
```

**顺子判定**：排序后 `max - min == 4` 且无重复；若含 A 时用 A=1 再判一次（处理 `A2345`）。

**逐步演示**（示例 2）：

```
牌: A红桃 A黑桃 A梅花 K红桃 K黑桃
数值: 14, 14, 14, 13, 13
频次: 14→3, 13→2
不是同花（红桃黑桃梅花混），不是顺子
频次含 3 且含 2 → 葫芦 → 输出 3 ✓
```

- 时间复杂度：\(O(1)\)（只有 5 张牌）
- 空间复杂度：\(O(1)\)

### 解法（Java）

```java
import java.util.*;

class Solution {
    private int toValue(String face) {
        switch (face) {
            case "J": return 11;
            case "Q": return 12;
            case "K": return 13;
            case "A": return 14;
            default:  return Integer.parseInt(face);
        }
    }

    private boolean isStraight(int[] nums) {
        // 标准顺子：max - min == 4 且无重复
        Set<Integer> set = new HashSet<>();
        int min = 15, max = 0;
        for (int x : nums) {
            if (!set.add(x)) return false;   // 有重复 → 不是顺子
            min = Math.min(min, x);
            max = Math.max(max, x);
        }
        if (max - min == 4) return true;
        // 处理 A2345：把 14 换成 1 再判断
        for (int i = 0; i < 5; i++) {
            if (nums[i] == 14) nums[i] = 1;
        }
        set.clear();
        min = 15; max = 0;
        for (int x : nums) {
            if (!set.add(x)) return false;
            min = Math.min(min, x);
            max = Math.max(max, x);
        }
        return max - min == 4;
    }

    public int handType(String[] cards) {
        int[] nums = new int[5];
        String firstSuit = "";
        boolean sameSuit = true;

        Map<Integer, Integer> freq = new HashMap<>();
        for (int i = 0; i < 5; i++) {
            String card = cards[i];
            String face = card.substring(0, card.length() - 2);
            String suit = card.substring(card.length() - 2); // 如 "红桃"
            nums[i] = toValue(face);
            if (i == 0) firstSuit = suit;
            else if (!suit.equals(firstSuit)) sameSuit = false;
            freq.put(nums[i], freq.getOrDefault(nums[i], 0) + 1);
        }

        boolean straight = isStraight(nums.clone());
        boolean flush = sameSuit;

        // 统计频次分布
        int pair = 0, three = 0, four = 0;
        for (int c : freq.values()) {
            if (c == 2) pair++;
            if (c == 3) three++;
            if (c == 4) four++;
        }

        int type;
        if (flush && straight)      type = 1;  // 同花顺
        else if (four == 1)         type = 2;  // 四条
        else if (three == 1 && pair == 1) type = 3; // 葫芦
        else if (flush)             type = 4;  // 同花
        else if (straight)          type = 5;  // 顺子
        else if (three == 1)        type = 6;  // 三条
        else if (pair == 2)         type = 7;  // 两对
        else if (pair == 1)         type = 8;  // 对子
        else                        type = 9;  // 高牌

        return type;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(1)\)，固定 5 张牌，所有解析、统计、判断均为常数次操作。
- **空间复杂度**：\(O(1)\)，仅使用大小固定的数组与哈希表。

> 💡 常见坑：
> 1. **A 的双重身份**：`A2345` 是最小顺子，记得把 A=14 换成 1 再判一次；
> 2. 判断顺序必须从高到低，否则「同花顺」会被判成「顺子」；
> 3. 牌面解析注意「10红桃」是 2 个字符的牌面 + 2 个字符的花色，用长度截取而不是 `charAt(0)`。
