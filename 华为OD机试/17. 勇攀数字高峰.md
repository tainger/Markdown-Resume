# 17. 勇攀数字高峰

> **难度**：🟡 中等 | **分值**：100 | **卷次**：新系统 2026-04-01 | **标签**：DFS、回溯 | **考点**：网格路径计数

## 题目描述

你在给定的**数字地形图**中寻找登山路径，图中每个数字代表当前位置的**海拔高度**。你需要从**最低点**（海拔最低的格子）爬到**最高点**（海拔最高的格子）。

移动规则：

- 只能**上下左右**移动（四方向）；
- 每步移动的**高度差绝对值 ≤ 单步最大高度差 k**；
- 不能重复经过同一个格子；
- 必须从最低点出发，到达最高点（最高点与最低点都唯一时）。

求**所有可行路径的数量**（成功登顶的次数）。

**函数签名**：

```java
// grid[i][j] 为海拔高度，k 为单步最大高度差
// 返回从最低点到最高点的可行路径数
public int countPaths(int[][] grid, int k)
```

## 示例

```
输入：
grid = [[4, 3],
        [3, 2]],  k = 1
输出：
2
```

**解释**：

```
最低点: (1,1) 海拔 2；最高点: (0,0) 海拔 4；单步最大高度差 1

路径1: (1,1) → (0,1) → (0,0)    2 → 3 → 4   每步差 1 ✓
路径2: (1,1) → (1,0) → (0,0)    2 → 3 → 4   每步差 1 ✓

共 2 条 ✓
```

---

## 提示

- 起点 = 海拔**最低**的格子，终点 = 海拔**最高**的格子（各唯一）。
- 每步高度差取**绝对值**（可上可下），不超过 k。
- 用 `visited[][]` 防止重复走；回溯时记得撤销。
- 路径数可能很大，注意数据范围。

---

## 思路

### 核心思想

**DFS + 回溯**，统计所有可行路径：

```
1. 扫描 grid 找最低点 (start) 和最高点 (end)
2. dfs(x, y):
   - 到达终点 → ans++
   - 四方向探索：不越界、未访问、|height[next] - height[cur]| <= k
   - 进入前标记 visited，退出后撤销（回溯）
```

**为什么不能简单去重**：题目要求**路径计数**（每条合法路径都算一次），所以需要回溯枚举所有路径，而不是只标记可达。

**逐步演示**（示例）：

```
起点 (1,1)=2 → 终点 (0,0)=4, k=1

(1,1) 的邻居: (0,1)=3 差1 ✓ | (1,0)=3 差1 ✓ | (0,1) 和 (1,0) 又都能到 (0,0)=4 差1 ✓
→ 2 条路径 ✓
```

- 时间复杂度：\(O(4^{n \cdot m})\)（最坏回溯全枚举，网格小则可行）
- 空间复杂度：\(O(n \cdot m)\)

### 解法（Java，DFS + 回溯）

```java
class Solution {
    int[][] grid;
    boolean[][] visited;
    int k, m, n;
    int ans = 0;
    int[] dx = {0, 0, 1, -1};
    int[] dy = {1, -1, 0, 0};

    void dfs(int x, int y, int ex, int ey) {
        if (x == ex && y == ey) {   // 到达最高点
            ans++;
            return;
        }
        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d], ny = y + dy[d];
            if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
            if (visited[nx][ny]) continue;
            if (Math.abs(grid[nx][ny] - grid[x][y]) > k) continue; // 高度差超限

            visited[nx][ny] = true;
            dfs(nx, ny, ex, ey);
            visited[nx][ny] = false;   // 回溯
        }
    }

    public int countPaths(int[][] grid, int k) {
        this.grid = grid;
        this.k = k;
        this.m = grid.length;
        this.n = grid[0].length;
        visited = new boolean[m][n];

        int sx = 0, sy = 0, ex = 0, ey = 0;
        int minH = Integer.MAX_VALUE, maxH = Integer.MIN_VALUE;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] < minH) { minH = grid[i][j]; sx = i; sy = j; }
                if (grid[i][j] > maxH) { maxH = grid[i][j]; ex = i; ey = j; }
            }
        }

        visited[sx][sy] = true;
        dfs(sx, sy, ex, ey);
        return ans;
    }
}
```

> 💡 记忆：**「路径计数」→ DFS + 回溯（visited 撤销）；「是否可达/最短」→ BFS 或 visited 不撤销的 DFS**，两者别混。
>
> ⚠️ 若题目版本中「最低点/最高点」不唯一，需要枚举所有最低点出发、所有最高点收束，计数规则以题意为准。
