# 18. 准备生日礼物（2026 新系统）

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-04-08 | **标签**：哈希表 | **考点**：覆盖式去重

## 题目描述

小明在一个充满人文关怀的公司上班，公司每个月都要为该月生日的同事送一份生日小礼物，该事项由小明负责。请帮助小明统计**某一月份应该准备多少份礼物**。

已知信息：

- 员工的生日信息可能被**重复录入**，**重复录入的员工生日以最后一次录入结果为准**；
- 员工列表与生日列表一一对应。

> 新系统（力扣模式）：无需处理输入输出，直接实现函数。

**函数签名**：

```java
// month: 要发放礼物的月份（1 ~ 12）
// employees: 员工列表（字符串数组）
// birthdays: 员工生日列表（与 employees 一一对应，格式为月份或日期）
// 返回该月应准备的礼物数量
public int countGifts(int month, String[] employees, String[] birthdays)
```

## 示例

```
输入：
month = 5
employees = ["Alice", "Bob", "Carol", "Alice"]
birthdays = [5, 5, 5, 7]
输出：
2
```

**解释**：

```
Alice 第一次录入生日 5 月，第二次录入 7 月 → 以最后一次为准：Alice 生日 = 7 月
Bob  生日 = 5 月
Carol 生日 = 5 月
5 月份生日的员工: Bob、Carol → 共 2 人 ✓
```

---

## 提示

- **覆盖式去重**：同一个员工出现多次，只保留最后一次的生日。
- 生日可能给月份（如 `5`），也可能给完整日期（如 `05-12`），统计时取月份。
- 输出的是**人数**，不是记录条数。

---

## 思路

### 核心思想

**HashMap 覆盖写入**：

```
1. 遍历员工列表：
   map.put(员工名, 该员工本次生日月份)   // 自动覆盖旧记录
2. 遍历 map 的 value：
   统计 == 目标月份 的个数
```

**为什么覆盖就够**：题目要求「以最后一次录入为准」，`put` 天然覆盖同名 key 的旧值，无需手动去重逻辑。

**逐步演示**（示例）：

```
录入: Alice→5, Bob→5, Carol→5, Alice→7
map:  {Alice: 7, Bob: 5, Carol: 5}    ← Alice 被覆盖为 7
统计 == 5: Bob、Carol → 2 ✓
```

- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(n)\)

### 解法（Java）

```java
import java.util.*;

public class Main {
    // 从生日字符串/数字中提取月份
    static int monthOf(String birthday) {
        if (birthday.contains("-")) {
            return Integer.parseInt(birthday.split("-")[0]); // "05-12" → 5
        }
        return Integer.parseInt(birthday);                    // "5" → 5
    }

    public int countGifts(int month, String[] employees, String[] birthdays) {
        Map<String, Integer> last = new HashMap<>();
        for (int i = 0; i < employees.length; i++) {
            last.put(employees[i], monthOf(birthdays[i]));   // 覆盖旧记录
        }

        int count = 0;
        for (int m : last.values()) {
            if (m == month) count++;
        }
        return count;
    }
}
```

> 💡 记忆：**「重复录入以最后一次为准」= HashMap 覆盖式 put**，最简单也最不容易错。
>
> ⚠️ 若生日给的是完整日期（如 `2026-05-12`），提取月份时 `split("-")[1]`（中间段），以题目格式为准。
