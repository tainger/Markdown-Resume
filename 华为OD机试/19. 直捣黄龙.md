# 19. 直捣黄龙（2026 新系统）

> **难度**：🔴 困难 | **分值**：200 | **卷次**：新系统 2026-04-08 | **标签**：BFS | **考点**：最短路径 + 路径计数

## 题目描述

小王在玩一款叫做「直捣黄龙」的小游戏：他从**入口**位置进入敌营，需要绕过哨兵的层层封锁，到达**敌军司令部**执行斩首行动。

地图是一个 **M × N 的网格**：

- `S`：入口（起点）
- `E`：敌军司令部（终点）
- `#`：哨兵/封锁区（不可走）
- `.`：空地（可走）
- 只能**上下左右**移动，每步耗时相等（1 个单位时间）

求从入口到司令部的最短路径中，一共有**多少条不同的最短路径**。

> 新系统（力扣模式）：无需处理输入输出，直接实现函数。
>
> ⚠️ 具体输入/输出细节随版本有差异（有的版本输出「最短时间 + 路径条数」），核心算法一致。

**函数签名**：

```java
// grid: 地图（'S' 起点，'E' 终点，'#' 障碍，'.' 空地）
// 返回从 S 到 E 的最短路径条数；不可达返回 0
public int countShortestPaths(char[][] grid)
```

## 示例

```
输入：
grid = [
  ['S', '.', '.'],
  ['#', '#', '.'],
  ['.', '.', 'E']
]
输出：
1
```

**解释**：唯一最短路径 `(0,0) → (0,1) → (0,2) → (1,2) → (2,2)`，长度 4 → 1 条。

**示例 2**（多条最短路径）

```
输入：
grid = [
  ['S', '.', '.'],
  ['.', '.', 'E']
]
输出：
3
```

**解释**：从 (0,0) 到 (1,2) 的最短距离为 3，共 3 条：

```
路径1: (0,0) → (1,0) → (1,1) → (1,2)
路径2: (0,0) → (0,1) → (1,1) → (1,2)
路径3: (0,0) → (0,1) → (0,2) → (1,2)
```

（每步向下或向右，恰好 3 步到达）→ 输出 3 ✓

---

## 提示

- 网格 BFS 天然给出**最短路径长度**；
- 要数**条数**，BFS 时不能简单用 visited 布尔，要额外记录：
  - `dist[x][y]`：起点到该点的最短距离；
  - `count[x][y]`：起点到该点的最短路径条数；
- 同层到达（`dist[nx][ny] == dist[x][y] + 1`）时**累加**条数；首次到达时**继承**条数。

---

## 思路

### 核心思想

**BFS + 路径计数**（在经典 BFS 上增加 `count[][]` 数组）：

```
dist[x][y]  = 起点到 (x,y) 的最短距离（初始 -1）
count[x][y] = 起点到 (x,y) 的最短路径条数（初始 0，起点为 1）

BFS 扩展 (x,y) → (nx,ny)：
  1. dist[nx][ny] == -1（首次到达）
     → dist[nx][ny] = dist[x][y] + 1; count[nx][ny] = count[x][y]; 入队
  2. dist[nx][ny] == dist[x][y] + 1（同层再次到达）
     → count[nx][ny] += count[x][y]   ← 关键：累加而不是覆盖
  3. 其他情况跳过
```

**为什么示例 2 是 3 条**：从 (0,0) 到 (1,2)，最短距离 = 3（1 步向下 + 2 步向右，顺序任意），`C(3,1) = 3` 种走法恰好对应 3 条最短路径。BFS 的 `count[][]` 累加会自动数出这个数——**最短路径条数只统计距离恰好等于最短距离的路径**，`count[E]` 即为答案。

**逐步演示**（示例 1）：

```
dist 初始化: 起点 (0,0) dist=0, count=1

(0,0) → (0,1): 首次到达, dist=1, count=1
(0,1) → (0,2): dist=2, count=1
(0,2) → (1,2): dist=3, count=1
(1,2) → (2,2): dist=4, count=1
(2,2) 是 'E' → count = 1 ✓
```

- 时间复杂度：\(O(M \times N)\)
- 空间复杂度：\(O(M \times N)\)

### 解法（Java，BFS + 计数）

```java
import java.util.*;

public class Main {
    public int countShortestPaths(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        int sx = 0, sy = 0, ex = 0, ey = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 'S') { sx = i; sy = j; }
                if (grid[i][j] == 'E') { ex = i; ey = j; }
            }
        }

        int[][] dist = new int[m][n];
        long[][] count = new long[m][n];
        for (int[] row : dist) Arrays.fill(row, -1);

        int[] dx = {0, 0, 1, -1};
        int[] dy = {1, -1, 0, 0};

        Queue<int[]> queue = new ArrayDeque<>();
        dist[sx][sy] = 0;
        count[sx][sy] = 1;
        queue.offer(new int[]{sx, sy});

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int x = cur[0], y = cur[1];
            for (int d = 0; d < 4; d++) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                if (grid[nx][ny] == '#') continue;          // 哨兵/障碍

                if (dist[nx][ny] == -1) {                   // 首次到达
                    dist[nx][ny] = dist[x][y] + 1;
                    count[nx][ny] = count[x][y];            // 继承条数
                    queue.offer(new int[]{nx, ny});
                } else if (dist[nx][ny] == dist[x][y] + 1) {
                    count[nx][ny] += count[x][y];           // 同层累加
                }
            }
        }
        return (int) count[ex][ey];
    }
}
```

> 💡 要点：**「最短路径条数」= BFS + dist 分层 + count 继承/累加**。区分「首次到达（继承）」和「同层再次到达（累加）」是关键，用 `long` 防溢出。
>
> ⚠️ 若题目还要求输出最短时间，直接输出 `dist[E]` 即可。
