# 2. 磁盘容量排序

> **难度**：🟢 简单 | **分值**：100 | **标签**：字符串解析、排序 | **考点**：稳定排序

## 题目描述

磁盘的容量单位常用的有 **M、G、T** 三个等级，换算关系为：

- \(1T = 1024G\)
- \(1G = 1024M\)

现在给定容量字符串数组 `caps`（每个字符串可能为**复合单位**，如 `3M12G9M`），请对它们按从小到大的顺序进行**稳定排序**，返回排序后的容量数组。

### 函数签名

```java
class Solution {
    public String[] sortDisks(String[] caps) {
        // ...
    }
}
```

---

## 示例

### 示例 1

```
输入：caps = ["1T", "20M", "3G"]
输出：["20M", "3G", "1T"]
```

**解释**：统一换算为 MB 后：`1T = 1048576`、`20M = 20`、`3G = 3072`，排序为 `20M < 3G < 1T`。

---

## 提示

- `1 <= caps.length <= 1000`
- 容量可能是复合形式，如 `3M12G9M`（= 3 + 12×1024 + 9×1024×1024）
- 容量相等时保持**输入顺序**（稳定排序）
- 换算结果可能超过 `int` 范围，用 `long`

---

## 思路

### 核心思想

把每个容量字符串**解析为统一单位（MB）**，再用自定义比较器排序：

```
解析规则（从左到右扫描）：
  数字部分累积 num
  遇到字母 M/G/T → 按单位换算累加到 total，num 清零
    M: ×1
    G: ×1024
    T: ×1024×1024

排序：total 从小到大；total 相同 → 按输入下标（稳定）
```

**逐步演示**（`10G6T`）：

```
扫描: 10 → 遇到 G → total += 10 × 1024 = 10240
     6  → 遇到 T → total += 6 × 1024 × 1024 = 6291456
total = 6301696 MB
```

### 为什么必须稳定排序

- Java 的 `Arrays.sort` 对**对象数组**是稳定排序（TimSort），对基本类型数组不稳定。
- 若手动实现排序，需在比较器里加「按下标升序」作为第二关键字，保证容量相等时顺序不变。

- 时间复杂度：\(O(n \log n)\)
- 空间复杂度：\(O(n)\)

### 解法（Java）

```java
import java.util.*;

class Solution {
    // 解析容量字符串 → MB（long）
    private long parse(String s) {
        long total = 0;
        long num = 0;
        for (char c : s.toCharArray()) {
            if (c >= '0' && c <= '9') {
                num = num * 10 + (c - '0');
            } else {
                switch (c) {
                    case 'M': total += num * 1L;                    break;
                    case 'G': total += num * 1024L;                 break;
                    case 'T': total += num * 1024L * 1024L;         break;
                }
                num = 0;
            }
        }
        return total;
    }

    public String[] sortDisks(String[] caps) {
        int n = caps.length;
        // 对象数组排序（TimSort 稳定），比较器以容量为主、下标为辅
        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) idx[i] = i;
        Arrays.sort(idx, (i, j) -> {
            long diff = parse(caps[i]) - parse(caps[j]);
            if (diff != 0) return diff > 0 ? 1 : -1;
            return i - j; // 容量相同 → 保持输入顺序
        });

        String[] result = new String[n];
        for (int i = 0; i < n; i++) {
            result[i] = caps[idx[i]];
        }
        return result;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n \log n)\)，排序主导；每次比较调用 `parse` 是 \(O(L)\)，可预先计算每个容量的 MB 值优化到 \(O(nL + n \log n)\)。
- **空间复杂度**：\(O(n)\)，下标数组与结果数组。

> 💡 直接对 `caps` 排序也可以（`Arrays.sort(caps, comparator)` 对对象数组稳定），但按 `idx` 排序更直观地体现了「稳定」这一考点。
