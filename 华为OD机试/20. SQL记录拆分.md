# 20. SQL记录拆分

> **难度**：🟡 中等 | **分值**：100 | **卷次**：新系统 2026-07（7.1/7.5 场次） | **标签**：并查集、贪心 | **考点**：传递约束合并 + 装箱

## 题目描述

某分布式数据库系统需要将 SQL 操作日志拆分到多个文件中。给定单个文件可保存的最大 SQL 语句行数 `split_line`，以及 SQL 语句数组 `sql_text`，请按规则将 SQL 语句拆分到不同文件中，返回**拆分后的文件数量**。

拆分规则：

1. **整行不可拆**：单个数组成员的 SQL 语句（可能含多条，按 `;` 分隔）必须作为同一行完整保存在同一文件中，不可跨文件拆分；
2. **事务绑定**：部分语句带事务标签 `[Tn]`（n 为正整数），如 `[T1]A;`，**相同事务标签的语句必须保存于同一文件中**；
3. **顺序贪心**：按语句组**首次出现的行号顺序**处理，优先放入当前文件，放入后超出 `split_line` 限制则新建文件；
4. **约束传递**：若 A 与 B 必须同文件、B 与 C 必须同文件，则 A、B、C 必须同一文件；约束合并后语句组计数**即便超过限制也必须放在同一文件**；
5. SQL 数组为空时返回 **0**。

**补充**：

- `split_line` 取值范围 [1, 10000]，无效值返回 0；
- `sql_text` 每行最多 1000 字符，总语句最多 100000 条，事务标签范围 [1, 1000]；
- 最后一条语句可以没有分号结尾；空语句（仅含分号）按 1 行计算。

## 示例

**示例 1**

```
输入：
split_line = 3
sql_text = ["[T1]A;[T2]B;", "[T1]C;"]
输出：
1
```

**解释**：

```
行0 含 [T1]A 和 [T2]B → 该行同时属于 T1、T2 事务
行1 含 [T1]C → 属于 T1
传递约束下 行0、行1 同组 = 2 行 ≤ 3 → 1 个文件 ✓
```

**示例 2**

```
输入：
split_line = 2
sql_text = ["[T1]A;", "[T2]B;", "[T1]C;", "[T2]D;"]
输出：
2
```

**解释**：

```
T1 组: 行 {0, 2} 共 2 行；T2 组: 行 {1, 3} 共 2 行
T1 首次出现在行0 → 先放入文件1（2 行 = 上限）
T2 放入会超 2 行 → 新建文件2（2 行）
共 2 个文件 ✓
```

## 提示

- 行（数组成员）是绑定和装箱的**最小单位**，一行即使含多条语句也只算 **1 行**；
- 一行含多个 tag 时，它把这些 tag 的组**全部连在一起**；
- 「同文件约束传递」= 并查集；
- 装箱顺序：按每组**最小行号**排序，贪心装入当前文件。

---

## 思路

### 核心思想

**并查集合并绑定关系 → 按首次出现顺序贪心装箱**：

```
1. 解析每行中的所有 [Tn] 标签
2. 对每个 tag：把它涉及的所有行号 union 到一起（并查集，自动处理传递）
3. 按并查集根节点分组；组大小 = 行数；组首次出现行号 = 组内最小行号
4. 按首次出现行号升序，贪心装箱：
   当前文件剩余空间 >= 组大小 → 装入
   否则 → 新建文件
```

**为什么需要并查集而不是直接分组**：同一行可能带多个 tag，这些 tag 的行集合通过该行互相牵连（示例 1 中 T1、T2 因行 0 被合并），并查集天然处理这种**传递性**。

**逐步演示**（示例 2）：

```
解析 tag:
  T1: {0, 2}   T2: {1, 3}
union 后两组独立: 组A(首次行号0, 大小2), 组B(首次行号1, 大小2)

装箱 (split_line=2):
  组A → 文件1 (2/2)
  组B → 放不下 → 文件2 (2/2)
答案 = 2 ✓
```

- 时间复杂度：\(O(n)\)（并查集近乎常数；解析每行需扫语句）
- 空间复杂度：\(O(n)\)

### 解法（Java，并查集 + 贪心装箱）

```java
import java.util.*;

class Solution {
    static class DSU {
        int[] parent;
        DSU(int n) {
            parent = new int[n];
            for (int i = 0; i < n; i++) parent[i] = i;
        }
        int find(int x) {
            while (parent[x] != x) {
                parent[x] = parent[parent[x]];  // 路径压缩
                x = parent[x];
            }
            return x;
        }
        void union(int a, int b) { parent[find(a)] = find(b); }
    }

    public int splitLogs(int splitLine, String[] sqlText) {
        if (splitLine < 1 || splitLine > 10000) return 0; // 无效值
        int n = sqlText.length;
        if (n == 0) return 0;                              // 空数组

        DSU dsu = new DSU(n);
        // tag → 该 tag 涉及的行号集合
        Map<Integer, Integer> tagFirstRow = new HashMap<>();

        for (int i = 0; i < n; i++) {
            String line = sqlText[i];
            // 用正则提取所有 [Tn] 标签（也可手动扫描）
            java.util.regex.Matcher m =
                java.util.regex.Pattern.compile("\\[T(\\d+)\\]").matcher(line);
            while (m.find()) {
                int tag = Integer.parseInt(m.group(1));
                if (tagFirstRow.containsKey(tag)) {
                    // 同 tag 的行必须同文件 → union
                    dsu.union(tagFirstRow.get(tag), i);
                } else {
                    tagFirstRow.put(tag, i);
                }
            }
        }

        // 分组: 根 → 组信息(大小, 最小行号)
        Map<Integer, int[]> groups = new HashMap<>(); // root -> {size, firstRow}
        for (int i = 0; i < n; i++) {
            int root = dsu.find(i);
            int[] g = groups.get(root);
            if (g == null) groups.put(root, new int[]{1, i});
            else { g[0]++; g[1] = Math.min(g[1], i); }
        }

        // 按首次出现行号排序
        List<int[]> list = new ArrayList<>(groups.values());
        list.sort((a, b) -> a[1] - b[1]);

        // 贪心装箱
        int files = 0, used = 0;
        for (int[] g : list) {
            if (g[0] > splitLine) {            // 组本身超限也必须同文件
                files++;                       // 独占一个文件
                used = 0;
                continue;
            }
            if (used + g[0] > splitLine) {     // 放不下 → 新开文件
                files++;
                used = g[0];
            } else {
                if (used == 0) files++;        // 首次使用也要算一个文件
                used += g[0];
            }
        }
        return files;
    }
}
```

> 💡 记忆：**「同文件约束传递」→ 并查集；「按组顺序装箱」→ 贪心**。一行带多个 tag = 多个组的**粘合剂**。
>
> ⚠️ 分组后若组大小 > split_line，规则 4 要求仍然同文件，直接独占一个文件即可（本解已处理）。
