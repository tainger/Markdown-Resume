# 2025-01. 字符串序列判定（2025 B/C 卷）

> **难度**：🟢 简单 | **分值**：100 | **卷次**：2025 B 卷 / C 卷 | **标签**：字符串、双指针 | **考点**：子序列判定

## 题目描述

输入两个字符串 `S` 和 `L`，都只包含英文小写字母。判定 `S` 是否是 `L` 的**有效子序列**。

判定规则：`S` 中的每个字符都能在 `L` 中找到（可以不连续），且这些字符在 `L` 中出现的**前后顺序**与在 `S` 中的顺序保持一致。

- 例：`S = "ace"` 是 `L = "abcde"` 的子序列（有效字符 a、c、e）；而 `"aec"` 不是。

**输出**：`S` 串**最后一个有效字符**在 `L` 中的位置（下标从 0 开始）；若 `S` 不是 `L` 的子序列，返回 **-1**。

约束：

- `S` 长度 ≤ 100，`L` 长度 ≤ 500000（`L` 很长，算法要线性）。

> 老系统需自行读入两行字符串；新系统（力扣模式）直接实现函数。

**函数签名**：

```java
// S: 待判定的短串；L: 主串
// 返回 S 最后一个有效字符在 L 中的下标；不是子序列返回 -1
public int lastValidIndex(String S, String L)
```

## 示例

**示例 1**

```
输入：
S = "ace", L = "abcde"
输出：
4
```

**解释**：a→下标0，c→下标2，e→下标4，顺序一致，最后一个有效字符 e 在下标 4。

**示例 2**

```
输入：
S = "fgh", L = "abcde"
输出：
-1
```

**解释**：f 在 L 中就找不到，`S` 不是子序列，返回 -1。

---

## 提示

- 经典**子序列判定**：双指针一次遍历 `L` 即可，`O(|L|)`。
- 只需顺序匹配，不要求连续，所以不匹配时只移动 `L` 的指针。
- 记录最后一次成功匹配时 `L` 的下标即为答案。

---

## 思路

### 核心思想

**双指针（贪心匹配）**：`i` 扫 `S`，`j` 扫 `L`。只要 `S[i] == L[j]` 就说明 `S` 的第 `i` 个字符在此处匹配成功，`i++` 并记下当前 `j` 为「最后有效位置」；无论是否匹配，`j` 都 `j++` 继续往后找。

- 遍历结束后，若 `i` 走到了 `S` 的末尾（`i == S.length()`），说明 `S` 的所有字符都按序匹配上了 → 返回记录的最后位置；
- 否则 `S` 还有字符没匹配到 → 返回 -1。

> 贪心正确性：对子序列匹配，`S[i]` 在 `L` 中**越早匹配越好**（给后续字符留更多空间），所以从左到右遇到就匹配一定不会漏掉可行解。

**逐步演示**（`S = "ace"`, `L = "abcde"`）：

```
j=0 L[0]=a == S[0]=a ✓  i→1, last=0
j=1 L[1]=b != S[1]=c    j++
j=2 L[2]=c == S[1]=c ✓  i→2, last=2
j=3 L[3]=d != S[2]=e    j++
j=4 L[4]=e == S[2]=e ✓  i→3, last=4
i==3==S.length → 返回 last = 4 ✓
```

- 时间复杂度：\(O(|L|)\)
- 空间复杂度：\(O(1)\)

### 解法（Java，双指针）

```java
public class Main {
    public int lastValidIndex(String S, String L) {
        int i = 0, last = -1;
        for (int j = 0; j < L.length() && i < S.length(); j++) {
            if (S.charAt(i) == L.charAt(j)) {
                last = j;   // 记录第 i 个字符匹配到的位置
                i++;        // S 指针前移
            }
        }
        // i 走完 S 才说明是有效子序列
        return i == S.length() ? last : -1;
    }
}
```

**老系统输入输出版**（若考的是 ACM 模式）：

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String S = sc.nextLine();
        String L = sc.nextLine();
        int i = 0, last = -1;
        for (int j = 0; j < L.length() && i < S.length(); j++) {
            if (S.charAt(i) == L.charAt(j)) { last = j; i++; }
        }
        System.out.println(i == S.length() ? last : -1);
    }
}
```

> 💡 记忆：**子序列判定 = 双指针贪心**，短串指针只在匹配时前移，长串指针一路走到底。
>
> ⚠️ 易错：① `S` 为空时按题意一般返回 -1（无有效字符），本实现 `i==0==S.length()` 会返回 `last=-1`，符合；② 返回的是**下标**不是长度；③ `L` 达 50 万，别用 `O(|S|·|L|)` 的暴力查找。
