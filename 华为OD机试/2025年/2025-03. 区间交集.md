# 2025-03. 区间交集（2025 B 卷）

> **难度**：🟡 中等 | **分值**：200 | **卷次**：2025 B 卷 | **标签**：区间、排序、模拟 | **考点**：两两求交集 + 区间合并

## 题目描述

给定一组**闭区间**，其中部分区间存在交集。

- 任意**两个**给定区间的交集，称为**公共区间**（如 `[1,2]` 与 `[2,3]` 的公共区间为 `[2,2]`；`[3,5]` 与 `[3,6]` 的公共区间为 `[3,5]`）。
- 公共区间之间若又存在交集，则需要**合并**（如 `[1,3]` 与 `[3,5]` 存在交集 `[3,3]`，需合并为 `[1,5]`）。

按**升序**排列输出合并后的公共区间列表。

约束与约定：

- `0 ≤ N ≤ 1000`；每个端点 `-10000 ≤ X ≤ 10000`。
- **单个区间**认定为无公共区间。
- 若没有任何公共区间，输出 `None`。

> ⚠️ 注意：本题不是「把原始区间合并」，而是**先求所有两两交集，再对这些交集做合并**。两者结果不同（见示例 2）。

> 老系统：第一行 N，接下来 N 行每行两个整数；输出每行一个区间。

**函数签名（新系统抽象）**：

```java
// intervals: N 个闭区间 [l, r]
// 返回合并后的公共区间列表（升序）；无公共区间返回空列表（老系统打印 None）
public List<int[]> intervalIntersection(int[][] intervals)
```

## 示例

**示例 1**

```
输入：
4
0 3
1 3
3 5
3 6
输出：
1 5
```

**解释**：两两交集有 `[1,3] [3,3] [3,5] [0,3]∩[3,6]=[3,3]` 等，这些交集彼此连通，合并为 `[1,5]`。

**示例 2**

```
输入：
4
0 3
1 4
4 7
5 8
输出：
1 3
4 4
5 7
```

**解释**：
- `[0,3]∩[1,4]=[1,3]`；`[1,4]∩[4,7]=[4,4]`；`[4,7]∩[5,8]=[5,7]`；其余两两无交集。
- 三个交集 `[1,3] [4,4] [5,7]` 互不重叠，各自成段输出。

**示例 3**

```
输入：
2
1 2
3 4
输出：
None
```

**解释**：仅有的两个区间无交集，无公共区间 → `None`。

## 提示

- 两区间 `[a1,b1]`、`[a2,b2]` 有交集 ⇔ `max(a1,a2) <= min(b1,b2)`，交集即 `[max(a1,a2), min(b1,b2)]`。
- N ≤ 1000，两两枚举 `O(N²)` 完全可接受。
- 求出所有交集后，做**标准区间合并**：按左端点排序，能接上就并，否则新起一段。

---

## 思路

### 核心思想

**两步走：先两两求交集，再合并交集**。

```
第 1 步：枚举所有 i<j 对，若相交则收集交集 [max(li,lj), min(ri,rj)]
第 2 步：对交集列表做经典区间合并
        - 按左端点升序排序
        - 依次扫描：若当前左端点 <= 已合并段的右端点 → 扩展右端点
                    否则 → 结束上一段，开新段
第 3 步：交集列表为空 → 输出 None
```

**区间合并的边界**：本题是闭区间，`[1,3]` 与 `[3,5]` 在端点 3 处相接也算相交（合并成 `[1,5]`），所以判定用 `cur[0] <= last[1]`（含等号）。

**逐步演示**（示例 2）：

```
原始: [0,3] [1,4] [4,7] [5,8]
两两交集:
  [0,3]∩[1,4] = [1,3] ✓
  [0,3]∩[4,7] : max(0,4)=4 > min(3,7)=3 → 无
  [1,4]∩[4,7] = [4,4] ✓
  [4,7]∩[5,8] = [5,7] ✓
交集列表排序: [1,3] [4,4] [5,7]
合并: [1,3] 与 [4,4]：4 > 3 不接 → 新段
      [4,4] 与 [5,7]：5 > 4 不接 → 新段
输出: 1 3 / 4 4 / 5 7 ✓
```

- 时间复杂度：\(O(N^2 + M\log M)\)，M 为交集数量（最多 \(O(N^2)\)）
- 空间复杂度：\(O(N^2)\)（存交集）

### 解法（Java，两两交集 + 合并）

```java
import java.util.*;

public class Main {
    public List<int[]> intervalIntersection(int[][] intervals) {
        int n = intervals.length;
        List<int[]> inter = new ArrayList<>();
        // 第 1 步：枚举所有两两组合求交集
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int lo = Math.max(intervals[i][0], intervals[j][0]);
                int hi = Math.min(intervals[i][1], intervals[j][1]);
                if (lo <= hi) inter.add(new int[]{lo, hi});   // 相交才收集
            }
        }
        if (inter.isEmpty()) return new ArrayList<>();        // 无公共区间

        // 第 2 步：标准区间合并
        inter.sort((a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
        List<int[]> res = new ArrayList<>();
        int[] cur = inter.get(0);
        for (int k = 1; k < inter.size(); k++) {
            int[] iv = inter.get(k);
            if (iv[0] <= cur[1]) {                 // 闭区间相接也合并
                cur[1] = Math.max(cur[1], iv[1]);
            } else {
                res.add(cur);
                cur = iv;
            }
        }
        res.add(cur);
        return res;
    }

    // 老系统入口：读入 + 打印
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = Integer.parseInt(sc.nextLine().trim());
        int[][] arr = new int[n][2];
        for (int i = 0; i < n; i++) {
            String[] p = sc.nextLine().trim().split("\\s+");
            arr[i][0] = Integer.parseInt(p[0]);
            arr[i][1] = Integer.parseInt(p[1]);
        }
        List<int[]> res = new Main().intervalIntersection(arr);
        if (res.isEmpty()) {
            System.out.println("None");
        } else {
            StringBuilder sb = new StringBuilder();
            for (int[] iv : res) sb.append(iv[0]).append(' ').append(iv[1]).append('\n');
            System.out.print(sb);
        }
    }
}
```

> 💡 记忆：**两两交集 → 再合并**。交集公式 `[max(左), min(右)]`，`max左 <= min右` 才相交；合并阶段闭区间用 `<=` 判相接。
>
> ⚠️ 易错：① 别直接对原区间合并（那是另一道题），本题要先求两两交集；② N≤1 时无公共区间输出 `None`；③ 闭区间端点相接（如 3 与 3）算相交，判定含等号；④ 输出要按升序。
