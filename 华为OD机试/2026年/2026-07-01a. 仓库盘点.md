# 2026-07-01a. 仓库盘点

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-01 | **标签**：哈希、排序 | **考点**：频次统计 + 首次出现位置 + 自定义比较器

## 题目描述

仓库中有若干类物品，每类物品都有一个类别编号（整型）。年底进行仓库盘点，统计每类物品的件数，按照件数**从多到少**的顺序为物品排序，整理完毕输出物品编号序列。

## 输入描述

一串物品类别编号，每个编号对应该类物品的一次入库，它是**按照入库先后**排列的。

格式：一行字符串，编号用逗号分隔，如 `1,2,2,3,3,3`

## 输出描述

整理后的物品编号序列，用逗号分隔。

### 补充说明

1. 如果物品的**件数相同**，则按照物品**首次入库的先后顺序**排列。
2. 物品种类不超过 `10`，所有物品的总件数不超过 `100`。

---

## 示例

### 示例 1

```
输入：1,2,2,3,3,3
输出：3,2,1
```

**说明**：编号 `3` 有 3 件，编号 `2` 有 2 件，编号 `1` 有 1 件，按件数从高到低排序：3 件 > 2 件 > 1 件，输出 `3,2,1`。

### 示例 2

```
输入：3,3,2,2,1,1
输出：3,2,1
```

**说明**：所有物品件数均为 2 件，按物品首次出现的先后顺序排序，输出 `3,2,1`。

---

## 提示

- **数据结构**：用 `Map<Integer, Integer>` 记录每个编号的件数；用 `Map<Integer, Integer>` 记录每个编号的首次出现位置
- **排序键**：`(-件数, 首次出现位置)`，即件数降序、首次位置升序
- **数据规模**：物品种类 ≤ 10、总件数 ≤ 100，规模很小，无需优化

---

## 思路

### 核心思想：哈希计数 + 自定义比较器

1. **遍历一次**：用 `Map` 统计每个编号的出现次数；同时记录每个编号首次出现的位置（仅首次写入）
2. **取出所有不同编号**：转为列表后排序
3. **排序键**：件数降序 → 首次位置升序
4. **输出**：将排序后的编号列表用逗号连接

**逐步演示**（示例 1，`1,2,2,3,3,3`）：

```
i=0: id=1, first[1]=0, cnt[1]=1
i=1: id=2, first[2]=1, cnt[2]=1
i=2: id=2,           cnt[2]=2
i=3: id=3, first[3]=3, cnt[3]=1
i=4: id=3,           cnt[3]=2
i=5: id=3,           cnt[3]=3

不同编号: [1, 2, 3]

排序键 (-cnt, first):
  1: (-3, 0)  ← cnt=1, first=0  → tuple(-1, 0)
  2: (-2, 1)  ← cnt=2, first=1  → tuple(-2, 1)
  3: (-3, 3)  ← cnt=3, first=3  → tuple(-3, 3)

升序排: (-3, 3) < (-2, 1) < (-1, 0)
即按 tuple 升序，得到 [3, 2, 1]

输出: "3,2,1"  ✓
```

- 时间复杂度：\(O(n + k \log k)\)，\(n\) 为总件数，\(k\) 为物品种类数（≤ 10）
- 空间复杂度：\(O(k)\)，存计数与首次位置

## 代码

### 我的伪代码

```java
class Solution {
    public String inventorySort(String input) {
        String[] arr = input.split(",");
        Map<Integer, Integer> cnt = new HashMap<>();
        Map<Integer, Integer> first = new HashMap<>();

        for (int i = 0; i < arr.length; i++) {
            int id = Integer.parseInt(arr[i]);
            cnt.merge(id, 1, Integer::sum);
            first.putIfAbsent(id, i);
        }

        List<Integer> ids = new ArrayList<>(cnt.keySet());
        ids.sort((a, b) -> {
            int cntCmp = cnt.get(b) - cnt.get(a);     // 件数降序
            if (cntCmp != 0) return cntCmp;
            return first.get(a) - first.get(b);       // 首次位置升序
        });

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < ids.size(); i++) {
            if (i > 0) sb.append(",");
            sb.append(ids.get(i));
        }
        return sb.toString();
    }
}
```

### 解法（Java）

```java
import java.util.*;

class Solution {
    public String inventorySort(String input) {
        if (input == null || input.isEmpty()) return "";
        String[] arr = input.split(",");

        Map<Integer, Integer> cnt = new HashMap<>();
        Map<Integer, Integer> first = new HashMap<>();

        for (int i = 0; i < arr.length; i++) {
            int id = Integer.parseInt(arr[i].trim());
            cnt.merge(id, 1, Integer::sum);
            first.putIfAbsent(id, i);
        }

        List<Integer> ids = new ArrayList<>(cnt.keySet());
        ids.sort((a, b) -> {
            int cntCmp = cnt.get(b) - cnt.get(a);   // 件数降序
            if (cntCmp != 0) return cntCmp;
            return first.get(a) - first.get(b);    // 首次位置升序
        });

        StringJoiner sj = new StringJoiner(",");
        for (int id : ids) sj.add(String.valueOf(id));
        return sj.toString();
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n + k \log k)\)，\(n\) 为总件数，\(k\) 为物品种类数（≤ 10，排序为常数级）
- **空间复杂度**：\(O(k)\)，两个哈希表

> 💡 **记忆**：**「Map 维护两件套：件数 + 首次位置；排序键 (件数降序, 首次位置升序)」**——属于「哈希统计 + 自定义排序」模板题，与 LeetCode 347「前 K 个高频元素」、451「根据字符频率排序」同源，差异仅在「件数相同时的次级键」。
>
> ⚠️ **易错**：① 件数相同时按**首次入库先后顺序**（即数组下标）排，**不是按编号大小**；② 用 `putIfAbsent` 或 `containsKey` 判断首次出现，避免覆盖；③ 输出格式为逗号分隔字符串，无方括号、无空格；④ 输入为空时输出空字符串。
