# 2026-07-01b. 奇偶三数之和

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-01

## 题目描述

给定一个包含 `n` 个整数的数组 `nums` 和一个整数 `target`，请从数组中找出所有**不重复**的三元组 `[nums[i], nums[j], nums[k]]`，满足以下两个条件：

1. **和为目标**：`nums[i] + nums[j] + nums[k] = target`
2. **奇偶性约束**：三个元素中**至少有两个是奇数**

返回所有满足条件的不重复三元组。

**数据范围**：

- `3 ≤ nums.length ≤ 3000`
- `−10^5 ≤ nums[i] ≤ 10^5`

## 输入描述

- 第一行：数组元素，逗号分隔
- 第二行：目标整数 `target`

## 输出描述

所有满足条件的不重复三元组，按特定格式输出。

### 输出格式

- 每个子数组内部的元素按**数值升序**排列
- 所有子数组之间按**字典序升序**排列（即先比较第一个元素，若相同再比较第二个，以此类推）
- 示例：`[[-1,-1,2],[-1,0,1]]`

---

## 示例

### 示例 1

```
输入：
-1,0,1,2,-1,-4
0

输出：
[[-1,-1,2],[-1,0,1]]
```

**说明**：

- `[-1, -1, 2]`：和为 0；奇数有 `-1, -1` 两个，满足奇偶约束 ✅
- `[-1, 0, 1]`：和为 0；奇数有 `-1, 1` 两个，满足奇偶约束 ✅
- 其他组合要么和不为 0，要么奇数不足两个

### 示例 2

```
输入：
0,0,0
0

输出：
[]
```

**说明**：`[0, 0, 0]` 和为 0，但**奇数个数为 0**，不满足奇偶约束。

### 示例 3

```
输入：
1,1,2,3,5,7
8

输出：
[[1,2,5]]
```

**说明**：`1 + 2 + 5 = 8`，且 `1` 和 `5` 都是奇数，满足奇偶约束。

## 提示

- **去重思路**：先排序，固定第一个数时跳过相邻相同的数；双指针移动时也跳过相同数
- **奇偶性判定**：`x % 2 != 0` 即为奇数（注意负数：`-3 % 2 == -1`，仍满足 `!= 0`）
- **三数之和模板**：经典 LeetCode 15「三数之和」基础上增加奇偶约束
- **溢出防护**：`nums[i] ∈ [-10^5, 10^5]`，三数之和最大 `3 × 10^5`，不溢出 `int`，但更稳妥可用 `long`

---

## 思路

### 核心思想：排序 + 双指针 + 奇偶性过滤

1. **排序**：先对数组升序排序，便于去重和双指针
2. **固定第一个数 `i`**：从 `0` 遍历到 `n - 3`，跳过相邻相同的数（去重）
3. **双指针**：`l = i + 1, r = n - 1`，向中间逼近
4. **奇偶性过滤**：在找到一组满足和为 `target` 的三元组后，**额外判断**其中奇数个数是否 ≥ 2
5. **去重**：在 `l` 与 `r` 移动时也跳过相邻相同数

**逐步演示**（示例 1，`[-1, 0, 1, 2, -1, -4]`，`target = 0`）：

```
排序后: [-4, -1, -1, 0, 1, 2]

i=0 (nums[i]=-4):
  l=1(-1), r=5(2): -1+2=1, sum=-4+(-1)+2=-3 < 0 → l++
  l=2(-1), r=5(2): -1+2=1, sum=-4+(-1)+2=-3 < 0 → l++
  l=3(0),  r=5(2): 0+2=2, sum=-4+0+2=-2 < 0 → l++
  l=4(1),  r=5(2): 1+2=3, sum=-4+1+2=-1 < 0 → l++
  l=5 == r → 结束

i=1 (nums[i]=-1) (跳过 i=0 因为 nums[0] != nums[1]):
  l=2(-1), r=5(2): -1+2=1, sum=-1+(-1)+2=0 ✅
    奇偶性: -1 (奇), -1 (奇), 2 (偶) → 奇数 2 个 ≥ 2 ✅
    加入结果 [-1, -1, 2]
    跳过 l=2 重复 (-1) → l=3
    跳过 r=5 重复 (无) → r=4
  l=3(0), r=4(1): 0+1=1, sum=-1+0+1=0 ✅
    奇偶性: -1 (奇), 0 (偶), 1 (奇) → 奇数 2 个 ✅
    加入结果 [-1, 0, 1]
    l++, r--

i=2 (nums[i]=-1, 与 nums[i-1] 相同 → 跳过)
i=3 (nums[i]=0):
  l=4(1), r=5(2): sum=0+1+2=3 ≠ 0
  ...
i=4 (nums[i]=1):
  l=5 == r → 结束

最终结果: [[-1,-1,2],[-1,0,1]]  ✓
```

- 时间复杂度：\(O(n^2)\)，外层 i 循环 \(O(n)\)，双指针 \(O(n)\)，排序 \(O(n \log n)\) 可忽略
- 空间复杂度：\(O(\log n)\)（排序所需栈空间，不计结果存储）

## 代码

### 我的伪代码

```java
class Solution {
    public List<List<Integer>> threeSumOdd(int[] nums, int target) {
        List<List<Integer>> ans = new ArrayList<>();
        Arrays.sort(nums);
        int n = nums.length;
        for (int i = 0; i < n - 2; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;     // 外层去重
            int l = i + 1, r = n - 1;
            while (l < r) {
                long sum = (long) nums[i] + nums[l] + nums[r];
                if (sum == target) {
                    if (countOdd(nums[i], nums[l], nums[r]) >= 2) {
                        ans.add(Arrays.asList(nums[i], nums[l], nums[r]));
                    }
                    // 内层去重：跳过相同 l 和 r
                    int lv = nums[l], rv = nums[r];
                    while (l < r && nums[l] == lv) l++;
                    while (l < r && nums[r] == rv) r--;
                } else if (sum < target) {
                    l++;
                } else {
                    r--;
                }
            }
        }
        return ans;
    }

    /** 统计三个数中奇数个数 */
    int countOdd(int a, int b, int c) {
        int cnt = 0;
        if (Math.abs(a) % 2 == 1) cnt++;
        if (Math.abs(b) % 2 == 1) cnt++;
        if (Math.abs(c) % 2 == 1) cnt++;
        return cnt;
    }
}
```

### 解法（Java）

```java
import java.util.*;

class Solution {
    public List<List<Integer>> threeSumOdd(int[] nums, int target) {
        List<List<Integer>> ans = new ArrayList<>();
        Arrays.sort(nums);                          // 升序排序
        int n = nums.length;

        for (int i = 0; i < n - 2; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;   // 外层去重
            int l = i + 1, r = n - 1;
            while (l < r) {
                long sum = (long) nums[i] + nums[l] + nums[r];
                if (sum == target) {
                    if (countOdd(nums[i], nums[l], nums[r]) >= 2) {
                        ans.add(Arrays.asList(nums[i], nums[l], nums[r]));
                    }
                    int lv = nums[l], rv = nums[r];
                    while (l < r && nums[l] == lv) l++;      // 内层去重
                    while (l < r && nums[r] == rv) r--;
                } else if (sum < target) {
                    l++;
                } else {
                    r--;
                }
            }
        }
        return ans;
    }

    /** 统计三个数中奇数个数（处理负数情况） */
    private int countOdd(int a, int b, int c) {
        int cnt = 0;
        if ((a & 1) != 0) cnt++;     // 负奇数 & 1 = -1 != 0，等价于 isOdd
        if ((b & 1) != 0) cnt++;
        if ((c & 1) != 0) cnt++;
        return cnt;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n^2)\)，外层 `i` 循环 \(O(n)\)，每次双指针 \(O(n)\)，总 \(O(n^2)\)；排序 \(O(n \log n)\) 可忽略
- **空间复杂度**：\(O(\log n)\)，排序所需栈空间（不计结果存储）

> 💡 **记忆**：**「排序 + 双指针三数之和模板，加一个奇偶性过滤条件」**——本质是 LeetCode 15「三数之和」的变体，只在找到候选三元组后多一步「奇数个数 ≥ 2」判断。
>
> ⚠️ **易错**：① **负奇数判定**：`-3 % 2 == -1`，所以 `% 2 != 0` 比 `% 2 == 1` 更安全；或用 `(x & 1) != 0`；② **去重要分内外两层**：外层 `i` 跳过相邻同值，内层 `l/r` 跳过相邻同值，**两层都不能漏**；③ **溢出**：三数之和虽然本题不溢出，但稳妥用 `long` 累加；④ 排序后元素天然升序，结果字典序天然满足，无需额外排序；⑤ 输出格式为 `[[-1,-1,2],[-1,0,1]]`，注意无空格。
