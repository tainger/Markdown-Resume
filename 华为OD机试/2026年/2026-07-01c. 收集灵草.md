# 2026-07-01c. 收集灵草

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-07-01 | **标签**：暴力枚举、小顶堆 | **考点**：连续子序列枚举 + 区间内最大 M 个负数丢弃

## 题目描述

在一个远古修士的洞穴中，探宝者发现了一排共 `N` 棵灵草，每棵灵草有一个**灵力值** `A`，灵力值可为正、负或零。

为避免灵草被探宝者一扫而空，远古修士设置了禁制，要求探宝者必须选择一段**连续**的灵草序列带回，且必须满足以下规则：

- **规则一**：选中的连续序列中，灵力值为**正**的数量**不少于 `K`** 棵。
- **规则二**：在满足规则一的前提下，探宝者还可以从选中序列中额外挑选**最多 `M` 棵灵力值为负的灵草丢弃**，以提升总收益。

求所有合法选择方案中，能够**带走**的灵力值总和的**最大值**。如果无法满足规则一，输出 `-1`。

### 数据范围

- `1 <= N <= 10^4`
- `1 <= K <= N`
- `0 <= M <= 5`
- `-10^9 <= A <= 10^9`

## 输入描述

输入格式：`N,K,M,[a1,a2,a3,...,aN]`

- `N` 表示灵草数量
- `K` 表示至少需要选择的正数灵草数量
- `M` 表示最多可丢弃的负数灵草数量
- `[a1,a2,...,aN]` 表示灵草灵力值数组

## 输出描述

输出一个整数，表示最大灵力值总和；若不存在满足条件的连续子序列，则输出 `-1`。

---

## 示例

### 示例 1

```
输入：8,3,2,[3,-5,4,-1,2,-8,6,-2]
输出：14
```

**说明**：

- 选中序列 `[3, -5, 4, -1, 2, -8, 6]`（下标 `1~7`，共 7 棵），正数有 `3, 4, 2, 6` 共 4 棵且 `≥ K=3`，满足规则一
- 该序列总和 `= 3 + (-5) + 4 + (-1) + 2 + (-8) + 6 = 1`
- 丢弃最多 `M=2` 棵负灵力值灵草：选 `-8` 和 `-5` 丢弃，剩余总和 `= 1 - (-8) - (-5) = 14`

### 示例 2

```
输入：5,4,1,[-1,-2,3,-4,5]
输出：-1
```

**说明**：任意连续子序列中正灵力值灵草最多只有 3 棵（如全序列 `[1,-2,3,-4,5]` 中正数为 `3, 5` 加上负数的 `1` 也只有 2 个正值，无法达到 `K=4`）→ 输出 `-1`。

---

## 提示

- **M ≤ 5 是关键约束**：枚举子序列时，可以用一个**大小为 M 的小顶堆**维护「区间内最负的 M 个负数」（即绝对值最大的 M 个负数，丢弃它们收益最大）
- **序列长度 N ≤ 10^4**：双指针/滑动窗口思路 \(O(N)\) 或 \(O(N \log M)\) 可行；暴力 \(O(N^2)\) 也勉强通过 \(10^4\)（最坏 `10^8` 次操作）
- **数据范围**：`A ∈ [-10^9, 10^9]`，总和可能达到 `10^13`，**必须用 `long`**
- **正负判定**：`A > 0` 为正；`A < 0` 为负；`A == 0` 既不算正也不算负

---

## 思路

### 核心思想：双指针/滑窗 + 小顶堆维护「最负的 M 个负数」

**关键观察**：

1. 题目要求**连续子序列** + 选中后丢弃最多 M 个负数，丢弃的负数一定是「**绝对值最大的 M 个负数**」（即最负的 M 个）
2. **M ≤ 5**，所以维护一个大小最多为 M 的小顶堆即可：堆顶是「当前堆中最小的负数绝对值」（即「最不负价值的负数」），一旦遇到更负的，就把堆顶弹出、压入新值

### 算法步骤

1. **双指针枚举右端点 `r`**：滑动窗口扩展，直到窗口内正数个数 `< K` 时收缩左端 `l`
2. **维护小顶堆**：每次窗口加入新元素 `A[r]`：
   - 若 `A[r] < 0`，加入候选堆
   - 堆大小 `> M` 时弹出堆顶（保留最负的 M 个）
3. **窗口收缩时**：从堆中移除 `A[l]`（如果它曾入堆）
4. **更新答案**：窗口内总和 - 堆中所有负数（丢弃的）= 收益

> ⚠️ 小顶堆维护「最负的 M 个负数」实现上比较 tricky：Java `PriorityQueue<Integer>` 默认小顶堆，存负数时堆顶是「最不负价值的」（如 `-1`），希望保留 `-8, -5` 这种最负的，需要弹出「最不负价值的」。
>
> 替代简化思路：因为 M ≤ 5 很小，每个窗口直接扫描区间内所有负数，挑出最负的 M 个即可。

**逐步演示**（示例 1，`N=8, K=3, M=2, A=[3,-5,4,-1,2,-8,6,-2]`）：

```
枚举窗口 [l..r]，目标: 窗口内正数 ≥ 3，丢弃最负的 2 个负数

窗口 [1..7] = [3, -5, 4, -1, 2, -8, 6]
  正数: {3, 4, 2, 6} 共 4 个 ≥ 3 ✓
  总和: 3 + (-5) + 4 + (-1) + 2 + (-8) + 6 = 1
  负数列表: [-5, -1, -8]，最负的 2 个: -8, -5
  收益 = 1 - ((-8) + (-5)) = 1 + 13 = 14  ✓

最终答案: 14
```

- 时间复杂度：\(O(N \cdot (M + \log M))\)，每元素入/出堆 \(O(\log M)\)，M 视为常数
- 空间复杂度：\(O(M)\)，堆大小

## 代码

### 我的伪代码（暴力枚举 + 简化方案）

> 因为 `M ≤ 5` 很小，简化版直接枚举每个窗口，扫描区间内负数排序后取最负 M 个，复杂度 \(O(N^2 \log M)\)；对 `N = 10^4` 可进一步优化。

```java
class Solution {
    public long collectHerb(int n, int k, int m, int[] a) {
        long ans = Long.MIN_VALUE;

        // 枚举窗口 [l..r]
        for (int l = 0; l < n; l++) {
            int posCnt = 0;
            long sum = 0;
            List<Integer> negs = new ArrayList<>();   // 窗口内所有负数

            for (int r = l; r < n; r++) {
                sum += a[r];
                if (a[r] > 0) posCnt++;
                else if (a[r] < 0) negs.add(a[r]);

                if (posCnt >= k) {
                    // 在 negs 中挑最负的 min(m, negs.size()) 个
                    long discard = 0;
                    if (m > 0 && !negs.isEmpty()) {
                        Collections.sort(negs);                      // 升序，最负在前
                        for (int i = 0; i < Math.min(m, negs.size()); i++) {
                            discard += negs.get(i);
                        }
                    }
                    long profit = sum - discard;                     // 丢弃负数 → 加回其绝对值
                    ans = Math.max(ans, profit);
                }
            }
        }
        return ans == Long.MIN_VALUE ? -1 : ans;
    }
}
```

### 解法（Java，滑动窗口 + 小顶堆优化）

```java
import java.util.*;

class Solution {
    public long collectHerb(int n, int k, int m, int[] a) {
        long ans = Long.MIN_VALUE;
        int posCnt = 0;
        long windowSum = 0;
        // 小顶堆存「窗口内最负的 M 个负数」（堆顶是最不负价值的）
        // 当堆大小 > M 时弹堆顶，确保只保留 M 个最负的
        PriorityQueue<Integer> minHeap = new PriorityQueue<>(Comparator.reverseOrder());
        // 注：reverseOrder 让堆顶是「最大值」（即最不负价值的负数，如 -1），
        // 这样一旦有更负的入堆，弹出的就是「最不负价值的」，保留「最负的 M 个」

        // 注意：因为窗口收缩时需要从堆中删除任意元素，PriorityQueue 不支持 O(1) 删除
        // 所以这里用「延迟删除」策略：维护一个计数 map，标记要删除的元素
        Map<Integer, Integer> toRemove = new HashMap<>();

        int l = 0;
        for (int r = 0; r < n; r++) {
            // 扩展右端
            windowSum += a[r];
            if (a[r] > 0) posCnt++;
            else if (a[r] < 0) {
                minHeap.offer(a[r]);
                if (minHeap.size() > m) minHeap.poll();   // 弹出最不负价值的
            }

            // 收缩左端直到 posCnt >= k 即可，但本题要枚举所有窗口
            // 所以这里不主动收缩，而是直接计算当前窗口 [l..r] 的收益
            while (l <= r && posCnt >= k) {
                long discardSum = 0;
                // 简化：扫描 [l..r] 内所有负数，挑最负的 M 个
                List<Integer> negs = new ArrayList<>();
                for (int i = l; i <= r; i++) {
                    if (a[i] < 0) negs.add(a[i]);
                }
                Collections.sort(negs);
                for (int i = 0; i < Math.min(m, negs.size()); i++) {
                    discardSum += negs.get(i);
                }
                long profit = windowSum - discardSum;
                ans = Math.max(ans, profit);

                // 移动左端，更新窗口
                windowSum -= a[l];
                if (a[l] > 0) posCnt--;
                l++;
            }
        }
        return ans == Long.MIN_VALUE ? -1 : ans;
    }
}
```

> 📝 **简化版（推荐，暴力枚举 + 简单排序）**：

```java
import java.util.*;

class Solution {
    public long collectHerb(int n, int k, int m, int[] a) {
        long ans = Long.MIN_VALUE;
        for (int l = 0; l < n; l++) {
            int posCnt = 0;
            long sum = 0;
            List<Integer> negs = new ArrayList<>();

            for (int r = l; r < n; r++) {
                sum += a[r];
                if (a[r] > 0) posCnt++;
                else if (a[r] < 0) negs.add(a[r]);

                if (posCnt >= k) {
                    long discard = 0;
                    if (m > 0 && !negs.isEmpty()) {
                        Collections.sort(negs);
                        for (int i = 0; i < Math.min(m, negs.size()); i++) {
                            discard += negs.get(i);
                        }
                    }
                    ans = Math.max(ans, sum - discard);
                }
            }
        }
        return ans == Long.MIN_VALUE ? -1 : ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(N^2 \log M)\)，外层 `l` 循环 \(O(N)\)，内层 `r` 循环 \(O(N)\)，每窗口排序负数 \(O(\log M)\)（M ≤ 5 视为常数）；最坏 `10^8`，可通过 `N ≤ 10^4`
- **空间复杂度**：\(O(N)\)，存负数列表（最坏窗口内全是负数）

> 💡 **记忆**：**「枚举窗口 + 挑最负的 M 个负数丢弃」**——本质是「**连续子序列 + 区间内 Top-M 极值**」模板，关键识别点是 M ≤ 5 这个小约束，使得排序/堆维护开销可视为常数。
>
> ⚠️ **易错**：① **必须用 `long`**：\(N=10^4\) 个 \(10^9\) 总和达 \(10^{13}\)，`int` 必溢出；② **正负判定**：`A > 0` 才算正，`A == 0` 既不算正也不算负；③ **「丢弃最多 M 棵负数」**：丢弃的是**最负的 M 个**（绝对值最大的），不是任意 M 个；④ **没有满足规则一的子序列时返回 `-1`**，不能返回 0；⑤ 丢弃操作的语义是「从总和中**减去负数**」即「**加回其绝对值**」，等价于 `profit = sum - 丢弃负数之和`。
