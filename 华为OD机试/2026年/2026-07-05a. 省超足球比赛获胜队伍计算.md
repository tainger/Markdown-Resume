# 2026-07-05a. 省超足球比赛获胜队伍计算

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-05

## 题目描述

江苏省举办省级足球超级联赛，以市为单位参赛。请根据给定的比赛结果，输出获得**冠军、亚军、季军**的队伍名称。

### 比赛安排

1. 参赛的队伍总数为 `teamNum`，`teamNum` 的取值范围是 `3 ≤ teamNum ≤ 15`；
2. 比赛采用**单循环赛制**：
   - 任意两支参赛队伍之间至少比赛 1 场，若两队队伍之间不存在比赛记录，说明其中有队伍弃赛；
   - 总比赛场次不超过 `teamNum × (teamNum−1) / 2` 场；
3. 比赛最终各队伍不允许出现积分和净胜球都完全相同的情况。

### 计分规则

1. 胜者得 `3` 分，平局各得 `1` 分，负者得 `0` 分；
2. 每场比赛记录双方的进球数（进球数 ≥ 0），从而计算净胜球（进球数 - 失球数）。

### 排名规则

- 首先按**总积分**从高到低排序；
- 若积分相同，则按**净胜球**从高到低排序。

## 输入描述

- 第一个参数：整数 `teamNum`，表示参赛队伍的数量。若 `teamNum` 超过 `[3, 15]` 范围则输入不合法。
- 第二个参数：二维数组，每一行表示一场比赛结果，格式为 `["队伍A名称", "队伍A进球数", "队伍B进球数", "队伍B名称"]`。

## 输出描述

- 如果输入合法，输出字符串列表 `[冠军, 亚军, 季军]`；
- 如果输入不合法，输出空字符串列表 `[]`。

### 补充说明

所有不符合「比赛安排」「计分规则」章节约束的输入均视为不合法输入，按输入不合法处理。

## 提示

- **数据结构**：用 `Map<String, Team>` 维护每支队伍的积分、进球数、失球数
- **非法校验**：① `teamNum` 不在 `[3, 15]`；② 比赛记录中的队伍名不在参赛队伍集合；③ 两队比赛场次超过 1；④ 最终排名出现「积分 + 净胜球」并列
- **数字解析**：进球数以字符串形式给出（如 `"2"`），需要 `Integer.parseInt` 转换
- **排序键**：先按积分降序，再按净胜球降序；如需稳定排名可加队伍名作第三键

---

## 思路

### 核心思想：哈希统计 + 自定义比较器

1. **合法性校验**：先校验 `teamNum` 范围与比赛记录中队伍是否合法
2. **遍历统计**：用 `Map<String, int[]>` 统计每支队伍的 `[积分, 进球, 失球]`
3. **排序**：将 map 转为 list，按 `(积分降序, 净胜球降序)` 排序
4. **取前三**：取前 3 名的队伍名输出

**逐步演示**（示例 1）：

```
比赛记录:
  Beijing  2:1  Shanghai   → Beijing 胜，+3 分，Beijing 净胜 +1，Shanghai 净胜 -1
  Beijing  3:0  Guangzhou  → Beijing 胜，+3 分，Beijing 净胜 +3，Guangzhou 净胜 -3
  Shanghai 1:1  Guangzhou  → 平局，各 +1 分，净胜 0

统计:
  Beijing:    积分=6, 进球=5, 失球=1, 净胜=+4
  Shanghai:   积分=1, 进球=2, 失球=3, 净胜=-1
  Guangzhou:  积分=1, 进球=1, 失球=4, 净胜=-3

排序（积分降序, 净胜球降序）:
  Beijing(6,+4) > Shanghai(1,-1) > Guangzhou(1,-3)

输出前三: ["Beijing","Shanghai","Guangzhou"]
```

- 时间复杂度：\(O(M + T \log T)\)，M 为比赛场数，T 为队伍数（≤ 15）
- 空间复杂度：\(O(T)\)，哈希表存储队伍信息

## 代码

### 我的伪代码

```java
class Solution {
    public List<String> calcChampion(int teamNum, String[][] matches) {
        // 1. 合法性校验
        if (teamNum < 3 || teamNum > 15) return Collections.emptyList();
        int maxMatches = teamNum * (teamNum - 1) / 2;
        if (matches.length > maxMatches) return Collections.emptyList();

        // 2. 收集所有参赛队伍名（用于校验比赛记录的合法性）
        // 题目未直接给队伍名，从比赛记录中收集
        Set<String> teamSet = new HashSet<>();
        for (String[] m : matches) {
            teamSet.add(m[0]); teamSet.add(m[3]);
        }
        // 队伍数 <= teamNum
        if (teamSet.size() > teamNum) return Collections.emptyList();

        // 3. 统计积分 / 进球 / 失球
        Map<String, int[]> stat = new HashMap<>();   // [积分, 进球, 失球]
        for (String[] m : matches) {
            String a = m[0], b = m[3];
            int ga = Integer.parseInt(m[1]);
            int gb = Integer.parseInt(m[2]);
            int[] sa = stat.computeIfAbsent(a, k -> new int[3]);
            int[] sb = stat.computeIfAbsent(b, k -> new int[3]);
            sa[1] += ga; sa[2] += gb;
            sb[1] += gb; sb[2] += ga;
            if (ga > gb)      { sa[0] += 3; }
            else if (ga < gb) { sb[0] += 3; }
            else              { sa[0] += 1; sb[0] += 1; }
        }

        // 4. 排序：积分降序, 净胜球降序
        List<String> teams = new ArrayList<>(stat.keySet());
        teams.sort((x, y) -> {
            int[] sx = stat.get(x), sy = stat.get(y);
            if (sy[0] != sx[0]) return sy[0] - sx[0];
            int diffX = sx[1] - sx[2], diffY = sy[1] - sy[2];
            return diffY - diffX;
        });

        // 5. 检查是否存在「积分 + 净胜球」并列
        // 取前三，若第三名和第四名并列则不合法
        // (此处简化：题目保证不并列，直接取前 3)
        return teams.subList(0, Math.min(3, teams.size()));
    }
}
```

### 解法（Java）

```java
import java.util.*;

class Solution {
    public List<String> calcChampion(int teamNum, String[][] matches) {
        // 1. teamNum 合法性
        if (teamNum < 3 || teamNum > 15) return Collections.emptyList();
        int maxMatches = teamNum * (teamNum - 1) / 2;
        if (matches.length > maxMatches) return Collections.emptyList();

        // 2. 统计积分 [0]=积分, [1]=进球, [2]=失球
        Map<String, int[]> stat = new HashMap<>();
        for (String[] m : matches) {
            String a = m[0], b = m[3];
            int ga, gb;
            try {
                ga = Integer.parseInt(m[1]);
                gb = Integer.parseInt(m[2]);
            } catch (NumberFormatException e) {
                return Collections.emptyList();   // 进球数非法
            }
            if (ga < 0 || gb < 0) return Collections.emptyList();

            int[] sa = stat.computeIfAbsent(a, k -> new int[3]);
            int[] sb = stat.computeIfAbsent(b, k -> new int[3]);
            sa[1] += ga; sa[2] += gb;
            sb[1] += gb; sb[2] += ga;
            if (ga > gb)      sa[0] += 3;
            else if (ga < gb) sb[0] += 3;
            else              { sa[0] += 1; sb[0] += 1; }
        }
        // 参赛队伍数不得超过 teamNum
        if (stat.size() > teamNum) return Collections.emptyList();

        // 3. 排序：积分降序 → 净胜球降序 → 队伍名升序（兜底）
        List<String> teams = new ArrayList<>(stat.keySet());
        teams.sort((x, y) -> {
            int[] sx = stat.get(x), sy = stat.get(y);
            if (sy[0] != sx[0]) return sy[0] - sx[0];
            int diffX = sx[1] - sx[2], diffY = sy[1] - sy[2];
            if (diffY != diffX) return diffY - diffX;
            return x.compareTo(y);
        });

        // 4. 检查前三名是否存在并列（积分 + 净胜球 完全相同）
        for (int i = 0; i < teams.size() - 1; i++) {
            int[] cur = stat.get(teams.get(i));
            int[] nxt = stat.get(teams.get(i + 1));
            int curKey = cur[0] * 10000 + (cur[1] - cur[2]);
            int nxtKey = nxt[0] * 10000 + (nxt[1] - nxt[2]);
            if (curKey == nxtKey) return Collections.emptyList();
        }

        // 5. 取前三
        return new ArrayList<>(teams.subList(0, Math.min(3, teams.size())));
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(M + T \log T)\)，M 比赛场数，T 队伍数（T ≤ 15），排序为常数级
- **空间复杂度**：\(O(T)\)，仅哈希表与排序列表

> 💡 **记忆**：**「Map<队伍, int[3]> 三件套：积分/进球/失球；排序键 (积分, 净胜球, 队名)」**——单循环积分统计是模板题，与 LeetCode 1244「力扣排行榜」、足球联赛积分统计同源。
>
> ⚠️ **易错**：① 进球数在输入里是**字符串**，要 `parseInt`；② **净胜球 = 进球 - 失球**，每场比赛双方都要累加（A 的进球即 B 的失球）；③ **非法输入**返回**空列表**（不是 null，不是抛异常）；④ 题目保证最终排名不并列，但仍需校验，发现并列即视为不合法。
