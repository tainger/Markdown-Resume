# 2026-07-05b. SQL记录拆分

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-05 | **标签**：并查集、哈希 | **考点**：行内语句 + 事务标签传递性合并 + 贪心分组

## 题目描述

某分布式数据库系统需要将 SQL 操作日志拆分到多个文件中。给定一组 SQL 语句输入（数组格式），请按要求将 SQL 语句拆分到不同文件中并返回拆分后的**文件数量**。

### 拆分规则

1. **行不跨文件**：单个数组成员的 SQL 语句（可能包含多条，按 `;` 分隔）按同一行完整保存，**不可跨文件拆分**，且同一行的语句必须在同一个文件中。
2. **事务同文件**：部分语句带事务标签 `[Tn]`（`n` 为正整数），如 `[T1]A`；**相同事务标签**的 SQL 语句必须保存于同一文件中。
3. **行数限制触发新文件**：当单个文件保存的**行数**超出限制时新建文件；按语句组首次出现的行号顺序处理，优先放入当前文件，超出限制则新建文件。
4. **传递性约束**：若语句 A 与语句 B 必须同文件，语句 B 与语句 C 必须同文件，则 A、B、C 必须在同一文件（约束**传递性**）。约束合并后语句组计数即便超过限制也必须放在同一文件。
5. **空数组返回 0**。

## 输入描述

- 参数 1：单个文件限定可保存的最大 SQL 语句**行数** `split_line`；
- 参数 2：SQL 语句数组 `sql_text`，每个数组成员可能包含多条 SQL 语句，用符号 `;` 分隔；

## 输出描述

按规则拆分后的**文件个数**。

### 补充说明

- `split_line` 取值范围 `[1, 10000]`，无效值返回 0；
- `sql_text` 每行最多 1000 字符，总语句最多 100000 条；
- 事务标签的范围 `[1, 1000]`；
- 最后一条语句可以没有分号结尾；
- 空语句（仅含分号）按 1 行计算。

---

## 示例

### 示例 1

```
输入：
3
["[T1]A;[T2]B;","[T1]C;"]

输出：
1
```

**说明**：

- 数组成员 0：`[T1]A;[T2]B;` → 行号 0，包含 `[T1]A` 与 `[T2]B`
- 数组成员 1：`[T1]C;` → 行号 1，包含 `[T1]C`
- `[T1]A` 和 `[T1]C` 同属 `T1` 事务 → 必须同文件
- `[T1]A` 和 `[T2]B` 同行 → 必须同文件
- **传递性**：`[T2]B` 与 `[T1]C` 间接同组 → 三条语句同组
- 组内涉及行号 `{0,1}` 共 2 行，不超过 `split_line=3` → 1 个文件

### 示例 2

```
输入：
2
["[T1]A;","[T2]B;","[T1]C;","[T2]D;"]

输出：
2
```

**说明**：

- 数组下标：0=`[T1]A`，1=`[T2]B`，2=`[T1]C`，3=`[T2]D`
- T1 事务：行 0 + 行 2 = 2 行 ≤ `split_line=2` → 同一文件（文件 A）
- T2 事务：行 1 + 行 3 = 2 行 ≤ `split_line=2` → 同一文件（文件 B）
- T1 组与 T2 组无关联 → 分别放入不同文件 → 共 2 个文件

## 提示

- **行号概念**：每个数组成员即「一行」，整行所有语句共享同一行号
- **事务标签解析**：用正则 `\[T(\d+)\]` 提取事务号；同一事务的语句必须落同一文件
- **传递合并**：使用**并查集**，让「同事务」「同行的语句」共用一个组代表
- **行数计算**：组内涉及的不同行号数（去重后）即该组占用的行数
- **分配策略**：按组首次出现的行号升序遍历，贪心放入当前文件，超出限制则新建

---

## 思路

### 核心思想：并查集合并约束 + 贪心分配

1. **解析每行语句**：按 `;` 拆分单行，得到语句列表，记录每个语句的行号、事务号
2. **建立约束图**：
   - 同一行内的所有语句 → 同组（行约束）
   - 同事务号的所有语句 → 同组（事务约束）
3. **并查集合并**：将所有约束传递性合并，每个连通分量就是一个「语句组」
4. **统计组行数**：对每个组，去重统计涉及的行号数 = 该组占用行数
5. **贪心分配**：按组首次出现的行号升序处理，当前文件累计行数 + 当前组行数 ≤ `split_line` 则并入当前文件；否则新建文件

**逐步演示**（示例 1，`split_line=3`）：

```
语句解析:
  行 0:  [T1]A, [T2]B
  行 1:  [T1]C

约束:
  行约束: (0 中 [T1]A,[T2]B 同组)
  事务约束: T1: [T1]A(行0), [T1]C(行1) 同组

并查集合并:
  union([T1]A, [T2]B)   ← 同行
  union([T1]A, [T1]C)   ← 同事务

连通分量: { [T1]A, [T2]B, [T1]C } 一个组
  组涉及行号 {0, 1} → 行数 = 2
  首次出现行号 = 0

贪心分配:
  当前文件 cnt=0, 累计=0, 容量=3
  组行数 2, 0+2 ≤ 3 → 并入, 累计=2

输出: 1
```

- 时间复杂度：\(O(N \cdot \alpha(N))\)，N 为总语句数，α 为反 Ackermann 函数（近似常数）
- 空间复杂度：\(O(N)\)，并查集与组行号集合

## 代码

### 我的伪代码

```java
class Solution {
    public int splitSQL(int splitLine, String[] sqlText) {
        if (splitLine < 1 || splitLine > 10000) return 0;
        if (sqlText == null || sqlText.length == 0) return 0;

        int N = 0;                                  // 总语句数（每个 ; 分隔片段）
        List<int[]> stmts = new ArrayList<>();      // [行号, 事务号(0 表示无事务)]
        for (int i = 0; i < sqlText.length; i++) {
            String[] parts = sqlText[i].split(";");
            for (String p : parts) {
                int tx = parseTx(p);                // 提取 [Tn]，无则 0
                stmts.add(new int[]{i, tx});
                N++;
            }
            // 空语句（仅含分号）按 1 行计算 — split 得空字符串时也算一条
        }

        // 并查集
        DSU dsu = new DSU(N);
        // 1. 同行约束: 每行的语句两两 union
        Map<Integer, List<Integer>> byRow = new HashMap<>();
        for (int i = 0; i < N; i++) byRow.computeIfAbsent(stmts.get(i)[0], k -> new ArrayList<>()).add(i);
        for (List<Integer> list : byRow.values()) {
            for (int i = 1; i < list.size(); i++) dsu.union(list.get(0), list.get(i));
        }
        // 2. 事务约束: 同事务号两两 union
        Map<Integer, List<Integer>> byTx = new HashMap<>();
        for (int i = 0; i < N; i++) {
            int tx = stmts.get(i)[1];
            if (tx > 0) byTx.computeIfAbsent(tx, k -> new ArrayList<>()).add(i);
        }
        for (List<Integer> list : byTx.values()) {
            for (int i = 1; i < list.size(); i++) dsu.union(list.get(0), list.get(i));
        }

        // 3. 组统计: 每个 root 的成员涉及的行号去重数 = 组行数；首次出现行号 = 最小行号
        Map<Integer, TreeSet<Integer>> groupRows = new HashMap<>();
        for (int i = 0; i < N; i++) {
            int r = dsu.find(i);
            groupRows.computeIfAbsent(r, k -> new TreeSet<>()).add(stmts.get(i)[0]);
        }
        // 每个 root 的「首次出现行号」即 TreeSet.first()

        // 4. 贪心: 按 group 首次出现行号升序处理
        List<Integer> roots = new ArrayList<>(groupRows.keySet());
        roots.sort(Comparator.comparingInt(r -> groupRows.get(r).first()));

        int fileCnt = 0, curUsed = 0;
        for (int r : roots) {
            int rows = groupRows.get(r).size();
            if (curUsed + rows > splitLine) {
                fileCnt++;
                curUsed = rows;          // 新文件，本组占用 rows 行
            } else {
                curUsed += rows;         // 并入当前文件
            }
        }
        if (curUsed > 0) fileCnt++;      // 最后一个未闭合的文件
        return fileCnt;
    }

    int parseTx(String s) {
        int i = s.indexOf("[T");
        if (i < 0) return 0;
        int j = s.indexOf("]", i + 2);
        if (j < 0) return 0;
        try { return Integer.parseInt(s.substring(i + 2, j)); }
        catch (Exception e) { return 0; }
    }

    static class DSU {
        int[] p;
        DSU(int n) { p = new int[n]; for (int i = 0; i < n; i++) p[i] = i; }
        int find(int x) { return p[x] == x ? x : (p[x] = find(p[x])); }
        void union(int a, int b) { p[find(a)] = find(b); }
    }
}
```

### 解法（Java）

```java
import java.util.*;

class Solution {
    public int splitSQL(int splitLine, String[] sqlText) {
        // 1. 合法性
        if (splitLine < 1 || splitLine > 10000) return 0;
        if (sqlText == null || sqlText.length == 0) return 0;

        // 2. 解析每条语句：[行号, 事务号]
        List<int[]> stmts = new ArrayList<>();
        for (int i = 0; i < sqlText.length; i++) {
            // 用 split(";", -1) 保留尾空串（空语句也算一行）
            String[] parts = sqlText[i].split(";", -1);
            for (String p : parts) {
                stmts.add(new int[]{i, parseTx(p)});
            }
            // 注意：若 split 得到尾空串（最后一个 ; 之后无内容），按题意算 1 行
            // 若不希望多算，可在尾部过滤空串，需根据用例调整
        }
        int N = stmts.size();
        DSU dsu = new DSU(N);

        // 3. 同行内语句合并
        Map<Integer, List<Integer>> byRow = new HashMap<>();
        for (int i = 0; i < N; i++) {
            byRow.computeIfAbsent(stmts.get(i)[0], k -> new ArrayList<>()).add(i);
        }
        for (List<Integer> list : byRow.values()) {
            for (int i = 1; i < list.size(); i++) dsu.union(list.get(0), list.get(i));
        }

        // 4. 同事务号合并
        Map<Integer, List<Integer>> byTx = new HashMap<>();
        for (int i = 0; i < N; i++) {
            int tx = stmts.get(i)[1];
            if (tx > 0) byTx.computeIfAbsent(tx, k -> new ArrayList<>()).add(i);
        }
        for (List<Integer> list : byTx.values()) {
            for (int i = 1; i < list.size(); i++) dsu.union(list.get(0), list.get(i));
        }

        // 5. 统计每个组的行号集合（去重）
        Map<Integer, TreeSet<Integer>> groupRows = new HashMap<>();
        for (int i = 0; i < N; i++) {
            int r = dsu.find(i);
            groupRows.computeIfAbsent(r, k -> new TreeSet<>()).add(stmts.get(i)[0]);
        }

        // 6. 按组首次出现行号升序贪心分配
        List<Integer> roots = new ArrayList<>(groupRows.keySet());
        roots.sort(Comparator.comparingInt(r -> groupRows.get(r).first()));

        int fileCnt = 0, curUsed = 0;
        for (int r : roots) {
            int rows = groupRows.get(r).size();
            if (curUsed + rows > splitLine) {
                fileCnt++;
                curUsed = rows;
            } else {
                curUsed += rows;
            }
        }
        if (curUsed > 0) fileCnt++;
        return fileCnt;
    }

    /** 从语句中解析事务号 [Tn]，无则返回 0 */
    private int parseTx(String s) {
        int i = s.indexOf("[T");
        if (i < 0) return 0;
        int j = s.indexOf("]", i + 2);
        if (j < 0) return 0;
        try { return Integer.parseInt(s.substring(i + 2, j)); }
        catch (Exception e) { return 0; }
    }

    static class DSU {
        int[] p;
        DSU(int n) { p = new int[n]; for (int i = 0; i < n; i++) p[i] = i; }
        int find(int x) { return p[x] == x ? x : (p[x] = find(p[x])); }
        void union(int a, int b) { p[find(a)] = find(b); }
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(N \cdot \alpha(N) + N \log N)\)，N 为总语句数；并查集近似常数，最后排序 \(O(G \log G)\)（G ≤ N）
- **空间复杂度**：\(O(N)\)，并查集 + 行号集合

> 💡 **记忆**：**「同行 + 同事务」两类约束 → 并查集传递合并 → 组行号去重 → 按首次出现行号贪心」**——本质是并查集分组 + 区间分配，与 7.08b「计算碳排放减少量」同属并查集考点。
>
> ⚠️ **易错**：① **行号概念**是「数组下标」而非语句下标，同一行多语句共享行号；② **空语句**（仅含分号）按 1 行计算，`split(";", -1)` 保留尾空串；③ **传递性**通过并查集天然实现，不要手写多轮传播；④ 组行数 = 该组涉及的**不同行号数**（去重），不是组内语句数；⑤ `split_line` 无效（< 1 或 > 10000）直接返回 0。
