# 2026-07-05c. 二叉树两节点间的最小跳数

> **难度**：🟢 中等 | **分值**：200 | **卷次**：新系统 2026-07-05

## 题目描述

给定一棵**完全二叉树**的层序遍历序列（用逗号分隔的节点值字符串表示），以及两个目标节点值 `frm` 和 `to`，求这两个节点之间的**最小跳数**（即最短路径经过的边数）。

### 完全二叉树的性质（数组表示）

- 根节点索引为 `0`
- 索引为 `i` 的节点的**父节点**索引为 `(i-1) // 2`
- 索引为 `i` 的节点的**左子节点**索引为 `2*i + 1`
- 索引为 `i` 的节点的**右子节点**索引为 `2*i + 2`

## 输入描述

- 第一行：字符串形式的层序遍历序列，节点值用逗号分隔，例如 `1,2,3,4,5,6,7`
- 第二行：起始节点值 `frm`
- 第三行：目标节点值 `to`

## 输出描述

输出一个整数，表示从 `frm` 到 `to` 的最小跳数（最短路径的边数）。

- 如果节点不存在于树中，返回 `-1`
- 如果 `frm == to`，返回 `0`

---

## 示例

### 示例 1

```
输入：
1,2,3
2
3

输出：
2
```

**说明**：二叉树结构

```
    1
   / \
  2   3
```

从节点 `2` 到节点 `3`，需要经过边：`2 → 1 → 3`，共 2 跳。

### 示例 2

```
输入：
1,2,3,4,5,6,7
4
5

输出：
2
```

**说明**：二叉树结构

```
        1
       / \
      2   3
     / \ / \
    4  5 6  7
```

节点 `4` 和节点 `5` 是**兄弟节点**，都位于节点 `2` 下方，最小跳数为 `2`（`4 → 2 → 5`）。

---

## 提示

- **完全二叉树索引**：节点 `i` 的父节点是 `(i-1) / 2`，深度可通过不断除 2 计算
- **节点存在性**：先在序列中找到 `frm` 和 `to` 的索引，若任一不存在直接返回 `-1`
- **重复值处理**：若序列中有多个相同值，以**首次出现**的索引为准
- **LCA 性质**：两节点到 LCA 的路径之和即为最短跳数
- **相同节点**：`frm == to` 时跳数为 0

---

## 思路

### 核心思想：索引 → 深度 → LCA

1. **定位索引**：在层序序列中找到 `frm` 和 `to` 的下标 `i` 和 `j`
2. **计算深度**：节点 `i` 的深度 = `floor(log2(i+1))`，或循环 `(i-1) / 2` 直至 0 累计
3. **求 LCA**：让较深的节点向上跳到与较浅节点同深度，然后两个一起向上跳，首次相遇即为 LCA
4. **最小跳数公式**：`depth(frm) + depth(to) - 2 * depth(LCA)`

**逐步演示**（示例 2，`1,2,3,4,5,6,7`，`frm=4, to=5`）：

```
定位索引:
  4 在下标 3 (数组从 0 开始)
  5 在下标 4

计算深度:
  depth(3) = ?  (3+1=4, log2(4)=2 → 深度 2)
  depth(4) = ?  (4+1=5, log2(5)≈2.32 → 深度 2)
  二者同深度，无需先跳

求 LCA:
  i=3, 父 = (3-1)/2 = 1 → 节点值 2
  j=4, 父 = (4-1)/2 = 1 → 节点值 2
  同步上跳一次即相遇，LCA 索引 = 1 (节点值 2)

depth(LCA=1) = 1  (1+1=2, log2(2)=1)

最小跳数 = 2 + 2 - 2*1 = 2  ✓
```

- 时间复杂度：\(O(n + \log n)\)，\(n\) 为节点数；定位索引 \(O(n)\)，LCA 上跳 \(O(\log n)\)
- 空间复杂度：\(O(n)\)，存储层序序列

## 代码

### 我的伪代码

```java
class Solution {
    public int minJumps(String tree, int frm, int to) {
        String[] vals = tree.split(",");
        int n = vals.length;

        // 1. 定位 frm 和 to 的下标（首次出现）
        int i = -1, j = -1;
        for (int k = 0; k < n; k++) {
            int v = Integer.parseInt(vals[k]);
            if (v == frm && i == -1) i = k;
            if (v == to  && j == -1) j = k;
        }
        if (i == -1 || j == -1) return -1;       // 节点不存在
        if (i == j) return 0;                     // 同节点

        // 2. 求 LCA
        int lca = lca(i, j);

        // 3. 最小跳数 = depth(i) + depth(j) - 2*depth(lca)
        return depth(i) + depth(j) - 2 * depth(lca);
    }

    /** 计算节点 i 的深度（根 0 为深度 0） */
    int depth(int i) {
        int d = 0;
        while (i > 0) { i = (i - 1) / 2; d++; }
        return d;
    }

    /** 求节点 i 和 j 的最近公共祖先的索引 */
    int lca(int i, int j) {
        while (i != j) {
            if (i > j) i = (i - 1) / 2;
            else       j = (j - 1) / 2;
        }
        return i;
    }
}
```

### 解法（Java）

```java
import java.util.*;

class Solution {
    public int minJumps(String tree, int frm, int to) {
        String[] vals = tree.split(",");
        int n = vals.length;

        // 1. 定位首次出现的索引
        int i = -1, j = -1;
        for (int k = 0; k < n; k++) {
            int v = Integer.parseInt(vals[k].trim());
            if (v == frm && i == -1) i = k;
            if (v == to  && j == -1) j = k;
        }
        if (i == -1 || j == -1) return -1;
        if (i == j) return 0;

        // 2. 求 LCA 索引
        int lca = lca(i, j);

        // 3. 公式
        return depth(i) + depth(j) - 2 * depth(lca);
    }

    /** 深度：根 0 为 0 层，每向上一代 +1 */
    private int depth(int i) {
        int d = 0;
        while (i > 0) { i = (i - 1) / 2; d++; }
        return d;
    }

    /** 朴素 LCA：先把深的跳到同高，再同步上跳 */
    private int lca(int i, int j) {
        int di = depth(i), dj = depth(j);
        // 让 i 始终是较深的
        if (di < dj) { int t = i; i = j; j = t; int td = di; di = dj; dj = td; }
        // 深的先跳到同高
        while (di > dj) { i = (i - 1) / 2; di--; }
        // 同步上跳
        while (i != j) {
            i = (i - 1) / 2;
            j = (j - 1) / 2;
        }
        return i;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n + \log n)\)，定位索引需 \(O(n)\)，LCA 与深度计算 \(O(\log n)\)
- **空间复杂度**：\(O(n)\)，存层序字符串数组

> 💡 **记忆**：**「完全二叉树父节点 = (i-1)/2，深度靠累加上跳，LCA = 同高后同步上跳」**——本质是树中两节点距离模板题，与剑指 Offer 68-II「二叉树的最近公共祖先」思路一致，只是把指针换成数组索引。
>
> ⚠️ **易错**：① **节点不存在**返回 `-1`，**同节点**返回 `0`，两个分支都要先判；② 重复值取**首次出现**索引；③ LCA 求法先把**深的跳到与浅的同高**，再同步上跳；④ **公式 `depth(frm) + depth(to) - 2 * depth(LCA)`** 是树中两节点距离的通用结论；⑤ 节点值可能为字符串以外的格式，注意 `trim` 防空格。
