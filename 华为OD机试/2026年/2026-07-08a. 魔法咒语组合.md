# 2026-07-08a. 魔法咒语组合

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-08

## 题目描述

玩家收集了 `N` 个魔法咒语碎片，它们可以组合成强大的魔法阵。但并不是所有碎片都能使用——**只含咒语中没有重复字母的碎片才是纯净的**，可以激活。

请找出所有**纯净碎片**，输出由所有纯净碎片组成的所有魔法阵方案。

### 备注

- 所有魔法咒语碎片**互不重复**

## 输入描述

1. 魔法咒语碎片为一个字符串，仅由小写字母构成，没有分隔符，字符串长度不超过 `26`
2. 魔法咒语碎片数量 `N` 不超过 `6` 个

## 输出描述

1. 魔法阵方案，由所有纯净碎片组成的长字符串，每个纯净碎片的字符串之间以**空格**隔开（`" "`）
2. 所有魔法阵方案按**字母序**排列输出

---

## 示例

### 示例 1

```
输入：fire,water,earth
输出：["earth fire water","earth water fire","fire earth water","fire water earth","water earth fire","water fire earth"]
```

**说明**：3 个碎片都纯净（字母不重复），3! = 6 种全排列。

### 示例 2

```
输入：noon,sun,sky
输出：["sky sun","sun sky"]
```

**说明**：

- `noon`：字母 `n` 重复，不纯净，舍弃
- `sun`：字母无重复，纯净
- `sky`：字母无重复，纯净
- 2! = 2 种全排列

---

## 提示

- **纯净判定**：用 `int[26]` 频次表，若任一字母频次 > 1 则不纯净
- **全排列**：N ≤ 6，全排列最多 `6! = 720` 种，递归回溯或 `Permutation` 库都行
- **字典序输出**：题目要求方案按字母序，两种思路：
  - 思路 1：先对纯净碎片列表**按字典序排序**，再做全排列（按 swap 方式生成时天然字典序）
  - 思路 2：先生成所有方案，最后统一排序
- **输出格式**：JSON 风格 `["a b","c d"]`，元素用双引号包裹

---

## 思路

### 核心思想：纯净过滤 + 全排列（递归回溯）

1. **过滤**：对每个碎片判定是否"字母不重复"（用 `int[26]` 频次表）
2. **全排列**：对纯净碎片列表做全排列（递归回溯 + 交换）
3. **格式化**：每个排列用空格连接成字符串，整体用 JSON 数组包裹

**逐步演示**（示例 2，`["noon","sun","sky"]`）：

```
纯净过滤:
  "noon" → n 出现 2 次 → 不纯净 → 舍弃
  "sun"  → 字母全不重复 → 纯净
  "sky"  → 字母全不重复 → 纯净

纯净列表: ["sun", "sky"]   （输入顺序，不做字典序排序的话）

全排列（按输入顺序）:
  [sun, sky] → "sun sky"
  [sky, sun] → "sky sun"

如果题目要求字典序，输出前先对结果排序:
  "sky sun" < "sun sky"
结果: ["sky sun","sun sky"]  ✓
```

- 时间复杂度：\(O(N! \times L)\)，N 纯净碎片数，L 平均长度（每个排列需拼接 N 个字符串）
- 空间复杂度：\(O(N! \times N \times L)\)，存储所有方案

## 代码

### 我的伪代码

```java
class Solution {
    public String magicCombo(String input) {
        String[] fragments = input.split(",");
        List<String> pure = new ArrayList<>();
        for (String f : fragments) {
            if (isPure(f)) pure.add(f);
        }
        // 按字典序排序后再全排列，保证生成顺序天然字典序
        Collections.sort(pure);
        List<String> ans = new ArrayList<>();
        backtrack(pure, 0, ans);
        // 转换 JSON
        return toJSON(ans);
    }
    boolean isPure(String s) {
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) {
            if (++cnt[c - 'a'] > 1) return false;
        }
        return true;
    }
    void backtrack(List<String> list, int idx, List<String> ans) {
        if (idx == list.size()) {
            ans.add(String.join(" ", list));
            return;
        }
        for (int i = idx; i < list.size(); i++) {
            Collections.swap(list, idx, i);
            backtrack(list, idx + 1, ans);
            Collections.swap(list, idx, i);   // 回溯
        }
    }
}
```

### 解法（Java，递归回溯全排列）

```java
import java.util.*;

class Solution {
    public String magicCombo(String input) {
        String[] fragments = input.split(",");
        List<String> pure = new ArrayList<>();
        for (String f : fragments) {
            if (isPure(f)) pure.add(f);
        }
        Collections.sort(pure);                   // 字典序排序后再排
        List<String> ans = new ArrayList<>();
        backtrack(pure, 0, ans);
        // 转换为 JSON 数组格式
        StringBuilder sb = new StringBuilder("[");
        for (int i = 0; i < ans.size(); i++) {
            if (i > 0) sb.append(",");
            sb.append("\"").append(ans.get(i)).append("\"");
        }
        return sb.append("]").toString();
    }

    private boolean isPure(String s) {
        int[] cnt = new int[26];
        for (int i = 0; i < s.length(); i++) {
            if (++cnt[s.charAt(i) - 'a'] > 1) return false;
        }
        return true;
    }

    private void backtrack(List<String> list, int idx, List<String> ans) {
        if (idx == list.size()) {
            ans.add(String.join(" ", list));     // 用空格连接
            return;
        }
        for (int i = idx; i < list.size(); i++) {
            Collections.swap(list, idx, i);      // 选 list[i] 放第 idx 位
            backtrack(list, idx + 1, ans);
            Collections.swap(list, idx, i);      // 回溯
        }
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(N! \times N \times L)\)，N 纯净碎片数，L 平均长度。最坏 6! = 720 种方案。
- **空间复杂度**：\(O(N! \times N \times L)\)，存储所有方案。

> 💡 **记忆**：**「纯净判定用 int[26] 频次 >1 即舍；全排列用 swap 回溯；先排序保证字典序」**——经典全排列模板，等价于 LeetCode 46「全排列」的字符串版。
>
> ⚠️ **易错**：① 纯净判定要**逐字符累计频次**，不是 `Set.size() == length`（虽然等价但前者更快）；② **先排序再回溯**才能保证输出字典序；③ 输出格式 JSON 风格 `["a b","c d"]`，元素用双引号包裹；④ N=0 时（全部不纯净）返回 `[]`。
