# 2026-07-08c. 迷宫相遇

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-07-08 | **标签**：BFS、状态压缩 | **考点**：双动点 BFS + 周期状态压缩

## 题目描述

在一个由 `n` 个节点组成的迷宫中（节点编号 0..n-1，节点间有无向边相连），有两个人 A 和 B：

- **A** 从节点 `startA` 出发，每一步可以**停留在原地**或**移动到相邻节点**
- **B** 沿固定的**巡逻路径** `patrolPath` 循环移动：第一步在 `patrolPath[0]`，第二步在 `patrolPath[1]`，……第 k 步在 `patrolPath[k-1]`

B 的巡逻路径是**往返循环**的：走到路径末尾后**原路返回**到起点，再重新出发，如此往复。具体地，若 `patrolPath = [p0, p1, ..., pk-1]`，则 B 的实际位置序列为：

```
p0, p1, ..., pk-1, pk-2, ..., p1, p0, p1, ..., pk-1, pk-2, ..., p1, p0, ...
```

（即 `[p0..pk-1]` + `[pk-2..p1]` 拼成一个长度 `T = 2k-2` 的循环，然后循环重复）

A 和 B **同时移动**（每步都同时前进一个时刻）。问 A 至少需要多少步才能与 B **在同一节点相遇**？若永远无法相遇，返回 `-1`。

## 输入描述

- 参数 1：`n`（int）：节点数量，编号 0..n-1
- 参数 2：`edges`（`int[][]`）：无向边列表，`edges[i] = [u, v]`
- 参数 3：`startA`（int）：A 的起始节点
- 参数 4：`patrolPath`（`int[]`）：B 的巡逻路径节点序列

## 输出描述

- 输出：A 与 B 相遇的最少步数
- 永远无法相遇返回 `-1`

---

## 示例

### 示例 1

```
输入：n=4, edges=[[0,1],[1,2],[2,3]], startA=0, patrolPath=[2,3]
输出：2
```

**说明**：B 往返周期 T = 2×2-2 = 2，实际位置序列 `2,3,2,3,...`。
- 步 0：A 在 0，B 在 2
- 步 1：A 移到 1，B 移到 3
- 步 2：A 移到 2，B 移到 2 → 相遇！输出 2

### 示例 2

```
输入：n=3, edges=[[0,1],[1,2]], startA=0, patrolPath=[2]
输出：2
```

**说明**：B 巡逻路径只有一个节点 2，T = max(1, 2×1-2) = 1，B 始终在 2。A 从 0 走到 2 需 2 步（0→1→2），输出 2。

### 示例 3

```
输入：n=4, edges=[[0,1]], startA=0, patrolPath=[3]
输出：-1
```

**说明**：B 始终在 3，但 A 所在的连通分量 {0,1} 无法到达 3，返回 -1。

---

## 提示

- **核心是 BFS + 状态 = (A 的位置, B 的相位)**
- B 的相位是周期 T 内的下标，T = `2k - 2`（k ≥ 2），k = 1 时 T = 1（B 不动）
- 状态空间：`n × T`，用 `visited[pos][phase]` 防止重复访问
- A 每步可选动作：停留（原地）+ 移动到每个相邻节点
- B 的相位每步 +1 mod T，B 的实际位置由相位查 `fullCycle` 数组
- 队列元素 `(aPos, phase, dist)`，弹出时先算 B 当前位置，相等则返回 dist

---

## 思路

### 核心思想：BFS + 周期状态压缩

**关键观察**：B 的位置随时间周期性变化（周期 T = 2k-2），所以"B 的位置"可以压缩为"相位 phase ∈ [0, T)"。状态 = `(A 的位置, B 的相位)`，共 `n × T` 种状态。

**预处理 B 的完整周期**：
- 若 `patrolPath = [p0, p1, ..., pk-1]`（k ≥ 2），完整周期 = `[p0, p1, ..., pk-1]` + `[pk-2, ..., p1]`，长度 `T = 2k-2`
- 若 k = 1，B 不动，T = 1，`fullCycle = [patrolPath[0]]`

**BFS 流程**：
1. 队列初始 `(startA, phase=0, dist=0)`，`visited[startA][0] = true`
2. 弹出 `(aPos, phase, dist)`，算 B 当前位置 `bPos = fullCycle[phase]`
3. 若 `aPos == bPos`，返回 dist
4. 否则算下一相位 `newPhase = (phase + 1) % T`
5. A 的下一位置候选：停留（`aPos`）+ 所有相邻节点
6. 对每个候选位置 `nxt`，若 `!visited[nxt][newPhase]`，标记并入队 `(nxt, newPhase, dist+1)`
7. 队列空仍没相遇，返回 -1

**逐步演示**（示例 1，n=4, edges=[[0,1],[1,2],[2,3]], startA=0, patrolPath=[2,3]）：

```
邻接表: 0→[1], 1→[0,2], 2→[1,3], 3→[2]
B 周期: patrolPath=[2,3], k=2, T=2×2-2=2
fullCycle = [2,3]  (正序 [2,3] + 反序 [3,2] 去掉首尾 → 但 k=2 时反序部分只有 [pk-2..p1] = [3..3]? )

修正: T=2k-2=2, fullCycle = [p0, p1] + [pk-2..p1] = [2,3] + [3]? 不对
正确定义: fullCycle = [p0..pk-1] ++ [pk-2..p1]
  = [2,3] ++ [3]?? 不对, pk-2 = p0 = 2, p1 = 3, 反序 [2..3] = [2]? 

最简实现: T = 2k-2 (k>=2), fullCycle 前 k 项为 patrolPath, 后 k-2 项为 patrolPath 倒数第二到第二
  k=2: T=2, fullCycle = [2,3] (前2项) + [] (后0项) = [2,3]
  B 位置序列: 2,3,2,3,...  ✓

BFS:
初始: queue=[(0,0,0)], visited[0][0]=true
弹出 (0,0,0): bPos=fullCycle[0]=2, 0≠2
  newPhase=1
  候选: 停留 0, 移到 1
  → (0,1,1) 入队 visited[0][1]=true
  → (1,1,1) 入队 visited[1][1]=true
弹出 (0,1,1): bPos=fullCycle[1]=3, 0≠3
  newPhase=0
  候选: 停留 0, 移到 1
  → (0,0,?) visited, 跳过
  → (1,0,2) 入队 visited[1][0]=true
弹出 (1,1,1): bPos=3, 1≠3
  newPhase=0
  候选: 停留 1, 移到 0/2
  → (1,0,?) visited
  → (0,0,?) visited
  → (2,0,2) 入队 visited[2][0]=true
弹出 (1,0,2): bPos=fullCycle[0]=2, 1≠2
  ...
弹出 (2,0,2): bPos=fullCycle[0]=2, 2==2 → 返回 2  ✓
```

- 时间复杂度：\(O(n \cdot T)\)，状态数 n×T，每个状态处理一次
- 空间复杂度：\(O(n \cdot T)\)，visited 数组 + 队列

## 代码

### 我的伪代码

```java
class Solution {
    public int meetInMaze(int n, int[][] edges, int startA, int[] patrolPath) {
        // 1. 建邻接表
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        // 2. 预处理 B 的完整周期
        int k = patrolPath.length;
        int T = (k == 1) ? 1 : (2 * k - 2);
        int[] fullCycle = new int[T];
        int idx = 0;
        for (int i = 0; i < k; i++) fullCycle[idx++] = patrolPath[i];
        for (int i = k - 2; i >= 1; i--) fullCycle[idx++] = patrolPath[i];

        // 3. BFS
        boolean[][] visited = new boolean[n][T];
        Queue<int[]> queue = new LinkedList<>();
        queue.offer(new int[]{startA, 0, 0});
        visited[startA][0] = true;

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int aPos = cur[0], phase = cur[1], dist = cur[2];
            int bPos = fullCycle[phase];
            if (aPos == bPos) return dist;

            int newPhase = (phase + 1) % T;
            // A 停留
            if (!visited[aPos][newPhase]) {
                visited[aPos][newPhase] = true;
                queue.offer(new int[]{aPos, newPhase, dist + 1});
            }
            // A 移动到相邻节点
            for (int nxt : graph.get(aPos)) {
                if (!visited[nxt][newPhase]) {
                    visited[nxt][newPhase] = true;
                    queue.offer(new int[]{nxt, newPhase, dist + 1});
                }
            }
        }
        return -1;
    }
}
```

### 解法（Java，BFS + 周期状态压缩）

```java
class Solution {
    public int meetInMaze(int n, int[][] edges, int startA, int[] patrolPath) {
        // 1. 邻接表
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        // 2. 预处理 B 完整周期（往返循环）
        int k = patrolPath.length;
        int T = (k == 1) ? 1 : (2 * k - 2);
        int[] fullCycle = new int[T];
        int idx = 0;
        for (int i = 0; i < k; i++) fullCycle[idx++] = patrolPath[i];
        for (int i = k - 2; i >= 1; i--) fullCycle[idx++] = patrolPath[i];

        // 3. BFS: 状态 = (A 位置, B 相位)
        boolean[][] visited = new boolean[n][T];
        Queue<int[]> queue = new LinkedList<>();
        queue.offer(new int[]{startA, 0, 0});
        visited[startA][0] = true;

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int aPos = cur[0], phase = cur[1], dist = cur[2];
            int bPos = fullCycle[phase];
            if (aPos == bPos) return dist;        // 相遇

            int newPhase = (phase + 1) % T;
            // A 停留原地
            if (!visited[aPos][newPhase]) {
                visited[aPos][newPhase] = true;
                queue.offer(new int[]{aPos, newPhase, dist + 1});
            }
            // A 移动到相邻节点
            for (int nxt : graph.get(aPos)) {
                if (!visited[nxt][newPhase]) {
                    visited[nxt][newPhase] = true;
                    queue.offer(new int[]{nxt, newPhase, dist + 1});
                }
            }
        }
        return -1;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n \cdot T)\)，状态数 n×T，每个状态出队一次处理 O(度数)
- **空间复杂度**：\(O(n \cdot T)\)，visited 二维数组 + 队列

> 💡 **记忆**：**「周期运动的追及 = BFS + 相位状态压缩」**。B 的位置随时间周期变化，把"B 的绝对位置"压缩为"B 的相位 phase"后，状态空间从无穷（时间无限）变为有限 `n × T`，BFS 必然能在有限步内判定能否相遇。
>
> ⚠️ **易错**：① **完整周期 T = 2k-2（k≥2）**，正序 k 项 + 反序 k-2 项（去掉首尾），不是简单的 2k；② k=1 时 B 不动，T=1，`fullCycle=[patrolPath[0]]`，特殊处理避免 `2k-2=0` 导致除零；③ A 每步**可以停留**（不移到相邻节点），不要漏掉这个动作；④ 先算 B 当前位置再判断相遇（用弹出时的 phase，不是 newPhase）。
