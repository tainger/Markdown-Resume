# 2026-07-12a. 字符串压缩编码

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-12

## 题目描述

给定一个只包含大小写英文字母的字符串，请实现字符串压缩编码功能。

### 压缩规则

- 如果字符**连续出现次数大于 1**，则用**字符 + 出现次数**表示
- 如果字符**连续出现次数等于 1**，则**直接输出字符**（不写数字 1）

## 输入描述

- 输入一行，包含一个字符串 `str`（长度 `1 ≤ |str| ≤ 1000`）
- 字符串只包含大小写英文字母

## 输出描述

输出压缩后的字符串。

---

## 示例

### 示例 1

```
输入：aabcccccaaa
输出：a2bc5a3
```

**说明**：`aa`→`a2`，`b`→`b`，`ccccc`→`c5`，`aaa`→`a3`。

### 示例 2

```
输入：b
输出：b
```

### 示例 3

```
输入：AAbB
输出：A2bB
```

### 示例 4

```
输入：aaabbbcccaaa
输出：a3b3c3a3
```

---

## 提示

- 大小写敏感：`A` 和 `a` 是不同字符
- **单个字符不写数字 1**——压缩后输出 `b` 而不是 `b1`
- `|str| ≤ 1000`，次数最多 1000 位，`int` 完全够用
- 注意"连续段"切分：相同字符必须**连续**才算一段，相同字符在不同位置是不同段（如示例 1 的 `a` 出现两次分段）

---

## 思路

### 核心思想：双指针（同向快慢指针）

慢指针 `i` 指向当前连续段起点，快指针 `j` 从 `i` 开始向右扫描，直到 `s[j] != s[i]` 或到末尾，则 `[i, j-1]` 是一段相同字符，长度 `j - i`。

**压缩规则**：

- `len == 1`：只输出字符
- `len > 1`：输出 `字符 + len`

**逐步演示**（示例 1，`s = "aabcccccaaa"`）：

```
i=0, j=2  → 段 "aa"  长度 2 → 输出 "a2"
i=2, j=3  → 段 "b"   长度 1 → 输出 "b"
i=3, j=8  → 段 "ccccc" 长度 5 → 输出 "c5"
i=8, j=11 → 段 "aaa" 长度 3 → 输出 "a3"

结果: "a2bc5a3"  ✓
```

- 时间复杂度：\(O(n)\)，快慢指针各最多扫描 n 次
- 空间复杂度：\(O(n)\)，结果字符串（最坏长度 `2n`，如 `ababab...`）

## 代码

### 我的伪代码

```java
class Solution {
    public String compress(String s) {
        StringBuilder sb = new StringBuilder();
        int i = 0;
        while (i < s.length()) {
            int j = i;
            while (j < s.length() && s.charAt(j) == s.charAt(i)) j++;
            int len = j - i;
            sb.append(s.charAt(i));
            if (len > 1) sb.append(len);
            i = j;
        }
        return sb.toString();
    }
}
```

### 解法（Java，双指针）

```java
class Solution {
    public String compress(String s) {
        StringBuilder sb = new StringBuilder();
        int n = s.length();
        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && s.charAt(j) == s.charAt(i)) {
                j++;
            }
            int len = j - i;
            sb.append(s.charAt(i));
            if (len > 1) {
                sb.append(len);              // 单个字符不写 1
            }
            i = j;
        }
        return sb.toString();
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，快慢指针各最多移动 n 次。
- **空间复杂度**：\(O(n)\)，结果字符串。
