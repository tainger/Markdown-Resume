# 2026-07-12b. 查找满足条件的数据包

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-12

## 题目描述

在数据包传输系统中，为了优化网络带宽利用率，系统需要对数据包序列进行处理，找出每个数据包**右侧第一个**满足某些条件、优先级更高的数据包。

每个数据包的格式为：`<priority>:<weight>`，其中：

- `<priority>` 是数据包的优先级（正整数，`1 ≤ priority ≤ 10^5`，**数值越大优先级越高**）
- `<weight>` 是数据包的权重（正整数，`1 ≤ weight ≤ 10^5`）

系统需要按照以下规则处理数据包：搜索整个数据包序列（从左到右），对于每个数据包，找出其**右侧第一个**同时满足如下条件的数据包：

- **条件 1**：目标数据包的 `priority` **大于**当前数据包的 `priority`
- **条件 2**：目标数据包的 `weight` **等于**当前数据包的 `weight`

请编写一个方法，实现数据包右侧第一个满足条件的数据包查找功能。

## 输入描述

参数 `packets`：数据包内容，长度为 `n`（正整数，`1 ≤ n ≤ 10^5`）的数组，每个元素为 `[priority, weight]`。

## 输出描述

右侧第一个满足条件的数据包 ID 组成的数组序列；

- 数据包 ID 是其在数组中的位置，即第 `i` 个数据包的 ID 为 `i+1`（从 1 开始计数，非数组下标 0）
- 如果某个数据包右侧没有满足条件的数据包，则输出 `0`

---

## 示例

### 示例 1

```
输入：[[5,10],[6,10],[4,10]]
输出：[2,0,0]
```

**说明**：

| 数据包 ID | (priority, weight) | 右侧首个满足条件 | 输出 |
|:---:|:---:|:---|:---:|
| 1 | (5,10) | 第 2 个 `(6,10)`：`6>5` 且 `weight=10` 相同 → 满足 | 2 |
| 2 | (6,10) | 第 3 个 `(4,10)`：`4<6`，不满足；无其他 | 0 |
| 3 | (4,10) | 右侧无数据包 | 0 |

最终输出 `[2, 0, 0]`。

---

## 提示

- **关键陷阱**：本题**不是简单的"下一个更大元素"**——单调栈只能处理"严格 greater"的一维条件，本题是 **二维条件**（priority 严格更大 + weight 完全相等）
- 解法思路：**按 weight 分组**，同 weight 的元素之间找"右侧第一个 priority 更大的位置"
- `n ≤ 10^5`，必须 `O(n)` 或 `O(n log n)`，暴力 `O(n²)` 会 TLE
- **同 weight 分组**后，组内对每个元素从右向左用单调栈（栈顶 priority 更大者即"右侧首个更大"）
- ID 从 1 开始，注意返回时**下标 + 1**

---

## 思路

### 核心思想：按 weight 分组 + 单调栈（从右往左）

由于条件 2 要求 `weight` 相等，所以**只可能在同一 weight 组内**找到答案。分组后，问题退化为"组内每个元素右侧第一个 priority 严格更大的位置"——经典单调栈。

**单调栈框架**（从右往左扫描）：

- 栈中保存**下标**，对应 priority **严格递减**（栈顶 priority 最小）
- 对当前下标 `i`，若 `stack.top().priority > p[i].priority`，则 `ans[i] = stack.top() + 1`（ID 从 1 起）
- 否则不断弹栈，直到栈空或栈顶 priority 更大
- 最后把 `i` 入栈

**逐步演示**（示例 1，`packets=[[5,10],[6,10],[4,10]]`）：

```
按 weight 分组:
  weight=10: 下标 [0,1,2]，priority=[5,6,4]

组内从右往左单调栈（求"右侧第一个 priority 更大"）:
  i=2 (p=4): 栈空 → ans[2]=0; 入栈 → 栈=[2]
  i=1 (p=6): 栈顶 priority=4 < 6 → 弹栈 → 栈空 → ans[1]=0; 入栈 → 栈=[1]
  i=0 (p=5): 栈顶 priority=6 > 5 → ans[0] = 栈顶下标+1 = 1+1 = 2 ✓
             不弹栈（保留更大者）→ 入栈 → 栈=[1,0]（其实不需要，因为已扫完）

最终 ans (下标从0开始): [2, 0, 0]
转换为 ID (下标+1):    [2, 0, 0]  ✓
```

- 时间复杂度：\(O(n)\)，分组 + 单调栈各扫描一次
- 空间复杂度：\(O(n)\)，分组哈希表 + 栈

## 代码

### 我的伪代码

```java
class Solution {
    public int[] findNextPacket(int[][] packets) {
        int n = packets.length;
        int[] ans = new int[n];
        // 按 weight 分组
        Map<Integer, List<Integer>> groups = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int w = packets[i][1];
            groups.computeIfAbsent(w, k -> new ArrayList<>()).add(i);
        }
        // 每组从右往左单调栈
        for (List<Integer> idxs : groups.values()) {
            Deque<Integer> stack = new ArrayDeque<>();
            for (int k = idxs.size() - 1; k >= 0; k--) {
                int i = idxs.get(k);
                while (!stack.isEmpty() && packets[stack.peek()][0] <= packets[i][0]) {
                    stack.pop();
                }
                ans[i] = stack.isEmpty() ? 0 : stack.peek() + 1;   // ID 从 1 起
                stack.push(i);
            }
        }
        return ans;
    }
}
```

### 解法（Java，分组 + 单调栈）

```java
import java.util.*;

class Solution {
    public int[] findNextPacket(int[][] packets) {
        int n = packets.length;
        int[] ans = new int[n];
        // 按 weight 分组（同 weight 才可能匹配条件 2）
        Map<Integer, List<Integer>> groups = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int w = packets[i][1];
            groups.computeIfAbsent(w, k -> new ArrayList<>()).add(i);
        }
        // 每组从右往左用单调栈求"右侧首个 priority 严格更大的下标"
        for (List<Integer> idxs : groups.values()) {
            Deque<Integer> stack = new ArrayDeque<>();
            for (int k = idxs.size() - 1; k >= 0; k--) {
                int i = idxs.get(k);
                while (!stack.isEmpty()
                       && packets[stack.peek()][0] <= packets[i][0]) {
                    stack.pop();                  // 栈顶 priority 不大于当前 → 弹
                }
                ans[i] = stack.isEmpty() ? 0 : stack.peek() + 1;  // 下标+1 = ID
                stack.push(i);
            }
        }
        return ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，分组扫描一次 + 每个元素入栈/出栈各一次。
- **空间复杂度**：\(O(n)\)，分组哈希表 + 栈。

> 💡 **记忆**：**「按 weight 分组，组内从右往左单调栈求右侧首个严格更大 priority」**——经典"下一个更大元素"LeetCode 496/503 的二维变体。
>
> ⚠️ **易错**：① ID 从 1 开始，**栈顶下标 + 1** 才是答案；② 单调栈**严格 `>`** 才满足（`priority` 必须大于当前），所以弹栈条件是 `<=`；③ 必须先分组，**不能跨 weight 比较**。
