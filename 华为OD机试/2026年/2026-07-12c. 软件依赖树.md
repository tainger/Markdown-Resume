# 2026-07-12c. 软件依赖树

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-07-12 | **标签**：BFS | **考点**：依赖树 BFS 展开 + 路径排除项传递

## 题目描述

在软件构建中，模块之间存在复杂的依赖关系。请基于给定的依赖规则和项目的直接依赖列表，按照依赖解析规则展开完整的依赖树，按 BFS 顺序输出所有依赖组件及其版本号。

### 数据格式

- **直接依赖 `directDeps`**：项目所直接依赖的组件列表。每条格式为 `name:version[:exclusions]`，多个组件用英文逗号分隔，多个排除项用逗号分隔。例如 `["A:1.0","B:2.0:C,D"]`。
- **依赖规则 `depRules`**：每个组件的子依赖列表。每条格式为 `name:depname:depversion[:exclusions]`，表示 `name` 依赖 `depname`（版本 `depversion`），若附带排除项则 `name` 的依赖传递中排除这些名字。

### 解析规则

1. 从直接依赖出发，依次展开每个组件的子依赖，形成依赖树。
2. 使用 **BFS（广度优先）** 遍历组件，同一层中按声明顺序处理父组件，父优先。
3. 同一组件**只保留首次出现的位置**，后续重复依赖需要去重。
4. 排除项沿路径**向下传递**：被排除的组件及其整个子树都不会被加入。
5. 子规则的 `exclusions` 与路径上的父级 `exclusions` 做**集合并集**后继续下传。

### 输出

按 BFS 顺序输出所有依赖组件（去重后），每个组件输出为 `name:version`。

## 输入描述

- 参数 1：`directDeps`（字符串数组）：项目直接依赖列表。
- 参数 2：`depRules`（字符串数组）：依赖规则列表。

## 输出描述

按解析后 BFS 顺序输出每个依赖项，格式为 `name:version`，用逗号分隔，整体用方括号包围，例：`["A:1.0","B:1.0","C:1.0"]`。

## 示例

### 示例 1

```
输入：
["A:1.0"]

输出：
```

**说明**：项目直接依赖 A:1.0；A 声明依赖 B:1.0 和 C:1.0。BFS 顺序：A → B → C。

**说明**：项目直接依赖 A:1.0，并排除 EXCL。A 规则依赖 B，但 (示例未完整说明，但根据规则 5，排除项沿路径传递，若 B 也被排除则 B 不出现)。

## 提示

- **BFS + 去重 + 路径排除项**：经典依赖解析问题（Maven/Gradle 同款）
- 队列元素要带 3 个字段：`name`、`version`、`exclusions`（路径累积的排除集合）
- 排除项是**沿路径累积**的（规则 5：父级排除项 ∪ 子规则自带排除项）
- **同一组件只保留首次出现**，但要注意"首次"是按 BFS 顺序，所以队列要先入队再标记 visited
- 字符串解析：用 `:` 分割，最多 3 段（`name:version` 或 `name:version:excl1,excl2`）

---

## 思路

### 核心思想：BFS + visited 去重 + 路径累积 exclusion

**队列元素**：`(name, version, pathExclSet)`，表示"该节点+从根到该节点累积的排除项集合"。

**BFS 流程**：

1. 把 `directDeps` 解析后入队，初始 `pathExclSet` 为该条依赖自带的 exclusion
2. 出队一个节点 `(name, version, exclSet)`：
   - 若 `name` 已在 `visited` 中，**跳过**（规则 3）
   - 否则加入 `visited` 和结果列表
   - 查 `depRules` 中所有 `name == 当前 name` 的规则，对每条 `(depname, depversion, ruleExcl)`：
     - 计算新累积排除集 `newExcl = exclSet ∪ ruleExcl`
     - 若 `depname ∈ newExcl`，**跳过**（规则 4）
     - 否则把 `(depname, depversion, newExcl)` 入队
3. BFS 结束后输出结果列表

**逐步演示**（示例 1）：

```
directDeps = ["A:1.0"]  → 初始队列: [(A, 1.0, {})]
depRules: A → B:1.0, A → C:1.0

BFS 出队 (A, 1.0, {}):
  A 未访问 → visited={A}, 结果=[A:1.0]
  A 的子规则:
    (B, 1.0, {}) → newExcl = {} ∪ {} = {} → B 不在排除集 → 入队
    (C, 1.0, {}) → newExcl = {} ∪ {} = {} → C 不在排除集 → 入队
  队列: [(B,1.0,{}), (C,1.0,{})]

出队 (B, 1.0, {}):
  B 未访问 → visited={A,B}, 结果=[A:1.0, B:1.0]
  B 无子规则 → 无入队

出队 (C, 1.0, {}):
  C 未访问 → visited={A,B,C}, 结果=[A:1.0, B:1.0, C:1.0]
  C 无子规则 → 无入队

输出: ["A:1.0","B:1.0","C:1.0"]  ✓
```

- 时间复杂度：\(O(N + E)\)，N 是组件数，E 是依赖边数
- 空间复杂度：\(O(N + E)\)，队列 + visited + depRules 哈希

## 代码

### 我的伪代码

```java
class Solution {
    public String resolveDeps(String[] directDeps, String[] depRules) {
        // 1. 解析 depRules → Map<name, List<Rule>>
        Map<String, List<String[]>> rules = new HashMap<>();
        for (String r : depRules) {
            String[] parts = r.split(":");
            // parts: [name, depname, depversion, (可选)excl]
            rules.computeIfAbsent(parts[0], k -> new ArrayList<>()).add(parts);
        }
        // 2. BFS
        Set<String> visited = new HashSet<>();
        List<String> result = new ArrayList<>();
        Deque<String[]> queue = new ArrayDeque<>();   // [name, version, exclStr]
        for (String d : directDeps) {
            String[] parts = d.split(":");
            String excl = parts.length > 2 ? parts[2] : "";
            queue.offer(new String[]{parts[0], parts[1], excl});
        }
        while (!queue.isEmpty()) {
            String[] cur = queue.poll();
            String name = cur[0], version = cur[1];
            Set<String> exclSet = parseExcl(cur[2]);
            if (visited.contains(name)) continue;
            visited.add(name);
            result.add(name + ":" + version);
            if (rules.containsKey(name)) {
                for (String[] r : rules.get(name)) {
                    String depname = r[1], depver = r[2];
                    String ruleExcl = r.length > 3 ? r[3] : "";
                    Set<String> newExcl = new HashSet<>(exclSet);
                    newExcl.addAll(parseExcl(ruleExcl));
                    if (newExcl.contains(depname)) continue;
                    queue.offer(new String[]{depname, depver, String.join(",", newExcl)});
                }
            }
        }
        // 3. 输出
        return "[" + String.join(",", result.stream().map(s -> "\"" + s + "\"").toList()) + "]";
    }
}
```

### 解法（Java，BFS + 路径排除项传递）

```java
import java.util.*;

class Solution {
    public String resolveDeps(String[] directDeps, String[] depRules) {
        // 1. 解析依赖规则 → name → 子规则列表
        Map<String, List<String[]>> rules = new HashMap<>();
        for (String r : depRules) {
            String[] parts = r.split(":");
            // parts: [name, depname, depversion, (可选)excl1,excl2]
            rules.computeIfAbsent(parts[0], k -> new ArrayList<>()).add(parts);
        }
        // 2. BFS：队列元素 {name, version, pathExclSet}
        Set<String> visited = new HashSet<>();
        List<String> result = new ArrayList<>();
        Deque<Object[]> queue = new ArrayDeque<>();
        for (String d : directDeps) {
            String[] parts = d.split(":");
            Set<String> excl = parts.length > 2
                ? new HashSet<>(Arrays.asList(parts[2].split(",")))
                : new HashSet<>();
            queue.offer(new Object[]{parts[0], parts[1], excl});
        }
        while (!queue.isEmpty()) {
            Object[] cur = queue.poll();
            String name = (String) cur[0];
            String version = (String) cur[1];
            @SuppressWarnings("unchecked")
            Set<String> exclSet = (Set<String>) cur[2];
            if (visited.contains(name)) continue;          // 去重
            visited.add(name);
            result.add(name + ":" + version);
            // 展开子依赖
            if (rules.containsKey(name)) {
                for (String[] r : rules.get(name)) {
                    String depname = r[1];
                    String depver = r[2];
                    Set<String> ruleExcl = r.length > 3
                        ? new HashSet<>(Arrays.asList(r[3].split(",")))
                        : new HashSet<>();
                    Set<String> newExcl = new HashSet<>(exclSet);
                    newExcl.addAll(ruleExcl);               // 路径并集传递
                    if (newExcl.contains(depname)) continue; // 被排除则跳过
                    queue.offer(new Object[]{depname, depver, newExcl});
                }
            }
        }
        // 3. JSON 风格输出
        StringBuilder sb = new StringBuilder("[");
        for (int i = 0; i < result.size(); i++) {
            if (i > 0) sb.append(",");
            sb.append("\"").append(result.get(i)).append("\"");
        }
        return sb.append("]").toString();
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(N + E)\)，N 是组件数，E 是依赖边数（每个边最多入队一次）。
- **空间复杂度**：\(O(N + E)\)，规则哈希 + 队列 + visited。

> 💡 **记忆**：**「BFS 展开 + 路径 exclusion 累积并集 + visited 去重」**——Maven 依赖解析同款逻辑，关键在"exclusion 沿路径传递，子规则自带 exclusion 加入累积集"。
>
> ⚠️ **易错**：① **去重要在出队时判断**，而不是入队时（因为入队时 visited 还没更新，多个相同 name 可能都入队）；② exclusion 是**沿路径累积**的，每次入队子节点时要把**父的 exclSet ∪ 子规则的 excl** 作为新 exclSet；③ 字符串解析 `name:version:excl` 时 **excl 可能有多个**，用 `,` 分隔。
