# 2026-07-15a. 谁没交卷

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-15 | **标签**：集合 | **考点**：集合差集 + 升序枚举

## 题目描述

某次考试共有 `n` 名学生，学号从 `1` 到 `n`。考试结束后，老师收到了部分学生提交的答卷，已交卷学生的学号以**逗号分隔的字符串**形式给出。

请找出**未交卷的学生学号**，按**升序**排列，并以 `[学号1,学号2,...]` 的格式输出（方括号内无空格）。

## 输入描述

- 参数 1：`n`（int）：班级学生总数，学号 1..n
- 参数 2：`submitted`（String）：已交卷学生学号的逗号分隔字符串，例如 `"1,3,5"`

## 输出描述

- 输出：未交卷学生学号升序排列，格式 `[1,2,4]`
- 若全部交卷，输出 `[]`

---

## 示例

### 示例 1

```
输入：n=5, submitted="1,3,5"
输出：[2,4]
```

**说明**：学号 1-5 中，1、3、5 已交卷，未交卷的是 2 和 4，升序输出 `[2,4]`。

### 示例 2

```
输入：n=3, submitted="1,2,3"
输出：[]
```

**说明**：所有学生都已交卷，输出空列表。

### 示例 3

```
输入：n=4, submitted="4,2,1,3"
输出：[]
```

**说明**：已交卷字符串无序，但 1-4 全部交卷，输出 `[]`。

---

## 提示

- **典型集合差集问题**：全集合 {1..n} 减去已交卷集合
- 由于学号天然是 1..n 的连续整数，**直接遍历 1..n 检查是否在已交卷集合中**即可，无需排序
- 用 `HashSet<Integer>` 存已交卷学号，查询 O(1)
- 注意输入字符串可能有空格，解析时要 `trim()`
- 输出格式：`[a,b,c]`，方括号内逗号分隔、无空格

---

## 思路

### 核心思想：HashSet + 升序枚举

把已交卷学号存入 `HashSet`，然后从 1 到 n 顺序枚举学号，不在集合中的就是未交卷的。由于枚举本身就是升序，无需额外排序。

**逐步演示**（示例 1，n=5, submitted="1,3,5"）：

```
解析 submitted → {1, 3, 5}
枚举 i=1..5:
  i=1: in set → 跳过
  i=2: not in set → missing=[2]
  i=3: in set → 跳过
  i=4: not in set → missing=[2,4]
  i=5: in set → 跳过
输出: [2,4]  ✓
```

- 时间复杂度：\(O(n)\)，枚举 1..n + 字符串解析 O(k)
- 空间复杂度：\(O(k)\)，k 为已交卷人数

## 代码

### 我的伪代码

```java
class Solution {
    public String findUnsubmitted(int n, String submitted) {
        Set<Integer> submittedSet = new HashSet<>();
        for (String s : submitted.split(",")) {
            submittedSet.add(Integer.parseInt(s.trim()));
        }
        List<Integer> missing = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            if (!submittedSet.contains(i)) missing.add(i);
        }
        StringBuilder sb = new StringBuilder("[");
        for (int i = 0; i < missing.size(); i++) {
            if (i > 0) sb.append(",");
            sb.append(missing.get(i));
        }
        return sb.append("]").toString();
    }
}
```

### 解法（Java，HashSet 差集 + 顺序枚举）

```java
class Solution {
    public String findUnsubmitted(int n, String submitted) {
        // 1. 解析已交卷学号到 HashSet
        Set<Integer> submittedSet = new HashSet<>();
        for (String s : submitted.split(",")) {
            submittedSet.add(Integer.parseInt(s.trim()));
        }
        // 2. 升序枚举 1..n，找出不在集合中的学号
        List<Integer> missing = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            if (!submittedSet.contains(i)) {
                missing.add(i);
            }
        }
        // 3. 拼接输出 [a,b,c]
        StringBuilder sb = new StringBuilder("[");
        for (int i = 0; i < missing.size(); i++) {
            if (i > 0) sb.append(",");
            sb.append(missing.get(i));
        }
        return sb.append("]").toString();
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n + k)\)，解析 k 个学号 + 枚举 n 个学号
- **空间复杂度**：\(O(k)\)，HashSet 存已交卷学号

> 💡 **记忆**：**「连续编号差集 = HashSet + 顺序枚举」**。学号是 1..n 的天然升序，枚举即排序，比"求差集再排序"更简单。
>
> ⚠️ **易错**：① 输入字符串可能有空格（如 `"1, 3, 5"`），必须 `trim()` 后再 `parseInt`；② 输出格式无空格 `[2,4]` 不是 `[2, 4]`；③ 空结果输出 `[]` 而非空字符串。
