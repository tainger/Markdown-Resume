# 2026-07-15b. 日期格式统一与排序

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-15 | **标签**：字符串、排序 | **考点**：日期解析 + 闰年校验 + 去重排序

## 题目描述

给定一组日期字符串，每个日期可能使用 `/` 或 `-` 作为分隔符。请将所有**合法日期**统一格式为 `YYYY-MM-DD`，**去重后按日期升序**输出。

### 合法日期规则

- 年份：4 位数字，范围 `[1000, 2100]`
- 月份：1-2 位数字，范围 `[1, 12]`
- 日：1-2 位数字，需符合该月实际天数（考虑闰年）
- **分隔符必须统一**：同一天日期中不能同时出现 `/` 和 `-`，且必须使用其中一种

非法日期（不满足上述任一条件）直接丢弃。

## 输入描述

- 参数：字符串数组 `dates`，每个元素是一个日期字符串

## 输出描述

- 输出：合法日期去重升序排列，格式 `["YYYY-MM-DD","YYYY-MM-DD",...]`
- 若所有日期都非法，输出 `["NULL"]`

---

## 示例

### 示例 1

```
输入：["2026/7/15","2026-07-15","2026/13/1","2026-2-30"]
输出：["2026-07-15"]
```

**说明**：
- `2026/7/15` → 合法，统一为 `2026-07-15`
- `2026-07-15` → 合法，统一为 `2026-07-15`（与上一条重复，去重）
- `2026/13/1` → 月份 13 非法，丢弃
- `2026-2-30` → 2 月没有 30 号，丢弃
- 最终去重升序：`["2026-07-15"]`

### 示例 2

```
输入：["2024/2/29","2025/2/29","abcd/1/1"]
输出：["2024-02-29"]
```

**说明**：2024 是闰年，2 月有 29 号（合法）；2025 非闰年，2 月只有 28 号（非法）；`abcd/1/1` 年份非数字（非法）。

### 示例 3

```
输入：["2026/1-1","abc"]
输出：["NULL"]
```

**说明**：`2026/1-1` 同时含 `/` 和 `-`（非法）；`abc` 无分隔符（非法）；全部非法，输出 `["NULL"]`。

---

## 提示

- **核心是字符串解析 + 闰年判断 + TreeSet 去重排序**
- 分隔符校验：`contains("/")` 与 `contains("-")` 不能同时为 true，且至少有一个
- 闰年规则：能被 4 整除且不能被 100 整除，或能被 400 整除
- 2 月天数：平年 28，闰年 29
- 用 `TreeSet<String>` 自动去重 + 排序（`YYYY-MM-DD` 字符串字典序与日期序一致）
- 全空时输出 `["NULL"]`，注意 NULL 是字符串字面量

---

## 思路

### 核心思想：解析 + 校验 + TreeSet

对每个日期字符串：
1. 判分隔符：只能含 `/` 或 `-` 之一，否则非法
2. 用对应分隔符 split，必须 3 段
3. 年份必须 4 位数字，月日必须为数字
4. 年份范围 [1000, 2100]，月份 [1, 12]
5. 根据月份和闰年判断日是否合法
6. 合法则格式化为 `YYYY-MM-DD` 加入 TreeSet

**逐步演示**（示例 1，`["2026/7/15","2026-07-15","2026/13/1","2026-2-30"]`）：

```
"2026/7/15": 仅含 /, split → [2026,7,15], 年4位✓ 月1-12✓ 7月31天, 15≤31✓ → "2026-07-15"
"2026-07-15": 仅含 -, split → [2026,07,15], 合法 → "2026-07-15" (重复, TreeSet 去重)
"2026/13/1": 月=13 > 12 → 非法, 丢弃
"2026-2-30": 2月, 2026非闰年, maxDay=28, 30>28 → 非法, 丢弃
TreeSet = {"2026-07-15"}
输出: ["2026-07-15"]  ✓
```

- 时间复杂度：\(O(k \log k)\)，k 个日期，TreeSet 插入 log k
- 空间复杂度：\(O(k)\)，TreeSet 存合法日期

## 代码

### 我的伪代码

```java
class Solution {
    public String unifyAndSort(String[] dates) {
        TreeSet<String> set = new TreeSet<>();
        for (String s : dates) {
            String fmt = parseDate(s);
            if (fmt != null) set.add(fmt);
        }
        if (set.isEmpty()) return "[\"NULL\"]";
        // 拼接 ["d1","d2",...]
        StringBuilder sb = new StringBuilder("[");
        boolean first = true;
        for (String d : set) {
            if (!first) sb.append(",");
            sb.append("\"").append(d).append("\"");
            first = false;
        }
        return sb.append("]").toString();
    }

    private String parseDate(String s) {
        boolean hasSlash = s.contains("/");
        boolean hasDash = s.contains("-");
        if (hasSlash && hasDash) return null;     // 分隔符混用
        String delim = hasSlash ? "/" : (hasDash ? "-" : null);
        if (delim == null) return null;           // 无分隔符
        String[] parts = s.split(delim);
        if (parts.length != 3) return null;
        if (!parts[0].matches("\\d{4}")) return null;  // 年份必须 4 位
        if (!parts[1].matches("\\d+") || !parts[2].matches("\\d+")) return null;
        int y = Integer.parseInt(parts[0]);
        int m = Integer.parseInt(parts[1]);
        int d = Integer.parseInt(parts[2]);
        if (y < 1000 || y > 2100 || m < 1 || m > 12) return null;
        int[] days = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        int maxDay = days[m - 1];
        if (m == 2 && ((y % 4 == 0 && y % 100 != 0) || y % 400 == 0)) maxDay = 29;
        if (d < 1 || d > maxDay) return null;
        return String.format("%04d-%02d-%02d", y, m, d);
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(k \log k)\)，k 个日期字符串，每个解析 O(L)，TreeSet 插入 O(log k)
- **空间复杂度**：\(O(k)\)，TreeSet 最多存 k 个合法日期

> 💡 **记忆**：**「日期统一 = 分隔符校验 + 闰年判断 + TreeSet」**。`YYYY-MM-DD` 字符串的字典序天然等于日期序，TreeSet 一把完成去重 + 排序。
>
> ⚠️ **易错**：① 分隔符不能混用（`/` 和 `-` 不能同时出现）；② 年份必须 4 位数字（`2026` 合法，`26` 非法）；③ 闰年规则是 `(能4且不能100) 或 能400`，不是简单的"能4整除"；④ 全非法时输出 `["NULL"]`（字符串字面量）而非 `[]`。
