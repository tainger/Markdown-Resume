# 2026-07-15c. 毕业旅行

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-07-15 | **标签**：图、最短路 | **考点**：Dijkstra 单源最短路 + 预算约束

## 题目描述

小明即将毕业，计划进行一次毕业旅行。共有 `n` 个城市（编号 1 到 `n`），小明从城市 `1` 出发，希望到达城市 `n`。

城市之间有 `m` 条**单向**路线，每条路线 `routes[i] = [u, v, c]` 表示从城市 `u` 到城市 `v` 需要花费 `c` 元。

小明此次旅行的预算为 `w` 元。请计算在**花费不超过预算 `w`** 的前提下，从城市 1 到城市 `n` 的**最小花费**；若无法在预算内到达，返回 `-1`。

## 输入描述

- 参数 1：`n`（int）：城市数量，编号 1..n
- 参数 2：`m`（int）：单向路线数量
- 参数 3：`w`（int）：旅行预算
- 参数 4：`routes`（`int[][]`）：每条路线 `[u, v, c]`，表示 u→v 花费 c

## 输出描述

- 输出：预算内从城市 1 到城市 n 的最小花费
- 不可达或超过预算，返回 `-1`

---

## 示例

### 示例 1

```
输入：n=4, m=5, w=10, routes=[[1,2,2],[1,3,5],[2,3,1],[2,4,6],[3,4,2]]
输出：5
```

**说明**：
- 路径 1→2→3→4：2+1+2=5（预算内）
- 路径 1→3→4：5+2=7（预算内但更贵）
- 路径 1→2→4：2+6=8（预算内但更贵）
- 最小花费为 5，不超过预算 10，输出 5

### 示例 2

```
输入：n=3, m=2, w=5, routes=[[1,2,10],[2,3,10]]
输出：-1
```

**说明**：1→2 花费 10 已超过预算 5，无法在预算内到达城市 3，返回 -1。

### 示例 3

```
输入：n=3, m=1, w=100, routes=[[1,2,5]]
输出：-1
```

**说明**：没有从城市 2 到城市 3 的路线，无法到达，返回 -1。

---

## 提示

- **典型单源最短路问题**：非负权边 + 求最小花费 → Dijkstra 算法
- 用**邻接表**存图（单向边），优先队列（小顶堆）按距离排序
- 最后判断：`dist[n] > w` 或 `dist[n] == INF` 都返回 -1
- 城市编号 1..n，建图时数组开 `n+1` 长
- 注意 n=1 的边界：起点即终点，花费 0

---

## 思路

### 核心思想：Dijkstra + 预算后置校验

用标准 Dijkstra 算法求从城市 1 到所有城市的最小花费，最后检查 `dist[n]` 是否超过预算 `w`。

**Dijkstra 流程**：
1. 初始化 `dist[1] = 0`，其余为 `INF`
2. 优先队列（按距离升序）初始放入 `(0, 1)`
3. 每次取出距离最小的节点 `u`，若 `d > dist[u]` 则跳过（过期节点）
4. 遍历 `u` 的出边 `(v, c)`，若 `dist[u] + c < dist[v]` 则更新并入队
5. 最后返回 `dist[n]`（需校验是否超预算）

**逐步演示**（示例 1，n=4, routes=[[1,2,2],[1,3,5],[2,3,1],[2,4,6],[3,4,2]]）：

```
邻接表: 1→[(2,2),(3,5)], 2→[(3,1),(4,6)], 3→[(4,2)], 4→[]
dist: [INF,0,INF,INF,INF]   (下标 0 不用)
pq: [(0,1)]

弹出 (0,1): 遍历 1 的边
  → 2: 0+2=2 < INF, dist[2]=2, 入 (2,2)
  → 3: 0+5=5 < INF, dist[3]=5, 入 (5,3)
弹出 (2,2): 遍历 2 的边
  → 3: 2+1=3 < 5, dist[3]=3, 入 (3,3)
  → 4: 2+6=8 < INF, dist[4]=8, 入 (8,4)
弹出 (3,3): 遍历 3 的边
  → 4: 3+2=5 < 8, dist[4]=5, 入 (5,4)
弹出 (5,3): 5 > dist[3]=3, 过期跳过
弹出 (5,4): 5 == dist[4]=5, 过期跳过 (或处理但无更新)
弹出 (8,4): 8 > dist[4]=5, 过期跳过

dist[n]=dist[4]=5 ≤ 10 (预算), 输出 5  ✓
```

- 时间复杂度：\(O((n+m) \log n)\)，优先队列 Dijkstra
- 空间复杂度：\(O(n+m)\)，邻接表 + dist 数组 + 优先队列

## 代码

### 我的伪代码

```java
class Solution {
    public int minTravelCost(int n, int m, int w, int[][] routes) {
        List<int[]>[] graph = new List[n + 1];
        for (int i = 0; i <= n; i++) graph[i] = new ArrayList<>();
        for (int[] r : routes) graph[r[0]].add(new int[]{r[1], r[2]});

        int[] dist = new int[n + 1];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[1] = 0;
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        pq.offer(new int[]{0, 1});

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int d = cur[0], u = cur[1];
            if (d > dist[u]) continue;
            for (int[] edge : graph[u]) {
                int v = edge[0], c = edge[1];
                if (d + c < dist[v]) {
                    dist[v] = d + c;
                    pq.offer(new int[]{dist[v], v});
                }
            }
        }
        return dist[n] == Integer.MAX_VALUE || dist[n] > w ? -1 : dist[n];
    }
}
```

### 解法（Java，Dijkstra 优先队列版）

```java
class Solution {
    public int minTravelCost(int n, int m, int w, int[][] routes) {
        // 1. 建邻接表（单向边）
        List<int[]>[] graph = new List[n + 1];
        for (int i = 0; i <= n; i++) graph[i] = new ArrayList<>();
        for (int[] r : routes) {
            graph[r[0]].add(new int[]{r[1], r[2]});
        }

        // 2. Dijkstra
        int[] dist = new int[n + 1];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[1] = 0;
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        pq.offer(new int[]{0, 1});

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int d = cur[0], u = cur[1];
            if (d > dist[u]) continue;            // 过期节点跳过
            for (int[] edge : graph[u]) {
                int v = edge[0], c = edge[1];
                if (d + c < dist[v]) {
                    dist[v] = d + c;
                    pq.offer(new int[]{dist[v], v});
                }
            }
        }

        // 3. 校验预算
        return dist[n] == Integer.MAX_VALUE || dist[n] > w ? -1 : dist[n];
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O((n + m) \log n)\)，每个节点最多入队 O(n) 次，每次出队 log n
- **空间复杂度**：\(O(n + m)\)，邻接表存 m 条边 + dist 数组 n + 优先队列

> 💡 **记忆**：**「非负权单源最短路 = Dijkstra 优先队列版」**。这是图论最经典的模板，必须熟练默写。预算约束只需最后校验 `dist[n] > w`，无需在算法中剪枝（剪枝反而可能漏解）。
>
> ⚠️ **易错**：① "过期节点"判断 `d > dist[u]` 必须 continue，否则会重复处理导致 TLE 或错误更新；② 城市编号 1..n，数组开 `n+1`，下标 0 不用；③ 返回时双重校验：`dist[n] == INF`（不可达）或 `dist[n] > w`（超预算）都返回 -1；④ 注意 n=1 边界（起点即终点，dist[1]=0，返回 0）。
