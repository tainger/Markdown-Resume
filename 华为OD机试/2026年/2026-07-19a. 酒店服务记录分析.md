# 2026-07-19a. 酒店服务记录分析

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-19 | **标签**：集合、哈希 | **考点**：按首次出现顺序输出重复字符

## 题目描述

你是某连锁酒店的数据分析师，酒店每天都会用一串编码记录各分店收到的服务请求类型，编码由小写字母 `[a-z]` 组成，每个字母代表一种特定类型的服务请求（如 a-客房清洁、b-设备维修、c-餐饮服务等等）。

为了优化资源分配，总部需要找出在当天内**重复出现**的服务类型，并按照它们**首次出现的时间顺序**生成报告。

现在给定一个服务记录字符串 `record`（仅包含小写字母 a-z），请找出所有**出现超过一次**的服务类型，并将这些服务类型按照它们在记录中**第一次出现的顺序**放入结果列表中。如果没有服务类型重复出现，返回空列表。

### 补充说明

- 结果只列出符合条件的服务类型的编号 `a-z`，编号的顺序按照**第一次出现**的顺序排列
- 输出格式为 JSON 风格列表：元素使用英文双引号包裹，多个元素之间使用英文逗号分隔，逗号后不加空格

## 输入描述

输入为一个字符串 `record`，仅包含小写字母 `a-z`。

## 输出描述

输出为一个列表，包含所有出现超过一次的服务类型的编号（`a-z`），按首次出现的顺序排列；若无重复类型，输出空列表 `[]`。

## 示例

### 示例 1

```
输入：programming
输出：["r","g","m"]
```

**说明**：`r` 出现 2 次（位置 2/3），`g` 出现 2 次（位置 4/11），`m` 出现 2 次（位置 7/10）。按首次出现顺序：r、g、m。

### 示例 2

```
输入：hello
输出：["l"]
```

**说明**：只有 `l` 重复出现（位置 3、4）。

### 示例 3

```
输入：abcde
输出：[]
```

## 提示

- 字符集小（26 个小写字母），用 `int[26]` 或 `int[128]` 当频次表即可
- **关键陷阱**：不能直接用 `LinkedHashSet` 收集所有重复字符——必须**按首次出现顺序**输出，所以扫描顺序要忠于原串
- 输出格式：JSON 风格 `["a","b"]`，**不是 Java `toString`** 的 `[a, b]`，需要手动拼接

---

## 思路

### 核心思想：两次扫描 + 去重标记

1. **第一遍**：统计每个字母在 `record` 中的总出现次数 `count[c]`
2. **第二遍**：按原串顺序扫描，遇到 `count[c] > 1` 且**未加入结果**的字母，加入结果并标记 `added[c] = true`

这样天然满足"按首次出现顺序"的要求。

**逐步演示**（示例 1，`record = "programming"`）：

```
第一遍统计:
  p=1, r=2, o=1, g=2, a=1, m=2, i=1, n=1

第二遍扫描（按原串顺序）:
  p (位置0): count=1, 跳过
  r (位置1): count=2>1, 未加入 → 加入, added[r]=T
  o (位置2): count=1, 跳过
  g (位置3): count=2>1, 未加入 → 加入, added[g]=T
  r (位置4): 已加入, 跳过
  a (位置5): count=1, 跳过
  m (位置6): count=2>1, 未加入 → 加入, added[m]=T
  m (位置7): 已加入, 跳过
  i (位置8): count=1, 跳过
  n (位置9): count=1, 跳过
  g (位置10): 已加入, 跳过
  m (位置11): 已加入, 跳过

结果: ["r","g","m"]  ✓
```

- 时间复杂度：\(O(n)\)，两遍扫描
- 空间复杂度：\(O(1)\)，固定 26/128 长度的频次表

## 代码

### 我的伪代码

```java
class Solution {
    public String duplicateServices(String record) {
        int[] cnt = new int[26];
        for (char c : record.toCharArray()) cnt[c - 'a']++;
        boolean[] added = new boolean[26];
        StringBuilder sb = new StringBuilder("[");
        for (char c : record.toCharArray()) {
            int i = c - 'a';
            if (cnt[i] > 1 && !added[i]) {
                if (sb.length() > 1) sb.append(",");
                sb.append("\"").append(c).append("\"");
                added[i] = true;
            }
        }
        return sb.append("]").toString();
    }
}
```

### 解法（Java，两次扫描 + JSON 拼接）

```java
class Solution {
    public String duplicateServices(String record) {
        int[] cnt = new int[26];
        for (int i = 0; i < record.length(); i++) {
            cnt[record.charAt(i) - 'a']++;
        }
        boolean[] added = new boolean[26];
        StringBuilder sb = new StringBuilder("[");
        for (int i = 0; i < record.length(); i++) {
            char c = record.charAt(i);
            int idx = c - 'a';
            if (cnt[idx] > 1 && !added[idx]) {
                if (sb.length() > 1) sb.append(",");       // 不是第一个元素才加逗号
                sb.append("\"").append(c).append("\"");    // JSON 风格双引号
                added[idx] = true;
            }
        }
        return sb.append("]").toString();
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，两遍扫描，`n = record.length()`。
- **空间复杂度**：\(O(1)\)，固定 26 长度的频次/标记数组。

> 💡 **记忆**：**「频次表 + 第二遍按原串扫描去重」**——按首次出现顺序输出的经典套路。
>
> ⚠️ **易错**：① 输出格式**JSON 风格** `["a","b"]`，不是 Java 默认的 `[a, b]`；② 第二遍扫描遇到 `count > 1` 的字符时，要**判断是否已加入**，避免同一字符重复输出；③ 空字符串或全不重复时要返回 `[]`，而非空。
