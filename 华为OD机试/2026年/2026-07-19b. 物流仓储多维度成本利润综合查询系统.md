# 2026-07-19b. 物流仓储多维度成本利润综合查询系统

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-19

## 题目描述

某物流企业在全国多个仓库开展仓储业务，需要对不同仓库、不同时间段的入库成本、出库收入和库存损耗进行综合统计分析，用于生成日报、周报和月报。

### 字段说明

| 字段 | 类型 | 取值范围 | 说明 |
|---|---|---|---|
| `warehouseId` | int | [0, 99] | 仓库编号 |
| `numOfWarehouse` | int | — | 仓库数量 |
| `startDay` | int | — | 统计开始天 |
| `endDay` | int | — | 统计结束天，`startDay <= endDay` |
| `inCost` | int | [0, 1000] | 入库成本（千元） |
| `outRevenue` | int | [0, 2000] | 出库收入（千元） |
| `loss` | int | [0, 100] | 库存损耗（千元），0 表示无损耗 |

## 输入描述

- `warehouses`：`int[]` 扁平化数组 `[w0d0in, w0d0out, w0d0loss, w0d1in, w0d1out, w0d1loss, ...]`，先存储仓库 0 的数据，再存储仓库 1 的数据，所有仓库数据个数均相同
- `queries`：`int[][]`，形如 `[[warehouseId, startDay, endDay], ...]`
- `numOfWarehouse`：`int`，仓库个数

输入保证最多 100 个仓库，每个仓库最多 100 天数据，每天数据连续，中间无空缺。

## 输出描述

返回 `int[][]`，每个查询结果为 `[累计净利润, 累计损耗, 风控标记]`。

### 业务计算规则

- **净利润** = 累计出库收入 − 累计入库成本
- **累计损耗** = Σ 每日损耗
- **损耗率** = 累计损耗 / (累计入库成本 + 累计出库收入) × 100%

### 风控规则

- 当损耗率 > 5% 时，触发风控标记（返回 `1`）
- 当损耗率 ≤ 5% 时，不触发风控（返回 `0`）

## 示例

### 示例 1（推断）

```
输入：
warehouses = [100, 200, 5,   90, 180, 10]   // 仓库 0 仅有 1 天数据
queries = [[0, 0, 0]]
numOfWarehouse = 2

输出：
[[95, 5, 0]]
```

**说明**：

- 仓库 0 的第 0 天：`inCost=100, outRevenue=200, loss=5`
- 净利润 = 200 − 100 = 95

- 损耗率 = 5 / (100 + 200) × 100% = 1.67% ≤ 5%，风控标记 = 0

### 示例 2（推断，触发风控）

```
输入：
warehouses = [100, 100, 20]   // 仓库 0 仅 1 天
queries = [[0, 0, 0]]
numOfWarehouse = 1

输出：
[[0, 20, 1]]
```

**说明**：损耗率 = 20 / (100 + 100) = 10% > 5%，风控触发。

## 提示

- 数据布局：扁平数组按 `仓库 0 全部天 → 仓库 1 全部天 → ...` 排列；每个仓库每天 3 个数（`in, out, loss`）
- **求 daysPerWarehouse**：`warehouses.length / numOfWarehouse / 3`
- 仓库 `w` 第 `d` 天的数据在扁平数组中的起始下标：`w * daysPerWarehouse * 3 + d * 3`
- 损耗率涉及**浮点除法**，要小心整数除法截断——可直接用 `loss * 100 > (inSum + outSum) * 5` 等价比较，**避免浮点**
- 所有值在 `int` 范围内，但累加最多 `100×100×1000 = 10^7`，远未溢出

---

## 思路

### 核心思想：扁平数组索引计算 + 区间求和

**关键在于把"仓库 w 第 d 天"映射到扁平数组下标**：

```
flatIdx(w, d) = w * daysPerWarehouse * 3 + d * 3
inCost    = warehouses[flatIdx + 0]
outRevenue = warehouses[flatIdx + 1]
loss      = warehouses[flatIdx + 2]
```

对每个查询 `[w, sd, ed]`，遍历 `d ∈ [sd, ed]`，累加三项，然后判定风控：

```
ratioCondition = lossSum * 100 > (inSum + outSum) * 5
```

这等价于 `loss / (in + out) > 5%`，但**用整数乘法避免浮点精度问题**。

**逐步演示**（示例 1，`warehouses=[100,200,5, 90,180,10]`，`numOfWarehouse=2`）：

```
daysPerWarehouse = 6 / 2 / 3 = 1
查询 [0, 0, 0]:
  flatIdx(0, 0) = 0 * 1 * 3 + 0 * 3 = 0
  inCost=100, outRevenue=200, loss=5
  inSum=100, outSum=200, lossSum=5
  净利润 = 200 - 100 = 95
  风控判定: 5 * 100 > (100+200) * 5
           500 > 1500  → false
  风控标记 = 0
输出: [[95, 5, 0]]  ✓
```

- 时间复杂度：\(O(q \cdot d)\)，`q` 查询数，`d` 平均区间长度
- 空间复杂度：\(O(q)\)，输出数组

## 代码

### 我的伪代码

```java
class Solution {
    public int[][] query(int[] warehouses, int[][] queries, int numOfWarehouse) {
        int days = warehouses.length / numOfWarehouse / 3;
        int[][] ans = new int[queries.length][];
        for (int i = 0; i < queries.length; i++) {
            int w = queries[i][0], sd = queries[i][1], ed = queries[i][2];
            int inSum = 0, outSum = 0, lossSum = 0;
            for (int d = sd; d <= ed; d++) {
                int base = w * days * 3 + d * 3;
                inSum   += warehouses[base];
                outSum  += warehouses[base + 1];
                lossSum += warehouses[base + 2];
            }
            int profit = outSum - inSum;
            int flag = (lossSum * 100 > (inSum + outSum) * 5) ? 1 : 0;
            ans[i] = new int[]{profit, lossSum, flag};
        }
        return ans;
    }
}
```

### 解法（Java，扁平索引 + 整数风控判定）

```java
class Solution {
    public int[][] query(int[] warehouses, int[][] queries, int numOfWarehouse) {
        int daysPerWarehouse = warehouses.length / numOfWarehouse / 3;
        int[][] ans = new int[queries.length][];
        for (int i = 0; i < queries.length; i++) {
            int w = queries[i][0];
            int sd = queries[i][1];
            int ed = queries[i][2];
            int inSum = 0, outSum = 0, lossSum = 0;
            for (int d = sd; d <= ed; d++) {
                int base = (w * daysPerWarehouse + d) * 3;     // 扁平索引
                inSum   += warehouses[base];
                outSum  += warehouses[base + 1];
                lossSum += warehouses[base + 2];
            }
            int profit = outSum - inSum;
            // 整数比较，避免浮点: loss/(in+out) > 5% ⟺ loss*100 > (in+out)*5
            int flag = (lossSum * 100 > (inSum + outSum) * 5) ? 1 : 0;
            ans[i] = new int[]{profit, lossSum, flag};
        }
        return ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(q \cdot d)\)，`q` 查询数，`d` 平均区间长度。
- **空间复杂度**：\(O(q)\)，仅返回数组。

> 💡 **记忆**：**「扁平数组 = 仓库 × 天 × 3，索引 `(w × days + d) × 3`；风控用整数比较 `loss*100 > (in+out)*5`」**——避免浮点精度。
>
> ⚠️ **易错**：① 索引顺序**仓库优先于天**（先排完仓库 0 所有天，再仓库 1），不是"天优先"；② 风控判定**用整数乘法等价**，避免 `double` 精度；③ 净利润可能为负，**不要写成正数比较**。
