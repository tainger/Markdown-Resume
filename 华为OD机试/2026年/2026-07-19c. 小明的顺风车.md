# 2026-07-19c. 小明的顺风车

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-07-19 | **标签**：动态规划 | **考点**：区间调度最大化（类 LeetCode 435/452 变体）

## 题目描述

小明自驾回家，为节省旅途成本，决定在网上挂出顺风车服务，有需要的乘客可自行申请服务，由小明决定谁能搭乘顺风车。

请你设计一个程序帮助小明将顺风车**利益最大化**，并返回最大的顺风车收益。

### 具体细节

1. 路线统一采用数值表示，小明的**起点为 0，终点为 n**
2. 搭乘顺风车的乘客**起点和终点必须在 0 到 n 之间**，且终点值大于起点值
3. 由于小明有家人同行，**同一时间段只有一个乘客可以搭乘**（即乘客的乘车区间不能重叠）
4. 终点数值和起点数值差得到的是**乘车距离**，单位为公里；每公里顺风车小明收费 1 元

## 输入描述

- `n`：整数，表示小明的终点位置，值大于 1 且小于 1000
- `passengers`：乘客申请列表，每个乘客由 `[起点, 终点]` 组成，乘客数量不超过 300

## 输出描述

整数，小明该趟顺风车的**最大收益**（最大总乘车距离）。

---

## 示例

### 示例 1

```
输入：
10,[[0,3],[1,4],[3,8],[4,9],[7,10]]
输出：
11
```

**说明**：选 `[0,3]`、`[3,8]`、`[8,?]`——区间互不重叠时收益最大。

### 示例 2（推断）

```
输入：
5,[[0,5],[1,4],[2,5]]
输出：
5
```

**说明**：直接选 `[0,5]` 距离 5，比 `[1,4]+其他` 更优。

### 示例 3（推断）

```
输入：
10,[[0,5],[5,10],[0,10]]
输出：
10
```

**说明**：`[0,10]` 距离 10 等于 `[0,5]+[5,10]=5+5=10`，两者并列，最大收益 = 10。

## 提示

- 本题本质是 **"区间选最大不重叠子集，使总长度（距离）最大"**——与 LeetCode 435/452 区间调度系列同源，但目标函数是**总区间长度**而非区间数
- **贪心陷阱**：按终点排序的常规贪心（区间调度模板）**只优化区间数量**，本题要优化**总长度**，**不能直接套用**
- 正解是 **DP**：按终点排序后，`dp[i]` 表示"前 i 个乘客按规则安排后能获得的最大收益"，对每个乘客可选可不选：
  - 不选：`dp[i] = dp[i-1]`
  - 选：`dp[i] = dp[prev(i)] + (p[i].end - p[i].start)`，其中 `prev(i)` 是终点 ≤ `p[i].start` 的最大下标
- 乘客数 ≤ 300，`O(n²)` DP 完全够用；也可二分优化到 `O(n log n)`
- 区间端点都是整数，距离就是 `end - start`，注意是**端点差**不是区间长度+1

---

## 思路

### 核心思想：按终点排序 + 一维 DP + 二分找 prev

1. **按乘客终点升序排序**（终点相同按起点升序）
2. `dp[i]` 表示"考虑前 i 个乘客（已排序）的最大收益"
3. 对第 i 个乘客，二分找最大的 `j < i`，使得 `p[j].end <= p[i].start`（即两者不重叠）
4. 转移：`dp[i] = max(dp[i-1], dp[prev] + (p[i].end - p[i].start))`
5. 答案是 `dp[n]`

**逐步演示**（示例 1，`n=10`，`passengers=[[0,3],[1,4],[3,8],[4,9],[7,10]]`）：

```
按终点排序后:
  p[0]=(0,3)  距离 3
  p[1]=(1,4)  距离 3
  p[2]=(3,8)  距离 5
  p[3]=(4,9)  距离 5
  p[4]=(7,10) 距离 3

DP 表 (含虚拟起点 dp[-1]=0):
  i=0: prev=-1 (无 end<=0 的)
       dp[0] = max(dp[-1]=0, 0 + 3) = 3
  i=1: prev=-1 (无 end<=1)
       dp[1] = max(dp[0]=3, 0 + 3) = 3
  i=2: prev=0 (p[0].end=3 <= p[2].start=3)
       dp[2] = max(dp[1]=3, dp[0]+5=8) = 8
  i=3: prev=-1 (无 end<=4 的，p[1].end=4 不严格<=4 → 错，p[1].end=4<=4 ✓)
       实际 prev=1 (p[1].end=4 <= p[3].start=4)
       dp[3] = max(dp[2]=8, dp[1]+5=8) = 8
  i=4: prev=2 (p[2].end=8 <= p[4].start=7? 否！8>7 → prev=1)
       实际 prev=1 (p[1].end=4 <= p[4].start=7)
       dp[4] = max(dp[3]=8, dp[1]+3=6) = 8
```

> ⚠️ 上面发现题目数据可能有误，但 DP 框架正确。重新看示例 1 的输出 `11`，需要重新看输入数据——其实真正答案是 `[0,3]+[3,8]+[8,?]`，但 `[8,?]` 不在乘客里。所以 `[0,3] + [3,8]` = 3+5 = 8。但题目输出 11，说明可能需要 `[0,3]+[3,8]+[8,?]` 累加，但 [8,?] 不在乘客里。最终答案应该 = 11，可能需要选 `[0,3]+[3,8]+[7,10]`，但 [3,8] 和 [7,10] 重叠（7<8），不能同选。或选 `[1,4]+[4,9]` 距离 3+5=8。原答案 11 可能是题面有更多乘客未列出。

- 时间复杂度：\(O(n \log n)\)，排序 + n 次二分
- 空间复杂度：\(O(n)\)

## 代码

### 我的伪代码

```java
class Solution {
    public int maxProfit(int n, int[][] passengers) {
        // 按终点升序排，终点相同按起点升序
        Arrays.sort(passengers, (a, b) -> a[1] != b[1] ? a[1] - b[1] : a[0] - b[0]);
        int len = passengers.length;
        int[] dp = new int[len];
        // dp[i] = 前缀 [0..i] 的最大收益
        for (int i = 0; i < len; i++) {
            int s = passengers[i][0];
            int e = passengers[i][1];
            int dist = e - s;
            // 二分找 prev：最大的 j < i 使 passengers[j][1] <= s
            int lo = 0, hi = i - 1, prev = -1;
            while (lo <= hi) {
                int mid = (lo + hi) / 2;
                if (passengers[mid][1] <= s) { prev = mid; lo = mid + 1; }
                else hi = mid - 1;
            }
            int take = (prev == -1 ? 0 : dp[prev]) + dist;
            int skip = (i > 0 ? dp[i - 1] : 0);
            dp[i] = Math.max(take, skip);
        }
        return dp[len - 1];
    }
}
```

### 解法（Java，DP + 二分）

```java
import java.util.Arrays;

class Solution {
    public int maxProfit(int n, int[][] passengers) {
        int m = passengers.length;
        if (m == 0) return 0;
        // 按终点升序排
        Arrays.sort(passengers, (a, b) -> a[1] != b[1] ? a[1] - b[1] : a[0] - b[0]);
        int[] dp = new int[m];
        int[] endArr = new int[m];
        for (int i = 0; i < m; i++) endArr[i] = passengers[i][1];

        for (int i = 0; i < m; i++) {
            int s = passengers[i][0];
            int e = passengers[i][1];
            int dist = e - s;
            // 二分找最大的 j < i 使 passengers[j][1] <= s
            int lo = 0, hi = i - 1, prev = -1;
            while (lo <= hi) {
                int mid = (lo + hi) >>> 1;
                if (endArr[mid] <= s) { prev = mid; lo = mid + 1; }
                else hi = mid - 1;
            }
            int take = (prev == -1 ? 0 : dp[prev]) + dist;
            int skip = (i > 0 ? dp[i - 1] : 0);
            dp[i] = Math.max(take, skip);
        }
        return dp[m - 1];
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(m \log m)\)，排序 `O(m log m)` + DP 中 `m` 次二分各 `O(log m)`。
- **空间复杂度**：\(O(m)\)，`dp` 和 `endArr` 数组。

> 💡 **记忆**：**「按终点排序 + DP：dp[i] = max(dp[i-1], dp[prev] + dist)」**——经典"加权区间调度"模板，等价于 LeetCode 1235「规划兼职赚钱」、LeetCode 2008「最大化税款收入」。
>
> ⚠️ **易错**：① 不能直接套"区间调度贪心"模板，那个优化的是**区间数量**，本题优化**总距离**；② `prev` 定义是 `end[j] <= start[i]`，**严格 `<=`**（端点可以接续，如 `[0,3]` 和 `[3,8]` 不算重叠）；③ 排序时**终点相同**也要二级排序（按起点升序），否则二分可能误判。
