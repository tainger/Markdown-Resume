# 2026-07-22b. 统计能源使用时段

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-22 | **标签**：双指针、滑动窗口 | **考点**：至多 2 种元素的最长子数组

## 题目描述

某智慧园区管理系统记录了 `N` 个连续的能源使用时段，每个时段使用的能源类型用整数表示（1=太阳能，2=风能，3=电能，4=天然气，5=地热能）。

为了优化能源配置，管理员需要分析：在这 `N` 个时段中，**连续使用不超过 2 种能源**的最长时段长度是多少？

请编写程序计算这个最大长度。

## 输入描述

- 输入是一个整数数组，表示各时段的能源类型
- 数组元素：1=太阳能，2=风能，3=电能，4=天然气，5=地热能
- 约束条件：`1 ≤ 数组长度 ≤ 100000`，能源类型为 1-5 的整数

## 输出描述

输出最长连续时段的长度。

### 补充说明

- 如果输入为空，则输出 0

---

## 示例

### 示例 1

```
输入：1,2,1,2,3,2,2,2
输出：5
```

**说明**：最长满足条件的连续时段是 `[2,3,2,2,2]`（下标 3 到 7），长度 5；该时段只使用了 2 种能源（2 和 3）。

### 示例 2

```
输入：1,2,3,4,5
输出：2
```

**说明**：最长的满足条件的连续时段是 2，因为每相邻两个时段不同（但任意三段都会出现 3 种能源）。

---

## 提示

- **典型滑动窗口**：求"至多包含 K 种元素"的最长子数组，K=2
- 能源类型只有 5 种，用 `int[6]` 数组当哈希表（计数）即可，无需 HashMap
- 维护"窗口内不同能源种类数" `kind`：新增元素时若 `count[x] == 0` 则 `kind++`；左指针移除时若 `count[x] == 0` 则 `kind--`
- `n ≤ 100000`，必须 `O(n)`，`O(n²)` 暴力会 TLE

---

## 思路

### 核心思想：滑动窗口 + 频次表

左右双指针 `left` / `right` 维护窗口，窗口内允许至多 2 种能源。`right` 右移加入新元素，若窗口内种类数 > 2，则**右移 `left`** 直到种类数回到 ≤ 2。每次窗口合法时，用 `right - left + 1` 更新答案。

**逐步演示**（示例 1，`[1,2,1,2,3,2,2,2]`）：

```
初始: left=0, kind=0, ans=0
right=0 (1): count[1]++ → kind=1, 合法, ans=1
right=1 (2): count[2]++ → kind=2, 合法, ans=2
right=2 (1): count[1]++ → kind=2, 合法, ans=3
right=3 (2): count[2]++ → kind=2, 合法, ans=4
right=4 (3): count[3]++ → kind=3 > 2
           → 移 left=0 (1): count[1]-- → 1, kind 不变
           → 移 left=1 (2): count[2]-- → 1, kind 不变
           → 移 left=2 (1): count[1]-- → 0, kind=2
           合法, ans=max(4, 4-2+1=3)=4
right=5 (2): count[2]++ → kind=2, 合法, ans=4
right=6 (2): count[2]++ → kind=2, 合法, ans=5
right=7 (2): count[2]++ → kind=2, 合法, ans=5

最终: ans = 5  ✓
```

- 时间复杂度：\(O(n)\)，每个元素最多进/出窗口各一次
- 空间复杂度：\(O(1)\)，固定 `int[6]` 频次表

## 代码

### 我的伪代码

```java
class Solution {
    public int longestSubarray(int[] arr) {
        int[] cnt = new int[6];
        int left = 0, kind = 0, ans = 0;
        for (int right = 0; right < arr.length; right++) {
            if (cnt[arr[right]]++ == 0) kind++;
            while (kind > 2) {
                if (--cnt[arr[left]] == 0) kind--;
                left++;
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

### 解法（Java，滑动窗口 + 数组频次）

```java
class Solution {
    public int longestSubarray(int[] arr) {
        if (arr == null || arr.length == 0) return 0;
        int[] cnt = new int[6];                  // 能源类型 1-5，开 6 长
        int left = 0, kind = 0, ans = 0;
        for (int right = 0; right < arr.length; right++) {
            int x = arr[right];
            if (cnt[x] == 0) kind++;
            cnt[x]++;
            while (kind > 2) {                  // 缩左直到种类数 <= 2
                int y = arr[left];
                cnt[y]--;
                if (cnt[y] == 0) kind--;
                left++;
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，左右指针各最多移动 n 次。
- **空间复杂度**：\(O(1)\)，固定 6 长度的频次数组。

> 💡 **记忆**：**「至多 K 种元素的最长子数组 = 滑动窗口」**，本题 K=2，等价于 LeetCode 159「至多两个不同字符的最长子串」、LeetCode 904「水果成篮」。
>
> ⚠️ **易错**：① 能源类型 1-5，开 `int[6]` 即可（用索引 1-5），不需要 HashMap；② **先 `++` 后判 kind** 还是**先判后 `++`** 都行，关键是 kind 在新增/移除时同步更新；③ 空 `arr` 特判返回 0。
