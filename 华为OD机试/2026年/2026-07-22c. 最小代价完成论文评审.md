# 2026-07-22c. 最小代价完成论文评审

> **难度**：� 中等 | **分值**：200 | **卷次**：新系统 2026-07-22

## 题目描述

某学术会议需要安排 `n` 篇论文的评审。共有 `m` 位评审教师，每位教师有固定的评审费用 `cost[j]`，且只能评审特定的论文集合。

为保证评审质量，**每篇论文至少要有一位教师能够评审**。请在满足"所有论文都能被评审"的前提下：

1. **优先选择教师数量最少**的方案
2. 若教师数量相同，**选择总费用最小**的方案

返回最优方案的最小总费用；若无法覆盖所有论文，返回 `-1`。

## 输入描述

- 参数 1：`n`（int）：论文数量，论文编号 0..n-1
- 参数 2：`m`（int）：教师数量，教师编号 0..m-1
- 参数 3：`files`（`List<List<Integer>>`）：`files.get(i)` 表示第 `i` 篇论文可以被哪些教师评审（教师编号列表）
- 参数 4：`cost`（`List<Integer>`）：`cost.get(j)` 表示第 `j` 位教师的评审费用

## 输出描述

- 输出：满足条件的最小总费用
- 无法覆盖所有论文时返回 `-1`

---

## 示例

### 示例 1

```
输入：n=3, m=3, files=[[0,1],[1,2],[0,2]], cost=[10,20,30]
输出：30
```

**说明**：选教师 0 和 1（费用 10+20=30）可覆盖所有论文（论文 0 由教师 0，论文 1 由教师 0/1，论文 2 由教师 1）；选教师 0 和 2 费用 40 更贵；选教师 1 和 2 费用 50 最贵；3 位全选费用 60。最优为 2 位、费用 30。

### 示例 2

```
输入：n=2, m=2, files=[[0],[1]], cost=[5,8]
输出：13
```

**说明**：论文 0 只有教师 0 能评，论文 1 只有教师 1 能评，必须两位都选，费用 5+8=13。

### 示例 3

```
输入：n=2, m=2, files=[[0],[0]], cost=[5,8]
输出：-1
```

**说明**：没有任何教师能评审论文 1，无法覆盖，返回 -1。

## 提示

- **典型集合覆盖问题**：教师数量 ≤ 20 时可用**位掩码枚举**所有子集
- 每篇论文可评审的教师集合用位掩码压缩：`paperMask[i]` 的第 j 位为 1 表示教师 j 能评审论文 i
- 枚举所有教师子集 `subset`（1 到 \(2^m-1\)），对每篇论文检查 `(subset & paperMask[i]) != 0`
- 同数量取最小费用：记录 `bestCount` 和 `bestCost`，先比数量再比费用
- 本题数据规模小（m ≤ 20），\(O(2^m \cdot n)\) 可接受

---

## 思路

### 核心思想：位掩码 + 子集枚举

把"第 i 篇论文能由哪些教师评审"压缩成一个 m 位的掩码 `paperMask[i]`。那么"subset 覆盖论文 i"等价于 `(subset & paperMask[i]) != 0`（subset 中至少有一个能评审论文 i 的教师）。

枚举所有非空教师子集，对每个子集：
1. 检查是否覆盖所有论文
2. 若覆盖，计算教师数（`Integer.bitCount(subset)`）和总费用
3. 按"数量优先、费用其次"更新最优解

**逐步演示**（示例 1，n=3, m=3, files=[[0,1],[1,2],[0,2]], cost=[10,20,30]）：

```
paperMask[0] = 0b011 = 3   (教师 0,1)
paperMask[1] = 0b110 = 6   (教师 1,2)
paperMask[2] = 0b101 = 5   (教师 0,2)

枚举 subset:
subset=1 (001): 覆盖? paper0&1=1✓ paper1&6=0✗ → 不覆盖
subset=2 (010): paper0&3=2✓ paper1&6=2✓ paper2&5=0✗ → 不覆盖
subset=3 (011): paper0&3=3✓ paper1&6=2✓ paper2&5=1✓ → 覆盖! cnt=2,cost=10+20=30
subset=5 (101): paper0&3=1✓ paper1&6=4✓ paper2&5=5✓ → 覆盖! cnt=2,cost=10+30=40 (费用更大,不更新)
subset=6 (110): paper0&3=2✓ paper1&6=6✓ paper2&5=4✓ → 覆盖! cnt=2,cost=20+30=50 (费用更大,不更新)
subset=7 (111): 覆盖, cnt=3,cost=60 (数量更多,不更新)

最优: cnt=2, cost=30  ✓
```

- 时间复杂度：\(O(2^m \cdot n)\)，枚举 \(2^m\) 个子集 × 检查 n 篇论文
- 空间复杂度：\(O(n)\)，存 paperMask

## 代码

### 我的伪代码

```java
class Solution {
    public int minCost(int n, int m, List<List<Integer>> files, List<Integer> cost) {
        // 1. 每篇论文的可评审教师 → 位掩码
        int[] paperMask = new int[n];
        for (int i = 0; i < n; i++) {
            int mask = 0;
            for (int t : files.get(i)) mask |= (1 << t);
            paperMask[i] = mask;
        }

        // 2. 枚举所有非空教师子集
        int bestCount = Integer.MAX_VALUE;
        int bestCost = Integer.MAX_VALUE;
        for (int subset = 1; subset < (1 << m); subset++) {
            // 检查是否覆盖所有论文
            boolean cover = true;
            for (int i = 0; i < n; i++) {
                if ((subset & paperMask[i]) == 0) { cover = false; break; }
            }
            if (!cover) continue;
            // 计算教师数和总费用
            int cnt = Integer.bitCount(subset);
            int c = 0;
            for (int j = 0; j < m; j++) {
                if ((subset & (1 << j)) != 0) c += cost.get(j);
            }
            // 更新最优：数量优先，费用其次
            if (cnt < bestCount || (cnt == bestCount && c < bestCost)) {
                bestCount = cnt;
                bestCost = c;
            }
        }
        return bestCost == Integer.MAX_VALUE ? -1 : bestCost;
    }
}
```

### 解法（Java，位掩码 + 子集枚举）

```java
class Solution {
    public int minCost(int n, int m, List<List<Integer>> files, List<Integer> cost) {
        // 每篇论文的可评审教师压缩为位掩码
        int[] paperMask = new int[n];
        for (int i = 0; i < n; i++) {
            int mask = 0;
            for (int t : files.get(i)) mask |= (1 << t);
            paperMask[i] = mask;
        }

        int bestCount = Integer.MAX_VALUE;
        int bestCost = Integer.MAX_VALUE;

        for (int subset = 1; subset < (1 << m); subset++) {
            // 检查 subset 是否覆盖所有论文
            boolean cover = true;
            for (int i = 0; i < n; i++) {
                if ((subset & paperMask[i]) == 0) { cover = false; break; }
            }
            if (!cover) continue;

            int cnt = Integer.bitCount(subset);
            int c = 0;
            for (int j = 0; j < m; j++) {
                if ((subset & (1 << j)) != 0) c += cost.get(j);
            }

            if (cnt < bestCount || (cnt == bestCount && c < bestCost)) {
                bestCount = cnt;
                bestCost = c;
            }
        }
        return bestCost == Integer.MAX_VALUE ? -1 : bestCost;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(2^m \cdot n)\)，枚举 \(2^m\) 个子集，每个子集检查 n 篇论文。m ≤ 20 时约 \(10^6 \cdot n\) 次运算，可接受
- **空间复杂度**：\(O(n)\)，存 paperMask 数组

> 💡 **记忆**：**「集合覆盖 + 小规模 m → 位掩码枚举」**。这是 NP-Hard 集合覆盖问题，m 小（≤ 20）时用位运算暴力枚举是最直接的写法。
>
> ⚠️ **易错**：① 覆盖判断是 `(subset & paperMask[i]) != 0`（有交集即可），不是 `== paperMask[i]`（那要求 subset 包含所有能评审的教师，过强）；② "数量优先、费用其次"的双关键字比较不能只比费用；③ 无法覆盖要返回 -1，用 `bestCost == MAX_VALUE` 判断。
