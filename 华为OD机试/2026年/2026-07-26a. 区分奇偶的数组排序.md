# 2026-07-26a. 区分奇偶的数组排序

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-26 | **标签**：排序、数组 | **考点**：拆分 + 升序 + 交替合并

## 题目描述

给定一个非负整数数组 `nums`，满足以下两个前提条件：

1. 数组长度为偶数，且 `2 ≤ nums.length ≤ 20000`
2. 数组中**恰好有一半**元素是偶数，另一半元素是奇数

请你对该数组进行重构，满足以下两个核心要求：

1. 重构后的数组中，所有位于**偶数下标**（下标从 0 开始）的元素必须是**偶数**，所有位于**奇数下标**的元素必须是**奇数**
2. 重构后，所有占据偶数下标的偶数元素，需按照**从小到大**的升序排列；所有占据奇数下标的奇数元素，也需按照**从小到大**的升序排列

返回满足上述所有条件的重构后数组。

### 补充说明

- 数组长度 `n` 满足 `2 ≤ n ≤ 20000`，且 `n % 2 == 0`
- 元素为非负整数 `0 ≤ nums[i] ≤ 1000`
- 偶数和奇数数量严格相等，各占 `n/2` 个
- 满足条件的输出数组**唯一**

---

## 示例

### 示例 1

```
输入：4,2,5,7
输出：2,5,4,7
```

**说明**：偶数元素 `[4,2]` 升序后为 `[2,4]`；奇数元素 `[5,7]` 升序后为 `[5,7]`，按下标奇偶交替合并。

### 示例 2

```
输入：1,3,2,6,8,5
输出：2,1,6,3,8,5
```

### 示例 3

```
输入：9,0,3,4,7,2
输出：0,3,2,7,4,9
```

---

## 提示

- 偶数判断：`x % 2 == 0`；**0 也是偶数**
- 拆分时**保持原顺序**不重要（因为后续要排序），但**奇偶判断必须基于原值**
- 严格满足 `n % 2 == 0`，无需考虑奇数长度边界
- `n ≤ 20000`，`O(n log n)` 排序完全够用

---

## 思路

### 核心思想：拆分 + 排序 + 交替合并

1. 一次遍历，把原数组拆成 `evens[]` 和 `odds[]`
2. 分别升序排序
3. 按下标奇偶性交替填回：`ans[2k] = evens[k]`，`ans[2k+1] = odds[k]`

**逐步演示**（示例 1，`nums = [4,2,5,7]`）：

```
原数组:  [4, 2, 5, 7]
拆分:    evens = [4,2],  odds = [5,7]
排序:    evens = [2,4],  odds = [5,7]
交替合并: ans[0]=2, ans[1]=5, ans[2]=4, ans[3]=7
结果:    [2,5,4,7]
```

- 时间复杂度：\(O(n \log n)\)，排序主导
- 空间复杂度：\(O(n)\)，两个临时数组

## 代码

### 我的伪代码

```java
class Solution {
    public int[] sortEvenOdd(int[] nums) {
        int n = nums.length;
        int[] evens = new int[n / 2];
        int[] odds  = new int[n / 2];
        int e = 0, o = 0;
        for (int x : nums) {
            if (x % 2 == 0) evens[e++] = x;
            else            odds[o++]  = x;
        }
        Arrays.sort(evens);
        Arrays.sort(odds);
        int[] ans = new int[n];
        for (int k = 0; k < n / 2; k++) {
            ans[2 * k]     = evens[k];
            ans[2 * k + 1] = odds[k];
        }
        return ans;
    }
}
```

### 解法（Java）

```java
import java.util.Arrays;

class Solution {
    public int[] sortEvenOdd(int[] nums) {
        int n = nums.length;
        int[] evens = new int[n / 2];
        int[] odds  = new int[n / 2];
        int e = 0, o = 0;
        for (int x : nums) {
            if ((x & 1) == 0) evens[e++] = x;   // 位运算判奇偶更快
            else              odds[o++]  = x;
        }
        Arrays.sort(evens);
        Arrays.sort(odds);
        int[] ans = new int[n];
        for (int k = 0; k < n / 2; k++) {
            ans[2 * k]     = evens[k];          // 偶数下标放偶数
            ans[2 * k + 1] = odds[k];           // 奇数下标放奇数
        }
        return ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n \log n)\)，两次排序主导。
- **空间复杂度**：\(O(n)\)，两个 `n/2` 数组 + 答案数组。

> 💡 **记忆**：**「拆偶奇 → 各排序 → 交替放（0/2/4... 是偶、1/3/5... 是奇）」**。
>
> ⚠️ **易错**：① `0` 是偶数（`0 % 2 == 0`）；② 题目保证奇偶数量相等，**不用考虑剩余**；③ 下标 `2k` 是偶数下标，下标 `2k+1` 是奇数下标，**别搞反成"偶数值放偶数下标"**。
