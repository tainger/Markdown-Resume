# 2026-07-26b. 数字系统转换器

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-26 | **标签**：数学逻辑、字符串 | **考点**：进制转换（任意字符集）

## 题目描述

在一个特殊的数学系统中，每个数字都有其独特的表示方式。给定两个不同的数字字符集和一个数字字符串，你需要将这个数字从一个字符系统转换到另一个字符系统。

实现一个函数，将使用**源字符集**表示的数字转换为使用**目标字符集**表示的数字。

### 补充说明

- `1 ≤ num.length ≤ 100`
- `2 ≤ sourceDigits.length ≤ 36`
- `2 ≤ targetDigits.length ≤ 36`
- `sourceDigits` 和 `targetDigits` 由不同的字符组成，且**不包含重复字符**
- `num` 中的所有字符都存在于 `sourceDigits` 中
- 输入保证是有效的，不会出现非法字符
- 转换结果**不应包含前导零**，除非数字本身就是 `0`

## 输入描述

- `num`：源字符集下表示的数字字符串
- `sourceDigits`：源字符集
- `targetDigits`：目标字符集

## 输出描述

转换后的目标字符集下表示的数字字符串。

---

## 示例

### 示例 1

```
输入：101,01,0123456789
输出：5
```

**说明**：二进制 `"101"` 转换为十进制是 `"5"`。

### 示例 2

```
输入：ff,0123456789abcdef,0123456789
输出：255
```

**说明**：十六进制 `"ff"` 转换为十进制是 `"255"`。

### 示例 3

```
输入：100,01,0123456789abcdef
输出：4
```

**说明**：二进制 `"100"` 转换为十六进制是 `"4"`。

### 示例 4

```
输入：7,0123456789,01
输出：111
```

**说明**：十进制 `"7"` 转换为二进制是 `"111"`。

### 示例 5

```
输入：10012,01234,012
输出：212102
```

**说明**：五进制 `"10012"` 转换为三进制是 `"212102"`。

## 提示

- 本质是经典**任意进制转换**：先 `源字符集 → 十进制数值`，再 `十进制数值 → 目标字符集`
- `num.length ≤ 100`，**进制基数 ≤ 36**，但位数可能很大（最多 100 位 36 进制），**十进制数值会爆 `long`**（36^100 远超 long 范围）
- 因此必须使用 `BigInteger`（Java），或手写大数运算
- 进制基数 = `sourceDigits.length()` / `targetDigits.length()`，**不是字符的字典序**
- 前导零处理：转换结果如果首位是字符集第 0 位（如 `"0"`、`"00"`），且数字非零，需去除前导零

---

## 思路

### 核心思想：源进制 → BigInteger → 目标进制

**两步走**：

1. **源字符集 → BigInteger 十进制**：从高位到低位，`result = result × sourceBase + digitValue`，其中 `digitValue = sourceDigits.indexOf(ch)`
2. **BigInteger → 目标字符集**：用**短除法**，反复对 `targetBase` 取余、商，**余数倒序**拼成字符串

**逐步演示**（示例 5，五进制 `"10012"` → 三进制）：

```
源字符集: "01234"  → 源基数 = 5
目标字符集: "012"    → 目标基数 = 3
num = "10012"

步骤 1: 源字符集 → 十进制 BigInteger
  result = 0
  '1' → 1, result = 0*5 + 1 = 1
  '0' → 0, result = 1*5 + 0 = 5
  '0' → 0, result = 5*5 + 0 = 25
  '1' → 1, result = 25*5 + 1 = 126
  '2' → 2, result = 126*5 + 2 = 632

步骤 2: 632 → 三进制
  632 / 3 = 210 余 2
  210 / 3 = 70  余 0
  70  / 3 = 23  余 1
  23  / 3 = 7   余 2
  7   / 3 = 2   余 1
  2   / 3 = 0   余 2
余数倒序: 212102  ✓
```

- 时间复杂度：\(O(L \cdot \log_B N)\)，其中 `L` 为 `num` 长度，`B` 为源基数，`N` 为十进制值。最坏 100 位 36 进制约 100 多次除法
- 空间复杂度：\(O(L + \text{结果长度})\)

## 代码

### 我的伪代码

```java
class Solution {
    public String convertSystem(String num, String src, String tgt) {
        BigInteger val = BigInteger.ZERO;
        BigInteger base = BigInteger.valueOf(src.length());
        for (char c : num.toCharArray()) {
            int d = src.indexOf(c);
            val = val.multiply(base).add(BigInteger.valueOf(d));
        }
        // 特判 0
        if (val.equals(BigInteger.ZERO)) return String.valueOf(tgt.charAt(0)));
        // 短除法
        StringBuilder sb = new StringBuilder();
        BigInteger t = BigInteger.valueOf(tgt.length());
        while (val.compareTo(BigInteger.ZERO) > 0) {
            BigInteger[] qr = val.divideAndRemainder(t);
            val = qr[0];
            sb.append(tgt.charAt(qr[1].intValue()));
        }
        return sb.reverse().toString();
    }
}
```

### 解法（Java，BigInteger 大数）

```java
import java.math.BigInteger;

class Solution {
    public String convertSystem(String num, String sourceDigits, String targetDigits) {
        // 步骤 1：源字符集 → 十进制 BigInteger
        BigInteger val = BigInteger.ZERO;
        BigInteger srcBase = BigInteger.valueOf(sourceDigits.length());
        for (int i = 0; i < num.length(); i++) {
            int d = sourceDigits.indexOf(num.charAt(i));     // 该字符在源字符集的索引 = 数值
            val = val.multiply(srcBase).add(BigInteger.valueOf(d));
        }

        // 特判 0：直接返回目标字符集第 0 位
        if (val.equals(BigInteger.ZERO)) {
            return String.valueOf(targetDigits.charAt(0));
        }

        // 步骤 2：十进制 → 目标字符集（短除法）
        BigInteger tgtBase = BigInteger.valueOf(targetDigits.length());
        StringBuilder sb = new StringBuilder();
        while (val.compareTo(BigInteger.ZERO) > 0) {
            BigInteger[] qr = val.divideAndRemainder(tgtBase);
            val = qr[0];                                      // 商
            int rem = qr[1].intValue();                       // 余数
            sb.append(targetDigits.charAt(rem));              // 余数倒序拼
        }
        return sb.reverse().toString();
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(L \cdot M)\)，`L = num.length`，`M` 为短除法迭代次数 ≈ `log_{tgtBase} val`，最坏 100 位 36 进制约 200 次大数除法。
- **空间复杂度**：\(O(L + \text{结果长度})\)。

> 💡 **记忆**：**「字符 indexOf 即数值，源 → 大数十进制 → 短除法 → 余数倒序」**——通用任意进制互转模板。
>
> ⚠️ **易错**：① **位数 100 必爆 `long`**（36^100 ≈ 10^155），必须用 `BigInteger`；② `num = "0"` 时**特判**返回 `targetDigits.charAt(0)`，不要走 `while` 循环（会返回空串）；③ 进制基数是 `字符集长度`，不是字符的字典序值（如源 `"01234"` 基数为 5，不是 10）。
