# 2026-07-26c. 炸弹人的雷区数量

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-07-26

## 题目描述

在一款游戏中设计炸弹人技能效果是**预埋地雷**，当敌人从地雷上走过时会触发地雷爆炸造成伤害。

当一个地雷被引爆时，在一定距离内的相邻的地雷也会引爆，这些能够同时引爆的地雷形成一个**雷区**。一个雷区可以由一枚孤立的地雷组成，也可以由一片有连锁爆炸反应的多枚地雷组成。

现给出一组炸弹人地雷连锁爆炸关联数据，请计算**有效雷区数量**。

## 输入描述

地雷连锁爆炸关系数组 `isChainExplosion`：地雷连锁爆炸信息被记录在一个 `n × n` 的二维数组 `isChainExplosion` 中：

- `isChainExplosion[i][j] = 1` 表示第 `i` 枚地雷和第 `j` 枚地雷有互相引爆关系
- `isChainExplosion[i][j] = 0` 表示第 `i` 枚地雷和第 `j` 枚地雷不会被彼此引爆

输入用例保证：

- `isChainExplosion[i][i]` 和 `isChainExplosion[j][j]` 的值同时为 0 或者同时为 1
- 地雷数量在 `[1, 20]` 之间

## 输出描述

有效雷区数量。

---

## 示例

### 示例 1

```
输入：[[1,0],[0,1]]
输出：2
```

**说明**：两枚地雷互相独立，其中一枚被引爆时不会触发另一枚地雷，所以雷区数量是 2。

### 示例 2

```
输入：[[1,0,0],[0,1,1],[0,1,1]]
输出：2
```

**说明**：一共三枚地雷，第一枚和第二、第三枚互相独立，第二枚和第三枚临近且引爆，因此雷区数量是 2。

### 示例 3

```
输入：[[1,1,1],[1,1,1],[1,1,1]]
输出：1
```

**说明**：全连通场景，三枚地雷两两直接互相引爆，形成一个雷区。

## 提示

- 题目本质：**邻接矩阵表示的图，求连通块数量**
- 关键陷阱：`isChainExplosion[i][i]` 可能是 0 或 1
  - 若对角线 = 1：每个节点自连通，孤立节点自身即一个雷区
  - 若对角线 = 0：孤立节点**仍算 1 个雷区**（题目定义"由一枚孤立的地雷组成"），需要单独计数
- 节点数 `n ≤ 20`，DFS / BFS / 并查集都能轻松过
- 邻接关系是**对称**的（题目保证），无向图处理即可

---

## 思路

### 核心思想：DFS 求连通块

把每枚地雷看作图中一个节点，`isChainExplosion[i][j] = 1` 视为无向边 `i ↔ j`。一个雷区 = 一个连通块。从每个未访问节点出发 DFS，标记所有可达节点，DFS 启动次数即连通块数。

**逐步演示**（示例 2，邻接矩阵 `[[1,0,0],[0,1,1],[0,1,1]]`）：

```
节点 0: isChain[0] = [1,0,0]  → 自连通，无其他邻居
节点 1: isChain[1] = [0,1,1]  → 邻居 {2}
节点 2: isChain[2] = [0,1,1]  → 邻居 {1}

visited = [F,F,F]
  i=0: 未访问 → DFS(0)
         visited[0]=T，无邻居（除自己）
         一块结束
  i=1: 未访问 → DFS(1)
         visited[1]=T
         邻居 2 未访问 → DFS(2) → visited[2]=T
         一块结束
  i=2: 已访问，跳过

连通块数 = 2  ✓
```

- 时间复杂度：\(O(n^2)\)，遍历整个邻接矩阵
- 空间复杂度：\(O(n)\)，`visited` 数组 + 递归栈

## 代码

### 我的伪代码

```java
class Solution {
    public int countMineFields(int[][] isChain) {
        int n = isChain.length;
        boolean[] visited = new boolean[n];
        int count = 0;
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                dfs(i, isChain, visited);
                count++;          // 每启动一次 DFS 就多一块
            }
        }
        return count;
    }
    void dfs(int u, int[][] g, boolean[] visited) {
        visited[u] = true;
        for (int v = 0; v < g.length; v++) {
            if (g[u][v] == 1 && !visited[v]) {
                dfs(v, g, visited);
            }
        }
    }
}
```

### 解法（Java，DFS）

```java
class Solution {
    public int countMineFields(int[][] isChainExplosion) {
        int n = isChainExplosion.length;
        boolean[] visited = new boolean[n];
        int count = 0;
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                dfs(i, isChainExplosion, visited);
                count++;
            }
        }
        return count;
    }

    private void dfs(int u, int[][] g, boolean[] visited) {
        visited[u] = true;
        for (int v = 0; v < g.length; v++) {
            if (g[u][v] == 1 && !visited[v]) {
                dfs(v, g, visited);
            }
        }
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n^2)\)，最坏 DFS 会访问所有节点 × 每个节点遍历整行。
- **空间复杂度**：\(O(n)\)，`visited` 数组 + 递归调用栈最深 `n` 层。

> 💡 **记忆**：**「邻接矩阵 → DFS，启动次数 = 连通块数」**——本题等价于 LeetCode 547「省份数量」。
>
> ⚠️ **易错**：① 题目说"一枚孤立的地雷也算一个雷区"，所以即使 `isChain[i][i] = 0`，孤立节点也要算 1 块——但用 DFS 时**自动处理**了（`i` 自身就是连通块起点）；② 不要因为对角线为 0 就跳过节点 `i`；③ 邻接矩阵**对称**，但代码别假设下三角 = 上三角，直接按行扫即可。
