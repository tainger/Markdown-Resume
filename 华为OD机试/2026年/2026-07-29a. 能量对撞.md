# 2026-07-29a. 能量对撞

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-29

## 题目描述

在一个充满魔法能量的**消除游戏**中，一排排不同颜色的能量球（代表不同质量/能量值）静止在网格中。当玩家触发消除机制时，相邻的能量球会发生**相互碰撞**。

### 消除规则

1. **碰撞机制**：当两个相邻的能量球相遇时，系统会根据它们的能量值（质量）进行判断。
2. **强弱判定**：如果两个能量球的能量值**不同**，能量值**较低**的那个球会被对手的能量能量波吞噬，从而消除。
3. **同归于尽**：如果两个能量球的能量值**完全相同**，它们会引发剧烈的能量湮灭反应，导致**两者同时被消除**。
4. **幸存条件**：只有能量值足够高且未发生碰撞（或碰撞后存活）的能量球，才能留在场上继续等待下一轮消除。

### 题目目标

给定一排初始的能量球序列，请模拟上述消除过程，找出最终**留在场上**的所有能量球及其顺序。

### 约束

- 能量球的个数不超过 1000 个
- 能量球的能量值是非负整数，最大不超过 10000

## 输入描述

输入共两行：

- 第一行输入整数 `n`，表示能量球数量。
- 第二行输入 `n` 个整数，使用英文逗号分隔，表示初始能量球序列。

## 输出描述

输出最终留在场上的所有能量球序列，以数组形式表示，格式为 `[b1,b2,...,bm]`。

---

## 示例

### 示例 1

```
输入：
5
3,5,5,2,3

输出：
[3]
```

**解释**（逐步模拟）：

| 步骤 | 当前能量球 | 栈状态 | 说明 |
|:---:|:---:|:---|:---|
| 1 | 3 | `[3]` | 栈空，3 入栈 |
| 2 | 5 | `[5]` | 5 > 3，3 被吞噬；栈空，5 入栈 |
| 3 | 5 | `[]` | 5 == 5，同归于尽 |
| 4 | 2 | `[2]` | 栈空，2 入栈 |
| 5 | 3 | `[3]` | 3 > 2，2 被吞噬；栈空，3 入栈 |

最终场上只剩 `[3]`。

### 示例 2

```
输入：
6
1,2,2,1,3,4

输出：
[4]
```

**解释**（简化）：

- 1 → 2 → 2 同归于尽 → 1 → 3 → 4
- 中间 1,2,2 全部湮灭，剩 4

## 提示

- `n ≤ 1000`，能量值 `≤ 10000`，无需考虑溢出（`int` 足够）。
- 每个新球入栈前**循环**与栈顶比较：① 同值湮灭后**继续看下一个栈顶**（可能继续湮灭）；② 不同则**较小的被消除**，较大的留下并**继续看下一个栈顶**；③ 栈空则入栈。
- 注意"消到一半遇到更强的球"：球 A 入栈时可能先消掉栈顶 B，但栈顶下面还有一个比 A 更强的 C，A 会被 C 吃掉。
- 本题本质等价于 LeetCode 735「行星碰撞」，只是方向改为左右相邻双向比较。

---

## 思路

### 核心思想：栈模拟消除

把"场上"看作一个**栈**，从左到右遍历能量球，每个新球 `x` 入栈前，**循环检查栈顶**：

1. 栈空 → 直接入栈
2. `stack.top() == x` → 同值湮灭，**出栈后 break**（新球也被消除，不再入栈）
3. `stack.top() > x` → 栈顶更强，新球被吞噬，**不入栈，break**
4. `stack.top() < x` → 新球更强，栈顶出栈（被吞噬），**继续循环检查下一个栈顶**

**逐步演示**（示例 1，球 `[3,5,5,2,3]`）：

```
初始: 栈 = []
遍历: 3 → 5 → 5 → 2 → 3

x=3: 栈空 → push          栈=[3]
x=5: 3<5 → pop 3 (被吞噬) → 栈空 → push  栈=[5]
x=5: 5==5 → pop 5 (同归于尽) → break      栈=[]
x=2: 栈空 → push          栈=[2]
x=3: 2<3 → pop 2 (被吞噬) → 栈空 → push  栈=[3]

最终栈：[3]
```

- 时间复杂度：\(O(n)\)，每个元素最多入栈/出栈一次（**均摊分析**）
- 空间复杂度：\(O(n)\)，栈最坏保存所有球（递增序列，无碰撞）

## 代码

### 我的伪代码

```java
class Solution {
    public int[] energyCollision(int[] balls) {
        Deque<Integer> stack = new ArrayDeque<>();
        outer:
        for (int x : balls) {
            while (!stack.isEmpty()) {
                int top = stack.peek();
                if (top == x) {            // 同归于尽
                    stack.pop();
                    continue outer;        // 新球也消失，处理下一个球
                } else if (top > x) {     // 新球被吞噬
                    continue outer;       // 新球不入栈
                } else {                  // 栈顶被吞噬
                    stack.pop();          // 继续看下一个栈顶
                }
            }
            stack.push(x);                // 栈空或都消完，新球入栈
        }
        // 把栈转成数组输出
    }
}
```

### 解法（Java，栈模拟）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] energyCollision(int[] balls) {
        Deque<Integer> stack = new ArrayDeque<>();
        outer:
        for (int x : balls) {
            while (!stack.isEmpty()) {
                int top = stack.peek();
                if (top == x) {             // 同归于尽
                    stack.pop();
                    continue outer;         // 新球消失，处理下一个
                } else if (top > x) {       // 新球被吞噬
                    continue outer;         // 不入栈
                } else {                    // 栈顶被吞噬
                    stack.pop();            // 继续看下一个栈顶
                }
            }
            stack.push(x);                  // 栈空或栈顶全消完
        }
        int[] ans = new int[stack.size()];
        int i = 0;
        for (int v : stack) ans[i++] = v;
        return ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)。每个元素最多入栈 1 次、出栈 1 次，总操作数 ≤ 2n。
- **空间复杂度**：\(O(n)\)。最坏情况为严格递增序列（如 `1,2,3,4,5`），无碰撞，栈保存全部。

> 💡 **记忆**：**「新球往前撞，栈顶同值湮尽、强吃弱、弱被吃不入栈」**——一球撞完一群可能继续撞下一个栈顶，所以是 `while` 不是 `if`。
>
> ⚠️ **易错**：① 同值湮灭后用 `continue outer` 跳到下个球，**不要 break 后又 push**（新球已消失）；② 用 `peek` 比较后再决定是否 `pop`，**不要先 pop 再比较**（要保留赢家）；③ 输出顺序要**保持原方向**，用迭代器遍历 `Deque` 即可。
