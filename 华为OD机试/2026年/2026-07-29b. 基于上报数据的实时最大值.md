# 2026-07-29b. 基于上报数据的实时最大值

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-29 | **标签**：暴力枚举 | **考点**：回溯窗口最大值（乱序到达）

## 题目描述

在工业物联网监控系统中，由于网络抖动、边缘节点缓存重发等原因，传感器上报数据往往是**乱序到达**；系统接收到一段数据流数据，流中的每个数据包包含一个**发生时刻**（单位秒）的时间戳和一个**测量值**。

对于流中到达的每一个数据点，系统需要以**该数据点的时间戳为基准**，回溯过去一段时间内（包含当前时间戳），数据点的**最大测量值**是多少。

请设计一段程序，按数据流 `data` 中各点的到达顺序，依次输出每个点对应回溯区间中的最大测量值。

### 约束条件

- `1 ≤ interval ≤ 10^9`
- `1 ≤ data.length ≤ 10^3`
- `−10^9 ≤ value ≤ 10^9`

## 输入描述

- 数据流 `data`：二维数组格式，每个数组元素包括两个参数，**发生时刻**和该时刻的**测量值**；如 `[1,10]` 表示时刻 1 的测量值为 10
- 回溯时间 `interval`：整型格式，如当前时刻为 1，回溯时间为 5，那么表示回溯时间起点为 `−4`，回溯区间为 `[−4,1]`

## 输出描述

每个时刻对应回溯区间的最大测量值组成的数组。

---

## 示例

### 示例 1

```
输入：
[[1,10],[6,12],[3,5],[10,7],[5,8]]
4

输出：
[10,12,10,12,10]
```

**解释**：

| 第 i 个到达 | (时刻,值) | 窗口 [t−4, t] | 系统已有点 | 落在窗口内 | 答案 |
|:---:|:---:|:---:|:---|:---|:---:|
| 1 | (1,10) | [−3,1] | (1,10) | (1,10) | **10** |
| 2 | (6,12) | [2,6] | (1,10),(6,12) | (6,12) | **12** |
| 3 | (3,5) | [−1,3] | (1,10),(6,12),(3,5) | (1,10),(3,5) | **10** |
| 4 | (10,7) | [6,10] | (1,10),(6,12),(3,5),(10,7) | (6,12),(10,7) | **12** |
| 5 | (5,8) | [1,5] | 全部 | (1,10),(3,5),(5,8) | **10** |

> ⚠️ 注意第 3 行：当前到达 (3,5) 后回溯 [−1,3] 窗口，虽然系统已经收到 (6,12)，但**时刻 6 在当前时刻 3 的未来**，不属于过去 4 秒范围。

### 示例 2

```
输入：
[[100,50],[95,80],[105,20]]
10

输出：
[50,80,80]
```

**解释**：

- 到达 (100,50)：窗口 [90,100]，只有 50，最大值 = 50
- 到达 (95,80)：窗口 [85,95]，只有 80，最大值 = 80
- 到达 (105,20)：窗口 [95,105]，已收到 (95,80),(100,50),(105,20)，最大值 = 80

## 提示

- `data.length ≤ 10^3`，**双重循环 O(n²)** 完全够用，不需求滑动窗口或单调队列
- **关键陷阱**：到达顺序 ≠ 时间戳顺序，当前点到达时，**未来时刻的点已经"提前收到"也在系统里**，但**不计入当前点的回溯窗口**
- 数据范围 `±10^9`，累加/比较用 `int` 即可，但若要存"最大值初值"，建议用 `Integer.MIN_VALUE` 或第 1 个有效点初始化
- `interval` 可以很大（`10^9`），不必开大数组，按时间戳差判断即可

---

## 思路

### 核心思想：暴力枚举已到达点

`n ≤ 1000`，对每个到达点 `i`，回溯遍历前 `i+1` 个已到达点（**包括自己**），筛选时间戳落在 `[t_i − interval, t_i]` 的，取最大值。

> ⚠️ 不能用单调队列/滑动窗口优化，因为：
> ① 时间戳是**乱序**到达的，不是有序流；
> ② 回溯窗口的**基准时刻每次都变**，窗口起点不固定；
> ③ 历史点会持续保留，新点到达可能落在更早时刻（如示例中第 3 个到达 (3,5) 时刻反而比第 2 个 (6,12) 更早）。

**逐步演示**（以示例 1 第 3 个到达为例）：

```
当前 i=2, 点=(3,5), interval=4
窗口 = [3-4, 3] = [-1, 3]
系统已到达: [(1,10),(6,12),(3,5)]
遍历前 i+1=3 个点:
  (1,10): 1 ∈ [-1,3]? 是 → 候选 10
  (6,12): 6 ∈ [-1,3]? 否 (未来时刻)
  (3,5):  3 ∈ [-1,3]? 是 → 候选 5
max(10,5) = 10  ✓
```

- 时间复杂度：\(O(n^2)\)，最坏 `1000² = 10^6`
- 空间复杂度：\(O(1)\)（不算返回数组）

## 代码

### 我的伪代码

```java
class Solution {
    public int[] realTimeMax(int[][] data, int interval) {
        int n = data.length;
        int[] ans = new int[n];
        for (int i = 0; i < n; i++) {
            int t = data[i][0], v = data[i][1];
            int lo = t - interval;          // 窗口起点
            int max = v;                    // 至少包含自己
            for (int j = 0; j <= i; j++) {  // 遍历已到达的点（含自己）
                if (data[j][0] >= lo && data[j][0] <= t) {
                    max = Math.max(max, data[j][1]);
                }
            }
            ans[i] = max;
        }
        return ans;
    }
}
```

### 解法（Java，暴力枚举）

```java
class Solution {
    public int[] realTimeMax(int[][] data, int interval) {
        int n = data.length;
        int[] ans = new int[n];
        for (int i = 0; i < n; i++) {
            int t = data[i][0];
            int lo = t - interval;              // 窗口下界
            int max = Integer.MIN_VALUE;
            for (int j = 0; j <= i; j++) {       // 已到达的点（含自己）
                int tj = data[j][0];
                if (tj >= lo && tj <= t) {       // 时间戳落在 [t-interval, t]
                    max = Math.max(max, data[j][1]);
                }
            }
            ans[i] = max;
        }
        return ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n^2)\)，外层 n 次到达，内层最多遍历 i+1 个点。
- **空间复杂度**：\(O(n)\)（返回数组）或 \(O(1)\)（不算返回）。

> 💡 **记忆**：**「乱序到达，回溯窗口是 [t−interval, t]，遍历已到达点取 max」**——窗口随每个点变化，不能用单调队列。
>
> ⚠️ **易错**：① 窗口是 `[t-interval, t]` **闭区间**，等号两端都包含；② 遍历范围是 `j ∈ [0, i]`（含自己），不是 `[0, i-1]`（要算上当前点）；③ 时间戳乱序，**判断条件是时间戳在窗口内，不是 j 索引范围**。
