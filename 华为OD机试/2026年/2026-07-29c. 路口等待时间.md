# 2026-07-29c. 路口等待时间

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-07-29 | **标签**：模拟 | **考点**：红绿灯周期 + 4 方向独立排队

## 题目描述

十字路口的红绿灯分为**东西向（E/W）** 和**南北向（S/N）** 两组，两组状态始终相反。

- 东西向红灯亮 `R` 秒，然后绿灯亮 `G` 秒，不断循环；
- 南北向则相反——绿灯亮 `R` 秒，然后红灯亮 `G` 秒。
- 刚开始时（`0` 秒）东西方向是**红灯**，南北方向是**绿灯**。
- 红绿灯切换**无过渡期**，红灯结束时绿灯立即开始，无需额外等待。

车辆到达路口时，遇到**绿灯直接走**，通过路口需要 `1` 秒；如遇到**红灯停下来等**。

- E/W/S/N 四个方向各有一条**独立车道**，各自排队，**互不干扰**
- 同向后车必须等前车走完才能走

求从**第一辆车到达路口**，到**最后一辆车完全离开**：
1. 共同花费多少秒（总耗时 = 最晚离开 − 最早到达）
2. 最后一辆离开的时间是第几秒

### 约束

- `1 ≤ R, G ≤ 60`
- 到达时刻 `≤ 100`
- 车辆数量 `≤ 100`
- 车辆的来向数量和到达时刻数量相等，且**到达时刻按非递减顺序排列**

## 输入描述

- 整数 `R`：东西向红灯持续秒数（对应南北向绿灯时长）
- 整数 `G`：东西向绿灯持续秒数（对应南北向红灯时长）
- 字符数组：大写字母表示车辆来向，`E`=东向西，`W`=西向东，`S`=南向北，`N`=北向南
- 整型数组：各车辆的到达时间

## 输出描述

二维数组，表示 `[第一辆车到达路口到最后一辆车完全离开的总耗时, 最后一辆车离开的时间]`。

---

## 示例

### 示例 1

```
输入：
3,5,[E,S,W,N],[0,1,3,6]

输出：
[9,9]
```

**解释**：

周期 `C = R+G = 8` 秒。
- E/W 红灯条件：`t % 8 < 3`
- S/N 红灯条件：`t % 8 >= 3`

所有车辆逐步模拟：

| 车辆 | 到达 | 方向 | 等待计算 | 通行开始 | 离开 |
|:---:|:---:|:---:|:---|:---:|:---:|
| 1 | 0 | E | `0%8=0 < 3` 红灯，等 `3-0=3` 秒 | 3 | 4 |
| 2 | 1 | S | `1%8=1 < 3` 绿灯，直接走 | 1 | 2 |
| 3 | 3 | W | `3%8=3 >= 3` 绿灯（即第 3 秒已进入绿灯），直接走 | 3 | 4 |
| 4 | 6 | N | `6%8=6 >= 3` 红灯，等 `8-6=2` 秒至下一周期 | 8 | 9 |

- 最早到达 = 0 秒
- 最晚离开 = 9 秒
- 总耗时 = 9 − 0 = 9 秒
- 最后一辆离开时间 = 9

### 示例 2

```
输入：
2,3,[E,E,S],[1,3,4]

输出：
[5,6]
```

**解释**：

周期 `C = R+G = 5` 秒。

| 车辆 | 到达 | 方向 | 等待计算 | 通行开始 | 离开 |
|:---:|:---:|:---:|:---|:---:|:---:|
| 1 | 1 | E | `1%5=1 < 2` 红灯，等 `2-1=1` 秒 | 2 | 3 |
| 2 | 3 | E | `3%5=3 >= 2` 绿灯；前车已离开（free[E]=3） | 3 | 4 |
| 3 | 4 | S | `4%5=4 >= 2` 红灯（南北向），等 `5-4=1` 秒 | 5 | 6 |

- 最早到达 = 1 秒
- 最晚离开 = 6 秒
- 总耗时 = 6 − 1 = 5 秒
- 最后一辆离开时间 = 6

## 提示

- 关键观察：**周期 `C = R + G`**，E/W 与 S/N **状态相反**
  - E/W 红灯 ⟺ `t % C < R`
  - S/N 红灯 ⟺ `t % C >= R`（即 S/N 红灯区间是 `[R, C)`）
- 4 个方向**独立排队**：同方向后车 `start = max(arrive, free[dir], 等绿灯时刻)`，**不要把"同方向"误以为是"同车道"**（E 和 W 是两个独立车道）
- 通过 1 秒：`leave = start + 1`
- 输出顺序：`[总耗时, 最晚离开时刻]`，注意总耗时 = **最晚离开 − 最早到达**，不是最晚离开本身
- 车辆数 ≤ 100、R/G ≤ 60，时间最坏 `100 * 60 * 100 = 6×10^5` 远小于 int 范围

---

## 思路

### 核心思想：4 方向独立队列 + 周期取模

把每个方向看作独立处理流水线，**只需维护 4 个变量 `free[dir]`** 表示该方向"下次车道空闲时刻"。每辆车到达后，**取 3 个值的最大值**作为实际通行开始时刻：

```
实际开始时刻 = max(arrive, free[dir], nextGreen(arrive, dir))
```

其中 `nextGreen(t, dir)` 是「从 t 开始，方向 dir 的下一个绿灯开始的时刻」：

- **E/W**（红灯区间 `[0, R)`）：若 `t%C < R`，等 `R - t%C` 秒；否则立即绿灯
- **S/N**（红灯区间 `[R, C)`）：若 `t%C >= R`，等 `C - t%C` 秒到下周期；否则立即绿灯

> ⚠️ 注意 `free[dir]` 已经是某车离开时刻，本身可能落在红灯区间。所以 `nextGreen` 必须基于 `max(arrive, free[dir])` 后再判断，不能只看 `arrive`。

**逐步演示**（示例 1，周期 `C=8`，`[E,S,W,N]` @ `[0,1,3,6]`）：

```
初始: free[E]=free[S]=free[W]=free[N]=0
车辆 E @ 0:
  base = max(0, free[E]=0) = 0
  0%8=0 < 3 → 红灯，等 3-0=3 秒 → start=3
  leave=4, free[E]=4, maxLeave=4

车辆 S @ 1:
  base = max(1, free[S]=0) = 1
  1%8=1 < 3 → 南北向绿灯 → start=1
  leave=2, free[S]=2, maxLeave=4

车辆 W @ 3:
  base = max(3, free[W]=0) = 3
  3%8=3 >= 3 → 东西向绿灯 → start=3
  leave=4, free[W]=4, maxLeave=4

车辆 N @ 6:
  base = max(6, free[N]=0) = 6
  6%8=6 >= 3 → 南北向红灯，等 8-6=2 秒 → start=8
  leave=9, free[N]=9, maxLeave=9

最早到达 = 0，最晚离开 = 9
输出 = [9-0, 9] = [9, 9]  ✓
```

- 时间复杂度：\(O(n)\)，每辆车 O(1) 计算
- 空间复杂度：\(O(1)\)，仅 4 个 `free[dir]` 变量

## 代码

### 我的伪代码

```java
class Solution {
    public int[] intersectionWait(int R, int G, char[] dirs, int[] arrives) {
        int C = R + G;                         // 周期
        int[] free = new int[4];               // 0=E, 1=W, 2=S, 3=N
        int minArrive = Integer.MAX_VALUE;
        int maxLeave = 0;
        for (int i = 0; i < dirs.length; i++) {
            int t = arrives[i];
            int d = indexOfDir(dirs[i]);        // E→0, W→1, S→2, N→3
            int base = Math.max(t, free[d]);    // 同时考虑排队
            int phase = base % C;
            boolean ewRed = (d == 0 || d == 1);  // E/W 红灯在 [0,R)
            boolean isRed = ewRed ? (phase < R) : (phase >= R);
            int wait = 0;
            if (isRed) {
                wait = ewRed ? (R - phase) : (C - phase);
            }
            int start = base + wait;
            int leave = start + 1;              // 通过需 1 秒
            free[d] = leave;                    // 占用至 leave 时刻
            minArrive = Math.min(minArrive, t);
            maxLeave = Math.max(maxLeave, leave);
        }
        return new int[]{maxLeave - minArrive, maxLeave};
    }
}
```

### 解法（Java，4 方向独立排队）

```java
class Solution {
    public int[] intersectionWait(int R, int G, char[] dirs, int[] arrives) {
        int C = R + G;                          // 红绿灯周期
        int[] free = new int[4];                // 0=E, 1=W, 2=S, 3=N
        int minArrive = Integer.MAX_VALUE;
        int maxLeave = 0;

        for (int i = 0; i < dirs.length; i++) {
            int t = arrives[i];
            int d = dirIndex(dirs[i]);
            int base = Math.max(t, free[d]);     // 车道空闲才能走
            int phase = base % C;
            boolean isEW = (d == 0 || d == 1);    // E/W 同相位
            boolean isRed = isEW ? (phase < R) : (phase >= R);
            int wait = 0;
            if (isRed) {
                wait = isEW ? (R - phase) : (C - phase);
            }
            int start = base + wait;
            int leave = start + 1;               // 通过 1 秒
            free[d] = leave;                     // 该方向车道占用至 leave
            minArrive = Math.min(minArrive, t);
            maxLeave = Math.max(maxLeave, leave);
        }
        return new int[]{maxLeave - minArrive, maxLeave};
    }

    private int dirIndex(char c) {
        switch (c) {
            case 'E': return 0;
            case 'W': return 1;
            case 'S': return 2;
            case 'N': return 3;
            default:  return -1;
        }
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，每辆车 O(1) 计算。
- **空间复杂度**：\(O(1)\)，仅 4 个 `free[dir]` 变量 + 常数。

> 💡 **记忆**：**「周期 C=R+G；E/W 红在 [0,R)，S/N 红在 [R,C)；每方向维护 free，取 max(arrive, free, nextGreen) + 1」**。
>
> ⚠️ **易错**：① 输出 `[总耗时, 最晚离开]`，总耗时 = **差值**，不是最晚离开本身；② `free[dir]` 已经是某车离开时刻，**nextGreen 必须基于 max(arrive, free) 后再算**，不能只看 arrive；③ E 和 W 是**两个独立车道**，不共享 `free`，别合并成一个变量。
