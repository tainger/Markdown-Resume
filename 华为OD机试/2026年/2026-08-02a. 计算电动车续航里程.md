# 2026-08-02a. 计算电动车续航里程

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-02

## 题目描述

给定电动车的电池容量 `capacity`（kWh）、能耗效率 `efficiency`（kWh/100km）、驾驶场景（城市/高速/山路，int 类型，分别是 `0/1/2`），计算该车的有效续航里程（km）。

**核心公式：**

- 理论续航里程 = (电池容量 × 容量能耗修正系数) / 能耗效率 × 100（结果按四舍五入保留 4 位小数）
- 有效续航里程 = 理论续航里程 × 总体损耗系数（结果四舍五入为整数）

**容量能耗修正系数 Kp（分段线性修正）：**

- 零段：电池容量 `capacity ≥ 160 kWh` 的部分，`kp0 = 1`（无损耗）
- 一段：`80 kWh < capacity < 160 kWh` 的部分，`kp1 = 0.98`
- 二段：`capacity ≤ 80 kWh` 的部分，`kp2 = 0.95`

即：容量的不同区间分别乘不同系数后累加，得到"等效电池容量"。

**总体损耗系数 kd：**

- kd = 基础损耗系数 `kb = 0.956` × 场景修正系数 `kc`（结果四舍五入保留 4 位小数）
- 场景系数：城市 `0 → kc0 = 1`；高速 `1 → kc1 = 0.92`；山路 `2 → kc2 = 0.85`

## 输入描述

- 电池容量范围：`20 ≤ capacity ≤ 200`（可能为小数，非整数需**向下取整**）
- 能耗效率范围：`5 ≤ efficiency ≤ 30`（可能为小数）
- 驾驶场景：整数 `0/1/2`

输入为一行，包含三个值，以英文逗号分隔，例如：`75.8,14.3,1`

## 输出描述

输出一个整数，表示四舍五入后的有效续航里程（单位：km）。

---

## 示例

### 示例 1

```
输入：75.8,14.3,1
输出：438
```

**说明**：

1. 电池容量向下取整：`75.8 → 75`，全部落在二段（≤80）：等效容量 = `75 × 0.95 = 71.25`
2. 理论里程 = `71.25 / 14.3 × 100 = 498.2517 km`（保留 4 位）
3. 总体损耗系数 = `0.956 × 0.92（高速）= 0.8795`（保留 4 位）
4. 有效里程 = `498.2517 × 0.8795 = 438.21...`，四舍五入 = `438`

### 示例 2

```
输入：135.1,12.3,2
输出：858
```

**说明**：

1. 容量向下取整：`135.1 → 135`
2. 二段部分 80：`80 × 0.95 = 76`；一段部分 `135-80 = 55`：`55 × 0.98 = 53.9`；等效容量 = `76 + 53.9 = 129.9`
3. 理论里程 = `129.9 / 12.3 × 100 = 1056.0976 km`（保留 4 位）
4. 总体损耗系数 = `0.956 × 0.85（山路）= 0.8126`（保留 4 位）
5. 有效里程 = `1056.0976 × 0.8126 = 858.18...`，四舍五入 = `858`

---

## 提示

- **容量先向下取整**：`75.8 → 75`，用 `Math.floor`，不是四舍五入
- 分段修正是**按容量区间分别乘系数再累加**：≤80 部分乘 0.95，80~160 部分乘 0.98，≥160 部分乘 1
- 理论里程和损耗系数都要**先四舍五入保留 4 位小数**，再相乘得到有效里程
- 最终结果四舍五入为整数；小数运算建议用 `BigDecimal` + `HALF_UP` 保证精度
- 场景与系数映射：0 城市 1.0、1 高速 0.92、2 山路 0.85

---

## 思路

### 核心思想：分段函数 + 逐步套公式

1. **容量取整**：`c = floor(capacity)`
2. **分段计算等效容量**（三段拼接）：

   ```
   二段（≤80）：      min(c, 80) × 0.95
   一段（80~160）：   max(0, min(c,160) - 80) × 0.98
   零段（≥160）：     max(0, c - 160) × 1.0
   ```

3. **理论里程** = 等效容量 / efficiency × 100，四舍五入 4 位
4. **损耗系数** = 0.956 × 场景系数，四舍五入 4 位
5. **有效里程** = 理论里程 × 损耗系数，四舍五入取整

**逐步演示**（示例 2，`135.1, 12.3, 2`）：

```
c = floor(135.1) = 135
等效容量 = 80×0.95 + (135-80)×0.98 + 0×1
        = 76 + 53.9 = 129.9
理论里程 = 129.9/12.3×100 = 1056.0976
kd = 0.956 × 0.85 = 0.8126
有效里程 = 1056.0976 × 0.8126 = 858.18 → 858  ✓
```

- 时间复杂度：\(O(1)\)
- 空间复杂度：\(O(1)\)

## 代码

### 解法（Java，分段模拟）

```java
import java.math.BigDecimal;
import java.math.RoundingMode;

class Solution {
    public int calculateRange(double capacity, double efficiency, int scene) {
        // 1. 电池容量向下取整
        int c = (int) Math.floor(capacity);

        // 2. 分段线性修正：<=80 段系数 0.95，80~160 段系数 0.98，>=160 段系数 1.0
        double effCapacity = Math.min(c, 80) * 0.95
                + Math.max(0, Math.min(c, 160) - 80) * 0.98
                + Math.max(0, c - 160) * 1.0;

        // 3. 理论续航里程，四舍五入保留 4 位小数
        double theory = round4(effCapacity / efficiency * 100);

        // 4. 场景修正系数：0 城市 1.0，1 高速 0.92，2 山路 0.85
        double kc;
        if (scene == 0) {
            kc = 1.0;
        } else if (scene == 1) {
            kc = 0.92;
        } else {
            kc = 0.85;
        }

        // 5. 总体损耗系数 = 基础损耗 0.956 × 场景系数，保留 4 位
        double kd = round4(0.956 * kc);

        // 6. 有效续航里程，四舍五入为整数
        return (int) Math.round(theory * kd);
    }

    // 四舍五入保留 4 位小数
    private double round4(double v) {
        return BigDecimal.valueOf(v).setScale(4, RoundingMode.HALF_UP).doubleValue();
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(1)\)，纯公式计算
- **空间复杂度**：\(O(1)\)

> 💡 **记忆**：**分段系数题 = 区间拆分累加**。把容量按 80、160 两个切点拆成三段，每段容量 × 对应系数再求和；公式题严格按题面顺序计算，中间结果该保留几位就保留几位。
>
> ⚠️ **易错**：① 容量是**向下取整**（`floor`），不是四舍五入；② 分段系数作用在"容量的不同部分"上（135 = 80 + 55），不是整容量乘一个系数；③ 理论里程和损耗系数要**先各自 round 到 4 位再相乘**，顺序反了结果会偏；④ 浮点四舍五入用 `BigDecimal HALF_UP`，避免 `0.5` 边界误差。
