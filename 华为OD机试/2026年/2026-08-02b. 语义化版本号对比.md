# 2026-08-02b. 语义化版本号对比

> **难度**：🟡 中等 | **分值**：100 | **卷次**：新系统 2026-08-02

## 题目描述

当前有一组版本号列表信息，单个版本号格式为：`Major.Minor.Patch`-可选先行版+可选构建信息，具体字段如下：

- `Major.Minor.Patch`：三个非负整数，**禁止前导零**
- 先行版和构建信息：可选段，由字母数字和符号（`.` 和 `-`）组成

请实现语义化版本号比较器，对输入版本号字符串列表按规则处理，返回**最大的版本号**（若存在相等的最大版本号，返回第一个）；若存在不合规格式则返回**空字符串**。

**优先级比较规则：**

1. 从左至右比较 `Major`、`Minor`、`Patch` 数字大小，大的优先
2. 若三者相同，比较先行版信息（第一个 `-` 为分隔符，**有信息大于无信息**）
3. 若先行版也相同，比较构建信息（第一个 `+` 为分隔符，**有信息大于无信息**）
4. 先行版/构建信息若包含 `.`，先按 `.` 切分再逐一对比，首个元素大的优先；单个元素对比规则：
   - **纯数值**：按数值大小比较（`10 > 9`）
   - **字符/混合串**：按 ASCII 字典序比较（`1 < A < a`）
   - **前缀相同**：内容多者优先（`a-b < a-b-c`）

## 输入描述

- 版本号列表长度 `[1,100]`，每个版本号字符串长度 `[0,1024]`
- 纯数字标识符的值在 `[0, 2^31-1]` 之间
- 先行版和构建信息保证：任意符号之间内容不为空，可能出现 `-` 或 `.`，不出现 `_`、`~`，不以符号开头或结尾，纯数字标识符无前导零；`+` 最多出现一次
- 输入为一行（或字符串数组），多个版本号之间使用英文逗号分隔

## 输出描述

返回最大的版本号字符串；若存在不合规格式则返回空字符串 `""`。

---

## 示例

### 示例 1

```
输入：["0.0.1","0.1.1","1.0.0"]
输出："1.0.0"
```

**说明**：按顺序比较 Major.Minor.Patch，`1.0.0` 的 Major 最大。

### 示例 2

```
输入：["1.0.0-alpha","1.0.0-alpha.alpha","1.0.0-alpha.beta"]
输出："1.0.0-alpha.beta"
```

**说明**：主版本号相同，先行版按 `.` 切分后逐段比较 ASCII：三者第一段都是 `alpha`，第二段 `alpha < beta`（`b > a`），故 `alpha.beta` 最大。

### 示例 3

```
输入：["1.0.0_alpha","1.0.0.alpha","1.0.0~alpha"]
输出：""
```

**说明**：`_`、`~` 属于非法字符，存在不合规格式，返回空字符串。

### 示例 4

```
输入：["1.0.0-alpha+2025","1.0.0-alpha+2026"]
输出："1.0.0-alpha+2026"
```

**说明**：主版本与先行版相同，比较构建信息：纯数值 `2026 > 2025`。

## 提示

- **先全量校验再比较**：列表中任意一个版本号非法，直接返回 `""`
- 非法情形速查：含 `_`/`~` 等非法字符、以 `.`/`-`/`+` 开头或结尾、两个符号相邻（如 `..`、`-.`）、`+` 超过一次、数字段有前导零（`01`）
- 解析顺序：先按第一个 `+` 拆构建信息，再按第一个 `-` 拆先行版，剩余部分按 `.` 拆出 Major/Minor/Patch
- 元素比较：**两段都是纯数字才按数值比**（`10>9`），否则按 ASCII 字符串比（天然满足 `1<A<a` 和"前缀短者小"）
- 注意本题先行版规则是**有信息大于无信息**（与标准 SemVer 相反），按题面来

## 思路

### 核心思想：解析 + 校验 + 多级比较器

1. **合法性校验**（逐字符 + 结构）：
   - 字符只能是字母、数字、`.`、`-`、`+`；禁止 `_`、`~`
   - 首尾不能是符号；任意两个符号不能相邻；`+` 至多一个
2. **解析**为五部分：`Major`、`Minor`、`Patch`（必须为无前导零的非负整数）、先行版标识符序列、构建信息标识符序列
3. **比较**（按优先级）：
   - 三段主版本号按数值比较
   - 先行版/构建信息：都没有 → 相等；一个有一个没有 → 有者大；都有 → 按 `.` 切分后逐段比较，缺失段方为小（前缀相同内容多者优先）
   - 单段比较：双方都为纯数字 → 数值比较；否则 → ASCII 字典序
4. 遍历列表维护最大值，**相等时保留先出现的**

**逐步演示**（示例 2）：

```
1.0.0-alpha        → 主版本 1.0.0，先行版 [alpha]
1.0.0-alpha.alpha  → 主版本 1.0.0，先行版 [alpha, alpha]
1.0.0-alpha.beta   → 主版本 1.0.0，先行版 [alpha, beta]
主版本相同 → 比先行版：
  第1段都是 alpha
  第2段：缺失 < alpha < beta（ASCII b>a）
最大 = 1.0.0-alpha.beta  ✓
```

- 时间复杂度：\(O(L)\)，L 为所有版本号总长度
- 空间复杂度：\(O(L)\)

## 代码

### 解法（Java，解析 + 多级比较）

```java
class Solution {
    public String findLatestVersion(String[] versions) {
        if (versions == null || versions.length == 0) {
            return "";
        }
        String best = null;
        for (String v : versions) {
            // 任意版本号非法 → 返回空字符串
            if (!isValid(v)) {
                return "";
            }
            if (best == null || compare(v, best) > 0) {
                best = v; // 相等时不更新，保留第一个
            }
        }
        return best;
    }

    // ========== 合法性校验 ==========
    private boolean isValid(String s) {
        if (s == null || s.isEmpty()) {
            return false;
        }
        // 字符白名单：字母、数字、. - +；禁止 _ ~ 等
        int plusCount = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '+') {
                plusCount++;
            }
            boolean ok = Character.isLetterOrDigit(c) || c == '.' || c == '-' || c == '+';
            if (!ok) {
                return false;
            }
            // 符号不能相邻
            if (i > 0 && isSym(s.charAt(i - 1)) && isSym(c)) {
                return false;
            }
        }
        if (plusCount > 1) {
            return false; // '+' 最多一次
        }
        // 不能以符号开头或结尾
        char first = s.charAt(0);
        char last = s.charAt(s.length() - 1);
        if (isSym(first) || isSym(last)) {
            return false;
        }

        String[] parsed = parse(s);
        // Major.Minor.Patch 必须为无前导零的非负整数
        for (int i = 0; i < 3; i++) {
            if (!isPureNumber(parsed[i])) {
                return false;
            }
        }
        // 先行版、构建信息的每个标识符合法
        if (!checkIdentifiers(parsed[3]) || !checkIdentifiers(parsed[4])) {
            return false;
        }
        return true;
    }

    private boolean isSym(char c) {
        return c == '.' || c == '-' || c == '+';
    }

    // 纯数字且无前导零（"0" 合法，"01" 非法）
    private boolean isPureNumber(String s) {
        if (s == null || s.isEmpty()) {
            return false;
        }
        for (char c : s.toCharArray()) {
            if (!Character.isDigit(c)) {
                return false;
            }
        }
        return s.length() == 1 || s.charAt(0) != '0';
    }

    // 校验先行版/构建信息：按 . 切分，标识符由字母数字和 - 组成，纯数字无前导零
    private boolean checkIdentifiers(String ext) {
        if (ext == null || ext.isEmpty()) {
            return true; // 无该段，合法
        }
        for (String id : ext.split("\\.")) {
            if (id.isEmpty()) {
                return false;
            }
            boolean allDigit = true;
            for (char c : id.toCharArray()) {
                if (!Character.isLetterOrDigit(c) && c != '-') {
                    return false;
                }
                if (!Character.isDigit(c)) {
                    allDigit = false;
                }
            }
            if (allDigit && !isPureNumber(id)) {
                return false;
            }
        }
        return true;
    }

    // ========== 比较：a>b 返回 1，a<b 返回 -1，相等 0 ==========
    private int compare(String a, String b) {
        String[] pa = parse(a);
        String[] pb = parse(b);
        // 1. Major.Minor.Patch 数值比较
        for (int i = 0; i < 3; i++) {
            int cmp = Long.compare(Long.parseLong(pa[i]), Long.parseLong(pb[i]));
            if (cmp != 0) {
                return cmp;
            }
        }
        // 2. 先行版
        int cmpPre = compareExt(pa[3], pb[3]);
        if (cmpPre != 0) {
            return cmpPre;
        }
        // 3. 构建信息
        return compareExt(pa[4], pb[4]);
    }

    // 比较先行版/构建信息：有信息 > 无信息
    private int compareExt(String x, String y) {
        boolean hx = x != null && !x.isEmpty();
        boolean hy = y != null && !y.isEmpty();
        if (!hx && !hy) {
            return 0;
        }
        if (!hx) {
            return -1; // x 无信息 → x 小
        }
        if (!hy) {
            return 1;
        }
        String[] ax = x.split("\\.");
        String[] ay = y.split("\\.");
        int len = Math.max(ax.length, ay.length);
        for (int i = 0; i < len; i++) {
            if (i >= ax.length) {
                return -1; // 前缀相同，内容多者优先
            }
            if (i >= ay.length) {
                return 1;
            }
            int cmp = compareIdentifier(ax[i], ay[i]);
            if (cmp != 0) {
                return cmp;
            }
        }
        return 0;
    }

    // 单个标识符：都为纯数字按数值比，否则按 ASCII 字典序
    private int compareIdentifier(String x, String y) {
        if (isAllDigits(x) && isAllDigits(y)) {
            return Long.compare(Long.parseLong(x), Long.parseLong(y));
        }
        return x.compareTo(y);
    }

    private boolean isAllDigits(String s) {
        for (char c : s.toCharArray()) {
            if (!Character.isDigit(c)) {
                return false;
            }
        }
        return true;
    }

    // ========== 解析：返回 [Major, Minor, Patch, 先行版, 构建信息] ==========
    // 先行版/构建信息无则为空串；主版本号中多于 3 段的点分内容并入先行版
    private String[] parse(String s) {
        String rest = s;
        String build = "";
        int plus = s.indexOf('+');
        if (plus >= 0) {
            rest = s.substring(0, plus);
            build = s.substring(plus + 1);
        }
        String core = rest;
        String pre = "";
        int dash = rest.indexOf('-'); // 第一个 '-' 为先行版分隔符
        if (dash >= 0) {
            core = rest.substring(0, dash);
            pre = rest.substring(dash + 1);
        }
        String[] parts = core.split("\\.");
        StringBuilder preSb = new StringBuilder();
        for (int i = 3; i < parts.length; i++) {
            if (preSb.length() > 0) {
                preSb.append('.');
            }
            preSb.append(parts[i]);
        }
        if (!pre.isEmpty()) {
            if (preSb.length() > 0) {
                preSb.append('.');
            }
            preSb.append(pre);
        }
        return new String[]{parts[0], parts[1], parts[2], preSb.toString(), build};
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(L)\)，L 为列表中所有版本号字符总数，每个字符常数次处理
- **空间复杂度**：\(O(L)\)，解析产生的字符串数组

> 💡 **记忆**：**版本号比较 = "拆段 + 分级比较"**。先拆构建（`+`）、再拆先行版（第一个 `-`）、最后拆主版本（`.`）；比较顺序主版本 → 先行版 → 构建信息；单段"双数字按数值，否则按 ASCII"。
>
> ⚠️ **易错**：① 先行版/构建信息是**有信息 > 无信息**，与标准 SemVer（先行版 < 正式版）相反，务必按题面；② `10` 和 `9` 都是纯数字要按数值比（10 大），不能直接字典序；③ 前导零非法（`01`），但单个 `0` 合法；④ 任一版本非法即返回 `""`，不要只比合法的；⑤ 相等最大值返回**第一个**，比较时用严格大于才更新。
