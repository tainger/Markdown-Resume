# 2026-08-02c. 战士技能规划设计

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-08-02

## 题目描述

你为一款动作游戏设计战士角色的技能：战士每个技能会消耗不同能量，释放技能有 2 个约束：

- 连续释放技能数量不能超过 `m` 个
- 一段内技能能量总和不能超过能量上限 `k`

如果超过则必须中断当前技能，进入调息状态（即**分段**）。

战士有一项**爆发技巧**：在单次战斗中有一次能量上限翻倍至 `2k` 的机会，此项场景下战士需使用连续的 `w` 个技能（技能数量限制 `m` 依然生效，即要求 `w ≤ m`）。

**任务目标：**

给定技能能量消耗列表 `a`，计算在合理使用爆发机会（或选择不使用）的前提下，释放完所有技能所需的**最少分段数**。

若存在某个技能的能耗过高，即使开启爆发也无法释放（`a[i] > 2k`），则判定无解，返回 `-1`。

## 输入描述

- `k`：能量上限，正整数（`1 ≤ k ≤ 10^9`）
- `m`：单次调息最大技能数，正整数（`1 ≤ m ≤ n`）
- `w`：爆发持续技能数，正整数（`1 ≤ w ≤ n`）
- `a`：技能能量消耗列表，长度 `n`（`1 ≤ n ≤ 100000`），每个元素为正整数（`1 ≤ a[i] ≤ 10^9`）

## 输出描述

输出满足条件的最少分段数（最少调息次数 + 1）；若无解则输出 `-1`。

---

## 示例

### 示例 1

```
输入：5,3,2,[3,4,3,4]
输出：3
```

**说明**：爆发窗口覆盖索引 0~1 的 `[3,4]`（和为 7 ≤ 2k=10）为 1 段；剩余 `[3]`、`[4]` 因 3+4=7>k=5 各成 1 段，共 3 段。

### 示例 2

```
输入：5,3,2,[6,1,2,3]
输出：2
```

**说明**：`a[0]=6 > k=5` 且 `6 < 2k=10`，普通分段无法容纳，必须靠爆发窗口覆盖 `a[0]`：窗口 `[6,1]`（和 7≤10）为 1 段，剩余 `[2,3]`（和 5≤5）为 1 段，共 2 段。

### 示例 3

```
输入：10,5,3,[1,1,1,1,1]
输出：1
```

**说明**：`sum=5 ≤ k=10` 且 `n=5 ≤ m=5`，无需爆发即可 1 段放完。若开启爆发，窗口最多覆盖 3 个技能，剩余 2 个需另开 1 段，反而变成 2 段，故不使用爆发更优。

---

## 提示

- **普通模式贪心最优**：固定序列下，每段尽可能多放技能（再放一个就超能量或超数量时才开新段），分段数最少
- **爆发窗口独立成段**：覆盖连续 `w` 个技能，能量上限 `2k`，但数量限制 `m` 仍在（`w > m` 时爆发不可用）
- **前后缀分解**：枚举爆发窗口 `[l, l+w)`，总分段数 = 前缀 `[0,l)` 贪心段数 + 1（爆发段）+ 后缀 `[l+w,n)` 贪心段数
- 预处理 `pre[i]`（前 i 个技能的贪心段数）和 `suf[i]`（从 i 到末尾的贪心段数），窗口内能量和用前缀和 \(O(1)\) 查询
- 普通贪心遇到 `a[i] > k` 的技能时该侧标记为不可行（INF），只能靠爆发覆盖；若 `a[i] > 2k` 直接返回 -1

---

## 思路

### 核心思想：贪心分段 + 枚举爆发窗口（前后缀分解）

1. **无解判定**：任意 `a[i] > 2k` → 返回 -1
2. **前缀贪心** `pre[i]`：从左到右，维护当前段的能量和与技能数，能塞就塞，塞不下就开新段；遇到 `a[j] > k` 则此后前缀均不可行（INF）
3. **后缀贪心** `suf[i]`：从右到左做同样的贪心（对称性保证最优）
4. **枚举爆发窗口**起点 `l`（`0 ≤ l ≤ n-w`）：
   - 窗口能量和 = 前缀和 `ps[l+w] - ps[l]`，必须 ≤ `2k`
   - 要求 `w ≤ m`、`pre[l]` 和 `suf[l+w]` 均可行
   - 总分段 = `pre[l] + 1 + suf[l+w]`
5. 答案 = 不使用爆发的 `pre[n]` 与所有窗口方案的最小值

**逐步演示**（示例 2，`k=5, m=3, w=2, a=[6,1,2,3]`）：

```
pre[0]=0；a[0]=6>k=5 → pre[1..]=INF
suf[2]：[2,3] 和为 5≤5、数量 2≤3 → 1 段
枚举窗口：
  l=0：窗口 [6,1] 和=7≤10 ✓ → pre[0]+1+suf[2] = 0+1+1 = 2
  l=1,2：pre[l]=INF（6 未被窗口覆盖）→ 跳过
答案 = 2  ✓
```

- 时间复杂度：\(O(n)\)，两次贪心 + 一次窗口枚举
- 空间复杂度：\(O(n)\)，pre/suf/前缀和数组

## 代码

### 解法（Java，贪心 + 前后缀分解）

```java
class Solution {
    private static final int INF = Integer.MAX_VALUE / 2;

    public int minSkillSegments(int k, int m, int w, int[] a) {
        int n = a.length;

        // 1. 无解判定：存在技能能耗超过爆发上限 2k
        for (int x : a) {
            if ((long) x > 2L * k) {
                return -1;
            }
        }

        // 2. 前缀贪心：pre[i] = 释放前 i 个技能所需的最少段数
        int[] pre = new int[n + 1];
        long sum = 0;   // 当前段能量和
        int cnt = 0;    // 当前段技能数
        int seg = 0;    // 已闭合的段数
        boolean bad = false;
        for (int j = 0; j < n; j++) {
            if (a[j] > k) {
                bad = true; // 普通模式无法容纳该技能
            }
            if (bad) {
                pre[j + 1] = INF;
                continue;
            }
            // 再放入 a[j] 会超能量或超数量 → 闭合当前段，开新段
            if (cnt > 0 && (sum + a[j] > k || cnt + 1 > m)) {
                seg++;
                sum = 0;
                cnt = 0;
            }
            sum += a[j];
            cnt++;
            pre[j + 1] = seg + 1;
        }

        // 3. 后缀贪心：suf[i] = 释放 a[i..n-1] 所需的最少段数
        int[] suf = new int[n + 1];
        sum = 0;
        cnt = 0;
        seg = 0;
        bad = false;
        for (int j = n - 1; j >= 0; j--) {
            if (a[j] > k) {
                bad = true;
            }
            if (bad) {
                suf[j] = INF;
                continue;
            }
            if (cnt > 0 && (sum + a[j] > k || cnt + 1 > m)) {
                seg++;
                sum = 0;
                cnt = 0;
            }
            sum += a[j];
            cnt++;
            suf[j] = seg + 1;
        }

        // 4. 前缀和，用于 O(1) 计算窗口能量和
        long[] ps = new long[n + 1];
        for (int i = 0; i < n; i++) {
            ps[i + 1] = ps[i] + a[i];
        }

        // 5. 答案初始为不使用爆发：pre[n]
        int ans = pre[n];

        // 6. 枚举爆发窗口 [l, l+w)，爆发段能量上限 2k、数量限制 m 仍生效
        if (w <= m) {
            for (int l = 0; l + w <= n; l++) {
                long windowSum = ps[l + w] - ps[l];
                if (windowSum > 2L * k) {
                    continue; // 爆发也容纳不下
                }
                if (pre[l] >= INF || suf[l + w] >= INF) {
                    continue; // 前缀或后缀普通分段不可行
                }
                ans = Math.min(ans, pre[l] + 1 + suf[l + w]);
            }
        }

        return ans >= INF ? -1 : ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，前缀贪心、后缀贪心、窗口枚举各一趟
- **空间复杂度**：\(O(n)\)，`pre`、`suf`、前缀和数组

> 💡 **记忆**：**"一次特殊操作 + 固定序列最优分段"= 前后缀分解**。先贪心算出每个前缀/后缀的最优段数，再枚举特殊窗口的位置，把答案拼成 `pre[l] + 窗口代价 + suf[l+w]`，与"不操作"的基线取最小。
>
> ⚠️ **易错**：① 爆发窗口**固定覆盖连续 w 个技能**且自身算 1 段，不是把 2k 应用到全局；② 数量限制 `m` 对爆发段仍生效，`w > m` 时不能爆发；③ 能量和用 `long`（`10^9 × 10^5` 超 int）；④ `a[i] > k` 但 `≤ 2k` 的技能**必须**被爆发窗口覆盖，靠 pre/suf 置 INF 自然过滤窗口位置；⑤ 不使用爆发的方案（示例 3）也要参与取最小。
