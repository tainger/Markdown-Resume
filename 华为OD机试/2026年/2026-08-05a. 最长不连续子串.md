# 2026-08-05a. 最长不连续子串

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-05

## 题目描述

给定一个整数数组，请找出最长的子串（连续子数组），使得该子串中**任意两个相邻元素的绝对差都严格大于 `1`**。输出这个最长子串的长度。

例如，数组 `[1, 3, 4, 5, 6, 5, 4]` 中，子串 `[1, 3]` 满足条件（`|1-3|=2>1`），且是最长的，因此答案为 `2`。

- 数组长度为 n，`0 ≤ n ≤ 1000`
- 数组范围 `nums[]`，`0 ≤ nums[i] ≤ 10000`

## 输入描述

输入为一个整数数组，数组元素在一行中给出，使用英文逗号分隔。数组中可以包含空格，例如：

```
1, 3, 4, 5
```

当输入为空行时，表示空数组。

## 输出描述

输出满足条件的最长子串的长度。

---

## 示例

### 示例 1

```
输入：1, 3, 4, 5, 6, 5, 4
输出：2
```

**说明**：最长子串是 `[1,3]`，长度是 `2`。`3` 和 `4` 的差为 1，不满足"严格大于 1"，子串在此断开。

### 示例 2

```
输入：1, 3, 5, 7
输出：4
```

**说明**：相邻元素差值分别为 2、2、2，全部合法，最长子串是 `[1, 3, 5, 7]`，长度是 `4`。

---

## 提示

- **子串要求连续**：合法性只取决于相邻两个元素，不需要考虑不相邻的元素对
- 合法条件是 `|nums[i] - nums[i-1]| > 1`，注意是**严格大于**，差值等于 1 即断开
- 断开后不需要回退，以 `nums[i]` 为起点重新统计即可，天然是双指针/滑动窗口思路
- 空数组返回 `0`；非空数组最短合法长度为 `1`（单个元素一定合法）

---

## 思路

### 核心思想：一次遍历 + 连续段计数

维护"当前合法子串"的长度 `cur`：

- 从第二个元素开始遍历，若 `|nums[i] - nums[i-1]| > 1`，当前合法子串可以继续延长，`cur += 1`
- 否则连续子串在此断开，以 `nums[i]` 重新开始，`cur = 1`
- 遍历过程中用 `ans` 记录 `cur` 的最大值

**逐步演示**（示例 1，`[1,3,4,5,6,5,4]`）：

```
i=1: |3-1|=2>1 → cur=2, ans=2   ([1,3] 合法)
i=2: |4-3|=1   → cur=1          (断开，从 4 重新开始)
i=3: |5-4|=1   → cur=1
i=4: |6-5|=1   → cur=1
i=5: |5-6|=1   → cur=1
i=6: |4-5|=1   → cur=1
ans = 2  ✓
```

- 时间复杂度：\(O(n)\)，只遍历一次
- 空间复杂度：\(O(1)\)

---

## 代码

### 解法（Java，一次遍历）

```java
class Solution {
    public int longestNonConsecutiveSubstring(int[] nums) {
        // 空数组直接返回 0
        if (nums == null || nums.length == 0) {
            return 0;
        }
        int cur = 1; // 当前合法子串长度，单个元素一定合法
        int ans = 1; // 最长合法子串长度
        for (int i = 1; i < nums.length; i++) {
            if (Math.abs(nums[i] - nums[i - 1]) > 1) {
                // 相邻差值严格大于 1，子串继续延长
                cur++;
            } else {
                // 差值 <= 1，子串断开，从当前元素重新统计
                cur = 1;
            }
            ans = Math.max(ans, cur);
        }
        return ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，数组只遍历一遍
- **空间复杂度**：\(O(1)\)，仅用两个计数器

> 💡 **记忆**：**「连续子串 + 相邻合法性」= 一次遍历计数**。条件只涉及相邻元素时，维护一个"当前连续段长度"，合法就 +1，不合法就重置为 1。
>
> ⚠️ **易错**：① 条件是**严格大于 1**，差值恰好为 1（如 3 和 4）要断开；② 空数组返回 0，非空数组初始长度是 1 而不是 0；③ 重置时 `cur = 1`（当前元素自身成段），不是 0。
