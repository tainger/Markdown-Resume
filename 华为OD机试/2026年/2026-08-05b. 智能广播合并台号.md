# 2026-08-05b. 智能广播合并台号

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-05

## 题目描述

某社区有多条广播线路，每条线路用一个大写英文字母编号表示（A-Z）。当发送广播时，为减少操作次数，会将连续相邻编号且满足一定个数的线路合并为一个区间，用"起始编号-结束编号"的简写形式表示；不连续或不满足个数的线路则单独列出。合并后的结果要求按字母升序排列，各项之间用一个逗号分隔。

具体合并规则如下：

- 若连续的线路编号个数 **≥ 3 个**，则合并为一个区间，格式为 `起始-结束`（如 `B-F` 表示 B、C、D、E、F 五条线路）
- 若连续线路编号个数 **= 2 个**，不合并，仍各自单独列出（如 A、B 两个编号写成 `A,B`）
- 若连续线路编号个数 **= 1 个**，单独列出（如 `G`）
- 不连续的线路之间各自处理，互不影响

## 输入描述

- 参数 1：整数 `n`，表示需要广播的线路条数（`1 ≤ n ≤ 26`）
- 参数 2：`n` 个大写字母，空格分隔，表示发送广播的线路编号。字母**可能重复**，但合并时每个编号只计一次

## 输出描述

一个字符串，表示合并后的广播线路列表，按字母升序排列，项间用逗号分隔。

---

## 示例

### 示例 1

```
输入：6,"G B A F D C"
输出：A-D,F,G
```

**说明**：字母去重排序后为 A B C D F G。其中 A-D 连续 4 个（≥3），合并为 `A-D`；F 和 G 相邻但仅 2 个，不合并，写成 `F,G`。最终结果 `A-D,F,G`。

### 示例 2

```
输入：3,"A C B"
输出：A-C
```

**说明**：字母排序后为 A B C，三字母连续，个数 = 3（≥3），合并为 `A-C`。

### 示例 3

```
输入：4,"A A B B"
输出：A,B
```

**说明**：去重后仅剩 A B，虽然相邻但只有 2 个字母，不满足 ≥3 的合并条件，因此各自单独列出，结果为 `A,B`。

---

## 提示

- **先去重再排序**：输入字母可能重复，用 `boolean[26]` 桶标记，天然完成去重 + 升序
- 双指针扫描：`i` 指向连续段起点，`j` 向右扩展到段末尾（`letters[j+1] - letters[j] == 1`）
- 段长 `j - i + 1 ≥ 3` 才输出 `X-Y`；段长为 1 或 2 时逐个字母输出
- 各项之间用逗号拼接，建议用 `StringBuilder` 且在每项前判断是否需要补逗号

---

## 思路

### 核心思想：桶去重 + 双指针扫描连续段

1. **去重排序**：字母只有 A-Z 共 26 个，用长度 26 的布尔数组 `seen` 标记出现过的字母，按下标 0~25 遍历即天然按字母升序
2. **扫描连续区间**：指针 `i` 为段起点，指针 `j` 向右扩展，只要 `seen[j+1]` 存在就继续；段长 `len = j - i + 1`
3. **按规则输出**：
   - `len >= 3`：输出 `(char)('A'+i) + "-" + (char)('A'+j)`
   - `len == 1 或 2`：段内字母逐个输出，字母间用逗号分隔

**逐步演示**（示例 1，`G B A F D C`）：

```
seen 标记后：A B C D . F G
i=0(A)：j 扩展到 3(D)，段长 4 ≥ 3 → 输出 "A-D"
i=5(F)：j=6(G)，段长 2 → 输出 "F,G"
结果：A-D,F,G  ✓
```

- 时间复杂度：\(O(n + 26)\)，标记 \(O(n)\)，扫描固定 26 个字母
- 空间复杂度：\(O(26) = O(1)\)

## 代码

### 解法（Java，桶去重 + 双指针）

```java
class Solution {
    public String mergeBroadcastChannels(int n, String channels) {
        // 1. 用布尔数组去重（下标 0~25 对应 A~Z），天然按字母升序
        boolean[] seen = new boolean[26];
        for (int i = 0; i < channels.length(); i++) {
            char c = channels.charAt(i);
            if (c >= 'A' && c <= 'Z') {
                seen[c - 'A'] = true;
            }
        }

        StringBuilder sb = new StringBuilder();
        int i = 0;
        while (i < 26) {
            if (!seen[i]) {
                i++;
                continue;
            }
            // 2. 双指针：i 为段起点，j 向右扩展连续段
            int j = i;
            while (j + 1 < 26 && seen[j + 1]) {
                j++;
            }
            if (sb.length() > 0) {
                sb.append(",");
            }
            int len = j - i + 1;
            if (len >= 3) {
                // 连续 >=3 个：合并为 起始-结束
                sb.append((char) ('A' + i)).append('-').append((char) ('A' + j));
            } else {
                // 连续 1~2 个：逐个单独列出
                for (int t = i; t <= j; t++) {
                    if (t > i) {
                        sb.append(",");
                    }
                    sb.append((char) ('A' + t));
                }
            }
            i = j + 1;
        }
        return sb.toString();
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，标记输入 \(O(n)\)，扫描 26 个字母为常数
- **空间复杂度**：\(O(1)\)，仅用长度 26 的布尔数组

> 💡 **记忆**：**「字符范围有限（A-Z）→ 桶数组」**。用 `boolean[26]` 同时完成去重和排序，再用双指针切连续段，是这类"区间简写"题的通用套路。
>
> ⚠️ **易错**：① 输入字母会重复，必须先去重；② 只有连续 **≥3** 个才合并，恰好 2 个（如 F、G）要写成 `F,G` 而不是 `F-G`；③ 合并区间用的是段首和段尾字母，段中间字母不输出。
