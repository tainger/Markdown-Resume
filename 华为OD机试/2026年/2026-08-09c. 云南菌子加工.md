# 2026-08-09c. 云南菌子加工

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-08-09

## 题目描述

云南的菌子加工厂要加工一批野生菌，所有菌子同时进厂。由于菌子新鲜度随时间流失，价值不断衰减。工厂不能同时加工菌子，即逐个串行加工，正在加工的菌子价值不再衰减，加工完毕立即售卖。

已知每个菌子的初始市场价值和新鲜度衰减速度（每小时损失的价值），菌子的**实际价值 = 初始价值 - 衰减速度 × 从进入工厂到开始加工的等待时间**。在给定时间内，合理安排加工顺序使得加工完成的菌子总价值最大化。

每个菌子的加工时间固定为 **5 小时**，加工所有菌子的总耗时不能超过给定的总加工时间。若菌子的实际价值衰减至零或负值，则不能再售卖，即不需要参与加工。

## 输入描述

输入为四行：

```
count
total
values
decays
```

- `count`：菌子数量，`1 <= count <= 15`
- `total`：可用总加工时间，`5 <= total <= 75`，单位小时
- `values[i]`：第 i 个菌子的初始市场价值
- `decays[i]`：第 i 个菌子的衰减速度（每小时损失价值）

数组 `values` 和 `decays` 使用英文逗号分隔。

## 输出描述

输出一个整数，表示在给定时间内能加工完成的菌子的最大总价值。

---

## 示例

### 示例 1

```
输入：
3
15
10,8,6
0,0,0
输出：24
```

**说明**：衰减速度均为 0，价值不随时间变化。总时间 15 小时恰好可加工 3 个菌子（每个 5 小时），总价值 10+8+6 = **24**。

### 示例 2

```
输入：
3
20
20,10,15
3,1,2
输出：25
```

**说明**：最多可加工 3 个（20/5=4，但只有 3 个菌子）。若加工菌子 0 和菌子 2：

- 第 1 个加工菌子 0：等待 0 小时，价值 20 - 3×0 = 20
- 第 2 个加工菌子 2：等待 5 小时，价值 15 - 2×5 = 5
- 第 3 个若加工菌子 1：等待 10 小时，价值 10 - 1×10 = 0，衰减至零不能售卖

因此最大总价值为 20 + 5 = **25**。

## 提示

- `count <= 15` 是**状态压缩 DP** 的典型信号：用二进制掩码 `mask` 表示已加工的菌子集合，状态总数 2^15 = 32768
- 每个菌子固定加工 5 小时，因此**已加工 cnt 个菌子时，下一个菌子的开始等待时间必为 `cnt × 5`**——等待时间只与加工数量有关，与具体加工了谁无关
- 实际价值必须**严格为正**才能加工：`values[i] - decays[i] * waitTime > 0`，等于 0 也不能售卖
- 总时间约束：加工第 cnt+1 个菌子后总耗时 `(cnt+1) × 5 <= total`，即最多加工 `total / 5` 个
- 贪心视角：对任意选定的菌子集合，**衰减速度快的优先加工**更优（交换论证：相邻两个菌子，衰减快的排前面总价值更高）；状压 DP 会隐式枚举所有顺序，天然求出最优

---

## 思路

### 核心思想：位掩码状态压缩 DP

**状态定义**：`dp[mask]` 表示已加工菌子集合恰好为 `mask` 时，能获得的**最大总价值**；不可达状态为 -1。

**状态转移**：设 `mask` 中已有 `cnt = popcount(mask)` 个菌子：

- 下一个菌子的开始等待时间为 `waitTime = cnt × 5`
- 枚举每个未加工的菌子 i：
  - 时间约束：`(cnt + 1) × 5 <= total`
  - 价值约束：`realValue = values[i] - decays[i] * waitTime > 0`
  - 满足则转移：`dp[mask | (1<<i)] = max(dp[mask | (1<<i)], dp[mask] + realValue)`

**答案**：所有可达状态 `dp[mask]` 的最大值（可以提前停止加工，不一定要用满时间）。

**贪心补充**：为什么 DP 不关心顺序也能对？因为菌子 i 排在第 cnt+1 位时的价值只取决于 cnt（等待时间 = cnt×5），与前面具体加工了哪些菌子无关。`dp[mask]` 保留了加工集合 mask 的所有排列中的最优值。交换论证可证：固定集合时按衰减速度**降序**加工最优——若相邻的 a、b 满足 `decay[a] < decay[b]` 但 a 排在 b 前，交换两者后总价值增加 `5×(decay[b]-decay[a])`。

**逐步演示**（示例 2，values=[20,10,15]，decays=[3,1,2]）：

```
dp[0]=0
cnt=0, wait=0 :  加工0→v=20  加工1→v=10  加工2→v=15
dp[{0}]=20, dp[{1}]=10, dp[{2}]=15
cnt=1, wait=5 :  {0}后加工2→v=15-2×5=5  → dp[{0,2}]=25
                {0}后加工1→v=10-1×5=5  → dp[{0,1}]=25
cnt=2, wait=10:  {0,2}后加工1→v=10-1×10=0 → 价值为0，不能加工
                 {0,1}后加工2→v=15-2×10=-5 → 负值，不能加工
所有状态最大值 = 25 ✓
```

- 时间复杂度：\(O(2^n \cdot n)\)，n = count ≤ 15，约 50 万次转移
- 空间复杂度：\(O(2^n)\)

## 代码

### 解法（Java，位掩码状态压缩 DP）

```java
import java.util.Arrays;

class Solution {
    /**
     * @param count  菌子数量
     * @param total  可用总加工时间（小时）
     * @param values 各菌子初始价值
     * @param decays 各菌子每小时衰减价值
     * @return 给定时间内可加工菌子的最大总价值
     */
    public int processMushrooms(int count, int total, int[] values, int[] decays) {
        int maxProcess = total / 5;          // 最多能加工的菌子数量
        int maskCount = 1 << count;          // 状态总数 2^count

        // dp[mask]：已加工集合为 mask 时的最大总价值，-1 表示不可达
        int[] dp = new int[maskCount];
        Arrays.fill(dp, -1);
        dp[0] = 0;

        int answer = 0;
        for (int mask = 0; mask < maskCount; mask++) {
            if (dp[mask] == -1) {
                continue;
            }
            answer = Math.max(answer, dp[mask]);

            int cnt = Integer.bitCount(mask);   // 已加工数量
            if (cnt >= maxProcess) {
                continue;                       // 时间不足以再加工一个
            }
            int waitTime = cnt * 5;             // 下一个菌子的开始等待时间

            for (int i = 0; i < count; i++) {
                if ((mask & (1 << i)) != 0) {
                    continue;                   // 菌子 i 已加工过
                }
                // 菌子 i 此刻开始加工的实际价值
                int realValue = values[i] - decays[i] * waitTime;
                if (realValue <= 0) {
                    continue;                   // 衰减至 0 或负值，不能售卖
                }
                int nextMask = mask | (1 << i);
                dp[nextMask] = Math.max(dp[nextMask], dp[mask] + realValue);
            }
        }
        return answer;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(2^n \cdot n)\)，n ≤ 15，共 32768 个状态，每个状态最多枚举 n 个菌子
- **空间复杂度**：\(O(2^n)\)，dp 数组约 128KB

> 💡 **记忆**：**「n ≤ 15/20 的排列/子集调度问题 = 位掩码 DP」**。用 mask 表示已选集合，`popcount(mask)` 往往就是推导"当前位置/已用资源"的钥匙；等待时间、已用容量等常只与集合大小有关。
>
> ⚠️ **易错**：① 实际价值必须**严格大于 0** 才加工（题面明确衰减至**零**也不能售卖），判断条件是 `realValue <= 0` 时跳过；② 等待时间是 `cnt × 5`（前面每个菌子各加工 5 小时），不是 `(cnt+1) × 5`；③ 总时间约束是加工完后的总耗时 `(cnt+1) × 5 <= total`；④ dp 数组要用 -1 标记不可达状态，不能默认 0，否则会从非法状态转移；⑤ 答案取**所有状态**的最大值（可以少加工），不是只有加工满的状态。
