# 2026-08-12a. LLM推理批次最大化

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-12 | **标签**：贪心 | **考点**：区间调度（最多不重叠区间）

## 题目描述

大语言模型推理时，显存中有一个 KV Cache，用于存储各请求的键值对。现有 N 个推理请求排队，第 i 个请求需要占用 KV Cache 中一段连续位置 `[Li, Ri]`。每个位置同一时间只能分配给一个请求。

请选出**尽可能多**的请求，使它们的区间互不重叠，从而最大化批次的吞吐量。

**注意**：若两个区间端点相接（例如 `[1,3]` 和 `[3,5]`），由于位置 `3` 被共同占用，仍然认为**重叠**。

## 输入描述

输入为一行 JSON-like 二维数组：

```
[[L1,R1],[L2,R2],...,[LN,RN]]
```

- `requests`：由 N 个推理请求构成的二维数组
- `requests[i]` 表示第 i 个推理请求，内容为 `[Li, Ri]`
- `1 <= N <= 10^5`
- `0 <= Li <= Ri <= 10^9`

## 输出描述

输出一个整数，表示**最多可选多少个不重叠区间**的请求。

---

## 示例

### 示例 1

```
输入：[[1,3],[2,5],[4,7],[6,9],[8,10],[11,12]]
输出：4
```

**说明**：选择 `[1,3]`、`[4,7]`、`[8,10]`、`[11,12]`，共 4 个区间互不重叠，为最大可行数。

### 示例 2

```
输入：[[1,3],[2,4],[3,3],[4,4]]
输出：2
```

**说明**：选择 `[1,3]`、`[4,4]`，共 2 个不重叠的区间。注意 `[3,3]` 与 `[1,3]` 在位置 3 相接，算重叠，不能选。

### 示例 3

```
输入：[[3,5]]
输出：1
```

**说明**：只有 1 个请求，可选择的个数即为 1。

## 提示

- **经典区间调度问题**：求"最多不重叠区间数"，贪心可解
- 贪心策略：**按右端点 Ri 升序排序**，每次选结束最早且与已选区间不重叠的区间
- 本题重叠判定是**闭区间**：端点相接也算重叠，因此下一个区间必须满足 `Li > 上一个选中的 R`（严格大于），不是 `>=`
- 按右端点排序后，结束越早的区间留给后续的空间越大，选择数一定最优
- N 可达 10^5，排序 O(N log N) 是主要开销

---

## 思路

### 核心思想：右端点贪心（区间调度）

这是经典的"活动选择问题"：

1. 将所有区间按**右端点 Ri 从小到大**排序（R 相同时按 L 排序）
2. 依次遍历，维护上一个选中区间的右端点 `lastEnd`（初始为 -∞）
3. 若当前区间满足 `L > lastEnd`（严格大于，端点相接也算重叠），则选中它，更新 `lastEnd = R`，计数加一
4. 否则跳过该区间

**为什么按右端点贪心最优？** 结束最早的区间占用资源的时间最短，给后续区间留下的空间最大。数学上可用交换论证证明：任何最优解都可以把第一个区间替换为结束最早的区间而不使结果变差。

**逐步演示**（示例 1，按 R 排序后顺序不变）：

```
[1,3]  → 3 > -∞，选中，lastEnd=3，count=1
[2,5]  → 2 > 3? 否，跳过
[4,7]  → 4 > 3? 是，选中，lastEnd=7，count=2
[6,9]  → 6 > 7? 否，跳过
[8,10] → 8 > 7? 是，选中，lastEnd=10，count=3
[11,12]→ 11 > 10? 是，选中，count=4  ✓
```

- 时间复杂度：\(O(N \log N)\)，排序主导
- 空间复杂度：\(O(1)\)（不计排序开销）

## 代码

### 解法（Java，右端点贪心）

```java
import java.util.Arrays;

class Solution {
    /**
     * @param requests 推理请求区间数组，每个元素为 [L, R]
     * @return 最多可选择的互不重叠区间数量
     */
    public int maxBatchCount(int[][] requests) {
        // 按右端点升序排序；右端点相同时按左端点升序
        Arrays.sort(requests, (a, b) -> a[1] != b[1] ? a[1] - b[1] : a[0] - b[0]);

        int count = 0;
        // 上一个选中区间的右端点，初始取比最小 L 还小的值
        long lastEnd = Long.MIN_VALUE;

        for (int[] req : requests) {
            int l = req[0];
            int r = req[1];
            // 闭区间：端点相接也算重叠，必须 L 严格大于上一个 R
            if (l > lastEnd) {
                count++;
                lastEnd = r;
            }
        }
        return count;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(N \log N)\)，排序一次 + 线性扫描
- **空间复杂度**：\(O(1)\)，仅用常数额外空间（排序栈空间忽略）

> 💡 **记忆**：**「区间最多选几个不重叠 = 按右端点排序贪心」**。三类区间问题要分清：①最多不重叠区间数 → 按 R 排序贪心；②最少点覆盖所有区间 → 按 R 排序取右端点；③合并重叠区间 → 按 L 排序。
>
> ⚠️ **易错**：① 本题是闭区间，`[1,3]` 与 `[3,5]` 共享位置 3，判定重叠，条件是 `L > lastEnd` 而非 `L >= lastEnd`；② 排序键是**右端点 R**，按左端点排序是错误的；③ 坐标可达 10^9，用 int 存 R 没问题，但 `lastEnd` 初值要足够小。
