# 2026-08-12b. 获取二叉树第k层的数值

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-12 | **标签**：二叉树、BFS | **考点**：层序遍历（按层 BFS）+ 去重排序

## 题目描述

给定一棵有根二叉树，请找出第 k 层上的所有节点值，**去重后按升序输出**。

**约定：**

- 根节点编号为 **0**
- 输入的边信息表示父子关系 `[father, child]`
- 根节点所在层为第 **0** 层

## 输入描述

输入为四行：

```
n
vals
edges
k
```

- `n`：节点数，节点编号为 `0 ~ n-1`
- `vals`：长度为 `n` 的数组，`vals[i]` 表示编号为 `i` 的节点值
- `edges`：二维数组，每个元素为 `[father, child]`，表示有向边
- `k`：目标层数

`vals` 使用英文逗号分隔；`edges` 使用 JSON-like 二维数组格式。

## 输出描述

输出第 k 层所有节点值**去重后**的升序数组，格式为：

```
[v1,v2,v3]
```

若第 k 层不存在节点，则输出：

```
[]
```

## 示例

### 示例 1

```
输入：
5
5,3,8,3,7
[[0,1],[0,2],[1,3],[1,4]]
2
输出：[3,7]
```

**说明**：树结构为 `0(5)` 的孩子是 `1(3)`、`2(8)`；`1(3)` 的孩子是 `3(3)`、`4(7)`。第 2 层节点为编号 3（值 3）和编号 4（值 7），去重升序后为 `[3,7]`。

### 示例 2

```
输入：
7
10,5,8,1,6,7,9
[[0,1],[0,2],[1,3],[1,4],[2,5],[2,6]]
1
输出：[5,8]
```

**说明**：第 1 层节点为编号 1（值 5）和编号 2（值 8），去重升序后为 `[5,8]`。

### 示例 3

```
输入：
1
42
[]
0
输出：[42]
```

**说明**：只有根节点，位于第 0 层，值为 `42`。

## 提示

- **按层 BFS** 是获取"第 k 层节点"最直接的方法：每处理完一层，层数加一
- 边是 `[father, child]` 有向边，根节点固定为编号 `0`，据此建**孩子邻接表**即可
- 第 k 层可能有重复值（如示例 1 中值 3 出现两次），需要**去重 + 升序**，用 `TreeSet` 一步到位
- k 超过树的最大深度时该层为空，返回空数组 `[]`
- 根节点在第 **0** 层，不要误当成第 1 层

---

## 思路

### 核心思想：建图 + 按层 BFS

1. **建树**：遍历 `edges`，为每个 father 维护孩子列表 `children[father]`
2. **层序遍历**：从根节点 0 开始 BFS，每轮用队列当前长度 `size` 圈定"这一层"的所有节点
3. **命中第 k 层**：当层数等于 k 时，把该层所有节点值放入 `TreeSet`（自动去重 + 升序），转成数组返回
4. **未命中**：把当前层节点的孩子全部入队，层数加一；若队列提前为空，说明第 k 层不存在，返回空数组

**逐步演示**（示例 1，k=2）：

```
第0层: [0]                      → level=0 ≠ 2，孩子 1,2 入队
第1层: [1,2]                    → level=1 ≠ 2，孩子 3,4 入队（2 无孩子）
第2层: [3,4] → vals=3,7         → level=2 = k，TreeSet={3,7} → [3,7] ✓
```

- 时间复杂度：\(O(n \log n)\)，BFS 为 O(n)，TreeSet 插入为 O(n log n)
- 空间复杂度：\(O(n)\)，邻接表 + 队列

## 代码

### 解法（Java，按层 BFS + TreeSet）

```java
import java.util.*;

class Solution {
    /**
     * @param n     节点数（编号 0~n-1）
     * @param vals  节点值数组，vals[i] 为编号 i 的节点值
     * @param edges 有向边 [father, child]
     * @param k     目标层数（根为第 0 层）
     * @return 第 k 层节点值去重升序后的数组；该层无节点返回空数组
     */
    public int[] getKthLevelValues(int n, int[] vals, int[][] edges, int k) {
        // 1. 建立孩子邻接表
        List<Integer>[] children = new List[n];
        for (int i = 0; i < n; i++) {
            children[i] = new ArrayList<>();
        }
        for (int[] edge : edges) {
            children[edge[0]].add(edge[1]);
        }

        // 2. 从根节点 0 开始按层 BFS
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(0);
        int level = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();

            if (level == k) {
                // 3. 命中目标层：收集节点值，TreeSet 自动去重 + 升序
                TreeSet<Integer> set = new TreeSet<>();
                for (int i = 0; i < size; i++) {
                    set.add(vals[queue.poll()]);
                }
                int[] result = new int[set.size()];
                int idx = 0;
                for (int v : set) {
                    result[idx++] = v;
                }
                return result;
            }

            // 4. 未命中：当前层节点出队，孩子入队
            for (int i = 0; i < size; i++) {
                int node = queue.poll();
                queue.addAll(children[node]);
            }
            level++;
        }

        // 第 k 层不存在（k 超过树的最大深度）
        return new int[0];
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n \log n)\)，每个节点入队一次 O(n)，TreeSet 插入合计 O(n log n)
- **空间复杂度**：\(O(n)\)，邻接表与队列最多存放 n 个节点

> 💡 **记忆**：**「树的第几层 = 按层 BFS」**。BFS 时用 `size = queue.size()` 圈定一层是固定套路；需要"去重 + 排序"时直接上 `TreeSet`，比 `HashSet + Collections.sort` 简洁。
>
> ⚠️ **易错**：① 根节点是第 **0** 层，层数计数从 0 开始；② 边是 father→child 有向边，根固定为编号 0，不要搞反邻接表方向；③ k 超过树深时要返回空数组 `[]`，不能报错；④ 输出要求**去重**，同值节点（如两个 3）只保留一个。
