# 2026-08-12c. 末世分配资源包

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-08-12 | **标签**：二分、贪心 | **考点**：二分答案 + 贪心分段（分割数组最大段和最小化）

## 题目描述

末世时代，政府为各地分配资源。现有资源分配表 `nums[n]`，要求按如下规则分配给 k 个营地：

1. 每个营地只分配一段**连续**的资源表；
2. 每个营地至少分到**一份**资源；
3. 所有的资源必须**全部分配完毕**；
4. 分配方式需**尽量平均**：即**得利最大的营地所获得的资源值尽量小**。

请返回在最优分配方案下，**得利最大营地**所获得的资源总数。

## 输入描述

输入为两行：

```
nums
k
```

- `nums`：资源存储数组，资源数 n 满足 `0 ≤ n ≤ 1000`，每份资源数 `1 ≤ nums[i] ≤ 100000`
- `k`：营地数量，`1 ≤ k ≤ min(50, n)`

`nums` 为英文逗号分隔的整数数组。

## 输出描述

输出一个整数，表示在最优平均分配情况下，**得利最大营地所获得的资源数**。

---

## 示例

### 示例 1

```
输入：
4,3,6,9,7
2
输出：16
```

**说明**：所有可能的切分方式及对应最大子段和如下：

| 切分方式 | 两段和 | 最大段和 |
|---|---|---|
| `[4]` , `[3,6,9,7]` | 4 , 25 | 25 |
| `[4,3]` , `[6,9,7]` | 7 , 22 | 22 |
| `[4,3,6]` , `[9,7]` | 13 , 16 | **16** |
| `[4,3,6,9]` , `[7]` | 22 , 7 | 22 |

因此，最大值最小的切分方式是第 3 种，返回 **16**。

### 示例 2

```
输入：
3,4,2,1
4
输出：4
```

**说明**：唯一合法切分方式为 `[3] , [4] , [2] , [1]`，最大子段和为 **4**（即数组中的最大元素）。

## 提示

- 经典的"**分割数组的最大值**"问题：把数组切成 k 个连续段，最小化最大段和
- **二分答案**：答案一定落在 `[max(nums), sum(nums)]` 之间——下界是单个最大元素（每份资源不能拆开），上界是全部资源给一个营地
- **贪心判定**：给定段和上限 `limit`，从左到右累加，当前段放不下下一个元素就新开一段；若所需段数 `≤ k` 则可行
- 可行性随 limit 单调：limit 越大，需要的段数越少，因此可以二分
- 段数 `< k` 也没关系：把某些段继续拆小不会增大最大段和（元素均为正数），所以 `≤ k` 即可行

---

## 思路

### 核心思想：二分答案 + 贪心分段

**第一步：确定二分范围**

- 下界 `left = max(nums)`：任何营地至少装一份资源，最大段和不可能小于最大元素
- 上界 `right = sum(nums)`：所有资源给一个营地

**第二步：贪心判定 `check(limit)`**

从左到右遍历数组，维护当前段和 `sum`：

- 若 `sum + nums[i] > limit`，则当前段结束，新开一段（段数 +1），`sum = nums[i]`
- 否则 `sum += nums[i]`

最终所需段数 `segments ≤ k` 时判定为**可行**。

**第三步：二分找最小可行值**

- `mid` 可行 → 尝试更小，`right = mid`
- `mid` 不可行 → 需要放大，`left = mid + 1`

**逐步演示**（示例 1，`[4,3,6,9,7]`，k=2）：

```
二分范围 [9, 29]
mid=19: 分段 [4,3,6,9]=22>19 → [4,3,6]=13,[9,7]=16 → 2 段 ≤ 2，可行，right=19
mid=14: [4,3,6]=13，+9 超 → [9]，+7 超 → [7]，共 3 段 > 2，不可行，left=15
mid=16: [4,3,6]=13，+9 超 → [9,7]=16，共 2 段 ≤ 2，可行，right=16
mid=15: [4,3,6]=13，[9]，+7 超 → [7]，共 3 段 > 2，不可行，left=16
left=right=16 → 答案 16 ✓
```

- 时间复杂度：\(O(n \log S)\)，S 为数组总和（每次判定 O(n)，二分 O(log S) 次）
- 空间复杂度：\(O(1)\)

## 代码

### 解法（Java，二分答案 + 贪心分段）

```java
class Solution {
    /**
     * @param nums 资源数组
     * @param k    营地数量
     * @return 最优分配下得利最大营地的资源数（最小化的最大段和）
     */
    public int allocateResources(int[] nums, int k) {
        int left = 0;   // 下界：最大单个元素
        int right = 0;  // 上界：数组总和
        for (int num : nums) {
            left = Math.max(left, num);
            right += num;
        }

        // 二分最小可行的段和上限
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (canSplit(nums, k, mid)) {
                right = mid;      // 可行，尝试更小的上限
            } else {
                left = mid + 1;   // 不可行，放大上限
            }
        }
        return left;
    }

    /**
     * 贪心判定：每段和不超过 limit 时，所需段数是否 ≤ k
     */
    private boolean canSplit(int[] nums, int k, int limit) {
        int segments = 1;
        int sum = 0;
        for (int num : nums) {
            if (sum + num > limit) {
                // 当前段放不下，新开一段
                segments++;
                sum = num;
                if (segments > k) {
                    return false;
                }
            } else {
                sum += num;
            }
        }
        return segments <= k;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n \log S)\)，S = sum(nums)，二分约 log(10^8) ≈ 27 次，每次线性扫描
- **空间复杂度**：\(O(1)\)，仅用常数变量

> 💡 **记忆**：**「最大值最小化 / 最小值最大化 → 先想二分答案」**。判定函数用贪心：能往当前段塞就塞，塞不下才新开。同类题还有"船的运载能力""拆分图书""木工切木料"。
>
> ⚠️ **易错**：① 二分下界是 `max(nums)` 不是 0——单份资源不可再分，limit 小于最大元素时永远不可行；② 判定条件是段数 `≤ k` 而非 `== k`（段数不足时可以继续拆细，段和不会变大）；③ 新开段时 `sum` 要重置为当前元素 `num`，不是 0；④ 元素均为正数是贪心成立的前提。
