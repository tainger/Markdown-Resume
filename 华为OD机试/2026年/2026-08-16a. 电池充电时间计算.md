# 2026-08-16a. 电池充电时间计算

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-16

## 题目描述

电池充电过程并非恒定电流，而是遵循一定的充电曲线。给定电池容量、当前电量百分比、目标电量百分比和充电器最大输出电流，请计算充电至目标电量所需的时间。

充电曲线规则如下：

1. 当电量 < 20% 时，采用**预充模式**，电流为最大电流的 20%；
2. 当电量 >= 20% 且 < 80% 时，采用**恒流模式**，电流为最大电流的 100%；
3. 当电量 >= 80% 时，采用**恒压模式**，电流随电量增加而线性衰减：

   `current(soc) = maxCurrent * (1 - (soc - 80) * 0.045)`

   - 其中 soc 为电量百分比，该公式保证 `current(80) = maxCurrent`，`current(100) = maxCurrent * 0.1`；
   - 每充入 `batteryCapacity * 1%` 的电量，根据当前电量所在阶段确定该步进的充电电流，然后累加该步进所需的时间。由于恒压阶段电流线性变化，可使用**平均电流法**计算充电时间：平均电流 =（起始电流 + 结束电流）/ 2。

## 输入描述

- `batteryCapacity`：电池容量（mAh），整型，范围 1000~10000
- `maxCurrent`：充电器最大输出电流（mA），整型，范围 500~10000
- `initialSOC`：当前电量百分比（0~100 的整数），整型
- `targetSOC`：目标电量百分比（initialSOC~100 的整数），整型

输入为一行，四个整数使用英文逗号分隔：

```
batteryCapacity,maxCurrent,initialSOC,targetSOC
```

## 输出描述

充电至目标电量所需的时间，浮点数，保留一位小数（四舍五入）。

---

## 示例

### 示例 1

```
输入：
3000,1500,0,100

输出：
3.9
```

**说明**：从 `0%` 充电到 `100%`：

- **预充阶段**（`0%~20%`）：电流 = 1500×20% = 300 mA
  - 充入电量 = 3000×20% = 600 mAh，时间 = 600/300 = 2.0 小时
- **恒流阶段**（`20%~80%`）：电流 = 1500 mA
  - 充入电量 = 3000×60% = 1800 mAh，时间 = 1800/1500 = 1.2 小时
- **恒压阶段**（`80%~100%`）：电流从 1500 mA 线性降至 150 mA
  - 充入电量 = 3000×20% = 600 mAh
  - 平均电流 = (1500+150)/2 = 825 mA，时间 = 600/825 ≈ 0.73 小时

总时间：2.0 + 1.2 + 0.73 = 3.93，四舍五入保留一位小数：`3.9`。

### 示例 2

```
输入：
3000,1500,70,85

输出：
0.3
```

**说明**：从 `70%` 充电到 `85%`：

- **恒流阶段**（`70%~80%`）：电流 = 1500 mA
  - 充入电量 = 3000×10% = 300 mAh，时间 = 300/1500 = 0.2 小时
- **恒压阶段**（`80%~85%`）：电流从 1500 mA 线性降至 1162.5 mA
  - 充入电量 = 3000×5% = 150 mAh
  - 平均电流 = (1500+1162.5)/2 = 1331.25 mA，时间 = 150/1331.25 ≈ 0.11 小时

总时间：0.2 + 0.11 = 0.31，四舍五入保留一位小数：`0.3`。

## 提示

- 三个阶段的区间分别是 **预充 `[0,20)`、恒流 `[20,80)`、恒压 `[80,100]`**，充电区间 `[initialSOC, targetSOC]` 与各阶段求交集后分段计算
- 某段充入电量（mAh）= `batteryCapacity × 该段百分比跨度 / 100`
- 预充、恒流阶段电流恒定，时间 = 电量 / 电流；**恒压阶段必须用平均电流**（段首段尾电流的平均值），不能直接按 1% 步进取调和（会与样例不符）
- 恒压段段尾电流：`current(soc) = maxCurrent × (1 - (soc-80) × 0.045)`，soc=100 时恰好剩 10%
- 最终用 `String.format("%.1f", x)` 输出，自动完成四舍五入

---

## 思路

### 核心思想：按阶段分段累计时间

把充电区间 `[initialSOC, targetSOC]` 与三个阶段区间分别求交集 `[lo, hi)`，对每个非空区间：

1. **预充段**（与 `[0,20)` 交集）：电流恒为 `0.2 × maxCurrent`；
2. **恒流段**（与 `[20,80)` 交集）：电流恒为 `maxCurrent`；
3. **恒压段**（与 `[80,100]` 交集）：
   - 段首电流 `cStart = maxCurrent × (1 - (lo-80) × 0.045)`
   - 段尾电流 `cEnd   = maxCurrent × (1 - (hi-80) × 0.045)`
   - 平均电流 = `(cStart + cEnd) / 2`

每段时间 = 该段电量（mAh）/ 该段电流（mA），单位为小时，累加后保留一位小数。

**逐步演示**（示例 1，`3000,1500,0,100`）：

```
预充 [0,20)：电量 600 mAh，电流 300 mA        → 2.00 h
恒流 [20,80)：电量 1800 mAh，电流 1500 mA     → 1.20 h
恒压 [80,100]：电量 600 mAh，平均电流 825 mA  → 0.73 h
合计 3.93 h → 输出 3.9  ✓
```

- 时间复杂度：\(O(1)\)，固定三段计算
- 空间复杂度：\(O(1)\)

## 代码

### 解法（Java，分阶段模拟）

```java
class Solution {
    /**
     * 计算按充电曲线充至目标电量所需时间
     * @param batteryCapacity 电池容量(mAh)
     * @param maxCurrent      最大输出电流(mA)
     * @param initialSOC      当前电量百分比
     * @param targetSOC       目标电量百分比
     * @return 所需时间（小时），保留一位小数字符串
     */
    public String chargeTime(int batteryCapacity, int maxCurrent,
                             int initialSOC, int targetSOC) {
        double hours = 0.0;

        // 1. 预充阶段 [0%, 20%)：电流 = 最大电流的 20%
        double lo = Math.max(initialSOC, 0);
        double hi = Math.min(targetSOC, 20);
        if (lo < hi) {
            double energy = batteryCapacity * (hi - lo) / 100.0;
            hours += energy / (maxCurrent * 0.2);
        }

        // 2. 恒流阶段 [20%, 80%)：电流 = 最大电流的 100%
        lo = Math.max(initialSOC, 20);
        hi = Math.min(targetSOC, 80);
        if (lo < hi) {
            double energy = batteryCapacity * (hi - lo) / 100.0;
            hours += energy / maxCurrent;
        }

        // 3. 恒压阶段 [80%, 100%]：电流线性衰减，使用平均电流法
        lo = Math.max(initialSOC, 80);
        hi = Math.min(targetSOC, 100);
        if (lo < hi) {
            double energy = batteryCapacity * (hi - lo) / 100.0;
            double currentStart = maxCurrent * (1 - (lo - 80) * 0.045);
            double currentEnd   = maxCurrent * (1 - (hi - 80) * 0.045);
            double avgCurrent = (currentStart + currentEnd) / 2.0;
            hours += energy / avgCurrent;
        }

        // 四舍五入保留一位小数
        return String.format("%.1f", hours);
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(1)\)，仅对三个固定阶段做常数次运算
- **空间复杂度**：\(O(1)\)

> 💡 **记忆**：**「分段曲线题 = 区间求交 + 分段套公式」**。恒流段电量除以恒定电流；线性变化段用"平均电流 =（首电流+尾电流）/2"，本质是线性函数在区间上的积分中值。
>
> ⚠️ **易错**：① 恒压阶段**不要**按每个 1% 步进取电流再取调和平均（`1/x` 非线性，结果偏大，会得到 4.2 而非 3.9），题目明确要求用段首尾平均电流；② 区间端点：预充/恒流是左闭右开 `[0,20)`、`[20,80)`，恒压段从 80% 开始；③ 只充到 80% 时恒压段不参与计算，注意 `lo < hi` 判断；④ 输出用 `String.format("%.1f", ...)` 保证四舍五入一位小数。
