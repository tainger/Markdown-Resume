# 2026-08-16b. 信道资源分配与掩码运算

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-16

## 题目描述

在进行信道资源分配时，需要通过掩码（Bitmask）来高效管理可用信道的状态。每个信道对应掩码中的一个二进制位（位置为 1 表示信道可用，位置为 0 表示信道被占用）。掩码状态编码以不同进制格式（二进制、十进制、十六进制）存储在配置文件中，由 64 位无符号整数表示（二进制从低位到高位对应信道 0 到信道 63），掩码的输入格式为带进制标识的字符串：

- 二进制字符串：以 `0b` 开头（如 `0b1011`）；
- 十六进制字符串：以 `0x` 开头（如 `0x1A3`）；
- 十进制字符串：无特殊前缀（如 `255`）。

为了优化资源利用率，需计算两组可用信道的集合：交集、并集，以及统计连续可用信道的最大长度（连续 1 的最长子串）；请实现一个函数完成以下操作：

1. 将两个输入的掩码字符串（`maskStrA`、`maskStrB`）转为 64 位无符号整数；
2. 计算两个掩码的可用信道**交集**（仅保留两个掩码中都为 1 的位）；
3. 计算两个掩码的可用信道**并集**（保留任意一个掩码中为 1 的位）；
4. 统计两个掩码的**连续可用信道最大长度**（并集的二进制中连续 1 的最长长度）。

函数需返回一个长度为 3 的数组（十进制整数），依次包含：交集结果、并集结果、最大连续可用信道长度。

## 输入描述

- 输入字符串仅包含合法的进制格式（无需处理非法输入）；
- 掩码值范围为 `0 <= mask <= 2^64 - 1`，超出范围的输入不存在；
- 二进制字符串长度不超过 64 位，十六进制字符串长度不超过 16 位；
- 连续可用信道长度计算规则：全 0 掩码返回 0，全 1 掩码返回 64。

## 输出描述

返回一个长度为 3 的数组（十进制整数），依次包含：交集结果、并集结果、最大连续可用信道长度。

---

## 示例

### 示例 1

```
输入：
"0b1011","0b1101"

输出：
[9,15,4]
```

**说明**：

- 进制转换：`0b1011` = 11（十进制），`0b1101` = 13（十进制）；
- 交集：11 & 13 = 9（二进制 `1001`）；
- 并集：11 | 13 = 15（二进制 `1111`）；
- 并集的二进制为 `0b1111`，连续 1 的最长长度为 4。

### 示例 2

```
输入：
"0","0xCC"

输出：
[0,204,2]
```

**说明**：

- 进制转换：`0`（十进制）= 0，`0xCC` = 204（十进制，二进制 `11001100`）；
- 交集：0 & 204 = 0；
- 并集：0 | 204 = 204；
- 并集二进制 `0b11001100`，连续 1 的最长长度为 2。

---

## 提示

- **前缀判进制**：`0b/0B` → 二进制，`0x/0X` → 十六进制，否则十进制；用 `Long.parseUnsignedLong(s, radix)` 解析
- 值可达 `2^64-1`，超过有符号 `long` 上限，**按无符号语义处理**：位运算（`&`、`|`、`>>>`）对补码二进制位照常工作，输出十进制时用 `Long.toUnsignedString`
- 交集 = 按位与 `&`，并集 = 按位或 `|`
- 最长连续 1 只统计**并集**：从信道 0（最低位）到信道 63（最高位）逐位扫描，遇 1 计数加一、遇 0 清零，过程中取最大值
- 信道 63 与信道 0 **不相邻**，掩码不是环，不能跨首尾连起来

---

## 思路

### 核心思想：前缀解析 + 按位与/或 + 线性扫位

1. **解析掩码**：根据前缀把字符串转成 64 位无符号整数（Java 中用 `long` 承载二进制位）：
   - `0b` 开头 → 去掉前缀按 2 进制解析；
   - `0x` 开头 → 去掉前缀按 16 进制解析；
   - 其余 → 按 10 进制解析。
2. **集合运算**：交集 `a & b`，并集 `a | b`，直接对两个 `long` 做位运算。
3. **最长连续 1**：扫描并集的第 0~63 位（`(union >>> i) & 1`），维护当前连续长度 `cur` 与最大长度 `best`：
   - 该位为 1：`cur++`，更新 `best`；
   - 该位为 0：`cur = 0`。

**逐步演示**（示例 1，`0b1011` 与 `0b1101`）：

```
a = 1011 (11)，b = 1101 (13)
交集 a & b = 1001 = 9
并集 a | b = 1111 = 15
扫描并集 1111：位0=1(cur=1) 位1=1(cur=2) 位2=1(cur=3) 位3=1(cur=4) → 最长 4
结果 [9, 15, 4]  ✓
```

- 时间复杂度：\(O(64) = O(1)\)，固定扫描 64 位
- 空间复杂度：\(O(1)\)

## 代码

### 解法（Java，位运算）

```java
class Solution {
    /**
     * 解析两个掩码字符串，返回 [交集, 并集, 并集最长连续1长度]
     * @param maskStrA 掩码字符串（0b 二进制 / 0x 十六进制 / 纯数字十进制）
     * @param maskStrB 掩码字符串
     * @return long[3]：交集、并集按 64 位无符号语义承载，最长连续 1 长度（0~64）
     */
    public long[] channelMaskAllocation(String maskStrA, String maskStrB) {
        long a = parseMask(maskStrA);
        long b = parseMask(maskStrB);

        long intersection = a & b;   // 交集：两位都为 1
        long union = a | b;          // 并集：任一位为 1
        int maxRun = longestConsecutiveOnes(union);

        return new long[]{intersection, union, maxRun};
    }

    /** 按前缀把掩码字符串解析为 64 位无符号整数（用 long 承载二进制位） */
    private long parseMask(String s) {
        s = s.trim();
        if (s.startsWith("0b") || s.startsWith("0B")) {
            return Long.parseUnsignedLong(s.substring(2), 2);
        }
        if (s.startsWith("0x") || s.startsWith("0X")) {
            return Long.parseUnsignedLong(s.substring(2), 16);
        }
        return Long.parseUnsignedLong(s, 10);
    }

    /** 统计 64 位中连续 1 的最长长度（信道 0~63 线性扫描，非环） */
    private int longestConsecutiveOnes(long mask) {
        int best = 0;
        int cur = 0;
        for (int i = 0; i < 64; i++) {
            if (((mask >>> i) & 1L) == 1L) {
                cur++;
                best = Math.max(best, cur);
            } else {
                cur = 0;
            }
        }
        return best;
    }

    /** 如需输出十进制字符串，使用 Long.toUnsignedString(x) 避免负数 */
}
```

### 复杂度分析

- **时间复杂度**：\(O(1)\)，进制解析与位扫描均为常数规模（最多 64 位）
- **空间复杂度**：\(O(1)\)

> 💡 **记忆**：**「掩码题三件套 = parseUnsigned 解析 → `&`/`|` 集合运算 → 逐位扫描统计」**。交集对应按位与，并集对应按位或，连续 1 靠 `>>> i` 逐位右移计数。
>
> ⚠️ **易错**：① 值可达 `2^64-1`，Java `long` 是有符号的，解析必须用 `Long.parseUnsignedLong`，输出十进制要用 `Long.toUnsignedString`（否则最高位为 1 时打印成负数）；② 右移用**无符号右移 `>>>`**，保证最高位补 0；③ 最长连续 1 只看**并集**且是线性的 64 位，信道 63 和信道 0 不相邻；④ 全 0 返回 0、全 1 返回 64，扫描逻辑天然满足。
