# 2026-08-16c. 智能家居模式调度优化

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-08-16 | **标签**：递归回溯、区间重叠 | **考点**：DFS 枚举保留/删除 + 坐标压缩时间片增量校验 + 剪枝

## 题目描述

在一个智能家居系统中，用户可以设置多个"自动化联动"模式。每个模式 `models[i] = [start_time, end_time, power]` 描述如下：

- 模式在左闭右开区间 `[start_time, end_time)`（单位：秒）内处于运行状态；
- 为了简化处理，`start_time`、`end_time` 已转化为相对于系统启动初始时间点的秒数；
- 运行期间，每秒消耗固定功率 `power`。

已知家里电网的最高承受功率 `max_power`。若同一时刻有多个模式同时运行，则总功率为各模式功率之和。如果总功率大于 `max_power`，则会导致跳闸。

系统允许永久删除（关闭）任意若干个模式，使剩余模式在任意时刻同时运行时永不跳闸。

请你计算：最少需要删除多少个模式？

## 输入描述

- `max_power`：整数，代表用户电网能承受的最大总电功率，取值 `1 <= max_power <= 10^6`
- `modes`：二维数组，每个子数组 `modes[i] = [start_time, end_time, power]`，表示第 i 个智能模式的启动时间、结束时间以及运行功率：
  - `start_time, end_time`：`0 <= start_time < end_time <= 10^5`
  - `power`：`1 <= power <= 10^4`
  - 模式数量 `1 <= n <= 22`

## 输出描述

最少需要删除的模式个数。

---

## 示例

### 示例 1

```
输入：
10,[[0,500,5],[400,600,7],[550,700,4]]

输出：
1
```

**说明**：

- 最高承受功率为 `10`
- 模式 0 在 `[0,500)` 运行，功率 5；模式 1 在 `[400,600)` 运行，功率 7；模式 2 在 `[550,700)` 运行，功率 4
- 在 `[400,500)` 区间内，模式 0 和 1 同时运行，功率 5+7=12 > 10，发生跳闸
- 删除 1 个模式即可避免（删除模式 1，保留模式 0 和 2）

### 示例 2

```
输入：
10,[[0,300,5],[400,600,7],[700,900,3]]

输出：
0
```

**说明**：3 个模式时间上互不重叠，可同时安全运行，无需删除。

### 示例 3

```
输入：
10,[[0,10,6],[0,10,6]]

输出：
1
```

**说明**：两个模式完全重叠，功率均为 6，同时运行为 12 > 10，必须删除一个。

## 提示

- `n <= 22` 是**枚举信号**：每个模式只有"保留/删除"两种选择，DFS 回溯枚举所有方案
- 单个模式功率 `power > max_power` 时，它单独运行就跳闸，**必须删除**，可先剔除并计数
- 跳闸只可能发生在某个模式的**启动/结束时刻**，把所有起止时间排序去重（坐标压缩），相邻时刻之间的"时间片"内活跃模式集合不变
- DFS 中尝试保留当前模式时，只需在它覆盖的时间片上叠加功率，任一时间片超过 `max_power` 即不可保留；回溯时减去功率即可
- **先尝试保留、再尝试删除**：尽快找到"删除数为 0"的优解，配合 `已删除数 >= 当前最优` 剪枝，实际搜索量极小

## 思路

### 核心思想：DFS 回溯 + 时间片增量校验

1. **预处理**：
   - 功率 `> max_power` 的模式必然跳闸，强制删除并计数 `forced`，不参与枚举；
   - 收集剩余模式所有起止时间，排序去重得到时间点 `t0 < t1 < ... < tk`，相邻两点构成一个时间片，片内总功率恒定；
   - 预处理每个模式覆盖的时间片区间 `[sl, sr)`。
2. **DFS 回溯**：逐个模式决策：
   - **保留分支**（优先）：若该模式覆盖的每个时间片当前功率加上它的功率后都不超限，则叠加功率并递归，回溯时减去；
   - **删除分支**：删除计数 +1 后递归。
3. **剪枝**：`已删除数 >= best` 时该分支不可能更优，直接返回。优先走保留分支能最快得到小的 `best`，剪枝效果极强。

**逐步演示**（示例 1，max=10，模式 `[0,500,5]`、`[400,600,7]`、`[550,700,4]`）：

```
时间点：0, 400, 500, 550, 600, 700 → 5 个时间片
保留模式0：时间片[0,400)、[400,500) 功率=5            ✓
尝试保留模式1：时间片[400,500) 上 5+7=12 > 10        ✗ → 删除模式1（deleted=1）
保留模式2：时间片[550,600)、[600,700) 功率=4          ✓
到达叶子：best = 1
答案 = forced(0) + best(1) = 1  ✓
```

- 时间复杂度：最坏 \(O(2^n \cdot n)\)，剪枝后实际接近 \(O(n^2)\)；\(n \le 22\)
- 空间复杂度：\(O(n)\)，时间片数组与递归栈

## 代码

### 解法（Java，递归回溯 + 坐标压缩）

```java
import java.util.*;

class Solution {
    private int[][] modes;
    private int maxPower;
    private int[] seg;     // 每个时间片上当前已保留模式的总功率
    private int[] segL;    // 每个模式覆盖的时间片左边界（含）
    private int[] segR;    // 每个模式覆盖的时间片右边界（不含）
    private int best;      // 当前最少删除数

    /**
     * 计算使任意时刻总功率不超过 maxPower 所需删除的最少模式数
     * @param maxPower 电网最高承受功率
     * @param modes    模式数组，每个为 [startTime, endTime, power]
     * @return 最少删除个数
     */
    public int minDeleteModes(int maxPower, int[][] modes) {
        this.maxPower = maxPower;

        // 1. 单个模式功率就超限的，必须删除，不参与枚举
        int forced = 0;
        List<int[]> valid = new ArrayList<>();
        for (int[] m : modes) {
            if (m[2] > maxPower) {
                forced++;
            } else {
                valid.add(m);
            }
        }
        int n = valid.size();
        this.modes = valid.toArray(new int[0][]);
        if (n == 0) return forced;

        // 2. 坐标压缩：收集所有起止时间点
        TreeSet<Integer> points = new TreeSet<>();
        for (int[] m : this.modes) {
            points.add(m[0]);
            points.add(m[1]);
        }
        int[] ts = new int[points.size()];
        int idx = 0;
        for (int t : points) ts[idx++] = t;

        this.seg = new int[ts.length - 1];
        this.segL = new int[n];
        this.segR = new int[n];
        for (int i = 0; i < n; i++) {
            segL[i] = Arrays.binarySearch(ts, this.modes[i][0]);
            segR[i] = Arrays.binarySearch(ts, this.modes[i][1]);
        }

        // 3. DFS 回溯：优先保留，尽快得到最优解用于剪枝
        this.best = n;   // 最坏情况：全部删除
        dfs(0, 0);
        return forced + best;
    }

    private void dfs(int i, int deleted) {
        if (deleted >= best) return;          // 剪枝：不可能更优
        if (i == modes.length) {
            best = deleted;                   // 所有模式决策完毕
            return;
        }

        int l = segL[i], r = segR[i], p = modes[i][2];

        // 分支一（优先）：保留模式 i —— 覆盖的时间片叠加功率后均不超限
        boolean canKeep = true;
        for (int k = l; k < r; k++) {
            if (seg[k] + p > maxPower) {
                canKeep = false;
                break;
            }
        }
        if (canKeep) {
            for (int k = l; k < r; k++) seg[k] += p;   // 选
            dfs(i + 1, deleted);
            for (int k = l; k < r; k++) seg[k] -= p;   // 撤销
        }

        // 分支二：删除模式 i
        dfs(i + 1, deleted + 1);
    }
}
```

### 复杂度分析

- **时间复杂度**：最坏 \(O(2^n \cdot n)\)（n ≤ 22），坐标压缩 \(O(n \log n)\)；"优先保留 + 删除数剪枝"在可大量保留时近乎 \(O(n^2)\)
- **空间复杂度**：\(O(n)\)，时间片数组（≤ 2n-1 片）与递归栈

> 💡 **记忆**：**「n ≤ 22 的选择类问题 = DFS 回溯枚举子集」**。可行性判断用"坐标压缩时间片 + 增量叠加/撤销"做到每步 \(O(n)\)；**先选优分支（保留）+ 下界剪枝**是回溯提速的两大法宝。
>
> ⚠️ **易错**：① 区间是**左闭右开** `[start, end)`，时间片边界与模式端点重合时用区间 `[segL, segR)` 叠加才不会多算/少算；② `power > max_power` 的模式单独运行就跳闸，必须先强制删除；③ 回溯时叠加的功率要**原样减回**，保证两个分支互不污染；④ 剪枝条件是 `deleted >= best`（含等号），配合"保留优先"才能在找到 0 删除方案后瞬间剪掉其余分支。
