# 2026-08-19a. 基站低能耗时段统计

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-19

## 题目描述

基站运维团队需要统计某区域基站的低能耗连续运行时段数目，以评估基站的节能优化效果。给定以下信息：

- 整数数组 `power`：`power[i]` 表示该基站第 i 小时的能耗值（单位：千瓦时），`power[i] >= 0`，能耗不会为负；
- 整数 `target`：低能耗阈值（单位：千瓦时），要求连续时段的总能耗不超过该阈值；
- 整数 `max_hour`：最大统计时长（单位：小时），要求连续时段的时长不超过该值，且至少为 1 小时。

请你统计满足以下两个条件的连续运行时段（子数组）的数目：

1. 连续时段的时长属于 `[1, max_hour]`；
2. 该时段内的总能耗 `<= target`。

补充说明：

- `1 <= power.length <= 10^5`
- `0 <= power[i] <= 100`
- `0 <= target <= 10^7`
- `1 <= max_hour < power.length`
- 所有能耗值非负

## 输入描述

输入包含两行：

- 第一行：整数数组 `power` 的表示形式，如 `[0,0,0]`；
- 第二行：两个整数 `target` 和 `max_hour`，以逗号分隔，如 `0,2`。

## 输出描述

输出一个整数，表示满足条件的连续运行时段数目。

---

## 示例

### 示例 1

```
输入：
[0,0,0]
0,2

输出：
5
```

**说明**：

- 长度 1 子数组：下标 0、1、2 处，共 3 个；
- 长度 2 子数组：下标区间 `[0,1]`、`[1,2]`，共 2 个；
- 总计：3+2=5 个。

### 示例 2

```
输入：
[3,1,2,4,1]
5,3

输出：
8
```

**说明**：

- 长度 1 子数组：每个单元素能耗均不超过 5，共 5 个；
- 长度 2 子数组：满足条件的有 3 个：
  - `[0,1]`：3+1=4 ≤ 5；`[1,2]`：1+2=3 ≤ 5；`[3,4]`：4+1=5 ≤ 5
  - 不满足：`[2,3]`：2+4=6 > 5
- 长度 3 子数组：满足条件的有 0 个（`[0,2]`=6、`[1,3]`=7、`[2,4]`=7 均 > 5）；
- 总计：5+3=8 个。

### 示例 3

```
输入：
[5,4,3]
6,2

输出：
3
```

**说明**：

- 长度 1 子数组：能耗分别为 5、4、3，均 ≤ 6，共 3 个；
- 长度 2 子数组：`[0,1]`=9 > 6，`[1,2]`=7 > 6，共 0 个；
- 总计：3 个。

## 提示

- **非负性是滑动窗口的前提**：所有 `power[i] >= 0`，窗口和随右端点右移单调不减，才能用双指针
- 固定左端点 `l` 时，合法右端点一定是从 `l` 开始的一段**连续前缀** `[l, r]`，共 `r-l+1` 个合法子数组
- 两个停止条件：窗口长度 `<= max_hour` **且** 窗口和 `<= target`
- 答案最大约为 `n * max_hour`，可达 \(10^{10}\) 量级，**必须用 `long`**
- 单个元素就超过 `target` 时（`power[l] > target`），以 `l` 为起点的合法子数组数为 0，注意右指针对齐

---

## 思路

### 核心思想：同向双指针（滑动窗口）

维护窗口 `[l, r]` 及其总和 `sum`。对每个左端点 `l`：

1. 不断尝试把 `r+1` 纳入窗口，直到任一条件不满足则停止：
   - 长度超限：`r - l + 2 > max_hour`
   - 和超限：`sum + power[r+1] > target`
   - 或右端点越界
2. 此时 `[l, r]` 是以 `l` 为起点的最长合法窗口，其中 `[l,l], [l,l+1], ..., [l,r]` 全部合法，共 `r-l+1` 个，累加到答案；
3. 左端点右移：`sum -= power[l]`。若 `r < l`（连 `power[l]` 单独都超阈值），把 `r` 对齐到 `l`，保证下一轮窗口为空。

由于能耗非负，`r` 全程只向右移动，总移动次数 \(O(n)\)。

**逐步演示**（示例 2，`[3,1,2,4,1]`，target=5，max_hour=3）：

```
l=0: r 扩展到 1（窗口 [0,1] 和=4；再纳 2 则和=6 超 target）→ +2，sum=1
l=1: r 扩展到 2（窗口 [1,2] 和=3；再纳 4 则和=7）        → +2，sum=2
l=2: r=2（纳 4 则和=6）                                  → +1，sum=0
l=3: r 扩展到 4（窗口 [3,4] 和=5）                        → +2，sum=1
l=4: r=4                                                → +1
合计 = 2+2+1+2+1 = 8  ✓
```

- 时间复杂度：\(O(n)\)，左右指针各移动 n 次
- 空间复杂度：\(O(1)\)

## 代码

### 解法（Java，滑动窗口）

```java
class Solution {
    /**
     * 统计满足 时长 ∈ [1, maxHour] 且总能耗 <= target 的连续子数组数目
     * @param power   每小时能耗（非负）
     * @param target  低能耗阈值
     * @param maxHour 最大统计时长
     * @return 合法连续时段数目
     */
    public long countLowEnergyPeriods(int[] power, int target, int maxHour) {
        int n = power.length;
        long ans = 0;
        long sum = 0;   // 当前窗口 [l, r] 的总能耗
        int r = -1;

        for (int l = 0; l < n; l++) {
            // 尽量扩展右边界：不越界、长度不超 maxHour、和不超 target
            while (r + 1 < n
                    && (r - l + 2) <= maxHour
                    && sum + power[r + 1] <= target) {
                sum += power[++r];
            }

            if (r >= l) {
                // [l,l]...[l,r] 共 r-l+1 个以 l 为起点的合法子数组
                ans += r - l + 1;
                sum -= power[l];   // 左端点右移，移出 power[l]
            } else {
                // power[l] 单独都超过 target，本轮无合法子数组
                // r 对齐到 l，使下一轮 l+1 时窗口为空（r = 新 l - 1）
                r = l;
            }
        }
        return ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，`l`、`r` 各只向右移动，总计 \(O(n)\) 次操作
- **空间复杂度**：\(O(1)\)，仅用指针、窗口和与答案计数器

> 💡 **记忆**：**「子数组计数 + 元素非负 + 单调条件 = 固定左端点扩右端点的滑动窗口」**。每个左端点贡献 `r-l+1` 个答案，比枚举所有子数组的 \(O(n^2)\) 快一个量级。
>
> ⚠️ **易错**：① 答案数目可达 \(n \times \text{max\_hour} \approx 10^{10}\)，**必须用 `long`**；② 窗口长度条件是新长度 `r-l+2 <= maxHour`，别写成 `r-l+1`；③ `power[l] > target` 时 `r < l`，不能执行 `sum -= power[l]`（它不在窗口里），且要把 `r` 对齐到 `l` 防止下轮状态错乱。
