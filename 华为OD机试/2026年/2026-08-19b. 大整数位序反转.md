# 2026-08-19b. 大整数位序反转

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-19 | **标签**：大数运算、进制转换 | **考点**：十进制大整数与二进制字符串的互相转换、位序翻转

## 题目描述

小华是一名嵌入式开发工程师，在处理芯片寄存器数据时，经常需要对超多位数据进行位翻转操作。寄存器中的数据可能是几百位甚至更长。

给定一个十进制大整数（最多 100 位），请将其二进制表示中的所有位顺序全部翻转（最低位变成最高位，次低位变成次高位，以此类推），然后输出翻转后的十进制表示。

## 输入描述

一个十进制大整数（字符串形式，范围：`0 ~ 10^100 - 1`，输入不带前导零，除非为 `0`）。

## 输出描述

翻转后的十进制整数（字符串形式，不能有前导零，除非输出为 `0`）。

---

## 示例

### 示例 1

```
输入：
1

输出：
1
```

**说明**：1 的二进制为 `1`，翻转后仍为 `1`，对应十进制 1。

### 示例 2

```
输入：
2

输出：
1
```

**说明**：2 的二进制为 `10`，翻转为 `01`（即 `1`），对应十进制 1。

### 示例 3

```
输入：
4

输出：
1
```

**说明**：4 的二进制为 `100`，翻转为 `001`（即 `1`），对应十进制 1。

---

## 提示

- **100 位十进制数远超 `long` 范围**（\(10^{100}\) 约 333 个二进制位），必须按**字符串**处理，Java 可直接用 `BigInteger`
- 翻转的是**二进制表示的所有位**：先转二进制字符串，整体反转，再转回十进制
- 反转后开头的 `0` 是前导零（如 `100` → `001`），转十进制时自然消失，无需手动删除
- `0` 的二进制是 `0`，反转后仍是 `0`，注意特判（`BigInteger` 已天然处理）
- 若不借助 `BigInteger`：十进制串**反复除 2 取余**得到的余数序列（低位在前）正好就是反转后的二进制位序，再用"乘 2 加位"累加回十进制串即可

---

## 思路

### 核心思想：十进制串 → 二进制串 → 反转 → 十进制串

用 JDK 自带的 `BigInteger` 完成大数进制转换（底层已实现任意精度）：

1. `new BigInteger(decimalStr).toString(2)`：得到不带前导零的二进制字符串；
2. `new StringBuilder(binStr).reverse().toString()`：所有位顺序翻转；
3. `new BigInteger(reversedBin, 2).toString(10)`：按二进制解析回十进制字符串输出。

**逐步演示**（输入 `4`）：

```
十进制 4  →  二进制 "100"
反转 "100"  →  "001"
"001" 按二进制解析 = 1  →  输出 "1"  ✓
```

再如输入 `10`（二进制 `1010`）→ 反转 `0101` = 5 → 输出 `5`。

**手工实现原理**（不依赖 BigInteger）：

- 十进制串转二进制：反复"除 2 取余"，先得到的余数是二进制**最低位**——余数序列恰好就是**反转后**的二进制位（从高位到低位排列）；
- 二进制转回十进制串：对每一位执行 `值 = 值 × 2 + 位`，用十进制数组模拟进位即可。

- 时间复杂度：\(O(d^2)\)，\(d\) 为十进制位数（约 100 位），大数进制转换为按位处理
- 空间复杂度：\(O(d)\)，存储二进制字符串

## 代码

### 解法（Java，BigInteger 大数进制转换）

```java
import java.math.BigInteger;

class Solution {
    /**
     * 将十进制大整数的二进制位序全部翻转，输出翻转后的十进制字符串
     * @param num 十进制大整数字符串（0 ~ 10^100-1，无前导零）
     * @return 翻转后的十进制整数字符串（无前导零）
     */
    public String reverseBigIntegerBits(String num) {
        // 0 的二进制反转后仍是 0
        if ("0".equals(num.trim())) {
            return "0";
        }

        // 1. 十进制大整数 -> 二进制字符串
        String binary = new BigInteger(num.trim()).toString(2);

        // 2. 二进制位序整体翻转（最低位变最高位）
        String reversed = new StringBuilder(binary).reverse().toString();

        // 3. 翻转后的二进制字符串 -> 十进制字符串（前导零自动忽略）
        return new BigInteger(reversed, 2).toString(10);
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(d^2)\)，大数进制转换按位/按"节"处理，\(d \le 100\) 完全无压力
- **空间复杂度**：\(O(d)\)，二进制串长度约 \(3.32d\)

> 💡 **记忆**：**「大数题先想 BigInteger」**——`new BigInteger(s, 进制)` 解析、`toString(进制)` 输出，任意进制互转一行搞定；位翻转 = 二进制字符串 `reverse()`。
>
> ⚠️ **易错**：① 翻转后产生的**前导零不用手动删**，`new BigInteger("001", 2)` 会自动得到 1；② 输入 `0` 要能正确输出 `0`；③ 不要用 `long`/`int` 接收——100 位十进制数必然溢出；④ 注意题目翻转的是**二进制位**而不是十进制数字（不是 `123 → 321`）。
