# 2026-08-19c. 点亮战争迷雾

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-08-19 | **标签**：二叉树、树形 DP | **考点**：三状态树形动态规划（监控二叉树变体）

## 题目描述

有一张二叉树地图，每一个节点都被战争迷雾所覆盖。在二叉树节点上插上一个侦察守卫，可以照亮该节点自身以及它的父节点和它的子节点的战争迷雾。在每个节点上插上侦察守卫的成本并不一样，用 `cost[i]` 表示节点 `i` 上的成本，每个节点的成本是正整数。

要求：

1. 所有的战争迷雾都被驱散（即每个节点都被照亮）；
2. 所花费的总成本最小。

**补充说明：**

1. 单个节点的成本，`1 <= cost[i] <= 100`；
2. 节点总数量 `<= 1000`。

## 输入描述

一行，一个层序遍历字符串（含首尾圆括号），空节点用 `#` 表示，例如 `(5,1,10,2,8,#,3)`。

## 输出描述

输出最小的总费用。

---

## 示例

### 示例 1

```
输入：
(5,1,10,2,8,#,3)

输出：
4
```

**说明**：二叉树结构（节点按层序编号 1~6，括号内为成本）：

```
          5(节点1, 成本5)
         / \
  1(节点2,成本1)  10(节点3,成本10)
       / \          \
  2(节点4) 8(节点5)   3(节点6,成本3)
```

最优方案：

- 在节点 2（成本 1）和节点 6（成本 3）插上侦察守卫，总成本 `1 + 3 = 4`
- 节点 2 的守卫覆盖节点 `2、1、4、5`；节点 6 的守卫覆盖节点 `6、3`；所有节点均被照亮

### 示例 2

```
输入：
(3,1,1)

输出：
2
```

**说明**：

```
      3(成本3)
     / \
   1     1   （均为成本1的叶子）
```

- 方案一：在节点 1（根，成本 3）插守卫，可照亮所有节点，成本是 `3`
- 方案二：在节点 2 和节点 3（两个叶子，成本各 1）插守卫，可照亮所有节点，成本是 `1+1=2`
- 因此最低成本是方案二，返回 `2`。

## 提示

- 这是 LeetCode 968「监控二叉树」的**带权版本**：每个节点放守卫的代价是节点值，求覆盖全树的最小代价
- 守卫照亮范围 = **自身 + 父节点 + 所有子节点**（距离 ≤ 1 的三代节点）
- 自底向上 DFS，每个节点维护**三种状态**的最小代价即可覆盖所有决策
- 空节点用"不可能放守卫（代价 ∞）+ 视为已覆盖（代价 0）"参与转移，叶子节点的状态自然成立
- **根节点没有父节点**，最终答案不能取"等待父节点照亮"的状态

---

## 思路

### 核心思想：三状态树形 DP

对每个节点 `u`，DFS 返回其子树的三种最小代价：

| 状态 | 含义 |
|---|---|
| `a`（placed） | `u` 上**放了守卫** |
| `b`（covered） | `u` 没放守卫，但**已被某个子节点**的守卫照亮 |
| `c`（wait） | `u` 没放守卫且**未被照亮**，等待父节点的守卫照亮（子树内部已全部合法覆盖） |

设左右子树返回 `(la, lb, lc)`、`(ra, rb, rc)`，转移方程：

- **`a`（本节点放守卫）**：付出 `cost[u]`，左右子树任意状态均可（守卫会照亮两个孩子）：

  `a = cost[u] + min(la,lb,lc) + min(ra,rb,rc)`

- **`b`（被孩子照亮）**：本节点无守卫，两个孩子都必须已被覆盖（状态 `a` 或 `b`，不能是 `c`——孩子等的是本节点，而本节点没守卫），且**至少一个孩子放了守卫**：

  `b = min(la+ra, la+rb, lb+ra)`

- **`c`（等父节点照亮）**：本节点无守卫、暂不要求被照亮，两个孩子仍须已被覆盖（状态 `a` 或 `b`）：

  `c = min(la,lb) + min(ra,rb)`

**空节点**约定：`a = ∞`（无处放守卫），`b = c = 0`（无需覆盖、无代价）。

**根节点**没有父节点，答案 = `min(a_root, b_root)`。

**逐步演示**（示例 2，树 `3 / 1  1`）：

```
叶子(1)：a=1, b=∞, c=0
根(3)：
  a = 3 + min(1,∞,0) + min(1,∞,0) = 3
  b = min(1+1, 1+∞, ∞+1) = 2
  c = min(1,∞) + min(1,∞) = 2
答案 = min(a, b) = min(3, 2) = 2  ✓
```

- 时间复杂度：\(O(n)\)，每个节点仅访问一次
- 空间复杂度：\(O(n)\)，递归栈深度最坏 \(O(n)\)

## 代码

### 解法（Java，三状态树形 DP）

```java
import java.util.*;

class Solution {
    private static final long INF = 1L << 60; // 不可能方案的无穷大代价

    private static class Node {
        int val;          // 该节点插守卫的成本
        Node left, right;
        Node(int val) { this.val = val; }
    }

    /**
     * 计算照亮整棵二叉树的最小守卫总成本
     * @param tree 层序遍历字符串，含首尾圆括号，空节点为 #，如 (5,1,10,2,8,#,3)
     * @return 最小总费用
     */
    public int lightFogCost(String tree) {
        Node root = buildTree(tree);
        long[] res = dfs(root);
        // 根没有父节点，不能处于"等待父节点照亮"的状态
        return (int) Math.min(res[0], res[1]);
    }

    /**
     * 后序遍历，返回 {a放守卫, b被孩子照亮, c等父节点照亮} 三种状态的最小代价
     */
    private long[] dfs(Node node) {
        if (node == null) {
            // 空节点：不能放守卫(∞)，视为已覆盖/等待均无代价(0)
            return new long[]{INF, 0, 0};
        }
        long[] L = dfs(node.left);
        long[] R = dfs(node.right);

        // 状态 a：本节点放守卫，孩子可处于任意状态
        long a = node.val
                + Math.min(Math.min(L[0], L[1]), L[2])
                + Math.min(Math.min(R[0], R[1]), R[2]);

        // 状态 b：本节点无守卫，两个孩子都已覆盖(a/b)，且至少一个孩子放守卫
        long b = Math.min(
                Math.min(L[0] + R[0], L[0] + R[1]),
                L[1] + R[0]
        );

        // 状态 c：本节点无守卫且暂不照亮，两个孩子须已覆盖(a/b)
        long c = Math.min(L[0], L[1]) + Math.min(R[0], R[1]);

        return new long[]{a, b, c};
    }

    /** 由层序遍历字符串（含圆括号、# 表示空节点）构建二叉树 */
    private Node buildTree(String tree) {
        String s = tree.trim();
        // 去掉首尾圆括号
        s = s.substring(1, s.length() - 1);
        String[] tokens = s.split(",");
        if (tokens.length == 0 || "#".equals(tokens[0].trim())) {
            return null;
        }

        Node root = new Node(Integer.parseInt(tokens[0].trim()));
        Queue<Node> queue = new LinkedList<>();
        queue.offer(root);

        int i = 1;
        while (!queue.isEmpty() && i < tokens.length) {
            Node cur = queue.poll();
            // 左孩子
            if (i < tokens.length) {
                String t = tokens[i++].trim();
                if (!"#".equals(t)) {
                    cur.left = new Node(Integer.parseInt(t));
                    queue.offer(cur.left);
                }
            }
            // 右孩子
            if (i < tokens.length) {
                String t = tokens[i++].trim();
                if (!"#".equals(t)) {
                    cur.right = new Node(Integer.parseInt(t));
                    queue.offer(cur.right);
                }
            }
        }
        return root;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，层序建树 \(O(n)\)，DFS 每个节点仅做常数次状态转移
- **空间复杂度**：\(O(n)\)，建树与递归栈最坏均为 \(O(n)\)

> 💡 **记忆**：**「树上覆盖/监控类问题 = 三状态树形 DP」**——放守卫、被孩子覆盖、等父节点覆盖，三个状态互相转移，根节点砍掉"等父亲"状态。这是 LeetCode 968 监控二叉树的带权模板。
>
> ⚠️ **易错**：① 状态 `b`（被孩子照亮）要求**至少一个孩子放守卫**，三种组合取 min，漏掉约束会导致叶子节点"凭空被照亮"；② 状态 `c` 的孩子不能也是 `c`（孩子等本节点照亮，可本节点没守卫）；③ 空节点约定 `a=∞, b=c=0` 是转移自洽的关键；④ 最终答案只取 `min(a, b)`，根不能"等父节点"；⑤ 解析输入时先**去掉首尾圆括号**，`#` 表示空节点不入队。
