# 2026-08-23a. 直线冲刺

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-23

## 题目描述

在一条长度为 n 的直线跑道上，每个格子的坐标从 0 到 n−1，每个格子上写着一个整数，存放在数组 `tiles` 中。这些数字有特殊含义：

- `tiles[i] = 0`：普通空地，可以通过
- `tiles[i] = 1`：弹簧加速垫
- `tiles[i] = -1`：陷阱

角色从坐标 0 出发，目标是成功到达或越过终点坐标 n−1（即坐标 `>= n-1` 即算通关）。

移动规则：
- 默认每一步向右移动 1 格
- 如果踩到弹簧加速垫（1），**下一步**可以向右移动 2 格
- 如果踩到陷阱（-1），游戏结束

## 输入描述

- 参数：整数数组 `tiles`，长度 n，`1 ≤ n ≤ 10000`
- 元素取值为 `0`、`1` 或 `-1`
- 输入为一行，数组元素用英文逗号分隔，如 `0,1,-1,0,0`

## 输出描述

- 通关返回所需步数；否则返回 `-1`

---

## 示例

### 示例 1

```
输入：0,1,-1,0,0
输出：3
```

**说明**：初始坐标 0（空地）。
- 第 1 步：移动 1 格到坐标 1（弹簧垫）
- 第 2 步：踩到弹簧，移动 2 格到坐标 3（越过坐标 2 的陷阱），当前为空地
- 第 3 步：移动 1 格到坐标 4 = n−1，通关

### 示例 2

```
输入：1,0,-1,0
输出：-1
```

**说明**：初始坐标 0（弹簧垫）。
- 第 1 步：移动 2 格到坐标 2（陷阱），游戏结束，返回 -1

---

## 提示

- **纯模拟题**：移动规则确定，无分支选择，从起点按规则一步步走即可
- 关键：**当前格子是弹簧 → 下一步走 2 格**；否则走 1 格
- 走到陷阱（-1）立即返回 -1
- 走到坐标 `>= n-1` 即通关（注意是"到达或越过"）
- 用 while 循环模拟，注意防止越界和死循环

---

## 思路

### 核心思想：指针模拟

从位置 `pos = 0` 开始，每步根据**当前位置**的格子值决定步长：
- `tiles[pos] == 1`：下一步走 2 格
- 否则：走 1 格

走到新位置后检查：
- 新位置 `>= n-1`：通关，返回步数
- 新位置 `< n` 且 `tiles[newPos] == -1`：踩陷阱，返回 -1
- 否则继续

**逐步演示**（示例 1，`[0,1,-1,0,0]`，n=5）：

```
pos=0, tiles[0]=0 → 走1格 → pos=1, steps=1
pos=1, tiles[1]=1 → 走2格 → pos=3, steps=2  (越过pos=2的陷阱)
pos=3, tiles[3]=0 → 走1格 → pos=4, steps=3
pos=4 >= n-1=4 → 通关, 返回 3  ✓
```

- 时间复杂度：\(O(n)\)，每步至少前进 1 格
- 空间复杂度：\(O(1)\)

---

## 代码

### 解法（Java，指针模拟）

```java
class Solution {
    public int straightSprint(int[] tiles) {
        int n = tiles.length;
        int pos = 0;
        int steps = 0;
        while (pos < n - 1) {
            // 当前格子是弹簧 → 下一步走 2 格，否则走 1 格
            int stride = (tiles[pos] == 1) ? 2 : 1;
            pos += stride;
            steps++;
            // 越过终点即通关
            if (pos >= n - 1) return steps;
            // 踩到陷阱
            if (tiles[pos] == -1) return -1;
        }
        return steps;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，每步至少前进 1 格，最多 n 步
- **空间复杂度**：\(O(1)\)，仅用指针和计数器

> 💡 **记忆**：**「规则确定无分支 = 纯模拟」**。这类题不要想复杂，按题面规则一步步走即可。
>
> ⚠️ **易错**：① 弹簧效果是"下一步走 2 格"，不是当前步走 2 格——判断的是**移动前所在格子**；② 通关条件是 `pos >= n-1`（越过也算），不是必须 `== n-1`；③ 走到新位置后先判通关再判陷阱（若 pos 越界则不能访问 tiles[pos]）。
