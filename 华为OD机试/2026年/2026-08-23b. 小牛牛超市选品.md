# 2026-08-23b. 小牛牛超市选品

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-23 | **标签**：枚举、滑动窗口 | **考点**：连续区间约束 + 最短长度

## 题目描述

牛牛在超市采购商品，每件商品有对应价格（均为正整数）。给定预算 `limit`，要求选出**连续一段**商品，满足两条约束：

1. 这段商品总价格**严格大于** `limit`
2. 这段商品中**最贵商品价格** `<= limit`

请找出满足以上两条规则的**最短连续商品长度**；不存在合法区间输出 `0`。

## 输入描述

- 参数 1：商品数量 `n`（`0 < n ≤ 10`）
- 参数 2：预算上限 `limit`（`0 < limit < 100`）
- 参数 3：商品价格数组 `prices`（`0 < Ai ≤ 10`），逗号分隔

## 输出描述

- 合法最短区间长度；无合法区间输出 `0`

---

## 示例

### 示例 1

```
输入：
n=6, limit=7
prices=[2,3,1,2,4,3]
输出：3
```

**说明**：
- `[4,3]` 和为 7，不满足"严格大于 7"，作废
- `[2,4,3]` 和为 9 > 7，最大值 4 ≤ 7，长度 3 ✓
- `[3,1,2,4]` 和为 10 > 7，长度 4
- 最短合法长度为 3

### 示例 2

```
输入：
n=3, limit=11
prices=[1,2,3]
输出：0
```

**说明**：所有商品总价 6 < 11，不满足约束，输出 0

---

## 提示

- **数据范围极小**（n ≤ 10），直接 \(O(n^2)\) 枚举所有连续区间即可
- 对每个起点 i，扩展终点 j，实时维护区间总和 `sum` 和最大值 `maxP`
- 约束 2"最贵商品 ≤ limit"意味着：只要区间内有一个商品 > limit，该区间永远非法，可以提前 break
- 约束 1"总和严格 > limit"：当 sum > limit 且 maxP ≤ limit 时，记录长度并 break（再扩展只会更长）

---

## 思路

### 核心思想：暴力枚举连续区间

双层循环：外层枚举起点 i，内层从 i 开始扩展终点 j，维护 `sum`（区间和）和 `maxP`（区间最大值）。

- 若 `prices[j] > limit`：该区间及更长区间都含超预算商品，break
- 若 `sum > limit` 且 `maxP ≤ limit`：找到合法区间，记录长度 j−i+1，break（继续扩展只会更长）

由于 n ≤ 10，暴力完全够用。

**逐步演示**（示例 1，`[2,3,1,2,4,3]`，limit=7）：

```
i=0: j=0 sum=2,max=2  sum≤7
     j=1 sum=5,max=3  sum≤7
     j=2 sum=6,max=3  sum≤7
     j=3 sum=8,max=3  sum>7,max≤7 → 长度4, ans=4
i=1: j=1 sum=3,max=3
     j=2 sum=4,max=3
     j=3 sum=6,max=3
     j=4 sum=10,max=4 → sum>7,max≤7 → 长度4, ans不变
i=2: j=2 sum=1,max=1
     j=3 sum=3,max=2
     j=4 sum=7,max=4  sum=7不>7
     j=5 sum=10,max=4 → 长度4
i=3: j=3 sum=2,max=2
     j=4 sum=6,max=4
     j=5 sum=9,max=4  → sum>7,max≤7 → 长度3, ans=3 ✓
i=4: j=4 sum=4,max=4
     j=5 sum=7,max=4  sum=7不>7 → 无
i=5: j=5 sum=3,max=3  sum≤7 → 无

ans = 3  ✓
```

- 时间复杂度：\(O(n^2)\)，n ≤ 10 无压力
- 空间复杂度：\(O(1)\)

## 代码

### 解法（Java，暴力枚举）

```java
class Solution {
    public int shortestSegment(int n, int limit, int[] prices) {
        int ans = Integer.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            int sum = 0, maxP = 0;
            for (int j = i; j < n; j++) {
                // 区间内含超过 limit 的商品，该区间及更长区间都非法
                if (prices[j] > limit) break;
                sum += prices[j];
                maxP = Math.max(maxP, prices[j]);
                // 总和严格大于 limit 且最贵商品不超预算
                if (sum > limit) {
                    ans = Math.min(ans, j - i + 1);
                    break;  // 再扩展只会更长
                }
            }
        }
        return ans == Integer.MAX_VALUE ? 0 : ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n^2)\)，双层循环枚举所有连续区间
- **空间复杂度**：\(O(1)\)，仅用 sum、maxP、ans

> 💡 **记忆**：**「n ≤ 10 = 暴力枚举信号」**。数据范围极小时直接 \(O(n^2)\) 枚举，不需要滑动窗口。
>
> ⚠️ **易错**：① 约束 1 是"**严格大于** limit"（`sum > limit`），不是 ≥；② 约束 2 是"最贵商品 ≤ limit"，即区间内不能有任何商品 > limit，遇到 `prices[j] > limit` 立即 break；③ 找到合法区间后 break 是因为继续扩展 j 只会让长度更大。
