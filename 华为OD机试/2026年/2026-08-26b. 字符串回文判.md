# 2026-08-26b. 字符串回文判

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-26 | **标签**：双指针、回文、贪心 | **考点**：删除一个字符后能否成回文，并收集所有可删下标

## 题目描述

给定一个仅由小写英文字母组成的字符串 `s`，请判断它是否可以在**删除一个字符**之后，变成一个回文串。

回文串的定义是：从左到右读和从右到左读完全相同。

如果可以，输出一个数组，数组由**可删除字符的索引值**构成；否则输出一个空数组。

## 输入描述

- 输入一个字符串 `s`，`2 ≤ s.length ≤ 10^5`

## 输出描述

- 输出一个数组，内容为所有可行删除方案的字符索引值（索引从 0 开始）。
- 如输入 `abca`，输出 `[1,2]`，代表有两种删除方式：
  - 删除索引 `1` 的字符 `b`，剩余 `aca`，是回文；
  - 删除索引 `2` 的字符 `c`，剩余 `aba`，是回文。

---

## 示例

### 示例 1

```
输入：s = "abca"
输出：[1,2]
```

**说明**：双指针从两端比较，`a==a` 后遇到 `b(1)` 与 `c(2)` 不匹配。删 `b` 得 `aca`、删 `c` 得 `aba`，均为回文，故可删下标为 `1、2`。

### 示例 2

```
输入：s = "abcd"
输出：[]
```

**说明**：无论删除哪个字符，剩余字符串都不是回文串，输出空数组。

### 示例 3

```
输入：s = "aba"
输出：[1]
```

**说明**：原串本身已是回文。删除中间字符 `b`（索引 1）得 `aa`，仍是回文；删两端的 `a` 得 `ba`/`ab`，不是回文。

---

## 提示

- **双指针找第一处不匹配**：左右指针从两端向中间靠拢，相等就同时内移，直到相遇或遇到不相等的一对 `(l, r)`
- 一旦出现不匹配，能救回文的删除位置**只有 `l` 或 `r`**：删别的位置无法消除这对失配字符
  - 删 `l`：检查子串 `s[l+1..r]` 是否回文
  - 删 `r`：检查子串 `s[l..r-1]` 是否回文
- **特殊情况**：双指针一路相等直到相遇，说明原串本身就是回文。此时可删的是**中间那一段连续相同字符**的所有下标（如 `abba` 可删中间 `b,b` → 下标 `1,2`；`aaa` 删任意一个都可 → 下标 `0,1,2`）
- 判断子串是否回文用一个 `isPalindrome(s, left, right)` 辅助函数，双指针夹逼即可
- 长度为 2 的串（如 `ab`）删任意一个字符都剩单字符，必为回文，结果 `[0,1]`

---

## 思路

### 核心思想：双指针 + 失配点贪心

删除一个字符后是否回文，关键在“第一处失配”：

1. `l=0, r=n-1`，当 `l<r 且 s[l]==s[r]` 时 `l++、r--`
2. **若 `l >= r`（原串本身是回文）**：
   - 可删除位置集中在字符串**中央连续相同字符**这一段。
   - 取中央位置 `L、R`（奇数长度 `L=R=n/2`；偶数长度 `L=n/2-1, R=n/2`），向两侧扩展，只要相邻字符仍等于中央字符就纳入，最终可删下标为 `[L, R]` 这一整段。
3. **若存在失配 `(l, r)`**：
   - 候选答案只有 `l` 和 `r`：
     - 若 `s[l+1..r]` 是回文 → 删 `l` 可行，加入 `l`
     - 若 `s[l..r-1]` 是回文 → 删 `r` 可行，加入 `r`
   - 其余下标删除后，`s[l]` 与 `s[r]` 仍会失配，不可能成回文

**逐步演示**：

```
"abca":  a==a → l=1(b), r=2(c) 失配
         删 l=1: 子串 s[2..2]="c" 回文 ✓ → 加入 1
         删 r=2: 子串 s[1..1]="b" 回文 ✓ → 加入 2
         结果 [1,2]  ✓

"aba":   a==a → l=1, r=1 相遇，原串是回文
         中央 L=R=1，字符 'b'；两侧 s[0]='a'≠'b'，不扩展
         结果 [1]  ✓

"abba":  a==a, b==b → l=2, r=1 相遇，原串是回文
         中央 L=1,R=2，字符 'b'；s[0]='a'≠'b'、s[3]='a'≠'b'
         结果 [1,2]（删任意一个中间 b 得 "aba"）✓
```

- 时间复杂度：\(O(n)\)，双指针与回文校验都只在线性扫描内完成
- 空间复杂度：\(O(1)\)（不计结果数组），仅用若干指针变量

## 代码

### 解法（Java，双指针 + 失配点判定）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    /**
     * 返回所有「删除该位置字符后，剩余字符串为回文」的下标
     * @param s 仅含小写字母的字符串
     * @return  可删除字符的索引列表（升序）；无可行方案返回空列表
     */
    public int[] palindromeAfterDelete(String s) {
        int n = s.length();
        int l = 0, r = n - 1;

        // 双指针从两端向中间找第一处不匹配
        while (l < r && s.charAt(l) == s.charAt(r)) {
            l++;
            r--;
        }

        List<Integer> ans = new ArrayList<>();

        if (l >= r) {
            // 原串本身就是回文：可删中央连续相同字符这一段
            int L, R;
            if (n % 2 == 1) {
                L = n / 2;
                R = n / 2;
            } else {
                L = n / 2 - 1;
                R = n / 2;
            }
            char center = s.charAt(L);
            // 向左右扩展，把与中央字符相同的连续段都纳入
            while (L > 0 && s.charAt(L - 1) == center) {
                L--;
            }
            while (R < n - 1 && s.charAt(R + 1) == center) {
                R++;
            }
            for (int i = L; i <= R; i++) {
                ans.add(i);
            }
        } else {
            // 存在失配 (l, r)：只有删 l 或删 r 才可能成回文
            if (isPalindrome(s, l + 1, r)) {
                ans.add(l);   // 删掉 s[l]
            }
            if (isPalindrome(s, l, r - 1)) {
                ans.add(r);   // 删掉 s[r]
            }
        }

        // 转为 int[] 返回
        int[] result = new int[ans.size()];
        for (int i = 0; i < ans.size(); i++) {
            result[i] = ans.get(i);
        }
        return result;
    }

    /**
     * 判断子串 s[left..right] 是否为回文（闭区间）
     */
    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，外层双指针 \(O(n)\)，两次回文校验合计也是 \(O(n)\)
- **空间复杂度**：\(O(1)\) 额外空间（结果数组最坏 \(O(n)\)，属于输出开销）

> 💡 **记忆**：**「删一个字符成回文」只需盯第一处失配**——能删的只有失配两端 `l` 或 `r`，分别校验内侧子串即可；若原串已是回文，答案是**中央连续相同字符段**。
>
> ⚠️ **易错**：① 失配时不要枚举所有下标，只有 `l`、`r` 两个候选；② 原串本身是回文的情况最容易漏——可删的是中央相同字符连续段（`aba`→[1]，`abba`→[1,2]，`aaa`→[0,1,2]），不是只能删正中间一个；③ 校验子串回文时区间下标别写错：删 `l` 对应 `[l+1, r]`，删 `r` 对应 `[l, r-1]`。
