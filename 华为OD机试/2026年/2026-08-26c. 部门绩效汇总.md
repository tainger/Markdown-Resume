# 2026-08-26c. 部门绩效汇总

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-08-26 | **标签**：二叉树、后序遍历、DFS | **考点**：子树求和（自底向上聚合）

## 题目描述

某公司使用二叉树结构管理组织汇报关系：每个节点代表一名员工，员工的“左下属”为研发组成员，“右下属”为产品组成员。若某侧无下属，则对应位置为空。

年终绩效考核时，每位员工有一个**基础绩效分**。按照公司制度，管理者的**最终绩效分**：

> 最终绩效分 = 自身基础分 + 左子树所有员工的最终绩效分之和 + 右子树所有员工的最终绩效分之和

请根据给定的公司完整员工树结构以及每位员工的基础绩效分，计算并返回每位员工的最终绩效分。

## 输入描述

共 4 个输入参数：

- `n`：员工总数（`1 ≤ n ≤ 1000`），编号 `0` 到 `n-1`
- `left`：长度为 `n` 的整数数组，`left[i]` 表示员工 `i` 的左下属编号，`-1` 表示无左下属
- `right`：长度为 `n` 的整数数组，`right[i]` 表示员工 `i` 的右下属编号，`-1` 表示无右下属
- `base`：长度为 `n` 的整数数组，`base[i]` 表示员工 `i` 的基础绩效分，`0 ≤ base[i] ≤ 10000`

约束：

- 员工编号无重复、无遗漏
- 整棵树为一棵合法二叉树，有且仅有一个根节点

## 输出描述

- 长度为 `n` 的数组，第 `i` 个元素表示员工 `i` 的最终绩效分，顺序与员工编号顺序一致。

---

## 示例

### 示例 1

```
输入：n=1, left=[-1], right=[-1], base=[10]
输出：[10]
```

**说明**：公司只有员工 0，无下属，最终绩效分就是其基础绩效分 10。

### 示例 2

```
输入：n=5, left=[1,3,-1,-1,-1], right=[2,-1,4,-1,-1], base=[5,3,2,4,7]
输出：[21,7,9,4,7]
```

**说明**：树结构如下（括号内为基础绩效分）：

```
        0(5)
       /    \
     1(3)    2(2)
     /         \
   3(4)        4(7)
```

按**后序遍历**（先下属、后自己）自底向上计算：

- 员工 3（叶子）：最终 = 4
- 员工 4（叶子）：最终 = 7
- 员工 1：`base[1] + 最终[3] + 0 = 3 + 4 = 7`
- 员工 2：`base[2] + 0 + 最终[4] = 2 + 7 = 9`
- 员工 0：`base[0] + 最终[1] + 最终[2] = 5 + 7 + 9 = 21`

结果按编号顺序为 `[21, 7, 9, 4, 7]`。

---

## 提示

- **本质是子树求和**：某员工的最终分 = 以该员工为根的子树中所有基础绩效分之和（因为孩子的最终分已经包含其整棵子树）
- 必须**后序遍历**：先算出左、右下属的最终分，才能算当前员工——`final[i] = base[i] + final[left[i]] + final[right[i]]`
- 根节点没有父节点：用一个 `hasParent` 标记（或 `isChild` 数组）找出**从未作为任何人下属**的编号，即为根
- 用记忆化数组 `finalScore` 缓存结果，每个节点只算一次，天然避免重复
- `-1` 表示空下属，递归前判空，空侧贡献为 0；基础分非负，累加和最大约 `1000 × 10000 = 10^7`，int 可容纳

---

## 思路

### 核心思想：后序 DFS 自底向上聚合

最终绩效分的定义是递归的：要算一个节点，必须先算完它的左右子树。这正是**后序遍历**的特征。

1. **找根**：遍历 `left`、`right`，把所有出现过的下属编号标记为“有父节点”，没被标记的那个就是根
2. **DFS 计算**：定义 `dfs(i)` 返回员工 `i` 的最终绩效分
   - 左下属存在则加 `dfs(left[i])`，右下属存在则加 `dfs(right[i])`
   - `finalScore[i] = base[i] + 左子树和 + 右子树和`
   - 由于孩子的最终分已含其全部后代，这里直接相加即得整棵子树之和
3. 从根发起一次 DFS，过程中会递归覆盖所有节点，最后返回 `finalScore` 数组

**逐步演示**（示例 2）：

```
dfs(0):
  dfs(1):
    dfs(3): 叶子 → final[3] = 4
    右下属为空 → 0
    final[1] = 3 + 4 + 0 = 7
  dfs(2):
    左下属为空 → 0
    dfs(4): 叶子 → final[4] = 7
    final[2] = 2 + 0 + 7 = 9
  final[0] = 5 + 7 + 9 = 21
结果 finalScore = [21,7,9,4,7]  ✓
```

- 时间复杂度：\(O(n)\)，每个节点仅访问一次
- 空间复杂度：\(O(n)\)，结果数组 \(O(n)\)，递归栈深度最坏 \(O(n)\)（树退化成链时）

## 代码

### 解法（Java，后序 DFS 子树求和）

```java
class Solution {
    private int[] left;
    private int[] right;
    private int[] base;
    private int[] finalScore;   // finalScore[i]：员工 i 的最终绩效分

    /**
     * 计算每位员工的最终绩效分
     * @param n     员工总数
     * @param left  left[i] 为员工 i 的左下属编号，-1 表示无
     * @param right right[i] 为员工 i 的右下属编号，-1 表示无
     * @param base  base[i] 为员工 i 的基础绩效分
     * @return      按编号顺序排列的最终绩效分数组
     */
    public int[] performanceSummary(int n, int[] left, int[] right, int[] base) {
        this.left = left;
        this.right = right;
        this.base = base;
        this.finalScore = new int[n];

        // 标记每个编号是否有父节点，用于找出根节点
        boolean[] hasParent = new boolean[n];
        for (int i = 0; i < n; i++) {
            if (left[i] != -1) {
                hasParent[left[i]] = true;
            }
            if (right[i] != -1) {
                hasParent[right[i]] = true;
            }
        }
        int root = 0;
        for (int i = 0; i < n; i++) {
            if (!hasParent[i]) {
                root = i;
                break;
            }
        }

        // 从根开始后序遍历，递归会覆盖所有节点
        dfs(root);
        return finalScore;
    }

    /**
     * 后序遍历：返回员工 i 的最终绩效分，并写入 finalScore[i]
     * 最终分 = 自身基础分 + 左子树最终分之和 + 右子树最终分之和
     */
    private int dfs(int i) {
        int sum = base[i];   // 自身基础绩效分

        // 累加左子树（左下属的最终分已包含其全部后代）
        if (left[i] != -1) {
            sum += dfs(left[i]);
        }
        // 累加右子树
        if (right[i] != -1) {
            sum += dfs(right[i]);
        }

        finalScore[i] = sum;
        return sum;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，每个员工节点恰好被递归访问一次
- **空间复杂度**：\(O(n)\)，`finalScore`、`hasParent` 各 \(O(n)\)，递归栈最坏 \(O(n)\)

> 💡 **记忆**：**“子树聚合”用后序遍历**——节点值依赖左右子树结果时，先递归孩子再处理自己，`节点值 = 自身值 + 左子树和 + 右子树和`。孩子的返回值天然就是整棵子树的汇总。
>
> ⚠️ **易错**：① 不能用前序（自上而下），必须后序——算管理者前要先算完下属；② 根节点不能默认是 0，要用 `hasParent` 找出唯一无父节点的编号；③ `-1` 表示空下属，递归前一定要判空，否则数组越界；④ 题目要求按**编号顺序**输出，所以结果直接写进 `finalScore[i]`，不要按遍历顺序收集。
