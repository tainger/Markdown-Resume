# 2026-08-30a. 小花获胜的奶茶

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-30 | **标签**：滑动窗口 | **考点**：定长连续子数组最大和

## 题目描述

小菊和小花是好朋友，他们经常一起玩游戏。这天他们玩一个数字游戏，获胜可以获得对方 1 杯奶茶。

游戏规则：

小菊在纸上写了一排数组，小花需要从中选择**连续 k 个数字**，使得这 k 个数字的**和最大**。

小花正确找到最大的值就是获胜，小菊则提供 1 杯奶茶；小花想获胜喝奶茶，请你帮助她。

## 输入描述

- 参数 1：给出的一排数字 `nums`
- 参数 2：整数 `k`，连续数字的个数

约束：

- `-2147483648 ≤ 单个数字 ≤ 2147483647`
- `0 < 一排数字长度 < 10^6`
- `1 ≤ k ≤ 一排数字的长度`

## 输出描述

- 返回连续 k 个数字的最大和

---

## 示例

### 示例 1

```
输入：nums = [1,3,8,6,4,10], k = 3
输出：20
```

**说明**：数组为 `[1,3,8,6,4,10]`，`k = 3`。

- 连续三个数的各种取法：`1+3+8=12`、`3+8+6=17`、`8+6+4=18`、`6+4+10=20`
- 其中 `6 + 4 + 10 = 20` 最大，故返回 `20`

### 示例 2

```
输入：nums = [-1,-2,-3], k = 2
输出：-3
```

**说明**：数字可能为负数。`-1 + -2 = -3`、`-2 + -3 = -5`，最大为 `-3`。注意最大值不能初始化为 0。

---

## 提示

- **固定长度窗口**：窗口大小恒为 k，是最经典的滑动窗口入门题
- 先求前 k 个数的和作为初始窗口，之后窗口每右移一格：**加入右侧新数、减去左侧旧数**
- 数字可以是负数，最大值初值要设为第一个窗口的和（或 `Long.MIN_VALUE`），不能设为 0
- 单个数字可达 21 亿、长度可达 10^6，累加和可能超过 int 范围，**必须用 `long`**
- k 等于数组长度时，窗口只有一个，直接返回总和

---

## 思路

### 核心思想：定长滑动窗口

要求长度**恰好为 k** 的连续子数组最大和。窗口大小固定，无需伸缩：

1. 先计算前 k 个元素之和 `windowSum`，作为初始答案 `maxSum`
2. 从下标 `k` 开始向右滑动：
   - 窗口右移，加入新元素 `nums[i]`
   - 同时移出最左侧旧元素 `nums[i - k]`
   - 即 `windowSum = windowSum + nums[i] - nums[i - k]`
3. 每次滑动后用 `windowSum` 更新 `maxSum`

**逐步演示**（示例 1，`[1,3,8,6,4,10]`，k=3）：

```
初始窗口 [1,3,8]          windowSum = 12, maxSum = 12
右移一格 [3,8,6]          windowSum = 12 + 6 - 1 = 17, maxSum = 17
右移一格 [8,6,4]          windowSum = 17 + 4 - 3 = 18, maxSum = 18
右移一格 [6,4,10]         windowSum = 18 + 10 - 8 = 20, maxSum = 20  ✓
```

- 时间复杂度：\(O(n)\)，每个元素最多进、出窗口各一次
- 空间复杂度：\(O(1)\)，只用常数额外变量

## 代码

### 解法（Java，定长滑动窗口）

```java
class Solution {
    /**
     * 求长度恰好为 k 的连续子数组的最大和
     * @param nums 一排数字
     * @param k    连续数字的个数
     * @return     连续 k 个数字的最大和
     */
    public long maxKSum(int[] nums, int k) {
        // 先计算第一个窗口（前 k 个元素）的和
        long windowSum = 0;
        for (int i = 0; i < k; i++) {
            windowSum += nums[i];
        }
        long maxSum = windowSum;

        // 窗口向右滑动：加入右侧新数 nums[i]，减去左侧旧数 nums[i-k]
        for (int i = k; i < nums.length; i++) {
            windowSum += nums[i];        // 加入右侧新元素
            windowSum -= nums[i - k];    // 移出左侧旧元素
            maxSum = Math.max(maxSum, windowSum);
        }
        return maxSum;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，初始窗口求和 \(O(k)\)，滑动 \(O(n-k)\)，整体线性
- **空间复杂度**：\(O(1)\)，仅用 `windowSum`、`maxSum` 两个变量

> 💡 **记忆**：**「窗口大小固定 = 一进一出滑窗」**。先建初始窗口，之后每步 `+新元素 -旧元素`，避免重复求和，把暴力的 \(O(nk)\) 降到 \(O(n)\)。
>
> ⚠️ **易错**：① 累加和要用 `long`（单值 21 亿 × 长度 10^6 会爆 int）；② 数字可能全为负，`maxSum` 初值不能给 0，要用第一个窗口的和；③ 滑动时减去的是 `nums[i - k]`，注意下标别写成 `nums[i - k - 1]`。
