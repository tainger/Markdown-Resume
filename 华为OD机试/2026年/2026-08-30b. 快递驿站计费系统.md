# 2026-08-30b. 快递驿站计费系统

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-30 | **标签**：模拟、哈希表、排序 | **考点**：按计费规则逐条累加并多关键字排序

## 题目描述

请开发一个快递驿站计费系统，根据给定的一组快递存取记录，计算每位业主要缴纳的总费用，并按总费用从高到低输出。

系统计费规则如下：

1. 免费存放时间为 `12` 小时，从存件时间开始计时，总存放时间 `≤ 12` 小时不收费；存放时间 = 取件时间 − 存件时间；
2. 超出免费存放时间的，每 `12` 小时收取 `1` 元，**不足 12 小时按 12 小时计算**（向上取整）。比如存放了 `25` 个小时，超出免费时间 `13` 小时，需要收费 `2` 元；
3. 同一个房间号的业主可能有多条存取记录，需要将该业主所有快递的超时费用**累加**得到总费用。

## 输入描述

一组快递存取记录列表，其中一条记录对应一个数组，该数组包含 `3` 个非负整数字段：**存件时间、取件时间、业主房间号**。存取时间已简化为整型数字，非 24 小时制格式。

- `0 ≤ 存件时间 ≤ 取件时间 ≤ 100000`
- `100 < 房间号 < 10000`
- 记录条数 `1 ≤ N ≤ 1000`

## 输出描述

一个二维数组/列表，表示一组收费记录，每条记录包含 `2` 个整数字段：**业主房间号、总费用**。

- 按**总费用从高到低**排序
- 总费用相同的，按**房间号从小到大**排序

## 示例

### 示例 1

```
输入：records = [[100,110,1111],[200,210,2222],[150,165,3333],[180,190,1111]]
输出：[[3333,1],[1111,0],[2222,0]]
```

**说明**：

- `3333` 房间：存件 150、取件 165，存放 `165-150=15` 小时，超出免费时间 `15-12=3` 小时，`⌈3/12⌉=1` 元
- `1111` 房间：两单存放时间都是 `10` 小时（≤12），各 `0` 元，总费用 `0`
- `2222` 房间：存放 `10` 小时，费用 `0`
- 费用相同时按房间号升序，故 `1111` 排在 `2222` 前面

### 示例 2

```
输入：records = [[10,30,303],[25,50,303],[40,70,201],[60,90,201],[100,130,102],[150,180,102]]
输出：[[102,4],[201,4],[303,3]]
```

**说明**：

- `102` 房间有 2 单，每单存放 `30` 小时、超时 `18` 小时，每单 `⌈18/12⌉=2` 元，共 `4` 元
- `201` 房间同理，2 单各超时 `18` 小时，共 `4` 元
- `303` 房间：第一单存放 `20` 小时超时 `8` 小时 → `1` 元；第二单存放 `25` 小时超时 `13` 小时 → `2` 元，共 `3` 元
- `102` 与 `201` 费用相同，按房间号升序，`102` 在前

## 提示

- **逐条模拟计费**：对每条记录算存放时长 `取件-存件`，再算超时费用，按房间号累加
- 超时费用公式：超时 `overtime = max(0, duration - 12)`；费用 `= ⌈overtime / 12⌉`，整数写法 `(overtime + 11) / 12`（overtime 为 0 时结果恰好为 0）
- 用 `HashMap<房间号, 总费用>` 聚合同一业主的多笔费用
- 排序是**双关键字**：费用降序为主，房间号升序为辅，注意比较器方向别写反
- 免费业主（费用 0）也要输出，不能只输出有费用的业主

---

## 思路

### 核心思想：哈希聚合计费 + 定制排序

分三步走：

1. **计费**：遍历每条记录 `[存件, 取件, 房间号]`
   - 存放时长 `duration = 取件 - 存件`
   - 超时 `overtime = duration - 12`（≤0 则免费）
   - 本单费用 `fee = ⌈overtime / 12⌉ = (overtime + 11) / 12`（整除自动向下，`+11` 实现向上取整）
2. **聚合**：用 `Map<房间号, 累计费用>`，把同一房间号的费用累加
3. **排序输出**：把 Map 转成列表，按「费用降序、房间号升序」排序后组装为二维数组

**逐步演示**（示例 1）：

```
[100,110,1111] duration=10, overtime=0,  fee=0  → 1111: 0
[200,210,2222] duration=10, overtime=0,  fee=0  → 2222: 0
[150,165,3333] duration=15, overtime=3,  fee=(3+11)/12=1 → 3333: 1
[180,190,1111] duration=10, overtime=0,  fee=0  → 1111: 0
聚合: {1111:0, 2222:0, 3333:1}
排序(费用降序, 房间号升序): 3333(1) → 1111(0) → 2222(0)
输出: [[3333,1],[1111,0],[2222,0]]  ✓
```

- 时间复杂度：\(O(N \log N)\)，计费聚合 \(O(N)\)，排序 \(O(N \log N)\)
- 空间复杂度：\(O(N)\)，哈希表与结果列表最多存 N 个业主

## 代码

### 解法（Java，哈希聚合 + 定制排序）

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    /**
     * 计算每位业主的快递超时总费用，并按规则排序
     * @param records 存取记录，每条为 [存件时间, 取件时间, 房间号]
     * @return        收费记录，每条为 [房间号, 总费用]，按费用降序、房间号升序
     */
    public int[][] billing(int[][] records) {
        // 房间号 -> 该业主累计总费用
        Map<Integer, Integer> feeMap = new HashMap<>();

        for (int[] record : records) {
            int storeTime = record[0];   // 存件时间
            int pickTime  = record[1];   // 取件时间
            int room      = record[2];   // 业主房间号

            int duration = pickTime - storeTime;   // 总存放时长
            int overtime = duration - 12;         // 超出免费时间的部分
            int fee = 0;
            if (overtime > 0) {
                // 每 12 小时 1 元，不足 12 小时按 12 小时算（向上取整）
                fee = (overtime + 11) / 12;
            }
            // 同一业主的多笔费用累加（getOrDefault 处理首次出现）
            feeMap.merge(room, fee, Integer::sum);
        }

        // 转为列表便于自定义排序
        List<int[]> list = new ArrayList<>();
        for (Map.Entry<Integer, Integer> entry : feeMap.entrySet()) {
            list.add(new int[]{entry.getKey(), entry.getValue()});
        }

        // 双关键字排序：总费用降序；费用相同则房间号升序
        list.sort((a, b) -> {
            if (a[1] != b[1]) {
                return b[1] - a[1];   // 费用高的在前
            }
            return a[0] - b[0];       // 房间号小的在前
        });

        // 组装为二维数组返回
        return list.toArray(new int[0][]);
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(N \log N)\)，遍历计费 \(O(N)\)，排序 \(O(N \log N)\)
- **空间复杂度**：\(O(N)\)，哈希表与结果列表随业主数线性增长

> 💡 **记忆**：**「分组聚合 → 双关键字排序」**是统计类模拟题的通用套路。`Map.merge(k, v, Integer::sum)` 一行完成「存在则累加、不存在则放入」。
>
> ⚠️ **易错**：① 向上取整用 `(overtime + 11) / 12`，且 overtime≤0 时费用必须为 0（不能直接套公式，否则 `(0+11)/12=0` 恰好对，但负数时长要先拦掉）；② 排序方向：费用降序用 `b[1]-a[1]`，房间号升序用 `a[0]-b[0]`，别写反；③ 费用为 0 的业主也要输出。
