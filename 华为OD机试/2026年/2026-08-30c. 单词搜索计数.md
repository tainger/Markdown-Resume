# 2026-08-30c. 单词搜索计数

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-08-30 | **标签**：DFS、回溯 | **考点**：网格中单词路径计数（四方向回溯）

## 题目描述

给定一个 `m × n` 的二维字符网格 `board` 和一个字符串单词 `word`。

请计算单词 `word` 在网格中出现的**总次数**。

单词必须按照字母顺序，通过**相邻**的单元格内的字母构成，其中“相邻”单元格是指**水平相邻或垂直相邻**的单元格。同一个单元格内的字母在一条搜索路径中**不允许被重复使用**。

## 输入描述

- `board`：二维字符列表，每个元素为大写英文字母，`1 ≤ m, n ≤ 10`
- `word`：字符串，由大写英文字母组成，`1 ≤ len(word) ≤ 100`

## 输出描述

- 返回一个整数，表示单词在网格中出现的**路径总数**

---

## 示例

### 示例 1

```
输入：board = [[A,B,C,E],[S,F,C,S],[A,D,E,E]], word = "ABCCED"
输出：1
```

**说明**：存在唯一一条路径 `A(0,0)→B(0,1)→C(0,2)→C(1,2)→E(2,2)→D(2,1)`，拼出 `ABCCED`，共 1 条。

### 示例 2

```
输入：board = [[A,A]], word = "A"
输出：2
```

**说明**：网格中有两个 `A`，每个都可以独立构成单词 `A`，共 2 条路径。不同起点算不同路径。

### 示例 3

```
输入：board = [[A,B],[C,D]], word = "ABCD"
输出：0
```

**说明**：`B` 在 `(0,1)`、`C` 在 `(1,0)`，二者是**斜对角**而非水平/垂直相邻，无法直接相连，所以不存在 `ABCD` 的路径。

---

## 提示

- **回溯模板**：枚举每个与 `word[0]` 相同的格子作为起点，DFS 向上下左右扩展
- 用 `visited` 矩阵（或原地改字符）标记当前路径已用格子，保证一条路径内不重复使用同一格；**回溯时务必撤销标记**
- 递归终止：匹配到单词最后一个字符（`index == word.length()-1`）时，找到一条完整路径，计数 +1
- 格子总数最多 `10×10=100`，而路径不重复用格，所以当 `word.length() > m*n` 时可直接返回 0
- 计数与“判断是否存在”不同：找到一条路径后**不能提前 return**，要继续搜索其他方向，统计全部路径

---

## 思路

### 核心思想：网格 DFS + 回溯

在网格里按四方向搜索单词，是经典的「岛屿/单词搜索」回溯模型：

1. 遍历每个格子 `(i,j)`，若 `board[i][j] == word[0]`，以它为起点发起 DFS
2. DFS 状态为 `(当前行, 当前列, 当前匹配到 word 的下标 index)`：
   - 越界、已访问、字符不匹配 → 返回 0
   - `index == word.length()-1` → 完整匹配一条路径，返回 1
   - 否则：标记当前格已访问，向**上下左右**四个方向递归，累加四条分支的路径数；最后**撤销标记**（回溯）
3. 把所有起点的结果累加即为总路径数

**逐步演示**（示例 2，`board=[[A,A]]`，`word="A"`）：

```
起点 (0,0)：字符 A == word[0]，且 index 已是最后一位 → 1 条
起点 (0,1)：字符 A == word[0]，且 index 已是最后一位 → 1 条
总计 = 2  ✓
```

**回溯骨架**：

```
dfs(i, j, index):
    if 越界 or visited[i][j] or board[i][j] != word[index]: return 0
    if index == word.length()-1: return 1          // 拼完整个单词
    visited[i][j] = true
    cnt = dfs(上) + dfs(下) + dfs(左) + dfs(右)
    visited[i][j] = false                          // 撤销，供其他路径使用
    return cnt
```

- 时间复杂度：\(O(m \cdot n \cdot 4^L)\)，其中 \(L\) 为单词长度；每个起点最多向 4 个方向分支 \(L\) 层（\(L \le m n\)）
- 空间复杂度：\(O(m \cdot n)\)，`visited` 矩阵 + 递归栈深度 \(O(L)\)

## 代码

### 解法（Java，四方向 DFS 回溯）

```java
class Solution {
    private char[][] board;
    private String word;
    private boolean[][] visited;
    private int m, n;
    // 上下左右四个方向
    private static final int[][] DIRS = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

    /**
     * 统计单词在网格中出现的路径总数
     * @param board 二维字符网格
     * @param word  目标单词
     * @return      路径总数
     */
    public int wordSearchCount(char[][] board, String word) {
        this.board = board;
        this.word = word;
        this.m = board.length;
        this.n = board[0].length;

        // 路径不能重复使用格子，单词长度超过格子总数必然无解
        if (word.length() > m * n) {
            return 0;
        }
        this.visited = new boolean[m][n];

        int count = 0;
        // 枚举每个可能的起点
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == word.charAt(0)) {
                    count += dfs(i, j, 0);
                }
            }
        }
        return count;
    }

    /**
     * 从 (i,j) 开始，尝试匹配 word[index...]
     * @return 从该状态出发能拼成剩余单词的路径条数
     */
    private int dfs(int i, int j, int index) {
        // 越界、当前格已被本路径使用、字符不匹配
        if (i < 0 || i >= m || j < 0 || j >= n
                || visited[i][j]
                || board[i][j] != word.charAt(index)) {
            return 0;
        }
        // 已匹配到单词最后一个字符，成功拼出一条完整路径
        if (index == word.length() - 1) {
            return 1;
        }

        // 标记当前格，本路径内不可再用
        visited[i][j] = true;
        int cnt = 0;
        for (int[] dir : DIRS) {
            cnt += dfs(i + dir[0], j + dir[1], index + 1);
        }
        // 回溯：撤销标记，让其他路径可以使用该格
        visited[i][j] = false;
        return cnt;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(m \cdot n \cdot 4^L)\)，\(L\) 为单词长度；网格规模 ≤10×10、\(L \le 100\)，剪枝后可通过
- **空间复杂度**：\(O(m \cdot n)\)，`visited` 矩阵 \(O(mn)\)，递归栈最深 \(O(L)\)

> 💡 **记忆**：**网格路径问题 = DFS 回溯三件套**：① `visited` 标记防重复；② 四个方向递归累加；③ 递归返回后**撤销标记**。计数题要把各分支结果**累加**而不是找到就停。
>
> ⚠️ **易错**：① 计数题找到完整路径后要 `return 1` 继续累计，不能像“判断存在”那样提前整体返回；② 回溯时必须 `visited[i][j]=false`，否则不同路径会互相干扰（示例 2 两个 A 就会漏算）；③ 只有水平/垂直四方向，**不含斜对角**（示例 3 的 B、C 斜对不算相邻）；④ 单词长度超过格子总数直接返回 0。
