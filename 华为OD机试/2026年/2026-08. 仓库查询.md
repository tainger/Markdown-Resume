# 2026-08. 仓库查询

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-26

## 题目描述

有一批货物 `A` 会**按顺序**进入仓库，第 `i` 件货物的价格是 `A[i]`。

管理员会发起一组查询请求 `B`，对于**第 `j` 次查询**，你需要回答：在当前已经进入仓库的**前 `B[j]` 件货物**中，按价格**从小到大排序**后，**第 `j` 位**的价格是多少。

题目保证所有查询合法，也就是说在第 `j` 次查询时，当前货物数量不少于 `j`。

约束：

- `1 ≤ j ≤ B[j] ≤ 5000`
- `1 ≤ A[i] ≤ 10^6`

## 示例

### 示例 1

```
输入：
n = 7
m = 4
A = [9, 7, 2, 8, 14, 1, 8]
B = [1, 2, 6, 6]
输出：
[9, 9, 7, 8]
```

**解释**：

- 7 件货物依次进入仓库，价格序列：`9, 7, 2, 8, 14, 1, 8`
- 4 次查询发生时刻分别是「前 1、前 2、前 6、前 6 件货物进入后」
- 注意：第 `j` 次查询问的不是「第几件货物」，而是「当前已进入的这些货物里，按价格升序排，**第 j 位**是多少」

逐步演示：

| j (第几次查询) | B[j] (前 B[j] 件) | 当前已进入货物 | 排序后 | 第 j 位 (索引 j-1) | 答案 |
|:---:|:---:|:---|:---|:---:|:---:|
| 1 | 1 | `[9]` | `[9]` | 索引 0 | **9** |
| 2 | 2 | `[9, 7]` | `[7, 9]` | 索引 1 | **9** |
| 3 | 6 | `[9, 7, 2, 8, 14, 1]` | `[1, 2, 7, 8, 9, 14]` | 索引 2 | **7** |
| 4 | 6 | `[9, 7, 2, 8, 14, 1]` | `[1, 2, 7, 8, 9, 14]` | 索引 3 | **8** |

最终输出 `[9, 9, 7, 8]`。

---

## 提示

- `n, m ≤ 5000`，`A[i] ≤ 10^6`
- 关键观察：**第 `j` 次查询的「第 j 位」是相对位置**（不是问 `B[j]` 自身），所以只要复制前缀、排序、取索引 `j-1`
- 货物按顺序进入，但查询 `B[j]` **不保证单调递增**（如示例中 `1 → 2 → 6 → 6`），不能直接复用上一次排序结果
- 暴力 `m × O(k log k)` 复杂度约 `5000 × 5000 × log(5000) ≈ 3×10^8`，Java 中可过 100 分题；若担心超时可改用 `TreeMap` 计数 + 第 `j` 位遍历

---

## 思路

### 核心思想

**前缀复制 + 排序 + 按索引取值**。对每次查询 `j`：

1. 取出 `A[0..B[j]-1]` 这 `B[j]` 件货物（即前 `B[j]` 件已进入仓库的货物）；
2. 复制到临时数组并**升序排序**；
3. 返回排序后**索引 `j-1`** 处的值（即第 `j` 位）。

> ⚠️ 易错点：题目里 `j` 是从 1 开始计数（「第 j 次」「第 j 位」），但 Java 数组下标从 0 开始，所以取的是 `sorted[j-1]` 而不是 `sorted[j]`。

**逐步演示**（以示例 1 第 3 次查询为例）：

```
j=3, B[j]=6
A 前 6 件: [9, 7, 2, 8, 14, 1]
复制+排序:  [1, 2, 7, 8, 9, 14]
取索引 j-1=2: A_sorted[2] = 7  ✓
```

- 时间复杂度：\(O(m \cdot k \log k)\)，其中 `k = B[j] ≤ n`
- 空间复杂度：\(O(n)\)，临时数组

### 解法（Java，前缀排序）

```java
import java.util.Arrays;

class Solution {
    public int[] warehouseQuery(int n, int m, int[] A, int[] B) {
        int[] ans = new int[m];
        for (int j = 0; j < m; j++) {
            int k = B[j];                       // 前 k 件货物
            int[] prefix = new int[k];
            System.arraycopy(A, 0, prefix, 0, k);  // 复制前缀
            Arrays.sort(prefix);                // 升序排序
            ans[j] = prefix[j];                 // 第 j+1 位，索引 j
        }
        return ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(m \cdot k \log k)\)，其中 `k = max(B[j]) ≤ n`。最坏 `m = n = 5000` 时约 `3×10^8` 次操作，Java 在 100 分题时限内可过。
- **空间复杂度**：\(O(n)\)，仅临时前缀数组。

> 💡 记忆：**「前 B[j] 件货物升序排，取第 j 位」**——查的是位置不是货号，排序后下标 `j-1` 即答案。
>
> ⚠️ 易错：① 第 `j` 位对应索引 `j-1`（不要写成 `sorted[j]`）；② `B[j]` 不一定单调，不能直接复用上次排序结果；③ 用 `System.arraycopy` 比 `for` 循环更快（底层 memcpy），大数据量推荐。
