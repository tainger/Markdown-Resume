# 2026-09-02a. 查找幸运数

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-09-02 | **标签**：字符串 | **考点**：线性扫描 + 有序集合去重排序

## 题目描述

在一个仅由数字组成的字符串中，找出只由 6 或 8 组成的最长的连续子串。

数字 6 和 8 被视为"幸运数字"，由它们连续拼接而成的子串称为"幸运子串"。请找出字符串中所有长度最长的幸运子串。

## 输入描述

- 参数：一个仅由数字组成的字符串，长度小于 256
- 字符串可能为空

## 输出描述

- 输出所有满足要求的最长子串，**去重**后按照**字典序升序**排序输出
- 当字符串为空或没有符合要求的子串时，输出空字符串，即 `[""]`

---

## 示例

### 示例 1

```
输入：1688
输出：["688"]
```

**说明**：扫描字符串，唯一的幸运连续段为 `"688"`（长度 3），输出 `["688"]`。

### 示例 2

```
输入：123
输出：[""]
```

**说明**：字符串中没有 6 或 8，不存在任何幸运子串，输出 `[""]`。

### 示例 3

```
输入：88612668
输出：["668","886"]
```

**说明**：存在两个最长幸运子串 `"886"`（开头）和 `"668"`（结尾），长度均为 3；去重后按字典序排序，`"668"` < `"886"`，输出 `["668","886"]`。

---

## 提示

- **幸运子串 = 极大连续段**：从某个 6/8 开始一直向右扩展，直到遇到非 6/8 字符为止，这一段才是候选子串，段内部不需要再切分
- 只保留**长度等于全局最长**的段；更短的段直接丢弃
- **去重 + 排序**可以交给 `TreeSet<String>` 一次性完成（元素唯一且按字典序排列）
- 边界情况：空串、全是非 6/8 字符 → 返回只含空串的列表 `[""]`
- 字典序即字符串默认的 `compareTo` 顺序（逐位比较字符 ASCII）

---

## 思路

### 核心思想：线性扫描切分极大段 + TreeSet 维护答案

幸运子串要求**连续**且每个字符只能是 `6` 或 `8`。因此从左到右扫描字符串，把所有由 6/8 构成的极大连续段截取出来，只保留长度最长的段：

1. 指针 `i` 遇到非 6/8 字符 → 跳过
2. 遇到 6/8 → 用指针 `j` 向右扩展到段尾，截取出子串 `sub`
3. 比较 `sub.length()` 与当前最长长度 `maxLen`：
   - 更长：清空集合，加入 `sub`，更新 `maxLen`
   - 相等：加入集合（`TreeSet` 自动去重）
   - 更短：忽略
4. 扫描结束后集合为空 → 返回 `[""]`；否则返回集合中所有元素

**逐步演示**（示例 3，`88612668`）：

```
i=0: '8' 是幸运字符 → 扩展 j 到 3，段="886"，长度3 > 0 → 集合={"886"}, maxLen=3
i=3: '1' 跳过；i=4: '2' 跳过
i=5: '6' 是幸运字符 → 扩展 j 到 8，段="668"，长度3 == maxLen → 集合={"668","886"}
TreeSet 自动按字典序排列 → ["668","886"]  ✓
```

- 时间复杂度：\(O(N + K \log K)\)，\(N\) 为字符串长度，\(K\) 为最长段的去重数量（集合操作对数级）
- 空间复杂度：\(O(K \cdot L)\)，\(L\) 为最长段长度

## 代码

### 解法（Java，线性扫描 + TreeSet）

```java
import java.util.*;

class Solution {
    public List<String> findLuckyNumbers(String s) {
        // TreeSet 自动去重，并按字典序升序维护候选子串
        TreeSet<String> set = new TreeSet<>();
        int maxLen = 0;
        int n = s.length();
        int i = 0;
        while (i < n) {
            char c = s.charAt(i);
            if (c != '6' && c != '8') {
                i++;
                continue;
            }
            // 扩展出一个只含 6/8 的极大连续段
            int j = i;
            StringBuilder sb = new StringBuilder();
            while (j < n && (s.charAt(j) == '6' || s.charAt(j) == '8')) {
                sb.append(s.charAt(j));
                j++;
            }
            String sub = sb.toString();
            if (sub.length() > maxLen) {
                // 发现更长的段：清空旧候选，重新记录
                maxLen = sub.length();
                set.clear();
                set.add(sub);
            } else if (sub.length() == maxLen) {
                // 等长段：加入集合（自动去重）
                set.add(sub);
            }
            i = j;
        }
        // 无任何幸运子串：输出 [""]
        if (set.isEmpty()) {
            List<String> empty = new ArrayList<>();
            empty.add("");
            return empty;
        }
        return new ArrayList<>(set);
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(N + K \log K)\)，每个字符最多扫描一次；集合插入/清空总计 \(O(K \log K)\)
- **空间复杂度**：\(O(K \cdot L)\)，存储去重后的最长幸运子串

> 💡 **记忆**：**「连续段问题 = 双指针切分极大段」**。要求"去重 + 字典序"时，`TreeSet` 一步到位，省去手动排序和判重。
>
> ⚠️ **易错**：① 段要取**极大连续段**（扩展到非 6/8 为止），不要在段内部截断；② 发现更长段时必须**清空集合**再加入，否则残留的短段会污染答案；③ 空串/无幸运字符时返回 `[""]`（含一个空字符串的列表），不是空列表 `[]`。
