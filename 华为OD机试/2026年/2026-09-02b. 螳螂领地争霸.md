# 2026-09-02b. 螳螂领地争霸

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-09-02

## 题目描述

在一根很高的竹子上生活着一群螳螂，每只螳螂都有一段自己的势力范围，不同螳螂在竹子上的领地有可能重叠。当发现自己的领地内出现其它螳螂时就会战斗，失败一方的领地会被胜利一方的螳螂占领。

请计算领地斗争全部结束后，螳螂们最终的领地信息。

## 输入描述

- 参数：二维数组 `originalLand`，`originalLand[i] = [x, y]` 表示第 i 只螳螂的领地在离地高度 `[x, y]` 之间的主干上（`x < y`，闭区间）
- 螳螂数量范围：`[1, 50]`
- 领地坐标满足：`0 ≤ x < y ≤ 150`

## 输出描述

- 返回领地斗争结束后的领地信息二维数组
- 结果必须按领地坐标**升序**返回：正确示例 `[[3,7],[9,13]]`，错误示例 `[[9,13],[3,7]]`

---

## 示例

### 示例 1

```
输入：[[1,5],[4,6],[8,15]]
输出：[[1,6],[8,15]]
```

**说明**：第一只螳螂的领地 `[1,5]` 与第二只的 `[4,6]` 在高度 4~5 段重叠，发生冲突后领地合并为 `[1,6]`；`[8,15]` 与其他领地不重叠，保持不变。

### 示例 2

```
输入：[[3,7],[9,13]]
输出：[[3,7],[9,13]]
```

**说明**：两只螳螂的领地范围没有重叠，不会发生冲突，最终领地状态与初始一致。

### 示例 3

```
输入：[[1,4],[4,5]]
输出：[[1,5]]
```

**说明**：两只螳螂的领地在高度 4 处**边界接触**，也会触发冲突，领地合并为 `[1,5]`。

---

## 提示

- 本质是经典的**区间合并**问题：斗争的结果等价于把所有相交（含边界接触）的闭区间合并成一个大区间
- 先按**左端点升序**排序，才能保证从左到右一次扫描完成合并
- 重叠判定是本题关键：闭区间下 `x <= lastEnd` 即重叠/接触，需要合并；`x > lastEnd` 才开启新区间
- 合并时右端点取两者右端点的最大值：`lastEnd = max(lastEnd, y)`（注意"包含"关系，如 `[1,10]` 吞掉 `[2,3]`）
- 排序后结果天然按坐标升序，无需再排序

---

## 思路

### 核心思想：排序 + 线性扫描合并

把每只螳螂的领地看成一个**闭区间**。排序后相邻区间只可能出现两种关系：

- 当前区间左端点 `x <= lastEnd`：与已合并区间重叠或端点接触 → 合并，更新 `lastEnd = max(lastEnd, y)`
- 当前区间左端点 `x > lastEnd`：中间有间隙，不冲突 → 把已合并区间存入结果，开启新段

**逐步演示**（示例 1，`[[1,5],[4,6],[8,15]]`）：

```
按左端点排序后：[1,5] [4,6] [8,15]
取首段：start=1, lastEnd=5
[4,6]：x=4 <= 5 → 重叠合并，lastEnd=max(5,6)=6
[8,15]：x=8 > 6 → 无冲突，先输出 [1,6]，再开启新段 start=8,lastEnd=15
扫描结束：输出 [8,15]
结果：[[1,6],[8,15]]  ✓
```

**端点接触演示**（示例 3，`[[1,4],[4,5]]`）：

```
[4,5]：x=4 <= lastEnd=4 → 边界接触也算重叠，lastEnd=max(4,5)=5
结果：[[1,5]]  ✓
```

- 时间复杂度：\(O(n \log n)\)，排序主导，扫描为 \(O(n)\)
- 空间复杂度：\(O(n)\)，存储合并结果

## 代码

### 解法（Java，排序 + 区间合并）

```java
import java.util.*;

class Solution {
    public int[][] mantisTerritory(int[][] originalLand) {
        // 按左端点升序排序；左端点相同时按右端点升序
        Arrays.sort(originalLand, (a, b) ->
                a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);

        List<int[]> merged = new ArrayList<>();
        int start = originalLand[0][0];
        int lastEnd = originalLand[0][1];

        for (int i = 1; i < originalLand.length; i++) {
            int x = originalLand[i][0];
            int y = originalLand[i][1];
            if (x <= lastEnd) {
                // 闭区间重叠或边界接触 → 合并，右端点取较大值
                lastEnd = Math.max(lastEnd, y);
            } else {
                // 存在间隙 → 保存当前段，开启新段
                merged.add(new int[]{start, lastEnd});
                start = x;
                lastEnd = y;
            }
        }
        // 别忘了最后一段
        merged.add(new int[]{start, lastEnd});
        return merged.toArray(new int[0][]);
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n \log n)\)，排序 \(O(n \log n)\) + 线性扫描 \(O(n)\)
- **空间复杂度**：\(O(n)\)，合并结果列表最多 n 个区间

> 💡 **记忆**：**区间合并三件套——排序、扫描、`max` 右端点**。所有"势力范围/时间段/区间重叠"类题目都是这个套路。
>
> ⚠️ **易错**：① 闭区间边界接触也算重叠，判定条件是 `x <= lastEnd`，写成 `<` 会让示例 3 挂掉；② 合并右端点要用 `max`，防止大区间包含小区间时右端点被缩回去；③ 循环结束后要补存最后一段。
