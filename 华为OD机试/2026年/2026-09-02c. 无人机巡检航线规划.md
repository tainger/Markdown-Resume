# 2026-09-02c. 无人机巡检航线规划

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-09-02 | **标签**：动态规划、状态压缩 | **考点**：状态压缩 DP 求解旅行商问题（TSP）

## 题目描述

某电力公司使用无人机对 n 个电力塔进行巡检。每个电力塔 i 位于坐标 (xi, yi)，无人机从基地（坐标 (0,0)）出发，需要依次飞达每个电力塔完成巡检后结束任务，**无需返回基地**。

无人机同一时刻只能飞向一个电力塔，请规划巡检顺序，使无人机飞行的总距离最短（两个坐标点间按**曼哈顿距离**计算，即 |x1−x2| + |y1−y2|），输出最短总距离。

## 输入描述

- 参数 1：整数 n，电力塔数量，`1 ≤ n ≤ 15`
- 参数 2：二维整数数组，第 i 个元素 `[xi, yi]` 表示第 i 个电力塔的坐标，`0 ≤ xi, yi ≤ 200`

## 输出描述

- 输出最短总距离（整数）

---

## 示例

### 示例 1

```
输入：n = 3，towers = [[1,2],[3,1],[2,3]]
输出：8
```

**说明**：3 个电力塔 A(1,2)、B(3,1)、C(2,3)，基地 O(0,0)。

- 顺序 A→C→B：O→A 距离 |1|+|2|=3，A→C 距离 |1−2|+|2−3|=2，C→B 距离 |2−3|+|3−1|=3，总距离 3+2+3=8
- 顺序 A→B→C：O→A 距离 3，A→B 距离 |1−3|+|2−1|=3，B→C 距离 |3−2|+|1−3|=3，总距离 9
- 顺序 B→A→C：O→B 距离 4，B→A 距离 3，A→C 距离 2，总距离 9

其余顺序总距离均不小于 8，最短总距离为 8。

### 示例 2

```
输入：n = 2，towers = [[1,1],[2,2]]
输出：4
```

**说明**：2 个电力塔 A(1,1)、B(2,2)。

- 顺序 A→B：O→A 距离 2，A→B 距离 |1−2|+|1−2|=2，总距离 4
- 顺序 B→A：O→B 距离 4，B→A 距离 2，总距离 6

最短总距离为 4。

### 示例 3

```
输入：n = 1，towers = [[3,4]]
输出：7
```

**说明**：只有 1 个电力塔，无人机从基地直飞该塔：|3|+|4|=7，巡检结束无需返航。

## 提示

- 本题本质是**起点固定、终点开放**的旅行商问题（TSP）：每个塔恰好访问一次，求最短排列
- `n ≤ 15` 是状态压缩 DP 的典型信号：用二进制掩码（bitmask）表示"已访问塔集合"，状态数 \(2^n \cdot n\) 最大约 50 万
- 曼哈顿距离在飞行前全部预处理成距离矩阵，DP 转移时直接查表
- 起点固定为基地 (0,0)：初始状态是"从基地直飞第一座塔"
- 与经典 TSP 的区别：**不需要回到起点**，所以答案是所有 `dp[全1掩码][i]` 中的最小值，不用再加返航距离

---

## 思路

### 核心思想：状态压缩动态规划

定义 `dp[mask][i]`：已经访问过的塔集合为 `mask`（二进制第 k 位为 1 表示塔 k 已访问），且**最后停在塔 i** 时的最短总距离。

**初始状态**（第一站从基地直飞塔 i）：

```
dp[1 << i][i] = dist(基地, 塔i)
```

**状态转移**（从塔 i 飞往尚未访问的塔 j）：

```
dp[mask | (1<<j)][j] = min(dp[mask | (1<<j)][j],
                           dp[mask][i] + dist(塔i, 塔j))
```

**最终答案**：所有塔都已访问（`mask = (1<<n) - 1`）时，停在任意塔的距离最小值：

```
ans = min(dp[(1<<n)-1][i])，i ∈ [0, n)
```

**逐步演示**（示例 1，A(1,2)、B(3,1)、C(2,3)）：

```
距离矩阵（含基地 O）：
  O→A=3  O→B=4  O→C=5
  A→B=3  A→C=2  B→C=3

初始化：dp[001][A]=3，dp[010][B]=4，dp[100][C]=5
转移：
  dp[011][B] = dp[001][A]+A→B = 3+3=6   (A→B)
  dp[101][C] = dp[001][A]+A→C = 3+2=5   (A→C)
  dp[011][A] = dp[010][B]+B→A = 4+3=7   (B→A)
  dp[110][C] = dp[010][B]+B→C = 4+3=7   (B→C)
  dp[101][A] = dp[100][C]+C→A = 5+2=7   (C→A)
  dp[110][B] = dp[100][C]+C→B = 5+3=8   (C→B)
全集 111：
  A→C→B：dp[111][B] = dp[101][C]+C→B = 5+3=8  ✓ 最小
  A→B→C：dp[111][C] = dp[011][B]+B→C = 6+3=9
  B→A→C：dp[111][C] = dp[011][A]+A→C = 7+2=9
答案：8
```

- 时间复杂度：\(O(2^n \cdot n^2)\)，n=15 时约 700 万次转移，轻松通过
- 空间复杂度：\(O(2^n \cdot n)\)，约 50 万 int

## 代码

### 解法（Java，状态压缩 DP）

```java
import java.util.*;

class Solution {
    public int minPatrolDistance(int n, int[][] towers) {
        final int INF = Integer.MAX_VALUE / 2;

        // 预处理曼哈顿距离矩阵：下标 n 表示基地 (0,0)
        int[][] dist = new int[n + 1][n + 1];
        for (int i = 0; i < n; i++) {
            // 基地到塔 i
            dist[n][i] = dist[i][n] = Math.abs(towers[i][0]) + Math.abs(towers[i][1]);
            for (int j = 0; j < n; j++) {
                // 塔 i 到塔 j
                dist[i][j] = Math.abs(towers[i][0] - towers[j][0])
                           + Math.abs(towers[i][1] - towers[j][1]);
            }
        }

        int full = 1 << n;
        int[][] dp = new int[full][n];
        for (int[] row : dp) {
            Arrays.fill(row, INF);
        }

        // 初始：第一站从基地直飞塔 i
        for (int i = 0; i < n; i++) {
            dp[1 << i][i] = dist[n][i];
        }

        // 枚举所有已访问集合
        for (int mask = 1; mask < full; mask++) {
            for (int i = 0; i < n; i++) {
                // 塔 i 必须在集合中，且状态可达
                if ((mask & (1 << i)) == 0 || dp[mask][i] == INF) {
                    continue;
                }
                // 尝试飞往尚未访问的塔 j
                for (int j = 0; j < n; j++) {
                    if ((mask & (1 << j)) != 0) {
                        continue;
                    }
                    int nextMask = mask | (1 << j);
                    dp[nextMask][j] = Math.min(dp[nextMask][j],
                                               dp[mask][i] + dist[i][j]);
                }
            }
        }

        // 所有塔访问完毕，无需返回基地，取停在各塔的最小值
        int ans = INF;
        for (int i = 0; i < n; i++) {
            ans = Math.min(ans, dp[full - 1][i]);
        }
        return ans;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(2^n \cdot n^2)\)，掩码数 × 当前塔 × 目标塔
- **空间复杂度**：\(O(2^n \cdot n)\)，dp 表规模；n≤15 时约 49 万元素，可接受

> 💡 **记忆**：**看到 n ≤ 15~20 的排列最优问题，立刻想到状态压缩 DP**。`dp[mask][i]` 表示"走过 mask 这些点、最后停在 i"，转移就是"再走一步到没去过的 j"。
>
> ⚠️ **易错**：① 本题**不用返航**，答案直接取全集状态最小值，不要再加回基地的距离（经典 TSP 才需要）；② 初始状态是"基地→第一座塔"，不是 dp[0][0]；③ 距离矩阵把基地虚拟成第 n 个点，代码更统一；④ 用 `INF = Integer.MAX_VALUE/2` 防止加法溢出。
