# 2026-09-06a. 仓储货物有序出库

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-09-06

## 题目描述

某仓储中心有一个货物堆放区，货物编号按乱序堆叠存放，只能从顶部取货（后进先出）。管理员需要将货物按编号**从小到大**依次取出出库。

仓库设有 1 个临时区，可将主库顶部货物依次转移到临时区，临时区也为堆叠存放（后进先出）；主库或临时区顶部货物均可直接出库；主库→临时区、临时区→主库的搬运均计为一次"暂存"操作，而出库操作不计次数。

请计算至少需要多少次暂存操作，能保证所有货物按编号从小到大依次出库。

补充说明：

- 临时区有且只有一个
- 出库顺序必须是严格升序，每件出库货物的编号必须大于前一件
- 所有货物编号互不重复（可能为负数，编号不保证连续）
- 题目保证总能找到一种合法的操作方案完成有序出库

## 输入描述

- 参数 1：整数 n（`1 < n < 1000`），货物总数量
- 参数 2：整数数组 `[a1, a2, …, an]`（`-1000 < ai < 1000`），货物编号从左到右依次对应货堆**底部到顶部**

## 输出描述

- 一个整数，表示最少暂存操作次数

---

## 示例

### 示例 1

```
输入：n = 3，goods = [3,1,2]
输出：1
```

**说明**：货堆初始状态（底部→顶部）为 [3号, 1号, 2号]，顶部货物为 2 号；目标出库顺序 1号 → 2号 → 3号。

- 顶部是 2 号，但目标需要 1 号：将 2 号暂存到临时区（暂存次数 = 1）
- 主库顶部是 1 号：直接出库 → 已出库 [1号]
- 临时区顶部是 2 号：出库 → 已出库 [1号, 2号]
- 主库顶部是 3 号：出库 → 已出库 [1号, 2号, 3号]

最少暂存次数为 1。

### 示例 2

```
输入：n = 3，goods = [1,2,3]
输出：2
```

**说明**：货堆初始状态（底部→顶部）为 [1号, 2号, 3号]，顶部货物为 3 号。

- 顶部是 3 号，目标需要 1 号：将 3 号暂存（次数 = 1）
- 顶部是 2 号，目标需要 1 号：将 2 号暂存（次数 = 2）
- 主库顶部是 1 号：直接出库
- 临时区顶部是 2 号：出库
- 临时区顶部是 3 号：出库

最少暂存次数为 2。

### 示例 3

```
输入：n = 4，goods = [2,1,4,3]
输出：3
```

**说明**：货堆（底部→顶部）为 [2号, 1号, 4号, 3号]，顶部为 3 号。

- 目标 1 号：3 号暂存到临时区（1 次），4 号暂存到临时区（2 次），主库露出 1 号出库
- 目标 2 号：主库顶部即为 2 号，直接出库
- 目标 3 号：临时区顶部是 4 号（3 号被压在下面），需把 4 号倒回主库（3 次），临时区露出 3 号出库
- 目标 4 号：主库顶部即为 4 号，直接出库

最少暂存次数为 3。本示例说明：货物可能需要在两个栈之间**来回搬运**。

---

## 提示

- 把主库和临时区都看成**栈**：数组首元素是栈底、末元素是栈顶，只能操作栈顶
- 出库顺序固定为编号升序，等价于按排序后的顺序逐个"取目标货物 x"
- 目标 x 若在某个栈顶，直接出库（免费）；若被压住，**挡在它上面的货物别无去处**，只能搬到另一个栈——每搬一件计 1 次暂存
- 因为 x 是当前未出库的最小编号，压住 x 的货物编号都大于 x，都不能提前出库，所以搬运是**被迫且唯一**的，模拟出来的次数就是最少次数
- 用一个 `Set` 记录某货物当前是否在主库，可快速判断该去哪个栈里"挖"目标

---

## 思路

### 核心思想：贪心模拟——按升序找目标，被迫搬运挡路货物

将货物编号排序，得到出库目标序列。依次处理每个目标 x：

1. 主库栈顶 == x → 直接出库（0 次）
2. 临时区栈顶 == x → 直接出库（0 次）
3. x 埋在**主库**中：把主库栈顶货物依次搬到临时区，直到露出 x（每件 +1 次），再出库 x
4. x 埋在**临时区**中：把临时区栈顶货物依次倒回主库，直到露出 x（每件 +1 次），再出库 x

为什么这是最少次数？x 是当前未出库的最小货物，任何压住 x 的货物编号都大于 x，无法提前出库；而两个栈之外没有第三个存放点，所以挡路货物**只能**搬到另一个栈，搬运次数被目标位置唯一确定，不存在更省的选择。

**逐步演示**（示例 3，主库底部→顶部 [2,1,4,3]）：

```
目标 1：主库顶=3≠1 → 3 搬临时区(+1)，4 搬临时区(+2)，主库顶=1 出库
       主库=[2]，临时区(底→顶)=[3,4]
目标 2：主库顶=2 → 直接出库
目标 3：临时区顶=4≠3 → 4 倒回主库(+3)，临时区顶=3 出库
       临时区=[]，主库=[4]
目标 4：主库顶=4 → 直接出库
总暂存次数 = 3  ✓
```

- 时间复杂度：\(O(n^2)\)，每个目标最多搬运 O(n) 件（n<1000，约 100 万次操作）
- 空间复杂度：\(O(n)\)，两个栈和一个集合

## 代码

### 解法（Java，双栈贪心模拟）

```java
import java.util.*;

class Solution {
    public int orderlyOutbound(int n, int[] goods) {
        // 主库栈：goods[0] 为底部，goods[n-1] 为顶部
        Deque<Integer> mainStack = new ArrayDeque<>();
        Deque<Integer> tempStack = new ArrayDeque<>();
        Set<Integer> inMain = new HashSet<>();
        for (int v : goods) {
            mainStack.addLast(v);
            inMain.add(v);
        }

        // 出库目标顺序：编号严格升序
        int[] targets = goods.clone();
        Arrays.sort(targets);

        int moves = 0;
        for (int x : targets) {
            if (!mainStack.isEmpty() && mainStack.peekLast() == x) {
                // 主库顶部就是目标：直接出库
                mainStack.pollLast();
                inMain.remove(x);
            } else if (!tempStack.isEmpty() && tempStack.peekLast() == x) {
                // 临时区顶部就是目标：直接出库
                tempStack.pollLast();
            } else if (inMain.contains(x)) {
                // 目标埋在主库：把挡路货物依次暂存到临时区
                while (mainStack.peekLast() != x) {
                    int v = mainStack.pollLast();
                    tempStack.addLast(v);
                    inMain.remove(v);
                    moves++;
                }
                mainStack.pollLast(); // 目标出库
                inMain.remove(x);
            } else {
                // 目标埋在临时区：把挡路货物依次倒回主库
                while (tempStack.peekLast() != x) {
                    int v = tempStack.pollLast();
                    mainStack.addLast(v);
                    inMain.add(v);
                    moves++;
                }
                tempStack.pollLast(); // 目标出库
            }
        }
        return moves;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n^2)\)，n 个目标，每个目标最坏搬运 O(n) 件；排序 \(O(n \log n)\)
- **空间复杂度**：\(O(n)\)，两个栈各存 O(n) 件货物，集合 O(n)

> 💡 **记忆**：**"一个乱序栈 + 一个缓冲栈 + 规定顺序输出"= 双栈模拟**。目标元素被压住时，挡路元素只能去另一个栈，被迫搬运的次数就是最优解，直接模拟即可。
>
> ⚠️ **易错**：① 数组顺序是**底部→顶部**，栈顶是最后一个元素，用 `addLast/peekLast/pollLast`；② 目标可能埋在**临时区**（如示例 3 的 3 号），需要倒回主库，漏掉这个方向会出错；③ 出库操作不计数，只有两个栈之间的搬运才计数；④ 货物编号可能为负数且不连续，排序后才是出库顺序。
