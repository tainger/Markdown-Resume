# 2026-09-06b. 少儿爬山闯关积分游戏

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-09-06 | **标签**：动态规划 | **考点**：带"上一步状态"的线性 DP（爬楼梯变种）

## 题目描述

山路一共设有 n 个关卡，按 1∼n 顺序排列。小朋友当前位于 1 号关卡，必须按照关卡从小到大闯关，且必须到达最后第 n 号关卡才算寻宝成功。每个关卡都有对应的宝藏分值（可能为负数），经过当前关卡即可获得该关卡分值，分数持续累加。

移动规则：

- 从当前关卡，下一次只能在前方 **1 关**或者 **2 关**处打卡（即每次前进 1 步或 2 步）
- 限制规则：**不能连续两次都一次性跳 2 关**，违反该规则的路线无效

请求出所有合法路线中，能够收集到的最大累加总分。

## 输入描述

- 参数 1：整数 n，关卡数量，`1 ≤ n ≤ 20`
- 参数 2：整数数组，依次表示第 1∼n 关的宝藏分值，每关分值 `-999 ≤ val ≤ 999`

## 输出描述

- 输出一个整数，代表合法路线的最大累加得分

---

## 示例

### 示例 1

```
输入：n = 5，scores = [10,5,8,3,15]
输出：41
```

**说明**：

- 合法路线 1→2→3→4→5（没有跳 2 关）：总分 10+5+8+3+15 = 41
- 路线 1→3→5 连续两次跳 2 关，违规，不计入统计

### 示例 2

```
输入：n = 4，scores = [10,1,1,100]
输出：112
```

**说明**：

- 路线 1→2→3→4（跳 1、跳 1）：10+1+1+100 = 112
- 路线 1→3→4（跳 2、跳 1）：10+1+100 = 111
- 路线 1→2→4（跳 1、跳 2）：10+1+100 = 111

最大值为 112。

### 示例 3

```
输入：n = 3，scores = [10,-5,20]
输出：30
```

**说明**：

- 路线 1→2→3（跳 1、跳 1）：10+(−5)+20 = 25
- 路线 1→3（跳 2，只跳一次不违规）：10+20 = 30

跳 2 关可以直接跳过负分关卡，最大值为 30。

---

## 提示

- 这是爬楼梯问题的变种：每次走 1 步或 2 步，但**不允许连续走两个 2 步**
- 关键：状态中必须记录"上一步跳了几关"，否则无法判断下一步跳 2 关是否合法
- 定义两个 DP 状态：到达第 i 关且**最后一步跳 1 关**的最大得分、**最后一步跳 2 关**的最大得分
- 最后一步跳 1 关：上一关无论跳 1 还是跳 2 都合法，取两者较大值
- 最后一步跳 2 关：上一跳必须是跳 1 关（防止连续跳 2），只能从"跳 1 关"状态转移
- 关卡分值可能为负，但 1 号关和 n 号关必须经过（起点与终点）

---

## 思路

### 核心思想：双状态线性 DP

定义（关卡按 0 基下标，第 1 关对应下标 0）：

- `one[i]`：到达第 i 关，且**最后一步跳 1 关**时的最大得分
- `two[i]`：到达第 i 关，且**最后一步跳 2 关**时的最大得分

转移方程：

```
one[i] = max(one[i-1], two[i-1]) + scores[i]
         // 跳 1 关而来：前一关两种状态都合法

two[i] = one[i-2] + scores[i]   (i ≥ 2)
         // 跳 2 关而来：上一跳必须是跳 1 关，否则连续两个 2 步违规
```

初始化：第 1 关是起点，获得 `scores[0]`。把起点视为"上一步跳 1 关"状态（`one[0] = scores[0]`），这样从起点直接跳 2 关到第 3 关是合法的；`two[0]` 不可达。

答案：`max(one[n-1], two[n-1])`（到达终点的两种方式取较大值）。

**逐步演示**（示例 2，[10,1,1,100]）：

```
one[0]=10, two[0]=-∞
i=1（第2关）：one[1]=max(10,-∞)+1=11；two[1] 不可达
i=2（第3关）：one[2]=max(11,-∞)+1=12；two[2]=one[0]+1=11
i=3（第4关）：one[3]=max(12,11)+100=112；two[3]=one[1]+100=111
答案 max(112,111)=112  ✓
```

- 时间复杂度：\(O(n)\)，每关常数次转移
- 空间复杂度：\(O(n)\)（可滚动优化到 \(O(1)\)）

## 代码

### 解法（Java，双状态动态规划）

```java
import java.util.*;

class Solution {
    public int maxClimbScore(int n, int[] scores) {
        final int NEG = Integer.MIN_VALUE / 2; // 不可达状态

        // one[i]：到达第 i 关且最后一步跳 1 关的最大得分
        // two[i]：到达第 i 关且最后一步跳 2 关的最大得分
        int[] one = new int[n];
        int[] two = new int[n];
        Arrays.fill(one, NEG);
        Arrays.fill(two, NEG);

        // 起点第 1 关：视为“上一步跳 1 关”，允许下一步直接跳 2 关
        one[0] = scores[0];

        for (int i = 1; i < n; i++) {
            // 最后一步跳 1 关：从第 i-1 关的任一状态转移
            one[i] = Math.max(one[i - 1], two[i - 1]) + scores[i];
            // 最后一步跳 2 关：只能从第 i-2 关“上一步跳 1 关”的状态转移
            if (i >= 2) {
                two[i] = one[i - 2] + scores[i];
            }
        }

        // 终点可由跳 1 关或跳 2 关到达
        return Math.max(one[n - 1], two[n - 1]);
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n)\)，单趟扫描
- **空间复杂度**：\(O(n)\)，两个长度 n 的 DP 数组（n≤20，无需滚动优化；实际可优化为 \(O(1)\)）

> 💡 **记忆**：**当转移合法性依赖"上一步动作"时，就把动作拆进状态**。本题用 `one/two` 两个状态区分最后一步跳 1 还是跳 2，"不能连续跳 2"的约束自然体现在 `two[i]` 只能从 `one[i-2]` 转移。
>
> ⚠️ **易错**：① `two[i]` 只能从 `one[i-2]` 转移，从 `two[i-2]` 转移就是连续两次跳 2 关，违规；② 起点第 1 关必须计入得分，且把它归为 `one` 状态，否则"第 1 关直接跳到第 3 关"的合法路线会漏掉；③ n=1 时答案就是 `scores[0]`。
