# 2026-09-06c. 嵌入式传感器寄存器数据解析

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-09-06 | **标签**：位运算 | **考点**：位域提取（移位 + 掩码）、奇偶校验、同或运算、32 位有符号解释

## 题目描述

系统从传感器的某个寄存器读取一个 32 位的 int 型整数 packet。请按如下要求解析输入数据，然后按十进制格式输出结果。

该数据的二进制结构定义如下：

- **bit0（最低位）**：状态。1 表示传感器正常，0 表示传感器故障
- **bit1∼bit2**：寄存器 ID。取值 0∼3
- **bit3**：数据类型。1 表示变长数据类型，0 表示固定长度数据类型
- **bit4∼bit11**：数据修正因子
- **bit12∼bit15**：数据有效长度。取值 0∼15，数据类型为 1 时才生效
- **bit16∼bit30**：数据。数据类型为 1 时，从低到高依据数据有效长度确定实际有效数据位；数据类型为 0 时，全部为有效数据位
- **bit31**：数据奇偶校验位。数据中的所有有效数据位与奇偶校验位中 1 的个数为偶数，表示数据校验通过；否则不通过

解析流程：

1. 检查状态，如果传感器故障（状态为 0），返回 −1
2. 检查数据奇偶校验是否通过，不通过则返回 −2
3. 数据类型为 1 时，数据有效长度如果为 0，则返回 −3
4. 寄存器 ID 为 0 时：返回有效数据与数据修正因子按位**与**的结果
5. 寄存器 ID 为 1 时：返回有效数据与数据修正因子按位**或**的结果
6. 寄存器 ID 为 2 时：返回有效数据与数据修正因子按位**异或**的结果
7. 寄存器 ID 为 3 时：返回有效数据与数据修正因子按位**同或**的结果

注：解析流程中 4、5、6、7 步骤的结果返回前需要和 `0x0FFFFFFFF` 取与。

## 输入描述

- 参数：一个 32 位整型数值 packet

## 输出描述

- 按十进制格式输出解析结果（错误码 −1/−2/−3，或运算结果）

## 示例

### 示例 1

```
输入：packet = 343873
输出：4
```

**说明**：正常解析（寄存器 ID=0，按位与运算）。

输入 packet = 0x00053F41（十进制 343873），二进制：`0000 0000 0000 0101 0011 1111 0100 0001`。

字段分析：

- bit0：1（状态正常）
- bit1∼bit2：00（寄存器 ID=0）
- bit3：0（固定长度类型）
- bit4∼bit11：`1111 0100` = 0xF4 = 244（修正因子）
- bit12∼bit15：0011（固定长度下不生效）
- bit16∼bit30：`000 0000 0000 0101` = 0x0005（有效数据）
- bit31：0（校验位）

解析流程：

- 状态检查：状态为 1，正常
- 数据提取：数据类型为 0，15 位全部有效，实际数据为 0x0005
- 奇偶校验：数据 0x0005（二进制 101）有 2 个 1，校验位为 0，总数 2+0=2 为偶数，校验通过
- 运算：寄存器 ID 为 0，执行按位与：0x05 & 0xF4

```
  0000 0101  (5)
& 1111 0100  (244)
= 0000 0100  = 4
```

- 结果与 0x0FFFFFFFF 取与后为 4，输出 4。

### 示例 2

```
输入：packet = 0
输出：-1
```

**说明**：packet = 0x00000000，bit0 = 0 表示传感器故障，直接返回 −1。

### 示例 3

```
输入：packet = 2147827521
输出：-2
```

**说明**：奇偶校验失败。

packet = 0x80053F41 = 0x80000000 + 343873，与示例 1 相比仅 bit31 被置 1（校验位为 1），其余字段相同：状态正常、有效数据仍为 0x0005（2 个 1）。

- 有效数据 1 的个数：2
- 奇偶校验位：1
- 总数 2+1=3 为**奇数**，校验不通过，返回 −2。

## 提示

- **位域提取三板斧**：`(u >> 起始位) & 掩码`。如 bit1∼bit2 是 `(u >> 1) & 0b11`，bit4∼bit11 是 `(u >> 4) & 0xFF`
- 先用 `packet & 0xFFFFFFFFL` 把输入归一化为 **32 位无符号**（用 long 承载），避免 Java 中负数右移补 1 的问题
- **变长数据**的有效位掩码：`(1 << dataLen) - 1`（dataLen=0 时掩码为 0，有效数据为 0）；**固定长度**时 bit16∼bit30 共 15 位全部有效
- 奇偶校验统计的是**有效数据位**（不是原始 15 位）与 bit31 中 1 的总数，奇数则失败，用 `Long.bitCount()` 数 1
- **同或（XNOR）= 异或取反**：`~(a ^ b)`；运算结果先 `& 0xFFFFFFFFL` 再强转 int，即可正确得到 32 位有符号十进制值
- 错误码返回有严格顺序：先状态（−1）→ 再校验（−2）→ 再变长长度（−3），不能颠倒

---

## 思路

### 核心思想：移位 + 掩码提取各字段，按流程顺序校验与运算

1. **归一化**：`u = packet & 0xFFFFFFFFL`，按 32 位无符号解释
2. **提取字段**：

   | 字段 | 提取表达式 |
   |---|---|
   | 状态 status | `u & 1` |
   | 寄存器 ID regId | `(u >> 1) & 3` |
   | 数据类型 dataType | `(u >> 3) & 1` |
   | 修正因子 factor | `(u >> 4) & 0xFF` |
   | 有效长度 dataLen | `(u >> 12) & 0xF` |
   | 原始数据 rawData | `(u >> 16) & 0x7FFF` |
   | 校验位 parity | `(u >> 31) & 1` |

3. **状态校验**：status == 0 → 返回 −1
4. **提取有效数据**：变长类型 `validData = rawData & ((1 << dataLen) - 1)`（dataLen=0 时掩码取 0）；固定类型 `validData = rawData`
5. **奇偶校验**：`bitCount(validData) + parity` 为奇数 → 返回 −2
6. **变长长度校验**：dataType==1 且 dataLen==0 → 返回 −3
7. **按寄存器 ID 运算**：0 与、1 或、2 异或、3 同或（`~(a ^ b)`）
8. 结果 `& 0xFFFFFFFFL` 后强转 int 输出

**逐步演示**（示例 1，packet = 0x00053F41）：

```
u = 0x00053F41
status=1, regId=0, dataType=0, factor=0xF4=244, dataLen=3, rawData=0x0005, parity=0
状态正常 → dataType=0 固定长度 → validData = 0x0005
bitCount(5)=2，parity=0，2+0=2 偶数 → 校验通过
regId=0 → 0x05 & 0xF4 = 0x04 = 4
& 0xFFFFFFFF 后强转 int → 4  ✓
```

- 时间复杂度：\(O(1)\)，纯位运算
- 空间复杂度：\(O(1)\)

## 代码

### 解法（Java，位运算解析）

```java
class Solution {
    public int parseRegister(int packet) {
        // 先按 32 位无符号理解（用 long 承载，避免负数右移补 1）
        long u = packet & 0xFFFFFFFFL;

        // ---- 提取各字段（右移 + 掩码）----
        long status   = u & 1L;              // bit0：状态
        long regId    = (u >>> 1) & 3L;      // bit1~bit2：寄存器 ID
        long dataType = (u >>> 3) & 1L;      // bit3：数据类型
        long factor   = (u >>> 4) & 0xFFL;   // bit4~bit11：修正因子（8 位）
        long dataLen  = (u >>> 12) & 0xFL;   // bit12~bit15：有效长度（4 位）
        long rawData  = (u >>> 16) & 0x7FFFL;// bit16~bit30：数据（15 位）
        long parity   = (u >>> 31) & 1L;     // bit31：奇偶校验位

        // 1. 状态检查：传感器故障
        if (status == 0) {
            return -1;
        }

        // 2. 提取有效数据
        long validData;
        if (dataType == 1) {
            // 变长类型：按有效长度取低位，dataLen=0 时掩码为 0
            long mask = dataLen == 0 ? 0L : ((1L << dataLen) - 1);
            validData = rawData & mask;
        } else {
            // 固定长度：15 位全部有效
            validData = rawData;
        }

        // 3. 奇偶校验：有效数据位与校验位中 1 的总数必须为偶数
        if ((Long.bitCount(validData) + parity) % 2 == 1) {
            return -2;
        }

        // 4. 变长类型但有效长度为 0
        if (dataType == 1 && dataLen == 0) {
            return -3;
        }

        // 5. 按寄存器 ID 执行对应位运算
        long result;
        switch ((int) regId) {
            case 0:  // 按位与
                result = validData & factor;
                break;
            case 1:  // 按位或
                result = validData | factor;
                break;
            case 2:  // 按位异或
                result = validData ^ factor;
                break;
            default: // 按位同或 = 异或取反
                result = ~(validData ^ factor);
                break;
        }

        // 结果与 0xFFFFFFFF 取与后，按 32 位有符号整数解释
        result &= 0xFFFFFFFFL;
        return (int) result;
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(1)\)，全部为常数次位运算
- **空间复杂度**：\(O(1)\)，仅用若干 long 变量

> 💡 **记忆**：**位域解析 = `(值 >> 起始位) & 掩码`**。先画清楚每个字段占哪几位，再逐个提取；校验类题目严格按题面顺序返回错误码。
>
> ⚠️ **易错**：① Java 的 int 负数右移是算术右移（补符号位），务必先 `& 0xFFFFFFFFL` 转 long 无符号再移位，且用 `>>>` 更稳妥；② 奇偶校验数的是**有效数据位**（变长时先截掩码）而非原始 15 位；③ 同或不要写错，XNOR 就是 `~(a ^ b)`；④ 最终结果要 `& 0xFFFFFFFFL` 再强转 int，才能把高于 32 位的取反位去掉并正确解释负数。
