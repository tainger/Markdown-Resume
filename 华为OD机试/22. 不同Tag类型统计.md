# 22. 不同Tag类型统计（2026 新系统）

> **难度**：🟡 中等 | **分值**：100 | **卷次**：新系统 2026-07-22 | **标签**：数组解析、哈希 | **考点**：TLV 协议解析

## 题目描述

给定一个数组，元素为数字，数组内容表示多个连续的 **TLV（Tag-Length-Value）** 块。

单个 TLV 具备以下特征：

- **tag**：占位 1 个数组元素，代表类型；
- **length**：占位 1 个数组元素，代表长度，且长度值 > 0；
- **value**：占位后面连续的 `length` 个数组元素；
- **TLV 长度限制**：单个 TLV 所占的数组元素必须是 **4 的倍数**，不足部分可用任意数字补齐；
- 数值取值范围在 [-99, 99] 内（版本差异：部分题目为 0~99，以实际为准）。

例如单个 TLV 数组 `2, 1, 3, 0`：第一个数字 `2` 是 tag，第二个 `1` 是 length，第三个 `3` 是 value，第四个 `0` 是补齐位。

请解析整个数组，输出**存在多少种不同类型的 tag**；若解析过程出现数组元素不符合规范，则输出错误码（流传版本为 `0` 或 `-1`，以题目为准）。

> 新系统（力扣模式）：无需处理输入输出，直接实现函数。

**函数签名**：

```java
// 返回不同 tag 的种类数；格式错误返回 -1（部分版本返回 0，以题目为准）
public int countTags(int[] arr)
```

## 示例

**示例 1**（格式错误）

```
输入：
[2, 1, 3, 0, 3, 1, 3, 0, 0]
输出：
-1（格式错误）
```

**解释**：前 8 个元素可解析为 2 个 TLV（各占 4 位），剩余 1 个元素 `0` 无法凑成完整的 TLV → 解析失败。

**示例 2**

```
输入：
[2, 1, 3, 0, 3, 1, 3, 0]
输出：
2
```

**解释**：格式正确，2 个 TLV 块，tag 分别为 2、3 → 共 2 种类型。

## 提示

- 数组长度 ≤ 10000，TLV 总数 ≤ 1000；
- 单个 TLV 的**实际占位** = `2 + length`，补齐到 4 的倍数：`((2 + length + 3) / 4) * 4`；
- 解析失败的场景：length ≤ 0、越界、取值超出范围、剩余元素不足以构成 TLV；
- 用 `HashSet` 收集 tag 自动去重。

---

## 思路

### 核心思想

**指针扫描 + 长度补齐 + 集合去重**：

```
index = 0
while index < n:
  1. 若剩余 < 2 → 格式错误（连 length 都没有）
  2. length = arr[index+1]; 若 length <= 0 → 格式错误
  3. blockLen = ((2 + length + 3) / 4) * 4    ← 补齐到 4 的倍数
  4. 若 index + blockLen > n → 越界 → 格式错误
  5. 校验块内所有元素在取值范围内；否则格式错误
  6. tag 集合加入 arr[index]
  7. index += blockLen
最后 index == n → 返回集合大小
```

**为什么是 `((2 + length + 3) / 4) * 4`**：原始占用 = tag(1) + length(1) + value(length) = `2 + length`，向上取整到 4 的倍数 = `ceil((2+length)/4)*4`，整数写法即上式。

**逐步演示**（示例 2，`2,1,3,0,3,1,3,0`）：

```
index=0: length=1 → blockLen = ((2+1+3)/4)*4 = 4 → 块 [2,1,3,0] ✓
         tag=2 入集合；index=4
index=4: length=1 → blockLen = 4 → 块 [3,1,3,0] ✓
         tag=3 入集合；index=8 == n ✓
集合 {2, 3} → 输出 2 ✓
```

- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(k)\)，k 为不同 tag 数

### 解法（Java，TLV 解析）

```java
import java.util.*;

public class Main {
    public int countTags(int[] arr) {
        Set<Integer> tags = new HashSet<>();
        int n = arr.length;
        int idx = 0;

        while (idx < n) {
            if (idx + 1 >= n) return -1;            // 连 length 都没有

            int length = arr[idx + 1];
            if (length <= 0) return -1;             // length 必须 > 0

            int blockLen = ((2 + length + 3) / 4) * 4;   // 补齐到 4 的倍数
            if (idx + blockLen > n) return -1;      // 越界

            // 校验块内取值（范围以题目为准）
            for (int i = idx; i < idx + blockLen; i++) {
                if (arr[i] < -99 || arr[i] > 99) return -1;
            }

            tags.add(arr[idx]);                     // tag 去重收集
            idx += blockLen;                        // 跳到下一个 TLV
        }
        return tags.size();
    }
}
```

> 💡 记忆：**协议解析类题 = 指针扫描 + 块长计算 + 边界校验**，三个校验点（length 合法性 / 越界 / 取值）一个都不能少。
>
> ⚠️ 格式错误的返回码在不同流传版本里是 `0` 或 `-1`，考试时注意题目说明；本解用 `-1`，改一处即可。
