# 24. 寻找孤立水站（2026 新系统）

> **难度**：🟡 中等 | **分值**：100 | **卷次**：新系统 2026-05-10 | **标签**：图、BFS | **考点**：多源可达性

## 题目描述

城市供水管道由若干个连接外部的**源头水站**，以及内部水站、水管组成。全市共有 n 个水站，编号 0 至 n-1。供水网络由若干管道连接，管道分两类：

- **单向管道（Type 0）**：水流只能从水站 u 流向水站 v；
- **双向管道（Type 1）**：水流可在 u 和 v 之间双向流动。

受战争影响，部分供水管道破裂导致部分水站无法获得供水，称为**孤立站**。假设**源头站一定有水（非孤立站）**，请根据各个水站的联通情况，输出孤立站列表，**从小到大排列**。

> 新系统（力扣模式）：无需处理输入输出，直接实现函数。

**函数签名**：

```java
// n: 水站数量（编号 0~n-1）
// sources: 源头水站编号数组
// pipes: [u, v, type] 数组，type=0 单向 u→v，type=1 双向
// 返回孤立站编号列表（升序）；无孤立站返回空列表
public List<Integer> findIsolated(int n, int[] sources, int[][] pipes)
```

## 示例

**示例 1**

```
输入：
n = 5, sources = [1], pipes = [[1,0,0],[1,2,0]]
输出：
[3, 4]
```

**解释**：1 号为源头站，单向流向 0 和 2；3、4 无水到达 → 孤立站 [3,4] ✓

**示例 2**

```
输入：
n = 5, sources = [0,1], pipes = [[0,2,0],[0,3,0],[4,3,0]]
输出：
[4]
```

**解释**：0、1 为源头；0 单向流向 2、3；`4 → 3` 是单向，但**没有水站向 4 供水** → 4 是孤立站 ✓

**示例 3**

```
输入：
n = 5, sources = [0], pipes = [[0,1,1],[0,2,1],[3,2,1],[4,2,1]]
输出：
[]
```

**解释**：双向管道可反向流动，0 → 1、2 → 3、4 全部可达 → 无孤立站 ✓

## 提示

- 本质是**有向图可达性**：从所有源头站出发能到达的站都有水；
- 双向管道 = 加**两条**有向边；
- 多源 BFS：所有源头站一起入队；
- 结果 = 遍历 0~n-1 中 visited 为 false 的编号（天然升序）。

---

## 思路

### 核心思想

**邻接表建图 + 多源 BFS**：

```
1. 建图：单向管道加一条边 u→v；双向管道加两条边 u→v、v→u
2. 所有源头站入队并标记 visited（源头一定有水）
3. BFS 沿水流方向扩展，标记所有能获得供水的站
4. 遍历 0~n-1：未被标记的编号 → 孤立站（遍历顺序天然升序）
```

**为什么单向边方向不能反**：示例 2 中 `4 → 3` 只能从 4 流向 3，水无法从 3 逆流回 4，所以 4 孤立——方向错了就全错。

**逐步演示**（示例 2）：

```
图: 0→2, 0→3, 4→3；源头 {0,1}
BFS 从 0、1 出发: 0 → 2、3；1 无出边；4 无人可达
visited = {0,1,2,3}；未访问: {4} → [4] ✓
```

### BFS vs DFS：本题两者等价

本题只需判断**「从源头出发能到达哪些点」**（纯可达性），不关心路径长度、层次或顺序，因此 **BFS 与 DFS 完全等价**，时间空间都是 \(O(n+m)\)，随便选。默认写 BFS 的三点考量：

| 原因 | 说明 |
|:---|:---|
| **多源天然契合** | 多个源头站可一起入队，一轮 BFS 全覆盖；DFS 则要 `for (s : sources) dfs(s)` 逐个起点跑 |
| **不会爆栈** | 递归 DFS 深度最坏 \(O(n)\)，链状大图可能栈溢出；BFS 用显式队列，再深也稳 |
| **判环无关** | 本题不需判环 / 拓扑序，选写起来最顺的即可 |

> ⚠️ **BFS/DFS 不能随便换的场景**：要**最短路径/最少步数** → 必须 BFS（无权图逐层保证最短）；要**拓扑序 / 三色判有向环** → 天然 DFS 或 Kahn；要**回溯枚举所有路径** → 用 DFS。本题只要「可达 or 不可达」一个 bool，不涉及以上任何一种，故两者皆可。

- 时间复杂度：\(O(n + m)\)（m 为管道数）
- 空间复杂度：\(O(n + m)\)

### 解法（Java，多源 BFS）

```java
import java.util.*;

public class Main {
    public List<Integer> findIsolated(int n, int[] sources, int[][] pipes) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());

        for (int[] p : pipes) {
            int u = p[0], v = p[1], type = p[2];
            graph.get(u).add(v);
            if (type == 1) graph.get(v).add(u);   // 双向再加反向边
        }

        boolean[] visited = new boolean[n];
        Queue<Integer> queue = new ArrayDeque<>();
        for (int s : sources) {                   // 多源入队
            if (!visited[s]) {
                visited[s] = true;
                queue.offer(s);
            }
        }

        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int v : graph.get(u)) {
                if (!visited[v]) {
                    visited[v] = true;
                    queue.offer(v);
                }
            }
        }

        List<Integer> ans = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (!visited[i]) ans.add(i);          // 升序收集孤立站
        }
        return ans;
    }
}
```

> 💡 记忆：**「从若干起点出发能到达哪些点」→ 多源 BFS**；有向边方向按题意严格建，双向 = 两条边。
>
> ⚠️ 源头站可能有重复/也可能包含孤立判定范围，先入队 + visited 去重即可。

### 解法二（Java，多源 DFS）

把「可达标记」从队列扩展换成递归下探即可，建图与升序收集逻辑完全不变；多源就是**逐个源头起 DFS**。

```java
import java.util.*;

public class Main {
    List<List<Integer>> graph;
    boolean[] visited;

    public List<Integer> findIsolated(int n, int[] sources, int[][] pipes) {
        graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] p : pipes) {
            int u = p[0], v = p[1], type = p[2];
            graph.get(u).add(v);
            if (type == 1) graph.get(v).add(u);   // 双向加反向边
        }

        visited = new boolean[n];
        for (int s : sources) {                   // 多源：逐个源头起 DFS
            if (!visited[s]) dfs(s);
        }

        List<Integer> ans = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (!visited[i]) ans.add(i);          // 升序收集孤立站
        }
        return ans;
    }

    void dfs(int u) {
        visited[u] = true;
        for (int v : graph.get(u)) {
            if (!visited[v]) dfs(v);
        }
    }
}
```

> 💡 与 BFS 版结果**完全一致**：都是从源头集合出发标记可达点，最后收集未标记编号。差别仅在扩展方式（队列 vs 递归栈）。
>
> ⚠️ 递归深度最坏 \(O(n)\)，`n` 很大又是链状图时可能栈溢出；这种场景优先用 BFS，或把 DFS 改为显式栈迭代。
