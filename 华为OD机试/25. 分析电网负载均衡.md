# 25. 分析电网负载均衡（2026 新系统）

> **难度**：🟡 中等 | **分值**：200 | **卷次**：新系统 2026-06-14 | **标签**：并查集 | **考点**：连通分量 + 组内统计

## 题目描述

某电力公司管理 N 个变电站节点（编号 0~N-1），节点间通过 M 条输电线路连接，**相连节点属于同一供电区**。定义**供电区的不均衡度 =（区内最大负载 - 最小负载）× 节点数**。

请找出**不均衡度最大**的供电区，输出其不均衡度；若**无有效供电区**（节点数 < 2 或 M = 0），输出 **-1**。

> 新系统（力扣模式）：无需处理输入输出，直接实现函数。

**函数签名**：

```java
// loads: 节点负载数组（长度 N）
// edges: 输电线路二维数组，每行 [u, v] 表示两节点相连
// 返回最大不均衡度；无有效供电区返回 -1
public int maxImbalance(int[] loads, int[][] edges)
```

## 示例

**示例 1**

```
输入：
loads = [100, 200, 150, 50, 300], edges = [[0,1],[1,2],[3,4]]
输出：
500
```

**解释**：

```
供电区 A: 节点 {0,1,2}，负载 [100,200,150] → (200-100)×3 = 300
供电区 B: 节点 {3,4}，负载 [50,300]       → (300-50)×2 = 500
B 更大 → 输出 500 ✓
```

**示例 2**

```
输入：
loads = [80, 90, 80, 90], edges = [[0,1],[1,2],[2,3]]
输出：
40
```

**解释**：4 个节点连成 1 个供电区 → (90-80)×4 = 40 ✓

**示例 3**

```
输入：
loads = [100, 200, 300], edges = []
输出：
-1
```

**解释**：M = 0，每个节点独立，无有效供电区 → -1 ✓

## 提示

- `1 ≤ N ≤ 100`，`0 ≤ M ≤ N×(N-1)/2`，`0 ≤ loads[i] ≤ 10000`，无重复边；
- 供电区 = 图的**连通分量**（并查集天然适配）；
- 只有**节点数 ≥ 2** 的分量才算有效供电区；
- 用 `long` 计算不均衡度防溢出（负载差 × 节点数最大 10⁴ × 100）。

---

## 思路

### 核心思想

**并查集合并相连节点 → 按根分组统计 max/min/节点数**：

```
1. 初始化并查集（N 个节点各自独立）
2. 遍历 edges：union(u, v)
3. 分组：根 → {最大负载, 最小负载, 节点数}
4. 对每组（节点数 >= 2）：
   不均衡度 = (max - min) × 节点数，更新答案
5. 无任何有效供电区 → -1
```

**为什么并查集**：只需「是否连通」与连通分量统计，不需要路径本身，并查集最简洁（连通分量计数类问题首选）。

**逐步演示**（示例 1）：

```
union(0,1), union(1,2) → {0,1,2}；union(3,4) → {3,4}
组 A: max=200, min=100, 节点数=3 → (200-100)×3 = 300
组 B: max=300, min=50,  节点数=2 → (300-50)×2 = 500
答案 = max(300, 500) = 500 ✓
```

- 时间复杂度：\(O(N + M \cdot \alpha(N))\)（\(\alpha\) 近似常数）
- 空间复杂度：\(O(N)\)

### 解法（Java，并查集）

```java
import java.util.*;

public class Main {
    static class DSU {
        int[] parent;
        DSU(int n) {
            parent = new int[n];
            for (int i = 0; i < n; i++) parent[i] = i;
        }
        int find(int x) {
            while (parent[x] != x) {
                parent[x] = parent[parent[x]];   // 路径压缩
                x = parent[x];
            }
            return x;
        }
        void union(int a, int b) { parent[find(a)] = find(b); }
    }

    public int maxImbalance(int[] loads, int[][] edges) {
        int n = loads.length;
        DSU dsu = new DSU(n);
        for (int[] e : edges) dsu.union(e[0], e[1]);

        // root -> [max, min, count]
        Map<Integer, long[]> groups = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int root = dsu.find(i);
            long[] g = groups.computeIfAbsent(root, k -> new long[]{Long.MIN_VALUE, Long.MAX_VALUE, 0});
            g[0] = Math.max(g[0], loads[i]);
            g[1] = Math.min(g[1], loads[i]);
            g[2]++;
        }

        long ans = -1;
        for (long[] g : groups.values()) {
            if (g[2] < 2) continue;              // 节点数 < 2 无效
            ans = Math.max(ans, (g[0] - g[1]) * g[2]);
        }
        return (int) ans;
    }
}
```

> 💡 记忆：**「连通分量 + 分量内统计」= 并查集 + Map<根, 统计信息>**，先合并、再分组、后统计。
>
> ⚠️ 注意「无有效供电区 → -1」：示例 3 中 M=0 时没有任何组节点数 ≥ 2，ans 保持 -1。
