# 27. 空间占用计算

> **难度**：🟡 中等 | **分值**：100 | **卷次**：新系统 2026-04-01 | **标签**：字符串解析、哈希 | **考点**：路径前缀统计

## 题目描述

员工 A 的磁盘空间经常被耗尽，需要找到占用空间最大的目录或文件，然后决定清理。给定某一目录，统计该目录内**一级子目录和文件**的占用空间，返回**占用空间最大的项**。

规则说明：

1. **目录占用空间** = 其内部所有文件 Size 的总和，且**目录本身 Size 为 0**；
2. 目录深度不高于 7 层，目录或文件名总长度不超过 128 字节；
3. 当存在多个子项占用空间均为最大时，多个子项**按字符升序排列**；
4. 目标目录不在文件系统中时（输入路径前缀匹配不到任何路径），返回**空列表**。

**函数签名**：

```java
// targetDir: 目标目录（如 "/dir1/dir2-1"）
// files: 文件系统内的文件路径列表
// sizes: 与 files 一一对应的文件 Size 列表
// 返回占用最大的项（多个按字符升序）；无匹配返回空列表
public List<String> maxOccupied(String targetDir, String[] files, int[] sizes)
```

## 示例

```
输入：
targetDir = "/dir1/dir2-1"
files = ["/dir0/dir1-1/file1-1", "/dir1/dir1-1/file1-1",
         "/dir1/dir2-1/file3-1", "/dir1/dir2-1/file3-2",
         "/dir1/dir2-1/file3-3"]
sizes = [8192, 81920, 2048, 8192, 1024]
输出：
["file3-2"]
```

**解释**：

```
目标目录 /dir1/dir2-1 的一级子项只有 3 个文件：
  file3-1 → 2048
  file3-2 → 8192   ← 最大
  file3-3 → 1024
/dir1/dir1-1/file1-1（81920）不在目标目录下，不参与统计 ✓
```

---

## 提示

- 「一级子项」= 路径去掉 `targetDir/` 前缀后的**第一段**；
- 目录占用 = 该目录前缀下**所有文件 size 之和**（按前缀累加即可，无需建树）；
- 只统计以 `targetDir + "/"` 开头的文件；
- 最大值可能并列，按字符串升序输出全部。

---

## 思路

### 核心思想

**路径前缀匹配 + 按首段聚合累加**：

```
1. 对每个文件路径：
   若以 targetDir + "/" 开头 → 属于目标目录
   去掉前缀后取第一段 → 一级子项名称
2. 聚合: Map<一级子项, size 累加和>
   （文件 → 自身 size；目录 → 该目录下所有文件 size 之和，前缀累加天然实现）
3. 找出最大值；并列多个 → 按字符串升序
4. 一个都没匹配到 → []
```

**为什么不需要建目录树**：目录占用 = 内部所有文件总和，把「同目录前缀」的文件 size 累加就是该目录的占用；文件直接就是自身的 size。一级子项的提取只需取首段路径。

**逐步演示**（示例）：

```
匹配前缀 "/dir1/dir2-1/"：
  /dir1/dir2-1/file3-1 → 首段 "file3-1" → +2048
  /dir1/dir2-1/file3-2 → 首段 "file3-2" → +8192
  /dir1/dir2-1/file3-3 → 首段 "file3-3" → +1024
最大值 8192 → ["file3-2"] ✓
```

- 时间复杂度：\(O(F \cdot L)\)（F 为文件数，L 为路径长度）
- 空间复杂度：\(O(K)\)（K 为一级子项数）

### 解法（Java，前缀聚合）

```java
import java.util.*;

class Solution {
    public List<String> maxOccupied(String targetDir, String[] files, int[] sizes) {
        String prefix = targetDir + "/";
        Map<String, Long> sizeMap = new HashMap<>();

        for (int i = 0; i < files.length; i++) {
            if (!files[i].startsWith(prefix)) continue;  // 不在目标目录下
            String rest = files[i].substring(prefix.length());
            int slash = rest.indexOf('/');
            String item = (slash == -1) ? rest : rest.substring(0, slash); // 一级子项
            sizeMap.merge(item, (long) sizes[i], Long::sum);
        }

        if (sizeMap.isEmpty()) return new ArrayList<>();  // 无匹配

        long max = Collections.max(sizeMap.values());
        List<String> ans = new ArrayList<>();
        for (Map.Entry<String, Long> e : sizeMap.entrySet()) {
            if (e.getValue() == max) ans.add(e.getKey());
        }
        Collections.sort(ans);                            // 并列按字符升序
        return ans;
    }
}
```

> 💡 记忆：**「目录占用 = 内部文件总和」→ 按路径前缀聚合累加，不需要真的建树**；一级子项 = 去前缀后的首段。
>
> ⚠️ 前缀必须带结尾 `/`（如 `"/dir1/dir2-1/"`），否则会把 `/dir1/dir2-10/...` 误匹配进来。
