# 28. 省超足球比赛获胜队伍计算（2026 新系统）

> **难度**：🟡 中等 | **分值**：100 | **卷次**：新系统 2026-07-04 | **标签**：模拟、排序 | **考点**：积分统计 + 多关键字排序

## 题目描述

江苏省举办省级足球超级联赛，以市为单位参赛。请根据给定的比赛结果，输出获得**冠军、亚军、季军**的队伍名称。

**比赛安排**：

1. 参赛队伍总数为 `teamNum`，取值范围 3 ≤ teamNum ≤ 15，超出则输入不合法；
2. 单循环赛制：任意两支队伍之间**至少比赛 1 场**，若两队之间不存在比赛记录，说明其中有队伍弃赛；
3. 总比赛场次不超过 `teamNum × (teamNum-1) / 2` 场；
4. 比赛最终各队伍不允许出现**积分和净胜球都完全相同**的情况（否则输入不合法）。

**计分规则**：

- 胜者得 3 分，平局各得 1 分，负者得 0 分；
- 每场记录双方进球数（≥ 0），净胜球 = 进球数 - 失球数。

**排名规则**：先按**总积分**从高到低；积分相同，按**净胜球**从高到低。

> 新系统（力扣模式）：无需处理输入输出，直接实现函数。

**函数签名**：

```java
// teamNum: 参赛队伍数量
// matches: 每场比赛 [队伍A, A进球数, B进球数, 队伍B]
// 返回 [冠军, 亚军, 季军]；输入不合法返回空列表
public List<String> winners(int teamNum, String[][] matches)
```

## 示例

**示例 1**

```
输入：
teamNum = 3
matches = [["Beijing","2","1","Shanghai"], ["Beijing","3","0","Guangzhou"],
           ["Shanghai","1","1","Guangzhou"]]
输出：
["Beijing", "Shanghai", "Guangzhou"]
```

**解释**：

```
Beijing:    胜Shanghai(+3分,+1球) + 胜Guangzhou(+3分,+3球) = 6分, 净胜球+4
Shanghai:   负Beijing(0分,-1球) + 平Guangzhou(+1分,0球) = 1分, 净胜球-1
Guangzhou:  负Beijing(0分,-3球) + 平Shanghai(+1分,0球) = 1分, 净胜球-3
排名: Beijing(6) > Shanghai(1,-1) > Guangzhou(1,-3) ✓
```

**示例 2**（完全并列 → 不合法）

```
输入：
teamNum = 3
matches = [["Beijing","1","1","Shanghai"], ["Guangzhou","1","1","Beijing"],
           ["Shanghai","1","1","Guangzhou"]]
输出：
[]
```

**解释**：三队全平，均为 2 分、净胜球 0，积分与净胜球完全相同 → 不合法 → [] ✓

## 提示

- 合法性校验有 4 点：teamNum 范围、队伍数匹配、每对至少一场、无完全并列；
- 输入行格式是 `[队伍A, A进球, B进球, 队伍B]`，**双方进球在中间**，别读反；
- 排序：积分降序 → 净胜球降序（平局不参与排名比较）；
- 净胜球 = 进球 - 失球，注意区分「积分」与「净胜球」。

## 思路

### 核心思想

**模拟统计 + 合法性校验 + 双关键字排序**：

```
1. 合法性校验：
   - teamNum ∈ [3, 15]
   - 去重后的队伍数 == teamNum
   - 总场次 <= teamNum*(teamNum-1)/2
   - 任意两队之间至少 1 场（用 Set<队伍对> 记录）
   - 不存在积分与净胜球都相同的两支队伍
2. 统计每队: 积分、进球、失球（每场更新双方）
3. 排序: 积分降序 → 净胜球降序
4. 取前三名
```

**为什么「完全并列」要判不合法**：示例 2 中三队同为 2 分 0 净胜球，无法区分名次，题目明确要求这种情况输出空列表。

**逐步演示**（示例 1）：

```
北京 2:1 上海 → 北京 +3分 +1净胜球；上海 0分 -1净胜球
北京 3:0 广州 → 北京 +3分 +3净胜球；广州 0分 -3净胜球
上海 1:1 广州 → 双方各 +1分；上海 0净胜球；广州 0净胜球
最终: Beijing 6分+4 > Shanghai 1分-1 > Guangzhou 1分-3 ✓
```

- 时间复杂度：\(O(T^2)\)（T = teamNum ≤ 15，校验 + 排序均可忽略）
- 空间复杂度：\(O(T)\)

### 解法（Java，模拟 + 排序）

```java
import java.util.*;

public class Main {
    public List<String> winners(int teamNum, String[][] matches) {
        if (teamNum < 3 || teamNum > 15) return new ArrayList<>();

        Map<String, int[]> stat = new HashMap<>();  // 队伍 -> {积分, 进球, 失球}
        Set<String> pairs = new HashSet<>();        // 已比赛队伍对

        for (String[] m : matches) {
            String a = m[0], b = m[3];
            int ga = Integer.parseInt(m[1]), gb = Integer.parseInt(m[2]);

            stat.computeIfAbsent(a, k -> new int[3]);
            stat.computeIfAbsent(b, k -> new int[3]);
            int[] sa = stat.get(a), sb = stat.get(b);
            sa[1] += ga; sa[2] += gb;
            sb[1] += gb; sb[2] += ga;

            if (ga > gb) sa[0] += 3;                 // A 胜
            else if (ga < gb) sb[0] += 3;            // B 胜
            else { sa[0] += 1; sb[0] += 1; }         // 平

            String key = a.compareTo(b) < 0 ? a + "#" + b : b + "#" + a;
            pairs.add(key);
        }

        // 校验：队伍数匹配
        if (stat.size() != teamNum) return new ArrayList<>();
        // 校验：场次上限
        if (matches.length > teamNum * (teamNum - 1) / 2) return new ArrayList<>();
        // 校验：每对至少一场
        if (pairs.size() != teamNum * (teamNum - 1) / 2) return new ArrayList<>();

        // 排序: 积分降序 → 净胜球降序
        List<String> teams = new ArrayList<>(stat.keySet());
        teams.sort((x, y) -> {
            int[] sx = stat.get(x), sy = stat.get(y);
            int gx = sx[1] - sx[2], gy = sy[1] - sy[2];
            if (sx[0] != sy[0]) return sy[0] - sx[0];
            return gy - gx;
        });

        // 校验：无「积分与净胜球完全相同」的并列
        for (int i = 0; i + 1 < teams.size(); i++) {
            int[] a = stat.get(teams.get(i)), b = stat.get(teams.get(i + 1));
            if (a[0] == b[0] && (a[1] - a[2]) == (b[1] - b[2])) return new ArrayList<>();
        }

        return teams.subList(0, Math.min(3, teams.size()));
    }
}
```

> 💡 记忆：**体育联赛排名 = 逐场累计（积分/进球/失球）+ 多关键字排序**；别忘了把「合法性校验」当成解题的一部分。
>
> ⚠️ 比赛记录格式是 `[队伍A, A进球, B进球, 队伍B]`——A、B 的进球夹在中间；读成「A, B进球, A进球, B」就会全错。
