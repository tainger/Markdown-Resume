# 30. 统计能源使用时段（2026 新系统）

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-07-22 | **标签**：滑动窗口、双指针 | **考点**：最长子串（至多两种不同元素）

## 题目描述

某智慧园区管理系统记录了 N 个连续的能源使用时段，每个时段使用的能源类型用整数表示（1=太阳能，2=风能，3=电能，4=天然气，5=地热能）。

为了优化能源配置，管理员需要分析：在这 N 个时段中，**连续使用不超过 2 种能源**的最长时段长度是多少？

> 新系统（力扣模式）：无需处理输入输出，直接实现函数。

**函数签名**：

```java
// energy: 各时段的能源类型（1~5 的整数）
// 返回最长连续时段的长度；输入为空返回 0
public int longestSegment(int[] energy)
```

## 示例

**示例 1**

```
输入：
energy = [1,2,1,2,3,2,2,2]
输出：
5
```

**解释**：最长满足条件的连续时段是 `[2,3,2,2,2]`（下标 3 到 7），长度 5，该时段只使用了 2 种能源（2 和 3）✓

**示例 2**

```
输入：
energy = [1,2,3,4,5]
输出：
2
```

**解释**：每个时段能源都不一样，任意连续 3 个时段都会出现 ≥3 种能源 → 最长长度只能是 2 ✓

## 思路

### 核心思想

**滑动窗口（右指针扩展 + 左指针收缩）**：

```
1. 空数组 → 返回 0
2. left = 0，计数表 count，窗口内不同能源种类数 kinds = 0
3. right 从左到右遍历：
   - 加入 energy[right]，若该种类此前计数为 0 → kinds++
   - kinds > 2 时：收缩左指针
       移出 energy[left]，计数减 1，减到 0 → kinds--
       直到 kinds <= 2
   - 窗口合法：ans = max(ans, right - left + 1)
4. 输出 ans
```

**为什么窗口合法时直接更新答案**：每次加入新元素后先收缩再更新，窗口始终是**以 right 为右端点的最靠右合法窗口**，它覆盖了所有以 right 结尾的合法区间中的最长者；right 遍历一遍即覆盖所有端点。

**逐步演示**（示例 1，[1,2,1,2,3,2,2,2]）：

```
right=0 加1 → 窗口[0,0]={1} len=1 → ans=1
right=1 加2 → 窗口[0,1]={1,2} len=2 → ans=2
right=2 加1 → 窗口[0,2]={1,2} len=3 → ans=3
right=3 加2 → 窗口[0,3]={1,2} len=4 → ans=4
right=4 加3 → {1,2,3} kinds=3 → 收缩：
  移出下标0的1 → [1,4]=2,1,2,3 仍3种
  移出下标1的2 → [2,4]=1,2,3 仍3种
  移出下标2的1 → [3,4]=2,3 kinds=2 ✓ len=2 → ans=4
right=5 加2 → 窗口[3,5]=2,3,2 len=3 → ans=4
right=6 加2 → 窗口[3,6]=2,3,2,2 len=4 → ans=4
right=7 加2 → 窗口[3,7]=2,3,2,2,2 len=5 → ans=5
最终 ans = 5 ✓（对应官方说明的下标 3~7）
```

> 💡 注意：**先收缩、后更新**，且收缩是循环直到合法——right=4 时连移 3 个元素窗口才重新合法。

- 时间复杂度：\(O(n)\)（每个元素最多进窗口一次、出窗口一次）
- 空间复杂度：\(O(1)\)（定长计数数组，能源类型只有 5 种）

### 解法（Java，滑动窗口 + 定长计数）

```java
public class Main {
    public int longestSegment(int[] energy) {
        if (energy == null || energy.length == 0) return 0;

        int[] count = new int[6];          // 能源类型 1~5，下标 1~5 使用
        int left = 0, kinds = 0, ans = 0;

        for (int right = 0; right < energy.length; right++) {
            if (count[energy[right]]++ == 0) kinds++;   // 新种类进入窗口

            while (kinds > 2) {                          // 收缩直到窗口合法
                if (--count[energy[left]] == 0) kinds--; // 某种能源彻底移出
                left++;
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

> 💡 记忆：**「连续 + 最多 K 种」→ 滑动窗口**；种类上限很小（如 5）时用定长计数数组，`0→1` 和 `1→0` 两处维护 `kinds`。
>
> ⚠️ 收缩是 `while` 不是 `if`——一次可能移不出第 3 种能源（示例 1 中连移 3 个元素窗口才合法）。
