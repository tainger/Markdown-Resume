# 31. 日期格式统一与排序

> **难度**：🟡 中等 | **分值**：100 | **卷次**：新系统 2026-07-15 | **标签**：字符串、日期 | **考点**：格式解析 + 合法性校验 + 去重排序

## 题目描述

在日常开发中，用户输入的日期格式五花八门。现需要你编写一个程序，能够识别多种日期格式，将其统一输出为 `yyyy-mm-dd` 格式，并按日期递增顺序排列。

支持的输入格式：

| 字符串格式类型 | 示例 | 说明 |
|:---|:---|:---|
| 斜杠分隔 | `2022/01/01`、`2022/1/1` | 月/日可能补零也可能不补零 |
| 横杠分隔 | `2022-01-01`、`2022-1-1` | 月/日可能补零也可能不补零 |

规则：

1. 合法年份范围：**1000 ~ 2100**；
2. 非法格式（非斜杠分隔、非横杠分隔、或斜杠横杠混用）**忽略**，不参与排序和输出；
3. 不同格式可能解析为同一日期，**相同日期只输出一次**；
4. 注意日期合法性：月份 ≤ 12、每月天数（二月平年 28 天、闰年 29 天等）；
5. 闰年：能被 4 整除且不能被 100 整除，或能被 400 整除；
6. 输出时月份和日期**不足两位补前导零**；
7. 若所有输入均非法，输出 `["NULL"]`。

**函数签名**：

```java
// dates: 输入日期字符串数组（长度 1~200，单个字符串长度 ≤ 50）
// 返回统一格式、递增排序、去重后的日期数组；全部非法时返回 ["NULL"]
public List<String> unifyDates(String[] dates)
```

## 示例

**示例 1**

```
输入：
dates = ["2022/01/01","2022-1-1","20220101","1640995200","2022/1/1","2022-01-01","2022-12-31","1641081600"]
输出：
["2022-01-01","2022-12-31"]
```

**解释**：

```
2022/01/01 斜杠分隔 → 2022-01-01
2022-1-1    横杠分隔，月/日补零 → 2022-01-01
20220101    无分隔符 → 非法，忽略
1640995200  非日期格式 → 非法，忽略
2022/1/1    斜杠分隔，补零 → 2022-01-01
2022-01-01  合法 → 2022-01-01（与上面重复，只保留一次）
2022-12-31  合法 → 2022-12-31
1641081600  非法，忽略
去重排序后 → ["2022-01-01","2022-12-31"] ✓
```

**示例 2**

```
输入：
dates = ["2021/02/29","2021/02-20"]
输出：
["NULL"]
```

**解释**：`2021/02/29` 日期非法（2021 不是闰年，2 月没有 29 日）；`2021/02-20` 斜杠横杠混用 → 非法。全部非法 → `["NULL"]` ✓

**示例 3**

```
输入：
dates = ["1970/1/1"]
输出：
["1970-01-01"]
```

**解释**：`1970/1/1` 转格式后为 `1970-01-01` ✓

## 提示

- 格式判定优先级：**包含 `/` → 按斜杠解析（此时不能再有 `-`）**；**包含 `-` → 按横杠解析（此时不能再有 `/`）**；否则非法；
- 拆分后必须正好 3 段，且**年份必须是 4 位数字**；
- 统一后的 `yyyy-mm-dd` 是定宽字符串，**字典序 = 日期递增序** → 排序直接用字符串排序；
- 去重用 `Set`，排序用 `TreeSet` 一步到位；年份范围校验在格式化之前。

## 思路

### 核心思想

**逐串解析 + 合法性校验 + 去重排序**：

```
1. 对每个字符串 s：
   - 含 '/' 且不含 '-' → split("/")
   - 含 '-' 且不含 '/' → split("-")
   - 其他 → 非法
2. 校验拆分后恰 3 段、每段全为数字、年份段长度 = 4
3. 转 int：年份 ∈ [1000, 2100]；月份 ∈ [1, 12]；
   天数 ≤ 该月天数（闰年 2 月 29 天）
4. 合法 → 格式化为 yyyy-mm-dd（补零）加入 TreeSet
5. TreeSet 空 → 返回 ["NULL"]；否则按序输出
```

**为什么定宽字符串能直接排序**：`2022-01-01` 这类 10 位定宽字符串，按字典序比较时从年份开始逐位比较，字典序恰好等价于日期先后（`2022-01-01` < `2022-12-31`），无需转换成时间戳。

**逐步演示**（示例 1 的部分元素）：

```
"2022/1/1"     → 含'/'不含'-' → split = ["2022","1","1"] ✓
                  年2022∈[1000,2100] 月1 日1 → 2022-01-01
"2022-1-1"     → 含'-'不含'/' → ["2022","1","1"] → 2022-01-01（去重）
"20220101"     → 无分隔符 → 非法
"1640995200"   → 无分隔符 → 非法
"2021/02/29"   → 月2 日29：2021 平年 → 非法
"2021/02-20"   → 同时含'/'和'-' → 非法
```

- 时间复杂度：\(O(N + K \log K)\)（N 为输入长度，K 为合法去重后的日期数）
- 空间复杂度：\(O(K)\)

### 解法（Java，解析 + TreeSet 去重排序）

```java
import java.util.*;

class Solution {
    public List<String> unifyDates(String[] dates) {
        int[] daysOfMonth = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        TreeSet<String> set = new TreeSet<>();

        for (String s : dates) {
            String[] parts;
            if (s.indexOf('/') >= 0 && s.indexOf('-') < 0) {
                parts = s.split("/");                 // 斜杠分隔
            } else if (s.indexOf('-') >= 0 && s.indexOf('/') < 0) {
                parts = s.split("-");                 // 横杠分隔
            } else {
                continue;                             // 混用 / 无分隔符 → 非法
            }

            if (parts.length != 3) continue;          // 必须正好 3 段
            int[] v = new int[3];
            boolean ok = true;
            for (int i = 0; i < 3; i++) {
                String p = parts[i];
                if (p.length() == 0 || (i == 0 && p.length() != 4)) { ok = false; break; }
                for (char c : p.toCharArray()) {
                    if (c < '0' || c > '9') { ok = false; break; }
                }
                if (!ok) break;
                v[i] = Integer.parseInt(p);
            }
            if (!ok) continue;

            int y = v[0], m = v[1], d = v[2];
            if (y < 1000 || y > 2100 || m < 1 || m > 12) continue;

            int maxDay = daysOfMonth[m];
            if (m == 2 && (y % 400 == 0 || (y % 4 == 0 && y % 100 != 0))) maxDay = 29;
            if (d < 1 || d > maxDay) continue;

            set.add(String.format("%04d-%02d-%02d", y, m, d));   // 定宽 → 字典序=日期序
        }

        if (set.isEmpty()) return Collections.singletonList("NULL");
        return new ArrayList<>(set);
    }
}
```

> 💡 记忆：**「多格式日期统一」→ 分隔符判定 + 范围校验 + 定宽格式化**；`%04d-%02d-%02d` 一步补零，`TreeSet` 同时搞定去重和排序。
>
> ⚠️ 两个易错点：① 混用分隔符必须判非法（`2021/02-20`）；② 年份必须 4 位——`1/2/3` 之类短年份直接非法，即使数值在范围内。
