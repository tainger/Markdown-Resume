# 34. 获取二叉树第 k 层的数值

> **难度**：🟡 中等 | **分值**：100 | **卷次**：新系统 2026-08-12 | **标签**：树、BFS、哈希 | **考点**：层序遍历定位第 k 层 + 去重排序

## 题目描述

给定一棵**有根二叉树**，请找出第 `k` 层上的所有节点值，**去重后按升序**输出。

- 默认**根节点编号为 `0`**，根节点所在层为**第 0 层**；
- 输入的边信息 `edges[i] = [father, child]` 表示一条有向父子边；
- 若第 `k` 层不存在任何节点，输出空数组。

**函数签名**：

```java
// n:     节点数，节点编号 0 ~ n-1
// vals:  长度 n 的数组，vals[i] 为编号 i 的节点值
// edges: 二维数组，每个元素为 [father, child]，表示有向边
// k:     层数，根节点（编号 0）所在层为 0
// 返回：第 k 层所有节点值去重后的升序数组；不存在则返回空数组
public int[] kthLevel(int n, int[] vals, int[][] edges, int k)
```

## 示例

**示例 1**

```
输入：
n = 5
vals = [5,3,8,3,7]
edges = [[0,1],[0,2],[1,3],[1,4]]
k = 2
输出：[3,7]
```

**解释**：树结构如下（括号内为节点值）：

```
        0(5)          ← 第 0 层
       /    \
    1(3)    2(8)       ← 第 1 层
   /   \
 3(3)  4(7)            ← 第 2 层
```

第 2 层节点为 `3(值3)`、`4(值7)` → 值集合 `{3,7}` → 去重升序 `[3,7]`。

**示例 2**

```
输入：
n = 7
vals = [10,5,8,1,6,7,9]
edges = [[0,1],[0,2],[1,3],[1,4],[2,5],[2,6]]
k = 1
输出：[5,8]
```

**解释**：第 1 层为节点 `1(值5)`、`2(值8)` → `[5,8]`。

**示例 3**

```
输入：
n = 1
vals = [42]
edges = []
k = 0
输出：[42]
```

**解释**：只有根节点，第 0 层就是根 → `[42]`。

---

## 提示

- 节点编号 `0 ~ n-1`，根节点固定为 `0`；
- 同一层不同节点的**值可能相同**，需要**去重**（如示例 1 中值 `3` 出现两次，只保留一次）；
- 若 `k` 超过树的最大深度，第 `k` 层为空，返回**空数组**；
- 用有向邻接表建图（只加 `father → child`），从根 `0` 开始 BFS 即可，无需处理无向边。

---

## 思路

### 核心思想

**BFS 逐层扩展**，数到第 `k` 层就停下，收集该层所有节点值，最后**去重 + 升序**：

```
1. 用 edges 建有向邻接表 graph[father] += child
2. 队列初始放入根节点 0，level = 0
3. 每轮「整层出队」（记录 size = 当前层节点数），把它们的孩子全部入队，level++
4. 当 level == k 时，队列里恰好是第 k 层的所有节点 → 收集其 vals，去重排序
5. 若 BFS 提前结束（队列空）仍没到第 k 层 → 返回空数组
```

**关键技巧：整层处理**。每轮循环开始先取 `size = queue.size()`，只弹出这么多个（即当前整层），把它们的孩子全部入队。这样每完成一轮循环 `level` 恰好 +1，队列里始终是「下一层」的完整集合。

> 也可以用 **DFS + 深度参数** `dfs(node, depth)`，当 `depth == k` 时收集节点值。BFS 更直观、更符合「第 k 层」的语义，两者复杂度相同。

### 去重排序

用 `TreeSet<Integer>` 收集第 `k` 层的值——插入即**自动去重 + 升序**，最后转数组，一步到位。

### 逐步演示（示例 1，`k=2`）

```
建图：0→[1,2], 1→[3,4], 2→[], 3→[], 4→[]
队列=[0]      level=0 (≠2) 出队0，孩子1,2入队 → 队列=[1,2] level=1
队列=[1,2]    level=1 (≠2) 出队1(孩子3,4)、2(无孩子) → 队列=[3,4] level=2
level==2 → 收集 vals[3]=3, vals[4]=7 → TreeSet{3,7} → [3,7] ✅
```

- 时间复杂度：\(O(n \log n)\)（BFS 遍历 `O(n)`，`TreeSet` 去重排序最坏 `O(n log n)`）
- 空间复杂度：\(O(n)\)（邻接表 + 队列）

```java
        // 2. queue = [0], level = 0
        // 3. while queue 非空 且 level < k:
        //      size = queue.size()
        //      弹出 size 个，把它们的孩子入队
        //      level++
        // 4. 若 level != k → 返回空数组
        // 5. 队列里就是第 k 层，vals 塞进 TreeSet 去重排序，转数组返回
    }
}
```

### 解法：BFS 层序遍历 + TreeSet 去重排序

```java
import java.util.*;

class Solution {
    public int[] kthLevel(int n, int[] vals, int[][] edges, int k) {
        if (n <= 0 || k < 0) return new int[0];

        // 1. 建有向邻接表
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            if (e[0] >= 0 && e[0] < n && e[1] >= 0 && e[1] < n) {
                graph.get(e[0]).add(e[1]);
            }
        }

        // 2. BFS 逐层下探，直到第 k 层或队列耗尽
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(0);
        int level = 0;
        while (!queue.isEmpty() && level < k) {
            int size = queue.size();          // 锁定当前整层
            for (int i = 0; i < size; i++) {
                int cur = queue.poll();
                for (int nxt : graph.get(cur)) queue.offer(nxt);
            }
            level++;
        }

        // 3. 没到第 k 层（树没那么深）→ 空数组
        if (level != k) return new int[0];

        // 4. 队列里就是第 k 层节点，取值去重升序
        TreeSet<Integer> set = new TreeSet<>();
        while (!queue.isEmpty()) set.add(vals[queue.poll()]);

        int[] ans = new int[set.size()];
        int idx = 0;
        for (int v : set) ans[idx++] = v;
        return ans;
    }
}
```

> 💡 记忆：**「第 k 层节点」→ BFS 整层处理**，每轮先记 `size` 再弹整层，`level` 自然 +1；去重升序交给 `TreeSet`。
>
> ⚠️ 两个易错点：① 每轮必须先固定 `size = queue.size()` 再循环，否则边弹边加会把下一层也算进当前层；② 判空要区分「第 k 层为空数组」和「树深度不够根本没有第 k 层」——两者都返回空数组，但 `level != k` 的判断不能漏。

## 个人总结

### 这是 LeetCode 102 的变形题

这道题的骨架就是 hot100 里的 **102. 二叉树的层序遍历**——核心都是 **BFS 整层处理**：每轮先锁定 `size = queue.size()`，只弹出这么多个（当前整层），再把它们的孩子全部入队，`level` 自然 +1。本题的 BFS 主循环和 102 的标准写法是同一个模板。

### 与 102 的关系对比

| 维度 | 102. 层序遍历 | 34. 第 k 层数值 |
|:---|:---|:---|
| 核心套路 | BFS 整层处理 | BFS 整层处理（**完全相同**） |
| 输出 | **每一层**都收集 → `List<List<Integer>>` | 只收集**第 k 层**，数到 k 就停 |
| 后处理 | 无 | 额外**去重 + 升序**（`TreeSet`） |
| 输入形式 | `TreeNode root`（指针树） | `n / vals / edges`（图式建树） |

### 三个变形点

1. **只取第 k 层**：不像 102 收集所有层，本题 `while (level < k)` 提前停，队列里恰好是第 k 层的完整集合；还要注意区分「第 k 层为空」和「树深度不够根本没有第 k 层」，用 `level != k` 判断。
2. **图式建树**：给的是 `edges = [father, child]` 而非 `TreeNode`，要先 `graph[father].add(child)` 建有向邻接表再 BFS——这是图论题的建图套路（类比 207 课程表、200 岛屿数量）。因为本质是树（无环、根固定为 0），所以无需 `visited` 数组。
3. **去重 + 升序**：用 `TreeSet<Integer>` 收集第 k 层的值，插入即自动去重升序，一步到位。

### 一句话概括

> **34 = 102（层序遍历，取第 k 层） + 图式建树（邻接表，类比 207 / 200） + TreeSet 去重升序**。

母题是 hot100 的 102，变形点在「只要第 k 层」「图式输入」「去重排序」三处。
