# 35. 点亮战争迷雾（2026 新系统）

> **难度**：🔴 困难 | **分值**：200 | **卷次**：新系统 2026-08-19 | **标签**：树、树形 DP | **考点**：树形 DP 三状态转移（监控二叉树带权变体，等价 LeetCode 968 加权版）

## 题目描述

有一张二叉树地图，每一个节点都被战争迷雾所覆盖。在某个二叉树节点上插上一个**侦察守卫**，可以照亮**该节点自身、它的父节点、它的所有子节点**的战争迷雾。在每个节点上插守卫的成本不同，用 `cost[i]` 表示节点 `i` 的成本（正整数）。

要求：

1. **所有节点**的战争迷雾都被驱散（都被照亮）；
2. 所花费的**总成本最小**。

补充说明：

- 单个节点成本 `1 ≤ cost[i] ≤ 100`；
- 节点总数 `≤ 1000`。

> 新系统（力扣模式）：输入为一行**层序遍历字符串**（含首尾圆括号），空节点用 `#` 表示，如 `(5,1,10,2,8,#,3)`；直接实现函数返回最小总成本。

**函数签名**：

```java
// levelOrder: 层序遍历字符串，如 "5,1,10,2,8,#,3"（成本即节点值，# 为空节点）
// 返回：驱散所有战争迷雾的最小总成本
public int minCost(String levelOrder)
```

## 示例

**示例 1**

```
输入：5,1,10,2,8,#,3
输出：4
```

**解释**：树结构（括号内为成本）：

```
        1(5)
       /    \
     2(1)   3(10)
    /  \       \
  4(2) 5(8)    6(3)
```

最优方案：在节点 `2`（成本 `1`）和节点 `6`（成本 `3`）插守卫，总成本 `4`。

- 节点 `2` 照亮 `{2, 父1, 子4, 子5}`；
- 节点 `6` 照亮 `{6, 父3}`；
- 所有 6 个节点均被覆盖，总成本 `1 + 3 = 4` ✅。

**示例 2**

```
输入：3,1,1
输出：2
```

**解释**：树结构：

```
      1(3)
     /   \
   2(1)  3(1)
```

- 方案一：只在根 `1` 插守卫，照亮全部，成本 `3`；
- 方案二：在 `2`、`3` 插守卫，成本 `1 + 1 = 2` ✅（更优）。

## 思路

### 核心思想

每个节点是否「被照亮」取决于**自己、父、子**三方谁装了守卫，状态耦合了上下两代——这是**树形 DP** 的典型场景。对每个节点定义**三种状态**，后序遍历自底向上转移：

| 状态 | 含义 | 谁来照亮它 |
|:---|:---|:---|
| `a` | 本节点**未被照亮**，等父节点装守卫来照 | 靠父节点 |
| `b` | 本节点**已被照亮**，但**自己没装**（靠某个子节点装的守卫照到） | 靠子节点 |
| `c` | 本节点**自己装了守卫** | 靠自己 |

`dfs(node)` 返回该节点在三种状态下、**保证以它为根的子树内除它以外全部被照亮**的最小成本。

### 状态转移（设左右孩子返回 `(la,lb,lc)`、`(ra,rb,rc)`）

- **`c`（自己装守卫）**：自己出成本 `cost`，装了守卫后左右孩子无论什么状态都已被照亮（被本节点照到），所以孩子取各自三状态最小值：

  ```
  c = cost + min(la,lb,lc) + min(ra,rb,rc)
  ```

- **`a`（自己不装、等父节点照）**：自己不被子节点照，那左右孩子**必须各自被照亮**（不能指望本节点），即孩子只能取「被照亮」的两种状态 `b` 或 `c` 的较小值：

  ```
  a = min(lb,lc) + min(rb,rc)
  ```

- **`b`（自己不装、被子节点照到）**：本节点要被某个子节点的守卫照到，**至少有一个孩子处于 `c`（装了守卫）**。同时每个孩子自身也必须被照亮（取 `b`/`c`）。枚举「哪个孩子装守卫」取最小：

  ```
  b = min( lc + min(rb,rc),      // 左孩子装守卫，右孩子被照亮即可
           min(lb,lc) + rc )     // 右孩子装守卫，左孩子被照亮即可
  ```

  > 注意 `lc + rc`（两个孩子都装）已被上面两式覆盖（`lc + min(rb,rc)` 里 `rc` 是候选，`min(lb,lc)+rc` 里 `lc` 是候选），无需单列。

- **空节点**：`{a=0, b=0, c=∞}`——空节点天然「被照亮」（无迷雾），但**不能装守卫**（`c` 设极大值屏蔽）。

### 最终答案

根节点没有父节点，不能依赖状态 `a`（那会让根「等父照亮」但根无父）。所以答案取根的 **`min(b, c)`**：要么根自己装守卫，要么被子节点照到。

### 逐步演示（示例 2，`3,1,1`）

```
叶子 2(1): a=0(等父), b=0(无子照它但也无子需照…叶子取 b=0), c=1(自装)
   —— 叶子的孩子都是空节点 {0,0,∞}
   c = 1 + min(0,0,∞) + min(0,0,∞) = 1
   a = min(0,∞)+min(0,∞) = 0
   b = min(∞+min(0,∞), min(0,∞)+∞) = 0  （空孩子无法装守卫，b 退化，仍取 0 因叶子自身可被父照）
叶子 3(1): 同上 a=0,b=0,c=1
根 1(3): 左(0,0,1) 右(0,0,1)
   c = 3 + min(0,0,1) + min(0,0,1) = 3
   b = min(1+min(0,1), min(0,1)+1) = min(1,1) = 2  （左或右装守卫照亮根）
   答案 = min(b,c) = min(2,3) = 2 ✅
```

- 时间复杂度：\(O(n)\)（每个节点一次后序访问，转移 O(1)）
- 空间复杂度：\(O(h)\)（递归栈，h 为树高）

        //    c = cost + min(左三态) + min(右三态)
        //    a = min(lb,lc) + min(rb,rc)

        // 3. 返回 min(根.b, 根.c)
    }

### 解法：建树 + 三状态树形 DP

```java
import java.util.*;

public class Main {
    // 二叉树节点：val 即成本
    static class TreeNode {
        int val;
        TreeNode left, right;
        TreeNode(int v) { val = v; }
    }

    private static final int INF = Integer.MAX_VALUE / 2;   // 防止相加溢出

    public int minCost(String levelOrder) {
        TreeNode root = build(levelOrder);
        if (root == null) return 0;
        int[] r = dfs(root);           // [a, b, c]
        return Math.min(r[1], r[2]);   // 根无父，只能自装 或 被子照
    }

    // 后序遍历，返回 {a: 未照等父, b: 已照非自装, c: 自装}
    private int[] dfs(TreeNode node) {
        if (node == null) return new int[]{0, 0, INF};   // 空节点天然被照，不能装守卫
        int[] l = dfs(node.left);
        int[] r = dfs(node.right);

        int c = node.val + Math.min(l[0], Math.min(l[1], l[2]))
                         + Math.min(r[0], Math.min(r[1], r[2]));
        int a = Math.min(l[1], l[2]) + Math.min(r[1], r[2]);
        int b = Math.min(l[2] + Math.min(r[1], r[2]),
                         Math.min(l[1], l[2]) + r[2]);
        return new int[]{a, b, c};
    }

    // 层序字符串建树，# 为空节点
    private TreeNode build(String s) {
        s = s.replaceAll("[()\\s]", "");          // 去掉圆括号和空白
        if (s.isEmpty()) return null;
        String[] t = s.split(",");
        if (t.length == 0 || t[0].equals("#")) return null;

        TreeNode root = new TreeNode(Integer.parseInt(t[0]));
        Queue<TreeNode> q = new LinkedList<>();
        q.offer(root);
        int i = 1;
        while (!q.isEmpty() && i < t.length) {
            TreeNode cur = q.poll();
            if (i < t.length && !t[i].equals("#")) {    // 左孩子
                cur.left = new TreeNode(Integer.parseInt(t[i]));
                q.offer(cur.left);
            }
            i++;
            if (i < t.length && !t[i].equals("#")) {    // 右孩子
                cur.right = new TreeNode(Integer.parseInt(t[i]));
                q.offer(cur.right);
            }
            i++;
        }
        return root;
    }
}
```

> 💡 记忆：**「装设备照亮自身 + 父 + 子，求最小代价」→ 三状态树形 DP**（等价监控二叉树 968 的带权版）。三态：`a` 等父照、`b` 被子照、`c` 自装。答案 = `min(根b, 根c)`。
>
> ⚠️ 三个易错点：① 空节点 `c=∞`（不能装守卫），但 `a=b=0`（无迷雾天然被照）；② 根不能取状态 `a`（根无父可依赖）；③ 用 `INF = MAX/2` 而非 `MAX`，否则相加溢出变负数。
