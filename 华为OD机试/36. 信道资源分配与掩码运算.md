# 36. 信道资源分配与掩码运算

> **难度**：🟢 简单 | **分值**：100 | **卷次**：新系统 2026-08-16 | **标签**：位运算、进制转换 | **考点**：按位与/或、连续 1 最长长度、64 位无符号整数处理

## 题目描述

在进行信道资源分配时，用**掩码（Bitmask）**高效管理可用信道的状态：每个信道对应掩码中的一个二进制位，位为 `1` 表示信道可用，为 `0` 表示被占用。掩码由 **64 位无符号整数**表示（二进制从低位到高位对应信道 0 到信道 63）。

掩码输入是**带进制标识的字符串**：

- 二进制字符串：以 `0b` 开头（如 `0b1011`）；
- 十六进制字符串：以 `0x` 开头（如 `0x1A3`）；
- 十进制字符串：无特殊前缀（如 `255`）。

给定两个掩码字符串 `maskStrA`、`maskStrB`，请实现一个函数完成：

1. 将两个掩码字符串转为 64 位无符号整数；
2. 计算两掩码的**交集**（仅保留两个掩码中都为 1 的位）；
3. 计算两掩码的**并集**（保留任意一个掩码中为 1 的位）；
4. 统计**并集**中连续可用信道的最大长度（二进制里连续 `1` 的最长子串长度）。

返回长度为 3 的数组（十进制整数）：`[交集, 并集, 并集的最大连续可用信道长度]`。

**函数签名**：

```java
// maskStrA, maskStrB: 带进制标识的掩码字符串
// 返回 [交集, 并集, 并集连续 1 的最长长度]（十进制）
public long[] channelMask(String maskStrA, String maskStrB)
```

## 示例

**示例 1**

```
输入：
maskStrA = "0b1011", maskStrB = "0b1101"
输出：
[9, 15, 4]
```

**解释**：`0b1011 = 11`，`0b1101 = 13`；交集 `11 & 13 = 9`；并集 `11 | 13 = 15`（二进制 `1111`），连续 1 最长为 4。

**示例 2**

```
输入：
maskStrA = "0", maskStrB = "0xCC"
输出：
[0, 204, 2]
```

**解释**：`0 = 0`，`0xCC = 204`（二进制 `11001100`）；交集 `0 & 204 = 0`；并集 `204`，连续 1 最长为 2。

## 提示

- 掩码值范围：`0 ≤ mask ≤ 2^64 - 1`（**64 位无符号**）；
- 二进制串长度 ≤ 64，十六进制串长度 ≤ 16，输入格式均合法，无需处理异常；
- 连续长度规则：全 0 返回 0，全 1 返回 64。

## 思路

### 核心思想

三步走：**进制解析 → 位与/位或 → 扫描连续 1**。难点不在算法而在 **Java 没有无符号 64 位类型**，`long` 最高位是符号位，直接 `Long.parseLong` 会因超出 `Long.MAX_VALUE`（2^63-1）而抛异常。

**关键：用 `Long.parseUnsignedLong` / `Long.parseLong(s, radix)` 的无符号版本**，把 `long` 当作 64 位无符号位模式来存。位运算（`&`、`|`）本身对有符号/无符号的位模式是一致的，不受影响；只有在**打印/比较大小**时才需要 `Long.toUnsignedString`、`Long.compareUnsigned`。

```
1. parseMask(s)：
   - "0b..." → 去掉前缀，Long.parseUnsignedLong(rest, 2)
   - "0x..." → 去掉前缀，Long.parseUnsignedLong(rest, 16)
   - 否则    → Long.parseUnsignedLong(s, 10)
2. and = a & b;  or = a | b;
3. 连续 1 最长：对 or 的 64 位从低到高扫描，遇 1 累加 cur 并更新 max，遇 0 清零 cur。
```

**统计连续 1 的两种写法**：

- **逐位扫描**：`for (int i=0;i<64;i++) 取第 i 位`，`O(64)`，直观。
- **位技巧（Brian Kernighan 变体）**：`while(x!=0){ x &= (x<<1); cnt++; }`——每次 `x &= x<<1` 会消掉每段连续 1 的最右一个，循环次数 = 最长连续 1 的长度。更巧但要注意 `x<<1` 在最高位的溢出（对 `long` 是自然截断，安全）。

**逐步演示**（示例 2，`or = 204 = 0b11001100`）：

```
位:  ...0 1 1 0 0 1 1 0 0   (从高到低看是 11001100)
扫描 cur: 遇到 "11" → cur=1,2(max=2)，遇 0 清零；再遇 "11" → cur=1,2 → max 保持 2
结果 = 2 ✓
```

- 时间复杂度：\(O(64)\) = \(O(1)\)（定长 64 位）
- 空间复杂度：\(O(1)\)

### 解法（Java，位运算 + 无符号解析）

```java
class Solution {
    public long[] channelMask(String maskStrA, String maskStrB) {
        long a = parseMask(maskStrA);
        long b = parseMask(maskStrB);

        long and = a & b;                 // 交集
        long or = a | b;                  // 并集
        long maxRun = maxConsecutiveOnes(or);

        return new long[]{and, or, maxRun};
    }

    // 按进制前缀无符号解析成 64 位位模式
    private long parseMask(String s) {
        if (s.startsWith("0b") || s.startsWith("0B")) {
            return Long.parseUnsignedLong(s.substring(2), 2);
        } else if (s.startsWith("0x") || s.startsWith("0X")) {
            return Long.parseUnsignedLong(s.substring(2), 16);
        } else {
            return Long.parseUnsignedLong(s, 10);
        }
    }

    // 统计 64 位无符号数中连续 1 的最长长度
    private long maxConsecutiveOnes(long x) {
        int max = 0, cur = 0;
        for (int i = 0; i < 64; i++) {
            if (((x >>> i) & 1L) == 1L) {  // 用 >>> 无符号右移，避免符号位扩展
                cur++;
                if (cur > max) max = cur;
            } else {
                cur = 0;
            }
        }
        return max;
    }
}
```

> 💡 记忆：**「64 位无符号 + Java」= 用 `Long.parseUnsignedLong` 解析、用 `>>>` 取位、用 `Long.toUnsignedString` 打印**。有符号 `>>` 会把符号位复制下来，取高位时全变 1，务必用 `>>>`。
>
> 🔁 位技巧版连续 1：`int c=0; while(x!=0){ x &= (x<<1); c++; }` 返回 `c` 即最长连续 1 长度。
