# 4. 单词接龙

> **难度**：🟡 中等 | **分值**：200 | **标签**：模拟、排序 | **考点**：贪心选择

## 题目描述

给定起始单词 `startWord` 和一个单词数组 `words`，按以下规则进行单词接龙：

1. 可用于接龙的单词，**首字母必须等于前一个单词的尾字母**；
2. 当存在多个首字母相同的候选单词时，取**长度最长**的单词；
3. 如果长度也相等，取**字典序最小**的单词；
4. 每个单词**只能使用一次**；
5. 若没有可接的单词，接龙结束。

返回最终接龙结果字符串（单词**直接拼接**，不加分隔符）。

### 函数签名

```java
class Solution {
    public String wordChain(String startWord, String[] words) {
        // ...
    }
}
```

## 示例

### 示例 1

```
输入：startWord = "word", words = ["dword", "dd", "da", "dc"]
输出："worddwordda"
```

**解释**：

```
当前 = word，尾字母 = 'd'
候选：dword(5) dd(2) da(2) dc(2)  → 取最长的 dword
当前 = worddword，尾字母 = 'd'
候选：dd(2) da(2) dc(2) → 长度相同 → 取字典序最小的 da
当前 = worddwordda，尾字母 = 'a'
候选：无（没有 a 开头的单词）→ 结束
```

### 示例 2

```
输入：startWord = "a", words = ["ab", "bc", "cd", "ab"]
输出："ababccd"
```

**解释**：`a → ab → ab → bc → cd`。注意 `words` 中有两个 `"ab"`，分别使用一次后均被消耗。

---

## 提示

- `1 <= startWord.length, words[i].length <= 100`
- `1 <= words.length <= 100`
- `words[i]` 仅包含小写英文字母
- 接龙时**只比较首字母和尾字母**，不看中间部分
- 「字典序最小」用 `compareTo` 比较即可
- 单词数组中可能存在**重复单词**，每个元素只能使用一次

---

## 思路

### 核心思想

**贪心模拟**：每一步在候选集里选「最长 → 字典序最小」的单词，直到无候选。

```
while (true):
    1. 候选 = 未使用 && 首字母 == 当前尾字母 的单词集合
    2. 候选为空 → 结束
    3. 排序规则：长度降序 → 字典序升序，取第一个
    4. 拼接，标记已使用
```

### 实现细节

- 用 `boolean[] used` 按下标记录使用状态（处理重复单词）；
- 用 `List<String>` 存候选，排序后取第一个；
- 也可以维护「以某字母开头的单词列表」做预分组，但 n 小没必要。

## 代码

### 解法（Java）

```java
import java.util.*;

class Solution {
    public String wordChain(String startWord, String[] words) {
        int n = words.length;
        boolean[] used = new boolean[n];

        StringBuilder sb = new StringBuilder(startWord);
        String cur = startWord;

        while (true) {
            char tail = cur.charAt(cur.length() - 1);
            List<String> candidates = new ArrayList<>();

            for (int i = 0; i < n; i++) {
                if (!used[i] && words[i].charAt(0) == tail) {
                    candidates.add(words[i]);
                }
            }
            if (candidates.isEmpty()) break;

            // 长度降序，长度相同字典序升序
            candidates.sort((a, b) -> {
                if (a.length() != b.length()) return b.length() - a.length();
                return a.compareTo(b);
            });

            String next = candidates.get(0);
            // 标记已使用（注意：单词可能有重复，需按下标标记）
            for (int i = 0; i < n; i++) {
                if (!used[i] && words[i].equals(next)) {
                    used[i] = true;
                    break;
                }
            }

            sb.append(next);
            cur = next;
        }
        return sb.toString();
    }
}
```

### 复杂度分析

- **时间复杂度**：\(O(n^2 \log n)\)，其中 \(n\) 为单词数。每轮扫描 \(O(n)\) 收集候选，排序 \(O(n \log n)\)，最坏接 \(n\) 轮。
- **空间复杂度**：\(O(n)\)，候选列表与 `used` 数组。

> 💡 如果题目版本要求「单词可重复使用」，去掉 `used` 标记即可，其余逻辑不变。
