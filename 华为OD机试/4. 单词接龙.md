# 4. 单词接龙

> **难度**：🟡 中等 | **分值**：200 | **标签**：模拟、排序 | **考点**：贪心选择

## 题目描述

单词接龙的规则是：

1. 可用于接龙的单词，**首字母必须与前一个单词的尾字母相同**；
2. 当存在多个首字母相同的候选单词时，取**长度最长**的单词；
3. 如果长度也相等，取**字典序最小**的单词；
4. 每个单词**只能使用一次**；
5. 若没有可接的单词，接龙结束。

给定起始单词和单词表，输出最终接龙结果（单词**直接拼接**，不加分隔符）。

**输入描述**：

```
第一行：起始单词 startWord
第二行：单词个数 n
第三行：n 个单词（空格分隔）
```

**输出描述**：接龙结果字符串。

## 示例

```
输入：
word
4
dword dd da dc
输出：
worddwordda
```

**解释**：

```
当前 = word，尾字母 = 'd'
候选：dword(5) dd(2) da(2) dc(2)  → 取最长的 dword
当前 = worddword，尾字母 = 'd'
候选：dd(2) da(2) dc(2) → 长度相同 → 取字典序最小的 da
当前 = worddwordda，尾字母 = 'a'
候选：无（没有 a 开头的单词）→ 结束
```

---

## 提示

- 接龙时**只比较首字母和尾字母**，不看中间部分。
- 已使用的单词不能再用（注意去重处理）。
- 「字典序最小」用 `compareTo` 比较即可。

---

## 思路

### 核心思想

**贪心模拟**：每一步在候选集里选「最长 → 字典序最小」的单词，直到无候选。

```
while (true):
    1. 候选 = 未使用 && 首字母 == 当前尾字母 的单词集合
    2. 候选为空 → 结束
    3. 排序规则：长度降序 → 字典序升序，取第一个
    4. 拼接，标记已使用
```

**复杂度**：每轮扫描一次单词表 \(O(n)\)，最多接 n 轮 → \(O(n^2)\)，单词数一般 ≤ 100，完全够用。

### 实现细节

- 用 `boolean[] used` 记录使用状态；
- 用 `List<String>` 存候选，排序后取第一个；
- 也可以维护「以某字母开头的单词列表」做预分组，但 n 小没必要。

### 解法（Java）

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String cur = sc.nextLine().trim();       // 起始单词
        int n = Integer.parseInt(sc.nextLine().trim());

        String[] words = sc.nextLine().trim().split(" ");
        boolean[] used = new boolean[n];

        StringBuilder sb = new StringBuilder(cur);

        while (true) {
            char tail = cur.charAt(cur.length() - 1);
            List<String> candidates = new ArrayList<>();

            for (int i = 0; i < n; i++) {
                if (!used[i] && words[i].charAt(0) == tail) {
                    candidates.add(words[i]);
                }
            }
            if (candidates.isEmpty()) break;

            // 长度降序，长度相同字典序升序
            candidates.sort((a, b) -> {
                if (a.length() != b.length()) return b.length() - a.length();
                return a.compareTo(b);
            });

            String next = candidates.get(0);
            // 标记已使用（注意：单词可能有重复，需按下标标记）
            for (int i = 0; i < n; i++) {
                if (!used[i] && words[i].equals(next)) {
                    used[i] = true;
                    break;
                }
            }

            sb.append(next);
            cur = next;
        }

        System.out.println(sb);
    }
}
```

> 💡 如果题目版本要求「单词可重复使用」，去掉 `used` 标记即可，其余逻辑不变。
