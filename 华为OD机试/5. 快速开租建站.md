# 5. 快速开租建站

> **难度**：🟡 中等 | **分值**：200 | **标签**：拓扑排序、BFS | **考点**：DAG 最长链

## 题目描述

IT 部门需要为子公司快速开租建站。一个站点的部署由一系列**部署任务项**构成，每个任务项部署耗时**固定为 1**。

任务项之间存在**依赖关系**：某个任务必须在它依赖的任务完成后才能开始；**不冲突的任务可以并行执行**。

给定任务项及其依赖关系，求一个站点的**最短开站时间**。

**输入描述**：

```
第一行：taskNum（任务数，任务编号 1 ~ taskNum）
第二行：relationNum（依赖关系数）
接下来 relationNum 行：每行两个整数 a b，表示任务 a 依赖任务 b
```

**输出描述**：最短开站时间（整数）。

## 示例

**示例 1**

```
输入：
3
2
2 1
3 1
输出：
2
```

**解释**：任务 1 先部署（耗时 1）；任务 2、3 都依赖任务 1，且互不依赖 → 第 2 个时间单位并行部署 → 总耗时 2。

**示例 2**（链式依赖）

```
输入：
5
4
2 1
3 2
4 2
5 3
输出：
4
```

**解释**：最长链 `1 → 2 → 3 → 5` 共 4 层（`2 → 4` 与 `3 → 5` 可并行）→ 总耗时 4。

---

## 提示

- 任务编号从 1 开始。
- 依赖方向不同版本可能相反（`a b` 也可能表示「b 依赖 a」），**先确认方向再建图**。
- 若存在环（互相依赖），任务永远无法完成，此时按题意输出（通常为 -1 或不存在环）。
- 核心考点：**并行执行 + 依赖 = 求 DAG 的最长链**（关键路径）。

---

## 思路

### 核心思想

拓扑排序 + BFS 分层（或 DP）：

```
1. 建图：b → a（b 完成后 a 才能开始），记录每个任务的入度
2. 队列初始化：所有入度为 0 的任务（第 1 层，耗时 1）
3. 逐层处理：
   - 处理当前层所有任务（并行，同层耗时只算 1）
   - 每个任务完成后，它的后继任务入度 -1，入度为 0 时进入下一层
4. 层数 = 最短开站时间
```

**为什么是「最长链」**：并行只影响「同一层内」的任务，串行链条无法压缩，所以答案 = 从任一无依赖任务出发的最长路径长度。

**逐步演示**（示例 2）：

```
依赖: 2←1, 3←2, 4←2, 5←3（b→a 边）
入度: 1:0, 2:1, 3:1, 4:1, 5:1

第 1 层: {1}        → 完成后: 2 的入度变 0
第 2 层: {2}        → 完成后: 3、4 入度变 0
第 3 层: {3, 4}     → 并行！完成后: 5 入度变 0
第 4 层: {5}
→ 共 4 层 → 输出 4 ✓
```

- 时间复杂度：\(O(V + E)\)
- 空间复杂度：\(O(V + E)\)

### 解法（Java，拓扑排序 + BFS）

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();            // 任务数
        int m = sc.nextInt();            // 依赖关系数

        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
        int[] indegree = new int[n + 1];

        for (int i = 0; i < m; i++) {
            int a = sc.nextInt();        // a 依赖 b
            int b = sc.nextInt();        // b 完成后 a 才能开始
            graph.get(b).add(a);         // 边 b → a
            indegree[a]++;
        }

        Queue<Integer> queue = new ArrayDeque<>();
        for (int i = 1; i <= n; i++) {
            if (indegree[i] == 0) queue.offer(i);
        }

        int time = 0;
        int done = 0;
        while (!queue.isEmpty()) {
            time++;                       // 新的一层（时间 +1）
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int cur = queue.poll();
                done++;
                for (int next : graph.get(cur)) {
                    if (--indegree[next] == 0) {
                        queue.offer(next);
                    }
                }
            }
        }

        // 若存在环，done < n
        System.out.println(done == n ? time : -1);
    }
}
```

> 💡 关键点：**每次取出整层**（`size` 固定）再处理，而不是边取边处理，才能正确按层计时。
