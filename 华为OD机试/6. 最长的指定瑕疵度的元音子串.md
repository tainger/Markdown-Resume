# 6. 最长的指定瑕疵度的元音子串

> **难度**：🔴 困难 | **分值**：300 | **标签**：滑动窗口、双指针 | **考点**：窗口收缩

## 题目描述

开头和结尾都是**元音字母**（`aeiouAEIOU`）的字符串称为**元音字符串**，其中混杂的**非元音字母数量**称为其**瑕疵度**。

例如：`"a"`、`"aa"` 是元音字符串（瑕疵度为 0）；`"aab"` 瑕疵度为 1（中间有一个非元音 `b`）。

给定一个字符串 S 和瑕疵度 k，请找出**最长的、瑕疵度恰好为 k 的元音字符串**（首尾必须都是元音），输出其长度；如果找不到，输出 0。

**输入描述**：

```
第一行：k（瑕疵度）
第二行：字符串 S
```

**输出描述**：最长元音子串的长度。

## 示例

```
输入：
0
asdbuiodevauufgh
输出：
3
```

**解释**：瑕疵度 0 → 子串必须全部是元音。S 中连续元音段：`uio`(3)、`e`(1)、`auu`(3)，最长 3。

**示例 2**

```
输入：
1
aba
输出：
3
```

**解释**：`aba` 首尾都是元音（a、a），中间 1 个非元音 `b`，瑕疵度恰为 1 → 长度 3。

---

## 提示

- 元音包含大小写：`a e i o u A E I O U`。
- 子串要求**首尾都是元音**，且**瑕疵度恰好等于 k**（不是 ≤）。
- 找不到输出 0。

---

## 思路

### 核心思想

滑动窗口（双指针）维护「以 right 结尾、瑕疵度 ≤ k 的最长窗口」，再检查是否满足三个条件：

```
条件：① 窗口内非元音个数 cnt == k
      ② 窗口左端 s[left] 是元音
      ③ 窗口右端 s[right] 是元音
满足 → 更新 ans = max(ans, right - left + 1)
```

```
right 遍历：
  1. s[right] 非元音 → cnt++
  2. cnt > k → 收缩 left：s[left] 非元音则 cnt--，left++
  3. 现在窗口 [left, right] 瑕疵度 ≤ k
  4. 若 cnt == k 且两端都是元音 → 更新答案
```

**为什么窗口收缩到 ≤ k 就够了**：所有以 right 结尾的窗口都包含在 `[left, right]` 里（比 left 更靠左的窗口瑕疵度 > k 不合法）；`[left, right]` 内若存在恰好 k 个瑕疵且两端元音的窗口，它必然以某个元音结尾（right 已是元音），只需保证左端。

**逐步演示**（`aba`，k=1）：

```
right=0: 'a' 元音, cnt=0 → cnt!=k
right=1: 'b' 非元音, cnt=1 → 窗口 [0,1]="ab", 左端 'a' 是元音但右端 'b' 不是 → 不更新
right=2: 'a' 元音, cnt=1 → 窗口 [0,2]="aba"
         cnt==k ✓, 左端 'a' ✓, 右端 'a' ✓ → ans = 3 ✓
```

- 时间复杂度：\(O(n)\)（每个字符最多进出窗口一次）
- 空间复杂度：\(O(1)\)

### 解法（Java，滑动窗口）

```java
import java.util.*;

public class Main {
    static boolean isVowel(char c) {
        return "aeiouAEIOU".indexOf(c) >= 0;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int k = Integer.parseInt(sc.nextLine().trim());
        String s = sc.nextLine().trim();

        int n = s.length();
        int left = 0, cnt = 0, ans = 0;

        for (int right = 0; right < n; right++) {
            if (!isVowel(s.charAt(right))) {
                cnt++;                    // 窗口瑕疵度 +1
            }
            while (cnt > k) {             // 瑕疵过多 → 收缩左边界
                if (!isVowel(s.charAt(left))) {
                    cnt--;
                }
                left++;
            }
            // 现在窗口 [left, right] 瑕疵度 ≤ k
            if (cnt == k
                    && isVowel(s.charAt(left))
                    && isVowel(s.charAt(right))) {
                ans = Math.max(ans, right - left + 1);
            }
        }

        System.out.println(ans);
    }
}
```

> 💡 常见坑：
> 1. 元音判断漏了**大写**；
> 2. 只判断 `cnt == k` 忘了检查**左端是元音**（左端是辅音时窗口不合法）；
> 3. `cnt < k` 时窗口不可能合法（所有以 right 结尾的子窗口瑕疵度都不超过 cnt），不要更新。
