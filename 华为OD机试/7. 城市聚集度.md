# 7. 城市聚集度

> **难度**：🔴 困难 | **分值**：300 | **标签**：树、DFS | **考点**：子树大小 / 拆树求最大块

## 题目描述

一张地图上有 n 个城市（编号 1 ~ n），城市和城市之间有且只有一条道路相连：要么直接相连，要么通过其它城市中转相连（可中转一次或多次）。即整个地图构成**一棵树**（n 个节点，n-1 条边），边由二维数组 `edges` 给出，每条边为 `[u, v]`。

当切断通往某个城市 i 的所有道路后，地图将分为多个**连通城市群**。设城市 i 的聚集度 \(DP_i\) 为：**切断 i 后，最大的城市群所包含的城市个数**。

返回**聚集度最小**的城市编号数组（若有多个，按编号升序排列）。

### 函数签名

```java
class Solution {
    public int[] findMinConcentrationCities(int n, int[][] edges) {
        // ...
    }
}
```

---

## 示例

### 示例 1

```
输入：n = 5, edges = [[1,2],[1,3],[2,4],[3,5]]
输出：[1]
```

**解释**：树结构为 `1-2-4` 和 `1-3-5`。

| 删除城市 | 剩余连通群 | 最大群大小（DP） |
|:---|:---|:---|
| 1 | {2,4}、{3,5} | 2 |
| 2 | {4}、{1,3,5} | 3 |
| 3 | {5}、{1,2,4} | 3 |
| 4 | {1,2,3,5} | 4 |
| 5 | {1,2,3,4} | 4 |

聚集度最小为 2（城市 1）→ 输出 `[1]`。

---

## 提示

- `1 <= n <= 1000`
- `edges.length == n - 1`
- `edges[i].length == 2`，`1 <= edges[i][0], edges[i][1] <= n`，`edges[i][0] != edges[i][1]`
- 图一定是**连通树**（n-1 条边），没有环。
- 切断城市 i 后，连通群 = i 的每个「子树」+ 「除 i 子树外的其余部分」。
- 聚集度最小 = **树的重心**思想（但这里比较的是最大块，不是最小块和）。

---

## 思路

### 核心思想

任选一个根（如 1）做一次 DFS，算出每棵子树的大小 `size[u]`。

对任意节点 u，切断它后：

```
删除 u 后的连通块：
  ① u 的每棵子树（大小 = size[child]）
  ② 除去 u 及 u 的子树外的部分（大小 = n - size[u]）

DP[u] = max( max(size[child]) , n - size[u] )
```

答案 = min(DP[u])，若有多个城市取最小，按编号升序输出。

**逐步演示**（示例，根 = 1）：

```
DFS 后子树大小:
  size[4]=1, size[5]=1
  size[2]=2 (含 4), size[3]=2 (含 5)
  size[1]=5

城市 1: 子树 {2:2, 3:2}, 其余 n-size[1]=0 → DP = max(2,2,0) = 2 ✓ 最小
城市 2: 子树 {4:1}, 其余 n-size[2]=3 → DP = max(1,3) = 3
城市 3: 子树 {5:1}, 其余 n-size[3]=3 → DP = max(1,3) = 3
城市 4: 无子树, 其余 n-size[4]=4 → DP = 4
城市 5: 无子树, 其余 n-size[5]=4 → DP = 4
→ 最小 DP = 2（城市 1）→ 输出 1 ✓
```

- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(n)\)

### 解法一：显式 parent 数组（推荐 ⭐）

**核心思想**：DFS 时额外记录 `parent[u]`，统计时用 `parent[v] == u` 精确判断 v 是否为 u 的孩子，逻辑最清晰、不易出错。

```java
import java.util.*;

class Solution {
    private List<List<Integer>> graph;
    private int[] size;
    private int[] parent;

    private void dfs(int u, int p) {
        parent[u] = p;
        size[u] = 1;
        for (int v : graph.get(u)) {
            if (v != p) {
                dfs(v, u);
                size[u] += size[v];
            }
        }
    }

    public int[] findMinConcentrationCities(int n, int[][] edges) {
        graph = new ArrayList<>();
        for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        size = new int[n + 1];
        parent = new int[n + 1];
        dfs(1, 0);

        int minDP = Integer.MAX_VALUE;
        List<Integer> ans = new ArrayList<>();

        for (int u = 1; u <= n; u++) {
            int dp = n - size[u];              // 父方向那一块
            for (int v : graph.get(u)) {
                if (parent[v] == u) {          // v 是 u 的子节点
                    dp = Math.max(dp, size[v]);
                }
            }
            if (dp < minDP) {
                minDP = dp;
                ans.clear();
                ans.add(u);
            } else if (dp == minDP) {
                ans.add(u);                    // 遍历顺序天然升序
            }
        }

        int[] res = new int[ans.size()];
        for (int i = 0; i < ans.size(); i++) res[i] = ans.get(i);
        return res;
    }
}
```

### 解法二：size 大小判断（最简洁）

**核心思想**：利用树的性质——孩子的 `size` 一定严格小于父亲。用 `size[v] < size[u]` 区分孩子与父亲，省去 `parent` 数组。

```java
import java.util.*;

class Solution {
    private List<List<Integer>> graph;
    private int[] size;

    private void dfs(int u, int p) {
        size[u] = 1;
        for (int v : graph.get(u)) {
            if (v != p) {
                dfs(v, u);
                size[u] += size[v];
            }
        }
    }

    public int[] findMinConcentrationCities(int n, int[][] edges) {
        graph = new ArrayList<>();
        for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        size = new int[n + 1];
        dfs(1, 0);

        int minDP = Integer.MAX_VALUE;
        List<Integer> ans = new ArrayList<>();

        for (int u = 1; u <= n; u++) {
            int dp = n - size[u];
            for (int v : graph.get(u)) {
                if (size[v] < size[u]) {       // 只考虑子节点
                    dp = Math.max(dp, size[v]);
                }
            }
            if (dp < minDP) {
                minDP = dp;
                ans.clear();
                ans.add(u);
            } else if (dp == minDP) {
                ans.add(u);
            }
        }

        int[] res = new int[ans.size()];
        for (int i = 0; i < ans.size(); i++) res[i] = ans.get(i);
        return res;
    }
}
```

> ⚠️ `size[v] < size[u]` 依赖「子树严格小于父」的性质。树中同一节点的两个邻居 size 不会相等（孩子 size 必 < 父，父 size 必 > 当前），因此安全。

### 解法三：换根 DP（两遍 DFS，拓展思路）

**核心思想**：第一遍 DFS 以 1 为根算 `size[]`；第二遍 DFS「换根」——把「父方向那一块的大小」作为参数 `upSize` 从父节点递推给子节点，递归中直接算出每个节点的 DP，无需再判断父子关系。

```java
import java.util.*;

class Solution {
    private List<List<Integer>> graph;
    private int[] size;
    private int[] dp;

    // 第一遍：以 1 为根算各子树大小
    private void dfs1(int u, int p) {
        size[u] = 1;
        for (int v : graph.get(u)) {
            if (v != p) {
                dfs1(v, u);
                size[u] += size[v];
            }
        }
    }

    // 第二遍：换根 DP
    // upSize = 切断 u 时「父方向」那一块的大小（由父节点递推下来）
    private void dfs2(int u, int p, int upSize, int n) {
        dp[u] = upSize;
        for (int v : graph.get(u)) {
            if (v != p) {
                dp[u] = Math.max(dp[u], size[v]);   // 子方向各块
            }
        }
        // 向子节点 v 换根：v 的「父方向」块 = n - size[v]
        // （包含 u、u 的父方向块、u 的其他子树，是一整块，大小恰为 n - size[v]）
        for (int v : graph.get(u)) {
            if (v != p) {
                dfs2(v, u, n - size[v], n);
            }
        }
    }

    public int[] findMinConcentrationCities(int n, int[][] edges) {
        graph = new ArrayList<>();
        for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        size = new int[n + 1];
        dp = new int[n + 1];
        dfs1(1, 0);
        dfs2(1, 0, 0, n);        // 根节点 1 的「父方向」块 = 0

        int minDP = Integer.MAX_VALUE;
        List<Integer> ans = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            if (dp[i] < minDP) {
                minDP = dp[i];
                ans.clear();
                ans.add(i);
            } else if (dp[i] == minDP) {
                ans.add(i);
            }
        }

        int[] res = new int[ans.size()];
        for (int i = 0; i < ans.size(); i++) res[i] = ans.get(i);
        return res;
    }
}
```

> 💡 **本题的「父方向块」恰好等于 `n - size[v]`**，可直接由 `size[]` 算出，所以换根 DP 在这里是「大材小用」——解法一/二更直接。换根 DP 的真正价值在于**父方向状态无法直接由 size 推出**的场景（如树上最大权路径、树形距离），此时必须把父方向状态递推下去。这里作为思想示范保留。

### 三种方案对比

| 方案 | 时间 | 空间 | 代码量 | 判断父子方式 | 推荐指数 |
|:---|:---:|:---:|:---:|:---|:---:|
| 解法一（parent 数组）| \(O(n)\) | \(O(n)\) | 中 | `parent[v] == u`（显式）| ⭐⭐⭐⭐⭐ |
| 解法二（size 比较）| \(O(n)\) | \(O(n)\) | 少 | `size[v] < size[u]`（隐式）| ⭐⭐⭐⭐ |
| 解法三（换根 DP）| \(O(n)\) | \(O(n)\) | 中 | 无需判断（递推 upSize）| ⭐⭐⭐ |

### 复杂度分析

- **时间复杂度**：三种方案均为 \(O(n)\)，建树 \(O(n)\) + DFS \(O(n)\) + 统计 \(O(n)\)。
- **空间复杂度**：均为 \(O(n)\)，邻接表 + `size`（解法一多一个 `parent`，解法三多一个 `dp`）。

> 💡 常见坑：
> 1. **树是无向的**，DFS 必须传 `parent`（或 `p`）防走回头路死循环。
> 2. **区分「孩子」与「父亲」是核心**：解法一用 `parent[v]==u` 最稳；解法二用 `size[v]<size[u]` 依赖子树严格小于父的性质。
> 3. **换根 DP 的陷阱**：一种常见错误写法是换根时把 `size[v] = n` 再用 `n - size[v]` 求父方向——这会让父方向块恒为 0，**漏算「除 v 子树外的其余部分」**（如本题删城市 2 时，`{1,3,5}` 这块大小 3 会被算成 0）。正确做法是直接用原始 `size[]` 推 `upSize = n - size[v]`，不要改写 `size`。
> 4. **递归栈**：n ≤ 1000 机试递归没问题；n 更大（如 10^5）链式树可能栈溢出，需改迭代栈或手动设大栈。
