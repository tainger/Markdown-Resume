# 7. 城市聚集度

> **难度**：🔴 困难 | **分值**：300 | **标签**：树、DFS | **考点**：子树大小 / 拆树求最大块

## 题目描述

一张地图上有 n 个城市（编号 1 ~ n），城市和城市之间有且只有一条道路相连：要么直接相连，要么通过其它城市中转相连（可中转一次或多次）。即整个地图构成**一棵树**（n 个节点，n-1 条边）。

当切断通往某个城市 i 的所有道路后，地图将分为多个**连通城市群**。设城市 i 的聚集度 \(DP_i\) 为：**切断 i 后，最大的城市群所包含的城市个数**。

求**聚集度最小**的城市编号（若有多个，按编号升序全部输出）。

**输入描述**：

```
第一行：n（城市数量）
接下来 n-1 行：每行两个整数 u v，表示城市 u 和城市 v 之间有道路
```

**输出描述**：聚集度最小的城市编号，多个时用空格分隔。

## 示例

```
输入：
5
1 2
1 3
2 4
3 5
输出：
1
```

**解释**：树结构为 `1-2-4` 和 `1-3-5`。

| 删除城市 | 剩余连通群 | 最大群大小（DP） |
|:---|:---|:---|
| 1 | {2,4}、{3,5} | 2 |
| 2 | {4}、{1,3,5} | 3 |
| 3 | {5}、{1,2,4} | 3 |
| 4 | {1,2,3,5} | 4 |
| 5 | {1,2,3,4} | 4 |

聚集度最小为 2（城市 1）→ 输出 `1`。

---

## 提示

- 图一定是**连通树**（n-1 条边），没有环。
- 切断城市 i 后，连通群 = i 的每个「子树」+ 「除 i 子树外的其余部分」。
- 聚集度最小 = **树的重心**思想（但这里比较的是最大块，不是最小块和）。

---

## 思路

### 核心思想

任选一个根（如 1）做一次 DFS，算出每棵子树的大小 `size[u]`。

对任意节点 u，切断它后：

```
删除 u 后的连通块：
  ① u 的每棵子树（大小 = size[child]）
  ② 除去 u 及 u 的子树外的部分（大小 = n - size[u]）

DP[u] = max( max(size[child]) , n - size[u] )
```

答案 = min(DP[u])，若有多个城市取最小，按编号升序输出。

**逐步演示**（示例，根 = 1）：

```
DFS 后子树大小:
  size[4]=1, size[5]=1
  size[2]=2 (含 4), size[3]=2 (含 5)
  size[1]=5

城市 1: 子树 {2:2, 3:2}, 其余 n-size[1]=0 → DP = max(2,2,0) = 2 ✓ 最小
城市 2: 子树 {4:1}, 其余 n-size[2]=3 → DP = max(1,3) = 3
城市 3: 子树 {5:1}, 其余 n-size[3]=3 → DP = max(1,3) = 3
城市 4: 无子树, 其余 n-size[4]=4 → DP = 4
城市 5: 无子树, 其余 n-size[5]=4 → DP = 4
→ 最小 DP = 2（城市 1）→ 输出 1 ✓
```

- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(n)\)

### 解法（Java，DFS 子树大小）

```java
import java.util.*;

public class Main {
    static List<List<Integer>> graph;
    static int[] size;
    static int n;

    // 计算子树大小（parent 防止走回头路）
    static void dfs(int u, int parent) {
        size[u] = 1;
        for (int v : graph.get(u)) {
            if (v != parent) {
                dfs(v, u);
                size[u] += size[v];
            }
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        n = sc.nextInt();

        graph = new ArrayList<>();
        for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());

        for (int i = 0; i < n - 1; i++) {
            int u = sc.nextInt(), v = sc.nextInt();
            graph.get(u).add(v);
            graph.get(v).add(u);
        }

        size = new int[n + 1];
        dfs(1, 0); // 任选根，如 1

        int minDP = Integer.MAX_VALUE;
        List<Integer> ans = new ArrayList<>();

        for (int u = 1; u <= n; u++) {
            int dp = n - size[u];        // 除 u 子树外的部分
            for (int v : graph.get(u)) {
                // 只考虑 u 的子树（v 是 u 的孩子时 size[v] 才是子树大小）
                if (size[v] < size[u]) {
                    dp = Math.max(dp, size[v]);
                }
            }
            if (dp < minDP) {
                minDP = dp;
                ans.clear();
                ans.add(u);
            } else if (dp == minDP) {
                ans.add(u);              // 编号升序（遍历顺序保证）
            }
        }

        for (int i = 0; i < ans.size(); i++) {
            if (i > 0) System.out.print(" ");
            System.out.print(ans.get(i));
        }
        System.out.println();
    }
}
```

> 💡 常见坑：
> 1. `size[v] < size[u]` 用来区分「孩子」和「父亲」——父亲节点的 size 一定大于当前节点，避免把整棵树当成子树；
> 2. 树是无向的，DFS 要传 `parent` 防死循环；
> 3. n 较大时递归可能栈溢出，可改迭代栈，但机试 n ≤ 1000 级别递归没问题。
