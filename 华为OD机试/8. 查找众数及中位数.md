# 8. 查找众数及中位数

> **难度**：🟢 简单 | **分值**：100 | **标签**：哈希、排序 | **考点**：众数统计 + 中位数

## 题目描述

1. **众数**是指一组数据中出现次数最多的那个数，众数可以是多个；
2. **中位数**是指把一组数据从小到大排列后最中间的那个数：如果个数为奇数，取最中间的数；如果个数为偶数，取中间两个数的平均值。

给定一组整型数据，请**把所有众数组成一个新数组**，求这个新数组的中位数并输出。

**输入描述**：一组整型数据（空格分隔）。

**输出描述**：众数组成的新数组的中位数。

## 示例

```
输入：
10 11 21 19 21 17 21 16 21 18 15
输出：
21
```

**解释**：`21` 出现 4 次（最多）→ 众数数组为 `[21]` → 中位数 21。

**示例 2**（多个众数）

```
输入：
1 2 2 3 3 4
输出：
2
```

**解释**：`2` 和 `3` 各出现 2 次（最多）→ 众数数组为 `[2,2,3,3]`（升序）→ 偶数个数取中间两数平均 `(2+3)/2 = 2`（整除）。

---

## 提示

- 众数可能多个，全部取出，**重复次数也要保留**（众数数组里每个众数出现 maxCount 次）。
- 中位数为新数组的中位数，不是原数组的。
- 偶数个数时「平均值」在不同版本可能取整或保留小数，以题意为准。

---

## 思路

### 核心思想

三步走：

```
1. 统计：HashMap<值, 次数>，同时记录最大次数 maxCount
2. 收集：把所有出现 maxCount 次的数，重复 maxCount 次放入新数组
3. 排序 + 中位数：升序排序；奇数取中间，偶数取中间两数和/2
```

**逐步演示**（示例 2）：

```
原数据: 1 2 2 3 3 4
计数:   1→1, 2→2, 3→2, 4→1      maxCount = 2
收集:   2 出现2次 → 放入2个2；3 出现2次 → 放入2个3
新数组: [2, 2, 3, 3]
排序:   [2, 2, 3, 3]
中位数: 偶数 4 个 → (2 + 3) / 2 = 2 ✓
```

- 时间复杂度：\(O(n \log n)\)（排序主导）
- 空间复杂度：\(O(n)\)

### 解法（Java）

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String[] parts = sc.nextLine().trim().split(" ");

        Map<Integer, Integer> cnt = new HashMap<>();
        int maxCount = 0;
        for (String p : parts) {
            int num = Integer.parseInt(p);
            int c = cnt.getOrDefault(num, 0) + 1;
            cnt.put(num, c);
            maxCount = Math.max(maxCount, c);
        }

        // 收集众数（出现 maxCount 次）
        List<Integer> list = new ArrayList<>();
        for (Map.Entry<Integer, Integer> e : cnt.entrySet()) {
            if (e.getValue() == maxCount) {
                for (int i = 0; i < maxCount; i++) {
                    list.add(e.getKey());
                }
            }
        }

        Collections.sort(list);
        int n = list.size();
        int mid = n / 2;
        if (n % 2 == 1) {
            System.out.println(list.get(mid));      // 奇数：最中间
        } else {
            System.out.println((list.get(mid - 1) + list.get(mid)) / 2); // 偶数：中间两数平均（整除）
        }
    }
}
```

> 💡 若题目要求偶数中位数保留小数，把 `(a+b)/2` 换成 `(a+b)/2.0` 输出即可。
