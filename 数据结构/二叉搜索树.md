# 二叉搜索树（Binary Search Tree, BST）

二叉搜索树是一棵**有序的二叉树**：对任意节点，**左子树所有值 < 该节点值 < 右子树所有值**。这条「左小右大」的递归约束，让它把「有序数组的二分查找」和「链表的动态增删」结合起来——查找、插入、删除都能做到 \(O(h)\)（`h` 为树高）。刷题里它是二叉树的重点子类，**中序遍历有序**是解题的万能钥匙。

---

## 一、核心性质

| 性质 | 说明 |
|:---|:---|
| **左小右大** | 对每个节点：左子树全部 `< val`，右子树全部 `> val`（递归成立，不只对直接孩子） |
| **中序遍历有序** | 左 → 根 → 右 的中序遍历得到**严格递增**序列（最重要的性质！） |
| **无重复值** | 标准 BST 通常不含重复元素（重复时需额外约定放左或放右） |
| **查找路径唯一** | 从根出发，比根小走左、比根大走右，路径唯一，长度 = \(O(h)\) |

```
          8                中序遍历： 1 3 4 6 7 8 10 13 14
        /   \              （得到的是升序序列 ✔）
       3     10
      / \      \
     1   6      14
        / \    /
       4   7  13
```

> **一句话抓住 BST**：它就是「把有序数组组织成树」。中序遍历还原有序数组，查找像二分。

---

## 二、三大基本操作

### 1. 查找（Search）

从根出发，比较目标与当前节点：相等即命中，较小走左，较大走右。

```java
TreeNode search(TreeNode root, int target) {
    while (root != null) {
        if (target == root.val) return root;   // 命中
        root = target < root.val ? root.left   // 比根小 → 左子树
                                 : root.right;  // 比根大 → 右子树
    }
    return null;                                // 没找到
}
```

### 2. 插入（Insert）

同样沿查找路径下降，走到空位置就挂上新节点。新节点**一定成为叶子**。

```java
TreeNode insert(TreeNode root, int val) {
    if (root == null) return new TreeNode(val); // 找到空位，创建
    if (val < root.val) root.left  = insert(root.left, val);
    else                 root.right = insert(root.right, val);
    return root;                                 // 返回本层根，供上层挂接
}
```

### 3. 删除（Delete）——最易错

删除要保持 BST 有序性，分三种情况：

| 情况 | 处理 |
|:---|:---|
| **叶子节点** | 直接删（置 null） |
| **只有一个孩子** | 用那个孩子顶替自己 |
| **有两个孩子** | 用「**右子树最小值**（后继）」或「**左子树最大值**（前驱）」替换本节点值，再去子树删掉那个替身 |

```java
TreeNode delete(TreeNode root, int key) {
    if (root == null) return null;
    if (key < root.val)      root.left  = delete(root.left, key);
    else if (key > root.val) root.right = delete(root.right, key);
    else {                                       // 找到要删的节点
        if (root.left == null)  return root.right;   // 情况1/2：无左孩子
        if (root.right == null) return root.left;    // 情况1/2：无右孩子
        TreeNode succ = root.right;                  // 情况3：找右子树最小值（后继）
        while (succ.left != null) succ = succ.left;
        root.val = succ.val;                         // 用后继值覆盖
        root.right = delete(root.right, succ.val);   // 再删掉后继
    }
    return root;
}
```

> 为什么用「右子树最小值」？因为它是**大于本节点的最小值**，替换后仍满足「左小右大」，且它必然没有左孩子（好删）。

## 三、中序遍历：BST 一切题的钥匙

BST 的中序遍历天然升序，几乎所有 BST 题都可归结为「在有序序列上做文章」。

```java
// 中序遍历 → 升序序列
void inorder(TreeNode root, List<Integer> res) {
    if (root == null) return;
    inorder(root.left, res);    // 左
    res.add(root.val);          // 根
    inorder(root.right, res);   // 右
}
```

由此衍生的高频套路：

| 需求 | 做法 |
|:---|:---|
| **验证是否为 BST** | 中序遍历必须严格递增（记录 `pre` 与当前比较） |
| **第 k 小元素** | 中序遍历第 `k` 个出队的值（不必全部遍历，计到 k 即停） |
| **第 k 大元素** | **反中序**（右 → 根 → 左）遍历第 `k` 个 |
| **累加树 / 求区间和** | 反中序累加，见 [538 把二叉搜索树转换为累加树](../leetcode-hot100/538.%20把二叉搜索树转换为累加树.md) |
| **两数之和** | 中序展开成有序数组后双指针 |

### 验证 BST（易错点最多）

```java
long pre = Long.MIN_VALUE;              // 用 long 防边界溢出
boolean isValidBST(TreeNode root) {
    if (root == null) return true;
    if (!isValidBST(root.left)) return false;   // 先左
    if (root.val <= pre) return false;          // 当前必须 > 前驱（严格递增）
    pre = root.val;                             // 更新前驱
    return isValidBST(root.right);              // 再右
}
```

> ⚠️ 常见错误：只比较「节点与其直接孩子」。BST 要求**整棵左子树都小于根**，不能只看左孩子。用中序 `pre` 或「上下界 `[lower, upper]` 递归传参」才正确。

## 四、其他常见构造

### 1. 有序数组构造平衡 BST

每次取**中点作根**，左右两半递归，保证树高 \(O(\log n)\)：

```java
TreeNode build(int[] nums, int lo, int hi) {
    if (lo > hi) return null;
    int mid = (lo + hi) >>> 1;              // 取中点作根，保证平衡
    TreeNode root = new TreeNode(nums[mid]);
    root.left  = build(nums, lo, mid - 1);
    root.right = build(nums, mid + 1, hi);
    return root;
}
```

### 2. 最近公共祖先（利用有序性）

BST 求 LCA 比普通二叉树简单——**都比根小去左，都比根大去右，否则当前就是分岔点（LCA）**：

```java
TreeNode lca(TreeNode root, TreeNode p, TreeNode q) {
    while (root != null) {
        if (p.val < root.val && q.val < root.val)      root = root.left;
        else if (p.val > root.val && q.val > root.val) root = root.right;
        else return root;                              // 一左一右 → 分岔点
    }
    return null;
}
```

## 五、复杂度分析

| 操作 | 平均（平衡） | 最坏（退化成链） |
|:---|:---:|:---:|
| 查找 / 插入 / 删除 | \(O(\log n)\) | \(O(n)\) |
| 中序遍历 | \(O(n)\) | \(O(n)\) |
| 空间（递归栈） | \(O(\log n)\) | \(O(n)\) |

> 关键在**树高 `h`**：随机插入近似 \(O(\log n)\)，但**按有序序列插入会退化成链表**（\(O(n)\)）。这正是 **AVL 树、红黑树** 通过旋转自平衡的动机；工程里 `TreeMap`/`TreeSet`（红黑树）保证最坏也 \(O(\log n)\)。

## 六、易错点与技巧

### 1. 验证 BST 别只看父子

必须保证「整棵子树」都在合法区间，用中序 `pre` 或上下界 `[lower, upper]`，不能只比直接孩子。

### 2. 边界溢出

验证 BST 时，若节点值可能取 `Integer.MAX_VALUE`/`MIN_VALUE`，`pre` 用 `long` 或改用 `Integer` 对象判空，避免溢出误判。

### 3. 删除节点要「返回新根」

递归删除必须 `root.left = delete(root.left, key)` 这样接住返回值，否则删除结果丢失。两孩子情况记得**删完替身**，别漏。

### 4. 第 k 小可提前终止

中序计数到 `k` 即可 `return`，不必遍历完整棵树，均摊更快。

### 5. 中序的「前驱指针」是全局状态

无论验证 BST、找众数（[501]）还是累加树，都靠一个跨递归的 `pre`，用**成员变量或数组**承载，别用值传递。

---

## 七、一句话总结

BST 是「有序数组的树形化」：**左小右大 + 中序有序**是全部题目的两把钥匙——查找/插入/删除沿路径下降是 \(O(h)\)，验证、第 k 小/大、累加树都落在中序（或反中序）遍历上；牢记**树高退化会到 \(O(n)\)**，这就是自平衡树存在的理由。
