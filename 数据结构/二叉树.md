# 二叉树（Binary Tree）

二叉树是每个节点**最多有两个孩子**（左孩子、右孩子）的树结构。它是链表向「分叉」的推广，也是 BST、堆、字典树、线段树等一切树形结构的地基。刷题里超高频——**遍历是根，递归是魂**。

---

## 一、基本概念

| 概念 | 说明 |
|:---|:---|
| **节点 / 根 / 叶子** | 根无父节点；叶子无孩子 |
| **深度 / 高度** | 深度：根到该点的边数（根深度 0）；高度：该点到最深叶子的边数 |
| **满二叉树** | 每个节点要么 0 个孩子要么 2 个孩子 |
| **完全二叉树** | 除最后一层外全满，且最后一层节点靠左连续排列（**堆的形态**） |
| **平衡二叉树** | 任意节点左右子树高度差 ≤ 1（AVL、红黑树近似） |
| **二叉搜索树 BST** | 左 < 根 < 右，中序遍历有序（见 [二叉搜索树.md](二叉搜索树.md)） |

```
        1              节点值 1
       / \
      2   3            2 是 1 的左孩子，3 是右孩子
     / \   \
    4   5   6          4、5、6 是叶子
```

### 节点定义（Java）

```java
class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}
```

> 记住三组「特例关系」：**满 ⊂ 完全**（满一定完全，反之不一定）；**完全二叉树可用数组存**（`i` 的孩子是 `2i+1`、`2i+2`）；**BST + 平衡 = 高效查找**。

## 二、四种遍历（刷题绝对核心）

### 1. 深度优先（DFS）：前序 / 中序 / 后序

区别只在**「根」在什么时候访问**，左右顺序永远「先左后右」：

| 遍历 | 顺序 | 递归代码位置 | 典型用途 |
|:---|:---|:---|:---|
| **前序** | 根 → 左 → 右 | 处理在递归前 | 复制树、序列化、自顶向下传参 |
| **中序** | 左 → 根 → 右 | 处理在两次递归中间 | **BST 得有序序列** |
| **后序** | 左 → 右 → 根 | 处理在递归后 | 自底向上（求高度、删树、[树形 DP](../leetcode-hot100/337.%20打家劫舍%20III.md)） |

```java
void inorder(TreeNode root, List<Integer> res) {
    if (root == null) return;
    inorder(root.left, res);       // 左
    res.add(root.val);             // 根（中序：放中间）
    inorder(root.right, res);      // 右
}
```

### 2. 中序遍历的迭代写法（用栈）

递归会爆栈时改用显式栈，中序最常考：

```java
List<Integer> inorderIterative(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {          // 一路向左压栈
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();             // 弹出即「最左未处理」
        res.add(cur.val);              // 访问根
        cur = cur.right;               // 转向右子树
    }
    return res;
}
```

### 3. 广度优先（BFS）：层序遍历

用队列逐层扫，**「整层处理」**是关键技巧——每轮先固定 `size = queue.size()`：

```java
List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new ArrayDeque<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int size = q.size();               // 锁定当前整层
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = q.poll();
            level.add(node.val);
            if (node.left != null) q.offer(node.left);
            if (node.right != null) q.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

- **用途**：层序、每层最右（右视图）、之字形、找某一层（如华为 OD「二叉树第 k 层」）。

## 三、递归解题的通用套路

二叉树 90% 的题都是递归。写递归只需想清三件事：

1. **返回值 & 参数**：这个函数返回什么给父节点？（一个值？还是 [多个状态](../leetcode-hot100/124.%20二叉树中的最大路径和.md)？）
2. **终止条件**：`root == null` 时返回什么（通常是递归的「空树答案」）。
3. **单层逻辑**：拿到左右子树的递归结果后，当前节点怎么合并。

```java
// 模板：求最大深度（后序：先拿左右深度，再合并）
int maxDepth(TreeNode root) {
    if (root == null) return 0;                 // 终止：空树深度 0
    int left = maxDepth(root.left);             // 左子树深度
    int right = maxDepth(root.right);           // 右子树深度
    return Math.max(left, right) + 1;           // 单层逻辑：取大 + 当前层
}
```

> **两种递归视角**：① **自顶向下**（前序，把信息作参数传下去，如路径和）；② **自底向上**（后序，把子树结果收上来合并，如求高度、[124 最大路径和](../leetcode-hot100/124.%20二叉树中的最大路径和.md)、[337 打家劫舍 III](../leetcode-hot100/337.%20打家劫舍%20III.md)）。**分不清用哪种时，先问「当前节点需要子树的什么信息」**。

## 五、复杂度

| 操作 | 时间 | 空间 |
|:---|:---:|:---:|
| 任意遍历（DFS/BFS） | \(O(n)\) | \(O(h)\) 递归栈 / \(O(w)\) 队列 |
| 建树 | \(O(n)\) | \(O(n)\) |
| 求高度 / 深度 | \(O(n)\) | \(O(h)\) |

> `h` 是树高：平衡树 \(O(\log n)\)，退化成链表时 \(O(n)\)；`w` 是最宽层节点数。

## 六、易错点与技巧

### 1. 前中后序的差别只在「根的位置」

代码几乎一样，只是 `res.add(root.val)` 放在两次递归的**前 / 中 / 后**。别死记，理解「根什么时候处理」即可。

### 2. 中序遍历 BST 得到有序序列

这是 BST 一切题的钥匙——验证 BST、找第 k 小、[538 累加树](../leetcode-hot100/538.%20把二叉搜索树转换为累加树.md)（反中序）都靠它。

### 3. BFS 分层必须先固定 `size`

`for` 循环里会往队列加下一层节点，若不先存 `size = q.size()`，会把下一层也算进当前层。

### 4. 树形 DP 常需返回「多个值」

只返回一个「最大值」往往丢信息。[337](../leetcode-hot100/337.%20打家劫舍%20III.md) 返回 `[偷, 不偷]`、[124](../leetcode-hot100/124.%20二叉树中的最大路径和.md) 区分「单边贡献」和「拐点答案」——**当父节点需要子树的多种情况时，返回数组或用全局变量**。

### 5. 递归爆栈风险

极度不平衡的树（退化成链）深度可达 `n`，`n` 很大时递归爆栈，改迭代（栈）或 BFS。

### 6. 空节点的处理

大量 bug 源于漏判 `null`。递归第一行几乎总是 `if (root == null) return ...`；序列化时 null 也要显式占位（见 [297](../leetcode-hot100/297.%20二叉树的序列化与反序列化.md)）。

---

## 七、一句话总结

二叉树题的解法几乎都是**递归**：想清「返回值 / 终止条件 / 单层逻辑」三件事；**前中后序的区别只是根在何时处理，层序靠队列整层扫**；自顶向下用前序传参、自底向上用后序合并、需要多信息就返回数组——这套框架能覆盖绝大多数二叉树题。
