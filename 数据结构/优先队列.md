# 优先队列（Priority Queue）与堆（Heap）

优先队列是一种**每次取出的都是「优先级最高」元素**的队列（而非先进先出）。它最常用**二叉堆**实现——一棵「完全二叉树」，用**数组**存储，支持 \(O(\log n)\) 插入、\(O(\log n)\) 弹出堆顶、\(O(1)\) 查看堆顶。刷题里是 Top-K、合并 K 路、Dijkstra、中位数、任务调度的看家结构。

---

## 一、核心概念

| 概念 | 说明 |
|:---|:---|
| **小顶堆（Min-Heap）** | 堆顶是**最小值**，父节点 ≤ 两个孩子 |
| **大顶堆（Max-Heap）** | 堆顶是**最大值**，父节点 ≥ 两个孩子 |
| **完全二叉树形态** | 除最后一层外全满、最后一层靠左 → 可用数组紧凑存储 |
| **堆序性** | 只保证「父子有序」，**兄弟之间、跨子树之间无序**（不是排序！） |

### 数组存储的下标关系（0-based）

```
        堆顶(下标0)
       /          \
   下标1           下标2
   /   \           /
 下标3  下标4    下标5

父节点 parent(i) = (i - 1) / 2
左孩子 left(i)   = 2i + 1
右孩子 right(i)  = 2i + 2
```

> 堆**不是有序数组**——它只保证堆顶是极值，其余元素部分有序。想「取出前 K 个有序」得逐个 `poll`。

---

## 二、两个核心操作：上浮与下沉

### 1. 上浮（sift-up）：插入时用

新元素放到数组末尾，不断和父节点比较，若比父节点「更该在上面」就交换，直到到位。

```java
// 小顶堆上浮：heap[i] 比父节点小就往上换
void siftUp(int[] heap, int i) {
    while (i > 0) {
        int parent = (i - 1) / 2;
        if (heap[i] >= heap[parent]) break;   // 已满足堆序，停
        swap(heap, i, parent);
        i = parent;
    }
}
```

### 2. 下沉（sift-down）：弹出堆顶时用

弹出堆顶后，把末尾元素移到堆顶，不断和「更极端的那个孩子」比较交换，直到到位。

```java
// 小顶堆下沉：heap[i] 比孩子大就往下换
void siftDown(int[] heap, int i, int size) {
    while (2 * i + 1 < size) {
        int child = 2 * i + 1;                          // 左孩子
        if (child + 1 < size && heap[child + 1] < heap[child]) {
            child++;                                     // 取更小的孩子
        }
        if (heap[i] <= heap[child]) break;               // 已满足堆序，停
        swap(heap, i, child);
        i = child;
    }
}
```

- 插入 = 末尾追加 + 上浮；弹出 = 堆顶与末尾交换、删末尾、堆顶下沉。两者都 \(O(\log n)\)（树高）。

## 三、Java `PriorityQueue` 用法（刷题直接用）

```java
// 默认小顶堆
PriorityQueue<Integer> minHeap = new PriorityQueue<>();

// 大顶堆：传入反向比较器
PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
// 或 new PriorityQueue<>(Collections.reverseOrder());

// 自定义对象：按某字段排序（如按距离小顶堆）
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]);

minHeap.offer(3);          // 入堆 O(log n)
int top = minHeap.peek();  // 看堆顶 O(1)，不删除
int min = minHeap.poll();  // 弹堆顶 O(log n)
int sz  = minHeap.size();
```

> ⚠️ 比较器用 `a - b` 可能因**整数溢出**出错（如 `Integer.MIN_VALUE`），稳妥用 `Integer.compare(a, b)`。

## 四、经典应用套路

### 1. Top-K 问题（最高频！）

**求前 K 大 → 用「大小为 K 的小顶堆」**（反直觉但关键）：堆里始终保留当前最大的 K 个，堆顶是这 K 个里最小的（最易被淘汰者）。新元素比堆顶大就替换。

```java
// 求前 K 大：维护大小为 K 的小顶堆
PriorityQueue<Integer> heap = new PriorityQueue<>();   // 小顶堆
for (int x : nums) {
    heap.offer(x);
    if (heap.size() > k) heap.poll();                  // 超过 K 个就弹最小
}
// 堆里就是前 K 大，堆顶是第 K 大
```

- **口诀**：**求前 K 大用小顶堆，求前 K 小用大顶堆**。复杂度 \(O(n\log k)\)，优于全排序 \(O(n\log n)\)。见 [347 前 K 个高频元素](../leetcode-hot100/347.%20前%20K%20个高频元素.md)、215 第 K 大。

### 2. 合并 K 路有序（[23 合并 K 个升序链表](../leetcode-hot100/23.%20合并%20K%20个升序链表.md)）

堆里只放「每路当前候选头」（恒 ≤ K 个），弹最小后补它的后继，\(O(N\log k)\)。

### 3. Dijkstra 最短路

小顶堆按「到源点距离」排序，每次贪心取最近的未确定点。见 [图.md](图.md) 第五节。

### 4. 数据流中位数（295）

**大顶堆存较小一半 + 小顶堆存较大一半**，两堆大小平衡，中位数即堆顶。对顶堆是经典技巧。

### 5. 任务调度 / 堆模拟

按结束时间、频率等排序动态取极值，见 [621 任务调度器](../leetcode-hot100/621.%20任务调度器.md)、[253 会议室 II](../leetcode-hot100/253.%20会议室%20II.md)。

## 五、建堆（heapify）与堆排序

### 原地建堆：\(O(n)\) 而非 \(O(n\log n)\)

从**最后一个非叶子节点**（下标 `n/2 - 1`）开始，依次向前对每个节点下沉：

```java
void buildHeap(int[] arr) {
    int n = arr.length;
    for (int i = n / 2 - 1; i >= 0; i--) {
        siftDown(arr, i, n);
    }
}
```

> 逐个 `offer` 建堆是 \(O(n\log n)\)；自底向上 `heapify` 是 **\(O(n)\)**（底层节点多但下沉浅，数学求和收敛到 `O(n)`）。

### 堆排序：\(O(n\log n)\)、原地、不稳定

建大顶堆 → 反复「堆顶与末尾交换 + 缩小堆 + 下沉」，得升序数组。

## 六、复杂度速查

| 操作 | 时间 |
|:---|:---:|
| 查看堆顶 `peek` | \(O(1)\) |
| 插入 `offer` | \(O(\log n)\) |
| 弹出堆顶 `poll` | \(O(\log n)\) |
| 建堆 `heapify` | \(O(n)\) |
| 堆排序 | \(O(n\log n)\) |
| 查找任意元素 | \(O(n)\)（堆非有序，无法二分） |

## 七、易错点与技巧

### 1. 求前 K 大用「小顶堆」，别用大顶堆

最反直觉的点：小顶堆堆顶是「K 个候选里最小的」，正是最该被更大新元素挤掉的。用大顶堆得全部入堆再弹 K 次，退化成 \(O(n\log n)\)。

### 2. Java `PriorityQueue` 默认是小顶堆

要大顶堆必须显式传比较器 `(a,b) -> b - a`，忘了会拿错极值。

### 3. 比较器防溢出

`a - b` 在极端值下溢出，改用 `Integer.compare(a, b)` 或 `Long.compare`。

### 4. 堆不能高效「查找 / 删除任意元素」

只有堆顶 \(O(1)\)/\(O(\log n)\)。要频繁删中间元素得用「懒删除 + 哈希标记」或换 `TreeMap`。

### 5. `peek` 前先判空

对空堆 `peek()`/`poll()` 返回 `null`（引用类型）或抛异常，循环里先 `!heap.isEmpty()`。

### 6. 堆顶 ≠ 有序

别以为遍历堆的底层数组是有序的——它只是完全二叉树的层序，除堆顶外无序保证。

---

## 八、一句话总结

优先队列用**二叉堆（数组存的完全二叉树）**实现，只保证堆顶是极值；插入 / 弹顶 \(O(\log n)\)、看顶 \(O(1)\)、建堆 \(O(n)\)。刷题记牢一句：**「求前 K 大用小顶堆、前 K 小用大顶堆」**；合并 K 路、Dijkstra、数据流中位数（对顶堆）都是它的主场。
