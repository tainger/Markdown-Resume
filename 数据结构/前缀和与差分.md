# 前缀和与差分（Prefix Sum & Difference Array）

前缀和与差分是一对「**逆运算**」的数组技巧：**前缀和**把「区间求和」从 \(O(n)\) 降到 \(O(1)\)（预处理后），**差分**把「区间批量加减」从 \(O(n)\) 降到 \(O(1)\)。它们不是独立数据结构，而是刷题里处理「区间统计 / 区间更新」的核心套路，与哈希表配合还能解一大类子数组问题。

---

## 一、前缀和（Prefix Sum）

### 核心定义（一维）

`preSum[i]` = 原数组前 `i` 个元素之和。约定 `preSum[0] = 0`（空前缀）：

$$preSum[i] = a_0 + a_1 + \cdots + a_{i-1}$$

则**任意区间 `[l, r]` 的和** = `preSum[r+1] - preSum[l]`，\(O(1)\) 得到。

```
a       =  [3, 1, 4, 1, 5]
preSum  = [0, 3, 4, 8, 9, 14]        preSum[0]=0
                                     区间和 a[1..3] = preSum[4]-preSum[1] = 9-3 = 6
```

```java
int[] pre = new int[n + 1];                  // 多留一位，pre[0]=0
for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + a[i];
int sum = pre[r + 1] - pre[l];               // 区间 [l, r] 的和，O(1)
```

> 关键：**多开一位、`pre[0]=0`**，让区间和公式统一，避免 `l=0` 的边界特判。

### 二维前缀和

`pre[i][j]` = 左上角到 `(i-1, j-1)` 的矩形和，用容斥求子矩阵和：

```java
pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i-1][j-1];
// 子矩阵 (r1,c1)~(r2,c2) 之和：
int s = pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1];
```

## 二、前缀和 + 哈希（高频套路）

求「**和为 K 的连续子数组个数**」：区间和 = `pre[j] - pre[i] = k`，即 `pre[i] = pre[j] - k`。**边扫边用哈希记录各前缀和出现次数**，查 `pre[j]-k` 出现过几次即可，\(O(n)\)。

```java
// 560. 和为 K 的子数组
int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> cnt = new HashMap<>();
    cnt.put(0, 1);                       // 空前缀和为 0 出现一次（关键初始化！）
    int pre = 0, res = 0;
    for (int x : nums) {
        pre += x;
        res += cnt.getOrDefault(pre - k, 0);   // 有多少个 i 使 pre[i]=pre-k
        cnt.merge(pre, 1, Integer::sum);        // 记录当前前缀和
    }
    return res;
}
```

> ⚠️ **必须 `cnt.put(0, 1)`**：表示「空前缀」，否则会漏掉「从下标 0 开始就等于 k」的子数组。见 [560 和为 K 的子数组](../leetcode-hot100/560.%20和为%20K%20的子数组.md)、[哈希表.md](哈希表.md)。

## 三、差分（Difference Array）

### 核心思想

差分是前缀和的逆：`diff[i] = a[i] - a[i-1]`。对 `diff` 求前缀和还原出 `a`。它的威力在于——**对原数组区间 `[l, r]` 整体加 `val`，只需改 `diff` 两个位置**：

```
diff[l]   += val;      // 从 l 起都加了 val
diff[r+1] -= val;      // 从 r+1 起把多加的减回去
```

最后对 `diff` 做一次前缀和，就得到所有区间更新后的结果。**m 次区间更新 + 一次还原 = \(O(n + m)\)**，远优于每次 \(O(n)\) 暴力。

```java
int[] diff = new int[n + 1];
// 多次区间加
for (int[] op : operations) {           // op = {l, r, val}
    diff[op[0]] += op[2];
    diff[op[1] + 1] -= op[2];
}
// 前缀和还原
int[] res = new int[n];
res[0] = diff[0];
for (int i = 1; i < n; i++) res[i] = res[i - 1] + diff[i];
```

### 典型应用：扫描线 / 事件计数

「会议室 II」「拼车」等区间重叠问题：在区间起点 `+1`、终点 `-1`，前缀和的**峰值 = 最大同时重叠数**。见 [253 会议室 II](../leetcode-hot100/253.%20会议室%20II.md)、1094 拼车。

## 四、复杂度对比

| 场景 | 暴力 | 前缀和 / 差分 |
|:---|:---:|:---:|
| 单次区间求和 | \(O(n)\) | \(O(1)\)（预处理 \(O(n)\)） |
| m 次区间求和 | \(O(mn)\) | \(O(n + m)\) |
| m 次区间批量加 | \(O(mn)\) | \(O(n + m)\)（差分） |
| 和为 K 的子数组 | \(O(n^2)\) | \(O(n)\)（前缀和 + 哈希） |

> 局限：前缀和/差分适合**「先大量更新、后统一查询」或「先固定、后多次查询」的离线场景**。若更新与查询**交替进行**，需改用 [线段树与树状数组.md](线段树与树状数组.md)（支持在线的 \(O(\log n)\) 单点/区间更新与查询）。

## 五、易错点与技巧

### 1. 前缀和多开一位、`pre[0]=0`

统一区间公式 `pre[r+1]-pre[l]`，消除 `l=0` 特判。

### 2. 前缀和 + 哈希务必初始化 `(0,1)`

漏了会算错从头开始的子数组个数。

### 3. 差分的 `r+1` 可能越界

数组要开 `n+1`（甚至 `n+2`）长度，`diff[r+1]` 才不越界。

### 4. 溢出

大数组累加可能超 `int`，前缀和用 `long`。

### 5. 前缀积（如 [238 除自身以外数组的乘积](../leetcode-hot100/238.%20除自身以外数组的乘积.md)）

同思想推广到乘法：用「左积 × 右积」避开除法（还能处理含 0）。

---

## 六、一句话总结

前缀和让**区间求和 \(O(1)\)**、差分让**区间批量加减 \(O(1)\)**，二者互为逆运算——**多开一位 + `pre[0]=0`** 统一边界；**前缀和 + 哈希**把「和为 K 子数组」压到 \(O(n)\)（记得 `put(0,1)`）；差分的扫描线求**重叠峰值**。它们是离线区间统计/更新的首选，需要在线交替更新查询时才上线段树/树状数组。
