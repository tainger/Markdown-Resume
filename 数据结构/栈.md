# 栈（Stack）与单调栈

栈是一种**后进先出（LIFO, Last In First Out）**的线性结构：只能在同一端（栈顶）进行插入（push）和删除（pop）。它是括号匹配、表达式求值、递归模拟、DFS 的底层结构；而它的变体**单调栈**更是「找下一个更大/更小元素」这一大类题的固定解法。

---

## 一、核心概念

| 概念 | 说明 |
|:---|:---|
| **栈顶（top）** | 唯一可操作的一端，push/pop/peek 都在这里 |
| **LIFO** | 后进先出——最后压入的最先弹出 |
| **push / pop / peek** | 入栈 / 出栈 / 查看栈顶（不删除），均 \(O(1)\) |
| **空栈判断** | 操作前必须判空，否则 pop/peek 会异常 |

```
push(1) push(2) push(3)          pop() → 3
   ┌───┐    ┌───┐                  ┌───┐
   │ 3 │←top │   │                  │ 2 │←top
   ├───┤    ├───┤                  ├───┤
   │ 2 │    │ 2 │                  │ 1 │
   ├───┤    ├───┤                  └───┘
   │ 1 │    │ 1 │
   └───┘    └───┘
```

### Java 用法（刷题直接用 `Deque`）

```java
// 推荐用 Deque，别用过时的 Stack 类（同步开销大）
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);              // 入栈
int top = stack.peek();     // 看栈顶，不删除
int x   = stack.pop();      // 出栈
boolean empty = stack.isEmpty();
```

> ⚠️ 老 `java.util.Stack` 继承自 `Vector`、方法带 `synchronized`，且底层「栈底在数组头」语义反直觉。刷题一律用 `ArrayDeque` 当栈。

## 二、普通栈的经典套路

### 1. 括号匹配（[20 有效的括号](../leetcode-hot100/20.有效的括号.md)）

遇左括号入栈，遇右括号弹栈顶比对，最后栈空才合法。

```java
boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    Map<Character, Character> pair = Map.of(')', '(', ']', '[', '}', '{');
    for (char c : s.toCharArray()) {
        if (pair.containsKey(c)) {                         // 右括号
            if (stack.isEmpty() || stack.pop() != pair.get(c)) return false;
        } else stack.push(c);                              // 左括号入栈
    }
    return stack.isEmpty();
}
```

### 2. 辅助栈 / 最小栈（[155 最小栈](../leetcode-hot100/155.%20最小栈.md)）

主栈存数据，**同步一个「当前最小值栈」**，使 `getMin()` 保持 \(O(1)\)。

### 3. 表达式求值 / 嵌套解析（[394 字符串解码](../leetcode-hot100/394.%20字符串解码.md)）

嵌套结构（括号内含括号）用栈把「外层状态」压起来，遇 `]` 弹出结算。递归与栈本质等价。

### 4. 递归改迭代 / DFS

系统调用栈就是栈。递归爆栈时用**显式栈**手动模拟（如二叉树中序迭代遍历、岛屿 DFS 转迭代）。

## 三、单调栈（Monotonic Stack）——高频重点

**单调栈**：维护一个栈内元素**单调递增或单调递减**的栈。新元素入栈前，把破坏单调性的栈顶不断弹出——被弹出的那一刻，往往就找到了它的答案。

**能解决的问题模型**：对每个元素，求它**左边/右边第一个比它大/小**的元素（或其下标、距离）。

### 口诀

| 求「下一个更大」 | 维护**单调递减栈**（存下标）；遇到更大元素时弹栈，被弹者的答案就是当前元素 |
|:---|:---|
| 求「下一个更小」 | 维护**单调递增栈** |

### 模板（[739 每日温度](../leetcode-hot100/739.%20每日温度.md)：找右边第一个更大）

```java
int[] dailyTemperatures(int[] t) {
    int n = t.length;
    int[] res = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();   // 存下标，对应温度单调递减
    for (int i = 0; i < n; i++) {
        // 当前温度比栈顶更高 → 栈顶找到了它右边第一个更大值
        while (!stack.isEmpty() && t[i] > t[stack.peek()]) {
            int idx = stack.pop();
            res[idx] = i - idx;                  // 距离（等更暖的天数）
        }
        stack.push(i);                           // 当前下标入栈
    }
    return res;
}
```

### 应用扩展

- **[42 接雨水](../leetcode-hot100/42.%20接雨水.md)**：单调递减栈，遇更高柱子时结算「凹槽」积水（横向按层接水）。
- **[85 最大矩形](../leetcode-hot100/85.%20最大矩形.md)** / 84 柱状图最大矩形：单调递增栈求每根柱子能扩展的左右边界。
- **[32 最长有效括号](../leetcode-hot100/32.%20最长有效括号.md)**：栈存下标，配合 `-1` 哨兵计算有效长度。

> 单调栈把「对每个元素找两侧第一个更大/更小」从暴力 \(O(n^2)\) 降到 **\(O(n)\)**——每个元素**最多入栈、出栈各一次**。

## 四、复杂度分析

| 操作 | 时间 | 空间 |
|:---|:---:|:---:|
| push / pop / peek | \(O(1)\) | — |
| 括号匹配 / 表达式求值 | \(O(n)\) | \(O(n)\) |
| 单调栈整体 | \(O(n)\)（每元素进出各一次） | \(O(n)\) |

---

## 五、易错点与技巧

### 1. 操作前必须判空

`pop()` / `peek()` 空栈会抛异常，循环里先 `!stack.isEmpty()`。

### 2. 单调栈一般存「下标」而非「值」

存下标既能取值 `arr[stack.peek()]`，又能算距离 `i - idx`，信息更全。

### 3. 想清「维护递增还是递减」

**求下一个更大 → 递减栈；求下一个更小 → 递增栈**。弹栈时机（`>` 还是 `>=`）决定相等元素如何处理，按题意定。

### 4. 哨兵简化边界

接雨水/最大矩形常在数组两端补 `0`（或用 `-1` 下标）当哨兵，避免最后栈内残留元素的特判。

### 5. 栈 ↔ 递归可互相转换

递归本质就是栈；深度过大爆栈时改显式栈迭代。

---

## 六、一句话总结

栈是「后进先出」的一端结构，push/pop/peek 全 \(O(1)\)——括号匹配、嵌套解析、递归模拟靠它；而**单调栈**是它最重要的应用：**对每个元素找两侧第一个更大/更小时，维护单调栈可把 \(O(n^2)\) 压到 \(O(n)\)**，记住「求更大用递减栈、求更小用递增栈、栈里存下标」。
