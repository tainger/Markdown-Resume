# 线段树与树状数组（Segment Tree & Binary Indexed Tree）

当「区间查询」和「元素更新」**交替、在线**进行时，前缀和会失效（每次更新都要 \(O(n)\) 重建）。线段树和树状数组正是为此而生——都支持 **\(O(\log n)\)** 的单点更新与区间查询。树状数组（BIT / Fenwick）代码短、常数小，适合前缀和类；线段树更通用，能维护区间和/最值/更多信息，还支持区间更新。

---

## 一、为什么需要它们

| 需求 | 前缀和 | 树状数组 / 线段树 |
|:---|:---:|:---:|
| 区间求和（不改动） | \(O(1)\) ✔ | \(O(\log n)\) |
| **单点更新 + 区间查询（交替）** | 更新 \(O(n)\) ✘ | **\(O(\log n)\)** ✔ |
| 区间更新 + 区间查询 | ✘ | 线段树（含懒标记）✔ |

> 一句话：**只查不改用前缀和；边改边查用树状数组 / 线段树**（见 [前缀和与差分.md](前缀和与差分.md)）。

---

## 二、树状数组（Binary Indexed Tree, Fenwick）

### 核心：`lowbit` 与「管辖区间」

每个下标 `i` 管辖一段长度为 `lowbit(i)` 的区间，`lowbit(i) = i & (-i)`（取最低位的 1）。更新和查询都沿 `lowbit` 跳跃，步数 = 二进制位数 = \(O(\log n)\)。

```
tree[i] 管辖 (i - lowbit(i), i]
下标：   1    2    3    4    5    6    7    8
lowbit： 1    2    1    4    1    2    1    8
       [1] [1,2] [3] [1..4][5][5,6][7][1..8]
```

### 模板（单点加 + 前缀和查询，1-based）

```java
class BIT {
    int[] tree; int n;
    BIT(int n) { this.n = n; tree = new int[n + 1]; }   // 下标从 1 开始

    int lowbit(int x) { return x & (-x); }

    void update(int i, int delta) {                     // 下标 i 增加 delta
        for (; i <= n; i += lowbit(i)) tree[i] += delta;
    }
    int query(int i) {                                  // 前缀和 [1, i]
        int s = 0;
        for (; i > 0; i -= lowbit(i)) s += tree[i];
        return s;
    }
    int rangeQuery(int l, int r) {                      // 区间和 [l, r]
        return query(r) - query(l - 1);
    }
}
```

> 树状数组只擅长「**可差分**」的信息（和、异或）；区间最值不能简单差分，得用线段树。

## 三、线段树（Segment Tree）

### 核心思想

把区间 `[0, n-1]` 递归**二分**，每个节点存一段区间的聚合值（和/最大/最小…）。查询和更新都从根往下走到相关区间，\(O(\log n)\)。

```
                [0,7] sum
              /          \
          [0,3]          [4,7]
         /    \          /    \
      [0,1]  [2,3]    [4,5]  [6,7]
      / \    / \      / \    / \
    [0][1][2][3]    [4][5][6][7]     叶子 = 单个元素
```

### 模板（区间和 + 单点更新，数组式建树）

```java
class SegTree {
    int[] tree; int n;
    SegTree(int[] a) {
        n = a.length;
        tree = new int[4 * n];          // 4n 足够容纳
        build(a, 1, 0, n - 1);
    }
    // node 当前节点下标，[lo,hi] 该节点管辖区间
    void build(int[] a, int node, int lo, int hi) {
        if (lo == hi) { tree[node] = a[lo]; return; }   // 叶子
        int mid = (lo + hi) >>> 1;
        build(a, 2 * node,     lo,      mid);
        build(a, 2 * node + 1, mid + 1, hi);
        tree[node] = tree[2 * node] + tree[2 * node + 1]; // 上推合并
    }
    // 单点更新：把下标 idx 改为 val
    void update(int node, int lo, int hi, int idx, int val) {
        if (lo == hi) { tree[node] = val; return; }
        int mid = (lo + hi) >>> 1;
        if (idx <= mid) update(2 * node,     lo,      mid, idx, val);
        else            update(2 * node + 1, mid + 1, hi,  idx, val);
        tree[node] = tree[2 * node] + tree[2 * node + 1];
    }
    // 区间查询 [l, r]
    int query(int node, int lo, int hi, int l, int r) {
        if (r < lo || hi < l) return 0;                  // 完全不相交
        if (l <= lo && hi <= r) return tree[node];        // 完全覆盖
        int mid = (lo + hi) >>> 1;
        return query(2 * node, lo, mid, l, r)
             + query(2 * node + 1, mid + 1, hi, l, r);
    }
}
```

### 懒标记（Lazy Propagation）

支持**区间更新**（如「区间整体加 val」）：更新时不下推到底，先在节点打「懒标记」，等下次访问其子节点时才下推，保证区间更新也 \(O(\log n)\)。（进阶，需要区间修改时才用。）

## 四、两者对比

| 维度 | 树状数组 BIT | 线段树 |
|:---|:---|:---|
| 代码量 | 极短（十几行） | 较长 |
| 常数 | 小、快 | 稍大 |
| 支持信息 | 可差分（和、异或） | 和/最值/GCD 等任意可合并信息 |
| 区间更新 | 需两个 BIT 技巧 | 懒标记，天然支持 |
| 适用 | 前缀和、逆序对计数 | 区间最值、区间修改、复杂聚合 |

> **口诀**：**能用树状数组就用（短、快）；要区间最值或区间修改就上线段树**。

## 五、复杂度分析

| 操作 | 时间 | 空间 |
|:---|:---:|:---:|
| 建树 | \(O(n)\) | BIT \(O(n)\) / 线段树 \(O(4n)\) |
| 单点更新 | \(O(\log n)\) | — |
| 区间查询 | \(O(\log n)\) | 递归栈 \(O(\log n)\) |
| 区间更新（懒标记） | \(O(\log n)\) | — |

## 六、易错点与技巧

### 1. 树状数组下标从 1 开始

`lowbit` 依赖 1-based，原数组下标要整体 `+1`，`tree[0]` 弃用。

### 2. 线段树数组开 `4n`

`2n` 在某些区间形状下不够，稳妥开 `4 * n`。

### 3. 查询区间的三种情况别漏

「完全不相交返回单位元、完全覆盖直接返回、部分相交递归左右」——顺序和边界要对。

### 4. 树状数组只能维护可差分信息

区间最大值**不能**用 `query(r)-query(l-1)`，最值不可差分，必须线段树。

### 5. 离散化

值域很大但元素少时（如逆序对、区间计数），先把值**离散化**成排名再建树，控制空间。

---

## 七、一句话总结

线段树与树状数组解决「**在线交替的区间查询 + 元素更新**」这一前缀和无能为力的场景，都做到 **\(O(\log n)\)**——**树状数组短小快、只管可差分信息（和/异或）**，**线段树通用、能维护区间最值并靠懒标记支持区间修改**；只查不改仍首选前缀和，能差分优先树状数组，需最值/区间改才上线段树。
