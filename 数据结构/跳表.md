# 跳表（Skip List）

跳表是一种**基于有序链表的概率性平衡数据结构**，通过多层索引把单链表的 \(O(n)\) 查找降到 \(O(\log n)\)，且实现远比平衡树简单。是 Redis ZSet、LevelDB MemTable、Java `ConcurrentSkipListMap` 的底层结构。

---

## 一、为什么需要跳表

**痛点**：有序链表查找 \(O(n)\)，但链表无法二分；平衡树（AVL / 红黑树）能 \(O(\log n)\) 但实现复杂、并发难。

**思路**：给有序链表加多层索引，让查找能"跳过"一段段节点，类似二分的逐层缩小。

```
Level 3:  head ------------------------> 50 ------------------------> nil
Level 2:  head --------> 20 ------------> 50 ------------> 80 ------> nil
Level 1:  head --> 10 -> 20 -> 30 -----> 50 -> 60 -----> 80 -> 90 -> nil
```

每次查找从最高层起步，向右走到不能走（下一节点值 ≥ 目标）就下降一层，到达最底层即定位目标。

---

## 二、核心定义

| 概念 | 说明 |
|:---|:---|
| **层级（Level）** | 最底层（Level 0）是完整链表，上层是稀疏索引 |
| **节点高度** | 每个节点出现在第 0 层，以概率 \(p\)（通常 1/2）继续上升到上一层 |
| **最高层** | `MAX_LEVEL`，常取 16~32，足以容纳 \(2^{16}\) ~ \(2^{32}\) 个节点 |
| **头节点** | 高度等于 `MAX_LEVEL` 的哨兵节点，不存数据 |

---

## 三、三个核心操作

### 1. 查找（Search）

从最高层开始：

- 当前节点的 `next` 值 **< 目标** → 向右走
- 当前节点的 `next` 值 **≥ 目标** 或为空 → 向下一层
- 到达 Level 0 时检查 `next` 是否等于目标

> 每层最多走几步就下降，所以总步数 \(\approx O(\log n)\)。

### 2. 插入（Insert）

1. **查找插入位置**：从顶到底逐层记录"将要下降的节点"到 `update[]` 数组
2. **随机生成层数**：抛硬币法，连续正面的次数作为层数
3. **创建节点**，按层数从 `update[]` 对应位置插入到每一层

```java
int randomLevel() {
    int level = 1;
    while (random.nextInt(2) == 1 && level < MAX_LEVEL) {   // p = 1/2
        level++;
    }
    return level;
}
```

### 3. 删除（Delete）

1. 同样记录 `update[]`
2. 在**每一层**找到目标节点后，把前驱的 `next` 指向目标节点的 `next`
3. 如果删完最高层空了，可以下调 `level` 表头

## 四、图解示例

在空跳表中依次插入 `10, 20, 30, 50, 60, 80, 90`，假设随机层数如下：

| 值 | 层数 |
|:---:|:---:|
| 10 | 1 |
| 20 | 2 |
| 30 | 1 |
| 50 | 3 |
| 60 | 2 |
| 80 | 1 |
| 90 | 1 |

最终结构：

```
Level 3:  head ------------------------> 50 ---------------------------> nil
Level 2:  head --------> 20 ------------> 50 ------------> 80 ---------> nil
Level 1:  head --> 10 -> 20 -> 30 -----> 50 -> 60 -----> 80 -> 90 -----> nil
```

查找 `60` 的路径：`head(L3) → 50(L3) → 下降 → 50(L2) → 50(L1) → 60(L1) 命中`，只走了 3 步而非链表的 6 步。

## 五、代码模板（Java）

一个支持插入、查找、删除的最小实现：

```java
public class SkipList {
    private static final int MAX_LEVEL = 16;
    private final Node head = new Node(null, MAX_LEVEL);
    private int levelCount = 1;
    private final Random random = new Random();

    private static class Node {
        Integer val;
        Node[] next;                                // 每层的后继
        Node(Integer val, int level) {
            this.val = val;
            this.next = new Node[level];
        }
    }

    // ---------- 查找 ----------
    public boolean search(int target) {
        Node p = head;
        for (int i = levelCount - 1; i >= 0; i--) {
            while (p.next[i] != null && p.next[i].val < target) {
                p = p.next[i];                      // 向右走
            }
        }
        // 到达 Level 0，检查右边是不是目标
        return p.next[0] != null && p.next[0].val == target;
    }

    // ---------- 插入 ----------
    public void insert(int val) {
        int level = randomLevel();
        Node newNode = new Node(val, level);

        Node[] update = new Node[level];
        Arrays.fill(update, head);

        Node p = head;
        for (int i = level - 1; i >= 0; i--) {
            while (p.next[i] != null && p.next[i].val < val) {
                p = p.next[i];
            }
            update[i] = p;                          // 记录每层的前驱
        }
        for (int i = 0; i < level; i++) {
            newNode.next[i] = update[i].next[i];
            update[i].next[i] = newNode;            // 标准链表插入
        }
        if (level > levelCount) levelCount = level; // 更新当前最高层
    }

    // ---------- 删除 ----------
    public boolean delete(int val) {
        Node[] update = new Node[levelCount];
        Node p = head;
        for (int i = levelCount - 1; i >= 0; i--) {
            while (p.next[i] != null && p.next[i].val < val) {
                p = p.next[i];
            }
            update[i] = p;
        }
        if (p.next[0] == null || p.next[0].val != val) return false;

        Node target = p.next[0];
        for (int i = 0; i < target.next.length; i++) {
            update[i].next[i] = target.next[i];     // 逐层摘除
        }
        return true;
    }

    private int randomLevel() {
        int level = 1;
        while (random.nextInt(2) == 1 && level < MAX_LEVEL) level++;
        return level;
    }
}
```

## 六、复杂度分析

| 操作 | 平均时间 | 最坏时间 | 空间 |
|:---|:---:|:---:|:---:|
| 查找 | \(O(\log n)\) | \(O(n)\) | — |
| 插入 | \(O(\log n)\) | \(O(n)\) | — |
| 删除 | \(O(\log n)\) | \(O(n)\) | — |
| 总空间 | — | — | \(O(n)\)（平均每节点 \(\frac{1}{1-p} \approx 2\) 个指针） |

> 最坏情况理论上存在（所有节点都拿到最高层），但概率极低，工程上视为 \(O(\log n)\)。

## 七、与其他数据结构对比

| 维度 | 跳表 | 红黑树 | B+ 树 |
|:---|:---|:---|:---|
| 查找 | \(O(\log n)\) | \(O(\log n)\) | \(O(\log_B n)\)（按块） |
| 插入 / 删除 | \(O(\log n)\) | \(O(\log n)\) | \(O(\log_B n)\) |
| 范围查询 | ✅ 天然支持（最底层就是有序链表） | ❌ 需中序遍历 | ✅ 叶子链表 |
| 实现复杂度 | 简单 | 复杂（旋转 + 着色） | 较复杂（节点分裂合并） |
| 并发友好度 | ✅ 局部 CAS 即可 | ❌ 旋转影响多个节点 | ❌ 节点分裂影响大 |
| 缓存友好度 | 差（指针跳跃） | 差 | ✅ 节点连续 |
| 适用场景 | 内存有序表 + 并发 | 通用内存索引 | 磁盘存储 |

## 八、经典应用

| 系统 | 用法 |
|:---|:---|
| **Redis ZSet** | 有序集合底层实现之一（元素数 < 128 且单元素 < 64B 时用 ziplist，否则用 skiplist + hash） |
| **LevelDB / RocksDB** | MemTable 用跳表存待落盘的 KV |
| **Java `ConcurrentSkipListMap`** | 并发有序 Map，跳表 + CAS 实现无锁并发 |
| **Lucene** | 倒排索引的 posting list 优化结构之一 |

### 为什么 Redis ZSet 选跳表而不是红黑树

1. **范围查询友好**：`ZRANGE` / `ZRANGEBYSCORE` 直接走最底层链表，\(O(\log n + m)\)
2. **实现简单**：代码量约为红黑树的 1/3，便于维护
3. **内存可控**：每个节点平均 1.33 个指针（Redis 用 \(p = 1/4\)，更省内存）
4. **并发友好**：局部修改不影响树形旋转

## 九、易错点与技巧

### 1. `update[]` 数组的作用

插入 / 删除时必须**从最高层向下逐层记录前驱**，因为低层前驱不一定能从高层直接推出。漏记会导致指针断链。

### 2. 随机层数不能是确定性的

如果层数固定（如按位置轮流分配），最坏情况会被构造数据卡成 \(O(n)\)。**必须用随机**才能保证期望平衡。

### 3. 概率 \(p\) 的选择

| \(p\) | 平均每节点指针数 | 平均查找长度 |
|:---:|:---:|:---:|
| 1/2 | 2 | 最短 |
| 1/4 | 1.33 | 略长但省内存（Redis 选择） |
| 1/4 是工程最优折中：内存比 1/2 省 33%，速度只慢一点点 |

### 4. `MAX_LEVEL` 的选择

最高层期望容纳 1 个节点，所以 `MAX_LEVEL = log_{1/p}(n)`。对 \(n=2^{32}, p=1/2\)，取 32 足够；工程上常直接写死 16 或 32。

### 5. 范围查询的实现

```java
// 返回所有 [min, max] 内的值，O(log n + m)
public List<Integer> range(int min, int max) {
    Node p = head;
    for (int i = levelCount - 1; i >= 0; i--) {
        while (p.next[i] != null && p.next[i].val < min) p = p.next[i];
    }
    p = p.next[0];                                 // 定位到第一个 ≥ min 的节点
    List<Integer> result = new ArrayList<>();
    while (p != null && p.val <= max) {
        result.add(p.val);
        p = p.next[0];                             // 最底层是有序链表，直接扫
    }
    return result;
}
```

## 十、一句话总结

跳表用**多层链表 + 随机化**把有序链表的 \(O(n)\) 查找降到 \(O(\log n)\)，实现远简单于平衡树，对**范围查询**和**并发**天然友好——这是它被 Redis / LevelDB / Java 并发库选中的根本原因。
