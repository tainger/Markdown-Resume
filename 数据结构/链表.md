# 链表（Linked List）

链表是用**节点 + 指针**串起来的线性结构：每个节点存值和指向下一个节点的引用。相比数组，它**插入/删除 \(O(1)\)（已知位置）**、无需连续内存、可动态扩容；代价是**不能随机访问**（查第 k 个要从头走）。刷题里是独立大类，套路高度模板化——**虚拟头、双指针、反转**三板斧覆盖绝大多数题。

---

## 一、分类与节点定义

| 类型 | 特点 |
|:---|:---|
| **单链表** | 每个节点只有 `next`，只能单向遍历 |
| **双链表** | 有 `prev` 和 `next`，可双向遍历（LRU、`LinkedList` 底层） |
| **循环链表** | 尾节点指回头，形成环（约瑟夫环） |

```
单链表:  head → 1 → 2 → 3 → null
双链表:  null ⇄ 1 ⇄ 2 ⇄ 3 ⇄ null
```

```java
class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}
```

---

## 二、虚拟头节点（哨兵）——第一板斧

在真正的头前面加一个 `dummy` 节点，**统一「操作头节点」和「操作中间节点」的逻辑**，避免大量对 `head == null` 的特判。凡是**可能删/改头节点**的题都该用。

```java
ListNode dummy = new ListNode(0);
dummy.next = head;
// ... 操作 ...
return dummy.next;      // 新头
```

### 删除倒数第 N 个（[19](../leetcode-hot100/19.%20删除链表的倒数第%20N%20个结点.md)）

```java
ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0, head);
    ListNode fast = dummy, slow = dummy;
    for (int i = 0; i < n; i++) fast = fast.next;   // fast 先走 n 步
    while (fast.next != null) {                     // 两指针同步走到末尾
        fast = fast.next; slow = slow.next;
    }
    slow.next = slow.next.next;                      // slow 恰在待删节点前
    return dummy.next;
}
```

## 三、双指针（快慢指针）——第二板斧

用两个速度/起点不同的指针解决「找中点、找环、找倒数第 k」等问题，**一趟遍历、\(O(1)\) 空间**。

### 1. 找中点（快 2 步慢 1 步）

```java
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;          // 慢指针 1 步
    fast = fast.next.next;     // 快指针 2 步
}
// fast 到底时，slow 恰在中点
```

### 2. 判环 + 找入口（[142 环形链表 II](../leetcode-hot100/142.%20环形链表%20II.md)）

Floyd 判圈：快慢指针相遇则有环；相遇后一指针回头，两指针同速再走，**再次相遇处即环入口**（数学可证）。

### 3. 相交链表（[160](../leetcode-hot100/160.%20相交链表.md)）

两指针分别走两条链，走到头就跳到对方起点，走过的总长相等，**相遇处即交点**（无交点则同时到 null）。

## 四、反转链表——第三板斧

### 迭代反转（[206](../leetcode-hot100/206.%20反转链表.md)）

三指针 `prev / cur / next`，逐个「掉头」：

```java
ListNode reverse(ListNode head) {
    ListNode prev = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next;   // 先存后继，别断链
        cur.next = prev;            // 掉头指向前驱
        prev = cur;                 // prev、cur 一起前移
        cur = next;
    }
    return prev;                    // prev 是新头
}
```

### 递归反转

```java
ListNode reverse(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode newHead = reverse(head.next);  // 先翻转后面
    head.next.next = head;                  // 后继反过来指我
    head.next = null;                       // 断开旧指向
    return newHead;
}
```

> 反转是「回文判断([234](../leetcode-hot100/234.%20回文链表.md))、K 个一组翻转、两数相加」等题的核心子操作。

## 六、复杂度分析

| 操作 | 时间 | 说明 |
|:---|:---:|:---|
| 访问第 k 个 | \(O(k)\) | 无法随机访问，须从头走 |
| 头部插入/删除 | \(O(1)\) | 改指针即可 |
| 已知前驱的插入/删除 | \(O(1)\) | 数组这里是 \(O(n)\) |
| 查找某值 | \(O(n)\) | 顺序遍历 |
| 反转 / 遍历 | \(O(n)\) 时间，\(O(1)\) 空间 | 迭代不需额外空间 |

> **数组 vs 链表**：数组随机访问 \(O(1)\) 但中间插删 \(O(n)\)；链表插删 \(O(1)\)（定位后）但随机访问 \(O(n)\)。按「读多还是改多」选。

## 七、易错点与技巧

### 1. 断链前先存后继

改 `cur.next` 之前务必 `ListNode next = cur.next;`，否则丢失后半段。

### 2. 空指针与单节点

循环条件 `fast != null && fast.next != null` 顺序不能反（短路避免 NPE）；单节点、空链表要能正确返回。

### 3. 能用虚拟头就用

凡涉及头节点可能变动（删头、插头、合并），`dummy` 能消掉一大堆特判。

### 4. 快慢指针的初始位置

找中点时 `slow/fast` 都从 `head` 起；有的题为「偏左中点」需从 `dummy` 起——按题意验证一遍小样例。

### 5. 环形链表别用 `equals`

判断是否同一节点用 `==`（引用相等），不是值相等。

---

## 八、一句话总结

链表靠指针串联，**插删快、随机访问慢**；刷题三板斧——**虚拟头**消除头节点特判、**快慢双指针**一趟解决中点/环/倒数第 k、**三指针反转**是众多题的核心子操作；动手前记住「改指针先存后继、循环条件先判 null」，链表题基本就稳了。
