# 队列（Queue）

队列是一种**先进先出（FIFO, First In First Out）**的线性结构：只能从**队尾入队（offer）**、从**队首出队（poll）**。它是 BFS 的载体，衍生出双端队列、单调队列、循环队列等，在刷题里是层序遍历、滑动窗口最值、拓扑排序的核心工具。

---

## 一、基本概念与分类

| 类型 | 特点 | 典型用途 |
|:---|:---|:---|
| **普通队列（Queue）** | 队尾进、队首出，FIFO | BFS、层序遍历 |
| **双端队列（Deque）** | 两端都能进 / 出 | 单调队列、既当栈又当队列 |
| **循环队列** | 数组首尾相连，复用空间 | 固定容量缓冲区（如设计题 622） |
| **单调队列** | 队内元素单调递增 / 减 | **滑动窗口最值**（239） |
| **优先队列** | 按优先级出队（非 FIFO） | 见 [优先队列.md](优先队列.md) |

```
入队 offer →  [ 队首 A  B  C  队尾 ]  → 出队 poll 从队首 A 出
              先进的 A 先出（FIFO）
```

> 对比栈（LIFO）：**队列先进先出（排队买票）**，栈后进先出（叠盘子）。BFS 用队列、DFS 用栈，本质就是这个差别。

## 二、Java 中的队列（刷题直接用）

```java
// 推荐：ArrayDeque，比 LinkedList 更快，可当队列 / 栈 / 双端队列
Deque<Integer> queue = new ArrayDeque<>();

// 作为普通队列（FIFO）
queue.offer(1);          // 入队（队尾）
queue.offer(2);
int head = queue.peek(); // 看队首，不删除 → 1
int x = queue.poll();    // 出队（队首）→ 1

// 作为双端队列
queue.offerFirst(0);     // 队首入
queue.offerLast(9);      // 队尾入
queue.pollFirst();       // 队首出
queue.pollLast();        // 队尾出

// 作为栈（LIFO）
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);           // = offerFirst
stack.pop();             // = pollFirst
```

> ⚠️ 别用 `Stack` 类（老旧、同步开销）；`ArrayDeque` 既能当栈又能当队列，是刷题首选。`Queue<Integer> q = new LinkedList<>()` 也行，但 `ArrayDeque` 性能更好（注意 `ArrayDeque` **不允许存 null**）。

## 三、最核心应用：BFS

队列是广度优先搜索的载体。模板见 [图.md](图.md) 与 [二叉树.md](二叉树.md)，要点：

```java
Queue<Node> q = new ArrayDeque<>();
q.offer(start);
visited[start] = true;                  // 图 BFS：入队即标记！
while (!q.isEmpty()) {
    int size = q.size();                // 需要分层时先固定 size
    for (int i = 0; i < size; i++) {
        Node cur = q.poll();
        for (Node next : neighbors(cur)) {
            if (!visited[next]) {
                visited[next] = true;
                q.offer(next);
            }
        }
    }
}
```

- **无权图最短路 = BFS 层数**；层序遍历、最少步数、多源 BFS（如 [994 腐烂的橘子](../leetcode-hot100/994.%20腐烂的橘子.md) 起点全入队）都靠它。

## 四、单调队列（滑动窗口最值利器）

用**双端队列**维护一个「单调递减」序列，队首始终是当前窗口最大值，把滑动窗口最大值从 \(O(nk)\) 降到 \(O(n)\)。

```java
// 239. 滑动窗口最大值：deque 存下标，值单调递减
int[] maxSlidingWindow(int[] nums, int k) {
    Deque<Integer> dq = new ArrayDeque<>();   // 存下标
    int[] res = new int[nums.length - k + 1];
    for (int i = 0; i < nums.length; i++) {
        // 1. 队尾：比当前小的都弹掉（它们不可能再当最大值）
        while (!dq.isEmpty() && nums[dq.peekLast()] < nums[i]) {
            dq.pollLast();
        }
        dq.offerLast(i);
        // 2. 队首：滑出窗口的下标移除
        if (dq.peekFirst() <= i - k) dq.pollFirst();
        // 3. 窗口成型后，队首即最大值
        if (i >= k - 1) res[i - k + 1] = nums[dq.peekFirst()];
    }
    return res;
}
```

> 单调队列核心：**队尾维护单调性（弹掉没用的），队首取答案（并淘汰过期的）**。求最小值就维护单调递增。这是「窗口内动态取极值」的通用套路。

## 五、循环队列

用定长数组 + 首尾指针（取模回绕）复用空间，避免普通数组队列「出队后前面空间浪费」：

```java
class MyCircularQueue {
    int[] arr; int head, count, capacity;
    MyCircularQueue(int k) { arr = new int[k]; capacity = k; }
    boolean enQueue(int v) {
        if (count == capacity) return false;
        arr[(head + count) % capacity] = v;   // 尾部 = (head+count)%cap
        count++;
        return true;
    }
    boolean deQueue() {
        if (count == 0) return false;
        head = (head + 1) % capacity;          // 队首后移
        count--;
        return true;
    }
}
```

## 六、复杂度

| 操作 | 时间 |
|:---|:---:|
| 入队 / 出队 / 看队首 | \(O(1)\)（`ArrayDeque`、`LinkedList`） |
| 单调队列处理一个滑窗 | 均摊 \(O(1)\)，整体 \(O(n)\)（每元素最多进出各一次） |
| 查找 / 随机访问 | \(O(n)\)（队列不支持下标访问） |

## 七、易错点与技巧

### 1. `ArrayDeque` 不能存 `null`

BFS 里若队列元素可能为 null（如带空节点的树序列化），改用 `LinkedList` 或用哨兵值代替。

### 2. 图 BFS「入队即标记」

出队才标记会导致同一节点被多个前驱重复入队，既慢又可能错。见 [图.md](图.md) 易错点。

### 3. 分层 BFS 先固定 `size`

`for` 里会往队列加下一层，不先存 `size = q.size()` 会把下一层算进当前层。

### 4. 单调队列存「下标」而非「值」

存下标才能判断「是否滑出窗口」（`peekFirst() <= i - k`）；只存值无法定位。

### 5. 单调队列的两个 `while / if` 别写反

队尾用 `while` 弹掉破坏单调性的，队首用 `if` 淘汰一个过期下标（窗口每次只滑出一个）。

### 6. 别用 `Stack` / `Vector` 系列

老旧且带同步锁，统一用 `ArrayDeque`。

---

## 八、一句话总结

队列是**先进先出**结构，Java 里统一用 `ArrayDeque`（能当队列 / 栈 / 双端队列，不许存 null）；它是 **BFS 的载体**（无权最短路、层序、多源扩散）；**单调队列**用双端队列维护单调性，是滑动窗口最值的 \(O(n)\) 解法——「队尾保单调、队首取答案」。
