## P7 必背清单（速查）

- **认证 vs 授权**：认证（AuthN）回答「你是谁」，授权（AuthZ）回答「你能干什么」；JWT 只做认证，权限永远服务端算。
- **六大模型一句话**：ACL 挂资源、DAC 自主放、MAC 强制管、RBAC 靠角色、ABAC 看属性、ReBAC 讲关系；工业界主流 = **RBAC 打底 + 数据权限/ABAC 补条件**。
- **RBAC 表**：user / role / menu(权限点) / user_role / role_menu 五张表；RBAC1 加继承、RBAC2 加互斥（会计出纳不能一人）。
- **权限点三级**：菜单（前端路由）→ 按钮（v-permission）→ 接口（`@PreAuthorize`）；**前端只是体验，后端注解才是防线**。
- **权限缓存治理**：Redis（30min）+ 本地 Caffeine（10s）双层；变更时**按角色反查用户批量删缓存** + MQ 广播清本地，否则多实例不一致。
- **JWT 注销**：短时 access(15min) + refresh 轮换 + **token 版本号**（改密/封禁 +1 全失效）或 jti 黑名单。
- **OAuth2 四模式**：授权码（Web 首选，App 加 PKCE）、Implicit（已废弃）、密码模式（不推荐）、客户端凭证（服务间 M2M）；「用微信登录」是 **OIDC**（OAuth2 + id_token 身份层）。
- **数据权限五档**：全部 / 自定义部门 / 本部门 / 本部门及以下 / 仅本人；实现首选 **MyBatis 拦截器 + JSqlParser 自动拼 WHERE**，ThreadLocal 用完必须 remove。
- **多租户三隔离**：列隔离（tenant_id 字段，索引最左前缀）、Schema 隔离、独立库；成本与隔离度反比，大客户独立 + 小客户共享混合路由。
- **微服务鉴权分工**：网关统一认证 + 粗授权（先删后写身份头防伪造），服务内细授权（注解 + 数据权限），服务间内网 token / mTLS；**内网当外网防 = 零信任**。

## 学习建议

1. **按 1→5 顺序学**：模型是理论地基 → RBAC 落地是 80% 面试的实操题 → 认证是前置高频题 → 数据权限是项目深挖必问 → 微服务架构是 P7 加分压轴。
2. **结合简历项目**：准备一套自己项目的完整答案链——「我们用 RBAC 五表 + Spring Security 注解 + 网关统一验签 + 拦截器数据权限」，每个环节都能被追问两层以上。
3. **每篇先答再对照**：盖住答案自问「Session 和 JWT 怎么选」「JWT 怎么注销」「多租户怎么隔离」「内网要不要鉴权」，卡壳就回去重读。
4. **动手验证**：本地搭个最小 RBAC（五表 + 3 个接口），把拦截器跑通一遍，面试画表才有底气。
