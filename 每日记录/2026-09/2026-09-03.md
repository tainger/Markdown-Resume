## 复习要点

> 今天主题：**简历体系化 + AI/Java 深度笔记 + 软考备战**，挑 7 条最有价值的收获。

1. **简历不是写出来的是"做"出来的**：代码反查发现 3 个风险点后，最佳策略不是删简历文字而是在本地代码中真正实现它们——面试时 `git log` show code 比任何话术都硬，这就是 [简历二次开发计划](../../简历/简历二次开发计划.md) 的核心思路
2. **虚拟线程 Pinned 问题是 JDK 21 最隐蔽的坑**：synchronized 块内阻塞不会 unmount，carrier 被钉住；解决方案是用 ReentrantLock 替代 synchronized，检测加 `-Djdk.tracePinnedThreads=full`——[虚拟线程.md](../../java/虚拟线程.md) 有完整机制图解
3. **守护线程 finally 不保证执行**：JVM 退出时直接 kill 守护线程，只有 Shutdown Hook（用户线程）才会被等待。关键 IO（写文件/发消息/释放锁）绝对不能放守护线程——[守护线程.md](../../java/守护线程.md)
4. **Skill 的本质是"给 Agent 用的可复用操作手册"**：Tool 是原子能力，Skill 是 Tool 的编排+业务逻辑+约束，Agent 靠 description 判断是否加载；边界约束必须写，因为 Agent 没有边界意识——[8. 如何编写一份skill.md](../../AI应用开发/8. 如何编写一份skill.md)
5. **Skill 异步长任务模式**：研发周报技能「立即受理返回 + 后台执行 + 完成后钉钉推送」解决同步超时，这是 AgentMate 实战中的关键设计——[8. 如何编写一份skill.md](../../AI应用开发/8. 如何编写一份skill.md)
6. **软考复习优先级**：系统架构设计（⭐⭐⭐⭐⭐）是最高权重，重点是 11 种架构风格对比 + 4+1 视图 + ATAM 评估；数据库/软件工程/网络/操作系统次之——[软考/README.md](../../软考系统架构师复习指南/README.md)
7. **简历亮点提炼 > 技术点堆砌**：AgentMate 的 git worktree 并发隔离、执行层过程式化重构、P0-P4 分级检索、pre/do/post 三态 Hook 都是真正有深度的决策，但埋在大段描述里面试官看不到——需要在每个项目开头加「技术亮点」标签行
