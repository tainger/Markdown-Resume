# 每日记录

> 记录每天在这个仓库干了啥，方便日后复习回看。
> 按月分子目录，文件名用 ISO 日期（`YYYY-MM-DD.md`）方便排序。

## 怎么用

1. 复制 [`_模板.md`](_模板.md) 到对应月份目录
2. 文件名改成当天日期，如 `2026-08-31.md`
3. 填写「今日概览 / 改动明细 / 复习要点」

## 目录结构

```
每日记录/
├── README.md          ← 本文件（索引）
├── _模板.md           ← 复制即用
└── YYYY-MM/           ← 按月分组
    └── YYYY-MM-DD.md  ← 每日一篇
```
