# 数学公式

刷题时高频用到的数学结论与技巧汇总。这些不是「算法」，而是能让某类题直接套公式、或规避溢出/精度陷阱的**基础工具**。

---

## 一、等差 / 等比数列

| 类型 | 通项 | 前 n 项和 |
|:---|:---|:---|
| 等差 | \(a_n = a_1 + (n-1)d\) | \(S_n = \dfrac{n(a_1 + a_n)}{2}\) |
| 等比（\(q\ne 1\)） | \(a_n = a_1 q^{n-1}\) | \(S_n = \dfrac{a_1(1 - q^n)}{1 - q}\) |

**最常用的一条**：\(1 + 2 + \dots + n = \dfrac{n(n+1)}{2}\)

```java
// 高斯求和：O(1) 求 1..n 之和。注意用 long 防溢出
long sum = (long) n * (n + 1) / 2;
```

> 「丢失的数字」（LeetCode 268）：用完整和 `n(n+1)/2` 减去数组实际和，差就是缺失的数。

## 二、取模运算（大数防溢出）

计数类题目答案常要求「对 \(10^9+7\) 取模」，因为答案会超过 `long`。取模满足分配律（除法除外）：

| 运算 | 公式 |
|:---|:---|
| 加 | \((a + b) \bmod m = ((a \bmod m) + (b \bmod m)) \bmod m\) |
| 乘 | \((a \times b) \bmod m = ((a \bmod m)\times(b \bmod m)) \bmod m\) |
| 减 | \((a - b) \bmod m = ((a \bmod m) - (b \bmod m) + m) \bmod m\)（加 m 防负） |

```java
static final int MOD = 1_000_000_007;
// 边算边取模，防止中间结果溢出
long res = 0;
res = (res + (long) a * b) % MOD;    // 乘法先转 long
res = ((res - x) % MOD + MOD) % MOD; // 减法要 +MOD 再取模，避免负数
```

> **除法不能直接取模**，需用「乘法逆元」（费马小定理：\(a^{-1} \equiv a^{m-2} \pmod m\)，m 为质数）。

## 三、快速幂

\(O(\log n)\) 求 \(a^n\)，是取模幂、逆元、矩阵幂的基础（推导见 [分治与递归.md](分治与递归.md)）：

```java
// 迭代版快速幂求 (base^exp) % mod
long quickPow(long base, long exp, long mod) {
    long res = 1;
    base %= mod;
    while (exp > 0) {
        if ((exp & 1) == 1) res = res * base % mod;   // 当前二进制位为 1，累乘
        base = base * base % mod;                     // 底数自乘
        exp >>= 1;
    }
    return res;
}
```

## 四、组合数学

| 概念 | 公式 | 含义 |
|:---|:---|:---|
| 阶乘 | \(n! = n\times(n-1)\times\cdots\times 1\) | n 个元素全排列数 |
| 排列 | \(A_n^k = \dfrac{n!}{(n-k)!}\) | 从 n 选 k 个**有序**排 |
| 组合 | \(C_n^k = \dfrac{n!}{k!(n-k)!}\) | 从 n 选 k 个**无序**取 |
| 帕斯卡递推 | \(C_n^k = C_{n-1}^{k-1} + C_{n-1}^{k}\) | 杨辉三角，DP 求组合数 |

```java
// 杨辉三角递推打表求组合数（避免大阶乘溢出）——LeetCode 118/119
int[][] C = new int[n + 1][n + 1];
for (int i = 0; i <= n; i++) {
    C[i][0] = 1;
    for (int j = 1; j <= i; j++)
        C[i][j] = C[i - 1][j - 1] + C[i - 1][j];   // 需要时可对 MOD 取模
}
```

> **不同路径**（LeetCode 62）：m×n 网格只能右/下走，答案就是 \(C_{m+n-2}^{m-1}\)。

## 五、最大公约数 / 最小公倍数

```java
// 辗转相除法（欧几里得算法）求 gcd
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}
// lcm = a*b/gcd，先除后乘防溢出
long lcm(int a, int b) {
    return (long) a / gcd(a, b) * b;
}
```

## 六、素数筛（埃拉托斯特尼筛）

一次性求出 `[2, n]` 内所有素数，\(O(n\log\log n)\)：

```java
// 埃氏筛：LeetCode 204 计数质数
public int countPrimes(int n) {
    boolean[] notPrime = new boolean[n];
    int count = 0;
    for (int i = 2; i < n; i++) {
        if (!notPrime[i]) {
            count++;
            for (long j = (long) i * i; j < n; j += i)   // 从 i*i 开始筛，用 long 防溢出
                notPrime[(int) j] = true;
        }
    }
    return count;
}
```

## 七、浮点数精度处理

- **判等**：浮点数**不能用 `==`**，比较差的绝对值：`Math.abs(a - b) < 1e-9`。
- **长链乘法**：连乘大量因子会累积误差，可转成**对数域**把乘法变加法：\(\log(a\times b) = \log a + \log b\)（见 [399 除法求值](../leetcode-hot100/399.%20除法求值.md)）。

## 八、常见数值边界（Java）

| 类型 | 范围 | 备注 |
|:---|:---|:---|
| `int` | 约 \(\pm 2.1\times 10^9\) | \(2^{31}-1 = 2147483647\) |
| `long` | 约 \(\pm 9.2\times 10^{18}\) | 计数题常用 |

> 求和/乘积可能超 `int` 时，**先转 `long` 再运算**：`(long) a * b`，别写成 `(long)(a * b)`（后者已经溢出了）。

## 十、一句话总结

数学公式题的关键是**认出模型**（等差/组合/gcd）直接套结论，以及在实现时守住两条底线：**大数边算边取模、浮点数用误差判等**。快速幂和素数筛是两个必背的模板。
