# DFS 搜索（深度优先搜索）

> 原文件名 `DFS搜素.md` 为错别字，已更正为 `DFS搜索.md`。与 [BFS搜索.md](BFS搜索.md) 成对食用。

DFS 的本质一句话：**一条路走到黑，走不通就退回来换条路**。它是递归思想在「图/网格/决策树」上的直接应用——[0.递归.md](0.递归.md) 讲机制，本篇讲图上的套路。

---

## 一、递归框架：三段式

```java
// ============ 形态一：网格 DFS（感染式/沉岛式）============
// 例：把连通的 '1' 全部改成 '0'，数被发动了几次 = 岛屿数量
static void dfs(char[][] grid, int i, int j) {
    // ① 终止条件：越界 / 不是陆地
    if (i < 0 || i >= grid.length || j < 0 || j >= grid[0].length
            || grid[i][j] != '1') return;
    grid[i][j] = '0';                      // ② 标记（直接改原数组=沉岛，省 visited）
    dfs(grid, i + 1, j);                   // ③ 向四个方向递归
    dfs(grid, i - 1, j);
    dfs(grid, i, j + 1);
    dfs(grid, i, j - 1);
    // 无需撤销：感染式 DFS 只关心"到没到过"，不关心路径
}

// ============ 形态二：显式 visited（不能改原数组时）============
static void dfs(int u, List<List<Integer>> adj, boolean[] visited) {
    visited[u] = true;                     // 进入时标记
    for (int v : adj.get(u)) {
        if (!visited[v]) dfs(v, adj, visited);
    }
    // 离开时（后序位置）可以做"子树信息汇总"：如拓扑排序、子树计数
}
```

复杂度：每个节点访问一次 → **网格 \(O(m \times n)\)，图 \(O(V + E)\)**；递归深度最坏等于节点数（**警惕栈溢出**）。

## 三、DFS vs 回溯 vs BFS（高频分界题）

| 对比项 | DFS（感染式） | 回溯 | BFS |
|:---|:---|:---|:---|
| 本质 | 图/网格上「到过就标记」 | 决策树上「选择→递归→**撤销**」 | 队列层序扩散 |
| 要不要撤销选择 | ❌ 不需要（标记永久保留） | ✅ 需要（路径/状态要还原） | ❌ |
| 求最短步数 | ❌ 可能绕远 | ❌ | ✅ 首达即最短 |
| 空间 | 递归栈（深度） | 递归栈 + 当前路径 | 队列（宽度，可能很大） |
| 信号词 | 连通、感染、可达 | 排列/组合/子集/所有方案 | 最少、最短、按层 |

一句话：**回溯 = 决策树上的 DFS + 撤销**；网格/图上数连通块用「不撤销的 DFS」，数方案用「撤销的回溯」，求最短步数换 BFS。

## 四、剪枝：DFS 的提速关键

1. **可行性剪枝**：当前状态已不可能到达目标，直接 return（如总和已超 target）。
2. **最优性剪枝**：当前代价 ≥ 已知最优解，放弃该分支（配合全局 best 变量）。
3. **重复剪枝**：同层跳过相同元素（排序后 `if (i > start && nums[i] == nums[i-1]) continue`），组合去重的标准动作，见 [回溯.md](回溯.md)。
4. **记忆化剪枝**：状态会重复计算 → 加缓存，就变成了 [记忆化搜索（DP）](1.动态规划.md)。

## 五、递归深度与栈溢出（工程题加分项）

- 网格 \(10^5\) 节点全连通时，递归深度 \(10^5\) 会触发 `StackOverflowError`（JVM 默认栈约 512KB~1MB）。
- 两种对策：
  1. 改**显式栈迭代**：用 `Deque<int[]> stack` 模拟递归（push/pop 代替调用）；
  2. 这类「只需连通性不需最短路」的场景，直接换 **BFS**（队列在堆上，不怕深）。
- 面试口诀：**深度大换 BFS，要最短也换 BFS**——DFS 适合「深而窄、要路径、要后序汇总」。

## 六、易错点 ⚠️

| 易错点 | 澄清 |
|:---|:---|
| **终止条件漏写越界检查** | 网格 DFS 第一行永远是「越界 + 非法」双检查，漏一个就数组越界 |
| **该撤销的没撤销** | 枚举路径时，回溯阶段必须把 `path`/状态还原，否则同层互相污染 |
| **visited 进入标记 vs 离开撤销搞混** | 感染式：进入标记、永不撤销；路径枚举：进入标记、离开撤销——先想清楚要哪一种 |
| **修改原数组 vs visited 数组** | 沉岛技巧省空间，但**会破坏输入**；题目要求输入可复用时必须用 visited |
| **递归深度爆栈** | \(10^5\) 量级节点先想迭代/换 BFS，别硬递归 |
| **方向数组顺序影响结果** | 不影响正确性（都会访问完），但影响路径形态与剪枝效率；固定写 `dx/dy` 数组防手滑 |

---

## 七、一句话总结

DFS = **递归三段式（终止 → 标记 → 多方向递归）**：网格数连通块用「不撤销的感染式」，枚举方案用「可撤销的回溯」，自底向上汇总靠后序位置；求最短步数或递归太深就换 BFS——**DFS 管「有没有/有哪些」，BFS 管「最少几步」**。
