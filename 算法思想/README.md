## 几组易混思想的分界

- **DP vs 贪心**：都求最优。DP 保存并比较**所有**子问题的解；贪心每步只做一个**不反悔**的选择。贪心是 DP 的特例，能贪则贪（更快），不确定就上 DP。
- **DP vs 回溯**：子问题重叠、只要「最优值/计数」→ DP；要「枚举出每一个具体方案」→ 回溯（有时回溯 + 记忆化 = DP）。
- **DP vs 分治**：子问题**重叠**用 DP（加记忆化），**不重叠**用分治（如归并排序）。
- **双指针 vs 滑动窗口**：滑动窗口是双指针的特例，专解「连续子数组/子串」；对撞/快慢指针则处理有序求和、链表环等。
- **单调栈 vs 单调队列**：栈解决「下一个更大/更小元素」；队列（双端）解决「滑动窗口最值」。
- **前缀和 vs 差分**：前缀和为「多次查区间和」预处理；差分为「多次改区间」预处理，二者互为逆操作。
- **BFS vs DFS**：无权图求最短步数用 BFS（层数即距离）；枚举路径、连通块、回溯用 DFS。
