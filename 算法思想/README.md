## 几组易混思想的分界

- **DP vs 贪心**：都求最优。DP 保存并比较**所有**子问题的解；贪心每步只做一个**不反悔**的选择。贪心是 DP 的特例，能贪则贪（更快），不确定就上 DP。
- **DP vs 回溯**：子问题重叠、只要「最优值/计数」→ DP；要「枚举出每一个具体方案」→ 回溯（有时回溯 + 记忆化 = DP）。
- **DP vs 分治**：子问题**重叠**用 DP（加记忆化），**不重叠**用分治（如归并排序）。
- **DP vs 状态机 DP**：一维状态装不下「约束信息」（不能连续/交替/持仓）→ 加状态维，见 [状态机](状态机.md)。
- **双指针 vs 滑动窗口**：滑动窗口是双指针的特例，专解「连续子数组/子串」；对撞/快慢指针则处理有序求和、链表环等。
- **滑动窗口 vs 前缀和+哈希**：数组**全为正数**用滑窗（单调性成立）；**含负数**窗口失效，用前缀和+哈希（[560](../leetcode-hot100/560.%20和为%20K%20的子数组.md)）。
- **单调栈 vs 单调队列**：栈解决「下一个更大/更小元素」；队列（双端）解决「滑动窗口最值」。
- **前缀和 vs 差分**：前缀和为「多次查区间和」预处理；差分为「多次改区间」预处理，二者互为逆操作。
- **BFS vs DFS**：无权图求最短步数用 BFS（层数即距离）；枚举路径、连通块、回溯用 DFS；网格上「能不能到」两者皆可。
- **网格 DP vs 网格 BFS**：只能向右/下移动（无后效性）→ DP；可四方向移动 → 图搜索 BFS/DFS。
- **枚举 vs 回溯**：回溯 = 枚举的递归系统化 + 剪枝；组合类枚举用「起点递增」天然去重，排列类必须 used 标记，见 [枚举](枚举.md) 与 [排列组合](排列组合.md)。
- **计数数组 vs HashMap 计数**：字符集/值域小且固定 → `int[128]`（零装箱）；键任意/稀疏 → HashMap，见 [统计](统计.md)。
