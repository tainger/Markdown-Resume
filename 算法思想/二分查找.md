# 二分查找

二分查找通过**每次砍掉一半搜索空间**，把在「有序 / 单调」结构上的查找从 \(O(n)\) 降到 \(O(\log n)\)。它不仅用于「在有序数组里找一个数」，更是「二分答案」这一大类最优化题的核心。

---

## 一、两大用途

| 用途 | 前提 | 例子 |
|:---|:---|:---|
| **在有序序列里查找** | 数组本身有序 | 找 target、找左右边界、找插入位 |
| **二分答案** | 答案单调可判定：`check(x)` 满足则更大/更小的 x 也满足 | 机器人搬砖、[分割数组最大值](../华为OD机试/32.%20末世分配资源包.md)、能力值/时间类最优化 |

> 二分的本质不是「数组有序」，而是**「答案空间上存在单调分界点」**——找到那个「恰好从否变是」的边界。

---

## 二、朴素二分模板（找是否存在）

```java
public int binarySearch(int[] nums, int target) {
    int l = 0, r = nums.length - 1;      // 闭区间 [l, r]
    while (l <= r) {
        int mid = l + (r - l) / 2;       // 防溢出，别写 (l+r)/2
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}
```

> **防溢出**：`mid = l + (r - l) / 2`；**区间一致性**：闭区间就 `l<=r` 且 `mid±1`，别混用。

## 三、找边界模板（最常考、最易错）

求「第一个 ≥ target 的位置」（左边界）：

```java
public int lowerBound(int[] nums, int target) {
    int l = 0, r = nums.length;          // 左闭右开 [l, r)
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] < target) l = mid + 1;   // mid 太小，舍弃左半含 mid
        else r = mid;                          // mid 可能是答案，保留
    }
    return l;   // l == 第一个 >= target 的下标（可能等于 n）
}
```

- 「第一个 > target」把 `< target` 换成 `<= target`。
- [在排序数组中查找元素的第一个和最后一个位置 34](../leetcode-hot100/34.%20在排序数组中查找元素的第一个和最后一个位置.md) = 求左边界 + 右边界。

## 四、二分答案模板（最优化问题的杀器）

当题目问「最小的可行值 / 最大值最小化 / 最少需要多少」，且**答案越大越容易/越难满足**时：

```java
// 求「最小可行值」：check(x) 为 true 表示 x 可行
public int minFeasible(int lo, int hi) {
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (check(mid)) hi = mid;    // mid 可行，试更小
        else lo = mid + 1;           // mid 不可行，必须更大
    }
    return lo;
}
```

**三步走**：① 确定答案的上下界 `[lo, hi]`；② 写 `check(x)`（通常是贪心/模拟，\(O(n)\)）；③ 二分找边界。总复杂度 \(O(n \log(\text{值域}))\)。

> 见 [华为OD #32 末世分配资源包](../华为OD机试/32.%20末世分配资源包.md)：二分「每段最大和」，`check` 贪心分段验证段数是否 ≤ k。

## 五、易错点清单

| 坑 | 说明 |
|:---|:---|
| `mid` 溢出 | 用 `l + (r-l)/2` |
| 区间开闭混用 | 闭区间 `[l,r]` 配 `l<=r`、`mid±1`；左闭右开 `[l,r)` 配 `l<r`、`r=mid` |
| 死循环 | `l<r` 时若 `l=mid`（没 +1）且 mid 恰为 l，会卡死；收缩必须让区间真的变小 |
| 边界返回值 | 想清返回 `l`、`r` 还是 `mid`，以及找不到时的语义（-1 或插入位） |
| check 单调性没验证 | 二分答案前先确认「可行性随 x 单调」，否则不能二分 |
