# 位运算

位运算直接操作整数的**二进制位**，速度快、常用于**状态压缩、集合表示、去重找唯一数**等场景。掌握几个固定套路，能把一些看似复杂的题变成一两行代码。

---

## 一、基本运算符

| 运算 | 符号 | 规则 | 例子 |
|:---|:---:|:---|:---|
| 与 | `&` | 都为 1 才为 1 | `6 & 3 = 2`（`110 & 011 = 010`） |
| 或 | `\|` | 有一个 1 就为 1 | `6 \| 3 = 7` |
| 异或 | `^` | 不同为 1，相同为 0 | `6 ^ 3 = 5` |
| 取反 | `~` | 0↔1（含符号位） | `~5 = -6` |
| 左移 | `<<` | 整体左移，低位补 0，相当于 ×2 | `1 << 3 = 8` |
| 右移 | `>>` | 算术右移，高位补符号位 | `8 >> 2 = 2` |
| 无符号右移 | `>>>` | 高位补 0（Java 特有） | `-1 >>> 28 = 15` |

---

## 二、异或（`^`）的三大性质——最常考

| 性质 | 公式 | 用途 |
|:---|:---|:---|
| 归零律 | `a ^ a = 0` | 成对出现的元素互相抵消 |
| 恒等律 | `a ^ 0 = a` | 从 0 开始累积 |
| 交换/结合律 | `a^b^c = c^b^a` | 顺序无关，可整段异或 |

**经典应用：只出现一次的数字（LeetCode 136）**

数组中除一个元素外都出现两次，全部异或起来，成对的抵消为 0，剩下的就是答案：

```java
public int singleNumber(int[] nums) {
    int ans = 0;
    for (int x : nums) ans ^= x;   // 成对抵消，O(n) 时间 O(1) 空间
    return ans;
}
```

> 交换两个数不借助临时变量：`a ^= b; b ^= a; a ^= b;`（面试常见小技巧）。

## 三、常用位操作模板

设 `i` 为位下标（从 0 开始，最低位是第 0 位）：

| 操作 | 写法 | 说明 |
|:---|:---|:---|
| 取第 i 位 | `(x >> i) & 1` | 结果为 0 或 1 |
| 第 i 位置 1 | `x \| (1 << i)` | |
| 第 i 位清 0 | `x & ~(1 << i)` | |
| 第 i 位取反 | `x ^ (1 << i)` | |
| 判断奇偶 | `(x & 1) == 0` | 偶数最低位为 0 |
| 取最低位的 1 | `x & (-x)` | lowbit，树状数组核心 |
| 去掉最低位的 1 | `x & (x - 1)` | 用于数 1 的个数 |
| 判断 2 的幂 | `x > 0 && (x & (x-1)) == 0` | 2 的幂只有一个 1 |

**统计二进制中 1 的个数（LeetCode 191）**

```java
public int hammingWeight(int n) {
    int count = 0;
    while (n != 0) {
        n &= (n - 1);   // 每次消掉最低位的 1，循环次数 = 1 的个数
        count++;
    }
    return count;
}
```

> Java 里也可直接用 `Integer.bitCount(n)`。

## 四、用位表示集合（状态压缩）

一个 `int` 有 32 位，可以表示一个「最多 32 个元素的集合」——第 i 位为 1 表示元素 i 在集合中。这是**状压 DP**和**子集枚举**的基础。

| 集合操作 | 位运算 |
|:---|:---|
| 空集 | `0` |
| 全集（n 个元素） | `(1 << n) - 1` |
| 元素 i 是否在集合 | `(s >> i) & 1` |
| 加入元素 i | `s \| (1 << i)` |
| 删除元素 i | `s & ~(1 << i)` |
| 并集 / 交集 | `a \| b` / `a & b` |
| 补集 | `((1 << n) - 1) ^ s` |

**枚举所有子集（LeetCode 78 子集的位运算解法）**

```java
public List<List<Integer>> subsets(int[] nums) {
    int n = nums.length;
    List<List<Integer>> res = new ArrayList<>();
    for (int mask = 0; mask < (1 << n); mask++) {   // 0 ~ 2^n-1，每个 mask 是一个子集
        List<Integer> sub = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if ((mask >> i & 1) == 1) sub.add(nums[i]);   // 第 i 位为 1 则选 nums[i]
        }
        res.add(sub);
    }
    return res;
}
```

## 五、易错点

1. **优先级坑**：`&`、`|`、`^` 的优先级**低于**比较运算符 `==`，写条件时务必加括号，如 `(x & 1) == 0` 不能写成 `x & 1 == 0`。
2. **移位溢出**：`1 << 31` 在 `int` 下会变负数，需要大位数用 `1L << i`。
3. **算术右移 vs 逻辑右移**：负数用 `>>` 高位补 1，需要补 0 用 `>>>`。
4. **异或不改变符号位判断**：判负数别用位技巧，直接比较更清晰。

## 七、一句话总结

位运算的价值在于**用二进制位直接表达状态与集合**：异或的「成对抵消」解决找唯一数，`x & (x-1)` 数 1，把 int 当集合做状压。写条件时**记得给位运算加括号**，是最容易踩的坑。
