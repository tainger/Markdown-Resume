# 0-1 背包和完全背包的区别

> 前两篇分别讲透了 [0-1 背包](1.0-1背包问题.md) 和 [完全背包](2.完全背包问题.md)，这一篇把它们**并排对照**，一次讲清「一处代码差异」背后的全部道理，避免混用。

## 一、一句话区别

| 模型 | 每种物品能用几次 | 一维写法的内层遍历 |
|:---|:---|:---|
| **0-1 背包** | 最多 **1 次**（选或不选） | 容量**倒序** |
| **完全背包** | **无限次**（可重复选） | 容量**正序** |

> 核心记忆：**0-1 倒序防重复，完全正序允重复。** 两者的状态定义和一维转移方程**完全相同**，唯一差别就是内层循环的方向。

---

## 二、题目信号：怎么一眼分辨

看到题目描述里出现这些字眼，就能判定属于哪一类：

| 描述 | 属于 |
|:---|:---|
| 「每个物品只有一件」「每个数只能用一次」「选或不选」 | 0-1 背包 |
| 「物品有无限个」「硬币无限供应」「同一个数可以重复取」 | 完全背包 |
| 「凑成金额」「换零钱」「用硬币/面值组合」 | 完全背包（面值可反复用） |
| 「子集和」「能否分成两半」「挑一部分数」 | 0-1 背包（每个数一次） |

## 三、状态转移方程对照

### 二维（差别在下标 `i` vs `i-1`）

$$
\text{0-1：} \quad dp[i][j] = \max(dp[i-1][j],\ dp[i-1][j-w] + v)
$$

$$
\text{完全：} \quad dp[i][j] = \max(dp[i-1][j],\ dp[i][j-w] + v)
$$

**区别只在「选」的那一项**：

- 0-1 用 `dp[i-1][j-w]`：选了第 i 件后，它**用完就没了**，回到「前 i-1 件」。
- 完全用 `dp[i][j-w]`：选了第 i 种后，它**还能继续选**，仍停留在「前 i 种」这一层。

### 一维（方程一模一样，靠遍历方向区分）

两者一维方程都是：

$$
dp[j] = \max(dp[j],\ dp[j-w] + v)
$$

差别转移到了**内层循环方向**上：

```java
// 0-1 背包：内层倒序
for (int j = W; j >= weight[i]; j--)
    dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);

// 完全背包：内层正序
for (int j = weight[i]; j <= W; j++)
    dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
```

---

## 四、为什么方向不同就换了模型（关键）

一维滚动数组里，`dp[j-w]` 到底是**旧值**还是**新值**，决定了同一物品能用几次。

| 方向 | 算 `dp[j]` 时 `dp[j-w]` 是… | 效果 |
|:---|:---|:---|
| **倒序**（0-1） | 下标更小、**本轮还没更新** → 上一轮旧值（不含第 i 件） | 每件**只用一次** |
| **正序**（完全） | 下标更小、**本轮已更新过** → 已含第 i 件的新值 | 第 i 件**可反复叠加** |

以 `w=1、价值 v` 为例直观看：

```
倒序 j: 4→3→2→1   dp[j] 用到的 dp[j-1] 都是旧值 → 每件只放 1 次
正序 j: 1→2→3→4   dp[2]=dp[1]+v（dp[1] 已放过一次）→ 同件被放第 2 次、第 3 次…
```

> 所以：把完全背包的内层改成倒序，它就**退化成 0-1 背包**；反之亦然。这正是两个模型「同源」的证据。

## 五、遍历顺序小结（含「求方案数」的额外规则）

| 场景 | 外层 | 内层 | 说明 |
|:---|:---|:---|:---|
| 0-1 背包（求最优/可行） | 物品 | 容量**倒序** | 固定写法 |
| 完全背包（求最优/可行） | 物品 | 容量**正序** | 固定写法 |
| 完全背包**求组合数** | 物品 | 容量正序 | `{1,2}` 与 `{2,1}` 算 1 种 |
| 完全背包**求排列数** | 容量 | 物品正序 | `1+2` 与 `2+1` 算 2 种 |

> 「组合 vs 排列」只在**求方案数**时才需要区分外内层顺序；求最大价值 / 最少个数 / 能否装满时不受影响。详见 [完全背包问题.md](2.完全背包问题.md) 第七节。

## 六、代码对照（一维，并排看）

```java
// ===== 0-1 背包：每件最多一次 =====
int[] dp = new int[W + 1];
for (int i = 0; i < n; i++) {
    for (int j = W; j >= weight[i]; j--) {        // ← 倒序
        dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
    }
}

// ===== 完全背包：每种无限次 =====
int[] dp = new int[W + 1];
for (int i = 0; i < n; i++) {
    for (int j = weight[i]; j <= W; j++) {        // ← 正序
        dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
```

**唯一改动**：内层 `for` 的方向（以及正序时下界从 `weight[i]` 起、倒序时上界从 `W` 起）。其余一字不差。

## 八、易混点提醒

1. **别把二维的「选」项写错**：0-1 是 `dp[i-1][j-w]`，完全是 `dp[i][j-w]`，差一个下标就换了模型。
2. **一维只认方向**：方程相同，写错方向就悄悄变成另一种模型，且**不报错**——最隐蔽的 bug。
3. **求方案数才分组合/排列**：其余问法两种顺序都对。
4. **初始化按问法定**：求最少个数要把非 0 位置置「无穷」，求方案数要 `dp[0]=1`（与背包问法一致，见前两篇）。

---

## 九、一句话总结

> 0-1 背包与完全背包**共用状态和一维转移方程**，本质区别只有一个：**同一物品能否重复使用**。落到代码上，就是一维内层容量**倒序（0-1，防重复）还是正序（完全，允重复）**。看懂这一点，两种背包就合二为一了。
