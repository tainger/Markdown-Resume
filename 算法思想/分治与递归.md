# 分治与递归

**递归**是「函数调用自己」的编程手法；**分治（Divide and Conquer）**是一种基于递归的算法思想——**把大问题分成若干个规模更小的同类子问题，分别求解后再合并**。归并排序、快速排序、二分查找都是分治的经典应用。

---

## 一、递归：分治的载体

一个递归函数必须有两部分，缺一不可：

| 组成 | 作用 | 反例后果 |
|:---|:---|:---|
| **递归出口（base case）** | 最小子问题直接返回，停止递归 | 没有 → 栈溢出 `StackOverflowError` |
| **递归关系** | 把问题缩小一步后调用自己 | 没缩小 → 死循环 |

```java
// 递归三要素：出口、缩小、返回
long factorial(int n) {
    if (n <= 1) return 1;              // 1. 出口：最小子问题
    return n * factorial(n - 1);      // 2. 缩小规模 + 3. 合并结果
}
```

> **写递归的心法**：**相信递归会把子问题正确解决**（「递归假设」），你只需要写清楚「出口」和「如何用子问题的解拼出当前问题的解」，不要试图在脑子里展开整个调用过程。

---

## 二、分治三步曲

分治把「解决一个大问题」拆成固定的三步：

| 步骤 | 英文 | 做什么 |
|:---|:---|:---|
| 1. 分 | **Divide** | 把问题拆成几个规模更小的子问题 |
| 2. 治 | **Conquer** | 递归解决每个子问题（子问题足够小就直接解） |
| 3. 合 | **Combine** | 把子问题的解合并成原问题的解 |

```java
Result divideAndConquer(Problem p) {
    if (p 足够小) return 直接求解(p);        // 治的边界
    子问题[] subs = divide(p);              // 分
    Result[] rs = new Result[subs.length];
    for (int i = 0; i < subs.length; i++)
        rs[i] = divideAndConquer(subs[i]);  // 治（递归）
    return combine(rs);                     // 合
}
```

**判断能不能用分治**：子问题之间**相互独立、不重叠**。如果子问题**重叠**（会被重复计算），那是[动态规划](1.动态规划.md)的地盘，需要加记忆化。

## 三、经典应用

### 1. 归并排序（稳定，\(O(n\log n)\)）

分治的教科书例子：从中间切两半分别排序，再**合并两个有序数组**。

```java
void mergeSort(int[] a, int lo, int hi) {
    if (lo >= hi) return;                 // 出口：单个元素天然有序
    int mid = lo + (hi - lo) / 2;
    mergeSort(a, lo, mid);                // 分 + 治：左半
    mergeSort(a, mid + 1, hi);            // 分 + 治：右半
    merge(a, lo, mid, hi);                // 合：合并两个有序段
}

void merge(int[] a, int lo, int mid, int hi) {
    int[] tmp = new int[hi - lo + 1];
    int i = lo, j = mid + 1, k = 0;
    while (i <= mid && j <= hi)
        tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];   // <= 保证稳定
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= hi)  tmp[k++] = a[j++];
    System.arraycopy(tmp, 0, a, lo, tmp.length);
}
```

> 归并排序的合并过程还能顺手解决「**逆序对计数**」（LeetCode 剑指 Offer 51）——合并时右边元素被取走，说明它比左边剩下的所有元素都小。

### 2. 快速排序（原地，平均 \(O(n\log n)\)）

先「分区（partition）」把小的放左、大的放右，再递归两边。与归并相反：**先合（分区）后分**。

```java
void quickSort(int[] a, int lo, int hi) {
    if (lo >= hi) return;
    int p = partition(a, lo, hi);   // 选基准，把数组分成 <p 和 >p 两部分
    quickSort(a, lo, p - 1);
    quickSort(a, p + 1, hi);
}
```

### 3. 二分查找

每次把搜索区间**砍掉一半**，是分治「只需解一个子问题」的特例，详见 [二分查找.md](二分查找.md)。

### 4. 树的递归

二叉树天然是递归结构（左子树 + 右子树都是子问题），最大深度、翻转、路径和都是分治：**递归处理左右子树 → 合并结果**。

```java
int maxDepth(TreeNode root) {
    if (root == null) return 0;                        // 出口
    int l = maxDepth(root.left);                       // 分治：左子树
    int r = maxDepth(root.right);                      // 分治：右子树
    return Math.max(l, r) + 1;                         // 合并
}
```

### 5. 快速幂（\(O(\log n)\) 求 \(a^n\)）

把「乘 n 次」用分治降到 \(O(\log n)\)：\(a^n = (a^{n/2})^2\)。

```java
double quickPow(double x, long n) {
    if (n == 0) return 1;
    double half = quickPow(x, n / 2);            // 只算一半
    return n % 2 == 0 ? half * half : half * half * x;
}
```

## 四、复杂度分析：主定理（Master Theorem）

分治的递归式一般是 \(T(n) = a\,T(n/b) + O(n^d)\)（分成 a 个子问题，每个规模 n/b，合并耗时 \(O(n^d)\)）：

| 比较 | 复杂度 | 例子 |
|:---|:---|:---|
| \(d > \log_b a\) | \(O(n^d)\) | 合并占主导 |
| \(d = \log_b a\) | \(O(n^d \log n)\) | 归并排序（a=2,b=2,d=1）→ \(O(n\log n)\) |
| \(d < \log_b a\) | \(O(n^{\log_b a})\) | 分裂占主导 |

> 记住归并排序这个 \(O(n\log n)\) 锚点即可，大多数分治题套这个结论。

## 五、递归 vs 迭代

| 维度 | 递归 | 迭代（循环） |
|:---|:---|:---|
| 可读性 | 树/分治问题更直观 | 线性问题更直观 |
| 空间 | 有调用栈开销 \(O(\text{深度})\) | \(O(1)\)（无额外栈） |
| 风险 | 深度过大会栈溢出 | 无 |
| 转换 | 可用**显式栈**改写成迭代 | — |

> 递归深度可能很大（如链表长 10 万）时，改写成迭代或显式栈更安全。

## 六、分治 vs 动态规划（最易混）

| | 分治 | 动态规划 |
|:---|:---|:---|
| 子问题 | **不重叠**、相互独立 | **重叠**、会重复计算 |
| 是否缓存 | 不需要 | 需要（记忆化 / dp 表） |
| 典型 | 归并、快排、二分 | 打家劫舍、LCS、背包 |

> 一句话：**子问题重不重叠**是分辨二者的分水岭。重叠就加记忆化，那就变成了 DP。

## 八、一句话总结

分治 = **分（拆小）→ 治（递归解）→ 合（并结果）**，前提是**子问题独立不重叠**；一旦子问题重叠，就该换成加了缓存的[动态规划](1.动态规划.md)。递归是它的实现载体，写递归只需想清「出口」和「如何用子问题的解拼出答案」。
