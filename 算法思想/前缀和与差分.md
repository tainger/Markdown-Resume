# 前缀和与差分

前缀和与差分是一对**互逆**的预处理技巧：前缀和让「区间求和」变 \(O(1)\)，差分让「区间批量加减」变 \(O(1)\)。核心都是「预处理一次，之后每次查询/修改都是常数时间」。

---

## 一、前缀和：把「区间和」查询降到 O(1)

定义 `pre[i] = nums[0] + ... + nums[i-1]`（`pre[0]=0`），则任意区间和：

```
sum(l, r) = pre[r+1] - pre[l]
```

```java
int[] pre = new int[n + 1];
for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + nums[i];
// 查询 [l, r] 区间和：pre[r + 1] - pre[l]
```

- 预处理 \(O(n)\)，每次查询 \(O(1)\)；适合**多次区间和查询**。
- 二维前缀和（矩阵区域和）：`pre[i][j] = 上 + 左 - 左上 + 当前`，查询用容斥。

---

## 二、前缀和 + 哈希：求「和为 K 的子数组」

很多题不是查区间，而是**统计满足条件的子数组个数**。关键恒等式：

```
子数组 (j, i] 的和 = K   ⟺   pre[i] - pre[j] = K   ⟺   pre[j] = pre[i] - K
```

于是边扫边用哈希表记录「各前缀和出现的次数」，查 `pre[i]-K` 出现过几次即可，\(O(n)\)：

```java
public int subarraySum(int[] nums, int k) {
    Map<Integer,Integer> cnt = new HashMap<>();
    cnt.put(0, 1);                 // 前缀和为 0 出现 1 次（空前缀）
    int pre = 0, ans = 0;
    for (int x : nums) {
        pre += x;
        ans += cnt.getOrDefault(pre - k, 0);   // 有多少个 j 使 pre[j]=pre-k
        cnt.merge(pre, 1, Integer::sum);
    }
    return ans;
}
```

> 这套「前缀和 + 哈希」也用在树上路径和（[437. 路径总和 III](../leetcode-hot100/437.%20路径总和%20III.md)）——DFS 时维护根到当前节点的前缀和，回溯时把当前前缀和从哈希表里减掉。

---

## 三、差分：把「区间批量加减」降到 O(1)

差分数组 `diff[i] = nums[i] - nums[i-1]`。**对原数组区间 `[l, r]` 整体 +val**，只需改两个位置：

```java
diff[l] += val;
diff[r + 1] -= val;   // r+1 越界则忽略
// 所有区间操作完成后，对 diff 求前缀和即可还原修改后的数组
```

- 适合**先批量做很多区间修改、最后一次性查询**（如航班预订、区间覆盖计数）。
- 差分是前缀和的逆运算：**对差分数组求前缀和 = 原数组**。

---

## 四、四者关系一图

| 需求 | 工具 | 预处理 | 单次操作 |
|:---|:---|:---:|:---:|
| 多次查区间和 | 前缀和 | \(O(n)\) | \(O(1)\) 查询 |
| 统计和为 K 的子数组 | 前缀和 + 哈希 | — | \(O(n)\) 总 |
| 多次区间批量加减 | 差分 | \(O(n)\) 还原 | \(O(1)\) 修改 |
| 二维区域和 | 二维前缀和 | \(O(mn)\) | \(O(1)\) 查询 |

---

## 五、易错点

1. **前缀和数组长度取 `n+1`**，`pre[0]=0`，避免区间边界特判。
2. **哈希表要先 `put(0,1)`**：处理「从头开始的子数组」这一情形。
3. **差分修改是 `diff[r+1] -= val`**，别漏掉 `r+1` 越界判断。
4. **溢出**：大数据量或大数值时前缀和用 `long`。
