# 单调栈

单调栈是一种特殊的栈结构，它维护栈内元素的**单调性**（要么单调递增，要么单调递减）。它是解决一类「寻找下一个更大/更小元素」问题的利器。

---

## 一、核心定义

栈内元素从栈底到栈顶保持严格单调（递增或递减）的栈。

| 类型 | 栈底 → 栈顶 | 栈顶元素 |
|:---|:---|:---|
| 单调递增栈 | 逐渐增大 | 最小 |
| 单调递减栈 | 逐渐减小 | 最大 |

> 「递增 / 递减」指的是**从栈底到栈顶**的顺序，不要和数组顺序混淆。

---

## 二、工作原理（以单调递增栈为例）

**入栈规则**：为了维持栈的单调递增性：

1. 若栈为空，或新元素 **大于** 栈顶元素 → 直接入栈
2. 若新元素 **小于或等于** 栈顶元素 → 不断弹出栈顶，直到栈为空或新元素大于栈顶元素，然后再入栈

**关键**：弹出的元素，其「下一个更小」的元素就是当前要入栈的新元素。

> 记忆口诀：**谁被弹出，谁就找到了答案。**

---

## 三、图解示例

数组 `[2, 1, 5, 6, 2, 3]`，构建单调递增栈（求下一个更小元素）：

| 步骤 | 当前元素 | 操作 | 栈内元素（底→顶） | 弹出元素的下一个更小值 |
|:---:|:---:|:---|:---|:---|
| 1 | 2 | 入栈 | `[2]` | — |
| 2 | 1 | 2 弹出，1 入栈 | `[1]` | 元素 2 的下一个更小值是 1 |
| 3 | 5 | 入栈 | `[1, 5]` | — |
| 4 | 6 | 入栈 | `[1, 5, 6]` | — |
| 5 | 2 | 6、5 弹出，2 入栈 | `[1, 2]` | 6 的下一个更小值是 2；5 的下一个更小值是 2 |
| 6 | 3 | 入栈 | `[1, 2, 3]` | — |
| 结束 | — | 弹出所有 | `[]` | 栈中剩余元素（1、2、3）没有下一个更小值 |

## 四、代码模板（Java）

### 模板 1：单调递增栈（求下一个更小元素）

```java
public int[] nextSmallerElement(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);                       // 默认 -1 表示没有更小值
    Deque<Integer> stack = new ArrayDeque<>();      // 存下标，不存值
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && nums[i] < nums[stack.peek()]) {
            int index = stack.pop();
            result[index] = nums[i];                // 栈顶元素的下一个更小元素是 nums[i]
        }
        stack.push(i);
    }
    return result;
}
```

### 模板 2：单调递减栈（求下一个更大元素）

```java
public int[] nextGreaterElement(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);
    Deque<Integer> stack = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && nums[i] > nums[stack.peek()]) {
            int index = stack.pop();
            result[index] = nums[i];                // 栈顶元素的下一个更大元素是 nums[i]
        }
        stack.push(i);
    }
    return result;
}
```

> 「下一个更大」和「距离几天」本质相同，把 `result[index] = nums[i]` 换成 `result[index] = i - index` 即可——这就是 [739. 每日温度](../leetcode-hot100/739.%20每日温度.md) 的解法。

## 六、复杂度分析

| 维度 | 复杂度 | 说明 |
|:---|:---|:---|
| 时间 | \(O(n)\) | 每个元素最多入栈一次、出栈一次 |
| 空间 | \(O(n)\) | 最坏情况栈中存储所有元素（严格递增/递减序列） |

## 八、易错点与技巧

### 1. 栈中存什么？

**通常存下标**，因为下标可以同时获取值和位置，方便计算距离（如每日温度问「几天后」，需要 `i - index`）。

口诀：**「要算距离存下标」**。

### 2. 如何记忆使用哪种栈？

| 目标 | 栈类型 | 规则 |
|:---|:---|:---|
| 求更大元素 | 单调递减栈 | 新元素大，就弹出小的 |
| 求更小元素 | 单调递增栈 | 新元素小，就弹出大的 |

### 3. 严格大于 vs 大于等于

- 题目说「更高 / 更大」→ 用严格 `>`
- 题目说「不低于 / 不小于」→ 用 `>=`

对照题意选择，否则会漏结算或误结算。

### 4. `if` vs `while`：单调栈最常见的 Bug

- `if`：只弹一次栈顶，会漏掉栈里同样小于当前元素的前序下标
- `while`：把所有比当前元素小（或大）的栈内下标一次结算干净

> 必须用 `while`，否则栈中会残留本该被结算的下标，导致结果错误。

### 5. 处理循环数组（如 503 题）

将数组长度翻倍，或使用取模运算 `i % n`，遍历两遍。

### 6. 剩余栈元素

遍历结束后栈中剩余的元素，说明它们**没有下一个更大/更小元素**，按题意填默认值（0 / -1）。如果默认值就是 0（如 Java `new int[n]`），可省去单独处理。

## 九、一句话总结

单调栈通过维护元素的单调性，在**一次遍历**中高效地找到每个元素左边 / 右边第一个比它大 / 小的元素，是「下一个更大 / 更小」问题的标准解法。

掌握了单调栈，[接雨水](https://leetcode.cn/problems/trapping-rain-water/)、[柱状图最大矩形](https://leetcode.cn/problems/largest-rectangle-in-histogram/) 这类看似复杂的题目就有了统一的解法。
