# 双指针与滑动窗口

双指针是用**两个下标**在数组/链表上协同移动，把很多 \(O(n^2)\) 的暴力枚举压到 \(O(n)\) 的通用技巧。滑动窗口是双指针的一个重要特例——两个指针围出一个「窗口」，随条件伸缩。

---

## 一、双指针的三种形态

| 形态 | 指针怎么动 | 适用信号 | 典型题 |
|:---|:---|:---|:---|
| **对撞指针** | 一头一尾向中间逼近 | **有序**数组求和/回文/盛水 | 两数之和 II、[接雨水 42](../leetcode-hot100/42.%20接雨水.md)、盛最多水的容器 |
| **快慢指针** | 同向，一快一慢 | 链表找环/中点、原地去重 | [环形链表 II 142](../leetcode-hot100/142.%20环形链表%20II.md)、[移动零 283](../leetcode-hot100/283.%20移动零.md) |
| **滑动窗口** | 同向，右扩左缩 | 求「满足条件的连续子串/子数组」 | [无重复字符的最长子串 3](../leetcode-hot100/3.%20无重复字符的最长子串.md)、[找字母异位词 438](../leetcode-hot100/438.%20找到字符串中所有字母异位词.md)、[最长瑕疵度元音子串 OD6](../华为OD机试/6.%20最长的指定瑕疵度的元音子串.md) |

> 判断口诀：**「有序 + 求两数关系」→ 对撞；「连续子数组/子串 + 最长/最短/定长」→ 滑动窗口；「链表环/中点、原地覆盖」→ 快慢。**

## 二、对撞指针模板

```java
public int[] twoSumSorted(int[] nums, int target) {
    int l = 0, r = nums.length - 1;
    while (l < r) {
        int sum = nums[l] + nums[r];
        if (sum == target) return new int[]{l, r};
        else if (sum < target) l++;   // 和太小，左指针右移增大
        else r--;                     // 和太大，右指针左移减小
    }
    return new int[]{-1, -1};
}
```

> 前提是**数组有序**；无序则先排序（会打乱下标，注意题目要不要原下标）。

## 三、滑动窗口模板（最通用）

```java
// 求「最长满足条件」的窗口
public int longestWindow(int[] nums) {
    int left = 0, ans = 0;
    Map<Integer,Integer> window = new HashMap<>();  // 窗口内状态（频次等）
    for (int right = 0; right < nums.length; right++) {
        window.merge(nums[right], 1, Integer::sum);  // 右端扩入
        while (/* 窗口不合法 */ window.get(nums[right]) > 1) {
            window.merge(nums[left], -1, Integer::sum); // 左端收缩
            left++;
        }
        ans = Math.max(ans, right - left + 1);          // 结算
    }
    return ans;
}
```

**三类窗口的差别只在「怎么收缩、何时结算」**：

| 窗口类型 | 收缩条件 | 结算位置 | 例题 |
|:---|:---|:---|:---|
| 最长（可变长） | 窗口**非法**时收缩 | 每次右扩后 | 无重复最长子串（3） |
| 最短（可变长） | 窗口**已满足**时收缩并记录 | 收缩过程中 | 最小覆盖子串（76） |
| 定长 | 窗口大小 > k 时收缩一格 | 窗口恰为 k 时 | 找字母异位词（438） |

---

## 四、易错点

1. **收缩用 `while` 不是 `if`**：可能需要连续弹出多个左端元素才恢复合法。
2. **结算时机**：求最长在「右扩后」结算，求最短在「收缩时」结算，别搞反。
3. **窗口状态维护**：频次表在左缩时要 `-1`，减到 0 记得考虑是否移除 key（判存在性时）。
4. **快慢指针找环起点**：快慢相遇后，让一个指针回到头，两指针同速再走，相遇点即环入口（Floyd 判圈，见 142）。

---

## 五、复杂度

- 时间 \(O(n)\)：每个元素最多被 left、right 各访问一次。
- 空间 \(O(1)\) 或 \(O(字符集)\)（窗口用哈希/定长数组记状态时）。
