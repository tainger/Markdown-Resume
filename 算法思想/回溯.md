

















回溯算法是解决**组合、排列、子集、棋盘问题**（如N皇后）等问题的通用方法。它的核心是**“尝试-递归-撤销”**，可以系统地搜索所有可能的解。

下面我为你提供一个**通用的回溯算法模板**，并结合一道经典题目（**全排列**）来演示如何使用。

---

## 一、通用回溯模板（Java版）

这个模板适用于大多数回溯问题，你可以将其作为框架，根据具体题目调整细节。

```java
public class BacktrackingTemplate {
    // 1. 定义全局变量，存放最终结果集和临时路径
    List<List<Integer>> result = new ArrayList<>();  // 所有满足条件的解
    LinkedList<Integer> path = new LinkedList<>();   // 当前正在构建的路径（解的一部分）
    
    public List<List<Integer>> solve(输入参数) {
        // 2. 可选：预处理（如排序、访问标记数组初始化）
        // boolean[] used = new boolean[n];
        // Arrays.sort(nums); // 如果题目要求去重
        
        // 3. 调用回溯函数，从初始状态开始
        backtrack(0, 其他参数);
        
        return result;
    }
    
    /**
     * 回溯递归函数
     * @param startIndex 用于控制组合/子集问题的起始位置，避免重复选择
     * @param otherParams 其他需要的参数，如原数组、used数组、目标值等
     */
    private void backtrack(int startIndex, /* 其他参数 */) {
        // 4. 终止条件：判断是否找到一个完整解
        if (/* 满足终止条件，例如：路径长度等于目标长度 */) {
            result.add(new ArrayList<>(path)); // ！！！关键：添加的是path的副本
            return;
        }
        
        // 5. 遍历当前层的所有选择
        for (int i = startIndex; i < /* 选择列表大小 */; i++) {
            // 6. 剪枝（可选）：提前跳过不可能的分支
            if (/* 当前选择不合法，例如：元素已使用过 */) {
                continue;
            }
            
            // 7. 【做选择】将当前选择加入路径
            // 例如：path.add(nums[i]); 或 used[i] = true;
            
            // 8. 【递归】进入下一层决策
            backtrack(/* 更新后的参数，例如 i+1 或 startIndex+1 */, /* 其他参数 */);
            
            // 9. 【撤销选择】（回溯的核心！）恢复状态，尝试其他选择
            // 例如：path.removeLast(); 或 used[i] = false;
        }
    }
}
```

## 二、实战演示：全排列问题 (LeetCode 46)

**题目**：给定一个不含重复数字的数组 `nums`，返回其所有可能的全排列。

**思路**：用 `used` 数组标记哪些数字已被选择，在递归的每一层尝试所有未被使用的数字。

**完整代码**：

```java
class Solution {
    List<List<Integer>> result = new ArrayList<>();
    LinkedList<Integer> path = new LinkedList<>();
    
    public List<List<Integer>> permute(int[] nums) {
        boolean[] used = new boolean[nums.length];
        backtrack(nums, used);
        return result;
    }
    
    private void backtrack(int[] nums, boolean[] used) {
        // 终止条件：path中的元素个数等于数组长度，说明找到一个完整排列
        if (path.size() == nums.length) {
            result.add(new ArrayList<>(path));
            return;
        }
        
        // 遍历所有元素，尝试将其加入当前排列
        for (int i = 0; i < nums.length; i++) {
            // 剪枝：如果当前元素已经使用过，跳过
            if (used[i]) {
                continue;
            }
            
            // 【做选择】
            path.add(nums[i]);
            used[i] = true;
            
            // 【递归】继续填充下一个位置
            backtrack(nums, used);
            
            // 【撤销选择】（回溯）
            used[i] = false;
            path.removeLast();
        }
    }
}
```

## 三、模板的关键点与变体

### 1. 终止条件的多样性
- **组合/子集问题**：`if (path.size() == k)` 或 `if (startIndex == nums.length)`
- **排列问题**：`if (path.size() == nums.length)`
- **搜索问题（如单词搜索）**：`if (index == word.length() - 1)`

### 2. 参数 `startIndex` 的作用
- **组合/子集**：用 `startIndex` 控制循环起始位置，避免重复组合（如 `[1,2]` 和 `[2,1]` 被视为相同）。
- **排列**：不需要 `startIndex`，因为顺序有意义，每次都从头遍历。

### 3. 去重操作（处理重复元素）
当输入数组有重复元素时，需要先**排序**，然后在循环中加入去重逻辑：
```java
// 在 for 循环中添加
if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) {
    continue; // 跳过重复的同一层选择
}
```

### 4. 剪枝优化
在进入递归前，如果当前路径已经不可能得到有效解，可以提前 `continue` 或 `break`。例如，组合总和问题中，如果当前和已经超过目标值，就可以 `break`（数组已排序）。

## 五、记忆口诀

> **回溯三部曲**：
> 1. **做选择**：标记当前选择。
> 2. **递归**：进入下一层决策。
> 3. **撤销选择**：清除当前选择，尝试下一个。

掌握这个通用模板后，你会发现大多数回溯题都是“换汤不换药”。建议你先用模板手写几道经典题（如全排列、组合总和），加深理解。如果对某个变体（如去重）的实现还有疑问，随时可以问我！ 😊
