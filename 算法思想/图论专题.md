# 图论专题

图论是把问题抽象成**点（节点）+ 边（关系）**后，用统一套路求解的一大类算法。刷题里最常考的是 **BFS / DFS 遍历、拓扑排序、最短路、最小生成树、并查集**（并查集见 [并查集.md](并查集.md)）。本篇讲清楚「什么问题该用哪种图算法、模板怎么写」。

BFS Breadth-First Search，中文为广度优先搜索
DFS Depth-First Search，中文为深度优先搜索
---

## 一、先把问题「翻译」成图

做图论题第一步永远是**建模**：谁是点、谁是边、边有没有方向、有没有权。

| 现实描述 | 点 | 边 | 图类型 |
|:---|:---|:---|:---|
| 课程 A 学完才能学 B | 课程 | 先修关系 | 有向图（拓扑） |
| 城市之间有航线、里程 | 城市 | 航线 | 带权图（最短路） |
| 网格里上下左右能走 | 格子 | 相邻格子 | 隐式图（网格 BFS/DFS） |
| 谁和谁是朋友 | 人 | 朋友关系 | 无向图（连通性/并查集） |

**存图三种方式**：

| 方式 | 适用 | 说明 |
|:---|:---|:---|
| 邻接矩阵 `int[n][n]` | 稠密图、n 小 | `g[u][v]` 存权值或 0/1，空间 \(O(n^2)\) |
| 邻接表 `List<int[]>[]` | 稀疏图（最常用） | 每个点存一个「邻居列表」，空间 \(O(n+m)\) |
| 隐式图 | 网格 / 状态搜索 | 不显式建图，遍历时按规则算出邻居（如四方向偏移） |

```java
// 邻接表建图（无向图；有向图只加一条边）
List<int[]>[] g = new List[n];
for (int i = 0; i < n; i++) g[i] = new ArrayList<>();
for (int[] e : edges) {              // e = {u, v, w}
    g[e[0]].add(new int[]{e[1], e[2]});
    g[e[1]].add(new int[]{e[0], e[2]});   // 有向图删掉这行
}
```

## 二、BFS 与 DFS：图遍历两大基石

|  | BFS（广度优先） | DFS（深度优先） |
|:---|:---|:---|
| 数据结构 | 队列 `Queue` | 栈 / 递归 |
| 扩展顺序 | 一层一层向外扩 | 一条路走到黑再回头 |
| 最擅长 | **无权图最短路径**、层序 | 连通块、路径枚举、回溯、拓扑 |
| 复杂度 | \(O(V+E)\) | \(O(V+E)\) |

### BFS 模板（含「层」的处理）

```java
public int bfs(int start, List<int[]>[] g, int n) {
    boolean[] visited = new boolean[n];
    Queue<Integer> queue = new ArrayDeque<>();
    queue.offer(start);
    visited[start] = true;             // 入队即标记，防止重复入队
    int depth = 0;
    while (!queue.isEmpty()) {
        int size = queue.size();       // 固定住「这一层」的节点数
        for (int i = 0; i < size; i++) {
            int cur = queue.poll();
            for (int[] nxt : g[cur]) {
                if (!visited[nxt[0]]) {
                    visited[nxt[0]] = true;
                    queue.offer(nxt[0]);
                }
            }
        }
        depth++;                       // 每处理完一层，深度 +1
    }
    return depth;
}
```

> **无权图**里，BFS 第一次访问到某点时的层数就是最短距离——这是 BFS 求最短路的原理。

### DFS 模板（递归版）

```java
public void dfs(int cur, List<int[]>[] g, boolean[] visited) {
    visited[cur] = true;
    // ... 处理当前节点 ...
    for (int[] nxt : g[cur]) {
        if (!visited[nxt[0]]) dfs(nxt[0], g, visited);
    }
}
```

### 网格 BFS/DFS（隐式图，超高频）

岛屿、腐烂橘子、被围绕的区域都是这个套路——不建图，用方向数组算邻居：

```java
int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};   // 上下左右
// 遍历时：
for (int[] d : dirs) {
    int nr = r + d[0], nc = c + d[1];
    if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == '1') {
        // 访问 (nr, nc)
    }
}
```

## 三、拓扑排序：有向无环图（DAG）的线性化

**用途**：给有依赖关系的任务排出一个「先后都不违反」的顺序（如排课、编译依赖）。**副产品：能否完成 = 图里有没有环。**

### Kahn 算法（BFS + 入度，最常用）

```java
public int[] topoSort(int n, List<Integer>[] g, int[] indegree) {
    Queue<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (indegree[i] == 0) queue.offer(i);  // 入度为 0 先入队
    int[] order = new int[n];
    int idx = 0;
    while (!queue.isEmpty()) {
        int cur = queue.poll();
        order[idx++] = cur;
        for (int nxt : g[cur]) {
            if (--indegree[nxt] == 0) queue.offer(nxt);   // 入度减到 0 才能入队
        }
    }
    return idx == n ? order : new int[0];   // idx<n 说明有环，无法完成
}
```

> 典型题：LeetCode 207 课程表（判断能否修完）、210 课程表 II（给出学习顺序）。

## 四、最短路：带权图的核心

| 算法 | 适用 | 复杂度 | 一句话 |
|:---|:---|:---|:---|
| **BFS** | 无权图 / 边权全为 1 | \(O(V+E)\) | 层数即最短距离 |
| **Dijkstra** | 非负权、单源 | \(O(E\log V)\) | 堆优化，每次取当前最近的点扩展 |
| **Bellman-Ford** | 含负权、单源 | \(O(VE)\) | 松弛 V-1 轮，可判负环 |
| **Floyd-Warshall** | 任意两点、可含负权 | \(O(V^3)\) | 三重循环 DP，n 小时首选 |

### Dijkstra（堆优化模板）

```java
public int[] dijkstra(int start, List<int[]>[] g, int n) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    // 小根堆按距离排序：{节点, 到起点的距离}
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]);
    pq.offer(new int[]{start, 0});
    while (!pq.isEmpty()) {
        int[] top = pq.poll();
        int u = top[0], d = top[1];
        if (d > dist[u]) continue;              // 过期的旧记录，跳过
        for (int[] e : g[u]) {                  // e = {v, w}
            int v = e[0], w = e[1];
            if (dist[u] + w < dist[v]) {        // 松弛
                dist[v] = dist[u] + w;
                pq.offer(new int[]{v, dist[v]});
            }
        }
    }
    return dist;
}
```

> **Dijkstra 不能处理负权边**——遇到负权用 Bellman-Ford / SPFA。求全源最短路且 n≤400 左右直接上 Floyd（三层 for，代码最短）。

### Floyd-Warshall（全源最短路，代码极简）

```java
for (int k = 0; k < n; k++)              // 枚举中转点，必须在最外层
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (dist[i][k] + dist[k][j] < dist[i][j])
                dist[i][j] = dist[i][k] + dist[k][j];
```

## 五、最小生成树（MST）：用最小代价连通所有点

**用途**：n 个点用若干带权边连成连通图，使总权值最小（修路、连电网）。

| 算法 | 思路 | 复杂度 | 适用 |
|:---|:---|:---|:---|
| **Kruskal** | 边按权排序，用[并查集](并查集.md)贪心加不成环的边 | \(O(E\log E)\) | 稀疏图（最常用） |
| **Prim** | 从一个点出发，堆维护「到已选集合最近的边」 | \(O(E\log V)\) | 稠密图 |

```java
// Kruskal：边排序 + 并查集
Arrays.sort(edges, (a, b) -> a[2] - b[2]);   // 按权重升序
UnionFind uf = new UnionFind(n);
int total = 0, cnt = 0;
for (int[] e : edges) {                       // e = {u, v, w}
    if (!uf.connected(e[0], e[1])) {          // 不成环才加入
        uf.union(e[0], e[1]);
        total += e[2];
        if (++cnt == n - 1) break;            // n-1 条边就够了
    }
}
```

## 六、如何按题目信号选算法

| 看到这样的描述… | 用什么 |
|:---|:---|
| 网格里数岛屿 / 连通块、被围绕的区域 | 网格 DFS / BFS / 并查集 |
| 无权图 / 步数最少、最短步数 | BFS（层数即距离） |
| 有先修 / 依赖关系、能否完成、排顺序 | 拓扑排序 |
| 带权图求单源最短路、非负权 | Dijkstra |
| 带权图含负权 / 判负环 | Bellman-Ford / SPFA |
| 任意两点最短路且点数很小（≤400） | Floyd-Warshall |
| 最小代价把所有点连通 | 最小生成树（Kruskal / Prim） |
| 判断是否连通 / 合并分组 | 并查集 |

## 七、常见坑点

1. **访问标记的时机**：BFS 应在**入队时**标记 `visited`，而不是出队时，否则同一节点会被重复入队。
2. **Dijkstra 的过期记录**：堆里可能有一个点的多条记录，取出时用 `if (d > dist[u]) continue;` 跳过旧的。
3. **拓扑排序判环**：最终排出的节点数 < n，说明存在环。
4. **有向 vs 无向**：建图时无向图要加两条边，别漏。
5. **网格越界**：四方向扩展前先判 `0 <= nr < m && 0 <= nc < n`。

## 九、一句话总结

图论题的通用套路是：**先建模（点/边/方向/权）→ 选遍历方式（BFS 最短、DFS 深搜）→ 按需求套专用算法（拓扑/最短路/MST）**。绝大多数「网格题」本质是隐式图上的 BFS/DFS。
