# 字符串处理思想

字符串题的套路密度极高：**不可变与拼接成本、反转系、回文系、匹配系（KMP）、编码解析**。本篇讲「字符串作为数据结构的特性 + 高频套路模板」；滑动窗口细看 [双指针与滑动窗口.md](双指针与滑动窗口.md)，栈解码看 [栈.md](栈.md)。

---

## 一、先懂 Java 字符串的坑（面试前置知识）

| 知识点 | 要点 |
|:---|:---|
| `String` **不可变** | 每次拼接 `+=` 都新建对象；循环拼接必须换 `StringBuilder`（否则 \(O(n^2)\)） |
| `StringBuilder` | 非线程安全、单线程首选；`reverse()` 直接可用 |
| `char` 与 int | `'a'`=97，`char - 'a'` 得 0~25 下标；`Character.isDigit/isLetter` 判类型 |
| `equals` vs `==` | 内容比较用 `equals`；`==` 比引用（字面量驻留的假象坑） |
| `split('.')` | 参数是正则，`.` 需转义 `split("\\.")` |
| `charAt` vs `toCharArray` | 多次访问转 `char[]` 更快，也方便原地交换 |

## 二、套路一：反转系（双指针原地交换）

```java
// 整体反转 / 区间反转 —— 一个模板全搞定
static void reverse(char[] a, int i, int j) {   // 闭区间 [i, j]
    while (i < j) {
        char t = a[i]; a[i++] = a[j]; a[j--] = t;
    }
}
```

| 题型 | 套路 |
|:---|:---|
| 整串反转 | `reverse(a, 0, n-1)` |
| 反转单词（保留空格） | 先整体反转，再**逐个单词内部反转回来** |
| 左旋 n 位 | 三步反转：前段 → 后段 → 整体（原地 O(1) 空间经典） |
| 下一个排列 | 从后找第一个升序对 → 交换 → 后缀反转，见 [31. 下一个排列](../leetcode-hot100/31.%20下一个排列.md) |

## 三、套路二：回文系（中心扩展）

```java
// 中心扩展：从每个"中心"向两边扩，统计回文子串个数
static int countPalindromes(String s) {
    int n = s.length(), ans = 0;
    for (int c = 0; c < 2 * n - 1; c++) {        // 2n-1 个中心：n 个字符 + n-1 个缝隙
        int i = c / 2, j = i + c % 2;            // 奇数中心(i,i) 偶数中心(i,i+1)
        while (i >= 0 && j < n && s.charAt(i) == s.charAt(j)) {
            ans++; i--; j++;                     // 每扩成功一次就是一个回文
        }
    }
    return ans;
}
```

- 判回文：双指针对撞；**跳过非字母数字**（`Character.isLetterOrDigit`）+ 忽略大小写是高频变体。
- 最长回文子串：中心扩展 \(O(n^2)\) 够用；Manacher \(O(n)\) 属于加分项不是必需。
- 相关题：[647. 回文子串](../leetcode-hot100/647.%20回文子串.md)、[234. 回文链表](../leetcode-hot100/234.%20回文链表.md)（反转后半段）。

## 四、套路三：匹配系（KMP 与「失败指针」思想）

朴素匹配 \(O(nm)\)；KMP 利用**已匹配前缀的信息**做到 \(O(n+m)\)：

```java
// next[j] = pattern[0..j-1] 的"最长相等前后缀"长度
static int[] buildNext(String p) {
    int m = p.length(), j = 0;
    int[] next = new int[m];
    for (int i = 1; i < m; i++) {
        while (j > 0 && p.charAt(i) != p.charAt(j)) j = next[j - 1]; // 失配回退
        if (p.charAt(i) == p.charAt(j)) j++;
        next[i] = j;
    }
    return next;
}
// 主串扫描：失配时 j = next[j-1] 回跳而不是从头再来
```

**思想价值大于代码价值**（手写 next 的机会少）：「失配不回头，利用前缀复用信息」的同族思想出现在——字符串周期判定（`next[m-1]` 求 最小循环节）、[28. 找出字符串中第一个匹配项]、树的后缀结构（AC 自动机）。面试一般考「next 数组含义」而不是默写。

## 六、易错点 ⚠️

| 易错点 | 澄清 |
|:---|:---|
| **循环里 `s += c`** | 不可变对象每次新建；用 `StringBuilder.append`（需线程安全用 `StringBuffer`） |
| **`split(".")` 得到空数组** | split 参数是正则，元字符要转义：`split("\\.")`、`split("\\|")` |
| **边界只顾中间忘两端** | 反转/对撞指针模板 `while (i < j)` 防交叉；中心扩展遍历 `2n-1` 个中心 |
| **大数乘 10 溢出** | `num * 10 + d` 超 int 前用 long；或及时 `num > (Integer.MAX_VALUE - d) / 10` 判截断 |
| **`==` 比较字符串内容** | `s1 == s2` 比引用；内容一律 `equals`，拆箱装箱同理 |
| **字符集假设错** | 只有小写字母才可用 `int[26]`；含大写/Unicode 用 `int[128]`/`int[256]` 或哈希表 |
| **原地修改 String** | String 不可变，先 `toCharArray()` 再操作，或 StringBuilder |

---

## 七、一句话总结

字符串题 = **Java 特性坑（不可变/正则转义/equals） + 五个模板**：双指针反转（整体/区间/三步旋转）、中心扩展回文（2n-1 中心）、KMP 失配复用、栈解嵌套编码、双指针大数运算——先判「能否原地（char[]）」，再选模板，复杂度自然从 \(O(n^2)\) 降到 \(O(n)\)。
