# 循环与模拟思想

OD/笔试里的「大模拟」、工程里的「按规则处理数据」，考的都是**把题意逐条翻译成循环与状态变量**的能力。模拟不涉及高级算法，拼的是：**规则拆解不漏、边界枚举不全错、方向与下标不手滑**。

---

## 一、模拟题的通用四步法

1. **流程化题意**：把叙述性规则改写成「每一步做什么、变量怎么变」的伪代码清单；
2. **枚举所有情况**：题目说「当 A 则 B」，先列出 A 的所有取值（含空、单元素、越界）；
3. **定义循环不变量**：每一轮开始时哪些变量必须满足什么关系（防止 off-by-one）；
4. **边界单独验**：空输入、单元素、极大值、首尾位置，样例手工走一遍。

```java
// 例：按规则模拟 —— 约瑟夫环（n 人围圈报数，报到 m 出圈，求最后幸存者）
// 朴素模拟 O(n*m)：队列/数组 + 计数
static int joseph(int n, int m) {
    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 1; i <= n; i++) queue.offer(i);
    int cnt = 0;                       // 当前报数（从 1 开始）
    while (queue.size() > 1) {
        int cur = queue.poll();
        cnt++;
        if (cnt == m) cnt = 0;         // 报到 m：出圈，计数复位
        else queue.offer(cur);         // 没报到：回队尾（绕圈）
    }
    return queue.poll();
}
// 递推公式法 O(n)：f(1)=0; f(i) = (f(i-1) + m) % i —— 模拟懂思想后可背公式
```

## 二、模拟的四大高频题型

| 题型 | 关键技巧 | 代表 |
|:---|:---|:---|
| **方向/路径模拟** | `dx/dy` 方向数组 + 转向表 + 边界/障碍检测 | 螺旋矩阵、机器人走位 |
| **规则计数** | 按题意逐条 if-else，注意条件覆盖完整 | OD 大多数大题 |
| **过程推演** | 队列/栈按时间顺序处理事件 | 约瑟夫环、任务调度 |
| **状态轮转** | 每轮统一更新，注意「同步 vs 逐个」更新 | 康威生命游戏、井字棋 |

### 2.1 方向模拟：螺旋矩阵骨架

```java
// l r t b 四边界收缩法：按 右→下→左→上 循环，每走完一条边收缩对应边界
static List<Integer> spiral(int[][] mat) {
    List<Integer> ans = new ArrayList<>();
    int l = 0, r = mat[0].length - 1, t = 0, b = mat.length - 1;
    while (l <= r && t <= b) {
        for (int j = l; j <= r; j++) ans.add(mat[t][j]);   // 上行向右
        for (int i = ++t; i <= b; i++) ans.add(mat[i][r]); // 右列向下（t 已收缩）
        if (t <= b) for (int j = --r; j >= l; j--) ans.add(mat[b][j]); // 下行向左
        if (l <= r) for (int i = --b; i >= t; i--) ans.add(mat[i][l]); // 左列向上
        l++;
    }
    return ans;
}
```

四边界收缩 vs 方向数组：**矩形边界用收缩法不易错；任意转向（碰壁改变方向）用 dx/dy + 转向规则**。

## 三、循环本身的三种优化形态

模拟写对之后，真正的算法提升是把「朴素循环」换成三类结构：

1. **前缀型循环**：把「每次都重新算一段」改成「跑动中累积」（前缀和、 running product）；
2. **双指针型循环**：两层 for 变一次扫描（快慢/对撞/滑动窗口），见 [双指针与滑动窗口.md](双指针与滑动窗口.md)；
3. **倍增/公式型循环**：发现周期性直接取模（约瑟夫递推、快乐数的循环检测用快慢指针找环）。

> 判断信号：循环里出现「重复计算同一区间/同一子问题」→ 上述三选一。模拟只是骨架，循环优化是血肉。

## 四、易错点 ⚠️

| 易错点 | 澄清 |
|:---|:---|
| **规则漏了某种情况** | 把题目每条规则编号列出，写完后**逐条回对**——模拟题错 90% 错在漏规则 |
| **同步更新写成逐个更新** | 生命游戏类：所有格子应基于**上一轮**状态更新 → 先复制或用额外状态位 |
| **边界收缩时机错** | 螺旋矩阵 `++t/--r` 的先后顺序画 3×3 手推，别凭感觉 |
| **绕圈用取模下标出错** | 环形结构 `idx = (idx + 1) % n`，删除元素后 n 要变 |
| **死循环** | 转向规则不终止/状态没推进时，加「步数上限」自保护（步数 > 4mn 必然循环） |
| **大模拟超时** | 先估算操作次数：\(10^8\) 量级 Java 会超时，必须找规律或换数据结构 |

---

## 五、一句话总结

模拟 = **题意翻译成循环 + 状态变量，靠「规则逐条对、边界手推验、循环不变量」保正确**；写对之后的优化方向是前缀、双指针、公式化——模拟保底分，循环优化拿满分。
