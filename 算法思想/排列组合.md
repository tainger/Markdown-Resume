# 排列与组合

排列组合是「回溯模板 + 计数公式」的双面题：**要列出所有方案 → 回溯模板**；**只要数量 → 数学公式/递推**。本篇把两面的分界和去重技巧讲透。模板细节另见 [回溯.md](回溯.md)，公式细节见 [2.数学公式.md](2.数学公式.md)。

---

## 一、先分清三兄弟：排列 / 组合 / 子集

| 对比项 | 排列 Permutation | 组合 Combination | 子集 Subset |
|:---|:---|:---|:---|
| 关心顺序？ | ✅ (1,2)≠(2,1) | ❌ (1,2)=(2,1) | ❌（每个元素选/不选） |
| 数量 | \(P(n,k)=\frac{n!}{(n-k)!}\) | \(C(n,k)=\frac{n!}{k!(n-k)!}\) | \(2^n\) |
| 回溯关键参数 | `used[]` 标记 | `start` 起点递增 | `start` 起点递增 |
| 收集时机 | 长度达标收集 | 长度达标收集 | **每个节点都收集** |

```java
// ============ 三套模板（背熟，k 换成具体约束）============
// ① 排列：used 标记，每层都从 0 开始选
void permute(int[] nums, boolean[] used, List<Integer> path) {
    if (path.size() == nums.length) { res.add(new ArrayList<>(path)); return; }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;                 // 已用过跳过
        used[i] = true; path.add(nums[i]);     // 做选择
        permute(nums, used, path);
        used[i] = false; path.remove(path.size() - 1); // 撤销选择
    }
}

// ② 组合：start 递增，只向后选 → 天然去重
void combine(int n, int k, int start, List<Integer> path) {
    if (path.size() == k) { res.add(new ArrayList<>(path)); return; }
    for (int i = start; i <= n - (k - path.size()) + 1; i++) { // ★ 剪枝上界
        path.add(i); combine(n, k, i + 1, path); path.remove(path.size() - 1);
    }
}

// ③ 子集：每个节点都收集，而非叶子收集
void subsets(int[] nums, int start, List<Integer> path) {
    res.add(new ArrayList<>(path));            // 进入即收集
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]); subsets(nums, i + 1, path); path.remove(path.size() - 1);
    }
}
```

## 二、重复元素的去重（高频坑）

**两层去重原则**（数组先排序是前提）：

1. **同层去重**（树的横向）：`if (i > start && nums[i] == nums[i-1]) continue;` —— 同一层里相同的值只选第一个；
2. **跨层不去重**（树的纵向）：同一条路径上重复元素可以再次出现（原数组有重复时）。

```java
// 含重复元素的组合（如 组合总和 II）：排序后同层跳过重复
Arrays.sort(nums);
void backtrack(int[] nums, int target, int start, List<Integer> path) {
    if (target == 0) { res.add(new ArrayList<>(path)); return; }
    for (int i = start; i < nums.length && nums[i] <= target; i++) {
        if (i > start && nums[i] == nums[i - 1]) continue; // ★ 同层去重
        path.add(nums[i]);
        backtrack(nums, target - nums[i], i + 1, path);    // 每个数只能用一次 → i+1
        path.remove(path.size() - 1);
    }
}
```

> 「元素可重复使用」→ 递归传 `i`（不 +1），如 [39. 组合总和](../leetcode-hot100/39.%20组合总和.md)；「只能用一次」→ 传 `i + 1`；「排列」→ used 数组。三个参数选择是回溯题的核心区分点。

## 三、只要数量：数学面

```java
// 组合数递推表（杨辉三角）：C(n,k) = C(n-1,k-1) + C(n-1,k)
// 用 long 防乘法溢出，模运算见 数学公式.md
static long[][] binomial(int n) {
    long[][] C = new long[n + 1][n + 1];
    for (int i = 0; i <= n; i++) {
        C[i][0] = 1;
        for (int j = 1; j <= i; j++)
            C[i][j] = C[i-1][j-1] + C[i-1][j];   // 选第 i 个 or 不选
    }
    return C;
}
```

| 场景 | 用公式 | 用回溯 |
|:---|:---|:---|
| 只要「多少种」 | ✅ 递推/乘法公式，\(O(n^2)\) 或 \(O(n)\) | ❌ n=30 就爆炸 |
| 要列出每种方案 | ❌ | ✅ 模板套用 |
| 大数取模计数 | ✅ 递推 + 取模 | ❌ |

- 排列数、卡特兰数（合法括号序列数）等常用公式速查见 [2.数学公式.md](2.数学公式.md)。
- 典型对照：[22. 括号生成](../leetcode-hot100/22.%20括号生成.md) 要**列出**所有合法括号 → 回溯（左括号数 < n、右 < 左 两个约束）；若只问有多少种 → 卡特兰数 \(C_n = \frac{1}{n+1}C(2n,n)\)。

## 四、易错点 ⚠️

| 易错点 | 澄清 |
|:---|:---|
| **排列用了 start、组合用了 used** | 排列每层从 0 扫（需 used）；组合只向后扫（start）——两者用反结果重复/遗漏 |
| **去重忘了先排序** | `nums[i]==nums[i-1]` 的同层去重依赖相邻相等，必须先 `Arrays.sort` |
| **去重条件写成 `i > 0`** | 会把「跨层合法复用」也剪掉；正确是 `i > start`（只剪同一层） |
| **结果集直接 add(path)** | 引用复用，最后全空——必须 `new ArrayList<>(path)` 拷贝 |
| **子集只在叶子收集** | 子集是每个节点收集；叶子收集只得到完整组合 |
| **组合剪枝上界漏算** | `i <= n - (k - path.size()) + 1`：剩余元素不够凑满 k 个就不用再试 |
| **数量题硬回溯** | n=30 求方案数直接卡特兰/DP 递推，回溯必超时 |

---

## 五、一句话总结

排列组合两把尺子：**要方案用回溯模板（排列 used / 组合与子集 start / 重复元素排序 + 同层去重 i>start），要数量用公式递推（C(n,k) 杨辉三角、卡特兰数）**——「可重复用 i、用一次 i+1、排列用 used」三个递归参数选对，模板题就稳了。
