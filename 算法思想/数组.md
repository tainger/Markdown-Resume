# 数组技巧

数组是最基础的容器，数组题的难点全在**原地操作**（O(1) 空间约束）与**下标语义**。本篇聚焦：原地覆盖系（双指针）、原地标记系（符号/交换）、前缀型复用——前缀和/滑动窗口细节见 [前缀和与差分.md](前缀和与差分.md) 与 [双指针与滑动窗口.md](双指针与滑动窗口.md)。

## 一、原地覆盖：读写双指针（同向）

**套路**：`slow` 指向「下一个可写位置」，`fast` 扫描；把「保留的元素」前移压缩数组。

```java
// ============ 移动零：保非零 + 剩余补零 ============
static void moveZeroes(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++)
        if (nums[fast] != 0)
            nums[slow++] = nums[fast];     // 先把非零前移覆盖
    for (int i = slow; i < nums.length; i++)
        nums[i] = 0;                       // 尾部补零
}

// ============ 删除重复项（有序）：保首个 + 计数保留 k 个 ============
static int removeDuplicates(int[] nums) {  // 每个元素最多保留 2 次
    int slow = 0;
    for (int x : nums)
        if (slow < 2 || nums[slow - 2] != x)  // ★ 和 slow-2 比：通用保留 k 个
            nums[slow++] = x;
    return slow;                           // 新长度
}
```

同族题：[283. 移动零](../leetcode-hot100/283.%20移动零.md)、[27. 移除元素]、[80. 删除有序数组重复项 II]、[448. 找到所有数组中消失的数字](../leetcode-hot100/448.%20找到所有数组中消失的数字.md)（变标记法）。

## 二、原地标记：用「符号位/偏移」当 HashMap

**值域恰好是 `[1, n]`** 时，下标本身就是天然的信息位——把出现过的值对应位置打成负数，一轮遍历即可统计，空间 \(O(1)\)：

```java
// 448 消失的数字：值 x 出现过 → 把 nums[|x|-1] 取负做标记
static List<Integer> findDisappeared(int[] nums) {
    for (int x : nums) {
        int idx = Math.abs(x) - 1;         // ★ 取 abs：可能已被打过负号
        if (nums[idx] > 0) nums[idx] = -nums[idx];
    }
    List<Integer> ans = new ArrayList<>();
    for (int i = 0; i < nums.length; i++)
        if (nums[i] > 0) ans.add(i + 1);   // 仍是正数 → i+1 没出现过
    return ans;
}
```

| 变体 | 标记方式 |
|:---|:---|
| 消失的数字 / 找重复 | 符号位（负数标记） |
| 旋转数组 | 三段反转（见下） |
| 寻找重复数 | **Floyd 快慢指针找环**（下标→值的映射当链表，`nums[i]` 是 next），[287. 寻找重复数](../leetcode-hot100/287.%20寻找重复数.md) |
| 缺失的第一个正数 | 交换归位：`while (nums[i] in [1,n] && nums[nums[i]-1] != nums[i]) swap` |

## 三、原地旋转/轮转：三段反转

```java
// 数组右移 k 位：整体反转 → 前 k 反转 → 后 n-k 反转（O(1) 空间，无需额外数组）
static void rotate(int[] a, int k) {
    int n = a.length;
    k %= n;                              // ★ k 可能大于 n
    reverse(a, 0, n - 1);
    reverse(a, 0, k - 1);
    reverse(a, k, n - 1);
}
static void reverse(int[] a, int i, int j) {
    while (i < j) { int t = a[i]; a[i++] = a[j]; a[j--] = t; }
}
```

除了反转法，还有 **环状替换**（从 0 出发每次跳 k 步直到回到起点，循环次数 = gcd(n,k)）；笔试里 `System.arraycopy` 到新数组最简单但空间 \(O(n)\)。

## 五、易错点 ⚠️

| 易错点 | 澄清 |
|:---|:---|
| **原地覆盖读还没扫的数据** | 同向双指针保证 `fast ≥ slow`，写永不超前于读；逆序遍历处理「写会覆盖后面」的场景 |
| **标记法忘了先取 abs** | 数组里可能已被改成负数，`Math.abs(x) - 1` 再定位 |
| **旋转 k 没取模** | `k %= n`，否则 k > n 时反转区间越界 |
| **保留 k 个重复时和 slow-1 比** | 应和 `slow - k` 比（保留 2 个 → `slow-2`），错比 slow-1 会误删 |
| **for-each 里改数组** | 增强 for 不支持下标写入，原地操作用显式下标循环 |
| **空数组/单元素漏判** | `n == 0` 时 `nums[0]` 直接越界，函数入口先判 |

---

## 六、一句话总结

数组题三板斧：**原地覆盖用读写双指针（slow 可写位）、原地标记用符号位/交换归位（值域 [1,n] 是信号）、区间问题先想前缀与差分**——见到「O(1) 空间」「原地」字样，先问「下标能不能当信息位」。
