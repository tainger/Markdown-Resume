# 枚举思想

枚举不是「无脑暴力」——它是**把答案空间定义清楚，再系统化遍历**的方法论。所有优化算法（剪枝、哈希、双指针、DP）都是对某个「笨枚举」的加速。面试时先给出正确的暴力枚举，往往就是优化推导的起点（用户刷题习惯也是先暴力再优化）。

---

## 一、枚举的三要素（写对暴力的检查单）

1. **枚举什么**：答案空间是「一对下标 / 一个子集 / 一个排列 / 一个切割点」？
2. **什么顺序**：去重怎么处理？有没有单调性可利用？
3. **何时提前终止**：剪枝条件是什么？

```java
// 例：三数之和最朴素的三层枚举 O(n^3)
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)          // j 从 i+1 起 → 组合去重（不回头选）
        for (int k = j + 1; k < n; k++)
            if (a[i] + a[j] + a[k] == 0) ans++;
```

这套循环设计的隐含约定：**下标递增 = 天然去重**（同一组数只按一种顺序被枚举）。「起点递增」是组合枚举的通用写法。

## 二、枚举对象分型速查

| 枚举对象 | 通用写法 | 复杂度 | 典型题 |
|:---|:---|:---:|:---|
| **数对** \((i,j)\) | 双层循环 `j>i` | \(O(n^2)\) | 两数之和（哈希优化到 \(O(n)\)） |
| **三元组/多元组** | 多层循环 + 双指针降维 | \(O(n^2)\)~\(O(n^3)\) | 三数之和 |
| **子序列** | 位掩码 / 递归选或不选 | \(O(2^n)\) | 子集、最大整除子集 |
| **排列** | 递归 + used 标记 | \(O(n!)\) | [46. 全排列](../leetcode-hot100/46.%20全排列.md) |
| **分割点** | 枚举每刀的位置 | \(O(n^2)\) | [139. 单词拆分](../leetcode-hot100/139.%20单词拆分.md) |
| **答案值** | 二分答案（枚举变二分） | \(O(n\log V)\) | 船最低载重、分割数组的最大值 |
| **区间** | 枚举左端点 + 右端点推进 | \(O(n^2)\)→窗口 | [回文子串 647](../leetcode-hot100/647.%20回文子串.md) |

## 三、加速枚举的五种手段（核心）

```
 暴力枚举 O(n^2) 以上的四个加速方向：

 ① 哈希换一维：两数之和外层定 i，内层找 target-nums[i] → 哈希 O(1) 查
 ② 单调性剪枝：排序后双指针夹逼（和大了右移、小了左移）→ O(n^2)→O(n)
 ③ 前缀/计数预处理：枚举时 O(1) 拿到"子问题答案"（前缀和、计数数组）
 ④ 位掩码枚举子集：n ≤ 20~24 时，子集枚举 O(2^n) 可接受 + 状压 DP
 ⑤ 二分答案：枚举"答案值"具有单调性 → 二分（见二分查找.md）
```

典型加速链（三数之和）：三层暴力 \(O(n^3)\) → **排序 + 固定 i + 双指针** \(O(n^2)\) → 命中后跳过重复元素。

## 四、子集/排列的两种系统枚举写法

```java
// ① 位掩码枚举子集：n ≤ 20，mask 的每一位表示"取/不取"
for (int mask = 0; mask < (1 << n); mask++) {
    for (int i = 0; i < n; i++)
        if ((mask & (1 << i)) != 0) /* 第 i 个元素在子集中 */ ;
}
// 枚举子集的子集（状压 DP 常用）：sub = (sub - 1) & mask 从大到小遍历

// ② 回溯枚举排列/组合：见 回溯.md 的 start/used 模板
```

选择依据：**要所有子集 → 位掩码或回溯都行；要排列 → 回溯 used；做 DP → 状压位掩码**。位运算细节见 [位运算.md](位运算.md)。

## 五、易错点 ⚠️

| 易错点 | 澄清 |
|:---|:---|
| **内层从 0 开始重复枚举** | 组合类用「起点递增」`j = i + 1` 天然去重；排列才需要 used/交换 |
| **n=20 的子集题想 DP** | \(2^{20}=10^6\) 枚举可行；\(2^{30}\) 就爆炸——先算数量级再选方法 |
| **枚举答案值忘了单调性** | 二分答案前提：「答案越大越容易/越难」单调解；不单调则枚举+剪枝 |
| **重复元素没排序去重** | 三数之和/组合总和 II：先排序，同层 `i > start && nums[i]==nums[i-1]` 跳过 |
| **long/int 混用** | 枚举乘积/和时（如 \(10^5\) 量级两数乘积）用 long 防溢出 |
| **写完暴力不验样例直接优化** | 优化版与暴力对拍小样例，是防翻车的最稳手段 |

---

## 六、一句话总结

枚举的方法论 = **先定义答案空间（对/子集/排列/分割点/答案值），再选加速手段（哈希/双指针/前缀/位掩码/二分）**：暴力枚举是所有优化的地基，面试先口述正确暴力再降维，既保底又有推导感——「\(O(n^3)\) 暴力 → 排序+双指针 \(O(n^2)\)」是最经典的讲述路径。
