# 栈的算法题套路

栈的结构与实现细节见 [../数据结构/栈.md](../数据结构/栈.md)。本篇讲**算法题中栈的四个固定套路**：括号匹配、表达式求值、嵌套解码、单调栈（已独立成篇）。

## 一、四大套路速查

| 套路 | 栈里存什么 | 信号词 | 代表题 |
|:---|:---|:---|:---|
| **括号/配对匹配** | 期待出现的左括号/下标 | 有效、匹配、成对 | [20. 有效的括号](../leetcode-hot100/20.%20有效的括号.md)、[32. 最长有效括号](../leetcode-hot100/32.%20最长有效括号.md) |
| **表达式求值** | 操作数（或运算符） | 计算器、表达式 | 基本计算器 I/II/III |
| **嵌套结构解码** | 上层上下文（次数+前缀） | 嵌套、重复、解码 | [394. 字符串解码](../leetcode-hot100/394.%20字符串解码.md)、[394 同型 301](../leetcode-hot100/301.%20删除无效的括号.md) |
| **单调栈** | 保持单调性的**下标** | 下一个更大/更小、跨度 | [739. 每日温度](../leetcode-hot100/739.%20每日温度.md)、[42. 接雨水](../leetcode-hot100/42.%20接雨水.md) |

## 二、括号匹配（计数器版 vs 栈版）

```java
// 只有单一括号类型 → 计数器即可 O(1) 空间
static boolean isValid(String s) {
    int cnt = 0;
    for (char c : s.toCharArray()) {
        if (c == '(') cnt++;
        else if (--cnt < 0) return false;   // ★ 中途变负 = 右括号先于左括号
    }
    return cnt == 0;                        // 结束时必须归零
}
// 多种括号 → 必须用栈：遇到左括号压"期望的右括号"，遇到右括号弹栈比对
```

## 三、嵌套解码（栈 = 保存现场）

```java
// 394: 3[a2[c]] → accaccacc；遇到 '[' 压现场，遇到 ']' 弹现场重建
static String decode(String s) {
    Deque<Integer> numStack = new ArrayDeque<>();   // 重复次数
    Deque<StringBuilder> strStack = new ArrayDeque<>(); // '[' 前已构建的前缀
    StringBuilder cur = new StringBuilder();
    int num = 0;
    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) num = num * 10 + (c - '0');
        else if (c == '[') {
            numStack.push(num); strStack.push(cur); // 压现场
            num = 0; cur = new StringBuilder();     // 开新层
        } else if (c == ']') {
            int k = numStack.pop();
            StringBuilder pre = strStack.pop();
            for (int i = 0; i < k; i++) pre.append(cur); // 重复 k 次
            cur = pre;                              // 恢复现场并续写
        } else cur.append(c);
    }
    return cur.toString();
}
```

> 「遇到左括号压现场、遇到右括号弹现场」——**栈的通用价值就是"保存未完成的上下文"**，递归转迭代也用它（显式栈模拟递归，见 [0.递归.md](0.递归.md)）。

## 四、易错点

| 易错点 | 澄清 |
|:---|:---|
| **单括号也用栈** | 单一类型计数器够用；多类型才需要栈比对 |
| **计数器不判中途为负** | `)(` 结束计数为 0 但非法——必须边扫边判 `< 0` |
| **解码数字多位** | `12[a]` 的 12 要 `num*10+d` 累积，不能只取一个字符 |
| **弹栈后忘记续写** | 弹出现场后 `cur` 要替换为合并结果，继续接后面的字符 |
| **单调栈存值不存下标** | 存值算不了跨度/宽度；单调栈统一存**下标**（见 [单调栈.md](单调栈.md)） |
| **Java 用 Stack 类** | 继承 Vector 有锁开销；用 `Deque<Integer> stack = new ArrayDeque<>()` |

## 五、一句话总结

栈的算法题本质 = **"后出现的约束先被满足"（LIFO 的现场保存）**：配对问题比对栈顶、嵌套问题压现场弹现场、单调问题维护下标单调性——认出「配对/嵌套/下一个更大」三类信号词，栈就是条件反射。
