## 一、四种遍历框架（一切树题的地基）

```java
// ============ ① 递归遍历：唯一区别是"处理时机"============
static void dfs(TreeNode node) {
    if (node == null) return;          // 终止条件
    // 前：处理 node（根）          —— 前序遍历
    dfs(node.left);
    // 中：处理 node                —— 中序遍历（BST → 升序！）
    dfs(node.right);
    // 后：处理 node                —— 后序遍历（自底向上汇总）
}

// ============ ② 层序（BFS）：队列 + 按层截断 ============
static void levelOrder(TreeNode root) {
    if (root == null) return;
    Deque<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();       // 固定本层元素数
        for (int s = 0; s < size; s++) {
            TreeNode cur = queue.poll();
            if (cur.left != null) queue.offer(cur.left);
            if (cur.right != null) queue.offer(cur.right);
        }
        // 此处可对"整层"做处理：右视图/锯齿/每层最值
    }
}

// ============ ③ 迭代前/中/后序：显式栈（中序最高频）============
static List<Integer> inorder(TreeNode root) {
    List<Integer> ans = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) { stack.push(cur); cur = cur.left; }  // 一路向左
        cur = stack.pop();                                        // 弹出最左
        ans.add(cur.val);                                         // 访问
        cur = cur.right;                                          // 转右子树
    }
    return ans;
}
```

| 遍历 | 处理时机 | 题目信号 |
|:---|:---|:---|
| 前序 | 自顶向下传递信息（路径前缀、构造） | 序列化、路径总和 |
| **中序** | BST 性质利用 | [538. 累加树](../leetcode-hot100/538.%20把二叉搜索树转换为累加树.md)（反向中序求降序累加）、验证 BST、[94. 中序遍历](../leetcode-hot100/94.%20二叉树的中序遍历.md) |
| **后序** | 自底向上汇总子树信息 | 最大深度、[124. 最大路径和](../leetcode-hot100/124.%20二叉树中的最大路径和.md)、[337. 打家劫舍 III](../leetcode-hot100/337.%20打家劫舍%20III.md) |
| 层序 | 按层处理 | 右视图、最小深度、[101. 对称二叉树](../leetcode-hot100/101.对称二叉树.md)（双指针式层序也可递归） |

## 二、递归套路：三问法

写任何树题先自问三个问题：

1. **返回什么**：子问题要给父节点什么信息？（深度 int / 子树和 / 是否平衡 + 深度）
2. **前序还是后序做处理**：自顶向下传状态→前序；汇总子树→后序；
3. **要不要全局变量**：答案路径型问题常用「全局 best + 递归返回局部贡献」双轨制。

```java
// 例：124 最大路径和 —— 经典"返回贡献值 + 全局更新"双轨
private int maxSum = Integer.MIN_VALUE;                 // 全局：完整路径和
public int maxPathSum(TreeNode root) {
    depth(root); return maxSum;
}
private int depth(TreeNode node) {                      // 返回：单边最大贡献
    if (node == null) return 0;
    int left  = Math.max(depth(node.left), 0);          // ★ 负贡献直接舍弃（取 0）
    int right = Math.max(depth(node.right), 0);
    maxSum = Math.max(maxSum, node.val + left + right); // 后序位置：折弯路径候选答案
    return node.val + Math.max(left, right);            // 给父节点：只带一条边
}
```

「返回值 = 局部合法贡献，全局变量 = 最终答案」——124、543（直径）、124/337 全是这一个套路。

## 三、进阶一：树形 DP（状态随遍历携带）

当「选不选父节点影响子节点决策」时，递归返回值升级为**状态数组**：

```java
// 337 打家劫舍 III：返回 [不偷该节点, 偷该节点] 两个状态
static int[] rob(TreeNode node) {
    if (node == null) return new int[2];
    int[] L = rob(node.left), R = rob(node.right);       // 后序：先拿子树两状态
    int notRob = Math.max(L[0], L[1]) + Math.max(R[0], R[1]); // 不偷：儿子随便
    int rob    = node.val + L[0] + R[0];                 // 偷：儿子必须不偷
    return new int[]{notRob, rob};
}
// 答案 = max(rob(root)[0], rob(root)[1])
```

同族思想见 [状态机.md](状态机.md)——把「约束」编码进返回值维度。

## 四、进阶二：树上前缀和（路径和问题）

```java
// 437 路径总和 III：前缀和 + HashMap（从根到当前节点的路径前缀）
private Map<Long, Integer> prefix = new HashMap<>();
private int target, ans;
public int pathSum(TreeNode root, int t) {
    target = t; prefix.put(0L, 1);                       // 空前缀：从根出发的路径
    dfs(root, 0L); return ans;
}
private void dfs(TreeNode node, long cur) {
    if (node == null) return;
    cur += node.val;
    ans += prefix.getOrDefault(cur - target, 0);         // 有多少前缀 = cur - target
    prefix.merge(cur, 1, Integer::sum);                  // 记录当前前缀
    dfs(node.left, cur); dfs(node.right, cur);
    prefix.merge(cur, -1, Integer::sum);                 // ★ 回溯撤销：左子树前缀不能带去右子树
}
```

「子数组问题和」搬到树上：数组前缀和 → **根到节点路径前缀**；滑动窗口失效（路径分叉）→ HashMap 计数 + **回溯撤销**。同源题目见 [437. 路径总和 III](../leetcode-hot100/437.%20路径总和%20III.md)、[560. 和为 K 的子数组](../leetcode-hot100/560.%20和为%20K%20的子数组.md)。

## 五、易错点 ⚠️

| 易错点 | 澄清 |
|:---|:---|
| **递归终止漏 `node == null`** | 所有树递归第一行；空树样例必须过 |
| **负值路径以为可以不选** | 124 里负贡献子树要 `max(贡献, 0)` 舍弃；「必经 root」约束只在全局更新处体现 |
| **中序迭代忘了 `cur = cur.right`** | 弹栈访问后不转右子树 → 死循环 |
| **BST 判断只比父子** | 要与**整棵左子树上界/右子树下界**比（传 min/max 递归）或用中序有序性 |
| **树上前缀和不回溯撤销** | `prefix` 是全局共享的，左右子树切换时必须把当前前缀计数 -1 |
| **层序 size 忘了先取** | `int size = queue.size()` 在 for 前固定；循环内队列在变 |
| **构造题找到分割点仍全扫** | 每次 O(n) 找根 O(n²)；用 HashMap 缓存「值→下标」降为 O(n) |

## 六、一句话总结

树题三板斧：**遍历框架选处理时机（BST 用中序、汇总用后序、构造用前序），递归三问法定返回值（返回贡献 + 全局答案双轨制），进阶把约束编码成返回状态（树形 DP）或把前缀和搬上树（HashMap + 回溯撤销）**——「返回局部贡献、全局记答案」一句话能讲清 124/543/337 全家。
