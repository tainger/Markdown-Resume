# 正则表达式

正则题分三层考：**Java API 层**（Pattern/Matcher、转义坑）、**算法层**（LeetCode 10 正则匹配 DP）、**思想层**（正则=有限状态自动机 NFA/DFA）。面试以第二层为主，第一层是工程常识，第三层是加分谈资。

---

## 一、Java 正则 API 与工程坑（速览）

```java
// 预编译复用（Pattern 线程安全，Matcher 每次新建）
private static final Pattern NUM = Pattern.compile("^\\d{1,3}(,\\d{3})*$");
Matcher m = NUM.matcher(input);
if (m.matches()) { ... }        // 全串匹配
m.find();                       // 找子串，配合 m.group(1) 取捕获组
input.replaceAll("\\s+", " ");  // 正则替换（压缩空白）
input.split("\\.");             // ★ split 参数是正则，元字符要转义
```

| 坑 | 说明 |
|:---|:---|
| **元字符转义** | `.` `|` `+` `?` `*` `(` `)` `[` `{` 在正则里有特殊义；字面量要 `\\.`；`split("|")` 切出单个字符 |
| **贪婪 vs 懒惰** | `.*` 贪婪吃到底；`.*?` 懒惰最小匹配——解析 HTML/括号必考 |
| **matches vs find** | `matches` 要求全串匹配；`find` 局部即可，混用会漏 |
| **回溯爆炸** | 嵌套量词如 `(.*)*` 在长输入上指数回溯（ReDoS）；改用占有符 `*+` 或简化模式 |

## 二、LeetCode 10 正则匹配（必考 DP）

**题意**：`s` 与模式 `p` 匹配，`.` 匹配任意单字符，`*` 让前一个字符出现 0 次或多次。

**状态定义**：`dp[i][j]` = s 的前 i 个字符与 p 的前 j 个字符**是否匹配**（布尔型状态机）。

**转移**（分 p[j-1] 是不是 `*`）：

```
p[j-1] != '*'：dp[i][j] = dp[i-1][j-1] && (s[i-1]==p[j-1] || p[j-1]=='.')
p[j-1] == '*'：
    ├─ 匹配 0 次：dp[i][j] = dp[i][j-2]            ← a* 整体跳过
    └─ 匹配 ≥1 次：dp[i][j] = dp[i-1][j] && (s[i-1]==p[j-2] || p[j-2]=='.')
                  （消掉 s 的一个字符，模式不动 = * 再吃一个）
```

```java
static boolean isMatch(String s, String p) {
    int m = s.length(), n = p.length();
    boolean[][] dp = new boolean[m + 1][n + 1];
    dp[0][0] = true;                              // 空串匹配空模式
    for (int j = 2; j <= n; j++)                  // ★ 初始化：a*b*c* 可匹配空串
        if (p.charAt(j - 1) == '*') dp[0][j] = dp[0][j - 2];
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++) {
            char pc = p.charAt(j - 1);
            if (pc == '*') {
                dp[i][j] = dp[i][j - 2]           // * 匹配 0 次
                        || (dp[i - 1][j] && match(s.charAt(i - 1), p.charAt(j - 2)));
            } else {
                dp[i][j] = dp[i - 1][j - 1] && match(s.charAt(i - 1), pc);
            }
        }
    return dp[m][n];
}
static boolean match(char a, char b) { return b == '.' || a == b; }
```

- 复杂度 \(O(mn)\)；**初始化第一行**（空 s vs `a*b*` 型模式）是最高频错误点。
- 变体 [44. 通配符匹配]（`*` 任意序列、`?` 单字符）同框架，转移更简单（`*` 不依赖前一字符）。

## 三、思想层：正则 = 有限状态自动机

```
 模式 "ab*c" 对应的 NFA（不确定有限状态机）：

   (q0) --a--> (q1) --b--> (q1)   ← b* 自环：吃任意多个 b
                  └--c--> ((q2)) 接受态

 引擎匹配 = 从初始态出发，每读一个字符沿边走，读完后停在接受态即匹配
 NFA：同一字符多条可走边 → 回溯；DFA：一条 → 线性
```

- **`*` 的本质是「自环边」**——和 [状态机.md](状态机.md) 的转移图完全同构，把 DP 表展开就是自动机。
- 工程谈资：Java `Pattern` 是 NFA 回溯实现（功能全但有 ReDoS 风险）；RE2/Google DFA 实现线性时间（无回溯）；Thompson 构造法把 NFA 转 DFA。
- 词法分析器（编译原理）、`grep`、路由匹配，底层都是这套状态机。

## 四、易错点 ⚠️

| 易错点 | 澄清 |
|:---|:---|
| **漏初始化 `dp[0][j]`** | s 为空时 `a*b*c*` 仍匹配（全取 0 次）：`dp[0][j] = dp[0][j-2] && p[j-1]=='*'` |
| **`*` 转移只写「吃一个」** | 必须同时保留「匹配 0 次」分支 `dp[i][j-2]`，否则 `mis*` 匹配不上 `mi` |
| **`.*` 当 `.*?` 用** | 贪婪匹配吃光再回吐，性能差且结果常不如预期；提取内容用懒惰 `.*?` |
| **split 未转义元字符** | `split(".")` 得空数组；`\\.`、`\\|`、`\\\\` 记牢 |
| **Pattern 每次重新编译** | 循环里 `str.matches(...)` 每次编译；提为 `static final Pattern` 复用 |
| **嵌套量词 ReDoS** | `(a+)+$` 这类模式在恶意输入上指数回溯；安全敏感场景用 RE2 风格引擎 |

## 五、一句话总结

正则三层：**API 记转义与贪婪（split 转义、`.*?` 懒惰、Pattern 复用），算法题记 `dp[i][j]` 布尔状态机（`*` = 0 次分支 + 吃一个分支，初始化空串行），思想层记正则=带自环的有限状态自动机**——和状态机 DP、NFA/DFA 一脉贯通，讲出自动机视角就是面试加分点。
