# 矩阵（二维数组）技巧

二维数组题考三类：**边界遍历（螺旋/对角线）、原地变换（旋转/转置/置零）、网格搜索（退化成图论）**。核心心法：**行下标 i、列下标 j 的语义先想清楚，再动手**。

---

## 一、遍历系：螺旋与对角线

### 1.1 四边界收缩法（螺旋矩阵标准解）

```java
// 按 右→下→左→上 顺序走，每走完一条边收缩对应边界（详见 循环.md）
static List<Integer> spiralOrder(int[][] mat) {
    List<Integer> ans = new ArrayList<>();
    int l = 0, r = mat[0].length - 1, t = 0, b = mat.length - 1;
    while (l <= r && t <= b) {
        for (int j = l; j <= r; j++) ans.add(mat[t][j]);               // 上行 →
        for (int i = ++t; i <= b; i++) ans.add(mat[i][r]);             // 右列 ↓
        if (t <= b) for (int j = --r; j >= l; j--) ans.add(mat[b][j]); // 下行 ←
        if (l <= r) for (int i = --b; i >= t; i--) ans.add(mat[i][l]); // 左列 ↑
        l++;
    }
    return ans;
}
// 两个 if 是防止单行/单列矩阵重复访问的关键
```

### 1.2 矩阵坐标速查

| 概念 | 坐标变换 |
|:---|:---|
| 主对角线 | `i == j` |
| 副对角线 | `i + j == n - 1` |
| 转置 | `(i,j) ↔ (j,i)`，沿主对角线交换 |
| 旋转 90°（顺时针） | 先**转置**再**每行左右反转** |
| 旋转 90°（逆时针） | 先转置再**每列上下反转** |
| 上下翻转 | 行序反转 |
| 中心对称（180°） | 转置 + 上下翻转 |

```java
// 顺时针旋转 90°：转置 + 行反转，原地 O(1)
static void rotate(int[][] mat) {
    int n = mat.length;
    for (int i = 0; i < n; i++)                    // ① 转置（沿主对角线）
        for (int j = i + 1; j < n; j++)            // ★ j 从 i+1 起，只走上三角防交换两次
            { int t = mat[i][j]; mat[i][j] = mat[j][i]; mat[j][i] = t; }
    for (int[] row : mat)                          // ② 每行左右反转
        for (int l = 0, r = n - 1; l < r; l++, r--)
            { int t = row[l]; row[l] = row[r]; row[r] = t; }
}
```

> 对角线遍历、[48. 旋转图像](../leetcode-hot100/48.%20旋转图像.md)、[54. 螺旋矩阵] 全是上表变换的组合，先在纸上画 3×3 坐标图再写代码。

## 二、原地标记系：置零与状态编码

```java
// 矩阵置零 O(1) 空间：用第一行/第一列当标记位
static void setZeroes(int[][] mat) {
    int m = mat.length, n = mat[0].length;
    boolean firstRow = false, firstCol = false;
    for (int j = 0; j < n; j++) if (mat[0][j] == 0) firstRow = true;  // 第一行自己有 0
    for (int i = 0; i < m; i++) if (mat[i][0] == 0) firstCol = true;
    for (int i = 1; i < m; i++)            // 用第一行/列记录"该行/列要清零"
        for (int j = 1; j < n; j++)
            if (mat[i][j] == 0) { mat[i][0] = 0; mat[0][j] = 0; }
    for (int i = 1; i < m; i++)            // 按标记清零内部
        for (int j = 1; j < n; j++)
            if (mat[i][0] == 0 || mat[0][j] == 0) mat[i][j] = 0;
    if (firstRow) for (int j = 0; j < n; j++) mat[0][j] = 0;  // 最后处理第一行/列
    if (firstCol) for (int i = 0; i < m; i++) mat[i][0] = 0;
}
```

> 标记位法的顺序敏感点：**第一行/列必须最后处理**（它们身兼标记与数据两职，先清会把标记毁掉）。

## 三、网格搜索系：矩阵当图

| 问题 | 思想 | 归属笔记 |
|:---|:---|:---|
| 岛屿数量/最大岛屿 | 网格 DFS 感染 / BFS | [DFS搜索.md](DFS搜索.md)、[BFS搜索.md](BFS搜索.md) |
| 最短路径（无权） | BFS 按层 | [BFS搜索.md](BFS搜索.md) |
| 最小路径和 | **网格 DP**：`dp[i][j] = min(上,左) + grid[i][j]` | [1.动态规划.md](1.动态规划.md)、[64. 最小路径和](../leetcode-hot100/64.%20最小路径和.md) |
| 最大正方形 | `dp[i][j] = min(三邻居) + 1`（正方形受最短板限制） | [221. 最大正方形](../leetcode-hot100/221.%20最大正方形.md) |
| 单调栈上矩形 | 逐行.histogram + 单调栈 | [85. 最大矩形](../leetcode-hot100/85.%20最大矩形.md)、[单调栈.md](单调栈.md) |
| 有序矩阵查找 | **右上角起步**：大于往左、小于往下，O(m+n) | [240. 搜索二维矩阵 II](../leetcode-hot100/240.%20搜索二维矩阵%20II.md) |

```java
// 有序矩阵（行升序、列升序）查找：从右上角出发的"淘汰"走法
static boolean searchMatrix(int[][] mat, int target) {
    int i = 0, j = mat[0].length - 1;          // 右上角：本行最大、本列最小
    while (i < mat.length && j >= 0) {
        if (mat[i][j] == target) return true;
        else if (mat[i][j] > target) j--;      // 当前值偏大 → 排除本列（下方只会更大）
        else i++;                              // 当前值偏小 → 排除本行（左侧只会更小）
    }
    return false;
}
```

> 右上角起步的本质：每次比较**排除一整行或一整列**（类似 BST 单点查找），是二维降一维的关键技巧。

## 四、易错点 ⚠️

| 易错点 | 澄清 |
|:---|:---|
| **行数列数搞反** | `mat.length` 是行 m，`mat[0].length` 是列 n；非方阵旋转/转置要开新矩阵 |
| **转置时双重循环全遍历** | `(i,j)` 与 `(j,i)` 交换两次等于没换；内层 `j` 从 `i+1` 起只走上三角 |
| **螺旋边界收缩时机** | `++t/--r/--b` 与 if 判断的顺序在纸上手推 3×3，别凭感觉 |
| **置零先清第一行/列** | 第一行/列是标记位，必须最后清；否则标记丢失全错 |
| **旋转方向搞反** | 顺时针=转置+行反转；逆时针=转置+列反转——写前先验证一个角元素 |
| **网格 DP 状态依赖方向** | 「只能向右/下」才能按行遍历；可四方向移动就是图搜索不是 DP |
| **锯齿数组假设全行等长** | Java 二维数组每行长度可不同；`mat[i].length` 按行取 |

---

## 五、一句话总结

矩阵题 = **坐标语义（旋转/转置/对角线公式表背下来） + 原地标记（第一行列当标记要最后处理） + 网格当图（BFS/DFS/网格 DP 三选一）**；有序矩阵先想「右上角淘汰法」，螺旋旋转先画 3×3 手推坐标再落键——二维降维的一切技巧都源于「每次比较排除一行或一列」。
