# 进制转换思想

OD 机试高频、面试基础题。核心就两个方向：**十进制 → 其他进制（除基取余倒排）**、**其他进制 → 十进制（按位权展开）**，以及工程坑：**负数/补码、大数、字母表示（16 进制 a-f）**。

---

## 一、两大基本模型

```
 十进制 13 → 二进制          二进制 1101 → 十进制
 13 ÷ 2 = 6 … 1  ┐           1×2³ + 1×2² + 0×2¹ + 1×2⁰
  6 ÷ 2 = 3 … 0  │ 余数倒排      = 8 + 4 + 0 + 1 = 13
  3 ÷ 2 = 1 … 1  │ = 1101
  1 ÷ 2 = 0 … 1  ┘
```

```java
// ============ 模型一：十进制 → k 进制（除基取余，余数倒排）============
static String toBase(int num, int base) {          // base: 2~16
    if (num == 0) return "0";
    char[] digits = "0123456789abcdef".toCharArray(); // 超过 10 用字母
    StringBuilder sb = new StringBuilder();
    boolean neg = num < 0;
    long n = num;                                   // ★ 负数转 long 处理，防 Integer.MIN_VALUE 溢出
    if (neg) n = -n;
    while (n > 0) {
        sb.append(digits[(int)(n % base)]);         // 取余得到当前最低位
        n /= base;                                  // 除基缩小
    }
    if (neg) sb.append('-');
    return sb.reverse().toString();                 // 余数是低位在前 → 倒排
}

// ============ 模型二：k 进制 → 十进制（按位权展开 / 滚动乘基）============
static long fromBase(String s, int base) {
    long res = 0;
    for (char c : s.toCharArray()) {
        int d = Character.isDigit(c) ? c - '0' : Character.toLowerCase(c) - 'a' + 10;
        if (d < 0 || d >= base) throw new IllegalArgumentException("非法字符: " + c);
        res = res * base + d;                       // ★ 滚动：高位结果×基 + 当前位
    }
    return res;
}
```

> `res = res * base + d` 是「按位权展开」的滚动形式：每次把已有结果整体左移一位（乘 base）再放新位——和「字符串转数字 `num*10+c`」同一个模子。

## 二、Java 自带工具（工程首选）

| API | 用途 | 注意 |
|:---|:---|:---|
| `Integer.toBinaryString(n)` | → 2 进制 | 负数输出**32 位补码**（无符号） |
| `Integer.toHexString/octalString(n)` | → 16/8 进制 | 同上，负数是补码形式 |
| `Integer.toString(n, radix)` | → 任意进制（2~36） | 负数带 `-` 号，非补码 |
| `Integer.parseInt(s, radix)` | 任意进制 → int | 非法字符抛 `NumberFormatException` |
| `Long.toBinaryString(n)` | long 版 | 大数用 long 系 |

```java
// 位运算取每一位（不转字符串，刷题更常用）
while (n != 0) {
    int bit = n & 1;        // 取最低位（等价 n % 2，但负数语义正确）
    n >>>= 1;               // ★ 无符号右移；>> 对负数会补 1 死循环
}
```

## 三、负数与补码（面试追问点）

- 计算机内整数用**补码**存储：`-1` 的 32 位二进制是 32 个 1。
- `Integer.toBinaryString(-5)` 输出的是**补码**（111...1011），不是「-101」；`Integer.toString(-5, 2)` 才输出 `-101`——两个 API 语义不同，面试说清楚是加分项。
- 位运算技巧族（异或找唯一、`n & (n-1)` 消最低位 1、 lowbit）见 [位运算.md](位运算.md)。

## 四、高频题型速查

| 题型 | 骨架 |
|:---|:---|
| 十进制转 k 进制 | 除基取余 + 倒排（模板一） |
| k 进制转十进制 | 滚动乘基（模板二） |
| **大数进制转换**（超 long） | 用字符串模拟除法/乘法：逐位「商×基+余」；或 BigInteger |
| k 进制加法 | 对齐末尾逐位相加 + 进位（`sum = a + b + carry; carry = sum / k`）——与大数加法同模 |
| 回文数/反转 | 转字符串或纯数学反转（`rev = rev*base + n%base`） |
| 7 进制/负进制 | 除基取余通用；**负进制**（如 -2）余数需调整为非负：`r = ((n % k) + k) % k; n = (n - r) / k` |

```java
// 大数除以 base（字符串模拟）：从高位往低位，余数往下带
static String bigDiv(String s, int base) {
    StringBuilder sb = new StringBuilder();
    long rem = 0;
    for (char c : s.toCharArray()) {
        long cur = rem * 10 + (c - '0');   // 上轮余数×10 + 当前位
        sb.append(cur / base);             // 本位商
        rem = cur % base;                  // 余数传给下一位
    }
    int i = 0; while (i < sb.length() - 1 && sb.charAt(i) == '0') i++; // 去前导零
    return sb.substring(i);
}
```

## 五、易错点 ⚠️

| 易错点 | 澄清 |
|:---|:---|
| **`Integer.MIN_VALUE` 取负溢出** | `-(-2147483648)` 还是它自己；先转 `long` 再处理 |
| **负数用 `>>` 右移求位** | `>>` 补符号位死循环；求位用 `>>>`（无符号右移）或 `n & 1` |
| **余数顺序忘了倒排** | 除基取余先得低位；`StringBuilder` 收集后必须 `reverse()` |
| **16 进制字符映射错** | `a~f` 对应 10~15：`c - 'a' + 10`；注意大小写统一 `toLowerCase` |
| **0 的特判** | `while (n > 0)` 循环对 n=0 直接跳过，输出空串——开头 `if (n == 0) return "0"` |
| **负进制直接取余** | Java `%` 结果可能是负数；负进制用 `r = ((n % k) + k) % k` 归一化 |
| **大数硬转 long** | 超 \(10^{18}\) 必须字符串模拟或 BigInteger |

---

## 六、一句话总结

进制转换两个模子打天下：**转出 = 除基取余倒排（注意 0 特判与负数 long 化），转入 = 滚动乘基 `res = res*base + d`**；进阶三件套 = 负数补码语义（`>>>` vs `>>`）、负进制余数归一化、大数字符串模拟——工程里直接 `Integer.toString(n, radix)` 一行解决，面试里要能白板写对。
