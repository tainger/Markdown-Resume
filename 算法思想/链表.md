# 链表的算法题套路

链表结构与实现细节见 [../数据结构/链表.md](../数据结构/链表.md)。链表题考点高度集中：**指针操作不丢链、快慢指针、反转系、合并系**——先记住「虚拟头节点 + 画图」两个保命习惯，再背四个模板。

## 一、保命习惯：虚拟头节点 + 画图

```java
// 头节点可能被删/被换时，一律上虚拟头节点，消除"头节点特判"
ListNode dummy = new ListNode(0, head);
// ...操作 dummy.next...
return dummy.next;
```

- 画图：每一步操作前画出 prev/cur/next 三个指针的指向，**先改谁后改谁**（防丢链）一眼看清；
- 判空链表：`dummy` 让空链表、单节点与其他情况走同一逻辑。

## 二、反转系（最高频，必背）

```java
// ① 全链反转：三指针迭代，O(n) O(1)
static ListNode reverse(ListNode head) {
    ListNode prev = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next;   // 先存后继
        cur.next = prev;            // 反转当前
        prev = cur; cur = next;     // 双指针右移
    }
    return prev;
}

// ② 区间反转 [m, n]：走到 m 前驱，头插法反转区间内节点
static ListNode reverseBetween(ListNode head, int m, int n) {
    ListNode dummy = new ListNode(0, head), pre = dummy;
    for (int i = 1; i < m; i++) pre = pre.next;   // pre = m 的前驱
    ListNode cur = pre.next;
    for (int i = 0; i < n - m; i++) {             // 每次"摘下 cur.next 头插到 pre 后"
        ListNode removed = cur.next;
        cur.next = removed.next;
        removed.next = pre.next;
        pre.next = removed;
    }
    return dummy.next;
}

// ③ K 个一组反转：数够 K 个 → 反转这组 → 递归/迭代接下一组（hard 常客）
```

> 反转后找中点/判回文/重排（取中→反转后半→交错合并三连）全由 ① 组合而成，见 [206. 反转链表](../leetcode-hot100/206.%20反转链表.md)、[234. 回文链表](../leetcode-hot100/234.%20回文链表.md)。

## 三、快慢指针（链表的"双指针"）

| 问题 | 写法 | 细节 |
|:---|:---|:---|
| 找中点 | fast 每次 2 步、slow 1 步 | 偶数长度返回**后半段头**（`while (fast != null && fast.next != null)` 返回中点偏左） |
| 判环 | 快慢相遇即有环 | 相遇后一个回 head，同速走到再相遇 = **环入口**（Floyd 数学） |
| 倒数第 k 个 | fast 先走 k 步，再同速 | fast 到尾时 slow 在倒数第 k；配合 dummy 处理删头，[19. 删除倒数第 N 个](../leetcode-hot100/19.%20删除链表的倒数第%20N%20个结点.md) |
| 判相交 | 两链表接起来走 | a→c→b 与 b→c→a 在相交点相遇，[160. 相交链表](../leetcode-hot100/160.%20相交链表.md) |
| 判回文 | 中点 + 反转后半 | [234. 回文链表](../leetcode-hot100/234.%20回文链表.md) |
| 循环检测（数组） | `i = nums[i]` 当 next 指针 | [287. 寻找重复数](../leetcode-hot100/287.%20寻找重复数.md)、快乐数 |

## 四、合并系与删除系

```java
// 21 合并两个有序链表：dummy + 尾插比较（O(m+n)）
static ListNode merge(ListNode a, ListNode b) {
    ListNode dummy = new ListNode(0), tail = dummy;
    while (a != null && b != null) {
        if (a.val <= b.val) { tail.next = a; a = a.next; }
        else                { tail.next = b; b = b.next; }
        tail = tail.next;
    }
    tail.next = (a != null) ? a : b;    // ★ 直接挂剩余整段
    return dummy.next;
}
// 23 合并 K 个：小顶堆装 K 个头节点（见 队列.md）或两两分治合并
```

- 删除节点：**找前驱**（dummy 起）而非找目标本身；快慢指针版一次遍历（[19](../leetcode-hot100/19.%20删除链表的倒数第%20N%20个结点.md)）。
- 成对交换/重排：**先存后继再改 next**，每步画图验证。

## 五、易错点

| 易错点 | 澄清 |
|:---|:---|
| **改 next 顺序错丢链** | 先保存 `cur.next` 再改指向；每步画图核对 prev/cur/next |
| **头节点被删/换没特判** | 虚拟头节点 dummy 统一处理，返回 `dummy.next` |
| **快慢指针 fast 跳两步判空不全** | `fast != null && fast.next != null` 两个条件缺一不可 |
| **合并时逐个节点挂剩余段** | 尾部剩余直接 `tail.next = a/b` 整段挂，不用循环 |
| **找中点偶数长度语义不清** | 约定并注释：返回前半尾还是后半头；回文题反转「后半段」 |
| **递归解链表忘深度** | 链长 10^5 递归爆栈；反转等一律迭代写法 |
| **比较用 `==`** | 节点相等比引用 `a == b`（对象比较没问题），但值比较要用 `a.val == b.val` 分清需求 |

## 六、一句话总结

链表题 = **dummy 头节点消特判 + 画图防丢链 + 四个模板（三指针反转、快慢指针五连用、dummy 合并、前驱删除）**；「环的入口、倒数第 k、中点」全靠快慢指针的间距差，记住间距含义就能现场推导。
