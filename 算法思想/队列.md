# 队列的算法题套路

队列的结构与实现细节见 [../数据结构/队列.md](../数据结构/队列.md)。本篇讲**算法题中队列的三个固定套路**：BFS 层序、单调队列、优先队列，以及双端队列的桥接作用。

## 一、三大套路速查

| 套路 | 队列形态 | 信号词 | 代表 |
|:---|:---|:---|:---|
| **BFS / 层序** | 普通队列 + 按层截断 | 最少步数、逐层、扩散 | [BFS搜索.md](BFS搜索.md)、[200. 岛屿数量](../leetcode-hot100/200.%20岛屿数量.md) |
| **单调队列** | 双端队列存**下标**，队头恒为最值 | 滑动窗口最大/最小值 | [单调队列.md](单调队列.md)、[239. 滑动窗口最大值] |
| **优先队列（堆）** | `PriorityQueue` 按比较器出队 | TopK、第 K 大、合并 k 路 | [347. 前 K 个高频元素](../leetcode-hot100/347.%20前%20K%20个高频元素.md)、[23. 合并 K 个升序链表](../leetcode-hot100/23.%20合并%20K%20个升序链表.md) |

## 二、BFS：队列 + 按层截断（骨架）

```java
// 队列的 FIFO 性质天然保证"先处理近的、后处理远的"——这就是 BFS 最短性的来源
Deque<int[]> queue = new ArrayDeque<>();
queue.offer(start);
visited[start] = true;                 // 入队即标记（铁律）
while (!queue.isEmpty()) {
    int size = queue.size();           // ★ 固定本层元素数（队列边出边进）
    for (int s = 0; s < size; s++) {
        int[] cur = queue.poll();
        for (int next : neighbors(cur))
            if (!visited[next]) { visited[next] = true; queue.offer(next); }
    }
    step++;                            // 每处理完一层步数 +1
}
```

## 三、单调队列与双端队列（队列的两端各司其职）

```java
// 滑动窗口最大值：队头恒为当前窗口最大值的下标
Deque<Integer> dq = new ArrayDeque<>(); // 存下标，对应值从队头到队尾递减
for (int i = 0; i < nums.length; i++) {
    if (!dq.isEmpty() && dq.peekFirst() <= i - k) dq.pollFirst(); // 队头过期出窗
    while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i])
        dq.pollLast();                                            // 队尾比新值小 → 永无出头之日
    dq.offerLast(i);
    if (i >= k - 1) ans.add(nums[dq.peekFirst()]);               // 队头即窗口最大值
}
```

- **队头管「过期」（出窗判断），队尾管「单调」（小元素弹出）**——双端队列的价值就是两端操作分工。
- 与单调栈对照：单调栈「淘汰左边」，单调队列「淘汰左边 + 队头受窗口约束」，见 [单调队列.md](单调队列.md)。

## 四、优先队列：带权重的队列

```java
// TopK（前 K 个高频）：小顶堆维护 K 个最值，O(n log k)
PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[1] - b[1]); // [值, 频次]
for (var e : cnt.entrySet()) {
    heap.offer(new int[]{e.getKey(), e.getValue()});
    if (heap.size() > k) heap.poll();          // 超过 K 弹最小频次
}
// Java 细节：默认小顶堆；大顶堆用 (a, b) -> b - a（防溢出用 compare）；
// 自定义对象实现 Comparable 或传 Comparator（见 leetcode-hot100/0.java中集合总结）
```

| 场景 | 堆型 | 原因 |
|:---|:---|:---|
| 求第 K 大 / 前 K 大 | **小顶堆**（大小 K） | 堆顶是 K 个里最小的，随时可被更大的替换 |
| 求第 K 小 / 前 K 小 | 大顶堆 | 对称 |
| 合并 K 个有序流 | 小顶堆装 K 个队首 | 每次弹全局最小，补进该流下一个 |

## 五、易错点

| 易错点 | 澄清 |
|:---|:---|
| **BFS 出队时才标记 visited** | 重复入队导致队列爆炸；入队时标记（见 [BFS搜索.md](BFS搜索.md)） |
| **按层截断忘了先取 size** | `queue.size()` 在循环内动态变化，必须先存局部变量 |
| **单调队列存值不存下标** | 判断队头「是否过期出窗」需要下标与 i 比较 |
| **PriorityQueue 当队列用** | 它出队按**优先级**不按先后；要先后顺序用 `ArrayDeque`/`LinkedList` |
| **大顶堆比较器写反/溢出** | `(a,b) -> b[1] - a[1]` 频次极大时减法溢出，用 `Integer.compare` |
| **堆解 TopK 全量入堆** | n 个全入是 O(n log n)；维护 K 大小堆才 O(n log k) |

## 六、一句话总结

队列三件套按「出队顺序」选：**FIFO 保序 → 普通队列（BFS 层序，入队即标记 + size 截断）；两端分工 → 双端队列（单调队列，队头过期/队尾保单调）；按权重出队 → 优先队列（TopK 小顶堆 K 大小）**——「谁先出队」这个问题的答案就是选型答案。
