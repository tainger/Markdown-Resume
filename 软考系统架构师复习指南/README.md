## 三科备考策略

### 综合知识（选择题 75 道）

- **前 25 题**：计算机基础 + 操作系统 + 计算机网络（基础分，必拿）
- **中 30 题**：软件工程 + 数据库 + 信息安全 + 系统架构（拉开差距的关键）
- **后 20 题**：项目管理 + 数学经济 + 嵌入式 + 数据通信 + 英语
- **答题技巧**：排除法 > 关键词匹配 > 蒙题（三长一短选短、两短两长选长仅作最后手段）

### 案例分析（3 道大题）

- **必考题 1**：架构设计题（给场景描述 → 选架构风格 + 画架构图 + 说明理由）
- **必考题 2**：数据库/系统分析题（ER 图 + 范式判断 + 优化方案）
- **选考题 3**：嵌入式 / 实时系统 / 安全（三选一）
- **答题套路**：先写结论 → 再写理由（分点）→ 最后画图表（UML 图、架构图、流程图）

### 论文（1 篇，2 小时）

- **题型**：给出 4 个题目方向，任选 1 篇，2000~2500 字
- **高频方向**：软件架构设计、微服务架构、高可用系统、数据架构、安全架构
- **写作模板**：
  1. 项目背景（300 字）：公司业务、系统规模、你的角色
  2. 问题与挑战（400 字）：3~5 个技术难点
  3. 架构设计与方案（1000 字，核心）：总体架构 + 关键决策 + 技术选型对比
  4. 实施与效果（400 字）：落地过程 + 量化指标
  5. 总结与展望（200 字）：经验教训 + 未来优化方向
- **关键**：结合真实项目（EasyBI / AgentMate / APASS），用具体数据说话，避免空泛

## 高频考点速查（综合知识 75 道必背）

### 系统架构设计

- **架构风格分类**：
  - 数据流风格：批处理、管道-过滤器
  - 调用-返回风格：主程序-子程序、面向对象、分层
  - 独立构件风格：进程通信、事件驱动（隐式调用）
  - 虚拟机风格：解释器、规则系统
  - 仓库风格：数据库系统、超文本系统、黑板系统
- **微服务 vs SOA**：微服务去中心化、独立部署、轻量通信（REST/gRPC）；SOA 重 ESB、服务编排、企业级总线
- **架构评估方法**：ATAM（属性驱动，多决策对比）> SAAM（场景驱动，单方案评价）> ARID（活动审查）
- **4+1 视图模型**：逻辑视图、开发视图、进程视图、物理视图 + 场景（用例）

### 软件工程

- **敏捷宣言 4 价值观**：个体交互 > 流程工具、可工作软件 > 详尽文档、客户协作 > 合同谈判、响应变化 > 遵循计划
- **CMMI 5 级**：初始级 → 已管理级 → 已定义级 → 量化管理级 → 优化级
- **UML 图**：结构（类/对象/组件/部署/包）+ 行为（用例/顺序/通信/状态/活动）
- **设计模式 3 类 23 种**：创建型（5）、结构型（7）、行为型（11）

### 数据库系统

- **范式**：1NF（原子性）→ 2NF（消除部分依赖）→ 3NF（消除传递依赖）→ BCNF
- **CAP 定理**：一致性 / 可用性 / 分区容错性，三选二
- **BASE 理论**：基本可用 + 软状态 + 最终一致性
- **分布式数据库分片**：水平分片 / 垂直分片 / 混合分片

### 操作系统

- **进程 vs 线程**：进程是资源分配单位，线程是 CPU 调度单位
- **IO 模型**：阻塞 IO → 非阻塞 IO → IO 多路复用（select/poll/epoll）→ 信号驱动 IO → 异步 IO
- **页面置换算法**：最佳置换（OPT）> 最近最少使用（LRU）> 先进先出（FIFO，有 Belady 异常）

### 信息安全

- **对称加密**：DES（56位）、3DES、AES（128/192/256位）、SM4
- **非对称加密**：RSA、ECC、SM2
- **哈希算法**：MD5（128位，已不安全）、SHA-256、SM3
- **数字签名**：发送方用私钥加密摘要 → 接收方用公钥验证

### 项目管理

- **挣值分析**：
  - PV（计划值）、EV（挣值）、AC（实际成本）
  - CV = EV - AC（成本偏差）、SV = EV - PV（进度偏差）
  - CPI = EV/AC（成本绩效）、SPI = EV/PV（进度绩效）
  - CPI < 1 超支、SPI < 1 滞后
