# 嵌入式系统

> 综合知识占比约 5%，案例分析选考方向之一。

---

## 一、嵌入式系统概述

### 1.1 定义

嵌入式系统是"以应用为中心、以计算机技术为基础、软硬件可裁剪、适应应用系统对功能、可靠性、成本、体积、功耗严格要求的专用计算机系统"。

### 1.2 特点

- 专用性强
- 实时性要求高
- 资源受限（CPU/内存/功耗）
- 可靠性要求高
- 低功耗

### 1.3 分类

| 维度 | 类型 |
|:---|:---|
| 实时性 | 强实时、弱实时 |
| 复杂度 | 单功能（微波炉）、多功能（智能手机） |
| 开发方式 | 裸机、RTOS、嵌入式 Linux |

## 二、嵌入式硬件

### 2.1 处理器

| 类型 | 特点 | 应用 |
|:---|:---|:---|
| MCU（微控制器） | 片上集成 RAM/ROM/外设，简单 | 传感器、家电 |
| MPU（微处理器） | 需外接内存，功能强 | 路由器、平板 |
| DSP | 数字信号处理优化 | 音视频、通信 |
| SoC | 单芯片集成多个核 | 智能手机 |

### 2.2 存储

| 类型 | 特点 | 用途 |
|:---|:---|:---|
| Flash | 非易失、可擦写 | 固件存储（NOR/NAND） |
| SRAM | 高速、需刷新 | Cache |
| DRAM | 密度高、需刷新 | 主存 |
| EEPROM | 可字节擦写 | 参数存储 |

## 三、实时系统（RTOS）

### 3.1 实时系统 vs 通用系统

| 维度 | 实时系统 | 通用系统 |
|:---|:---|:---|
| 目标 | 确定性 + 及时性 | 吞吐量 |
| 调度 | 抢占式、优先级驱动 | 时间片、公平 |
| 响应 | 硬截止时间 | 尽量快 |

### 3.2 实时调度算法

| 算法 | 说明 |
|:---|:---|
| RMS（速率单调调度） | 周期短的任务优先级高，静态优先级 |
| EDF（最早截止时间优先） | 截止时间近的优先级高，动态优先级 |
| LLF（最低松弛度优先） | 松弛度 = 截止时间 - 当前时间 - 执行时间 |

### 3.3 RTOS 核心

- 任务管理（创建、删除、挂起、恢复）
- 调度器（抢占式优先级）
- 同步互斥（信号量、互斥锁、消息队列）
- 内存管理（固定分区、动态分区）
- 时钟管理（节拍、定时器）

## 四、嵌入式软件架构

### 4.1 前后台系统

```
后台：主循环轮询处理任务
前台：中断处理紧急事件
```

- **优点**：简单
- **缺点**：实时性差、任务切换不灵活

### 4.2 时间片轮转

- 每个任务分配固定时间片
- 适合任务复杂度相近的场景

### 4.3 优先级抢占式

- 高优先级任务可抢占低优先级
- 适合实时系统
- **注意**：优先级反转问题（低优先级持有锁，高优先级等待中优先级抢占）
- **解决**：优先级继承协议

### 4.4 分层架构

```
应用层
抽象层（HAL/BSP）
驱动层
硬件层
```

## 五、嵌入式开发流程

```
需求分析 → 硬件设计 → 软件设计 → 编码 → 仿真/调试 → 烧录 → 测试 → 部署
```

- **工具链**：交叉编译器（ARM GCC）、调试器（JTAG）、烧录器
- **调试手段**：仿真器、日志、示波器、逻辑分析仪
