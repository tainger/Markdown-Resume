## 一、进程与线程

### 1.1 进程 vs 线程

| 维度 | 进程 | 线程 |
|:---|:---|:---|
| 定义 | 资源分配单位 | CPU 调度单位 |
| 资源 | 独立地址空间、文件句柄等 | 共享进程资源 |
| 开销 | 创建/切换开销大 | 轻量、切换快 |
| 通信 | IPC（管道/消息队列/共享内存/信号量） | 直接读写共享变量（需同步） |

### 1.2 进程状态转换

```
        创建
          ↓
        就绪 ←──────────┐
          ↓  时间片到    │
        运行 ───────────┘
          ↓  I/O 请求
        阻塞 ── I/O 完成 → 就绪
          ↓  退出
        终止
```

### 1.3 进程调度算法

| 算法 | 说明 | 适用场景 |
|:---|:---|:---|
| FCFS | 先来先服务 | 简单、非抢占 |
| SJF | 短作业优先 | 平均等待时间短，可能饿死长作业 |
| 高优先级 | 优先级调度 | 紧急任务优先 |
| 时间片轮转 | 公平分配时间片 | 分时系统 |
| 多级反馈队列 | 多队列 + 动态调整 | 通用 |

## 二、内存管理

### 2.1 分页 vs 分段 vs 段页式

| 维度 | 分页 | 分段 | 段页式 |
|:---|:---|:---|:---|
| 划分依据 | 固定大小（页） | 逻辑段（代码/数据） | 先分段再分页 |
| 地址 | 一维 | 二维（段号+段内偏移） | 二维（段号+页号+页内偏移） |
| 碎片 | 页内碎片（小） | 外部碎片 | 页内碎片 |
| 共享 | 不便 | 便于共享 | 便于共享 |
| 保护 | 弱 | 强（段属性） | 强 |

### 2.2 虚拟内存

- **原理**：程序部分装入内存即可运行，其余放磁盘，需要时换入
- **核心**：局部性原理（时间局部性 + 空间局部性）
- **缺页中断**：访问的页不在内存 → 换入

### 2.3 页面置换算法（必考）

| 算法 | 策略 | 性能 | Belady 异常 |
|:---|:---|:---|:---|
| OPT（最佳置换） | 置换未来最长时间不用的页 | 最优 | 无 |
| LRU（最近最少使用） | 置换最久未访问的页 | 好 | 无 |
| LFU（最不经常使用） | 置换访问次数最少的页 | 较好 | 无 |
| FIFO（先进先出） | 置换最早进入的页 | 差 | 有（页数增加反而缺页增多） |

> **Belady 异常**：FIFO 特有，分配的物理页数增加，缺页次数反而增加。

## 三、IO 模型（高频）

### 3.1 五种 IO 模型

```
1. 阻塞 IO（BIO）：线程等数据准备好 → 线程被挂起
2. 非阻塞 IO（NIO）：轮询数据是否就绪 → 线程可返回做其他事
3. IO 多路复用（select/poll/epoll）：一个线程管多个 fd，数据就绪才通知
4. 信号驱动 IO：数据就绪时发 SIGIO 信号
5. 异步 IO（AIO）：内核完成后直接通知应用程序
```

### 3.2 select vs poll vs epoll（必考）

| 维度 | select | poll | epoll |
|:---|:---|:---|:---|
| 连接数 | 1024（FD_SETSIZE） | 无上限 | 无上限 |
| 效率 | O(n) 轮询 | O(n) 轮询 | O(1) 事件通知 |
| fd 拷贝 | 每次都拷贝全量 | 每次都拷贝全量 | 只拷贝就绪 fd |
| 触发模式 | LT | LT | LT / ET |
| 适用场景 | 少量连接 | 中等连接 | 大量高并发连接 |

> 详细见 [`../io/`](../io/)

## 四、文件系统

### 4.1 文件分配方式

| 方式 | 说明 | 优点 | 缺点 |
|:---|:---|:---|:---|
| 连续分配 | 文件占用连续磁盘块 | 顺序访问快 | 外部碎片 |
| 链接分配 | 每个块指向下一个块 | 无外部碎片 | 随机访问慢 |
| 索引分配 | 索引块记录所有块地址 | 支持随机访问 | 索引块开销 |

### 4.2 磁盘调度算法

| 算法 | 策略 | 性能 |
|:---|:---|:---|
| FCFS | 先来先服务 | 一般 |
| SSTF | 最短寻道时间优先 | 好，可能饿死 |
| SCAN（电梯算法） | 沿一个方向到头再回头 | 好、公平 |
| C-SCAN | 单向扫描到头直接回起点 | 更公平 |

## 五、死锁

### 5.1 死锁四个必要条件

1. **互斥**：资源不可共享
2. **请求保持**：持有资源的同时请求新资源
3. **不可剥夺**：资源只能持有者主动释放
4. **循环等待**：存在进程-资源循环等待链

### 5.2 死锁处理

| 策略 | 说明 |
|:---|:---|
| 预防 | 破坏 4 个条件之一（如顺序请求破坏循环等待） |
| 避免 | 银行家算法，动态检查是否安全 |
| 检测与恢复 | 允许死锁发生 → 检测 → 杀进程恢复 |
| 忽略 | 鸵鸟策略，假装没有 |
