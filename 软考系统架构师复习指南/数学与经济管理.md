## 一、运筹学

### 1.1 线性规划

- **三要素**：决策变量、目标函数、约束条件
- **标准形式**：
  - max/min Z = CX
  - s.t. AX ≤ b, X ≥ 0
- **求解**：单纯形法、图解法（两变量）

### 1.2 最短路径

| 算法 | 适用 | 复杂度 |
|:---|:---|:---|
| Dijkstra | 单源最短路径，权值非负 | O(n²) 或 O(E log V) |
| Bellman-Ford | 允许负权 | O(VE) |
| Floyd | 全源最短路径 | O(n³) |

### 1.3 关键路径法（CPM）

- 见 [`项目管理.md`](项目管理.md) 第三节

### 1.4 最大流

- **网络流**：source → sink，边有容量
- **最大流最小割定理**：最大流量 = 最小割容量
- **算法**：Ford-Fulkerson、Edmonds-Karp

### 1.5 排队论

| 模型 | 说明 |
|:---|:---|
| M/M/1 | 泊松到达、指数服务、单服务台 |
| M/M/c | 多服务台 |

- **指标**：
  - Ls = 系统中平均顾客数
  - Lq = 队列中平均顾客数
  - Ws = 系统中平均等待时间
  - Wq = 队列中平均等待时间
  - Little 公式：L = λW

## 二、概率与统计

### 2.1 常见分布

| 分布 | 应用 |
|:---|:---|
| 二项分布 | n 次独立试验成功次数 |
| 泊松分布 | 单位时间内事件发生次数 |
| 正态分布 | 自然现象、测量误差 |
| 指数分布 | 可靠性、排队系统 |

### 2.2 期望与方差

- E(X) = Σ x·P(x)
- D(X) = E(X²) - [E(X)]²

## 三、经济评价

### 3.1 资金时间价值

```
终值 F = P × (1+i)^n
现值 P = F / (1+i)^n
```

### 3.2 经济评价指标

| 指标 | 说明 | 判断 |
|:---|:---|:---|
| 净现值（NPV） | 未来现金流现值 - 初始投资 | NPV > 0 可行 |
| 内部收益率（IRR） | 使 NPV = 0 的折现率 | IRR > 基准收益率可行 |
| 投资回收期 | 收回投资的时间 | 越短越好 |
| 投资回报率（ROI） | 年收益 / 总投资 | 越高越好 |
