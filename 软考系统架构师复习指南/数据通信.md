## 一、数据传输基础

### 1.1 数据 vs 信号

- **数据**：信息的表示形式（数字数据、模拟数据）
- **信号**：数据的物理表现（数字信号、模拟信号）
- **码元**：信号的一个基本单位

### 1.2 带宽与速率

- **带宽**：信道频率范围（Hz）或数据传输能力（bps）
- **波特率**：每秒码元数（Baud）
- **比特率**：每秒比特数（bps）
- **关系**：比特率 = 波特率 × log2(N)，N 为码元状态数

### 1.3 Nyquist 定理

```
最大码元传输速率 = 2W Baud（W 为带宽）

理想信道最大数据速率 = 2W × log2(N) bps
```

### 1.4 Shannon 定理（信噪比）

```
C = W × log2(1 + S/N)

C = 信道容量（bps）
W = 带宽（Hz）
S/N = 信噪比（dB）
```

## 二、数据编码

### 2.1 数字数据 → 数字信号

| 编码 | 特点 |
|:---|:---|
| 不归零码（NRZ） | 高 1 低 0，简单但无时钟 |
| 曼彻斯特编码 | 中间跳变，自带时钟（以太网） |
| 差分曼彻斯特 | 开头有无跳变表示 0/1 |
| 4B/5B | 5 位编码 4 位数据，提高效率 |

### 2.2 数字数据 → 模拟信号

- **ASK**（幅移键控）：幅度变化
- **FSK**（频移键控）：频率变化
- **PSK**（相移键控）：相位变化
- **QAM**：幅度 + 相位组合

## 三、交换方式

| 方式 | 原理 | 优点 | 缺点 |
|:---|:---|:---|:---|
| 电路交换 | 建立专用链路 | 低延迟、独占 | 建立慢、利用率低 |
| 报文交换 | 存储转发整个报文 | 无需建立连接 | 延迟大、对中间节点要求高 |
| 分组交换 | 报文分小分组存储转发 | 延迟小、利用率高 | 分组开销、可能乱序 |

## 四、差错控制

### 4.1 检错码

- **奇偶校验**：1 位校验，检测奇数个错误
- **CRC（循环冗余校验）**：多项式除法，检错能力强
- **海明码**：不仅检错还能纠错

### 4.2 纠错码

- **海明码**：通过校验位定位并纠正单比特错误
- **Turbo 码 / LDPC**：接近 Shannon 极限

### 4.3 ARQ（自动重传请求）

| 方式 | 原理 |
|:---|:---|
| 停止等待 ARQ | 发一个等一个 ACK |
| 回退 N ARQ | 出错回退重发 N 个 |
| 选择重传 ARQ | 只重发出错的 |
