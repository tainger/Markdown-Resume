## 一、计算机组成

### 1.1 冯·诺依曼架构

- 运算器、控制器、存储器、输入设备、输出设备
- 程序和数据以二进制存储
- 存储程序原理：指令按顺序执行

### 1.2 性能评价

| 指标 | 含义 |
|:---|:---|
| MIPS | 每秒百万条指令 |
| MFLOPS | 每秒百万次浮点运算 |
| CPI | 每条指令平均时钟周期数 |
| 响应时间 | 从提交到完成的时间 |
| 吞吐量 | 单位时间完成的任务数 |

### 1.3 Amdahl 定律（必考）

```
加速比 = 1 / [(1 - P) + P/N]

P = 可并行部分比例
N = 并行度

例：90% 可并行，10 核加速比 = 1 / (0.1 + 0.9/10) = 5.26x
```

## 二、存储层次

```
寄存器（最快、最小）
    ↓ L1 Cache
    ↓ L2 Cache
    ↓ L3 Cache
内存（主存）
    ↓
磁盘（辅存）
    ↓
磁带（归档）
```

### Cache 映射方式

| 方式 | 说明 | 优点 | 缺点 |
|:---|:---|:---|:---|
| 直接映射 | 固定位置 | 简单、快 | 冲突多 |
| 全相联 | 任意位置 | 命中率高 | 查找慢 |
| 组相联 | 分组内全相联 | 折中 | — |

## 三、流水线

### 3.1 流水线加速比

```
加速比 = 非流水线执行时间 / 流水线执行时间

理想加速比 = 流水段数
```

### 3.2 流水线冒险

| 冒险 | 原因 | 解决 |
|:---|:---|:---|
| 结构冒险 | 硬件资源冲突 | 资源分离、暂停 |
| 数据冒险 | 指令间数据依赖 | 转发、暂停 |
| 控制冒险 | 分支跳转 | 预测、延迟分支 |

## 四、可靠性

### 4.1 可靠性指标

| 指标 | 含义 |
|:---|:---|
| MTBF | 平均无故障时间 |
| MTTR | 平均修复时间 |
| 可用性 | MTBF / (MTBF + MTTR) |

### 4.2 可靠性模型

| 系统 | 公式 | 说明 |
|:---|:---|:---|
| 串联 | R = R1 × R2 × ... × Rn | 任一故障则全故障 |
| 并联 | R = 1 - (1-R1)(1-R2)...(1-Rn) | 全故障才故障 |
| 表决 | n 中取 k 个正常即可 | 如 TMR 三取二 |
