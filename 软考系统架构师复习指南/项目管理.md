## 二、WBS（工作分解结构）

- **定义**：将项目可交付成果分解为更小、更易管理的组件
- **原则**：100% 原则（WBS 包含全部工作）、8/80 原则（最底层不超过 80 小时）
- **最底层**：工作包（Work Package）

---

## 三、关键路径法（CPM）

- **关键路径**：网络图中最长的路径，决定项目最短工期
- **关键活动**：总时差为 0 的活动
- **正推法**：从前往后算最早开始（ES）/最早完成（EF）
- **逆推法**：从后往前算最晚开始（LS）/最晚完成（LF）
- **总时差**：TF = LS - ES = LF - EF

## 四、挣值分析（必考计算题）

### 4.1 三个基本变量

| 变量 | 全称 | 含义 |
|:---|:---|:---|
| PV | Planned Value | 计划值（计划完成的预算） |
| EV | Earned Value | 挣值（实际完成的预算） |
| AC | Actual Cost | 实际成本（实际花的钱） |

### 4.2 偏差与绩效

| 指标 | 公式 | 含义 | 判断 |
|:---|:---|:---|:---|
| CV（成本偏差） | EV - AC | 成本偏差 | CV < 0 超支 |
| SV（进度偏差） | EV - PV | 进度偏差 | SV < 0 滞后 |
| CPI（成本绩效） | EV / AC | 成本绩效 | CPI < 1 超支 |
| SPI（进度绩效） | EV / PV | 进度绩效 | SPI < 1 滞后 |

### 4.3 预测指标

| 指标 | 公式 | 含义 |
|:---|:---|:---|
| BAC | 项目总预算 | — |
| EAC | BAC / CPI | 估算完工成本 |
| ETC | EAC - AC | 估算剩余成本 |
| VAC | BAC - EAC | 完工偏差 |

### 4.4 例题

> 项目计划 100 万，工期 10 个月。第 5 个月底检查：PV=50 万，EV=40 万，AC=45 万。
>
> CV = 40 - 45 = -5 万（超支）
> SV = 40 - 50 = -10 万（滞后）
> CPI = 40/45 = 0.89（成本绩效差）
> SPI = 40/50 = 0.8（进度绩效差）
> EAC = 100/0.89 = 112.4 万（预计超支）

## 五、风险应对策略

| 策略 | 适用 | 例子 |
|:---|:---|:---|
| 规避 | 威胁大且可规避 | 改变计划、澄清需求 |
| 转移 | 无法规避但可转移 | 保险、外包 |
| 减轻 | 可降低概率/影响 | 冗余、测试 |
| 接受 | 风险可控 | 应急储备 |
| 开拓 | 机会 | 分配资源确保实现 |
| 分享 | 机会 | 合资 |
| 提高 | 机会 | 增加资源 |
