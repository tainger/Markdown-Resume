## 核心原则

1. **策略决定方向，仓位决定生死** — 仓位管理比策略更重要
2. **没有止损不交易** — 单笔风险不超过总资金 2%
3. **回测不是实盘** — 未来函数和过拟合是最大陷阱
4. **活下来比赚得多更重要** — 最大回撤控制在 20% 以内
