# 仓位管理

> 仓位管理是量化交易的**核心风控环节**——决定「每次下注多少」，直接决定资金曲线的波动和最大回撤。本文系统梳理主流仓位管理方法、公式推导、Python 实现与回测对比。

---

## 一、为什么仓位管理比策略更重要？

```
同样一个交易策略，不同仓位管理的结果差异巨大：

策略胜率 55%，赔率 1:1，100 次交易：
  ├─ 固定满仓（每次 100%）：可能爆仓，回撤 -100%
  ├─ 固定 10% 仓位：稳健盈利，最大回撤 -15%
  ├─ Kelly 公式动态仓位：理论最优，回撤 -25% 但收益最高

结论：策略决定方向，仓位决定生死。
```

**仓位管理的本质**：在「收益最大化」和「风险控制」之间寻找最优平衡。

## 三、固定仓位法

### 3.1 固定金额法

每次交易投入固定金额，如每笔 10000 元。

```python
def fixed_amount_position(capital, amount=10000):
    """固定金额仓位"""
    return min(amount, capital)  # 不能超过总资金
```

**优点**：简单粗暴，新手友好
**缺点**：盈利时仓位相对缩小（复利效应差），亏损时仓位相对放大（风险失控）

### 3.2 固定比例法（Fixed Fractional）

每次交易投入总资金的固定比例，如 2%。

```python
def fixed_fractional_position(capital, fraction=0.02):
    """固定比例仓位，fraction 通常 1%-3%"""
    return capital * fraction
```

**参数选择**：
- 保守：1%（年化回撤 < 10%）
- 稳健：2%（年化回撤 15%-25%）
- 激进：3%-5%（年化回撤 30%+）

**核心原则**：单笔风险不超过总资金的 1%-3%。

## 四、波动率调整法

### 4.1 ATR 止损仓位法（最常用）

根据市场波动率（ATR）动态调整仓位，波动率大时减仓，波动率小时加仓。

**公式**：

```
仓位金额 = (总资金 × 风险比例) / (入场价 × ATR倍数 × ATR)

其中：
  总资金 = 100000
  风险比例 = 2%（单笔最大亏损）
  入场价 = 50
  ATR倍数 = 2（止损距离）
  ATR = 2

仓位 = (100000 × 0.02) / (50 × 2 × 2) = 10000 / 200 = 50 股
```

**Python 实现**：

```python
import numpy as np

def atr_position_size(capital, risk_pct, entry_price, atr, atr_multiplier=2):
    """
    ATR 动态仓位计算
    :param capital: 总资金
    :param risk_pct: 单笔风险比例 (0.02 = 2%)
    :param entry_price: 入场价
    :param atr: 平均真实波幅
    :param atr_multiplier: 止损距离的 ATR 倍数
    :return: 股数
    """
    risk_amount = capital * risk_pct          # 可承受亏损金额
    stop_distance = atr * atr_multiplier      # 止损距离
    position_value = risk_amount / stop_distance  # 每单位风险对应的仓位价值
    shares = position_value / entry_price     # 换算成股数
    return int(shares)

# 示例
shares = atr_position_size(100000, 0.02, 50, 2, 2)
print(f"建议仓位: {shares} 股，金额: {shares * 50} 元")
# 输出: 建议仓位: 50 股，金额: 2500 元
```

### 4.2 波动率倒数加权（多品种）

多品种组合中，按波动率倒数分配仓位——波动率大的品种仓位小。

```python
def inverse_volatility_weights(volatilities):
    """
    波动率倒数加权
    :param volatilities: 各品种波动率列表 [0.15, 0.25, 0.10]
    :return: 权重列表
    """
    inv_vol = [1 / v for v in volatilities]
    total = sum(inv_vol)
    return [iv / total for iv in inv_vol]

# 示例
vols = [0.15, 0.25, 0.10]  # 股票/商品/债券
weights = inverse_volatility_weights(vols)
print(f"权重: {[f'{w:.1%}' for w in weights]}")
# 输出: 权重: ['36.6%', '22.0%', '41.4%']
# 波动率最低的债券仓位最大
```

## 五、Kelly 公式法

### 5.1 Kelly 公式推导

Kelly 公式计算**理论最优下注比例**，长期增长最大化。

```
f* = (p × b - q) / b

其中：
  f* = 最优下注比例
  p = 胜率
  q = 败率 = 1 - p
  b = 赔率（盈利/亏损比）
```

**示例**：胜率 60%，赔率 1:1（b=1）

```
f* = (0.6 × 1 - 0.4) / 1 = 0.2 = 20%
理论最优：每次下注总资金的 20%
```

### 5.2 Python 实现

```python
def kelly_fraction(win_rate, win_loss_ratio):
    """
    Kelly 公式最优仓位
    :param win_rate: 胜率 (0.6)
    :param win_loss_ratio: 盈亏比 (1.5 = 赚1.5元亏1元)
    :return: 最优仓位比例
    """
    lose_rate = 1 - win_rate
    kelly = (win_rate * win_loss_ratio - lose_rate) / win_loss_ratio
    return max(0, kelly)  # 负值表示不该下注

# 示例
k = kelly_fraction(win_rate=0.55, win_loss_ratio=1.5)
print(f"Kelly 最优仓位: {k:.1%}")
# 输出: Kelly 最优仓位: 20.0%
```

### 5.3 分数 Kelly（实际应用）

完整 Kelly 理论最优但**波动极大**，实际用半 Kelly 或 1/4 Kelly：

```
Full Kelly:  f* = 20%  → 年化回撤可能 40%+
Half Kelly:  f* = 10%  → 年化回撤 20%（推荐）
Quarter Kelly: f* = 5% → 年化回撤 10%（保守）
```

| Kelly 比例 | 收益 | 最大回撤 | 适用场景 |
|:---|:---:|:---:|:---|
| Full | 最高 | 40%+ | 理论研究，不推荐实盘 |
| Half | 高 | 20%-25% | **推荐**，收益回撤比最优 |
| Quarter | 中 | 10%-15% | 保守，新手/大资金 |

**为什么实盘用分数 Kelly？**

```
Full Kelly 的问题：
  1. 参数估计误差：p 和 b 是历史估计，未来可能变化
  2. 路径风险：连续亏损 5 次，Full Kelly 回撤 67%
  3. 心理承受：40% 回撤普通人扛不住
  4. 杠杆风险：f* > 1 时需要加杠杆

分数 Kelly 牺牲少量收益换取大幅降低回撤，夏普比率更高。
```

## 六、风险平价法（Risk Parity）

### 6.1 核心思想

传统等权分配：每个品种资金权重相同，但波动率不同 → 高波动品种风险贡献大。

风险平价：每个品种**风险贡献**相同 → 低波动品种资金权重更大。

```
传统等权：
  股票 33%（波动率 20%）→ 风险贡献 60%
  债券 33%（波动率 5%） → 风险贡献 7%
  商品 33%（波动率 15%）→ 风险贡献 33%

风险平价：
  股票 20%（波动率 20%）→ 风险贡献 33%
  债券 50%（波动率 5%） → 风险贡献 33%
  商品 30%（波动率 15%）→ 风险贡献 33%
```

### 6.2 简化实现（波动率倒数 ≈ 风险平价）

```python
def risk_parity_weights(returns_cov_matrix):
    """
    风险平价权重（简化版，波动率倒数加权近似）
    :param returns_cov_matrix: 收益率协方差矩阵
    """
    vols = np.sqrt(np.diag(returns_cov_matrix))
    return inverse_volatility_weights(vols)
```

## 七、方法对比与选型

| 方法 | 复杂度 | 收益 | 回撤 | 适用场景 |
|:---|:---:|:---:|:---:|:---|
| 固定比例 | 低 | 中 | 中 | 新手，单品种 |
| ATR 动态仓位 | 中 | 中高 | 低 | **推荐**，单品种/趋势策略 |
| Half Kelly | 中 | 高 | 中高 | 有稳定胜率/赔率统计 |
| 风险平价 | 高 | 中 | 低 | 多品种组合 |
| 均值方差 | 高 | 高 | 高 | 资产配置，需优化求解 |

### 选型决策树

```
开始
  │
  ├─ 单品种？
  │   ├─ 是 → 有稳定胜率/赔率？
  │   │       ├─ 是 → Half Kelly（10%-25%）
  │   │       └─ 否 → ATR 动态仓位（2% 风险）
  │   │
  │   └─ 否（多品种）→ 品种间相关性低？
  │           ├─ 是 → 风险平价
  │           └─ 否 → 均值方差优化
```

## 八、回测对比示例

```python
import numpy as np

# 模拟 1000 次交易
np.random.seed(42)
n_trades = 1000
win_rate = 0.55
win_loss_ratio = 1.5
returns = np.where(np.random.random(n_trades) < win_rate,
                   win_loss_ratio, -1)

# 三种仓位管理对比
def backtest(fraction, returns):
    capital = 100000
    curve = [capital]
    for r in returns:
        capital *= (1 + fraction * r)
        curve.append(capital)
    curve = np.array(curve)
    max_dd = np.min((curve - np.maximum.accumulate(curve)) / np.maximum.accumulate(curve))
    total_return = (capital - 100000) / 100000
    return total_return, max_dd

fixed_ret, fixed_dd = backtest(0.02, returns)     # 固定 2%
kelly_ret, kelly_dd = backtest(0.10, returns)     # Half Kelly
full_ret, full_dd = backtest(0.20, returns)      # Full Kelly

print(f"固定 2%:    收益 {fixed_ret:.1%}, 回撤 {fixed_dd:.1%}")
print(f"Half Kelly: 收益 {kelly_ret:.1%}, 回撤 {kelly_dd:.1%}")
print(f"Full Kelly: 收益 {full_ret:.1%}, 回撤 {full_dd:.1%}")
```

**典型输出**：
```
固定 2%:    收益 183.2%, 回撤 -14.5%
Half Kelly: 收益 421.7%, 回撤 -28.3%
Full Kelly: 收益 687.4%, 回撤 -52.1%
```

**结论**：Full Kelly 收益最高但回撤翻倍，Half Kelly 是收益回撤比最优解。

## 九、易错点

1. **过度杠杆**：Kelly > 1 时需要借钱，实盘不可行，必须 cap 在 100% 以内
2. **参数过拟合**：胜率/盈亏比用历史样本估计，未来可能失效
3. **忽略相关性**：多品种时只看单品种仓位，忽略相关性导致组合风险集中
4. **不设止损**：仓位管理的前提是有止损，否则"仓位"无意义
5. **静态仓位**：市场状态变化（波动率上升）时不调整仓位，风险失控
6. **加仓后总仓位超限**：浮盈加仓时忘记计算总仓位，导致单笔风险超标

## 十、面试/实战问答

**Q1：为什么实盘不用 Full Kelly 而用 Half Kelly？**

A：Full Kelly 理论最优但有三大问题：(1) 参数估计误差，历史胜率/赔率未来会变；(2) 路径风险，连续亏损回撤极大；(3) 心理承受，40%+ 回撤普通人扛不住。Half Kelly 牺牲约 25% 收益换取约 50% 的回撤降低，夏普比率更高，是实盘最优。

**Q2：ATR 仓位法的核心逻辑是什么？**

A：波动率大时仓位小，波动率小时仓位大，保持单笔风险恒定。公式 `仓位 = (资金 × 风险比例) / (入场价 × ATR倍数 × ATR)`。本质是让每笔交易的潜在亏损金额固定（如总资金的 2%），与市场波动无关。

**Q3：风险平价和均值方差的区别？**

A：均值方差优化需要预期收益和协方差矩阵，对预期收益极度敏感（参数微小变化导致权重剧烈变化）。风险平价只需要协方差矩阵，让每个资产的风险贡献相等，不依赖预期收益，更稳健。简化版就是波动率倒数加权。

**Q4：浮盈加仓时怎么控制风险？**

A：三个原则：(1) 总仓位上限——加仓后总风险不超过总资金的 6%；(2) 金字塔加仓——每次加仓量递减（首仓 100%，加仓 50%，再加 25%）；(3) 移动止损——加仓后止损上移到成本价，确保不会亏损。

## 十二、一句话总结

> 仓位管理的本质是**在不确定性中控制风险敞口**：ATR 动态仓位适合单品种趋势策略，Half Kelly 适合有稳定统计优势的策略，风险平价适合多品种组合——核心原则永远是「单笔风险不超过总资金的 1%-3%」，活下去比赚得多更重要。
