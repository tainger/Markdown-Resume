# 策略回测框架

> 策略回测是量化交易的**验证核心**——没有回测的策略是赌博，有回测但有未来函数的策略更是灾难。本文梳理回测框架设计、回测陷阱、Python 实现与评价指标。

## 二、回测陷阱（Future Functions）

### 2.1 未来函数分类

| 陷阱 | 描述 | 危害 |
|:---|:---|:---|
| **Look-ahead Bias** | 用了未来数据（如收盘价信号当天开盘买入） | 回测虚高 50%+ |
| **Survivorship Bias** | 只回测存活下来的股票（忽略退市） | 高估收益 2-3% |
| **Overfitting** | 参数优化过度拟合历史 | 实盘完全失效 |
| **忽略交易成本** | 不算手续费/滑点/冲击成本 | 高频策略收益蒸发 |
| **流动性假设** | 假设任意价格都能成交 | 实盘滑点巨大 |
| **前视复权** | 用未来的分红/拆股数据调整历史价格 | 信号失真 |

### 2.2 未来函数示例与修正

```python
# ❌ 错误：用当天收盘价算信号，当天收盘前买入（未来函数）
def bad_strategy(prices):
    signal = prices['close'].rolling(5).mean() > prices['close'].rolling(20).mean()
    # 当天收盘才知道 signal，但用它决定当天买入
    positions = signal.shift(0).astype(int)

# ✅ 正确：信号延迟一天，下一天开盘买入
def good_strategy(prices):
    signal = prices['close'].rolling(5).mean() > prices['close'].rolling(20).mean()
    positions = signal.shift(1).astype(int)  # shift(1) 避免未来函数
```

**黄金法则**：所有信号必须 `shift(1)` 后才能用于交易决策。

## 三、事件驱动回测 vs 向量化回测

### 3.1 向量化回测（快速但不精确）

```python
# 向量化回测：一次性计算所有信号，速度快但无法处理复杂逻辑
import pandas as pd
import numpy as np

def vectorized_backtest(prices, short_window=5, long_window=20):
    """向量化均线交叉回测"""
    # 生成信号
    prices['short_ma'] = prices['close'].rolling(short_window).mean()
    prices['long_ma'] = prices['close'].rolling(long_window).mean()
    prices['signal'] = (prices['short_ma'] > prices['long_ma']).astype(int)
    
    # 信号延迟一天（避免未来函数）
    prices['position'] = prices['signal'].shift(1).fillna(0)
    
    # 计算收益
    prices['returns'] = prices['close'].pct_change()
    prices['strategy_returns'] = prices['position'] * prices['returns']
    
    # 扣除手续费（单边万分之三）
    prices['trade'] = prices['position'].diff().abs()
    commission = 0.0003
    prices['strategy_returns'] -= prices['trade'] * commission
    
    # 累计收益
    prices['cumulative'] = (1 + prices['strategy_returns']).cumprod()
    
    return prices

# 示例
np.random.seed(42)
dates = pd.date_range('2023-01-01', periods=252)
prices = pd.DataFrame({'close': 100 + np.cumsum(np.random.randn(252) * 2)}, index=dates)
result = vectorized_backtest(prices)
total_return = result['cumulative'].iloc[-1] - 1
print(f"策略累计收益: {total_return:.1%}")
```

### 3.2 事件驱动回测（精确但慢）

```python
# 事件驱动回测：逐根 K 线处理，精确模拟实盘
class EventDrivenBacktest:
    def __init__(self, initial_capital=100000, commission=0.0003, slippage=0.001):
        self.capital = initial_capital
        self.initial_capital = initial_capital
        self.commission = commission
        self.slippage = slippage
        self.position = 0          # 持仓股数
        self.entry_price = 0
        self.trades = []
        self.equity_curve = []
    
    def on_bar(self, bar):
        """每根 K 线触发"""
        # 策略逻辑（示例：均线交叉）
        # ... 计算信号 ...
        
        if signal == 1 and self.position == 0:
            # 买入（次日开盘价 + 滑点）
            buy_price = bar['open'] * (1 + self.slippage)
            shares = int(self.capital * 0.95 / buy_price)  # 95% 仓位
            cost = shares * buy_price * (1 + self.commission)
            self.capital -= cost
            self.position = shares
            self.entry_price = buy_price
            self.trades.append(('BUY', bar.name, buy_price, shares))
        
        elif signal == -1 and self.position > 0:
            # 卖出
            sell_price = bar['open'] * (1 - self.slippage)
            revenue = self.position * sell_price * (1 - self.commission)
            pnl = (sell_price - self.entry_price) * self.position
            self.capital += revenue
            self.position = 0
            self.trades.append(('SELL', bar.name, sell_price, pnl))
        
        # 更新净值
        equity = self.capital + self.position * bar['close']
        self.equity_curve.append(equity)
    
    def run(self, data):
        """运行回测"""
        for date, bar in data.iterrows():
            self.on_bar(bar)
        return self.equity_curve
```

### 3.3 两种方法对比

| 维度 | 向量化 | 事件驱动 |
|:---|:---|:---|
| 速度 | 快（批量计算） | 慢（逐根循环） |
| 精度 | 低（无法处理复杂逻辑） | 高（精确模拟） |
| 复杂策略 | 不支持（止损/动态仓位） | 支持 |
| 适用场景 | 快速验证思路 | 精确回测/参数优化 |

## 四、回测评价指标

```python
import numpy as np
import pandas as pd

class BacktestMetrics:
    def __init__(self, equity_curve, rf=0.02):
        self.equity = np.array(equity_curve)
        self.returns = np.diff(self.equity) / self.equity[:-1]
        self.rf = rf
        self.periods = len(self.returns)
    
    def total_return(self):
        return self.equity[-1] / self.equity[0] - 1
    
    def annual_return(self):
        return (1 + self.total_return()) ** (252 / self.periods) - 1
    
    def max_drawdown(self):
        cumulative = self.equity / self.equity[0]
        peak = np.maximum.accumulate(cumulative)
        dd = (cumulative - peak) / peak
        return dd.min()
    
    def sharpe(self):
        excess = self.returns - self.rf / 252
        return np.sqrt(252) * excess.mean() / excess.std() if excess.std() > 0 else 0
    
    def calmar(self):
        return self.annual_return() / abs(self.max_drawdown())
    
    def win_rate(self):
        return (self.returns > 0).sum() / self.periods if self.periods > 0 else 0
    
    def profit_factor(self):
        wins = self.returns[self.returns > 0].sum()
        losses = abs(self.returns[self.returns < 0].sum())
        return wins / losses if losses > 0 else float('inf')
    
    def summary(self):
        return {
            '累计收益': f'{self.total_return():.1%}',
            '年化收益': f'{self.annual_return():.1%}',
            '最大回撤': f'{self.max_drawdown():.1%}',
            '夏普比率': f'{self.sharpe():.2f}',
            '卡玛比率': f'{self.calmar():.2f}',
            '胜率': f'{self.win_rate():.1%}',
            '盈亏比': f'{self.profit_factor():.2f}',
        }

# 使用示例
np.random.seed(42)
equity = 100000 * np.cumprod(1 + np.random.normal(0.001, 0.015, 252))
metrics = BacktestMetrics(equity)
for k, v in metrics.summary().items():
    print(f"{k}: {v}")
```

**典型输出**：
```
累计收益: 34.2%
年化收益: 34.7%
最大回撤: -8.5%
夏普比率: 1.45
卡玛比率: 4.08
胜率: 54.2%
盈亏比: 1.68
```

## 五、参数优化与过拟合防范

### 5.1 Walk-Forward 分析（滚动窗口优化）

```
传统优化（过拟合风险）：
  全样本优化参数 → 全样本回测 → 虚高收益

Walk-Forward（样本外验证）：
  ┌─────────────┬──────────┐
  │ 训练窗      │ 测试窗   │
  │ 优化参数    │ 验证收益 │
  ├─────────────┼──────────┤
  │ 滚动向前... │          │
  └─────────────┴──────────┘
  最终只看测试窗收益（样本外）
```

### 5.2 过拟合防范清单

1. **样本外测试**：至少预留 30% 数据做样本外验证
2. **参数敏感性**：参数小幅变化（±20%）收益应稳定，否则过拟合
3. **简化优先**：能用 2 个参数解决的不用 10 个
4. **多市场验证**：策略在多个品种/时段都有效才可信
5. **蒙特卡洛模拟**：打乱交易顺序多次模拟，看收益分布稳定性

```python
def monte_carlo_analysis(trades, n_simulations=1000):
    """
    蒙特卡洛模拟：评估策略稳定性
    :param trades: 每笔交易收益率列表
    """
    import numpy as np
    returns = []
    for _ in range(n_simulations):
        shuffled = np.random.permutation(trades)
        equity = np.cumprod(1 + shuffled)
        returns.append(equity[-1] - 1)
    returns = np.array(returns)
    print(f"5%分位: {np.percentile(returns, 5):.1%}")
    print(f"50%分位: {np.percentile(returns, 50):.1%}")
    print(f"95%分位: {np.percentile(returns, 95):.1%}")
    return returns
```

## 六、实盘前检查清单

| 检查项 | 标准 | 状态 |
|:---|:---|:---:|
| 样本外收益 | > 样本内收益的 50% | ☐ |
| 最大回撤 | < 20% | ☐ |
| 夏普比率 | > 1.0 | ☐ |
| 参数敏感性 | ±20% 变化收益稳定 | ☐ |
| 交易频率 | 非过度拟合（< 1000 笔/年） | ☐ |
| 滑点影响 | 滑点翻倍收益下降 < 30% | ☐ |
| 多品种验证 | 至少 3 个品种有效 | ☐ |
| Walk-Forward | 样本外夏普 > 0.5 | ☐ |

## 七、易错点

1. **未来函数**：信号不 shift(1)，回测虚高，实盘必亏
2. **忽略手续费**：高频策略手续费吞噬所有收益
3. **忽略滑点**：回测按理想价格成交，实盘滑点巨大
4. **生存者偏差**：只回测存活股票，高估收益
5. **参数过拟合**：10 个参数优化 100 次，必然过拟合
6. **样本内测试**：只看训练集收益，不做样本外验证
7. **忽略涨跌停**：信号买入但实际无法成交
8. **资金量假设**：回测 100 万，实盘 1000 万冲击成本不同

## 九、一句话总结

> 策略回测的本质是**在历史数据上模拟未来表现**，但历史不代表未来——最大的敌人是未来函数和过拟合，所有信号必须 shift(1)，所有参数必须做样本外验证，回测收益打对折才是实盘预期。
