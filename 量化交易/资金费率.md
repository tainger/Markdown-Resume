# 币安资金费率

> 资金费率（Funding Rate）是永续合约的**价格锚定机制**——多空双方定期互相付费，把没有到期日的永续价格拉回现货指数。本文系统梳理币安资金费率的**机制原理、2025-09-18 新公式、结算规则、上下限、年化换算、套利策略与 Python 计算**。
>
> ⚠️ 规则以币安官方公告为准：资金费率公式于 **2025-09-18 16:01（东八区）更新**，旧版"每 8 小时固定 0.01%"的简单算法在 1h/4h 合约上已失效。

---

## 一、为什么永续合约需要资金费率？

```
传统期货：有到期日 ──→ 到期交割，期货价格自然收敛现货（价格锚点）
永续合约：无到期日 ──→ 可以无限期持仓，价格可能永久偏离现货
                        │
                        ▼
              资金费率：定期让多空互相付费
              用真金白银把合约价拉回现货指数
```

**天秤模型**：

| 市场状态 | 合约价 vs 现货 | 资金费率 | 谁付给谁 | 调节效果 |
|:---|:---|:---:|:---|:---|
| 偏多（过热） | 合约价 > 现货 | **正（+）** | **多头 → 空头** | 增加做多成本，吸引开空，价格回落 |
| 偏空（过冷） | 合约价 < 现货 | **负（−）** | **空头 → 多头** | 增加做空成本，吸引开多，价格回升 |
| 均衡 | 基本贴合 | ≈ 0 | 几乎不转移 | — |

> 🔑 **资金费率不是手续费**：钱在多头和空头持仓者之间直接转移，**币安不抽成**。手续费是交给交易所的，资金费是交易者之间结算的。

## 二、计算公式（2025-09-18 新版）

### 2.1 新老公式对比

| 版本 | 公式 |
|:---|:---|
| 旧版（2025-09-18 前） | `F = P + clamp(I − P, +0.05%, −0.05%)`（利率随结算频率变化：8h=0.01%，1h=0.00125%） |
| **新版（现行）** | `F = [ P + clamp(I − P, +0.05%, −0.05%) ] ÷ (8 / N)` |

- **F（Funding Rate）**：最终资金费率
- **P（Premium Index）**：结算间隔内的**平均溢价指数**——合约标记价相对现货指数的偏离度（间隔内按秒采样取时间加权平均）
- **I（Interest）**：基础利率，**固定 0.01%**；例外：**BNBUSDT、ETHBTC 永续利率为 0%**
- **N**：结算间隔小时数（8 / 4 / 1）
- **clamp(x, +0.05%, −0.05%)**：钳位函数，把 `I−P` 强制限制在 [−0.05%, +0.05%]，防止费率剧烈波动

### 2.2 为什么要除以 (8/N)？

把不同结算频率的**单次费率统一折算回 8 小时基准**，保证"一天收的总量"一致：

| 结算间隔 | N | 缩放因子 8/N | 单次利率分量 | 每天结算次数 | 日利率 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 8 小时 | 8 | 1 | 0.01% | 3 | 0.03% |
| 4 小时 | 4 | 2 | 0.005% | 6 | 0.03% |
| 1 小时 | 1 | 8 | 0.00125% | 24 | 0.03% |

> 高频结算合约单次费率被等比例缩小，避免"持仓即被费率拖垮"。**比较不同结算频率的合约时不能直接比单次费率，要先年化。**

### 2.3 计算示例

**例 1：PUMPUSDT，4h 结算（N=4），P = 0.02%**

```
括号内 = 0.02% + clamp(0.01% − 0.02%, ±0.05%)
       = 0.02% + (−0.01%)
       = 0.01%
F = 0.01% ÷ (8/4) = 0.01% ÷ 2 = 0.005%
```

**例 2：BTCUSDT，8h 结算，溢价极小 P = 0.008%**

```
F = [0.008% + clamp(0.01% − 0.008%, ±0.05%)] / 1
  = 0.008% + 0.002%
  = 0.01%
```

### 2.4 三种行情下的公式行为（以 8h 为例）

| 情形 | 条件 | clamp 行为 | F 结果 |
|:---|:---|:---|:---|
| 均衡（最常见） | `|I−P| ≤ 0.05%` | 不截断，clamp = I−P | **F = I = 0.01%**（P 被抵消） |
| 严重溢价 | P > I + 0.05%（即 P > 0.06%） | 截断为 −0.05% | F = P − 0.05%（费率随溢价上涨但被限速） |
| 严重折价 | P < I − 0.05%（即 P < −0.04%） | 截断为 +0.05% | F = P + 0.05%（转负但被限速） |

> 💡 这就是"**为什么资金费率总是 0.01%**"的数学答案：只要溢价在 ±0.05% 的温和区间，P 就被利率项精确抵消，F 恒等于 0.01%。BitMEX Research 数据显示 2025 Q3 超 92% 的时间费率为正、聚集在 0.01% 附近——**公式内置正向锚点 + Ethena 等基差套利资本压制溢价上限**。

## 三、资金费用怎么算？

```
资金费用 = 仓位名义价值 × 资金费率
仓位名义价值 = 标记价格 × 持仓数量（U 本位以 USDT 计）
```

**关键：按名义价值算，与杠杆无关。** 10 倍杠杆和 100 倍杠杆持有同样名义价值的仓位，收付的资金费**一样多**——杠杆只影响占用多少保证金，不影响资金费。资金费直接从**保证金余额**扣减，极端费率下可能触发强平。

**示例**：持有 10,000 USDT 名义价值的 BTCUSDT 多仓，费率 +0.01%

```
资金费用 = 10,000 × 0.01% = 1 USDT（多头付出，空头收入）
```

### 3.1 年化换算

```
年化资金费率 = 单次费率 × 每天结算次数 × 365
            = 单次费率 × (24 / N) × 365
```

| 单次费率 | 结算频率 | 日费率 | 年化（名义价值口径） |
|:---:|:---:|:---:|:---:|
| 0.01% | 8h | 0.03% | **10.95%** |
| 0.005% | 4h | 0.03% | 10.95% |
| 0.05% | 8h | 0.15% | 54.75% |
| 0.75% | 8h | 2.25% | **821.25%**（极端行情） |

> ⚠️ 年化是**名义价值**收益率，不是保证金收益率。若用 5 倍杠杆且保证金充足，空头端资金费收入对保证金的年化约放大 5 倍——但爆仓风险同步放大。

## 四、结算规则

### 4.1 结算时间

- **默认每 8 小时一次**：UTC `00:00 / 08:00 / 16:00`（北京时间 `08:00 / 16:00 / 00:00`）
- 部分合约（新币、波动大的）从上线起就是 **4 小时**结算
- 极端行情下币安可**临时**把频率调到 4h 甚至 1h，并临时调整费率上下限（无需事先同意，以合约页倒计时为准）

### 4.2 持仓快照规则

```
只有在结算时间戳「精确持有仓位」的账户才参与本期资金费结算：

  开仓 ────────────── 结算时刻T(快照持仓) ────────────── 平仓
  └──────── 这期间持有才收/付 ────────┘

  T 之前已平仓        → 不参与
  T 之后才开仓        → 不参与
  跨越 T 持有（含 T）  → 按整期费率收/付（不按持仓时长折算）
```

- 资金费**不按持仓时间比例折算**：结算前 1 分钟开仓并跨过结算点，也要按完整一期费率收付
- 结算系统完成全平台快照和扣款需要数十秒到 1 分钟，"准点抢费率"存在执行风险
- 费率在间隔内**实时变化**，最终按**结算时刻**的费率扣款（页面显示的是预测费率，不保证等于最终值）

## 五、资金费率上下限（Cap / Floor）

币安对 U 本位永续设强制上下限，且**与合约的最大杠杆/维持保证金档位挂钩**：

| 合约类型 | 单次费率上下限 |
|:---|:---:|
| 最大杠杆 **≥ 30x** 的 U 本位合约 | **±0.75 × 维持保证金率（MMR）** |
| 最大杠杆 **≤ 25x** 的 U 本位合约 | **±3%** |

**解读**：高杠杆合约允许的费率上限更低——因为单次费率若超过维持保证金率的一定比例，一次结算就可能把高杠杆仓位直接"费率强平"。

```
示例：某高杠杆合约当前仓位档位的维持保证金率 = 0.5%
  → 费率上限 = 0.75 × 0.5% = 0.375%
  → 持有 100,000 USDT 名义仓位，单次最多被扣 375 USDT
```

> 维持保证金率随**名义仓位档位**递增（仓位越大、杠杆越低、MMR 越高），因此同一个合约在你加仓后费率上限也可能变化。具体数值看合约页面「合约信息 → 杠杆与保证金」。

**特殊阶段**：盘前交易合约（如 0GUSDT 上线初期）没有溢价指数，费率固定（4h 结算时为 0.005%），转标准合约后上限可能是 ±2%，再过渡到常规档位。

## 六、怎么读资金费率（行情视角）

| 信号 | 含义 | 量化视角 |
|:---|:---|:---|
| 长期 +0.01% | 市场常态，温和多头 | 公式锚点，不代表强烈看涨 |
| 持续高正费率（>0.05%/8h） | 多头拥挤/逼空行情 | 基差套利资本入场信号，但往往是顶部区域 |
| 持续负费率 | 空头拥挤、恐慌或新币事件 | 做空成本高，多头可收息；常出现在急跌后 |
| 费率骤降转负 + 价格上涨 | 空头被挤压平仓 | 轧空（short squeeze）前兆之一 |
| 费率与价格背离 | 价格新高但费率走低 | 追涨动能衰竭，背离风险提示 |

**数据入口**：合约交易页顶部（当前费率 + 结算倒计时）、币安「实时资金费率」「历史资金费率」页、第三方 Coinglass（跨所对比，注意延迟）。

## 七、资金费率套利

### 7.1 期现套利（正费率场景）

```
正费率 → 多头付空头：
  ① 现货买入 1 个 BTC
  ② 永续开等值空单（对冲方向风险）
  ③ 每期结算：空单收取多头支付的资金费
  ④ 基差收敛/费率回落时双边平仓

净收益 = 资金费收入 − 双边手续费 − 滑点 − 基差变化 − 资金占用成本
```

三个工程难点：
1. **数量对齐**：现货与合约名义价值要动态等值（delta neutral），价格波动后敞口会漂移
2. **保证金安全垫**：急拉盘时空单浮亏，保证金不足会先爆仓——爆一次，前面收的费全部回吐
3. **费率反转**：刚开仓费率就由正转负，收费方变付费方

### 7.2 跨交易所套利

同一标的在币安/Bybit/OKX/Bitget 费率不同 → 在费率高的一侧持收费方向，另一侧反向对冲。额外风险：**标记价/指数差异、双边深度差、链上划转延迟、API 风控差异、保证金分散导致资金效率低**。

### 7.3 成本清单（不算清就是亏钱）

| 成本/风险 | 说明 |
|:---|:---|
| 双边手续费 | 开仓 + 平仓（+ 现货买卖），吃单费率通常 0.04%~0.05%/边 |
| 滑点 | 小币种盘口薄，实际成交价远差于预期 |
| 基差波动 | 价差可能继续扩大，平仓时亏损 |
| 爆仓风险 | 杠杆高 + 单边插针 + 费率扣款三重挤压 |
| 费率反转 | 预测费率不等于最终费率 |
| 结算频率切换 | 8h 临时改 1h，收费节奏全变 |
| 转账延迟 | 跨所搬砖错过结算快照 |

> 例：0.01% 一期的费率收入，若吃单开平双边手续费 0.09%（0.045%×2），**要连续收 9 期（3 天）才刚回本**。低费率时套利利润极薄，这也是机构倾向挂单（maker 0.02%）+ 大资金的原因。

## 八、Python 实现

### 8.1 费率与资金费计算（新公式）

```python
def funding_rate(P: float, I: float = 0.0001, N: int = 8,
                 clamp_band: float = 0.0005) -> float:
    """
    币安资金费率（2025-09-18 新公式）
    F = [P + clamp(I - P, +0.05%, -0.05%)] / (8 / N)

    :param P: 平均溢价指数（小数，0.02% 传 0.0002）
    :param I: 基础利率，默认 0.01%=0.0001；BNBUSDT/ETHBTC 传 0
    :param N: 结算间隔小时数：8 / 4 / 1
    :param clamp_band: 钳位区间 ±0.05%
    :return: 单次资金费率（小数）
    """
    clamped = max(-clamp_band, min(clamp_band, I - P))
    return (P + clamped) / (8 / N)


def funding_fee(notional_usdt: float, rate: float) -> float:
    """资金费用 = 名义价值 × 费率（与杠杆无关），正=多头付出"""
    return notional_usdt * rate


def annualized(rate_per_period: float, N: int) -> float:
    """年化费率（名义价值口径）= 单次费率 × 每天(24/N)次 × 365"""
    return rate_per_period * (24 / N) * 365


# ---- 示例 ----
# 例1: PUMPUSDT 4h 结算, P=0.02%
f1 = funding_rate(P=0.0002, N=4)
print(f"PUMP 单次费率: {f1:.5%}")                 # 0.00500%
print(f"年化: {annualized(f1, N=4):.2%}")         # 10.95%

# 例2: BTCUSDT 8h, 均衡区 P=0.008%
f2 = funding_rate(P=0.00008, N=8)
print(f"BTC 单次费率: {f2:.5%}")                  # 0.01000%

# 例3: 10000 USDT 多仓, 费率 +0.01%
fee = funding_fee(10_000, 0.0001)
print(f"多头付出资金费: {fee} USDT")              # 1.0
```

### 8.2 期现套利收益计算器

```python
def cash_and_carry_pnl(
    notional: float,          # 单边名义价值 (USDT)
    expected_rates: list[float],  # 每期预测费率（收费方向为正）
    taker_fee: float = 0.00045,   # 吃单单边手续费率
    slippage: float = 0.0002,     # 单边滑点估计
    spot_fee: float = 0.001,      # 现货双边总费率
) -> dict:
    """期现套利净收益（合约端 maker/taker + 现货端）"""
    income = sum(notional * r for r in expected_rates)
    # 合约开+平双边 + 滑点双边 + 现货买卖
    cost = notional * (taker_fee * 2 + slippage * 2 + spot_fee)
    return {
        "资金费收入": round(income, 2),
        "交易成本": round(cost, 2),
        "净收益": round(income - cost, 2),
        "盈亏平衡期数": max(1, round(
            (taker_fee * 2 + slippage * 2 + spot_fee) / 0.0001)),
    }

# 0.01%/8h, 10 万名义, 吃单（含滑点+现货双边成本）
print(cash_and_carry_pnl(100_000, [0.0001] * 9))
# 资金费收入 90，交易成本 230 → 净收益 -140（需约 23 期 = 7~8 天才回本）
# 若只算合约吃单双边 0.09%，也要 9 期（3 天）才刚覆盖手续费
```

### 8.3 调币安公开 API 查实时费率（无需密钥）

```python
import requests
from datetime import datetime, timezone, timedelta

def get_funding(symbol: str = "BTCUSDT") -> dict:
    """
    GET /fapi/v1/premiumIndex   当前/预测资金费率 + 下次结算时间
    GET /fapi/v1/fundingInfo    结算间隔等合约参数（2025-09 新增）
    """
    base = "https://fapi.binance.com"
    idx = requests.get(f"{base}/fapi/v1/premiumIndex",
                       params={"symbol": symbol}, timeout=5).json()
    info = requests.get(f"{base}/fapi/v1/fundingInfo", timeout=5).json()
    interval = next((x["fundingIntervalHours"] for x in info
                     if x["symbol"] == symbol), None)

    next_t = datetime.fromtimestamp(idx["nextFundingTime"] / 1000,
                                    tz=timezone(timedelta(hours=8)))
    rate = float(idx["lastFundingRate"])
    n = interval or 8
    return {
        "symbol": symbol,
        "当前/预测费率": f"{rate:.4%}",
        "结算间隔": f"{n}h",
        "下次结算(北京)": next_t.strftime("%Y-%m-%d %H:%M"),
        "年化(名义)": f"{annualized(rate, n):.2%}",
        "方向": "多头付空头" if rate > 0 else
                ("空头付多头" if rate < 0 else "均衡"),
    }

if __name__ == "__main__":
    print(get_funding("BTCUSDT"))
    # {'symbol': 'BTCUSDT', '当前/预测费率': '0.0100%', '结算间隔': '8h',
    #  '下次结算(北京)': '2026-... 08:00', '年化(名义)': '10.95%',
    #  '方向': '多头付空头'}
```

> 实盘要点：结算频率、上下限是**逐合约**参数且可能被临时调整，程序里必须实时拉 `fundingInfo`，不能写死 8h。

## 九、易错点

1. **把资金费率当手续费**：资金费是多空之间转移，交易所不收；手续费是另算的交易成本。
2. **还在用旧公式**：2025-09-18 后 4h/1h 合约单次费率要除以 `8/N` 缩放；看到 1h 合约显示 0.00125% 不要以为"费率很低"，它一天结 24 次。
3. **年化口径混淆**：10.95% 是**名义价值**年化；上杠杆后相对保证金的收益和亏损都成倍放大，不是无风险 10%。
4. **以为按持仓时间折算**：资金费只看结算时刻快照，跨过结算点就按整期收付，不按分钟比例算。
5. **资金费按保证金算**：错，按**名义价值**算，与杠杆无关；高杠杆 + 高费率可能一次结算直接触发强平。
6. **忽略上下限与档位**：高杠杆合约上限是 `±0.75 × MMR`（如 0.375%），不是 ±3%；仓位升档后上限也会变。
7. **把预测费率当最终值**：页面显示的是预测值，费率在间隔内实时变动，结算时刻才定版。
8. **认为套利无风险**：费率反转、基差扩大、插针爆仓、滑点、频率切换都能让"躺赚"变亏损；0.01% 的费率连双边手续费都覆盖不了几期。

## 一句话总结

> **资金费率 = 永续合约的"看不见的到期日"**：用 `F = [P + clamp(I−P, ±0.05%)] / (8/N)` 让多空按溢价互相付费，温和行情下被公式锚定在 0.01%/8h（年化 10.95%），极端行情受 `±0.75×MMR` 上限保护；看懂收付方向、结算快照和年化口径是交易的前提，而套利赚的从来不是费率本身，而是**费率收入覆盖交易成本与风险之后的残差**。
