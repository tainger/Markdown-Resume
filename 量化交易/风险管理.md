# 风险管理

> 风险管理是量化交易的**生命线**——没有风控的策略终将爆仓。本文系统梳理止损方法、回撤控制、风险指标计算与 Python 实现。

---

## 一、风险管理体系

```
风险管理金字塔（从下到上）：

┌─────────────────────────────┐
│  组合层面：相关性/集中度控制  │  ← 最顶层
├─────────────────────────────┤
│  策略层面：最大回撤/波动率约束│
├─────────────────────────────┤
│  单笔层面：止损/仓位/风险预算 │
└─────────────────────────────┘
         执行层面：下单/滑点/流动性  ← 最底层
```

**核心原则**：风险控制必须多层次，任何一层失效都有兜底。

## 二、止损方法

### 2.1 固定止损 vs 动态止损

| 方法 | 原理 | 优点 | 缺点 | 适用场景 |
|:---|:---|:---|:---|:---|
| 固定百分比止损 | 入场价 × (1 - 固定%) | 简单 | 忽略波动率 | 新手 |
| ATR 止损 | 入场价 ± k × ATR | 适应波动率 | 参数敏感 | 趋势策略 |
| 跟踪止损 | 价格创新高时止损上移 | 锁定利润 | 震荡市易被洗 | 趋势策略 |
| 时间止损 | N 根 K 线未盈利则退出 | 提高资金效率 | 可能错过反弹 | 短线 |

### 2.2 ATR 止损实现

```python
def atr_stop_loss(entry_price, atr, multiplier=2, direction='long'):
    """
    ATR 动态止损
    :param entry_price: 入场价
    :param atr: 平均真实波幅
    :param multiplier: ATR 倍数（通常 1.5-3）
    :param direction: long/short
    """
    if direction == 'long':
        return entry_price - multiplier * atr
    else:
        return entry_price + multiplier * atr
```

### 2.3 跟踪止损（Chandelier Exit）

```python
def chandelier_exit(highs, atr, multiplier=3, direction='long'):
    """
    吊灯止损（跟踪止损）
    :param highs: 最高价序列
    :param atr: ATR 序列
    """
    if direction == 'long':
        return highs - multiplier * atr  # 从最高点回撤 k×ATR 止损
    else:
        return highs + multiplier * atr
```

## 三、回撤控制

### 3.1 最大回撤（Maximum Drawdown）

```python
import numpy as np

def max_drawdown(returns):
    """
    计算最大回撤
    :param returns: 收益率序列（日收益率）
    :return: 最大回撤（负数）
    """
    cumulative = (1 + returns).cumprod()
    peak = cumulative.expanding().max()
    drawdown = (cumulative - peak) / peak
    return drawdown.min()

# 示例
returns = np.random.normal(0.001, 0.02, 252)  # 一年日收益
mdd = max_drawdown(returns)
print(f"最大回撤: {mdd:.1%}")
```

### 3.2 回撤控制规则

```
常见回撤控制规则：
  ├─ 单笔止损：单笔亏损不超过总资金 2%
  ├─ 单日止损：单日亏损不超过总资金 5%
  ├─ 单月止损：单月亏损不超过总资金 15%
  ├─ 最大回撤熔断：总回撤超过 20% → 停止交易 24h
  └─ 恢复规则：回撤恢复到 10% 以内 → 恢复交易
```

## 四、风险指标体系

### 4.1 核心指标计算

```python
import numpy as np

def sharpe_ratio(returns, rf=0.02, periods=252):
    """夏普比率（年化）"""
    excess = returns - rf / periods
    return np.sqrt(periods) * excess.mean() / excess.std()

def sortino_ratio(returns, rf=0.02, periods=252):
    """索提诺比率（只惩罚下行波动）"""
    excess = returns - rf / periods
    downside = excess[excess < 0].std()
    return np.sqrt(periods) * excess.mean() / downside

def calmar_ratio(returns, periods=252):
    """卡玛比率（年化收益/最大回撤）"""
    annual_return = (1 + returns).prod() ** (periods / len(returns)) - 1
    mdd = abs(max_drawdown(returns))
    return annual_return / mdd

def win_rate(returns):
    """胜率"""
    return (returns > 0).sum() / len(returns[returns != 0])

def profit_factor(returns):
    """盈亏比（平均盈利/平均亏损）"""
    wins = returns[returns > 0].mean()
    losses = abs(returns[returns < 0].mean())
    return wins / losses if losses > 0 else float('inf')
```

### 4.2 指标参考标准

| 指标 | 差 | 中 | 好 | 优秀 |
|:---|:---:|:---:|:---:|:---:|
| 夏普比率 | < 0.5 | 0.5-1.0 | 1.0-2.0 | > 2.0 |
| 索提诺比率 | < 1.0 | 1.0-2.0 | 2.0-3.0 | > 3.0 |
| 卡玛比率 | < 1.0 | 1.0-2.0 | 2.0-3.0 | > 3.0 |
| 胜率 | < 40% | 40%-50% | 50%-60% | > 60% |
| 最大回撤 | > 30% | 20%-30% | 10%-20% | < 10% |

## 五、仓位风险预算

### 5.1 单笔风险预算

```python
def risk_budget_position(capital, max_risk_pct, entry_price, stop_price):
    """
    基于风险预算的仓位计算
    :param capital: 总资金
    :param max_risk_pct: 单笔最大风险比例 (0.02)
    :param entry_price: 入场价
    :param stop_price: 止损价
    :return: 股数
    """
    risk_amount = capital * max_risk_pct
    risk_per_share = abs(entry_price - stop_price)
    return int(risk_amount / risk_per_share)

# 示例
shares = risk_budget_position(100000, 0.02, 50, 48)
print(f"建议仓位: {shares} 股，风险金额: {shares * 2} 元")
# 输出: 建议仓位: 1000 股，风险金额: 2000 元
```

### 5.2 组合风险预算

```python
def portfolio_risk_budget(capital, max_portfolio_risk, positions):
    """
    组合风险预算分配
    :param capital: 总资金
    :param max_portfolio_risk: 组合最大风险 (0.06 = 6%)
    :param positions: 各品种 [(entry, stop, weight), ...]
    """
    total_risk = 0
    for entry, stop, weight in positions:
        risk_pct = abs(entry - stop) / entry
        total_risk += risk_pct * weight
    
    if total_risk > max_portfolio_risk:
        # 按比例缩仓
        scale = max_portfolio_risk / total_risk
        print(f"组合风险超标，缩仓至 {scale:.1%}")
        return scale
    return 1.0
```

## 六、相关性与集中度控制

```python
import numpy as np

def correlation_risk_check(returns_matrix, threshold=0.7):
    """
    相关性风险检查：高相关品种不能同时重仓
    """
    corr = np.corrcoef(returns_matrix)
    high_corr_pairs = []
    for i in range(len(corr)):
        for j in range(i+1, len(corr)):
            if abs(corr[i,j]) > threshold:
                high_corr_pairs.append((i, j, corr[i,j]))
    return high_corr_pairs

# 示例
returns = np.random.randn(4, 252)  # 4 个品种
pairs = correlation_risk_check(returns)
print(f"高相关品种对: {pairs}")
```

**集中度控制规则**：
- 单品种仓位不超过总资金 30%
- 同板块仓位不超过总资金 50%
- 高相关品种（corr > 0.7）合计仓位不超过 40%

## 七、实盘风控清单

| 检查项 | 阈值 | 动作 |
|:---|:---|:---|
| 单笔亏损 | > 2% | 立即止损 |
| 单日亏损 | > 5% | 停止当日交易 |
| 单月亏损 | > 15% | 暂停策略，复盘 |
| 最大回撤 | > 20% | 熔断，24h 后评估 |
| 仓位超限 | > 100% | 强制减仓 |
| 滑点异常 | > 0.5% | 暂停该品种交易 |
| 流动性不足 | 持仓 > 日均成交量 1% | 减仓或退出 |

## 八、易错点

1. **止损太近**：正常波动就被洗出，胜率极低
2. **止损不执行**：心理抗拒止损，小亏变大亏
3. **过度集中**：单一品种/板块重仓，黑天鹅爆仓
4. **忽略相关性**：以为分散持仓，实际高度相关
5. **杠杆过高**：3 倍杠杆 + 10% 回撤 = 30% 亏损
6. **不设熔断**：连续亏损不止损，最终爆仓

> 风险管理的本质是**用规则约束贪婪和恐惧**：单笔 2% 止损是底线，组合 6% 风险预算是红线，20% 回撤熔断是生命线——活下来永远是第一位的。
