## 二、大厂四轮面试考点全景图（一眼速查）

```
 投递/简历筛选
    │
    ▼
 笔试 / 机考 ──────► 选择题(计算机基础) + 编程题(2~3道中等难度)      淘汰率 ~50%
    │
    ▼
 技术一面（40–60min）───────────────────────────────────────── 通过率 ~40%
   自我介绍 + Java 基础 + 集合 + JVM 入门 + 1~2 道算法题(中等)
    │
    ▼
 技术二面（60–90min）───────────────────────────────────────── 通过率 ~30%
   并发(AQS/线程池) + 中间件(Redis/MQ) + MySQL 深挖 + 项目深挖 10 分钟 + 1 道中难算法
    │
    ▼
 技术三面 / 交叉面 / 总监面（60–90min）──────────────────────── 通过率 ~50%
   系统设计（秒杀/短链/Feed流等） + 开放性架构题 + 职业规划
    │
    ▼
 HR 面（20–40min）──────────────────────────────────────────── 通过率 ~90%
   行为面试 + 离职原因 + 期望薪资 + 文化匹配
```

## 四、「P7 必背清单」——80% 场次会出现的 15 道骨架题

刷过这些题不等于能拿 Offer，但**答不出这些基本一面就挂**。按面经复现频率排序：

| # | 高频题 | 面试场上的"关键词骨架" | 答案在哪 |
|:---|:---|:---|:---|
| 1 | HashMap 底层 + JDK1.7/1.8 区别？ | 数组+链表+红黑树；阈值 8→6；尾插法防环形；泊松分布 $0.000006\%$ | [Java/HashMap](../java/HashMap的应用场景和源码分析.md) |
| 2 | ConcurrentHashMap 1.7 vs 1.8？ | 分段锁 → CAS + synchronized 桶级锁；协助扩容；LongAdder 计数 | [Java/ConcurrentHashMap](../java/ConcurrentHashMap应用场景和源码分析.md) |
| 3 | `synchronized` vs `ReentrantLock` + 锁升级？ | JVM vs AQS；偏向→轻量→重量；可中断/公平/多条件 | [JUC](../java/JUC并发包.md) 二、三节 |
| 4 | volatile 原理？为什么不能保证原子性？ | 可见性 StoreLoad 屏障；有序性禁止重排；count++ 是读改写三步 | [JUC](../java/JUC并发包.md) + [JMM](../jvm/JMM内存模型.md) |
| 5 | 线程池 7 大参数 + 拒绝策略？为什么不能用 Executors？ | core/max/queue/keepAlive/threadFactory/rejected；OOM 风险 | [JUC](../java/JUC并发包.md) 线程池小节 |
| 6 | ThreadLocal 原理？为什么内存泄漏？ | ThreadLocalMap + 线性探测；key 弱引用 value 强引用；finally remove | [ThreadLocal](../java/ThreadLocal源码分析.md) |
| 7 | JVM 内存结构 + 垃圾回收算法对比？ | 堆/栈/方法区；标记清除/复制/标记整理；CMS vs G1 | [JVM 内存结构](../jvm/内存结构.md)、[GC 算法](../jvm/垃圾回收算法.md) |
| 8 | MySQL 索引为什么用 B+ 树不用 B 树/哈希？ | 磁盘友好；叶子链表范围查；哈希只支持等值 | [MySQL/索引](../mysql/4.%20索引.md) |
| 9 | MVCC + 事务隔离级别 + 间隙锁？ | 隐藏列+undo 版本链+ReadView；可重复读 = 快照读+间隙锁防幻读 | [MySQL/事务与锁](../mysql/5.%20事务与锁.md) |
| 10 | 缓存穿透 / 击穿 / 雪崩？ | 空值缓存/布隆过滤器；互斥锁/永不过期；多级缓存+Jitter | [Redis/缓存问题](../redis/缓存问题与实战.md) |
| 11 | Redis 分布式锁 + Redisson 看门狗？ | SETNX+过期+Lua；看门狗续期 30s → 10s；看门狗=兜底 | [分布式/分布式锁](../分布式/分布式锁.md) |
| 12 | MQ 消息不丢 / 不重复 / 有序？ | 生产端 confirm + 落盘 + 消费端 ACK；幂等（去重表/唯一键） | [RocketMQ](../rocketMq/可靠性与高可用.md) |
| 13 | TCP 三次握手 / 四次挥手 + TIME_WAIT？ | 双方确认收发能力；MSL=2；time_wait 回收策略 | [计算机网络/TCP](../计算机网络/TCP.md) |
| 14 | HTTP 1.0 / 1.1 / 2 / 3 区别？ | 长连接/管线化 → 多路复用/HPACK → QUIC + UDP + 0RTT | [计算机网络/HTTP](../计算机网络/HTTP.md) |
| 15 | 手撕 LRU / 两数之和 / 反转链表 / TopK？ | HashMap+双向链表；哈希/双指针；快慢指针；堆/快排partition | [算法思想/哈希表](../算法思想/哈希表.md)、[leetcode-hot100](../leetcode-hot100/) |

## 五、9 大常见踩坑（面试前务必过一遍）

| # | 踩坑点 | 后果 | 对策 |
|:---|:---|:---|:---|
| 1 | **自我介绍啰嗦、无关信息多** | 面试官 30s 失去兴趣，直接问基础 | 2 分钟模板：技术栈 + 最硬项目 + 岗位匹配锚点，见 [项目深挖与自我介绍模板](项目深挖与自我介绍模板.md) |
| 2 | **算法题一上来就写代码，不问边界** | 方向偏了、写出来也不过 | 按 [算法面试实战指南](算法面试实战指南.md) 7 步法：澄清 → 举例 → 思路 → 编码 → 测试 |
| 3 | **八股只背结论，不背原理和"为什么"** | 追问连环 3 层就哑火 | 每道题按"原理→优缺点→选型→落坑→优化"五段式准备 |
| 4 | **项目全讲"我负责了什么"，没讲"为什么"和"结果"** | 被认为只是执行者不是思考者 | STAR + 量化：背景 → 任务 → 技术选型 trade-off → **可量化结果** |
| 5 | **简历夸大/造假** | 深挖项目或代码细节时一秒露馅，直接挂且进黑名单 | 写在简历上的每一行都能讲 3 分钟；不会的写"了解"而非"熟悉" |
| 6 | **反问环节问"加不加班/有没有加班费"** | 减分，被认为把钱放在首位 | 问技术栈挑战、新人培训、晋升机制、团队业务方向，见 [面试全流程](面试全流程与准备路线.md) HR 节 |
| 7 | **谈薪资报期望一口价，不留余地** | 谈崩 / 低了亏 / 高了被压 | 了解市场区间；给范围；问清楚总包结构（基本+绩效+年终+股票+签字费） |
| 8 | **HR 面吐槽前公司/前同事/前老板** | 一票否决，稳定性与协作能力判零分 | 永远正面表述："之前平台学到了A，想在贵司做B方向" |
| 9 | **挂了不复盘，连面 10 家都挂同一点** | 越面越没信心 | 每次面试 24h 内写复盘：哪题不会 / 哪题答得好 / 追问点，见 [面试全流程](面试全流程与准备路线.md) 复盘模板 |

## 六、一句话总结

**面试 = 30% 技术储备 + 40% 结构化表达 + 20% 项目深度 + 10% 运气**。前四项你能控制的是 90%，别把结果全归因于"运气不好"。
