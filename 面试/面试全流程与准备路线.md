# 面试全流程与准备路线

> 面试不是"等通知"的被动过程，而是 **准备 → 执行 → 复盘 → 迭代** 的闭环。本文从「投递前 4 周」到「拿到 Offer 谈薪」按时间线拆解，每一轮告诉你：**面试官考什么、你该做什么、哪些坑不能踩**。

---

## 一、时间线总览（备战 4 周 → 拿到 Offer 8 周）

```
第1周 ──► 简历打磨 + 八股第一轮 + 算法分类刷（数组/链表/树）
第2周 ──► 八股第二轮（并发+中间件）+ 算法滑窗/DP/二分 + 项目 STAR 拆解
第3周 ──► 系统设计速览 + 模拟面试 2 次 + 复盘错题 + 投递中厂练手
第4周 ──► 冲刺大厂（先投想去的二梯队，再投dream公司）
│
[面试阶段]
笔试 ─► 一面 ─► 二面 ─► 三面/交叉面 ─► HR面 ─► 谈薪/背调 ──► Offer
```

## 二、第 0 步：简历优化（决定你能不能拿到面试机会）

### 2.1 简历不是履历清单，是**价值证明**

| ❌ 错误写法 | ✅ 正确写法（STAR + 量化） |
|:---|:---|
| "负责后端接口开发，使用 MySQL 和 Redis" | "独立负责订单模块核心接口，引入 Redis 缓存热点 SKU，将峰值接口响应从 **300ms 降至 80ms，QPS 从 500 提升至 3000**" |
| "参与了 XX 项目的开发" | "主导 XX 模块从 0 到 1 落地，解决了并发支付下的库存超卖问题，上线后 **3 个月零故障，支撑 GMV 增长 200%**" |
| "熟悉 Java、Redis、MySQL" | "核心技能：Java（JUC/AQS 源码级理解）· Redis（分布式锁/缓存穿透雪崩全套方案）· MySQL（索引优化 + MVCC 原理）· RocketMQ（高可靠投递）" |

### 2.2 一页纸结构建议

```
① 个人信息（姓名/电话/邮箱/GitHub/博客）──────── 顶部简洁
② 技术栈摘要（3~5 行，按 JD 关键词顺序排列）─── 抓住 HR 30 秒
③ 项目经验（2~3 个最硬的，STAR 展开 + 量化）─── 技术面也看这个
④ 工作/实习经历（如已被项目覆盖可略）
⑤ 教育背景（应届生放前面）
⑥ 附加（开源贡献/技术文章/竞赛奖项）
```

⚠️ **避坑**：
- 不要写"精通"，除非你能手写其实现（建议用"深入理解/熟练使用/实践过"）
- 不要把所有技术都堆上去，只放**目标岗位匹配度 > 70%** 的
- 简历 PDF 命名：`姓名-岗位-年限-公司（如有）.pdf`

## 三、第 1~4 周：系统备战路线

### 3.1 算法（每天 4~6 题，贯穿全程）

| 周 | 目标 | 清单 |
|:---|:---|:---|
| 第 1 周 | 建立数据结构手感 | 数组（双指针、滑动窗口）、链表（反转/合并/判环）、二叉树（三序遍历/递归）；刷 Hot100 |
| 第 2 周 | 核心算法模式 | DFS/BFS、二分查找、回溯（排列/组合/子集）、前缀和+哈希、单调栈 |
| 第 3 周 | 困难模式与系统设计常考 | DP（线性/背包）、图（拓扑/最短路径）、**手撕 LRU / TopK / 并查集 / 快排 / 归并** |
| 第 4 周 | 模拟面试限时 | LeetCode Mock / 朋友对练；**15 分钟想出解法，30 分钟写完跑通** |

> 详细套路见 [算法面试实战指南](算法面试实战指南.md)；思想建模见 [../算法思想/](../算法思想/)。

### 3.2 八股（按模块 2h/天，周末复盘）

| 优先级 | 模块 | 重点 | 对应资料 |
|:---|:---|:---|:---|
| P0 必背 | Java 集合 + 并发 | HashMap/ConcurrentHashMap/synchronized/volatile/线程池/AQS/ThreadLocal | [../java/](../java/) |
| P0 必背 | JVM | 内存结构/GC算法/G1 vs CMS/类加载双亲委派/OOM排查 | [../jvm/](../jvm/) |
| P0 必背 | MySQL | B+树索引/MVCC/事务隔离/间隙锁/慢SQL/分库分表 | [../mysql/](../mysql/) |
| P1 高频 | Redis | 数据类型/三大缓存问题/持久化/分布式锁/集群 | [../redis/](../redis/) |
| P1 高频 | 计算机网络 | TCP三次握手四次挥手/TIME_WAIT/HTTP 版本演进/HTTPS | [../计算机网络/](../计算机网络/) |
| P2 加分 | Spring + MQ + 分布式 | 循环依赖三级缓存/AOP/Bean生命周期；MQ不丢不重有序；分布式事务/锁 | [../Spring/](../Spring/)、[../rocketMq/](../rocketMq/)、[../分布式/](../分布式/) |
| P3 面大厂 | 系统设计 | 秒杀/短链/Feed流/ID生成器（七步法：需求→容量→API→存储→架构→深挖→容错） | [../系统设计/](../系统设计/) |

### 3.3 项目深挖（你简历上的每一行都能讲 3 分钟）

每个项目按以下 8 个维度准备**草稿笔记**，面试前默背一遍：

1. **背景**：项目解决什么业务痛点？当时业务规模（QPS/数据量/日活）大概多少？
2. **架构**：画张系统架构图，有哪些服务/组件？请求的全链路走哪条路？
3. **我的角色**：独立负责 / 主导 / 协作？代码量占比？
4. **技术难点 Top3**：你遇到最难的 3 件事是什么？**怎么选型的？trade-off 是什么？**
5. **量化结果**：性能提升 / 成本下降 / 故障减少 / 业务增长，**一定有数字**
6. **踩过的坑**：线上出过什么问题？怎么排查的？复盘后做了什么改进？
7. **优化空间**：如果让你再做一次，有什么可以做得更好的？
8. **延伸问**：如果流量 ×10、数据 ×10，你会怎么架构升级？

> 模板与实战示例见 [项目深挖与自我介绍模板](项目深挖与自我介绍模板.md)。

### 3.4 模拟面试（至少 2 次）

找朋友或 [Pramp](https://www.pramp.com/) 对练，全程录屏：
- **自我介绍**：能否 2 分钟讲完，不啰嗦、重点突出？
- **答题表达**：是否"嗯、啊"太多、逻辑跳步？
- **算法节奏**：是否先问边界、先讲思路再写？
- **项目深挖**：被追问到没准备过的问题，是否有结构化应对？

## 四、笔试 / 机考

| 考察内容 | 形式 | 通过率 | 对策 |
|:---|:---|:---:|:---|
| 计算机基础选择题（网络/OS/数据库/Java） | 单选 + 多选 | ~60% | 刷牛客历年真题，注意细节（比如 TCP 定时器个数、ThreadLocalMap 哈希算法） |
| 编程题 2~3 道 | ACM 模式（自己写输入输出）/ 核心代码模式 | ~50% | 中等难度为主，**先过样例再优化**；别死磕一题；用自己最熟的语言 |

⚠️ **机考避坑**：
- **一定要认真读输入输出格式**，很多人死在输出末尾多了空格/换行
- 能过 60% 的测试用例就先提交，回头再优化边界（大厂机考是按 case 给分的，不是要么全对要么 0）
- 用 Java 的同学注意：ACM 模式要用 `Scanner` 或 `BufferedReader` 自己读，建议提前写过几套牛客的题适应

## 五、技术一面（40~60 分钟，通过率 ~40%）

### 面试官画像：通常是同级工程师或小组长，手里握着你的简历

### 考察什么

- 基础知识牢不牢（会不会背八股）
- 代码能力行不行（1~2 道算法题）
- 项目经验是否真实（聊 5~10 分钟项目）

### 标准流程 + 应对

```
① 自我介绍（2 分钟）──► 按模板，不啰嗦，结尾锚定"岗位匹配度"
② Java 基础 & 集合（10 分钟）──► HashMap/ConcurrentHashMap/ArrayList 三件套必问
    │                              每道题按"结构 + 原理 + 优缺点 + 选型 + 落坑"五段式答
    ▼
③ JVM / 并发入门（10 分钟）──► 内存结构 / GC 判定对象死 / volatile / synchronized
    │
    ▼
④ 算法题 1~2 道（15~20 分钟）──► 按7步法：澄清→举例→思路→编码→测试
    │                               一面难度：Easy ~ Medium，几乎必考 Hot100 原题变形
    ▼
⑤ 项目简介 + 1~2 个小追问（5~10 分钟）──► 别讲太细，点出亮点和难点即可
    │
    ▼
⑥ 反问环节（2~3 分钟）──► 必问！不问显得没兴趣
```

### 反问环节安全提问清单（一面用）

| 推荐（加分） | 不推荐（踩雷） |
|:---|:---|
| 团队目前在做什么业务？技术栈是什么？ | 你们加班多吗？ |
| 这个岗位的主要职责是什么？新人入职有培训吗？ | 你们有没有加班费？ |
| 团队在技术上目前最大的挑战是什么？ | 公司会不会裁员？ |
| 我这次面试有什么可以改进的地方吗？（收尾加分） | 薪资大概多少？（留到 HR 面问） |

## 六、技术二面（60~90 分钟，通过率 ~30%）

### 面试官画像：组长 / 技术骨干，比一面更资深，会深挖

### 考察什么

- **追问深度**：一面你会的，二面会问 3~5 层直到你答不上来（看你深度够不够）
- **项目深度**：项目深挖 15~20 分钟，看你是不是独立思考的
- **系统设计入门**：给个场景，看你架构思维

### 常见追问链示例（一面问 HashMap，二面会怎么追）

```
Q1: HashMap 底层结构？（一面已会）
   └─► Q2: 为什么链表长度≥8 才树化？泊松分布原理？
        └─► Q3: 扩容 rehash 的过程？1.7 头插法为什么会死循环？画图？
             └─► Q4: ConcurrentHashMap 1.8 怎么保证线程安全？putVal 流程？
                  └─► Q5: 多线程协助扩容的 transfer 怎么分工的？sizeCtl 含义？
```

**应对方法**：不会的坦诚说"这块我不太清楚，但我了解相关的 XXX"，然后往你会的方向引；**千万不要瞎编**，面试官写这些代码的，编的一眼看穿。

### 算法面难度升级

- Medium 难度为主，可能出 **Hard**（如接雨水、合并 K 链表、正则匹配）
- 有的公司会给**两道**，30 分钟限时（字节常见）
- **一定要边写边讲**，面试官看的是你的思维过程，不只是最终代码

## 七、技术三面 / 交叉面 / 总监面（60~90 分钟，通过率 ~50%）

### 面试官画像：总监 / 跨部门 leader，看格局和潜力，不纠结细节

### 考察什么

- **系统设计能力**：给你一个业务场景（秒杀/短链/Feed流），让你从零设计
- **业务理解 + 架构 sense**：trade-off 能力，不是堆技术名词
- **软技能**：沟通、抗压、学习能力、职业规划
- **交叉面**（阿里常见）：别的部门 leader 面，防止前面的面放水

### 系统设计七步法（直接套）

1. **需求澄清**：功能点（用户能做什么）+ 非功能（QPS、延迟、可用性）
2. **容量估算**：QPS、存储、带宽（粗算量级，别精确到个位）
3. **API 设计**：几个核心接口，入参出参是什么（RESTful 风格）
4. **数据模型 + 存储选型**：表结构、索引设计、Redis 存什么、MQ 怎么解耦
5. **高层架构图**：画 ASCII 图，用户请求怎么走，哪层做什么
6. **核心深挖**：热点数据怎么防击穿、分布式事务一致性、限流熔断降级
7. **扩展性 + 容错**：单点故障怎么办？流量 10 倍怎么扩？

> 系统设计详解与 4 个经典案例见 [../系统设计/](../系统设计/)。

### 开放性问题应对

| 常见开放性问题 | 答题框架（别空泛，结合自身经历） |
|:---|:---|
| "你遇到过最难的技术问题是什么？怎么解决的？" | 背景 → 难点 3 点 → 每点你怎么解决的（技术选型）→ 结果 → 复盘学到了什么 |
| "如果给你 XX 流量，你怎么架构？" | 先估容量 → 按"接入层→服务层→数据层"三层讲 → 每一层的选型与 trade-off |
| "你为什么想离开现在的公司？" | **永远正面！** 之前平台学到了A（具体），现在想做B方向（和目标公司业务一致），贵司在B方面有优势（具体到团队/产品），**不要吐槽前司任何人和事** |
| "你未来 1~3 年的职业规划？" | 第一年：快速融入，吃透业务，成为独当一面的工程师；第二年：在某个技术方向深入，做有影响力的项目；第三年：能带小团队 / 成为技术专家 |
| "你还有什么想问我的？"（总监面反问） | ① 贵司在 XX 业务（你面的业务）接下来 1 年的技术重点是什么？② 团队的人才培养和晋升路径是怎样的？③（如果面试表现不错）您觉得我目前还有哪些短板需要补？ |

## 八、HR 面（20~40 分钟，通过率 ~90%，但也会挂人）

### HR 画像：手握否决权，没有通过权；主要看文化匹配、稳定性、性价比

### ⚠️ HR 面不是随便聊！每一句话都在打分

### 常见问题 + 标准答案思路

| HR 问题 | 问题背后在问什么 | 答题思路 |
|:---|:---|:---|
| 自我介绍一下（非技术版） | 表达是否顺畅、逻辑是否清晰 | 30 秒版本：姓名 + 学历/上份公司 + 核心技能标签 + 为什么想来贵司 |
| 为什么离开上家公司？ | 稳定性、是否会吐槽老东家 | 参考上节总监面；**绝对不能说前司坏话** |
| 你找工作最看重什么？ | 期望是否和公司能提供的匹配 | 按 业务成长 > 技术挑战 > 团队氛围 > 薪酬福利 排序 |
| 你的职业规划？ | 稳定性：干 1 年就跑的公司不想招 | 同上节总监面；**至少提在贵司稳定 2~3 年成长** |
| 你手上有其他 Offer 吗？ | 用来谈薪资，也用来判断你是不是抢手 | 如实说"有 X 个在流程中，不过贵司是我的首选因为 XX" |
| 你最大的优点 / 缺点？ | 自我认知能力、情商 | 优点：具体案例支撑；缺点：**不要说致命缺点**，要说"我有不足 XX，现在通过 XX 方法在改进"（如：业务理解力不够→现在每次做需求先问 3 个为什么） |
| 能接受加班吗？ | 抗压能力、文化匹配 | 不直接说能/不能，讲："我认可项目关键期需要集中精力冲刺，但也注重效率和工作质量。之前做 XX 项目，大促期间连续奋战 X 周，最后顺利上线" |
| 期望薪资？ | 💡 谈薪环节，别随便说！ | 见下节"谈薪策略" |

### HR 面禁忌（命中任何一个都可能直接挂）

- ❌ 吐槽前公司 / 前同事 / 前老板任何坏话
- ❌ 撒谎（伪造项目、学历、薪资流水，背调 100% 查到）
- ❌ 频繁跳槽 + 理由都是"公司不行"（稳定性直接判负）
- ❌ 对薪资斤斤计较但说不出任何技术追求（被认为只看钱）

## 九、谈薪策略（最容易吃亏的环节）

### 9.1 谈薪前的情报工作

1. **查市场价**：用脉脉、OfferShow、BOSS直聘查同年限、同城市、同岗位的**薪资区间**
2. **了解总包结构**：大厂 Offer 通常由这些构成，不能只看月薪：
   ```
   总包 = 月薪 × （12 + 年终奖月数）
         + 股票/期权（分 N 年归属，注意归属比例）
         + 签字费（一次性，注意服务期协议）
         + 补贴（餐补/交通/住房/夜班车折算）
   ```
3. **手上有至少一个 Offer 再谈**：手里有牌不慌，没牌时谈价最吃亏

### 9.2 当 HR 问"你的期望薪资是多少？"

| 情况 | 应对话术 |
|:---|:---|
| 你有其他 Offer 且价位明确 | "我目前有 XX 公司给的总包大概是 **XX 万（略低于或持平你的目标值）**，如果贵司能给到 **YY 万**，我会优先考虑贵司" |
| 你没有其他 Offer，但知道市场价 | "根据我对行业和岗位的了解，这个级别通常的总包范围是 **A~B 万**，我个人期望的合理区间是 **(A+B)/2 ~ B 万**，具体我也愿意根据贵司的薪酬体系沟通" |
| HR 压价："我们这个级别最高只能给到 X" | "X 比我的预期低一些。请问薪资之外，**股票 / 签字费 / 补贴 / 入职级别**上还有调整空间吗？如果级别能到 PX+1 / 签字费有 XX 万，我可以接受" |

### 9.3 几个绝对不要做的事

- ❌ **不要漫天要价**：超出市场价 50% 以上，直接被认为不真诚，Pass
- ❌ **不要说"你们能给多少"把球踢回去**：HR 只会按最低档位给你
- ❌ **不要接受口头承诺**：所有薪资、级别、归属、签字费必须写在正式 Offer 邮件里

## 十、复盘：每面必做，24 小时内完成

用一份固定模板记录，面 10 家之后你会有一本自己的《面试真题手册》：

```
公司：XX 部门：YY 轮次：一面 日期：YYYY-MM-DD 结果：过/挂
──────────────────────────────
1. 自我介绍 + 项目介绍环节：
   - 面试官追问了什么？我答得好吗？有没讲清楚的点？
2. 八股环节（逐题列）：
   - Q1：XXX  我的回答：...  追问点：...  扣分/加分点：...
   - Q2：XXX  ...
```
