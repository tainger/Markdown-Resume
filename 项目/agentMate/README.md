## 项目背景

AgentMate 是企业级 AI Agent 平台，核心能力包括：
- RAG 知识库问答
- Skill 技能体系
- 可观测/可中断/可回放
- 多 Agent 协作

技术栈：Spring AI + Milvus + DashScope（阿里云百炼）
